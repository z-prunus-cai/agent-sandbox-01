# 规格：多个 Markdown 片段拼接成一个 Word 文档（Java）

## 1. 目标

用 Java 把多个 Markdown 片段按一棵章节树拼成一个 .docx 文档。每项功能放在独立的源文件中，可以只取其中一部分单独实现。

## 2. 平台与版本

| 组件 | 版本 |
| --- | --- |
| JDK | 25 |
| Apache POI（`org.apache.poi:poi-ooxml`） | 5.5.1 |
| commonmark-java（`org.commonmark:commonmark`，以及 `commonmark-ext-gfm-tables`、`commonmark-ext-gfm-strikethrough`、`commonmark-ext-task-list-items`、`commonmark-ext-footnotes`、`commonmark-ext-autolink`） | 0.30.1 |
| 测试：JUnit（`org.junit.platform:junit-platform-console-standalone`） | 6.1.3 |
| 测试：完整 OOXML schema（`org.apache.poi:poi-ooxml-full`） | 5.5.1 |

不提供构建工程（Gradle、Maven 文件）和依赖下载脚本。文档列出依赖坐标（Gradle 写法）；示例和测试用 `java` / `javac` 命令运行，classpath 由读者提供。

目标阅读软件是 Microsoft Word。

## 3. 交付物

目录 `md2docx/`，文档用中文，代码标识符用英文：

| 路径 | 内容 |
| --- | --- |
| `BRIEF.md`、`attachments/` | 说明文档 |
| `examples/` | Java 源码：拼接器与各项功能，以及可运行的示例入口和示例 Markdown |
| `tests/` | JUnit 测试 |

## 4. 行为

### 4.1 输入与输出

- 输入：一棵有序的章节树，加上文档级选项。每个章节可以有标题、Markdown 正文、图片根目录（`baseDir`）和子章节。
- 输出：一个 .docx 文档，写入 `OutputStream` 或返回字节数组。
- 拼接器不保存状态，可以被多个线程同时使用。

### 4.2 核心拼接

- 深度为 d 的章节，标题为 d 级标题。
- 片段内部的标题整体平移：片段中最浅的一级落在章节标题的下一级，相对层级不变。超过 9 级的按 9 级处理。
- 章节标题的四种来源：显式传入；取片段开头的标题（并从正文中移除）；只有标题、没有正文（用于归组）；没有标题（正文直接接在上级标题下，正文中的标题与同级章节标题平级）。
- Markdown 支持：段落；粗体、斜体、删除线、行内代码；有序、无序列表，多级嵌套，任务列表；GFM 表格（列对齐、表头跨页重复、行不跨页拆分、按内容长度分配列宽）；代码块（等宽字体，保留缩进与空行）；引用块（可嵌套）；分割线；链接与自动识别的网址；`<br>` 换行。
- 其他内联 HTML 只保留文字；HTML 块去掉标签后按纯文本输出。

### 4.3 跨片段处理

- 脚注标签按片段隔离：两个片段都用 `[^1]` 时生成两个独立的 Word 原生脚注。
- 每个有序列表重新编号，保留起始数字。
- 锚点链接 `[文字](#标题)` 先在本片段内查找，再在全文查找；锚点按 GitHub 的规则生成（含重复标题的序号后缀）。找不到目标时只输出文字。
- 两个相邻片段首尾都是表格时，中间插入一个空段落，使 Word 不把它们合并成一个表格。

### 4.4 图片与安全默认值

- 图片相对路径按所在章节的 `baseDir` 解析；支持 PNG、JPEG、GIF、BMP；超出页面宽度时等比缩小；单独成段的图片居中。
- 默认的图片读取只接受 `baseDir` 内的文件和 `data:image/...;base64` 数据，不发起网络请求；拒绝 `..`、绝对路径等越出 `baseDir` 的路径。图片读取方式可替换。
- 只有 `http`、`https`、`mailto`、`ftp` 链接生成超链接，其他协议只输出文字。
- 清除 XML 1.0 不允许的字符。

### 4.5 文档级排版（选项，默认全部关闭或为空，另有说明的除外）

- 文档标题、副标题。
- 目录：Word 目录域，收录 1 到 n 级标题；目录项预先填好并可点击跳转；可选让 Word 打开文档时更新域（默认开启）。
- 标题自动编号：用 Word 多级列表编号，不写成文字。
- 分页：顶级章节之间分页（单个章节可以覆盖）；有标题或目录时正文另起一页（默认开启）。
- 页脚居中页码；模板已有页脚时不重复添加。
- 模板：复用 .docx / .dotx 的样式、页面设置和页眉页脚，丢弃其正文；样式按名称匹配（包括本地化 Word 保存的样式 ID）；模板缺少的样式用内置样式补上；模板标题样式已带编号时不再叠加编号；.dotx 转为 .docx 的内容类型。
- 不使用模板时的默认字体：西文、东亚、等宽各一种，可配置。

### 4.6 错误与边界

- 章节树为空、正文为空：生成只含已有内容的合法文档。
- 图片不存在、越界、格式不支持、`data:` 数据损坏：不中断生成，输出图片的替代文字。
- 模板文件不存在或不是 .docx / .dotx：抛出异常，说明原因。

## 5. 正确性验证

- 生成文档的各部件（document、styles、numbering、footnotes、settings、footer 等）按 ECMA-376 完整 schema 校验。
- 无法在 Microsoft Word 中实测，只能依赖 schema 校验；文档中注明。

## 6. 非目标

- LaTeX 公式、代码语法高亮、HTML 块的渲染；
- 远程图片；
- 构建工程、依赖下载与打包发布；
- 读取或修改已有 .docx 的正文；
- 输出 .docx 以外的格式。

## 7. 未指定项与假设

- 未指定：依赖如何获得。示例假设读者用自己的构建工具按第 2 节的坐标解析依赖（含传递依赖），检查命令通过环境变量 `CLASSPATH` 接收这些 jar。
- 未指定：默认字体。示例假设西文 Calibri、东亚 Microsoft YaHei、等宽 Consolas。
- 未指定：页面尺寸。示例假设 A4，页边距 2.54 cm；使用模板时以模板为准。
