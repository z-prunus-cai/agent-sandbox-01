== 概述

本章介绍订单履约系统的业务背景与目标读者。中文正文渲染是这个 POC 的**核心验证点**:在 CI 容器里,缺 CJK 字体会导致中文出现方块或空白。

=== 业务背景

订单履约(Order Fulfillment)覆盖从「用户下单」到「商品送达」的全过程。系统需要协调 *库存*、*支付*、*物流* 三个子系统,并对外提供统一的订单状态查询。

关键指标:

[cols="1,2,1", options="header"]
|===
| 指标 | 说明 | 目标值
| 履约时长 | 下单到发货的平均耗时 | < 2 小时
| 准时率 | 承诺时间内送达的订单占比 | > 98%
| 库存准确率 | 系统库存与实物一致的比例 | > 99.5%
|===

=== 混排与样式验证

这一段刻意混合 **中文粗体**、_中文斜体_、`中文等宽 code`、以及 English **bold** 和 _italic_,用来验证 theme 的 `catalog` 字体映射(已知坑 3)是否把四个 variant 都指对了路径。若粗体失效,中文粗体会 fallback 到 Helvetica 从而直接丢字。
