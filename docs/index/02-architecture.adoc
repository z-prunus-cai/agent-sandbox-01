= 系统架构
:keywords: 架构, plantuml

本页用 PlantUML 组件图展示子系统边界。图表使用 **Smetana 布局引擎**(`!pragma layout smetana`),
构建期无需 Graphviz。Confluence Publisher 会把 PlantUML 渲染成 PNG,作为**附件**上传并插入本页。

[plantuml, diagram-architecture, png]
....
@startuml
!pragma layout smetana
skinparam componentStyle rectangle

package "订单履约系统" {
  [订单服务] as Order
  [库存服务] as Inventory
  [支付服务] as Payment
  [物流服务] as Logistics
}

database "订单库" as OrderDB
queue "事件总线" as Bus

Order --> OrderDB : 持久化
Order --> Bus : 发布订单事件
Inventory --> Bus : 订阅/扣减
Payment --> Bus : 订阅/收款
Logistics --> Bus : 订阅/发货
@enduml
....

== 架构说明

* **订单服务**:聚合根,负责订单状态机与一致性边界。
* **事件总线**:解耦子系统,保证最终一致性。
* **库存 / 支付 / 物流**:各自独立部署,通过事件协作。
