== 业务背景

订单履约(Order Fulfillment)覆盖从「用户下单」到「商品送达」的全过程。系统需要协调
*库存*、*支付*、*物流* 三个子系统,并对外提供统一的订单状态查询。

关键指标:

[cols="1,2,1", options="header"]
|===
| 指标 | 说明 | 目标值
| 履约时长 | 下单到发货的平均耗时 | < 2 小时
| 准时率 | 承诺时间内送达的订单占比 | > 98%
| 库存准确率 | 系统库存与实物一致的比例 | > 99.5%
|===
