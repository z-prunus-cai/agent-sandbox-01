## 5.1 特征值与特征向量

### 5.1.1 特征值 / 特征向量定义（Av=λv）

对一个 n×n 方阵 A，如果存在一个非零向量 v 和一个标量 λ，使得 A 作用在 v 上等于把 v 乘以 λ，那么 λ 叫作 A 的特征值，v 叫作对应于 λ 的特征向量。写成等式就是：

Av = λv,  v ≠ 0

几何上，A 一般会把一个向量既拉伸又转向；但对特征向量这条特殊方向，A 只做拉伸（或压缩、反向），不改变它所在的那条直线。

可以把矩阵 A 想成一个"作用"：喂进去一个向量，吐出来另一个向量。大多数方向进去出来会转弯，唯独沿着特征向量的方向，出来的向量还落在同一条直线上，只是长度变了 λ 倍。所以特征向量就是"A 作用下方向保持不变的轴"，λ 是这条轴上的缩放倍数：λ>1 拉长、0<λ<1 缩短、λ<0 反向、λ 为复数则暗含旋转。

有两个常见易错点。第一，必须要求 v≠0：如果允许 v=0，那么任何 λ 都能让 Av=λv 成立（两边都是零），这就没有意义了，所以零向量永远不算特征向量。第二，λ 本身可以等于 0：λ=0 对应 Av=0 有非零解，也就是 A 是奇异（不可逆）的，此时对应的特征向量落在 A 的零空间里。换句话说，"A 有没有 λ=0 这个特征值"和"A 可不可逆"是同一件事的两种说法。

### 5.1.2 特征方程 det(A−λI)=0 与特征多项式

要找特征值，先把定义改写：Av=λv 等价于 (A−λI)v=0 有非零解 v。一个齐次方程组有非零解，当且仅当它的系数矩阵不可逆（行列式为零）。于是得到特征方程：

det(A − λI) = 0

把这个行列式按 λ 展开，会得到一个关于 λ 的 n 次多项式，称为特征多项式 p(λ)；它的根就是 A 的全部特征值。

为什么要绕到行列式？因为直接从 Av=λv 里 λ 和 v 两个未知量耦合在一起，不好解。移项成 (A−λI)v=0 后，问题变成"哪些 λ 让这个方程有非零解"。而"方阵乘一个非零向量得到零"意味着这个方阵把某个方向压扁了，也就是它奇异、行列式为 0——这就是把求特征值转化成解一个纯 λ 的多项式方程的关键一步。

一个 n×n 矩阵的特征多项式次数恰好是 n，所以由代数基本定理，A 在复数范围内（计入重数）恰有 n 个特征值。初学者容易忽略"计入重数、计入复数"这两个前提：实矩阵可能没有实特征值（见 5.1.6 旋转矩阵），也可能同一个特征值重复出现（见 5.1.4 重数）。

### 5.1.3 求特征值与求特征向量

标准两步法：第一步解特征方程 det(A−λI)=0 得到所有特征值 λ；第二步对每一个 λ，回代解齐次方程组

(A − λI)v = 0

它的解空间就是 A−λI 的零空间（nullspace），这个零空间里的任意非零向量都是该 λ 的特征向量。

直觉上，第一步是"找出哪些缩放倍数 λ 是允许的"，第二步是"对每个允许的 λ，找出被这样缩放的方向有哪些"。注意特征向量从来不是唯一的：如果 v 是特征向量，那么 2v、−v、任意非零倍数也都是（因为 A(cv)=cAv=c·λv=λ(cv)）。所以我们通常说的是"特征方向"或"特征空间"，具体取哪个代表向量、要不要归一化，是习惯问题。

最小例子，取对称矩阵

A = [[2, 1], [1, 2]]

则 det(A−λI)=(2−λ)²−1=0，解得 λ=1 和 λ=3。回代 λ=3 得特征向量方向 [1,1]，回代 λ=1 得 [1,−1]。本机 numpy 实测特征值为 {1.0, 3.0}，与手算一致。

### 5.1.4 代数重数 vs 几何重数

同一个特征值可以从两个角度"数"它的重数。代数重数是 λ 作为特征多项式根出现的次数；几何重数是 λ 对应特征空间的维数，也就是 dim null(A−λI)（该 λ 下线性无关特征向量的个数）。二者永远满足：

1 ≤ 几何重数 ≤ 代数重数

这条不等式是理解"能不能对角化"的核心（见 5.2）。直觉上，代数重数是"这个 λ 在多项式意义上重复了几次"，几何重数是"这个 λ 实际能提供几个独立方向"。理想情况两者相等，此时该特征值提供的独立特征向量足够多；一旦几何重数严格小于代数重数，就说明"名义上重复了 k 次，却凑不出 k 个独立方向"，这种矩阵称为亏损（defective，见 5.2.3）。

一个经典易错点：不要以为特征值重复就一定亏损。对称矩阵 [[2,1],[1,2]] 若换成有重根的对称阵，几何重数仍会补满；真正亏损的是像

[[2, 1], [0, 2]]

这样的矩阵——λ=2 代数重数为 2，但 (A−2I) 的零空间只有一维，几何重数只有 1。本机 SymPy `eigenvects()` 实测对它只返回一个特征向量 [1,0]（三元组显示 `(2, 2, [[1,0]ᵀ])`，即"特征值 2、代数重数 2、只有 1 个特征向量"），直接坐实几何重数 1 < 代数重数 2。

### 5.1.5 迹=特征值之和、行列式=特征值之积

不必真的解出特征向量，就能用两条速查关系把特征值和矩阵的两个易算量联系起来：迹（对角元之和）等于全部特征值之和，行列式等于全部特征值之积（都按重数计）：

tr(A) = Σ λᵢ

det(A) = Π λᵢ

这两条最实用的场景是当校验和心算。比如 2×2 矩阵解出两个特征值后，立刻用"和=迹、积=行列式"验一遍，几秒钟就能发现算错；反过来，已知迹和行列式也能快速反推 2×2 的两个特征值。它们也解释了 5.1.1 里的观察——det(A)=Πλ 中只要有一个 λ=0，行列式就是 0，A 就奇异。

最小例子仍取 A=[[2,1],[1,2]]，λ=1,3：迹 2+2=4=1+3，行列式 4−1=3=1×3。本机实测 trace(A)=4.0=Σλ、det(A)=3.0=Πλ（数值上 det 显示为 2.9999999999999996，是浮点舍入，属正常）。

### 5.1.6 特殊情形：三角 / 对角阵、重特征值、复特征值

有几类矩阵的特征值可以一眼看出或有特殊结构。三角矩阵（含对角阵）的特征值就是它的对角元，因为此时 det(A−λI) 直接是各对角元减 λ 的连乘。实矩阵若有复特征值，它们必成共轭对出现。纯旋转矩阵

[[cos θ, −sin θ], [sin θ, cos θ]]

没有实特征值（θ 不是 π 的整数倍时），其特征值为一对共轭复数 e^{±iθ}。

三角/对角阵这条非常省事：看到上三角或下三角矩阵，不用算行列式，对角线上的数就是全部特征值。复特征值这条则解释了一个初学者常见的困惑——"为什么一个实实在在的实矩阵会算出虚数特征值？"旋转矩阵就是最直观的答案：平面上纯旋转没有任何一条方向能保持不变（转一下就偏了），所以它根本没有实的特征向量，"方向不变"这件事只能在复数意义下成立，对应的复特征值 e^{±iθ} 恰好把旋转角 θ 编码了进去。

要特别当心一个陷阱：对角元相同不等于可对角化。[[2,1],[0,2]] 的对角元都是 2、看起来"很对角"，但它恰恰是上面 5.1.4 那个亏损、不可对角化的例子。"对角元"和"能对角化"是两回事。

## 5.2 对角化与矩阵的幂

### 5.2.1 对角化 A=SΛS⁻¹

如果 A 有 n 个线性无关的特征向量，把它们作为列拼成矩阵 S，把对应的特征值放到对角线上组成对角阵 Λ，那么 A 可以写成：

A = S Λ S⁻¹

（等价地 S⁻¹AS=Λ）。这叫作把 A 对角化。

对角化的意义是"换一副坐标看 A"。S⁻¹ 把向量换到以特征向量为坐标轴的新坐标系，Λ 在新坐标系里只是对每根轴各自做缩放（对角阵最简单），S 再换回原坐标系。所以 A 复杂的作用被拆解成"进特征坐标 → 各方向独立缩放 → 出特征坐标"三步，这正是后面算矩阵幂、矩阵指数、解微分方程时把矩阵问题降成一堆标量问题的总开关。

一个命名差异要留意，否则对照工具时会困惑：MIT/Strang 习惯写 A=SΛS⁻¹（S 是特征向量矩阵、Λ 是特征值对角阵）；而 SymPy 的 `diagonalize()` 返回一对 `(P, D)`，满足

M = P · D · P⁻¹

这里 P 就是 S、D 就是 Λ，符号不同但内容完全一样，不是两种不同的分解。

### 5.2.2 可对角化的充要条件

A（n×n）可对角化，当且仅当它有 n 个线性无关的特征向量；等价地，当且仅当每一个特征值的几何重数都等于其代数重数。特征值两两互不相同是一个充分（但非必要）条件——不同特征值的特征向量自动线性无关，凑够 n 个就够了。

初学者可以这样把握逻辑链：要对角化，S 必须可逆（因为 A=SΛS⁻¹ 里要用到 S⁻¹），而 S 由特征向量作列，可逆就要求这 n 个特征向量线性无关。什么时候凑不满 n 个？就是某个特征值几何重数不足（5.1.4 的亏损情形）。所以"几何重数处处等于代数重数"正是"特征向量恰好凑满 n 个"的精确说法。"充分非必要"的意思是：特征值全不同一定能对角化，但能对角化的矩阵不一定特征值全不同（重特征值只要几何重数补满也行）。

补充一条重要但此处点到即止的结论：实对称矩阵（更一般地正规矩阵）总是可对角化，而且能用一组正交的特征向量对角化——这是谱定理，承接大主题3的正交性，细节不在本报告展开。本机 SymPy `Matrix.is_diagonalizable()` 可直接检验一个矩阵是否满足上述充要条件。

### 5.2.3 不可对角化（亏损 / defective）矩阵

当某个特征值的几何重数严格小于代数重数（也就是特征向量凑不满 n 个）时，A 不可对角化，称为亏损矩阵。此时退一步用约当标准形（Jordan form）来"接近对角"，把无法对角化的部分收进对角线上方的 1，这属于大主题8的内容，本报告不展开。

理解上，亏损就是 5.2.2 那个"S 凑不满、不可逆"的具体后果。它并不罕见——只要有重特征值又补不满方向就会发生。最小例子仍是

[[2, 1], [0, 2]]

它 λ=2 代数重数 2、几何重数 1，亏损。本机 SymPy `is_diagonalizable()` 实测返回 False，与 5.1.4 里 eigenvects 只给出一个特征向量互相印证。

### 5.2.4 矩阵的幂 A^k=SΛ^kS⁻¹

一旦 A=SΛS⁻¹，求它的高次幂就变得极其简单。因为相邻两个因子里 S⁻¹S 抵消：

A^k = S Λ^k S⁻¹

而 Λ 是对角阵，Λ^k 只是把对角线上的每个特征值各自取 k 次方。于是一个本来要做 k−1 次矩阵乘法的问题，被降成"对几个标量取 k 次方"。

这就是特征分解最有说服力的用途之一：分析矩阵的长期／高次行为。因为 A^k 的大小完全由 λ^k 决定，哪个 |λ| 最大，长期就由那个特征方向主导（这也预告了 5.3 的稳定性和 5.4 的马尔可夫稳态）。

经典应用是斐波那契数列。取

[[1, 1], [1, 0]]

它的 k 次幂的 (0,1) 元恰好是第 k 个斐波那契数 F_k。本机实测该矩阵的 10 次幂 [0,1] 元=55（正是 F_10），且用 SΛ⁶S⁻¹ 算出的 A^6 与直接的 `np.linalg.matrix_power(A,6)` 逐元素误差为 0。NumPy 里直接算矩阵幂用 `np.linalg.matrix_power`。

### 5.2.5 相似性与对角化的关系

两个矩阵 A、B 相似，指存在可逆矩阵 M 使得

B = M⁻¹ A M

相似矩阵共享相同的特征值（因而特征多项式、迹、行列式也都相同）。对角化不过是"A 相似于一个对角阵 Λ"这个特例。

直觉上，相似就是"同一个线性变换在不同基下的两张不同矩阵表"——换基不改变变换本身的内在量（特征值就是这样的内在量），只改变数字的摆放。所以对角化可以重新表述为一句话：能对角化 = 能找到一组基（特征向量基）让这张矩阵表变成最简单的对角形式。相似矩阵的完整讨论见大主题8，此处点到即止。

## 5.3 微分方程与矩阵指数

### 5.3.1 线性方程组 du/dt=Au 的解

一阶线性常系数微分方程组

du/dt = A u,  u ∈ ℝⁿ

的解可以统一写成初值乘上矩阵指数：

u(t) = e^{At} u(0)

如果 A 可对角化，把初值按特征向量展开 u(0)=Σ cᵢ vᵢ，解就分解成每个特征方向独立演化：

u(t) = Σ cᵢ e^{λᵢ t} vᵢ

这是标量方程 du/dt=au 解为 u(t)=e^{at}u(0) 的向量推广。单个变量时增长率 a 决定指数快慢；多个耦合变量时，A 把它们纠缠在一起，而特征向量恰好是"解耦方向"——沿每根特征轴，系统各自按自己的增长率 e^{λt} 独立演化，彼此不再干扰。把这些独立演化按初值权重 cᵢ 叠加，就是整个系统的解。这也说明为什么特征值的符号（下一条）能直接决定系统命运。

### 5.3.2 矩阵指数 e^{At} 的级数定义与特征分解计算

矩阵指数照搬标量指数的泰勒级数定义，把幂换成矩阵幂：

e^{At} := Σ_{k≥0} (At)^k / k!

这个级数对任意方阵都收敛。若 A=SΛS⁻¹，代入并利用 A^k=SΛ^kS⁻¹，可得一个便于计算的公式：

e^{At} = S · e^{Λt} · S⁻¹

其中 e^{Λt} 只是对角线上各元素取标量指数 e^{λᵢt}。于是又一次把矩阵运算降成了标量运算。

要分清"定义"和"实际怎么算"。级数定义在理论上干净，但直接截断级数在数值上不稳（尤其 A 的元素大时）。SymPy 的 `Matrix.exp()` 能符号地求矩阵指数；而工程数值库 SciPy 的 `scipy.linalg.expm` 既不截断级数、也不走特征分解，而是用 Padé 逼近加上 scaling-and-squaring 技术（Al-Mohy & Higham 2009 算法，scipy 1.17.1 官方文档），以获得更好的数值稳定性。这三条路（级数定义、谱方法 SΛS⁻¹、Padé）在数学上给出同一个 e^{At}，只是精度与效率不同。本机实测：谱方法 S·e^{Λt}·S⁻¹ 与 `scipy.linalg.expm` 在 t=0.5 时的最大逐元素误差约 2.2e-16（机器精度量级），证实两者一致。

### 5.3.3 稳定性判据（特征值实部符号）

由 u(t)=Σcᵢe^{λᵢt}vᵢ 可知，系统长期行为由各 e^{λt} 主导，而 |e^{λt}|=e^{Re(λ)·t}，所以只看特征值的实部符号：

所有 Re(λ) < 0 ⇒ u(t) → 0（渐近稳定 / 收敛）

任一 Re(λ) > 0 ⇒ 发散

最大 Re(λ) = 0（其余 < 0）⇒ 临界（有界不衰减 / 振荡）

关键在于抓住 e^{λt} 的模只取决于实部这一点：虚部只贡献振荡（旋转），不改变幅度大小，真正决定"越来越大还是越来越小"的是实部。所以判断一个线性系统稳不稳定，不必解出全解，算出特征值、看实部符号就够了。最小例子：

B = [[−2, 1], [0, −3]]

它是上三角阵，特征值直接读对角线为 {−2, −3}，全为负实部，系统收敛。本机实测 B 的特征值为 [−2, −3]，符合。

### 5.3.4 与 A^k（离散）的类比

同一套特征分解，在离散和连续两种动态里长这样：离散迭代 u_{k+1}=A u_k 的长期行为看 λ^k，连续演化 du/dt=A u 的长期行为看 e^{λt}。两者一一对应：

λ^k  ↔  e^{λt}

稳定阈值也对应：离散看 |λ| 与 1 比较（|λ|<1 收敛、|λ|>1 发散、|λ|=1 临界），连续看 Re(λ) 与 0 比较。

这个类比很值得记住，因为它把 5.2（矩阵幂、离散）和 5.3（矩阵指数、连续）串成一件事：无论离散还是连续，特征分解都把系统拆成各方向独立演化，长期命运由"最主导的那个特征值"决定，只是离散用乘幂 λ^k、连续用指数 e^{λt} 来度量增长。下一节 5.4 的马尔可夫矩阵正是离散侧 |λ|=1 临界情形的典型（λ=1 对应稳态不衰减）。

## 5.4 马尔可夫矩阵与 Fourier 级数（离散↔连续视角）

> 分账说明（一句）：本节走**线代视角**（马尔可夫矩阵的特征值/特征向量、稳态=λ=1 特征向量）；与 L2-03「马氏链/平稳分布」的**随机过程视角**互补，不重复立项。

### 5.4.1 马尔可夫（随机）矩阵定义

一个（列）随机矩阵指所有元素非负、且每一列的元素之和都等于 1 的方阵。它把一个概率分布向量映成另一个概率分布向量（各分量非负、总和守恒为 1）。

直觉上，马尔可夫矩阵描述"状态之间的转移概率"：第 j 列列出"当前处在状态 j 时，下一步转到各个状态的概率"，列和为 1 表示"下一步一定落在某个状态里，概率不会凭空多出或消失"。因为总概率守恒，反复迭代 M 不会让向量爆掉或缩没，这正是后面 λ=1、|λ|≤1 结论的根源。

这里有一个必须两边都记的命名分歧：MIT/Strang 惯用列随机（每列和为 1，稳态是右特征向量）；而许多概率论教材和 Wikipedia 用行随机（每行和为 1，稳态是左特征向量/行向量）。两者只是转置约定不同，不是矛盾。本报告统一采用列随机。

### 5.4.2 λ=1 必存在、其余 |λ|≤1、稳态=λ=1 的特征向量

列随机矩阵一定有特征值 λ=1，且所有特征值满足 |λ|≤1（谱半径为 1）。对应 λ=1 的（右）特征向量，归一化成概率分布后就是稳态分布。

λ=1 为什么必然存在有一个漂亮的理由：全 1 行向量 𝟙ᵀ 是 M 的左特征向量，因为"每列和为 1"正好写成

𝟙ᵀ M = 𝟙ᵀ

而矩阵和它的转置有相同特征值，所以 M 也有右特征值 1。至于 |λ|≤1，直觉是概率守恒不允许任何方向被放大超过 1 倍，否则反复迭代总概率就会发散。λ=1 特征向量之所以叫"稳态"，是因为 Mx=x——它是迭代下不再变化的分布，一旦系统到达它就停在那里。

最小例子：

M = [[0.9, 0.2], [0.1, 0.8]]

两列和都是 1。本机实测特征值为 {1, 0.7}，λ=1 的特征向量归一化后为 [2/3, 1/3]（实测 [0.666667, 0.333333]），即稳态分布。

### 5.4.3 稳态收敛条件（正矩阵 / Perron–Frobenius 要点，浅提）

如果马尔可夫矩阵是正的（所有元素严格大于 0，或更一般地某个幂为正、即不可约且非周期），那么 λ=1 是唯一的模最大特征值且是单根，其余特征值都严格满足 |λ|<1。于是从任意初始分布出发，M^n 都收敛到那个唯一的稳态分布。这是 Perron–Frobenius 定理的要点。反过来，如果存在别的 |λ|=1 的特征值（对应周期性或可约结构），系统就不会收敛到单一稳态，而可能永远振荡。

为什么"正"这么关键？回到 5.2.4／5.3.4 的主导特征值思想：M^n 的长期行为由最大 |λ| 主导。当 λ=1 是唯一的模最大值时，其余 |λ|<1 的成分随 n 增大按 |λ|^n 迅速衰减到 0，只剩 λ=1 那一项，系统就被"吸"到稳态。而若有两个模为 1 的特征值（比如 λ=1 和 λ=−1），后者不衰减、会反复翻转，系统就在几个分布之间来回跳，不收敛。"所有元素为正"是保证 λ=1 独占模最大的一个简单充分条件。

最小例子：上面的 M 所有元素为正，本机实测 M^200 的两列都收敛到 [2/3, 1/3]（即 [0.666667, 0.333333]），与稳态一致。

### 5.4.4 Fourier 级数作为「正交基下投影」的特征视角（浅提）

Fourier 级数把一个函数按一组正交基 {e^{ikx}}（或等价的 sin/cos 基）展开，每个系数等于该函数在对应基向量上的投影（内积）。这与线代里"用一组正交的特征向量作基、把向量展开成各分量、每个分量独立演化"是同一个"正交基投影"思想，只不过从有限维向量搬到了无限维的函数空间。

把这条和前几节接起来看会很通透：复指数 e^{ikx} 其实是微分算子 d/dx（以及平移算子）的特征函数——对它求导只是乘上 ik，方向（函数形状）不变、只缩放，正是 5.1 里 Av=λv 的函数版本。所以"用特征向量基解耦"和"用 Fourier 基分析函数"是同一思想在有限维与无限维的两个面孔（承接大主题3的正交性）。本节仅点到即止，Fourier 分析的完整内容不在此展开。

环境串：`基线 Py3.11.15/np2.4.6/gcc13.3 @2026-07-26`（实测 python 3.11.15 / numpy 2.4.6 / sympy 1.14.0 / scipy 1.17.1）。

```python
import numpy as np, sympy as sp, scipy.linalg as sla
A = np.array([[2.,1.],[1.,2.]])

assert abs(np.trace(A) - w.sum()) < 1e-9       # tr = Σλ = 4

                   (S @ np.diag(w**6) @ np.linalg.inv(S)).real)      # 5.2: A^6

J = sp.Matrix([[2,1],[0,2]]); assert not J.is_diagonalizable()      # 5.1/5.2: 亏损
t = 0.5
assert np.allclose(sla.expm(A*t),
                   (S @ np.diag(np.exp(w*t)) @ np.linalg.inv(S)).real)  # 5.3: e^{At}
M = np.array([[0.9,0.2],[0.1,0.8]])            # 列随机
wm, Sm = np.linalg.eig(M); assert np.isclose(max(wm), 1.0)          # 5.4: λ=1
```
