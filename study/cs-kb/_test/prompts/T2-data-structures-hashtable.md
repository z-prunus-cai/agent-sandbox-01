## 4.1 哈希函数（锚 CLRS 4th §11.3）
- 哈希表/哈希函数的基本定义：键空间 → 槽位（slot/bucket）映射；直接寻址表 vs 哈希表的关系（CLRS §11.1 直接寻址作引入）。
- 除留余数法（division method）：h(k)=k mod m；m 的选取（避 2 的幂、宜取质数）。
- 乘法法（multiplication method）：h(k)=⌊m·(k·A mod 1)⌋；常数 A 的选取（Knuth 建议值）。
- 全域哈希（universal hashing，CLRS §11.3.3）：随机选哈希函数族抵御对抗输入、期望碰撞界。
- 简单均匀哈希假设（simple uniform hashing）：分析用的理想化前提。
- 好哈希函数的判据：均匀分布、确定性、雪崩/低碰撞直觉。
- 〔实证机会，可选〕Python `hash()` 对若干键的分布观察。

## 4.2 链地址法 / 拉链法（锚 CLRS 4th §11.2 Hashing with chaining）
- 桶数组 + 每桶一条链表（或其他结构）解决冲突的基本结构。
- 插入/查找/删除操作与其代价（查找期望 Θ(1+α)，α 为负载因子）。
- 简单均匀哈希下成功/不成功查找的期望长度分析。
- 链地址的空间开销（指针/结点）与优点（删除简单、α 可 >1）。
- 〔实证机会，可选〕Python 手写链地址哈希表（list of lists）。

## 4.3 开放定址法（锚 CLRS 4th §11.4 Open addressing）
- 开放定址基本思想：所有元素存于表内，冲突时按探测序列找下一空槽；α ≤ 1 约束。
- 线性探测（linear probing）：探测序列与一次聚集（primary clustering）问题。
- 二次探测（quadratic probing）：缓解一次聚集、二次聚集问题、常数选取约束。
- 双重哈希（double hashing）：h(k,i)=(h1(k)+i·h2(k)) mod m；h2 与 m 互质要求，近均匀探测。
- 删除的复杂性：墓碑标记（deleted/tombstone），删除破坏探测链的问题。
- 开放定址查找期望代价（成功/不成功，与 α 的关系）。
- 〔实证机会，可选〕Python 探测序列/聚集可视化实验。

## 4.4 负载因子与再散列（锚 CLRS 4th §11.2-11.4 负载因子 α；交叉 CPython dictobject.c 实现）
- 负载因子 α = n/m 的定义及其对各操作期望代价的支配作用。
- 动态扩容/再散列（rehashing）：扩容阈值、表倍增（table doubling）、重哈希全部元素、O(1) 均摊插入（引 CLRS Ch16 均摊 / round3b 4.4）。
- 缩容（shrink）与阈值滞后（避免抖动）直觉。
- CPython dict 的紧凑（compact）dict 实现要点：索引数组 + 紧凑 entries 数组、保序、开放定址探测（含扰动 perturb）、resize 策略与 growth 因子。这里须显式做「CLRS 理论 vs CPython 实现」分歧比对。
- 规范 vs 实现分账：CLRS 讲的通用理论（链地址/开放定址/α 阈值）与 CPython 具体选择（紧凑 dict、伪随机探测、具体扩容倍数/阈值）分开标注；具体常量（如 resize 触发点、扰动位移量）以读源码取证为准，不凭记忆填，取不到标「待核」。
- 〔实证机会，可选〕读 CPython Objects/dictobject.c 的 resize 相关注释与常量；Python 观察 dict 扩容后行为。

## 4.5 最坏 O(n) 退化（锚 CLRS 4th §11.2-11.3；交叉哈希碰撞攻击资料）
- 最坏情形：所有键碰撞到同一桶/同一探测链 → 查找退化为 O(n)。
- 触发条件：坏哈希函数、对抗性/碰撞输入（adversarial input）。
- 缓解手段：全域哈希/随机化哈希（对抗攻击者）、良好负载因子控制、桶内改用平衡树（如 Java 8 HashMap treeify 的做法，作实现对照，具体阈值待核）。
- 安全视角：哈希碰撞 DoS 攻击与 hash randomization（如 CPython PYTHONHASHSEED / SipHash，作实现对照，具体机制标版本/待核）。
- 〔实证机会，可选〕Python 制造碰撞键观察退化。
