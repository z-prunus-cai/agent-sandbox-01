## 每轮内部流程（一个 workflow）
1. **轮前 prep**（主 agent）：为本轮每门课写一条 prompt（`round-prompts/RN-*.md`）；clone 本轮系统课需要的一手源码到 `.reference/`（gitignore）。
2. **阶段 4 取证**：每门课一个 subagent，读 brief + 方法论 + 范例报告 + 自己那条 prompt → 三条腿取证 → **自己 Write** 到 `findings/NNN-*.md`。
3. **阶段 5 对抗质检**：独立 subagent 逐份对照原始 prompt 核对覆盖度 + 方法论符合度 + 红线抽查 → 判 PASS/MINOR/MAJOR。
4. **阶段 5 修订**：MAJOR 与事实错误必修（最小编辑订正）；MINOR 按价值补。
5. **收口**：核验抬头 → 更新 ledger → 提交推送 → 清 scratchpad。
6. 向用户汇报本轮判级摘要，**等批准再进下一轮**。
