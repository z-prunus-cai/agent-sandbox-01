# 执行计划 · 计算机科学知识库

方法论见 `_methodology-skill.md`。**Round = skill 的六个阶段**，每个 round 一个审批门，开跑前等用户批准。

## Round 划分（= skill 阶段，每轮一个审批门）
| Round | 阶段 | 产物 | 内容 |
|-------|------|------|------|
| **R1** | 阶段1 广度 scoping | `round1-map.md` | 多路正交并发检索（权威课纲/行业实践/最新动态），核实时效，合并成查全的对象地图。用户课表 = 种子。 |
| **R2** | 阶段2 中度定方向 | `round2-deep-dive.md` | 对象编 ~10–15 组，每组重点方向 + 组内选型/对比表 + 优先级。 |
| **R3** | 阶段3 造 prompt 库 | `round-prompts/` + `round3-index.md` | 每个「对象×方向」一条可投喂 prompt，subagent 直接落盘。 |
| **R4** | 阶段4 逐条取证 | `findings/NNN-*.md` | 逐条三条腿取证出自足教学报告（量最大，阶段内部按层/优先级分批并发）。 |
| **R5** | 阶段5 对抗质检 | 判级 + 修订 | 独立 subagent 逐点对照 prompt 复核、判 PASS/MINOR/MAJOR、修。 |
| **R6** | 阶段6 收口合并 | 索引 + 对账 | 全库一致性扫描、合并视图、ledger 对账、质检留痕声明。 |

> 课表的**六层**（见 `object-map.md`）不是 round，而是 R2–R4 内部组织内容、分组、依赖排序用的结构。
