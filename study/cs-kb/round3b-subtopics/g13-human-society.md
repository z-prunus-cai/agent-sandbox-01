## L5-09 人机交互 HCI · 小主题清单

### HCI-1 人的认知基础与人因
> 锚点：Rogers-Sharp-Preece 认知章；Norman《DOET》2013（心智模型/概念模型/情感三层次）

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 1.1 | 感知与知觉 | 视/听/触通道特性 + 格式塔组织原则对界面分组/布局的约束 |
| 1.2 | 记忆与学习 | 工作记忆容量限制、识别优于回忆、长期记忆对命名/结构/一致性的要求 |
| 1.3 | 注意与信息加工 | 选择性注意、中断/多任务代价、信息显著性与视觉搜索 |
| 1.4 | 心智模型与认知负荷 | 用户心智模型 vs 设计者概念模型的匹配；执行/评估鸿沟（gulf of execution/evaluation）与负荷控制 |
| 1.5 | 运动与人因定量律 | Fitts 定律（目标获取时间）、Hick-Hyman 定律（选择反应时间）等可量化人因规律 |
| 1.6 | 情感与体验维 | Norman 情感设计三层次（本能/行为/反思）与动机、愉悦对交互质量的影响（UX 具体条目待核） |

### HCI-2 可用性的可测量定义
> 锚点：ISO 9241-11:2018（有效性/效率/满意度 + 使用情境）

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 2.1 | 有效性（effectiveness） | 用户达成指定目标的准确性与完整性 |
| 2.2 | 效率（efficiency） | 达成目标所耗资源（时间/步数/错误率等） |
| 2.3 | 满意度（satisfaction） | 使用过程中的舒适度、主观接受度与情感反应 |
| 2.4 | 使用情境（context of use） | 用户/任务/设备/物理与社会环境的界定——三维度量的前提 |
| 2.5 | 范畴边界 | 可用性 vs 用户体验 vs 可访问性在 ISO 9241 体系内的定位与区分 |

### HCI-3 交互设计原则
> 锚点：Norman《DOET》2013（五原则）；Rogers-Sharp-Preece 设计原则章

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 3.1 | 可视性与反馈 | 状态可见、操作有即时且恰当的反馈 |
| 3.2 | 示能与意符 | affordance（可执行动作的可能性）与 signifier（提示动作的可感线索）之别 |
| 3.3 | 映射 | 控件与效果的自然/空间对应（natural mapping） |
| 3.4 | 约束与防错 | 物理/逻辑/文化约束 + forcing functions/错误预防设计 |
| 3.5 | 一致性与标准 | 内部一致性、外部一致性与平台惯例遵循 |
| 3.6 | 概念模型与系统映像 | 设计者概念模型如何经系统映像（system image）传达给用户 |

### HCI-4 评估方法体系（analytic vs empirical）
> 锚点：Nielsen 10 Heuristics（1994/2020 措辞）；ISO 9241-11；SUS 量表 · 本组唯一可本机演示实证点在 4.1

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 4.1 | 启发式评估 | Nielsen 10 启发式 + 0–4 严重度评级的专家 analytic 法（可本机复现的框架清单实证） |
| 4.2 | 认知走查 | 以学习性/新手可用性为焦点的逐步任务走查 |
| 4.3 | 可用性测试 | 真实用户任务观察，产行为/绩效数据（empirical，需招募用户、非本机可跑） |
| 4.4 | A/B 测试与在线实验 | 对照组指标对比；统计推断（假设检验/功效/样本量）↔ **L2-03** |
| 4.5 | 问卷与标准化量表 | SUS、NASA-TLX 等主观测量工具 |
| 4.6 | 分析法 vs 实证法权衡 | 各方法覆盖点与遗漏点——「何时用哪种」的选型逻辑 |

### HCI-6 无障碍与包容性设计
> 锚点：WCAG 2.2（W3C Rec 2023-10-05；POUR 四原则；移除 4.1.1 Parsing）· 此处做技术标准，与 SEP 社会正当性分账

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 6.1 | 可感知（Perceivable） | 文本替代、字幕、对比度、可适应/可区分的内容呈现 |
| 6.2 | 可操作（Operable） | 键盘可达、充足时间、避免癫痫诱发、可导航 |
| 6.3 | 可理解（Understandable） | 可读、可预测、输入辅助与错误纠正 |
| 6.4 | 健壮（Robust） | 与辅助技术（AT）/未来 user agent 的兼容 |
| 6.5 | 合规等级与准则结构 | A/AA/AAA 三级、86 条成功准则、WCAG 2.2 新增准则与 ISO/IEC 40500 采纳 |
| 6.6 | 辅助技术与包容性设计原则 | 屏幕阅读器/替代输入等 AT；包容性设计取向（技术标准侧，SEP 承公平包容诉求） |

## L5-10 社会伦理职业 / 负责任 AI SEP · 小主题清单

> SEP = 系统对社会的宏观影响 + 规范 + 责任（不做界面级交互）。作为跨层整合 KA，独立清单承「框架 + 规范」骨架，技术手段指回对应课。**本机实证腿弱**：以援引权威条款做可核对断言替代源码/实证两腿。

### SEP-1 规范性伦理框架（分析工具）
> 锚点：CS2023 SEP KA（Analytical Tools）；经典伦理学文本 · 底层分析工具，横切所有下述维度

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 1.1 | 后果论/功利主义 | 以结果/总效用评价技术决策（NIST/EU 风险框架骨架近后果论） |
| 1.2 | 义务论 | 规则/义务/权利本位的判断（ACM Code 的义务腿） |
| 1.3 | 德性论 | 以行为者品格与专业德性为中心 |
| 1.4 | 契约论与正义论 | Rawls 公平/无知之幕在资源分配与公平诉求中的应用 |
| 1.5 | 应用分析法 | 伦理案例分析、利益相关者分析、伦理决策流程——识别技术选择背后隐含框架 |

### SEP-2 专业操守与责任（ACM Code 2018）
> 锚点：ACM Code of Ethics 2018（4 节结构）· 「职业」腿一手承重

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 2.1 | 一般伦理原则（§1） | 公共利益(1.1)、避免伤害(1.2)、诚实(1.3)、公平不歧视(1.4)、尊重隐私(1.6)等条款 |
| 2.2 | 职业责任（§2） | 专业胜任、高质量工作、遵守既有规范、构建稳健安全系统 |
| 2.3 | 职业领导责任（§3） | 领导者对公共利益、团队与制度的额外责任 |
| 2.4 | 遵守准则（§4） | 拥护/推广准则、违反准则的后果 |
| 2.5 | 责任归属与工程落点 | 发布决策/事件响应/whistleblowing 的落地 ↔ **L4-06 软工**、L6-07 元课程 |

### SEP-3 负责任 AI 多维张力
> 锚点：round2 表B；CS2023 SEP + NIST RMF trustworthy 特征 · SEP 承「为何要做」，技术手段指回 L5-02/L6-03

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 3.1 | 公平与偏见 | 群体/个体公平定义、偏见来源（数据/模型/部署）——诉求侧 |
| 3.2 | 问责 | 责任链、可审计性、human-in-the-loop 的规范要求 |
| 3.3 | 透明与可解释 | 透明度诉求 + 模型卡（Model Cards）/数据表（Datasheets）的「为何要做」（实现归 L5-02/L6-03） |
| 3.4 | 隐私维张力 | AI 语境下隐私诉求与数据需求的冲突 |
| 3.5 | 硬冲突 | 公平不可能性定理（多公平度量不可同时满足，需 L5-04/L2-03 交叉）、隐私 vs 透明取舍 |

### SEP-4 AI 治理框架
> 锚点：NIST AI RMF 1.0 + AI 600-1；EU AI Act 2024/1689；ISO/IEC 42001:2023 · **必带 EU AI Act 时效硬标**

| 编号 | 小主题 | 一句话范围 |
|------|--------|-----------|
| 4.1 | NIST AI RMF 四功能 | GOVERN/MAP/MEASURE/MANAGE（19 类/72 子类）风险管理分解 |
| 4.2 | NIST GenAI Profile (AI 600-1) | 2024-07-26 发布；12 类 GenAI 特有/放大风险（confabulation、prompt injection、数据隐私等） |
| 4.3 | EU AI Act 风险分级 | 禁止/高风险(Annex III)/有限/最小四级 |
| 4.4 | EU AI Act 关键条款 | Art.5 禁止性实践、Art.13 透明、Art.14 有效人类监督、Art.26 部署者义务、Art.50 透明度义务 |
| 4.5 | EU AI Act 时效硬标 | Art.5 自 2025-02-02、GPAI 自 2025-08-05；高风险 Annex III 推迟至 **2027-12-02**（Annex I 至 2028-08-02）——勿用「2026-08 高风险生效」旧记忆，Round4 必复核 |
| 4.6 | ISO/IEC 42001 AIMS | 2023 首版组织级 AI 管理体系认证框架 |
