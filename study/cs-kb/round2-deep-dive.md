## §2 · 优先级校准汇总（各组回报，主 agent 裁定）

**已采纳（独立依据充分，更新入 ledger）**
- **L6-09 数据密集型应用 P2 → P1**：DDIA 第2版（2024/2026 新版）成熟且覆盖复制/分区/流批「架构选型」这一 L4-03/L6-04 都不碰的独立价值；工程读者需求高。⚠Round 3 须与 L5-01 分布式划清边界防重。
- **L4-06 软件工程**：维持 P1 但**排批提前**，并拆为 **VC / 测试-CI** 两个子对象群产出——并入 N-06/N-07 后它已是三门业界一等能力的合并体，且是唯一可 `git` 硬实证的交付课（组内已本机核对 git 对象模型 SHA 通过）。

**条件性（默认保持，仅当用户把 AI/ML 设为主攻方向时上调）**
- **L2-03 概率统计 P1 → P0**：ML 的最大似然/交叉熵/贝叶斯/评估全建于概率；AI 主攻下与线代/微积分同级，排批可提前到批0 邻接。
- **L1-03 线代**：维持 P0，AI 视图下把 **SVD 提为一级方向**。
- **L1-04 微积分**：维持 P1，AI 视图下锚定为反向传播关键路径、视同 P0 不可后置（round1-map §2-B2 已标枢纽↑）。

> 决策请见 §4 提问；未定则按"通用 CS 视图"保持现状，AI 相关课在报告内仍完整覆盖，只是排批与标注不同。

**确认不变**：L4-04 编译 P1（组内子图仍最先产、按 P1 深度讲机制+LLVM 实物，不追求造完整编译器）；L5-01 分布式 P1（系统/云方向可升）；L5-10 SEP P1 跨层（横切嵌入，紧邻 L5-02/L5-04 编排）；L5-03 图形 P2（但 numpy 证腿价值高，作组内首选深挖）。
