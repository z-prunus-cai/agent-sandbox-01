## 读法约定
- **层（Layer）**：课表的依赖层级，用于 Round 2–4 内部组织内容与排序，**不是** skill 的 round。
- **优先级**：P0 = 枢纽/必经（后续大量课依赖它）；P1 = 重要主干/方向；P2 = 方向深化/选修。
- **取证腿**：文=一手文档/规范/教材；码=一手源码副本；证=本机实证。理论课的「证」= Python 数学库（numpy/sympy/scipy）跑验证。
