## 5.1 循环结构与参数共享

### 5.1.1 什么是循环神经网络

循环神经网络（RNN）是专门处理序列 x₁, x₂, …, x_T 的网络。它维护一个隐藏状态（hidden state）h，逐个时间步读入元素并更新这个状态：每一步用当前输入 x_t 和上一步的隐藏状态 h_{t-1} 算出新的隐藏状态 h_t。最基础的「vanilla RNN」更新式（Goodfellow §10.2）是

h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b_h)

其中 W_hh 是「状态到状态」的循环权重、W_xh 是「输入到状态」的权重、b_h 是偏置，激活通常取 tanh。若该步要产生输出，再从隐藏状态映射出去，例如做分类时

o_t = W_hy · h_t + b_y，  ŷ_t = softmax(o_t)

**所有时间步共用同一套 W_hh、W_xh、W_hy、b**——这就是参数共享。

对初学者，最好把 RNN 想成一个「带记事本的循环」：拿同一个函数，反复地「读一个词、更新一下记事本、（可选）说一句话」，记事本 h 就是它对「到目前为止看过的东西」的浓缩。因为函数每次都是同一个，所以它不在乎序列有多长——这正是它能处理变长输入的原因。

### 5.1.2 为什么要参数共享（而不是每步一套权重）

参数共享有两个不可替代的好处。第一是**处理变长序列**：如果每个位置都配一套独立权重，网络就只能处理训练时见过的固定长度，且长度变了就没法用；共享一套参数则同一个 RNN 能吃任意长的序列。第二是**跨位置泛化**：语言里「同一个规律」可能出现在句子任何位置（比如「不」出现在哪都表示否定），共享参数让网络在位置 3 学到的东西自动用到位置 30，不必在每个位置从头学一遍。

Goodfellow §10.2 把这一点类比成卷积网络：CNN 在**空间**上共享一个卷积核（平移等变），RNN 在**时间**上共享一套转移函数——都是「同一规律在不同位置复用」的思想，只是一个沿空间、一个沿时间。初学者常见的误解是把 RNN 画成「很多层、每层不同权重」的深网络，其实展开图里那些「层」是同一套参数的多次复用，参数量并不随序列变长而增加。

### 5.1.3 展开计算图与「动力系统」视角

把循环 h_t = f(h_{t-1}, x_t; θ) 沿时间一步步写开，就得到一张链式的计算图：

h₀ → h₁ → h₂ → … → h_T

每个箭头都是同一个带参数 θ 的函数 f。这个操作叫**展开（unfolding）**，展开后的图是一个普通的（没有环的）前馈计算图，只不过很深、且每一层共享参数。

这一步为什么重要？因为一旦把循环展开成前馈图，就可以直接在它上面套用大主题1 学过的反向传播——这正是 5.2 BPTT 的全部基础。Goodfellow §10.1 从「动力系统」角度描述同一件事：RNN 是一个把过去压缩进定长状态 h 的递推系统，h_t 是对历史 (x₁…x_t) 的有损摘要。它「有损」这一点是把双刃剑——好处是记忆开销恒定、不随序列增长，坏处是很久以前的信息可能被后续覆盖掉，这为 5.3 的长期依赖难题埋下伏笔。

## 5.2 时间反向传播 BPTT

### 5.2.1 BPTT 是什么

时间反向传播（Backpropagation Through Time，BPTT）就是把展开后的循环图当成一张普通计算图，在它上面跑标准反向传播。因为所有时间步共享同一套参数，某个参数（如 W_hh）的总梯度是它在**每一个时间步上贡献的梯度之和**：

∂L/∂W_hh = Σ_t (∂L/∂W_hh)|_step t

前向时按 t=1…T 依次算出并缓存每一步的 h_t；反向时从最后一步的损失出发，沿时间倒着（t=T…1）把误差信号一步步传回去，每经过一个时间步就累加一次对共享参数的梯度。

对初学者，一句话抓住它：BPTT ≠ 一种新的求导法，它就是大主题1 的反向传播，只不过作用在「沿时间展开、且层层共享参数」的深图上，所以要点是「梯度按时间步累加」。本报告在 scratchpad 手写 4 步 RNN 的解析 BPTT 与数值梯度对拍，最大相对误差 5.8e-9，正是「BPTT 就是普通反传」的直接证据。

### 5.2.2 计算与内存代价，以及截断 BPTT

BPTT 的一个硬约束：要反传就得**缓存整条序列每一步的隐藏状态**（前向的中间量），所以内存随序列长度 T 线性增长，计算也是 O(T)，而且这些时间步是顺序依赖的、难以在时间维上并行（这正是后来 Transformer 相对 RNN 的一大优势——可沿序列并行）。

当序列非常长（比如上万步）时，完整 BPTT 既费内存又会让梯度问题（5.3）更严重。实践中用**截断 BPTT（truncated BPTT）**：把长序列切成若干段，前向可以连续跑、但反传只回传固定的若干步就截断，用这段的梯度更新一次。代价是网络学不到比截断窗口更长的依赖，是「能训得动」与「能看多远」之间的折中。初学者要记住这是近似——它节省了资源，但把超出窗口的长期依赖直接砍掉了。

### 5.2.3 输出到隐藏的循环与 teacher forcing

RNN 有两类常见接线：一类是「隐藏到隐藏」的循环（h_{t-1}→h_t，即 5.1 的式子，最通用）；另一类是「输出到隐藏」的循环，即用上一步的**输出** o_{t-1}（而非隐藏态）喂回下一步。后一类在训练时可以用 **teacher forcing**：训练时不把模型自己上一步的（可能错的）输出喂回去，而是喂**真实的**上一步目标值。

好处是训练可以并行、且不会被早期错误带偏；代价是「训练时喂真值、推理时只能喂自己的预测」，两者分布不一致（叫 exposure bias / 训练-推理失配），推理时一旦某步错了后面可能连锁跑偏。Goodfellow §10.2.1 明确讨论了这一取舍。这一概念对理解后来所有自回归生成（含 Transformer 语言模型的训练）都通用，值得初学者早点建立。

## 5.3 梯度消失/爆炸与裁剪

### 5.3.1 长期依赖难题的来源

训练 RNN 最核心的困难叫**长期依赖（long-term dependencies）**：让网络学会「很久以前的输入影响现在的输出」很难。根因在 BPTT 的梯度形式——把误差从时间步 t 传回到时间步 k（t≫k）时，要连乘一长串隐藏状态之间的雅可比矩阵：

∂h_t/∂h_k = ∏_{i=k+1}^{t} (∂h_i/∂h_{i-1})

这是同一类矩阵（都由循环权重 W_hh 决定）的多次连乘。矩阵连乘的行为由其特征值（谱半径）主导：若相关特征值的量级持续小于 1，乘积会**指数衰减到 0**（梯度消失）；若持续大于 1，乘积会**指数爆炸**（梯度爆炸）。Goodfellow §10.7 与 Pascanu et al. 2013 给出的正是这套分析。

把矩阵退化成一个标量 w，连乘 50 次就是 w⁵⁰。本报告实测 0.8⁵⁰≈1.4×10⁻⁵、1.2⁵⁰≈9.1×10³——一个几乎归零、一个飙到近万。梯度消失的后果不是「训不动」而是更隐蔽的「只学得到短期依赖」：近处的梯度信号正常、远处的被淹没，网络于是只关注最近几步。

### 5.3.2 tanh/sigmoid 饱和让消失雪上加霜

vanilla RNN 的雅可比里还带着激活函数的导数。tanh 的导数最大只有 1（在 0 处），大部分区域远小于 1；sigmoid 更差，导数峰值仅 0.25。每传一步就再乘一个 ≤1 的因子，于是即便循环权重本身不算太小，**激活饱和也会持续把梯度往下压**，加剧消失。这与大主题1 讲激活函数饱和是同一现象在时间维上的连乘放大。初学者要把这两件事连起来看：5.1 用 tanh 是为了前向稳定（把状态压在 [-1,1]），但它的小导数又是 5.3 消失的帮凶——这正是门控（5.4）要绕开的地方。

### 5.3.3 梯度裁剪（治爆炸）

梯度爆炸有一个简单有效的对症疗法——**梯度裁剪（gradient clipping）**，Pascanu et al. 2013 提出的按全局范数裁剪最常用：算完整个梯度向量 g 后，若它的范数超过阈值 τ，就把它整体缩放回范数为 τ，方向不变：

若 ‖g‖ > τ：  g ← g · (τ / ‖g‖)

直觉上，爆炸的梯度会让参数一步迈出巨大、乱跳的更新（甚至数值溢出为 NaN），把优化毁掉；裁剪相当于「限速」——保留梯度指的方向，只把过大的步长压回可控范围。关键性质是**只缩幅、不改方向**：本报告实测取 ‖g‖=5、τ=1，裁后范数恰为 1.000、且单位方向与原梯度完全一致，正是这一点的直接验证。

裁剪治的是**爆炸**（把大梯度压小），它对**消失**无能为力（消失是梯度太小、没东西可裁）。消失没有这么廉价的补丁，只能靠改结构——用带门控的 LSTM/GRU（5.4）、或改用 ReLU 类激活 + 精心初始化、或加残差/跳连。这条「爆炸→裁剪、消失→换结构」的分工是初学者最该记牢的一句话。梯度裁剪作为通用优化工程件的完整讨论归大主题3，本节只讲它在 RNN 语境为何几乎是必需。

## 5.4 LSTM / GRU 门控

### 5.4.1 门控的核心思想

门控循环单元（LSTM、GRU）是为攻克梯度消失、让 RNN 记住长期依赖而设计的。共同思想是引入**门（gate）**——一些取值在 0 到 1 之间（由 sigmoid 产生）的「阀门」，逐元素地控制信息「保留多少 / 写入多少 / 读出多少」。最关键的设计是给记忆开一条**近似线性、加性更新**的通道：新记忆 ≈ 旧记忆（乘一个接近 1 的保留门）+ 新增内容。因为这条通道以「加」而非「反复乘一个权重矩阵」为主，梯度沿它回传时不会被指数级地连乘衰减——这正是 5.3 消失难题的破解口。Goodfellow §10.10 把这条通道形象地称作「让梯度能长时间流动的路径」。

对初学者，一句心智模型：vanilla RNN 每一步都把整块记忆用 tanh(W·…) **重写一遍**（所以远处信息经不起层层重写与连乘）；门控单元则把记忆放上一条**传送带**，每步只做「有选择地擦掉一点、有选择地添一点」，默认倾向于「原样带过去」，于是远处的信息能稳稳流到现在。

### 5.4.2 LSTM 的门与细胞状态

LSTM（Hochreiter & Schmidhuber 1997；Goodfellow §10.10）在隐藏状态 h 之外，额外维护一条**细胞状态（cell state）C**——就是那条「传送带」。它有三个门（下式中 σ 为 sigmoid、⊙ 为逐元素乘、[h_{t-1}, x_t] 表示拼接，W_*、b_* 为各门自己的参数）：

遗忘门  f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
输入门  i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
候选记忆 C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)
细胞更新 C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t
输出门  o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
隐藏状态 h_t = o_t ⊙ tanh(C_t)

遗忘门 f 决定「上一刻的记忆保留多少」（f≈1 全留、f≈0 清空）；输入门 i 决定「本刻的候选内容 C̃ 写入多少」；细胞更新那一行就是「保留旧的 + 写入新的」的加性传送带；输出门 o 决定「从细胞里读出多少作为对外的隐藏态 h」。当 f≈1、i≈0 时，C_t≈C_{t-1}，记忆几乎原样传递，梯度也几乎无损通过——这就是它记得住长期依赖的原因。

LSTM 的**遗忘门偏置 b_f 常初始化为正值（如 1）**，让训练初期默认「多记少忘」，帮助学到长依赖（Goodfellow §10.10 明确提到这一技巧）。另外，门的具体接线在文献里有小变体（如是否加 peephole 连接把 C 也接进门的输入），本节给的是 Goodfellow / 主流框架采用的标准无 peephole 版本；变体不改「加性传送带 + 门控」的核心，细节差异「按具体实现为准」。

### 5.4.3 GRU：更精简的门控

GRU（Gated Recurrent Unit，Cho et al. 2014）是 LSTM 的精简版：**没有单独的细胞状态**，只用隐藏态 h；门也从三个减到两个——更新门 z 和重置门 r（下式取 Cho 2014 原论文写法）：

更新门  z_t = σ(W_z · [h_{t-1}, x_t] + b_z)
重置门  r_t = σ(W_r · [h_{t-1}, x_t] + b_r)
候选状态 h̃_t = tanh(W_h · [r_t ⊙ h_{t-1}, x_t] + b_h)
状态更新 h_t = (1 − z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t

重置门 r 决定「算候选新状态时，忽略多少旧状态」（r≈0 就几乎当作从头开始）；更新门 z 是一个「线性插值旋钮」——在「保留旧状态 h_{t-1}」和「采用候选 h̃_t」之间加权。当 z≈0 时 h_t≈h_{t-1}，状态原样带过去，同样形成加性、近似恒等的记忆通道，起到和 LSTM 细胞状态类似的护梯度作用，只是用更少的参数实现。

一处必须点明的**记号分歧**：Cho 2014 原论文写的是 h_t = (1−z)⊙h_{t-1} + z⊙h̃（z 大 → 更多采用新候选）；但另一些教材/实现把更新门的角色写反，记作 h_t = z⊙h_{t-1} + (1−z)⊙h̃（z 大 → 更多保留旧状态）。两种写法只是 z 与 (1−z) 的命名对调，数学等价、不影响机制，但读代码/论文时务必看清该处用的是哪种约定，否则会把门的方向理解反。本报告统一采用 Cho 原论文约定。

LSTM 与 GRU 怎么选？GRU 参数更少、算得更快；LSTM 表达力略强、在部分任务上更稳。二者孰优**没有普适定论、依任务而定**，这是文献的共识（Goodfellow §10.10 亦持此谨慎态度），初学者不必纠结，任选其一都能拿到远好于 vanilla RNN 的长依赖表现。

## 5.5 双向与编码-解码 / seq2seq

### 5.5.1 双向 RNN（BiRNN）

标准 RNN 在时间步 t 只能看到「t 及之前」的输入（因为 h_t 只由过去累积而来）。但很多任务里，一个位置的正确解读需要**同时看左右上下文**——比如命名实体识别、词性标注，判断某个词的角色往往要看它后面的词。**双向 RNN（Schuster & Paliwal 1997；Goodfellow §10.3）**用两个独立的 RNN 解决：一个从左往右跑得到前向隐藏态 →h_t，一个从右往左跑得到后向隐藏态 ←h_t，把两者**拼接**作为该位置的表示

h_t = [→h_t ; ←h_t]

于是每个位置的表示都融合了它左边和右边的全部信息。

双向 RNN **必须拿到整条序列才能计算**（后向那一路要从序列末尾开始），所以它**只能用于「已给定完整输入」的任务**（如离线的序列标注、编码器），**不能用于流式/在线**或自回归生成（那些场景在时刻 t 根本还看不到未来）。初学者常见的错是想把双向 RNN 用作语言模型逐词生成——这会「偷看未来」、造成信息泄露，是不允许的。这条「能不能看未来」的界线，后来在 Transformer 里以「双向编码器 vs 因果解码器 + 掩码」的形式再次出现（接大主题6）。

### 5.5.2 编码-解码 / seq2seq

当输入和输出都是序列、且长度可以不同（如机器翻译：英文句 → 中文句），用**编码-解码（encoder-decoder，又称 seq2seq）**结构（Sutskever et al. 2014；Cho et al. 2014；Goodfellow §10.4）。它由两个 RNN 组成：

编码器：把输入序列 x₁…x_T 读完，压成一个定长的上下文向量 c（通常取编码器最后的隐藏状态）
解码器：以 c 为初始信息，逐步生成输出序列 y₁…y_{T'}

直觉是「先理解、再表达」——编码器把整句话的意思浓缩进 c，解码器再把 c 展开成目标语言的句子。它的重要突破是**输入输出长度可以不等**（vanilla RNN 做不到序列到序列的变长映射），奠定了神经机器翻译等一大类任务的范式。

### 5.5.3 定长瓶颈与通往注意力的桥

编码-解码有一个致命弱点——**信息瓶颈**：无论输入多长，整句话都被硬塞进那**一个定长向量 c**。句子越长，c 越装不下，靠前的信息容易被后面覆盖，翻译长句时质量明显下滑。

解决它的正是**注意力机制（Bahdanau et al. 2015）**：不再逼解码器只靠一个 c，而是让它在生成每个输出词时，都能「回头看」编码器**所有时间步**的隐藏状态，并按当前需要加权聚焦到相关的输入位置上。这既缓解了瓶颈，也提供了一种软对齐（生成某目标词时对齐到相关源词）。注意力最初是作为 RNN seq2seq 的补丁提出的，随后「Attention Is All You Need」(2017) 干脆抛掉循环、只留注意力，催生了 Transformer——这就是为什么本报告一再说 RNN 是「理解 Transformer 动机的前置课」。注意力/Transformer 的完整机制（QKV、多头、位置编码、掩码）归大主题6，本节只把这座桥指出来。
