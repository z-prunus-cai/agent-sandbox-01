## 1.1 深度前馈网与万能逼近

### 1.1.1 什么是深度前馈网络

深度前馈网络（deep feedforward network），也叫前馈神经网络或多层感知机（MLP），是深度学习最基本的模型。它的目标是逼近某个函数 f\*：给定输入 x，学一组参数 θ 使模型 f(x; θ) 尽量接近 f\*(x)。之所以叫"前馈"，是因为信息从输入单向流向输出、中间没有把输出接回输入的反馈环；之所以叫"网络"，是因为它把很多个函数**复合**（compose）起来，一层的输出是下一层的输入。一个 L 层网络就是

f(x) = f^(L)( … f^(2)( f^(1)(x) ) … )

其中第 l 层做的事是一次线性（仿射）变换再套一个逐元素非线性激活 g：

z^(l) = W^(l) a^(l−1) + b^(l)

a^(l) = g(z^(l))

约定 a^(0) = x 是输入、a^(L) 是网络输出，W^(l) 是第 l 层权重矩阵、b^(l) 是偏置向量，这些合起来就是参数 θ。

给初学者的直觉。把网络想成一条流水线，每一站（层）先对上一站的产物做一次"加权重组"（Wa+b），再过一道"非线性闸门"（g）。中间那些层叫**隐藏层**，因为训练数据只告诉你输入 x 和最终该输出什么，并不规定隐藏层每个单元该取什么值——网络自己决定怎么用这些隐藏单元，这也是"隐藏"一词的由来。一个常见的计数易错点：习惯上只数**带权重的层**（隐藏层 + 输出层），输入层不算，所以"两层网络"通常指一个隐藏层加一个输出层。另外，"深度"指层数（复合的次数），"宽度"指每层的单元数，二者是两个独立的旋钮。

### 1.1.2 为什么必须有非线性（否则整网塌成线性）

隐藏层里的非线性激活 g 不是可有可无的修饰，而是让"深度"产生价值的**必要条件**：若把所有 g 都换成线性/恒等函数，无论堆多少层，整个网络都等价于一个单层线性模型。用两层验证：设两层都无激活，

a^(2) = W^(2)(W^(1) x + b^(1)) + b^(2) = (W^(2) W^(1)) x + (W^(2) b^(1) + b^(2))

括号里 W^(2)W^(1) 合并成一个矩阵、后一项合并成一个向量，结果还是 W′x + b′ 这种线性形式；堆一百层照样如此。

这背后是线代的基本事实——**线性变换的复合仍是线性变换**。非线性激活打断这种坍缩，让每层能对上层输出做一次"弯折"，弯折累积起来才能表达弯曲的决策边界与复杂曲面。一个易错点：偏置 b 带来的只是仿射平移，多个仿射变换复合仍是仿射，替代不了真正的非线性 g。这一条在 L5-02 大主题8 已用 XOR 例子讲过（单层学不会 XOR、加一层非线性隐藏层就能），此处只做承接。

### 1.1.3 万能逼近定理

万能逼近定理（Universal Approximation Theorem）是前馈网表达力的理论保证：一个**带单个隐藏层**、隐藏单元数足够多、激活为合适非线性函数的前馈网络，可以在紧致集上以任意精度逼近任意连续函数。原始结果由 Cybenko（1989，sigmoid 类激活）与 Hornik/Stinchcombe/White（1989）、Hornik（1991，推广到任意有界非常数激活）证明；后续工作还给出对 ReLU 等激活的版本。Goodfellow §6.4.1 陈述此定理并强调其为**存在性**结论。

直觉上为什么"一个隐藏层就够"：每个隐藏单元加非线性，相当于在输入空间里"竖起一小块台阶/凸起"，输出层再把成百上千块这样的小台阶加权叠加，就能拼出任意形状的曲面——类似用足够多的小矩形逼近曲线下面积。

必须点破三个易错点，这正是"讲到懂即止、不过度承诺"的分寸。其一，万能逼近是**存在性**定理：它保证"存在这样一组参数"，**不保证**梯度下降能学到、也不保证所需隐藏单元数可承受（最坏可能随输入维度指数增长）。其二，"单隐藏层足够"是理论可行、不等于实践高效——**深**网络常能用远少的参数表达同样复杂的函数（Goodfellow §6.4.1 讨论深度的表达优势），这是深度学习要"变深"而非只"变宽"的动机之一；其经验与更细机制归本课后续大主题，本节不展开。其三，定理管的是"逼近训练分布上的连续函数"，不谈**泛化**（训练集外的表现），泛化是大主题2 正则化与 L5-02 学习理论的范畴。

## 1.2 激活函数

### 1.2.1 隐藏单元的激活：ReLU 及其定义

激活函数是插在每层线性变换之后、逐元素作用的非线性函数。对隐藏单元，现代默认首选是**修正线性单元（ReLU, Rectified Linear Unit）**：

ReLU(z) = max(0, z)

其导数为

ReLU′(z) = 1（z > 0）， 0（z < 0）， z = 0 处不可导（工程上按次梯度取 0 或 1）

Goodfellow §6.3.1 把 ReLU 列为隐藏单元的默认推荐。

给初学者的直觉。ReLU 就是"负的清零、正的原样通过"的一条折线，计算极快（只是一次取最大）。它相比 sigmoid/tanh 的关键好处：在正区间导数恒为 1，梯度不会因为落在正区间而被压小，从而缓解深层网络里"梯度越传越弱"的问题。一个必须知道的易错点是**死亡 ReLU（dead ReLU）**：若某单元的输入长期为负，它的输出恒为 0、梯度也恒为 0，参数再也更新不了、这个单元就"死"了；这催生了 Leaky ReLU、ELU、GELU、SwiGLU 等变体。变体的深入比较与选型属工程纵深，本节只点名（呼应本课后续大主题的激活选择讨论），不展开。

### 1.2.2 sigmoid 与 tanh 及饱和问题

早期隐藏层常用 sigmoid 与 tanh 这两个"挤压型"（squashing）激活，它们把整条实轴压到一个有界区间。定义与导数（导数在 1.5 反传里要用）：

σ(z) = 1 / (1 + e^(−z))

σ′(z) = σ(z)·(1 − σ(z))

tanh(z) = (e^z − e^(−z)) / (e^z + e^(−z))

tanh′(z) = 1 − tanh(z)²

两者关系是 tanh(z) = 2σ(2z) − 1，即 tanh 是"零中心版的 sigmoid"。

给初学者的直觉与关键分寸。sigmoid 输出落在 (0,1)，可读作"概率/开关强度"；tanh 输出落在 (−1,1)，零中心通常让训练更顺，所以历史上隐藏层多偏好 tanh 而非 sigmoid。二者共同的致命弱点叫**饱和（saturation）**：当输入很大或很小时曲线趋平、导数趋近 0。观察 σ′ 的最大值——σ′(0) = 0.25，两侧迅速衰减；tanh′ 最大为 1（在 0 处）但同样两侧趋 0。反向传播时（见 1.5）每经过一层要乘一次激活导数，导数普遍小于 1 且饱和处近 0，多层连乘就会让梯度**指数级衰减**，这就是**梯度消失**的直观来源，也是深层网络里 ReLU 取代 sigmoid/tanh 做隐藏层激活的主要动机。Goodfellow §6.3.2 明确指出 sigmoid/tanh 因饱和不宜作深层前馈网的隐藏激活，但在必须有界输出或 RNN 门控等场景仍有用武之地。

### 1.2.3 隐藏层激活与输出层激活的分工

要区分两件不同的事：**隐藏层激活**的目的是提供非线性表达力（首选 ReLU 族），**输出层激活**的目的是匹配任务的输出语义与损失（sigmoid/softmax/线性，详见 1.3）。二者选择逻辑不同，不要混为一谈。

一个初学者常犯的错是"给分类网络的输出层也套 ReLU"——分类输出该用 sigmoid（二分类）或 softmax（多分类）以给出概率，ReLU 是隐藏层的选择。另一个关联点：sigmoid/softmax 与交叉熵配对之所以好，是因为它们的梯度形式极干净（正好是"预测 − 真值"），这一点 1.3 讲损失匹配、1.5 讲反传时都会直接用到。

## 1.3 输出层与损失匹配

### 1.3.1 输出层与损失为何要"成对"选

输出层的激活与损失函数不是各自随便挑的，而是**成对**设计，使两者组合后梯度干净、训练稳定。三对经典配对是：回归任务用**线性（恒等）输出 + 均方误差 MSE**；二分类用 **sigmoid 输出 + 二元交叉熵**；多分类用 **softmax 输出 + 交叉熵**。这套配对的统一根据是"最大似然 / 负对数似然"：Goodfellow §6.2.1 指出现代前馈网几乎总用最大似然训练，即损失取负对数似然

J(θ) = − E_{(x,y)∼data} [ log p_model(y | x; θ) ]

不同任务只是对 p_model(y|x) 选了不同的输出分布，配对就是从这个分布推出来的。

给初学者的直觉。你先决定"输出该服从什么分布"：连续实值 → 高斯（→ 线性输出 + MSE）；一个是非概率 → 伯努利（→ sigmoid + 二元交叉熵）；多选一 → 类别分布（→ softmax + 交叉熵）。选好分布，损失就是"让数据的对数似然最大"，输出激活就是"把网络打分映射成该分布的参数"。这样配的最大好处见下一节——梯度会化简成极简的"预测减真值"。

### 1.3.2 softmax + 交叉熵

多分类的输出层用 softmax 把一组实数打分 z（logits）变成一个概率分布：

softmax(z)_i = e^{z_i} / Σ_j e^{z_j}

配交叉熵损失（真标签为 one-hot 的 y，或用真类索引）：

J = − Σ_i y_i log softmax(z)_i

对 logits z 求梯度，结果化简为极简形式：

∂J / ∂z = softmax(z) − y

即"预测概率减真标签"。

给初学者的要点与易错点。其一，softmax 里所有 e^{z_i} 都要减去 max(z) 再算（数值稳定技巧），否则大 logit 会让 e 溢出；这不改变结果因为分子分母同乘常数。其二，softmax 输出恒正且和为 1，可解释为概率；但它对"整体加一个常数"不敏感（softmax(z+c) = softmax(z)），所以 logits 只有相对大小有意义。其三，工程上几乎总把 softmax 与交叉熵**合并成一个算子**（如各框架的 "softmax cross-entropy with logits"），既数值稳定又直接得到那个干净梯度——如果你分开实现再手动相乘，容易在 log(0) 处出 NaN。这个 softmax−y 的干净梯度，正是 1.5 反传里输出层误差 δ^(L) 的来源。

### 1.3.3 linear + MSE 与 sigmoid + 二元交叉熵

回归任务的输出层用**线性（恒等）激活**，损失用均方误差：

J = (1/2) ‖ŷ − y‖²

对输出 ŷ 的梯度为 ŷ − y。它对应"输出服从固定方差高斯、做最大似然"这一假设（Goodfellow §6.2.2）。

二分类用 **sigmoid 输出**给出正类概率，配**二元交叉熵**（伯努利负对数似然）：

ŷ = σ(z)

J = − [ y log ŷ + (1 − y) log(1 − ŷ) ]

对 logit z 的梯度同样化简为 ŷ − y。

给初学者的直觉与易错点。三对配对（linear+MSE、sigmoid+BCE、softmax+CE）对各自输出的梯度都收敛到同一个干净形式"预测 − 真值"，这不是巧合，而是"规范链接 + 指数族 / 最大似然"带来的必然结果（呼应 L5-02 大主题3 的 GLM 视角）。一个高频错配是"分类任务用 MSE"：sigmoid + MSE 会在输出饱和（接近 0 或 1）时梯度趋近 0、学习几乎停滞，而 sigmoid + 交叉熵能避免这种饱和拖累，所以分类应优先交叉熵而非 MSE（Goodfellow §6.2.1 讨论了交叉熵损失相对 MSE 的这一优势）。另一个易错点是 MSE 里的 1/2 只是为了让求导后系数干净、可有可无，不影响最优解。

- 交叉核对一致项：输出激活与损失按最大似然成对设计、softmax+CE 与 sigmoid+BCE 及 linear+MSE 三配对、三者梯度均化简为"预测−真值"、分类避免用 MSE——两源一致。
- 本机实证：1.5 的两层 MLP（softmax+CE）反传实证间接坐实 ∂J/∂z = softmax(z) − y 这一化简。
- 术语差异（非冲突）：logits（softmax 前的实数打分）在不同资料也叫 scores/pre-activations；"交叉熵"在多分类语境即类别分布负对数似然，与二分类"二元交叉熵"同源。

## 1.4 计算图

### 1.4.1 什么是计算图

计算图（computational graph）是把一段数值计算画成有向图：**节点**是变量（张量），**边**表示"由哪些变量、经哪个基本运算算出"。每个节点要么是输入/参数（叶子），要么是把若干父节点经一个基本操作（加、乘、矩阵乘、ReLU、softmax……）算出的中间量。整个前馈网络的前向传播，就是按拓扑序（从输入到输出）在这张图上逐节点求值，最后得到标量损失 J。Goodfellow §6.5.1 正是用计算图作为讲反向传播的统一语言。

给初学者的直觉。把复杂表达式拆成一串最基本的小运算，每个小运算画成一个节点，就得到计算图。例如 J = (Wx + b) 过 ReLU 再算损失，会被拆成"矩阵乘 → 加偏置 → ReLU → …… → 损失"这一串节点。这样做的意义在于：只要我们知道**每个基本运算的局部导数**怎么算，就能用链式法则沿图把整体导数拼出来——复杂函数的求导被化约成"一堆简单运算的局部导数 + 按图连乘相加"，这正是反向传播（1.5）和自动微分（1.6）的立足点。一个要点：计算图必须是**有向无环图（DAG）**，前馈网天然无环；RNN 看似有环，但训练时按时间步"展开"成无环图（本课后续大主题会讲）。

### 1.4.2 前向传播与中间量缓存

前向传播就是在计算图上从叶子往输出算，逐节点得到并**保存**每个中间量的值。之所以要保存（缓存），是因为反向传播算梯度时，很多局部导数依赖前向时算出的那些中间量。举两个最常见的例子：

ReLU 的反向需要知道前向时 z 的符号（z>0 处导数为 1，否则 0）；

矩阵乘 z = W a 的反向里，∂J/∂W = δ aᵀ 需要用到前向缓存的输入 a。

给初学者的直觉与权衡。可以把前向想成"边算边把每个中间结果记在便签上"，反向时再逐张便签取用。这带来一个核心工程权衡——**用显存换计算**：缓存越多，反向越快但越吃内存；反过来，"梯度检查点（gradient checkpointing）"技术选择只缓存少数节点、反向时对未缓存段**重算**一次前向，用额外计算省显存（Goodfellow §6.5.8 讨论了这种内存-计算权衡）。一个初学者易踩的坑：推理（inference）阶段不需要反向，所以框架里要把梯度记录关掉（如 PyTorch 的 `torch.no_grad()`）以免白白缓存中间量、浪费显存——这属实现层，标 `⚙演进快·锚版本 PyTorch autograd`，具体 API 以官方文档当版本为准。

#### 来源与时效（本小主题末集中列）

- 一手锚点：Goodfellow《Deep Learning》2016 §6.5.1「Computational Graphs」、§6.5.8（重算 vs 存储的内存-计算权衡，即梯度检查点思想）；CS224n Winter 2026 backprop 讲义（用计算图讲前向/反向）。
- 交叉核对一致项：计算图 = 变量为节点、基本运算为边的有向无环图、前向按拓扑序求值并缓存反向所需中间量、缓存是"显存换计算"的权衡——两源一致。
- 规范与实现分账：计算图是数学/算法抽象（稳定）；具体框架如何构建图（动态图 vs 静态图）、`no_grad`/checkpoint API 属实现层，标 `⚙演进快·锚版本 PyTorch autograd`，以 pytorch.org 官方 autograd 文档当版本为准（未逐 API 版本取证，标「待核」+核实日期 2026-07-30）。

## 1.5 反向传播算法

### 1.5.1 反向传播是什么、不是什么

反向传播（backpropagation）是在计算图上高效算出标量损失对所有参数（及所有中间量）梯度的算法：做一次前向传播算出并缓存各节点值，再做一次**反向**遍历，从损失节点出发沿边逆向把梯度"传"回每个节点，总代价约等于两次前向传播。

先把定位讲清，这是初学者最容易误解的地方。反向传播**不是一种新的求导原理**——它就是**链式法则**；它也**不是优化算法**——真正更新参数的是梯度下降（θ ← θ − η·∂J/∂θ）。反向传播只负责"高效算梯度"，梯度下降负责"用梯度走一步"，两者分工协作。它高效的关键在于**复用**：从输出往输入走，先算出的下游梯度会被上游反复利用，避免了对每个参数从头连乘一遍（那样是指数级重复计算）。Goodfellow §6.5.2–6.5.4 强调"backprop"专指这个反向的链式法则计算过程，不含参数更新。

### 1.5.2 反向传播的四步核心方程

把网络按 1.1 的记法逐层展开，定义每层的"误差信号"

δ^(l) = ∂J / ∂z^(l)

即损失对该层线性输出（激活前）的偏导。反向传播归结为四个方程，⊙ 表示逐元素相乘，g′ 是激活导数（见 1.2）。输出层误差：

δ^(L) = ∇_a J ⊙ g′(z^(L))

误差从第 l+1 层反传回第 l 层：

δ^(l) = ((W^(l+1))ᵀ δ^(l+1)) ⊙ g′(z^(l))

由每层误差读出该层权重梯度（误差与上层激活的外积）：

∂J / ∂W^(l) = δ^(l) (a^(l−1))ᵀ

该层偏置梯度等于误差本身：

∂J / ∂b^(l) = δ^(l)

给初学者的读法。第一式是"起点"——在输出层，损失对输出的直接偏导乘输出激活的局部导数，得到输出层误差。第二式是"传递"——要得到某层误差，把下一层误差经该层权重**转置**"抬回来"（转置负责把误差按连接反向分配），再乘本层激活导数 g′(z^(l))；这里的 g′ 就是 1.2 说的"每层乘一次激活导数"，sigmoid/tanh 饱和时 g′≈0 会让误差越传越小，正是梯度消失。第三、四式是"落地"——拿到某层误差后，权重梯度 = 误差 × 上层激活转置（外积），偏置梯度 = 误差本身。一个重要化简（呼应 1.3）：当输出层用 softmax+CE 或 sigmoid+BCE 时，第一式恰好化简为

δ^(L) = a^(L) − y

即"预测减真值"。整体骨架是：前向逐层算 z、a 并缓存 → 算 δ^(L) → 对 l=L−1,…,1 递推 δ^(l) → 读出各层 ∂J/∂W、∂J/∂b → 交给梯度下降。

### 1.5.3 反向传播作为通用图算法（不止 MLP）

1.5.2 的四方程是"逐层 MLP"的特例；反向传播的一般形式是**计算图上的通用算法**，不依赖网络是不是规整的层。一般形式这样看：对图里每个节点，一旦它所有下游（消费它的节点）的梯度都算好了，就把这些下游梯度经"本节点到下游的局部导数（局部 Jacobian）"回传、相加，得到本节点的梯度。用向量-Jacobian 积（VJP）表述，若中间量 v 经操作得到 u、已知 ∂J/∂u，则

∂J / ∂v = (∂u / ∂v)ᵀ · (∂J / ∂u)

对多个下游分支，各分支贡献相加（多元链式法则的"多路径求和"）。

给初学者的直觉。可以把反向想成"责任分摊会议"：损失先把"该怎么改"的信号发给它的直接输入，每个节点收到所有下游发来的信号后求和，再按自己这步运算的局部导数把信号继续往上游发。因为按逆拓扑序走、每个节点只在下游都就绪后算一次，所以每条边的局部导数只被用一次、总代价与前向同阶。这个通用视角很关键：它解释了为什么同一套 backprop 能训练 CNN、RNN、Transformer——只要把它们写成计算图、每种基本运算给出局部导数（VJP）即可；这也正是 1.6 要讲的"反向模式自动微分"。一个易错点：反传要求图里每个基本运算都能给出局部导数，ReLU 在 0 处不可导用次梯度顶替、`argmax`/硬采样这类不可导操作会截断梯度（需重参数化等技巧绕开，属后续大主题）。

### 1.5.4 numpy 手写反传 + 梯度检验（本机实证）

为给 1.5.2 的方程"体检"，在 scratchpad 就地手写了两层 MLP（输入 4 维 → ReLU 隐藏层 6 单元 → softmax 输出 3 类 → 交叉熵），用四方程算解析梯度，再用中心有限差分算数值梯度对拍。核心反传代码（与方程逐行对应）：

dz2 = (p − onehot(y)) / N        # 输出误差，softmax+CE 化简形式

dW2 = a1ᵀ @ dz2 ; db2 = Σ dz2

da1 = dz2 @ W2ᵀ                  # 误差抬回隐藏层

dz1 = da1 ⊙ (z1 > 0)             # 乘 ReLU′

dW1 = Xᵀ @ dz1 ; db1 = Σ dz1

有限差分对每个 W1[i,j] 取 (J(+ε) − J(−ε)) / (2ε)，ε=1e-6。真实输出（环境 Py3.11.15/np2.4.6 @2026-07-30）：

loss = 0.695927

解析 dW1[0] = [0.014785  0.045083  0.109932  0.114019  0.012623  0.352710]

数值 dW1[0] = [0.014785  0.045083  0.109932  0.114019  0.012623  0.352710]

相对差 ‖解析 − 数值‖ / (‖解析‖ + ‖数值‖) = 2.247×10⁻¹⁰

相对差在 1e-10 量级，远小于 1e-6 的经验通过阈，坐实反向传播四方程推导正确。这种"数值梯度对拍解析梯度"就是调试神经网络的标准手段（**梯度检验**）：写反传时若某层导数写错，相对差会立刻从 1e-10 跳到 1e-2 甚至更大。梯度检验只在调试时开、正式训练时关掉（有限差分对每个参数各跑两次前向，太慢），其工程化归大主题12 实践方法论。

## 1.6 自动微分模式

### 1.6.1 自动微分是什么（与另外三种求导对比）

自动微分（automatic differentiation, AD；又译自动求导）是让计算机对"用代码写出的函数"精确、高效求导的技术。它的立足点和 1.4 一样：任何程序都可拆成一串基本运算（加、乘、exp、matmul……）组成的计算图，每个基本运算的导数已知，AD 只需按链式法则把这些局部导数按图组合，就得到整体导数——且结果是**精确到浮点误差**的，不是近似。

给初学者的对比，四种"求导"别混淆。手工推导（human 手推）——准但易错、改模型要重推。符号微分（symbolic，如 sympy）——给出导数的解析表达式，但对复杂程序会"表达式膨胀"、且难处理控制流。数值微分（有限差分，如 (f(x+ε)−f(x−ε))/(2ε)）——实现简单但有截断/舍入误差、且对 n 个输入要跑 O(n) 次前向，只适合做梯度检验（见 1.5.4），不适合训练。自动微分——精确（无截断误差）、能处理循环/分支、且（反向模式下）对多参数只需约一次前向的代价，这就是为什么所有深度学习框架的核心都是 AD。一个常见误解是把 AD 等同于符号微分或数值微分，其实它两者都不是：它不产出符号表达式，也不做差分近似，而是在具体数值上按图传播导数。

### 1.6.2 前向模式：沿计算方向传播导数

前向模式（forward mode）与前向计算**同方向**传播导数。给定一个输入方向（"种子"，seed），它在正向求值每个节点的同时，也正向求值该节点对这个输入方向的导数（切线，tangent）。用对偶数（dual number）实现最直观：每个量带一个"值 + 导数"分量，基本运算按导数规则同时更新两部分。它一次前向算的是**雅可比与一个方向向量的积**（Jacobian-vector product, JVP）：

前向模式一次 pass 得到 J·v（J 是输出对输入的 Jacobian，v 是输入方向）

给初学者的直觉与代价。想象你想知道"把输入沿方向 v 轻推一下，输出会怎么动"——前向模式就是让这个扰动跟着计算一路往前流。它一次 pass 只能覆盖**一个输入方向**，所以要拿到对全部 n 个输入的完整梯度，需要 n 次前向（每次种一个坐标方向）。因此前向模式在**输入少、输出多**（n 小、m 大）时划算。它的实现和内存都简单——不需要缓存整张图、不需要反向遍历，边算边推导数即可。

### 1.6.3 反向模式：反向传播就是它

反向模式（reverse mode）与前向计算**反方向**传播导数：先做一次前向把各节点值缓存，再从输出出发反向遍历，对每个节点算"输出对它的导数"（伴随量，adjoint）。它一次反向 pass 算的是**一个输出方向与雅可比的积**（vector-Jacobian product, VJP）：

反向模式一次 pass 得到 uᵀ·J（u 是输出方向；对标量损失 u=1，一次就得到对全部输入的梯度）

这正是 1.5 的反向传播——backprop 就是"反向模式 AD 应用在标量损失的神经网络上"这一特例。

给初学者的直觉与代价。反向模式一次 pass 能覆盖**一个输出方向**、但一次性拿到对**所有**输入的导数。深度学习里损失是**单个标量**（输出维度 m=1），而参数动辄百万上亿（输入维度 n 巨大），所以只需一次反向 pass 就能算齐所有参数梯度——代价约等于一次前向。这就是为什么训练神经网络清一色用反向模式。它的代价是**内存**：必须缓存前向的中间量供反向使用（呼应 1.4.2 的显存-计算权衡、梯度检查点）。一个易记的判据：反向模式适合**输入多、输出少**（n 大、m 小），前向模式适合输入少、输出多。

### 1.6.4 两模式的取舍与本机对照

选哪种模式取决于函数的"形状"——输入维度 n 与输出维度 m 的相对大小。粗略地说：

m ≪ n（输出远少于输入，如标量损失对海量参数）→ 反向模式（代价 ∝ 输出数）

m ≫ n（输出远多于输入）→ 前向模式（代价 ∝ 输入数）

两者算的是**同一个雅可比**里的信息，只是遍历方向和"一次 pass 覆盖行还是列"不同：前向模式一次得 Jacobian 的一列方向（JVP），反向模式一次得一行方向（VJP）。

为坐实"两模式给同一个梯度"，在 scratchpad 对函数 f(x) = sin(x₀·x₁) + x₀² 分别用前向模式（对偶数，跑两次各种一个坐标方向）与反向模式（一次反向）算梯度。真实输出（Py3.11.15/np2.4.6 @2026-07-30）：

前向模式 grad = [3.029622, 0.797869]

反向模式 grad = [3.029622, 0.797869]

两者 np.allclose 判定为 True。这个 2 输入 1 输出的小例子里，前向模式要跑 2 次（每输入一次）、反向模式 1 次就够——直观演示了"输出少用反向更省"。给初学者的收尾直觉：训练神经网络之所以可行，很大程度上就靠"损失是标量 + 反向模式一次拿全部梯度"这个匹配；如果换成要算"每个输出对每个输入"的完整雅可比（m、n 都大），两种模式都省不了，那是另一类问题。实现层面，各框架的 AD 引擎（PyTorch autograd、JAX 的 grad/jvp/vjp 等）具体 API 属 `⚙演进快·锚版本`，以官方文档当版本为准；但"前向=JVP、反向=VJP、backprop=标量损失的反向模式"这一机制层结论是稳定的。
