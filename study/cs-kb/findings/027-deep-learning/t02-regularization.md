## 2.1 参数范数惩罚（L1 / L2 在深度语境）

### 2.1.1 什么是参数范数惩罚

参数范数惩罚是最经典的正则化：在原来的训练损失 J 上额外加一项「参数越大、惩罚越重」的项，逼着优化在「拟合数据」和「参数保持小」之间折中。带惩罚的总目标写作

J̃(θ; X, y) = J(θ; X, y) + α · Ω(θ)

其中 Ω 是参数的某种范数，α ≥ 0 是控制惩罚强度的超参数（α=0 即不正则，α 越大约束越强）。深度学习里最常用的两种是 L2（Ω(θ)=½‖w‖₂²，即权重平方和）和 L1（Ω(θ)=‖w‖₁，即权重绝对值之和）。

对初学者，关键是把这件事和 L5-02 大主题6 讲过的岭回归/Lasso 接上：那里是在线性模型上加同样的惩罚，这里只是把同一个 Ω 加到深度网络的损失上，机制一模一样，区别只在「深度网络的 J 是高度非凸的、参数分很多层」。所以本节不重推偏差-方差分解（归 L5-02），只讲深度语境下三个必须重新交代的点：为什么通常**只惩罚权重、不惩罚偏置**、L2 和「权重衰减」到底是不是一回事、以及惩罚与先验的对应关系。

### 2.1.2 L2 正则（权重衰减视角）

L2 正则在损失里加 (α/2)·‖w‖₂²。对它求梯度得到 α·w，于是一步梯度下降的更新变成

w ← w − η·(∇_w J + α·w) = (1 − η·α)·w − η·∇_w J

括号里的 (1 − η·α) 是一个略小于 1 的系数——每一步先把权重整体**乘以一个略小于 1 的数**「收缩」一下，再走常规的梯度步。正因为这个「每步先缩一点」的效果，L2 正则在深度学习圈被普遍叫作**权重衰减（weight decay）**。

直觉上，L2 惩罚让优化倾向于选「幅值小、分布均匀」的权重：它不会把任何一个权重精确压到 0，而是把所有权重**成比例地朝原点拉**，在那些「对降低训练损失贡献不大」的方向上收缩得最狠。几何上（在最优点做二次近似）可以证明，L2 沿 Hessian 特征值小的方向收缩得多、特征值大的方向几乎不动——也就是「没用的方向被压扁、有用的方向留着」。小权重意味着网络对输入的微小变化不敏感、函数更平滑，这正是抗过拟合想要的。Goodfellow §7.1.1 给出了这套二次近似的完整推导，此处只取结论。

### 2.1.3 L1 正则（诱导稀疏）

L1 正则在损失里加 α·‖w‖₁（权重绝对值之和）。它对梯度的贡献是 α·sign(w)——一个不随权重大小变化的**固定幅度**推力，把每个权重恒定地往 0 推。结果是：足够多的权重会被**精确压到 0**，得到一个稀疏的权重向量。

L1 与 L2 最重要的区别就在这个「稀疏」上。L2 把权重压小但极少压到恰好 0；L1 则会让一批权重变成 0，等于自动做了特征/连接选择。直觉可以这样看——L1 的惩罚在原点是个「尖角」（绝对值函数不可导的地方），这个尖角像一个「势阱」，把落在附近的权重直接吸到 0；而 L2 在原点是平滑的抛物线底，没有这种吸附力。因此想要「稀疏、可解释、砍掉冗余参数」时用 L1，想要「整体收缩、改善数值条件、平滑」时用 L2。深度学习实践中 L2/权重衰减远比 L1 常用，L1 更多出现在需要稀疏性的特定场景。

### 2.1.4 惩罚等价于先验（MAP 视角）与「只惩罚权重」

参数范数惩罚有一个漂亮的概率解释：在贝叶斯 MAP（最大后验）估计下，L2 惩罚等价于给权重加一个**零均值高斯先验**，L1 惩罚等价于加一个**零均值拉普拉斯先验**。也就是说，「偏好小权重」在数学上就是「事先相信权重应该集中在 0 附近」。

这解释了实践中一条几乎通用的约定——**只惩罚权重（weight），不惩罚偏置（bias）**。原因是：权重刻画的是「两个变量如何相互作用」，需要大量数据才能拟合准，容易过拟合，值得加先验约束；而偏置只控制单个神经元的整体平移，用很少数据就能拟合，且惩罚它反而会引入明显的欠拟合（Goodfellow §7.1 明确指出这一点）。同理，通常也不对 BatchNorm/LayerNorm 的缩放/平移参数 γ、β 做权重衰减。初学者常犯的错是「对所有参数一刀切地加 weight decay」，实现里应把 bias 和归一化参数排除在外。

### 2.1.5 weight decay 与 L2 在自适应优化器下的分歧

`⚙演进快·锚 AdamW 论文 2019`

有一个现代必须点明的分歧：「把 (α/2)‖w‖² 加进损失里」和「每步把权重乘以 (1−η·α) 」这两种写法，在**普通 SGD 下完全等价**，但在 **Adam 这类自适应优化器下不等价**。原因是自适应优化器会用各参数的历史梯度平方去缩放每个方向的步长——如果把 L2 惩罚混进梯度里，这个惩罚也会被同样缩放，导致「梯度大的参数被衰减得反而少」，偏离了「均匀收缩」的本意。

Loshchilov & Hutter 在 2019 年（ICLR，arXiv 2017 首发）提出 **AdamW**，把权重衰减从梯度里「解耦」出来、直接在参数更新末尾乘 (1−η·α)，恢复了 SGD 下那种干净的收缩语义，并成为如今训练 Transformer 的默认做法。初学者要记住的分寸是：在 SGD 里 L2 和 weight decay 可以混着说；一旦用 Adam，请用 AdamW（即解耦式权重衰减），二者数值行为不同。本条属现代实践演进，锚 2019 论文时点。

## 2.2 Dropout（训练期随机置零的集成视角）

### 2.2.1 Dropout 是什么

Dropout 在**训练时**，对某一层的每个神经元，以概率 (1−p) 独立地把它的输出**临时置零**（p 是「保留概率」keep probability），相当于每次前向都在随机地「关掉」网络里的一部分单元。被关掉的单元这一步既不参与前向、也不接收反向的梯度。**推理（测试）时**不再随机置零，而是用完整网络，但要对激活做相应缩放以补偿训练期的置零（见 2.2.2）。

它由 Srivastava、Hinton 等人 2014 年在 JMLR 系统提出（更早的雏形见 Hinton et al. 2012 arXiv），是深度学习最有效、最常用的正则化之一，Goodfellow 用整个 §7.12 讲它。直觉上，随机丢神经元逼迫网络**不能过度依赖任何单个单元或某几个单元的固定搭配**——因为它们随时可能消失——于是网络学到的是更分散、更冗余、更鲁棒的表示，这正是抗过拟合的来源。

### 2.2.2 训练/推理的缩放（inverted dropout）

置零会改变一层输出的期望规模：训练时平均只有比例 p 的单元存活，推理时全部存活，两者的量纲对不上。解决办法有两种等价写法。原始论文的**权重缩放推理规则**是训练时照常置零、推理时把该层权重（或激活）乘以 p，让推理期望与训练期望对齐。现代实现更常用**inverted dropout（反向 dropout）**：把缩放挪到训练期——训练时置零后**立即除以保留概率 p**，推理时则什么都不做、用原始网络。

设某单元训练期激活为 a、掩码 mask 以概率 p 取 1、否则取 0，则 inverted dropout 的训练期输出为

y_train = (a · mask) / p

推理期直接 y_test = a。因为 E[mask] = p，所以 E[y_train] = E[a·mask]/p = (p·a)/p = a = y_test，期望在训练/推理间保持一致。本次 numpy 实证（丢弃概率 0.3、即 p=0.7）测得训练期输出均值≈0.0005、原始均值≈0.0016，二者基本相等，坐实了这一点。初学者最常踩的坑有两个：一是**推理时忘了关掉 dropout**（把随机置零也用到测试上，结果每次预测都在抖）；二是误以为除以 p「把方差也还原了」——实证同时显示方差被放大了（0.99→1.42），inverted dropout 保的是**期望**不是方差，这是设计取舍。框架里 `torch.nn.Dropout` 的默认丢弃概率 p=0.5（`⚙演进快·锚 PyTorch 文档 @2026-07-30`；注意 PyTorch 的参数 p 指「丢弃」概率，与论文「保留」概率 p 记号相反，易混）。

### 2.2.3 集成 / bagging 视角

Dropout 最深刻的解释是把它看成一种**廉价的模型集成（近似 bagging）**。一个有 n 个可丢单元的网络，其所有「丢/留」组合对应 2ⁿ 个不同的子网络；每次训练前向随机采一个掩码，就等于在训练 2ⁿ 个**共享参数**的子网络中的一个。训练结束后用完整网络（配合权重缩放）做推理，近似于对这指数多个子网络的预测求**几何平均**——相当于一次性把一大票模型的集成塞进单个网络里，而集成正是降方差、抗过拟合的经典手段。

这个视角能一次讲通好几件事。它解释了为什么 Dropout 要**参数共享**（否则训练 2ⁿ 个独立模型不可能）；解释了推理期的权重缩放本质上是在做「集成平均」的近似（Goodfellow §7.12 称之为 weight scaling inference rule，并指出它对某些模型是精确的、对深层网络是启发式近似）；也解释了它和 bagging 的区别——bagging 的各模型独立、用不同数据子集训练到收敛，而 Dropout 的子网络共享参数、绝大多数从未被单独训练过。初学者不必纠结「几何平均是否精确」这类纵深，只需记住核心图景：**训练时随机采子网、推理时用整网做近似集成**。

### 2.2.4 实践要点与与 BN 的相互作用

实践中 Dropout 一般加在**全连接层之后**、且常只作用于隐藏层（输入层若用则保留概率更高，如保留 0.8）；卷积层因参数共享、本身过拟合风险较低，用得较少或用专门变体。丢弃概率是要调的超参数，太大导致欠拟合、太小则正则不足。

一个现代必须知道的相互作用是 **Dropout 与 BatchNorm 同用会打架**。BN 依赖批内统计（均值/方差），而 Dropout 在训练期随机置零会扰动这些统计、且训练/推理的方差不一致，两者叠放常导致性能下降；实践中很多现代架构（尤其带 BN 的 CNN）**索性去掉 Dropout、只靠 BN 的正则副作用**，或把 Dropout 放到 BN 之后、或只在最后的分类头上用。Transformer 则用 LayerNorm（不依赖批统计）配 Dropout，冲突较小。这是「多种正则叠加会相互作用」的典型例子，初学者不要机械地「层层都加 Dropout」。本条属现代实践经验，具体讲次锚 CS231n/CS224n（`待核`当学期讲义）。

## 2.3 早停（以验证集为隐式正则）

### 2.3.1 早停是什么

早停（early stopping）是训练循环里最简单也最常用的正则化：训练时定期在**验证集**上评估，记录到目前为止验证误差最低的那组参数；当验证误差在连续若干次评估中不再改善（超过「耐心值」patience）时，就**停止训练并回退到验证误差最低的那组参数**。它几乎零成本，Goodfellow §7.8 称其为深度学习中最常用的正则化形式。

它的动机来自一个几乎普遍的现象：训练久了，**训练误差会持续下降，但验证误差会先降后升**——升上去的那一段就是网络开始过拟合、把训练集噪声也背下来的阶段。早停就是在验证误差的「谷底」处叫停，不让网络走进过拟合区。初学者可把它对照 L5-02 大主题6 的验证曲线：那条随复杂度先降后升的 U 形，在这里是随「训练轮数」先降后升，早停就是在时间轴上找 U 形谷底。

### 2.3.2 为什么早停是「隐式正则」

早停被称为**隐式**正则，是因为它不往损失函数里加任何惩罚项，而是通过**限制优化走的步数**来间接限制模型的「有效复杂度」。可以这样理解：参数通常从接近 0 的小值初始化，训练每走一步就让权重朝拟合训练数据的方向多走一点、幅值多长一点；训练轮数越少，权重能离开初始点的距离就越有限——这恰恰和 L2 惩罚「把权重拉向 0」是同一件事的两种实现。

Goodfellow §7.8 给出了一个精确的对应：在最优点附近做二次近似，**早停等价于 L2 正则**，其中「训练步数 × 学习率」扮演的角色与 L2 强度 α 成**反比**——训练越久相当于 α 越小（正则越弱），训练越短相当于 α 越大（正则越强）。这解释了为什么早停能当正则用：它把「训练多久」变成了一个复杂度旋钮。两者相比，早停的最大优点是**几乎免费**——它在正常训练过程中顺便就把「最优正则强度」找出来了，不像 L2 需要跑多次不同 α 去搜索。

### 2.3.3 实践要点

用早停要注意几件事。其一，需要划出独立的验证集，这会「吃掉」一部分训练数据；常见补救是早停确定好轮数后，**再用全部数据（训练+验证）重训到那个轮数**，把验证集的数据也用上（Goodfellow §7.8 给了两种具体策略）。其二，验证误差往往有噪声、会抖动，所以要设**耐心值 patience**（容忍连续多少次不改善才停），而不是一看到上升就停，否则会被随机波动骗到过早停止。其三，一定要**保存并回退到「最佳」那组参数**（restore best weights），而不是停在最后一步的参数——停下来那一刻的参数已经比谷底差了。

早停和其它正则可以叠加使用（如同时用 weight decay + Dropout + 早停），它们从不同角度压过拟合，通常互补而非互斥。初学者最容易忽略的是「回退到最佳权重」这一步——只记了「什么时候停」却停在了更差的参数上，等于白做。

#### 来源与时效

- 主锚：Goodfellow《Deep Learning》(2016) §7.8「Early Stopping」（隐式正则、与 L2 的二次近似等价、训练步数 × 学习率 ~ 1/α、两种数据回收策略）。
- 交叉核对：L5-02 大主题6 验证曲线（验证误差先降后升的 U 形，本节将其搬到「训练轮数」轴上，结论一致）；CS231n/CS224n Winter 2026 训练实践讲义均把 early stopping + restore best weights 列为标准做法（当学期讲次「待核」）。
- 「早停 ≈ L2」为二次近似下的结论，非任意损失景观下的精确等式——Goodfellow 明确其为近似，无来源冲突。

## 2.4 数据增强（不变性先验注入）

### 2.4.1 数据增强是什么

数据增强（data augmentation）是在训练时对每个样本施加**保标签（label-preserving）的随机变换**，生成大量「新」样本喂给网络。比如一张猫的图片，平移几个像素、水平翻转、轻微旋转、改变亮度后，它**仍然是一张猫**——标签不变，但像素值变了。用这些变体训练，等于免费扩大了训练集。Goodfellow §7.4 把它列为最有效的正则化之一，尤其对图像分类。

它之所以算正则化，是因为它直接对抗过拟合的根源——数据太少。更深一层的理解是：数据增强在向模型**注入不变性先验**。选择「平移、翻转、缩放不改变类别」这些变换，其实是在告诉网络「你应该对这些变换保持不变」；网络在拟合这些变体的过程中，被迫学到对它们不敏感的表示。所以增强不是随便加噪声，而是**把我们对任务的先验知识（哪些变化无关紧要）编码进训练数据**。

### 2.4.2 各模态的常见增强

图像上最经典：随机裁剪、水平翻转、小角度旋转、平移、缩放、颜色/亮度/对比度扰动、加噪声。选哪些取决于任务的不变性——自然物体分类可以水平翻转，但**手写数字识别不能随便做水平翻转或大角度旋转**（6 翻转/旋转会变成别的数字，标签就变了），这是增强必须「保标签」的直接体现，也是最经典的易错点。

文本和语音的增强要谨慎得多，因为语言对微小改动很敏感（改一个词可能改变句意），常见做法有同义词替换、回译、随机删除/交换（幅度要小），远不如图像增强那样无脑好用。表格数据一般不做几何式增强。核心判据始终是：**这个变换会不会改变样本的正确标签**——不会才能用。

### 2.4.3 与噪声注入的关系；现代增强

数据增强和「向输入注入噪声」是近亲：给输入加小噪声可看成一种增强，Goodfellow §7.4–7.5 还指出向权重或隐层注入噪声、以及标签平滑（label smoothing，把 one-hot 标签软化一点）也都是相关的正则手段。它们共同的思想是「让模型在扰动下仍给出一致输出」。

现代增强手法已远超简单几何变换，如 mixup（把两张图及其标签按比例线性混合）、Cutout/随机擦除、RandAugment/AutoAugment（自动搜索增强策略组合）等，在现代视觉训练里几乎是标配。这些属于 2016 年 Goodfellow 成书后的活跃发展，本报告只登记、不展开、不排名，`⚙演进快·锚版本`，具体方法与默认强度「待核」当学期 CS231n 讲义。初学者阶段掌握「保标签变换 + 注入不变性先验」这条主线即可。

#### 来源与时效

- 主锚：Goodfellow《Deep Learning》(2016) §7.4「Dataset Augmentation」、§7.5「Noise Robustness」（增强、输入/权重噪声注入、与不变性的关系）；标签平滑见 §7.5.1。
- 交叉核对：CS231n Winter 2026 视觉训练讲（随机裁剪/翻转/颜色扰动为标准 pipeline，手写数字不可翻转的保标签原则一致）——当学期讲次「待核」。
- 现代增强（mixup / Cutout / RandAugment / AutoAugment）：晚于 Goodfellow 2016，`⚙演进快·锚版本`，只登记不作定论，默认强度「待核」。

## 2.5 BatchNorm / LayerNorm（归一化兼具正则与优化效应）

### 2.5.1 BatchNorm 是什么与前向公式

BatchNorm（批归一化，Ioffe & Szegedy 2015）在网络中间插入一层，把某层激活在**一个 mini-batch 内、按每个特征通道**重新归一化到零均值、单位方差，再用两个可学习参数 γ、β 做缩放和平移。设一个 batch 有 m 个样本，对某个特征通道，前向为

μ_B = (1/m) · Σᵢ xᵢ

σ²_B = (1/m) · Σᵢ (xᵢ − μ_B)²

x̂ᵢ = (xᵢ − μ_B) / √(σ²_B + ε)

yᵢ = γ · x̂ᵢ + β

其中 ε 是防止除零的小常数（PyTorch `BatchNorm` 默认 ε=1e-5，`⚙演进快·锚 PyTorch 文档 @2026-07-30`）。可学习的 γ、β 让网络在需要时能「撤销」归一化（若 γ=√(σ²_B+ε)、β=μ_B 就恢复原激活），保证归一化不会削弱表达力。本次 numpy 前向实证：对 (batch=8, feature=4) 输入沿 batch 维归一化后，每个特征的 x̂ 均值≈0、标准差≈1，坐实公式。

初学者要抓住「沿哪个维度统计」这个关键：BN 对**每个特征通道、跨 batch 内所有样本**求均值方差。所以 BN 的行为**依赖 batch**——同一个样本，和不同的邻居凑成一个 batch，归一化结果会不同。这正是它带来正则副作用的原因，也是它诸多陷阱的根源。

### 2.5.2 训练 / 推理的差异（running statistics）

BN 在训练和推理时行为不同，这是必须讲清的一点。**训练时**用当前 batch 现算的 μ_B、σ²_B 归一化；同时用滑动平均悄悄累积一份**全局运行统计量**（running mean / running var），更新形如

running_mean ← (1 − momentum) · running_mean + momentum · μ_B

（PyTorch 的 momentum 默认 0.1，且其约定是「新观测占 momentum 权重」，与一般动量记号相反，易混，`⚙演进快·锚 PyTorch 文档 @2026-07-30`）。**推理时**不再依赖 batch，而是用这份累积好的运行统计量做归一化——这样单个样本也能推理，且结果不受同批邻居影响、可复现。

初学者最常见的 bug 就是忘了切换训练/推理模式（框架里如 PyTorch 的 `model.train()` / `model.eval()`）。若在推理时仍用当前 batch 统计、或 batch 只有 1 个样本，方差会失真甚至为 0，导致输出错乱。这与 Dropout「推理要关掉」是同类陷阱：**BN/Dropout 都是训练/推理行为不一致的层，模式切换绝不能忘**。

### 2.5.3 为什么有效：优化效应 vs 正则效应（含机制争议）

`⚙演进快·锚 原论文 2015 vs Santurkar 2018`

BN 带来两方面好处，本大主题主要关心其中的正则侧。**优化侧**：归一化让各层输入分布更稳定、量级更一致，使损失景观更平滑，从而允许更大的学习率、加速收敛、降低对初始化的敏感——这是 BN 被发明的主要目的（完整讲法归本课大主题3）。**正则侧**：因为每个样本的归一化依赖它所在 batch 的随机组成，同一样本在不同 batch 里会被施加略有不同的缩放，相当于给激活注入了一点「批采样噪声」，起到类似 Dropout 的轻度正则作用——这也是为什么用了 BN 后往往可以少用甚至不用 Dropout（呼应 2.2.4）。

这里有一处必须点明的**机制争议**。原论文（Ioffe & Szegedy 2015）把 BN 的功效归因于减少「内部协变量偏移」（Internal Covariate Shift，ICS，指训练中各层输入分布不断变化拖慢训练）。但 Santurkar et al. 2018（NeurIPS）通过实验反驳了这一解释，主张 BN 真正起作用的是**让损失景观更平滑**（使梯度更可预测、可用更大步长），而与 ICS 关系不大。两边都记：ICS 是原始动机叙事、至今仍被广泛引用；「平滑损失景观」是后续更被接受的解释。初学者的正确认知是——**BN 确实有效且广泛使用是共识，但「为什么有效」尚无定论**，不必当成已盖棺的知识，硬标 `⚙演进快`。

### 2.5.4 LayerNorm 与两者对比

LayerNorm（层归一化，Ba, Kiros & Hinton 2016）和 BN 公式几乎一样（同样是减均值除标准差再 γ、β 仿射），唯一但关键的区别是**沿哪个维度统计**：LayerNorm 对**单个样本、跨该样本的所有特征**求均值方差，完全**不跨 batch**。前向对每个样本独立地算

μ = (1/D) · Σⱼ xⱼ，  σ² = (1/D) · Σⱼ (xⱼ − μ)²，  x̂ⱼ = (xⱼ − μ) / √(σ² + ε)，  yⱼ = γ · x̂ⱼ + β

（对特征维求和，D 为特征数；PyTorch `LayerNorm` 默认 ε=1e-5，无 momentum 参数，因为不需要累积跨 batch 的运行统计量。）本次 numpy 实证：同一 (8,4) 输入沿 feature 维归一化后，每个样本的 x̂ 均值≈0、标准差≈1，坐实「按样本跨特征」。

BN 依赖 batch，batch 太小（甚至为 1）时统计不可靠、性能骤降，且训练/推理需切换统计来源；LayerNorm 每个样本自给自足、**与 batch 大小无关**、训练推理行为一致，也天然适合序列长度可变、batch 里样本长度不一的场景。正因如此，**LayerNorm 是 Transformer 的标配**（BN 在变长序列 + 小 batch 的 NLP 场景水土不服），而 BN 在固定尺寸、大 batch 的 CNN 视觉任务里仍是主流。初学者记一句话即可：**BN 跨样本按通道、适合视觉大 batch；LN 跨特征按样本、适合序列/Transformer**。

### 2.5.5 易错点与关联

其一，训练/推理**模式切换**别忘（2.5.2）；其二，BN 层的 γ、β **不做 weight decay**（呼应 2.1.4，它们是归一化参数不是普通权重）；其三，BN 与 Dropout 同用易冲突（呼应 2.2.4），现代带 BN 的网络常省掉 Dropout；其四，小 batch 用 BN 要警惕统计噪声过大，此时可换 GroupNorm/LayerNorm 等 batch 无关的归一化。

从关联上看，本节只从「正则副作用」这一侧切入 BN/LN；它们作为「让网络能训得更深」的核心优化工程件（与残差连接、参数初始化并列）的完整讲法归本课大主题3。Transformer 里把 LN 放在残差子层之前还是之后（Pre-LN vs Post-LN）会显著影响训练稳定性与是否需要 warmup，属架构工程取舍，归大主题6 与 L6-08，本报告只指路不展开。
