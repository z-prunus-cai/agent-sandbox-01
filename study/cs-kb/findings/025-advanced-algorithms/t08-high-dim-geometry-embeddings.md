## 8.1 凸包

### 8.1.1 凸包的定义与算法要输出什么

平面上 n 个点的**凸包**（convex hull）是包含所有点的最小凸多边形；等价地，它是这些点集的凸组合构成的最小凸集，其边界由一部分「极点」（在凸包上的顶点）按顺序连接而成。凸包算法的标准输出不是一个集合，而是这些极点**按沿边界的顺序（顺时针或逆时针）排好的序列**——顺序本身是结果的一部分，因为它编码了多边形的边。

初学者可以把点想成钉在木板上的钉子，凸包就是套住所有钉子的橡皮筋绷紧后的形状：橡皮筋只碰到最外圈的钉子，内部的钉子对形状毫无贡献。判断一个点是不是极点、以及三点转弯方向（左转/右转/共线），全靠一个基本原语——**叉积**（cross product）符号

cross(O, A, B) = (A_x − O_x)(B_y − O_y) − (A_y − O_y)(B_x − O_x)

它大于 0 表示 O→A→B 是逆时针（左转），小于 0 是顺时针（右转），等于 0 表示三点共线。几乎所有平面凸包算法都反复调用它，且它只用加减乘、不需除法或开方，数值上稳健，这是它成为几何算法基石的原因。

### 8.1.2 Graham 扫描

**Graham 扫描**（Graham scan）先固定一个必在凸包上的点（通常取 y 最小、并列时 x 最小的点作锚点），把其余点按相对锚点的**极角排序**，再沿排序后的序列用一个栈扫一遍：每加入一个新点，就检查栈顶两点与新点是否构成左转，若不是（右转或共线）就弹出栈顶，直到构成左转再压入新点。扫完一圈栈里剩下的就是凸包顶点。

一个更易实现、数值更省心的变体是 **Andrew 单调链**（monotone chain）：先把点按 (x, y) 字典序排序，然后分别构造「下凸包」和「上凸包」两条单调链，各自用同样的「非左转就弹栈」规则扫一遍，拼起来即得完整凸包。它避免了极角排序里的反正切与角度并列处理，本报告的实测就用这一变体。

关键直觉是「弹栈」对应橡皮筋绷紧：当新点让原本的拐角变成凹进去（右转），说明那个拐角其实不在凸包上，弹掉它。每个点最多被压入一次、弹出一次，所以扫描阶段是线性的 O(n)，总代价被排序主导（见 8.1.4）。一个常见易错点是共线点的处理——要不要保留边上的中间点，取决于定义；判等用「≤ 0 弹栈」会去掉共线中间点，用「< 0」则保留，写代码前须明确需求。

本机实测（可选，非承重）：对 60 个随机点，Andrew 单调链的输出顶点集合与 scipy.spatial.ConvexHull 完全一致（`mine==scipy: True`，凸包 12 个顶点），佐证实现正确。

### 8.1.3 增量法

**增量法**（incremental algorithm）换一个思路：不预先排序全体，而是一个点一个点地插入，始终维护「已插入点的凸包」。插入新点 p 时，若 p 落在当前凸包内部则直接丢弃；否则 p 在外部，需找出从 p 看当前凸包的两条「切线」，删掉这两条切线之间那段被 p「遮住」的旧边界，再把 p 接上去，更新凸包。

朴素增量法每次插入可能花 O(n) 找切线，n 次共 O(n²)。但若**先把点按 x 坐标排序**再按序插入，则每个新点必在当前凸包右侧、切线可从上次维护的边界局部推进找到，配合和 Andrew 单调链同构的分析可做到总计 O(n log n)（排序主导）。更强的是**随机增量**版本：按随机顺序插入、辅以「冲突图」记录哪个未插入点落在哪块区域，用与 8.2 同款的 backwards analysis 可证期望 O(n log n)。

Graham 扫描是「先全局排序、再一趟扫」，增量法是「边插边修」。二者在平面上都能做到 O(n log n)，但增量法的思想（尤其是随机增量 + backwards analysis）能推广到高维凸包、Delaunay 三角剖分（8.3）和低维 LP（8.2），是计算几何里比单个凸包算法更通用的范式，这也是 6.854 把它和后面几讲串在一起讲的原因。

### 8.1.4 O(n log n) 复杂度与 Ω(n log n) 下界

平面凸包的主流算法（Graham 扫描、Andrew 单调链、排序后增量法、分治法）都是

O(n log n)

且这**不是巧合**：计算凸包有一个匹配的下界

Ω(n log n)

因此这些算法在「基于比较的一般算法」意义下是渐进最优的。

给 n 个实数 x₁,…,xₙ，把每个 xᵢ 映射到抛物线上的点 (xᵢ, xᵢ²)。这些点全在抛物线（凸曲线）上，所以它们**全是凸包顶点**，而凸包把它们按边界顺序输出，恰好就是把 xᵢ 按大小排好序。于是「排序」被规约到了「凸包」，而基于比较的排序有 Ω(n log n) 下界（决策树叶子数 ≥ n!，树高 ≥ log₂(n!) = Θ(n log n)，见 L3-01 大主题04），这个下界就传递给了凸包。

初学者容易忽略「下界依赖计算模型」这一点：Ω(n log n) 是在比较/代数决策树模型下成立；若允许更强的运算或对输入有额外假设，界可以更低。此外，若只关心**输出规模** h（凸包顶点数）很小的情形，存在**输出敏感**算法（见 8.1.5）能打破 n log n 这个「与 h 无关」的界——所以说 O(n log n) 最优，指的是最坏情形、h 可达 Θ(n) 时。

### 8.1.5 输出敏感算法

当凸包顶点数 h 远小于 n（例如大量点挤在内部）时，**输出敏感**（output-sensitive）算法能比 O(n log n) 更快。最简单的是 **Jarvis 步进 / 礼品包裹法**（gift wrapping），从最低点出发，每一步用叉积找「相对当前边最靠右」的下一个凸包顶点，像包礼品一样一圈裹回来，代价

O(n · h)

h 很小时优于 n log n，但 h = Θ(n) 时退化到 O(n²)。**Chan 算法**（Chan's algorithm, 1996）巧妙融合分治与 Jarvis，达到最优的输出敏感界

O(n log h)

它既在 h 小时快、又永不劣于 O(n log n)。

直觉上 Jarvis 法每包一个顶点要扫全部 n 个点、共包 h 个，所以是 nh；Chan 算法先把点分成大小 m 的小组各自求凸包，再用类似 Jarvis 的方式跨组包裹，并用「猜 h、指数递增地重试 m」的技巧凑出 log h。初学者不必深究 Chan 的实现细节，只需记住结论层次：一般最坏情形 Θ(n log n) 最优；对 h 敏感时 Θ(n log h) 最优，后者严格更精细（h ≤ n 时 log h ≤ log n）。

## 8.2 固定维线性规划

### 8.2.1 低维 LP 的问题设定

线性规划（LP）在一般情形下变量数 d 与约束数 n 都大（用单纯形/内点法，见 L6-01 大主题03）。这里研究的是一个特殊而重要的机制：**维数 d 固定（是小常数）、约束数 n 很大**。此时 LP 写成

min cᵀx，subject to aᵢᵀx ≤ bᵢ（i = 1,…,n），x ∈ ℝᵈ

几何上是在 n 个半空间的交（一个多面体）里，沿目标方向 c 找最靠前的顶点。d 固定意味着「最优解由至多 d 个约束决定」（最优顶点是 d 个超平面的交点）。

初学者要抓的关键是「固定维」带来的组合有限性：既然最优只由 d 个约束定，而 d 是常数，那么再多的约束里绝大多数都是「冗余的」——问题的真正复杂度来自「从 n 个里挑出决定最优的那 ≤ d 个」。这类问题（含最小包围圆、最小包围球等）统称 **LP-type 问题**，Seidel 的方法对它们都适用。

### 8.2.2 Seidel 随机增量法

**Seidel 随机增量算法**（Seidel 1991）把 n 个约束**随机排列**后一个个加入，维护「当前所有已加约束下的最优解 v」。加入第 i 个约束 hᵢ 时分两种情况

若 v 已满足 hᵢ，则最优不变，直接继续；

若 v 违反 hᵢ，则新最优必落在 hᵢ 的边界超平面上，于是把问题**降一维**：在 hᵢ 这张 (d−1) 维超平面上、对前 i−1 个约束递归求解 LP。

递归的基例是 d = 1（一维 LP 就是区间求交、取端点，O(n)）。整个算法只用最基本的算术原语，代码极短，是随机化几何算法的教科书范例。

直觉在于「大多数时候新约束不影响当前最优，白加一下（O(d) 检查）就过；只有偶尔它真的把最优挤到自己边界上，才付一次昂贵的降维递归」。算法正确性不依赖随机顺序（任何顺序都对），随机化只用来保证**期望代价**低——即让「昂贵的降维递归」很少发生。

### 8.2.3 backwards analysis 与期望 O(d! · n)

分析用的是 Seidel 推广的 **backwards analysis**（逆向分析）：不问「加入第 i 个约束时会不会触发递归」，而是**倒过来**看——固定前 i 个约束已加入、当前最优为 v，问「如果把这 i 个里随机抽一个删掉，最优会变吗」。最优 v 由至多 d 个约束决定，所以随机抽到的那个恰好是「决定 v」的约束的概率 ≤ d/i。而只有当「第 i 个加入的约束正好是决定当前最优的那个」时，第 i 步才触发降维递归——由对称性，这个概率也是 ≤ d/i。

于是期望代价满足递推

T(n, d) ≤ T(n−1, d) + O(d) + (d/n)·[O(dn) + T(n−1, d−1)]

其中 O(d) 是「检查 v 是否满足新约束」的固定开销，方括号项是以概率 d/n 触发的降维（重算 (d−1) 维 LP）。解这个递推得期望时间

O(d! · n)

### 8.2.4 固定维即 O(n) 线性期望时间

因为 d 是**固定常数**，d! 也是常数，所以 Seidel 算法在固定维下的期望运行时间是

O(n)

即关于约束数**线性**（对固定 d 而言最优——至少要读一遍所有约束）。代价里对维数 d 的依赖是 d!（超指数），所以这套方法只对**低维**实用；维数一高，d! 就爆炸。

初学者要抓两个对照。其一，和单纯形/内点法比：那些方法针对 d、n 都大的通用 LP，多项式或实践高效；Seidel 针对「d 小 n 大」这个专门场景，把对 n 的依赖压到线性，是不同战场的最优。其二，d! 的超指数依赖后来被 Clarkson、以及 Matoušek–Sharir–Welzl 的 subexponential 算法改进（对高一点的维数更好）⚙演进快·锚 1990s；但在「d 固定、看 n」的教辅口径下，记住 Seidel 给出期望 O(n) 即可。所有界都是**期望**（对算法内部随机排列取期望，与输入分布无关），不是最坏情形——最坏排列仍可能慢，但概率极低。

## 8.3 Voronoi 图与 Delaunay 三角剖分

### 8.3.1 Voronoi 图

给平面上 n 个点（称**站点**，sites）p₁,…,pₙ，**Voronoi 图**（Voronoi diagram）把平面划分成 n 个区域（Voronoi 胞元），第 i 个胞元 V(pᵢ) 是「离 pᵢ 比离任何其他站点都近」的所有点集合

V(pᵢ) = { x : ‖x − pᵢ‖ ≤ ‖x − pⱼ‖，对所有 j ≠ i }

每个胞元是若干半平面的交，因而是凸多边形（可能无界）。相邻两胞元的公共边落在两站点连线的**垂直平分线**上，三个胞元交汇的 Voronoi 顶点到那三个站点等距。

直觉是「势力范围划分」：每个站点圈占离它最近的地盘，边界是「到两家一样近」的分界线。它直接回答**最近邻查询**——给一个查询点，落在哪个胞元里，最近站点就是谁。一个易错点是别把 Voronoi 边当成连接站点的线：Voronoi 边是垂直平分线的片段、**分隔**站点，真正连接站点的是它的对偶 Delaunay 边（见 8.3.3）。

### 8.3.2 复杂度与 O(n log n) 构造

平面上 n 个站点的 Voronoi 图，虽然胞元是二维区域，但它作为平面图的总规模是**线性**的

顶点数、边数、胞元数均为 O(n)

（由欧拉公式，平面图边数 ≤ 3V−6）。构造它的最优算法是 Fortune 的**扫描线算法**（Fortune's sweepline, 1987），时间

O(n log n)

且这是最优的——Voronoi 图能在 O(n) 时间导出有序凸包/排序，故同样有 Ω(n log n) 下界。

初学者常有的疑问是「n 个二维区域为什么总大小才 O(n)」：因为胞元虽是面，但它们彼此**共享**边和顶点、拼成一张无重叠的平面划分，平面图的欧拉公式把面数、边数、顶点数锁在线性关系里。Fortune 算法的巧思是用一条扫描线扫过平面、维护一条「海岸线」（beach line，已扫过站点的抛物线弧包络），把二维构造化成一维事件队列处理，细节较深，教辅层记住「O(n log n)、最优」即可。另有分治法与增量法也能到 O(n log n)。

### 8.3.3 Delaunay 三角剖分与对偶关系

**Delaunay 三角剖分**（Delaunay triangulation）是 Voronoi 图的**对偶**：为每个站点画一个对偶顶点，两个站点的胞元若相邻（共享一条 Voronoi 边），就在这两个站点间连一条 Delaunay 边。对于一般位置（无四点共圆）的点集，这些边把点集三角剖分成一堆三角形，且

三个站点构成一个 Delaunay 三角形 ⟺ 它们的三个 Voronoi 胞元交于一个公共 Voronoi 顶点

所以 Voronoi 顶点对应 Delaunay 三角形、Voronoi 边对应 Delaunay 边、Voronoi 胞元对应站点，二者一一对偶，知道一个就能 O(n) 导出另一个。

Voronoi「分隔」站点、画的是边界；Delaunay「连接」站点、画的是三角网。两张图叠在一起，每条 Delaunay 边都恰好穿过它对偶的那条 Voronoi 边（垂直相交）。因为 Voronoi 图规模 O(n)，Delaunay 三角剖分同样 O(n) 大小、O(n log n) 可构造。它在网格生成、地形建模、插值中是核心结构。

### 8.3.4 空外接圆性质与最大化最小角

Delaunay 三角剖分有一条刻画它的核心性质——**空外接圆**（empty circumcircle）：一个三角形属于 Delaunay 三角剖分，当且仅当它的外接圆内部不含任何其他站点。等价地，一条边是 Delaunay 边，当且仅当存在一个过该边两端点的圆、其内部不含其他站点。

由此推出它最著名的最优性质——**最大化最小角**（max-min angle）：在同一点集的所有三角剖分中，Delaunay 三角剖分使「所有三角形的最小内角」达到最大（按角度序列字典序最优）。

这个性质的直觉与实际价值在于「避免又瘦又长的三角形」：瘦长三角形（小角）在有限元、插值、渲染里会放大数值误差，而 Delaunay「尽量让三角形胖一点」，所以它是网格生成的默认选择。空外接圆性质还给出构造/验证的局部规则——**边翻转**（edge flip）：若相邻两三角形拼成的四边形里，一个三角形的外接圆包含了对面顶点，就翻转它们共享的对角线，反复翻到无处可翻即得 Delaunay 剖分。一个易错点是这些漂亮性质依赖「一般位置」假设（无三点共线、无四点共圆）；退化情形下 Delaunay 剖分可能不唯一，需要额外的符号扰动或约定处理。

## 8.4 度量嵌入

### 8.4.1 度量嵌入与失真

一个**度量空间** (X, d) 是一组点加一个满足非负、对称、三角不等式的距离函数 d。**度量嵌入**（metric embedding）是把 (X, d) 映到另一个（通常结构更好的，如欧氏空间 ℓ₂）度量空间的映射 f，我们关心它把距离改变了多少。映射 f 的**失真**（distortion）定义为：存在常数使

(1/α)·d(u,v) ≤ ‖f(u) − f(v)‖ ≤ β·d(u,v)（对所有 u, v）

失真即 α·β 的最小值（可先把 f 整体缩放，让一边为 1）。失真 = 1 表示等距嵌入（完美保距），越大表示距离被扭曲越厉害。

许多问题在欧氏空间（ℓ₂）里有好算法（最近邻、聚类、分割），但真实数据的度量（如图上最短路距离、编辑距离）不是欧氏的。若能以小失真把任意度量嵌入 ℓ₂，就能把欧氏空间的算法「借」给一般度量用，代价是近似比乘上失真。初学者要抓的是：嵌入不是要求完美保距（一般做不到），而是求**失真尽量小**——这是一个「用可控的距离误差换算法可用性」的交易。

### 8.4.2 Bourgain 定理

**Bourgain 定理**（Bourgain 1985）是这套理论的奠基结果：**任意** n 点度量空间都能嵌入欧氏空间 ℓ₂，失真为

O(log n)

也就是说，无论原度量多「不欧氏」，只要付 O(log n) 倍的距离扭曲，就总能塞进欧氏空间。这个界对 n 点度量是普适的、不依赖度量的任何特殊结构。

初学者要理解这是一个**存在性 + 构造性**的强保证：它不是说「某些好度量能低失真嵌入」，而是说「**所有**度量，哪怕最刁钻的，失真都不超过 O(log n)」。log n 随点数增长而非常数，看似不小，但相对「任意度量」这个极弱前提已是惊人地好——正是它让「嵌入 + 用欧氏算法」成为近似算法（如 sparsest cut，见 L6-01 大主题04）的通用武器。

### 8.4.3 Bourgain 定理的紧性

Bourgain 的 O(log n) 失真是**渐进最优**的，无法普遍改进。存在 n 点度量，任何到 ℓ₂ 的嵌入失真都至少

Ω(log n)

因此这个问题的最优失真是 Θ(log n)。

最优性的经典证据是**常数度扩张图**（constant-degree expander）的最短路度量：Linial–London–Rabinovich (1995) 证明把这类图度量嵌入 ℓ₂ 必然产生 Ω(log n) 失真。直觉是扩张图「所有点彼此都差不多远、又高度连通」，这种「均匀地挤在一起」的结构和欧氏空间（低维时点会稀疏散开）本质冲突，硬塞进去必然大幅扭曲某些距离。初学者记住结论层次即可：Bourgain 上界 O(log n) 与扩张图下界 Ω(log n) 夹逼出 Θ(log n)，这个界不能靠更聪明的嵌入绕过。

### 8.4.4 Bourgain 嵌入的构造思路

Bourgain 定理的证明本身给出一个**随机构造**：坐标由「到随机点子集的距离」给出。对每个规模尺度 2ᵏ（k = 0,…,log n），随机抽若干个点子集 S；嵌入的每一维坐标就是该点到某个 S 的最短距离

f_S(x) = d(x, S) = min_{s∈S} d(x, s)

把这些坐标（跨所有尺度、每尺度多次采样，共 O(log²n) 维）拼成向量并适当归一化，就得到失真 O(log n) 的欧氏嵌入。

直觉是「到一个随机点集的距离」这种 **Fréchet 型坐标**天然是 1-Lipschitz 的（由三角不等式，任何两点的这类坐标之差 ≤ 它们的真实距离），所以上界那半（不放大距离）几乎自动成立；难的是下界那半——要证明「用足够多、足够多尺度的随机子集，就能让某些坐标把每对点的距离拉开到与真实距离同阶（只差 O(log n)）」，这一步用概率论证保证「大概率至少有一个尺度的采样把这对点分得够开」。初学者不必深究证明，抓住「坐标 = 到随机子集的距离、多尺度采样、维数 O(log²n)」这个构造骨架即可。

### 8.4.5 Johnson–Lindenstrauss 引理

如果原度量**本来就是欧氏的**、只是维数太高，那有比 Bourgain 更强得多的结果——**Johnson–Lindenstrauss 引理**（JL, 1984）：ℝᵈ 中任意 n 个点，可用一个**随机线性映射**投到

k = O(log n / ε²)

维，使**所有**点对距离都被保持在 (1 ± ε) 之内（高概率）

(1 − ε)‖u − v‖² ≤ ‖f(u) − f(v)‖² ≤ (1 + ε)‖u − v‖²

关键在于目标维数 k **只依赖点数 n 和精度 ε，完全不依赖原维数 d**。

映射可以极简单：取一个 k×d 的随机矩阵（元素独立取标准高斯，或 ±1），乘上向量再除以 √k 归一化即可。原理是「随机投影后，每对点距离的平方是一个集中在其期望附近的随机变量」，用 Chernoff 型集中不等式证明单对失真超过 ε 的概率 < 1/n²，再对全部 C(n,2) 对做 union bound。初学者要抓 JL 与 Bourgain 的分工：JL 要求**输入已是欧氏**、几乎不失真（失真 1+ε）地**降维**；Bourgain 处理**任意度量**、但只能保证 O(log n) 失真。二者常被并列讲，却解决不同问题。

本机实测（可选，非承重）：500 个点从 d = 2000 维用高斯随机投影降到 k = ⌈8 ln n / ε²⌉ = 1243 维（ε = 0.2），全部 124750 对点的距离比值落在 [0.914, 1.083] 内，越界比例 = 0.0000，均值 0.998——与 JL 的 (1±0.2) 保证吻合。

### 8.4.6 Bourgain 与 JL 的辨析

两条结果都叫「嵌入进 ℓ₂」，但适用前提和保证完全不同，初学者极易混淆。

Bourgain 处理**任意（非欧）度量**，失真 O(log n)（随 n 增长），目标维数约 O(log²n)，是「把结构未知的度量塞进欧氏空间」的通用桥；JL 要求**输入已是欧氏**，失真仅 1 + ε（可任意接近无失真），目标维数 O(log n / ε²)，是「高维欧氏点集的降维」。一句话对照

任意度量 → ℓ₂ ：失真 Θ(log n)（Bourgain，不可再普遍改进）

欧氏 → 低维欧氏 ：失真 1 ± ε（JL，几乎无损降维）

一个常见误区是把 JL 的「1+ε 失真」套到一般度量上——那是错的，一般度量的 Θ(log n) 下界（8.4.3）挡在那里，JL 的强保证严格依赖「输入是欧氏、有内积和平方距离可集中」这个前提。任务提到「用 numpy 佐证 JL 降维」正对应 8.4.5 的实测。

## 8.5 欧氏 TSP 的 PTAS

### 8.5.1 PTAS 定义与欧氏 TSP 的特殊性

**PTAS**（polynomial-time approximation scheme，多项式时间近似方案）指：对任意固定精度 ε > 0，都有一个多项式时间算法输出一个 (1 + ε)-近似解（最小化问题里解 ≤ (1+ε)·最优）。它比常数近似强得多——精度可任意逼近最优，代价是运行时间随 1/ε 变差（但对固定 ε 仍是关于输入规模的多项式）。

**欧氏 TSP**（Euclidean TSP）是「平面（或 ℝᵈ）上给 n 个点，求访问所有点恰一次的最短闭合巡回」。一般度量 TSP 只有常数近似（Christofides 的 3/2，见 L6-01 大主题04），且被证明**不存在 PTAS**（除非 P = NP）；欧氏 TSP 仍是 NP 难的，但它的**几何结构**（点在平面上、距离是真欧氏距离、满足三角不等式且有坐标）让 PTAS 成为可能——这正是本节的核心反差：同一个问题，加上「欧氏」这个几何前提，近似难度就从「常数是极限」变成「可任意逼近最优」。

### 8.5.2 Arora 方案：随机移位四叉树 + portal + 动态规划

**Arora 的 PTAS**（Arora 1998，2010 年 Gödel 奖）的骨架分三步。

其一，把所有点框进一个大正方形，构造一棵**随机移位的四叉树**（shifted quadtree）：随机选偏移量把整个坐标平移后，递归地把每个方格四等分，直到每个方格至多含一个点。随机移位是保证「期望近似比达标」的关键，不能省。

其二，在四叉树每条方格边界上放 m 个等距的 **portal（传送门）**，并规定：算法只考虑那些**每次跨越方格边界都恰好从某个 portal 通过**的巡回（portal-respecting tour），且限制每条边界被穿越的次数不超过某个常数 r（m-light 条件）。

其三，自底向上做**动态规划**：对每个方格，其内部最优「portal-respecting 部分巡回」只取决于「巡回在该方格边界的 portal 上进出的配对方式」这一有限接口信息；把子方格的最优解按接口拼起来，逐层合并到根，即得全局近似最优巡回。

四叉树把平面递归切成小块，portal 把「巡回可以在哪里跨越切线」离散成有限个点，于是「方格内部怎么走」就只剩有限种接口情形，动态规划得以逐块求解再拼装。核心的技术保证是一条**结构定理**（structure theorem）：存在一条 (1 + ε)-近似的巡回，它是 portal-respecting 且 m-light 的，其中 m = O(log n / ε)、跨越次数 r = O(1/ε)。随机移位保证「把最优巡回改造成 portal-respecting 所付的额外长度，期望上 ≤ ε·最优」——这就是随机化的用处。

### 8.5.3 运行时间与相关结果

平面欧氏 TSP，Arora 方案对固定 ε 给出 (1 + ε)-近似，运行时间（随机化版本，2D）

O( n · (log n)^{O(1/ε)} )

对固定 ε 这是 n·polylog(n)，确是多项式（PTAS 达标）。它可以**去随机化**（对所有移位取最优，代价乘一个多项式因子）得到确定性 PTAS。推广到 ℝᵈ 维时，运行时间对 d 呈双指数式恶化，形如

n · (log n)^{ (O(√d / ε))^{d−1} }

所以「维数固定」同样是关键前提（与 8.2 的固定维精神一致）。

初学者要抓三点。其一，PTAS 里 1/ε 跑到了指数位置（(log n) 的幂次是 O(1/ε)），所以 ε 越小越慢——这正是 PTAS 「对固定 ε 多项式、但对 ε 不一致多项式」的典型形态（区别于对 1/ε 也多项式的 FPTAS，欧氏 TSP 不太可能有 FPTAS）。其二，**Mitchell (1999) 用「guillotine（断头台）分割」独立地得到了同样的 PTAS**，与 Arora 并列获 2010 年 Gödel 奖，二者思路不同（Arora 用 portal + 四叉树 DP，Mitchell 用 guillotine 子分割）但结论一致——这是一处「多来源相互印证」的经典范例。其三，这套「几何分治 + portal/分割 + DP」框架不止 TSP，还适用于 Steiner 树、k-MST 等一批几何优化问题。⚙演进快·锚 2021：Euclidean TSP 的近似–时间权衡近年有 Gap-ETH 意义下的匹配结果（更精细的下界刻画），但经典 PTAS 结论仍以 Arora/Mitchell 为准。
