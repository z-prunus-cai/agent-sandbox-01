## 3.1 LP 标准型与几何

### 3.1.1 线性规划是什么：目标与约束都线性

线性规划（Linear Programming, LP）是这样一类优化问题——**在一组线性等式/不等式约束下，最大化或最小化一个线性目标函数**。一个典型写法（CLRS 4e §29.1 称为"标准型 standard form"）是

maximize　cᵀx

subject to　Ax ≤ b,　x ≥ 0

其中 x ∈ ℝⁿ 是决策变量向量，c ∈ ℝⁿ 是目标系数，A 是 m×n 约束矩阵，b ∈ ℝᵐ 是右端向量。"线性"指目标 cᵀx 与每条约束都是变量的一次式，没有 x²、xy、log x 这类项。

初学者先建立的直觉是"LP 是最简单的一类连续优化，简单到有一整套漂亮理论"。因为目标和约束都是线性的，可行域是一堆半空间的交（平的边界），目标的等值面也是平的（一族平行超平面），最优化就退化成一个纯几何问题：把目标等值面朝改进方向平推，推到再推就离开可行域的那一刻，接触点就是最优。一个最小的例子：max x₁ + x₂ s.t. x₁ ≤ 3, x₂ ≤ 2, x ≥ 0，可行域是个矩形 [0,3]×[0,2]，最优在角点 (3,2)，值为 5。抓住"目标平推到顶点"这一画面，后面所有算法都在具体化"怎么找到那个顶点"。

### 3.1.2 标准型、松弛型与各种形式的互相转化

LP 有多种等价书写形式，任何一个都能通过机械变换转成另一个，所以"标准型"只是约定而非限制。CLRS 4e §29.1 用两个术语：**标准型（standard form）**是上面的 max cᵀx s.t. Ax ≤ b, x ≥ 0；**松弛型（slack form）**是给每条不等式引入一个非负松弛变量 sᵢ ≥ 0，把 Ax ≤ b 改写成等式

Ax + s = b,　s ≥ 0

常用的四种转化规则是：最小化 cᵀx 等于最大化 (−c)ᵀx；等式约束 aᵀx = b 拆成 aᵀx ≤ b 与 aᵀx ≥ b 两条；≥ 约束两边乘 −1 变 ≤；无符号限制（自由）变量 xⱼ 用两个非负变量之差 xⱼ = xⱼ⁺ − xⱼ⁻ 替换。

这里有一处**跨来源约定分歧，须显式标注**：CLRS 4e（§29.1）和多数算法教材把"标准型"定义成不等式形式 Ax ≤ b；而优化领域的经典教材 Bertsimas–Tsitsiklis §1.1 与 Boyd–Vandenberghe §4.3 把"标准型（standard form）"定义成**等式加非负**的形式

minimize　cᵀx　s.t.　Ax = b,　x ≥ 0

两个"标准型"指的是不同东西。初学者读跨学科材料时最容易在这里卡住——看到"standard form"务必先确认是哪一派约定。本报告在讲单纯形时采用等式（松弛/字典）形式，讲对偶时采用不等式形式，均会就地点明。之所以能随意切换，正是因为上面四条转化规则保证了各形式的最优解一一对应。

### 3.1.3 多面体、半空间与凸性

LP 的可行域 {x : Ax ≤ b, x ≥ 0} 是一个**多面体（polyhedron）**——有限个半空间的交集。每条不等式 aᵢᵀx ≤ bᵢ 定义一个半空间（一张超平面切开空间后的一侧），交起来就是一块可能无界的"多面积木"。有界的多面体又叫**多胞形（polytope）**。

关键性质是可行域一定是**凸集**：若 x、y 都可行，则线段上任一点 λx + (1−λ)y（0 ≤ λ ≤ 1）也可行。证明一句话——半空间是凸的，凸集的交仍是凸的。凸性是 LP 一切好性质的根源：它保证了"局部最优即全局最优"（凸集上线性函数不会有假的局部极值），也保证了"最优点能取在顶点"（下一项）。

初学者要留意可行域的三种形态，都会真实出现：空（无可行解，如 x ≤ 1 且 x ≥ 2）、有界（多胞形，最优必存在）、无界（如只有 x ≥ 0，此时若目标沿无界方向可无限改进，则 LP "无界 unbounded"、无有限最优）。把"可行、有界、最优存在"三件事分清，是读懂后面对偶定理各种情形组合的前提。

### 3.1.4 顶点、极点与基本可行解的三位一体

多面体的"角"有三个来自不同角度、但可证等价的刻画，这是 LP 理论的枢纽概念（Bertsimas–Tsitsiklis §2.2 给出等价性定理，CLRS 4e §29.1 用几何语言介绍）。**顶点（vertex）**是几何定义：不能表示成可行域中两个不同点的严格凸组合的点。**极点（extreme point）**是同一件事的另一种说法。**基本可行解（basic feasible solution, BFS）**是代数定义。

以等式形式 Ax = b, x ≥ 0（A 为 m×n、秩 m）为例，一个基本解这样构造

选 m 个线性无关的列构成基 B，令这 m 个基变量 x_B = B⁻¹b，其余 n−m 个非基变量置 0

若得到的 x_B ≥ 0，则这个基本解同时可行，就是一个**基本可行解**。三者等价定理说：x 是顶点 ⟺ x 是极点 ⟺ x 是基本可行解。

初学者最该记住的直觉是"顶点 = 让足够多条约束同时取等号（'卡死'）的可行点"。在 n 维空间里，要唯一钉住一个点需要 n 个线性无关的等式；顶点就是让至少 n 条约束（含 x ≥ 0 的那些）变成等式、把点卡在一个角上。代数上"非基变量置 0"正对应"这些 xⱼ ≥ 0 取等号"。一个易错点：BFS 的个数是有限的（至多从 n 列里选 m 个，即 C(n, m) 种基），这正是单纯形能在有限步内枚举顶点的原因——把连续的搜索离散化成了有限个角之间的跳跃。

### 3.1.5 线性规划基本定理

线性规划基本定理（Fundamental Theorem of LP，Bertsimas–Tsitsiklis §2.6、CLRS 4e §29.1）把"最优在顶点"这件事说成定理

若 LP 的可行域非空且至少有一个顶点，且 LP 有有限最优值，则必存在一个顶点（基本可行解）达到该最优值

换句话说，找最优不必搜遍整块多面体的内部与边界，只要**在有限个顶点里找**就够了。

理解这条定理为什么成立，可借线性目标"平推"的画面：把目标等值超平面沿改进方向推，最后停在可行域边界；若停在一条边或一个面上（而非单个角），那条边/面的端点顶点也同样最优——所以总能"退到"一个顶点取到最优。这就是把无限连续搜索变成有限组合搜索的理论许可证，是单纯形法（3.2）合法性的地基。需要留意前提"至少有一个顶点"：像整个 ℝⁿ（无任何约束）这种含直线的可行域没有顶点，定理不直接适用；但 LP 标准型有 x ≥ 0，自动排除了这种退化情形。另一个边界情形是最优值可能在"整条边/整个面"上都取到（目标与某约束平行），此时最优解不唯一，但仍至少有一个是顶点。

## 3.2 单纯形法

### 3.2.1 单纯形法的核心思想：沿棱从顶点走到顶点

单纯形法（Simplex method，Dantzig 1947）是求解 LP 的经典算法，思想直接来自 3.1 的基本定理——既然最优必在某顶点，那就**从一个顶点出发，沿多面体的棱走到相邻顶点，每一步都让目标不变差，直到无法再改进为止**。它是一种在顶点之间跳跃的、单调改进的局部搜索，但由于凸性，局部走不动时就是全局最优。

一轮迭代（一次"转轴 pivot"）的骨架是

在当前基本可行解上，找一个能改进目标的非基变量让它"进基"（entering variable）

沿该方向增大它的值，直到某个基变量先降到 0，让那个变量"出基"（leaving variable）

更新基与基本可行解，重复

初学者可以把它想成"在多面体的骨架（顶点+棱）上爬山"：当前站在一个角，环顾相邻的角，只要有一个角目标更好就走过去，没有更好的邻角就说明到顶了。为什么"没有更好的邻角"就能保证全局最优？因为可行域凸、目标线性，不存在被"低谷"隔开的另一个更高的角——这正是凸性买来的红利。判断"是否还能改进"靠的是**既约成本（reduced cost）**：把目标用非基变量表示后，某非基变量系数若还指向改进方向，就说明沿它走能变好；全部非基既约成本都不指向改进时即达最优。

### 3.2.2 字典/单纯形表与转轴的机制

具体运算通常在**字典（dictionary）或单纯形表（tableau）**上做（CLRS 4e §29 讲松弛型下的 PIVOT；Bertsimas–Tsitsiklis Ch3 用表格形式）。字典把每个基变量和目标 z 都表示成非基变量的线性式，例如某步

z = 28 + (改进系数)·(非基变量)

x_B = (常数) − (系数)·(非基变量)

转轴一步做两件事：选一个既约成本还指向改进的非基变量进基；再用**比值检验（ratio test）**——在保持所有基变量 ≥ 0 的前提下，看进基变量最多能增大到多少，最先被逼到 0 的那个基变量出基。然后代数消元，重写字典，得到相邻顶点。

初学者容易混淆"进基/出基"的方向：进基变量从 0 开始变大（对应离开一个"卡死"的边界、朝可行域内部走一小段），出基变量被推到 0（对应撞上一个新的边界、卡死到新的角）。比值检验的本质是"沿这条棱最多能走多远才不越界"。一个实用的最小算例（CLRS 4e Ch29 经典例，本报告下面实证也用它）

maximize 3x₁ + x₂ + 2x₃　s.t.　x₁+x₂+3x₃ ≤ 30,　2x₁+2x₂+5x₃ ≤ 24,　4x₁+x₂+2x₃ ≤ 36,　x ≥ 0

单纯形从原点出发，几步转轴后停在 x = (8, 4, 0)，最优值 28。

### 3.2.3 退化与循环

**退化（degeneracy）**指某个基本可行解里有基变量取值恰为 0。几何上，退化顶点是"被超过 n 条约束同时卡住"的角（约束冗余地重合在同一点）。退化本身不是错，但它会带来一个危险：转轴时比值检验可能算出"能走 0 步"，即换了基却没换顶点、目标也没改进——这种原地打转若周而复始，就是**循环（cycling）**，单纯形永不终止。

理解为什么退化会导致循环，可以想象一个被三条约束卡在同一点的二维顶点（正常只需两条）：算法可能在这几组"卡死约束"对应的不同基之间反复切换，几何上一直停在同一个角，代数上基却在变，于是有可能绕回起点。循环在实践中极其罕见（随机扰动几乎必然打破），但理论上确实存在具体反例（如 Beale 的经典 3 变量循环例），所以证明单纯形"一定终止"就必须处理它。初学者要分清"退化"（一个静态状态，很常见）与"循环"（一个动态灾难，需专门规则杜绝）这两件不同的事。

### 3.2.4 Bland 反循环规则与终止性

只要没有循环，单纯形必然有限终止——因为顶点/基只有有限个（C(n,m)），而每步目标严格改进就不会重复访问。要根除循环，用一条**反循环转轴规则（anti-cycling pivoting rule）**即可。最著名的是 **Bland 规则（Bland's rule, 1977）**

在所有可作进基的候选（既约成本指向改进的非基变量）中，选**下标最小**的进基；在所有可出基的候选（比值检验并列取到最小比值的基变量）中，也选**下标最小**的出基

能够证明，采用 Bland 规则的单纯形永不循环，从而在有限步内终止（Bertsimas–Tsitsiklis §3.4 给出证明）。

初学者理解这条规则，只需记住"打破并列时永远用固定的、确定性的偏好（最小下标）来选，就杜绝了在同一组基之间反复横跳"。另一族反循环方案是**字典序规则（lexicographic rule）/ 扰动法**，思想是给 b 加无穷小扰动使退化消失，同样保证不循环。两者都只保证终止，不改善速度。这里要防一个常见误解：反循环规则解决的是"会不会终止"，不是"要走多少步"——即便有 Bland 规则，单纯形的步数在最坏情形仍可能是指数级（下一项）。

### 3.2.5 单纯形的复杂度：实践高效、最坏指数

单纯形法在**实践中极其高效**（对大多数实际 LP，转轴步数大致与约束数 m 线性相关），但它**不是多项式时间算法**：最坏情形下步数可指数增长。经典反例是 **Klee–Minty 立方体（Klee–Minty, 1972）**——一个 n 维的"扭曲超立方体"，用标准的最陡上升（Dantzig）转轴规则时，单纯形会访问全部 2ⁿ 个顶点才到最优。

n 维 Klee–Minty 例中单纯形访问顶点数达

2ⁿ

这说明"沿棱爬山"这个几何策略在恶意构造的多面体上会绕遍所有角。

这一项要澄清一个初学者常见的困惑："既然最坏指数，为什么单纯形还是最常用的 LP 求解器？"答案是最坏情形几乎不出现在真实问题上，且平滑分析（Spielman–Teng, 2004）从理论上解释了单纯形在"轻微扰动"的输入上期望多项式表现。另一个重要事实：**是否存在最坏也多项式的转轴规则，至今仍是开放问题**（与 Hirsch 猜想、多面体直径相关）——所以 3.4、3.5 的椭球法与内点法才有意义，它们是不同思路下**已证明**的多项式算法。别把"单纯形实践快"误当成"单纯形多项式"，二者是两回事。

## 3.3 LP 对偶

### 3.3.1 对偶：每个 LP 都配一个"影子 LP"

**对偶（duality）**是 LP 理论的心脏——每个线性规划（称为**原问题 primal**）都对应地配一个线性规划（**对偶问题 dual**），二者的数据来自同一组 (A, b, c)，只是角色对调。对不等式标准型的原问题

(P)　maximize cᵀx　s.t. Ax ≤ b,　x ≥ 0

其对偶是

(D)　minimize bᵀy　s.t. Aᵀy ≥ c,　y ≥ 0

原问题的每条约束对应一个对偶变量 yᵢ，原问题的每个变量对应一条对偶约束；max 变 min，A 转置，b 与 c 互换角色。一个基本事实是**对偶的对偶等于原问题**——(D) 再取一次对偶就回到 (P)，所以"谁是原谁是对偶"只是叫法。

初学者建立直觉的最好角度是"对偶变量 = 影子价格（shadow price）"：yᵢ 度量"第 i 条资源约束 bᵢ 若放松一个单位，最优目标能增长多少"。对偶问题 min bᵀy 的含义是"用最省的方式给每条约束定价，使得这套价格能证明原问题不可能做得更好"。为什么原问题的变量数会等于对偶的约束数、约束数等于对偶的变量数？因为对偶正是把原问题的"约束"和"变量"两个角色整体互换。一个死记硬背前先理解的口诀：**原 max/≤ 约束 ↔ 对偶 min/≥ 约束，变量非负性与约束方向一一配对**（不同教材约定的方向表见 Bertsimas–Tsitsiklis §4.2 的完整对照表）。

### 3.3.2 弱对偶：对偶永远是原问题的"天花板"

**弱对偶定理（Weak Duality）**说：对任意**同时可行**的原问题解 x 与对偶解 y，恒有

cᵀx ≤ bᵀy

即任何一个对偶可行解的目标值，都是原问题（最大化）最优值的一个上界；反过来任何原问题可行解也是对偶（最小化）最优值的下界。

这条定理证明只需三行（Aᵀy ≥ c 且 x ≥ 0 给出 cᵀx ≤ (Aᵀy)ᵀx = yᵀAx；Ax ≤ b 且 y ≥ 0 给出 yᵀAx ≤ yᵀb = bᵀy，串起来即得）。初学者要抓住它的两个巨大用处：其一，**它给了"证明最优"的手段**——只要你手上一个原问题解与一个对偶解目标值相等，就立刻断定两者都最优（不必再搜索），因为一个是所有下界、一个是所有上界，夹住了。其二，**它给了"证明无界/不可行"的联系**——若原问题无界（目标可 →∞），则对偶必不可行（上界不存在）。弱对偶对任意 LP 无条件成立，是强对偶（下一项）成立的一半。

### 3.3.3 强对偶：最优值精确相等

**强对偶定理（Strong Duality）**是 LP 最深刻的结论

若原问题 (P) 有有限最优解，则对偶 (D) 也有有限最优解，且两者最优值精确相等

max cᵀx = min bᵀy

弱对偶只说"≤"，强对偶把这个间隙压到 0——**LP 没有对偶间隙（duality gap）**。这与一般非凸优化形成鲜明对比（后者常有正的对偶间隙）。

这条定理是许多组合最小最大定理（min-max theorem）的统一来源：最大流最小割定理、König 二部图定理、矩阵博弈的 von Neumann minimax 定理，本质都是某个 LP 的强对偶。初学者理解其分量，最好配全套"情形组合"记牢（这是易错点）：原问题与对偶的状态只有三种（有有限最优 / 无界 / 不可行），且互相约束——若一方无界，另一方必不可行；两方可以同时不可行；但**不可能一方有有限最优而另一方不可行**。证明强对偶通常有两条路：从单纯形终止时的既约成本直接读出对偶最优解（构造性），或用凸集分离超平面定理（Farkas 引理）。下面 3.3.5 的实证会亲眼验证 max = min。

### 3.3.4 互补松弛

**互补松弛（Complementary Slackness）**刻画了原问题最优解 x* 与对偶最优解 y* 之间的精确配对关系（CLRS 4e §29、Bertsimas–Tsitsiklis §4.3）。对上面的标准型对偶对，最优性当且仅当同时满足

对每个变量 j：xⱼ* > 0 ⟹ 第 j 条对偶约束取等号 (Aᵀy*)ⱼ = cⱼ

对每条约束 i：yᵢ* > 0 ⟹ 第 i 条原约束取等号 (Ax*)ᵢ = bᵢ

换个等价说法，一个变量为正，则它对应的那条对偶约束必"紧"（无松弛）；一条约束有正的对偶价格，则那条约束必被"用满"（等号成立）。反过来说，**有松弛的约束其对偶价格必为 0**——"没用满的资源不值钱"。

互补松弛把强对偶从"两个数相等"细化成"两组解在每个分量上如何咬合"，因而极其有用。初学者的直觉锚点还是影子价格：如果某条资源约束没被用满（还有剩），再多给一点也没用，所以它的影子价格 yᵢ* = 0；反之只有被用满（成为瓶颈）的资源才可能有正价格。它的算法价值在于"从原问题最优解反解对偶最优解"（或反向）——知道 x* 后，互补松弛把大部分对偶约束定成等式，剩下的用线性方程组解出 y*。一个易错点：互补松弛是"xⱼ>0 ⟹ 对偶约束紧"，不是双向的强等价里两边都能取 0（可能出现 xⱼ=0 且对偶约束也恰好紧的退化情形），所以它是一组蕴含条件，不是简单的"非此即彼"。

### 3.3.5 强对偶与互补松弛的实证核对

用 3.2.2 的 CLRS 算例（原问题 max 3x₁+x₂+2x₃）与其对偶（min 30y₁+24y₂+36y₃ s.t. Aᵀy ≥ c, y ≥ 0）双跑 scipy `linprog`，本机 @2026-07-30 真实输出为

primal opt value = 28.0　x = [8. 4. 0.]

dual　 opt value = 28.000000000000004　y = [0. 0.166667 0.666667]

原问题与对偶最优值都等于 28（浮点误差 ~1e-14），**强对偶成立**。

进一步核对互补松弛，全部吻合：原问题解 x=(8,4,0)代入三条约束得 (12, 24, 36)，第 1 条 12 < 30 有松弛 ⟹ 对偶 y₁=0（✓，输出正是 0）；第 2、3 条取满（24=24, 36=36）⟹ 允许 y₂,y₃>0（✓，为 1/6 与 2/3）。变量侧：x₃=0 对应第 3 条对偶约束 3y₁+5y₂+2y₃ = 0+5/6+4/3 ≈ 2.17 > 2 有松弛（✓，故 x₃ 被压到 0）；x₁,x₂>0 对应其对偶约束取等号。这是一次把 3.3.1–3.3.4 全部结论一次性坐实的最小实证。初学者可据此复现流程：先解原问题、再按 3.3.1 机械写出对偶、独立求解、比对最优值、逐条检查互补松弛——这套流程本身就是"验证一个 LP 解是否真最优"的标准手段。

## 3.4 椭球法

### 3.4.1 椭球法：LP 的第一个多项式时间算法

**椭球法（Ellipsoid method）**由 Khachiyan（1979）用于证明**线性规划可在多项式时间内求解**——这是 LP 理论史上的里程碑，第一次给出 LP 的多项式算法（单纯形最坏是指数的，见 3.2.5）。算法本身的几何思想更早来自 Shor 与 Yudin–Nemirovski 的凸优化工作，Khachiyan 的贡献是证明它对 LP 的运行时间是输入比特长度的多项式。

它解决的是"可行性问题"：给定多面体 P = {x : Ax ≤ b}，判断它是否非空并找一点（优化问题可通过对目标值二分或加对偶约束归约到可行性）。算法维护一个**包含候选解的椭球**，每步用一个"违反的约束"把椭球砍掉一半，再用一个更小的椭球包住剩下部分，如此收缩。

初学者先建立的大图景是"椭球法是一种在连续空间里做的二分/剪枝搜索"：不像单纯形在顶点上跳，它在整个空间里不断缩小"最优解可能藏身的范围"。它的历史意义远大于实用意义——它第一次回答了"LP 是 P 类问题吗"这个理论问题（是），但实际跑起来比单纯形和内点法都慢得多，工程上基本不用。理解它是理解"多项式可解性"这一理论标尺的入口。

### 3.4.2 收缩机制、分离预言机与"指数多约束也能解"

椭球法一轮迭代的骨架是

维护一个椭球 E 保证包含可行域（若非空）

取 E 的中心 c，若 c 可行则完成；否则找一条被 c 违反的约束 aᵀx ≤ b（a 是分离超平面）

用半空间 aᵀx ≤ aᵀc 把 E 切成一半，构造包住这半个椭球的最小新椭球 E′，令 E ← E′，重复

关键定量事实是**每步椭球体积按固定比例收缩**，n 维时

vol(E′) / vol(E) ≤ e^(−1/(2(n+1)))

由于体积单调指数下降，而"若可行域非空则它有一个不太小的体积下界"（由数据比特长度 L 给出），迭代次数被 n 与 L 的多项式界住。

对算法理论最深远的一点是**分离预言机（separation oracle）**：椭球法每步只需要"给定一点，要么确认它可行、要么返回一条被违反的约束"这个能力，**并不需要显式列出全部约束**。这带来一个惊人推论——即便一个 LP 有**指数多条约束**，只要存在一个多项式时间的分离预言机，椭球法就能多项式时间求解它。这正是组合优化里许多"约束数指数级"的 LP 松弛（如生成树多面体、匹配多面体）能被证明多项式可解的根据，也是理论组合优化偏爱椭球法的原因。初学者要记住这条"椭球法的真正威力在预言机而非约束枚举"，它是本节最该带走的洞见。一个易错点：分离预言机存在与否本身可能很难，椭球法把"求解 LP"归约到了"设计一个高效分离预言机"。

## 3.5 内点法与锥规划/SDP

### 3.5.1 内点法：穿过多面体内部走向最优

**内点法（Interior-Point Method, IPM）**由 Karmarkar（1984）引入，是继椭球法之后 LP 的第二类多项式算法，且**实践上真正高效**——对大规模 LP 常能与单纯形竞争甚至胜出。与单纯形"沿边界顶点跳"、椭球"外部收缩"都不同，内点法**从可行域内部出发，沿一条平滑轨迹穿过内部，逐步逼近最优顶点**。

它的核心技巧是**障碍函数（barrier function）**：把"x ≥ 0"这类不等式约束换成一个在边界处趋于 +∞ 的罚项，最常用对数障碍

minimize　cᵀx − μ · Σⱼ log(xⱼ)

参数 μ > 0 控制"离边界多远"。对每个固定 μ 解出的最优点记作 x(μ)，当 μ 从大到小趋于 0，这些点连成一条**中心路径（central path）**，其极限就是 LP 最优解。算法就是不断减小 μ、用 Newton 法追踪中心路径。

初学者的直觉锚点是"障碍像一堵软墙，把迭代点推离边界、留在内部安全区，等快到最优时再慢慢松开墙、让点滑向最优角"。μ 大时点在正中间（远离所有约束），μ 小时点被目标拉向最优顶点。为什么要绕这么大圈从内部走，而不直接像单纯形沿边界？因为在内部走可以避开"顶点太多、绕遍所有角"的组合爆炸（Klee–Minty 那种），把步数变成与精度对数、与维度平方根相关的多项式。这里要澄清一个初学者易混点：单纯形的复杂度按"转轴步数（组合量）"衡量，内点法按"Newton 迭代数 × 每步线性代数代价（连续量）"衡量，两者是不同的计量框架。

### 3.5.2 中心路径、Newton 步与迭代复杂度

内点法主流实现是**原始–对偶内点法（primal-dual interior-point）**：同时维护原问题变量 x、对偶变量 y 与松弛 s，追踪由如下条件（松弛化的 KKT 条件）定义的中心路径

Ax = b,　Aᵀy + s = c,　x, s ≥ 0,　xⱼ sⱼ = μ（对所有 j）

注意最后一条 xⱼsⱼ = μ 是"松弛化的互补松弛"（3.3.4）——μ→0 时退回精确互补松弛 xⱼsⱼ=0，正是最优性条件。每步用 Newton 法解这组非线性方程的线性化系统，得到搜索方向，再取合适步长并按固定比例缩小 μ。

理论上，用短步障碍法追踪中心路径，把对偶间隙从初值降到 ε 所需的 Newton 迭代数是

O(√n · log(1/ε))

即迭代数只与变量数的平方根、精度的对数相关（Boyd–Vandenberghe Ch11、Nesterov–Nemirovski 自和谐障碍理论）。

初学者要抓住两个数量级对比：椭球法虽多项式但慢（收缩极慢），内点法的 O(√n log(1/ε)) 迭代加上每步一个线性方程组求解，使它在实践中对稀疏大规模问题表现极佳。一个常被误解的点是"内点法给出的是内部近似解，需要额外一步'取整/纯化（purification/crossover）'才能落到一个精确顶点解"——若下游需要基本可行解（如做灵敏度分析），求解器会在内点收敛后再切到单纯形做 crossover。中心路径 xⱼsⱼ=μ 这条式子是理解内点法的钥匙：它把"何时最优"（互补松弛）参数化成了一条可追踪的连续路径。

### 3.5.3 从 LP 到锥规划：统一的推广框架

**锥规划（conic programming）**是 LP 的自然推广：把 LP 里的"x ≥ 0"（要求 x 落在非负象限这个锥里）换成"x 落在某个更一般的凸锥 K 里"

minimize　cᵀx　s.t.　Ax = b,　x ∈ K

取不同的锥 K 得到不同的问题族：K = 非负象限 ℝⁿ₊ 就是**线性规划（LP）**；K = 二阶锥（Lorentz cone，{(t,u) : ‖u‖₂ ≤ t}）就是**二阶锥规划（SOCP）**；K = 半正定矩阵锥（对称半正定矩阵集合）就是**半定规划（SDP）**。三者构成一个由弱到强的层级 LP ⊆ SOCP ⊆ SDP（每个都是下一个的特例）。

这套推广的意义在于**内点法的框架几乎原样适用于所有锥规划**——只要该锥配一个"自和谐障碍函数"（self-concordant barrier，Nesterov–Nemirovski 1994 的理论），就能用同样的中心路径思想多项式求解。初学者理解这一层，能把"LP、SOCP、SDP"从三个孤立话题串成一条线：它们是同一个内点法机器在不同凸锥上的实例化。为什么值得推广？因为许多用 LP 表达不了的凸约束（如"某矩阵半正定""某范数有界"）能用 SOCP/SDP 表达，从而把更广的一类凸优化纳入可多项式求解的范围。

### 3.5.4 半定规划（SDP）概览

**半定规划（Semidefinite Programming, SDP）**的决策变量是一个**对称半正定矩阵** X ⪰ 0，目标与约束都是矩阵的线性函数（用矩阵内积 ⟨A, X⟩ = trace(AᵀX)）

minimize　⟨C, X⟩　s.t.　⟨Aᵢ, X⟩ = bᵢ (i=1..m),　X ⪰ 0

其中 X ⪰ 0 表示 X 对称且所有特征值 ≥ 0。SDP 可用内点法在多项式时间内求到任意精度（注意：是"任意 ε 精度"，因最优解可能无理，不像 LP 有有理最优顶点）。

SDP 在算法理论中最著名的应用是 **Goemans–Williamson 的 Max-Cut 近似（1995）**：把 Max-Cut 松弛成一个 SDP，解出后用随机超平面舍入，得到期望

0.878

倍最优的割（此结论详见本课大主题04 近似算法，此处只点名衔接）。初学者理解 SDP 的门槛在"变量从向量升级成矩阵、非负性升级成半正定性"这一步：X ⪰ 0 是"矩阵版的 x ≥ 0"，半正定锥是"非负象限的矩阵推广"。一个直觉是 SDP 能捕捉"向量之间的两两内积/夹角"这类二次几何关系（因为任何半正定 X 都能写成一组向量的 Gram 矩阵 X = VᵀV），这正是它能松弛 Max-Cut 这种"把顶点分到 ±1 两侧"的组合问题的原因。要留意的边界：SDP 虽多项式可解，但求解器规模上仍远比 LP 吃力，大规模 SDP 的高效求解是工程上仍活跃演进的方向。
