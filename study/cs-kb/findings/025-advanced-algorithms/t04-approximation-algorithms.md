## 4.1 近似比框架与组合近似

### 4.1.1 ρ-近似的统一定义

一个多项式时间算法称为某优化问题的 **ρ-近似算法**（ρ-approximation algorithm），当它对**任意**输入都返回一个可行解，其目标值 C 与最优值 C\* 满足下面这把「同时管最小化和最大化」的尺子

max( C / C\* , C\* / C ) ≤ ρ

其中最小化问题里 C ≥ C\* 起作用的是 C/C\*，最大化问题里 C ≤ C\* 起作用的是 C\*/C；两种情形算出的 ρ 都 ≥ 1，越靠近 1 越好，ρ = 1 即精确。近似算法与「无保证的启发式」的根本区别就在这个**最坏情形保证**上。

Williamson–Shmoys 与 CLRS 在符号上略有差异但含义一致：W–S 常把最大化问题的比写成「解 ≥ α·C\*」（α ≤ 1，称 α-近似），CLRS 与 6.854 则统一取 ρ ≥ 1。两套记法只是倒数关系（α = 1/ρ），读文献时先认清作者用的是哪一套，否则会把「0.878-近似」误当成「近似比小于 1」。本报告除 Max-Cut 一节沿用文献习惯写 0.878 外，其余用 ρ ≥ 1 口径。

初学者要抓住的是：证一个算法是 ρ-近似，关键从来不是「算出真正的 C\*」（那通常是 NP 难的），而是给 C\* 找一个**多项式可算的界**（下界用于最小化、上界用于最大化），再证「我的解 C 不超过这个界的 ρ 倍」。下面每一种手法，本质都是在造这样一个可算的界——组合论证造它、LP 松弛造它、对偶造它、SDP 造它。

### 4.1.2 顶点覆盖的组合 2-近似

给无向图 G，**顶点覆盖**（vertex cover）是一个顶点子集，使每条边至少有一个端点被选中；目标是最小化选中顶点数（带权版最小化总权）。无权情形有一个一行算法：**求任意一个极大匹配 M，把 M 中每条边的两个端点全选进覆盖**，得到 |2M| 个顶点，这是一个 2-近似。

|C| = 2·|M| ≤ 2·C\*

论证的两步都很短。其一，M 中的边两两不共享端点，要覆盖这 |M| 条边，任何覆盖（包括最优）都至少要 |M| 个顶点，故 C\* ≥ |M|——这就是给 C\* 造的**下界**。其二，M 是极大匹配意味着「任何边都至少碰到 M 的某个已选端点」，所以选中 M 的全部 2|M| 个端点确实是一个合法覆盖。两步合起来即 |C| = 2|M| ≤ 2C\*。

这个例子是「组合近似」的范本：不解 LP、不用对偶，纯靠一个组合对象（匹配）同时**当解的构造**又**当最优的下界**。一个常见易错点是以为「取极大匹配」要取**最大**匹配——不需要，任意极大（maximal，即不能再加边）匹配就够，贪心扫一遍即可，正是它的廉价之处。顶点覆盖至今没有已知的优于 2 的常数近似（见 4.5.3 的 hardness）。

### 4.1.3 集合覆盖的贪心 H(n) ≈ ln n 近似

**集合覆盖**（set cover）：给全集 U（|U| = n）和若干子集 S₁,…,S_m（可带成本），选最少成本的一批子集使其并集覆盖 U。**贪心**策略是每一步选「单位新覆盖成本最低」的集合——无权情形即每次选**覆盖当前最多未覆盖元素**的集合，直到覆盖完。它是一个 H(n)-近似，其中 H(n) 是第 n 个调和数

H(n) = 1 + 1/2 + 1/3 + … + 1/n，且 ln n ≤ H(n) ≤ ln n + 1

因此贪心近似比约为 ln n（更精确地，是 H(g)，g 为最大集合的元素数，而 H(g) ≤ H(n)）。

直觉可以用摊还记账来把握——把每个被覆盖元素分摊它被覆盖那一刻的「单位成本」，可证第 k 个（按被覆盖顺序）元素分摊到的成本 ≤ C\*/(n−k+1)，全部求和恰好凑成 C\*·H(n)。W–S 与 CLRS 给出的都是这一 H(n) 界，口径一致。

要点是集合覆盖的近似比**不是常数而是随 n 增长的 ln n**，这与顶点覆盖（它其实是集合覆盖的特例：每条边是一个「元素」、每个顶点是一个「集合」）的常数 2 形成对照——因为顶点覆盖里每个元素只属于 2 个集合（频率 f = 2），而一般集合覆盖频率可以很大。4.5.3 会说明这个 ln n 在 P ≠ NP 下**几乎不可改进**，所以它不是算法笨，而是问题本身的难度天花板。

### 4.1.4 度量 TSP 与 Christofides 3/2-近似

**度量旅行商问题**（metric TSP）：城市间距离满足三角不等式，求一条访问所有城市恰一次的最短闭合巡回。一个朴素的 2-近似是「求最小生成树 MST、绕树走一圈（每边走两遍）再抄近路（shortcut）跳过重复点」，因为最优巡回删一条边就是一棵生成树，故 MST ≤ C\*，绕两遍 ≤ 2·MST ≤ 2C\*。**Christofides 算法**把它改进到 3/2

C ≤ (3/2)·C\*

做法是：先求 MST T，找出 T 中度数为奇的顶点集合 W（|W| 必为偶数），在 W 上求一个**最小权完美匹配** M，把 M 加进 T——此时每个顶点度数都变偶，图存在**欧拉回路**，沿欧拉回路抄近路即得巡回。

关键的一步在于说明加进来的匹配 M 权重不超过 C\*/2。把最优巡回限制到 W 上（抄近路后仍是 W 上一个环，权 ≤ C\*），这个偶数长的环可拆成两个完美匹配，较小者权 ≤ C\*/2，故最小匹配 M ≤ C\*/2。于是 C ≤ MST + M ≤ C\* + C\*/2 = (3/2)C\*。这是「组合近似」里最精巧的经典结果之一。

初学者需注意三角不等式是**前提**：一般（非度量）TSP 除非 P = NP 否则无任何常数近似（否则能用它判哈密顿回路）。另外「3/2 保持了 40 余年最优纪录」这一点已在近年被打破：Karlin–Klein–Oveis Gharan (2021) 给出一个**随机化 (3/2 − ε)-近似**（ε ≈ 10⁻³⁶，仅存在性意义上的突破，实用价值有限）⚙演进快·锚 2021·随时变；教辅层面记住经典界是 3/2 即可。

## 4.2 LP 舍入

### 4.2.1 LP 松弛与整数间隙

许多组合优化问题能写成 **0-1 整数规划**（变量 x_i ∈ {0,1} 表示「选不选」）。**LP 松弛**（LP relaxation）把约束放宽成 x_i ∈ [0,1]，得到一个多项式可解的线性规划，其最优值 LP\* 是原问题最优值 C\* 的一个**界**（最小化问题里 LP\* ≤ C\*，因为可行域被放大了）。这个 LP\* 就是 4.1.1 说的「给 C\* 找的可算下界」，是所有 LP 类近似的出发点。

拿到 LP 的分数最优解后，要把它「圆」回一个整数可行解——这一步叫 **舍入**（rounding）。整个手法的近似比，取决于「舍入后代价」相对「LP\*」放大了多少倍。

衡量一个 LP 松弛能好到什么程度，用**整数间隙**（integrality gap）：最坏实例上「整数最优 / LP 最优」的比值。

integrality gap = sup over instances ( IP\* / LP\* )

它是**任何**以该 LP 为下界的舍入算法近似比的**下限**——若间隙是 2，你就别指望靠这个 LP 证出比 2 更好的比。这解释了为什么改进近似比常要换更强的松弛（如后面 4.4 的 SDP）。初学者易混淆「整数间隙」（松弛本身的缺陷，与算法无关）和「近似比」（算法表现）：前者是天花板，后者是你实际够到的高度。

### 4.2.2 确定性舍入

**确定性舍入**（deterministic rounding）按一个固定阈值规则把分数解变整数。顶点覆盖是最干净的例子：LP 松弛给每个顶点变量 x_v ∈ [0,1]、每条边 (u,v) 约束 x_u + x_v ≥ 1，解完后**把所有 x_v ≥ 1/2 的顶点选入覆盖**。

C ≤ 2·LP\* ≤ 2·C\*

先看可行性，每条边 x_u + x_v ≥ 1 意味着 x_u, x_v 至少一个 ≥ 1/2，故该边被覆盖。再看比值，每个被选顶点满足 x_v ≥ 1/2，即 1 ≤ 2x_v，求和得 |C| ≤ 2·Σx_v = 2·LP\*。于是又得到一个 2-近似——与 4.1.2 的匹配法殊途同归，但这条路是**通用**的。

推广到一般**集合覆盖**：设 f 为「频率」= 任一元素所属集合数的最大值，把所有 x_S ≥ 1/f 的集合选入，得到 **f-近似**（顶点覆盖是 f = 2 的特例）。要点是确定性舍入靠的是「约束里变量个数有限（≤ f）⇒ 至少一个不小于 1/f」这个鸽巢式论证；当 f 很大（如一般集合覆盖 f 可达 m）时它就退化，这时才需要下面的随机舍入。

### 4.2.3 随机舍入

**随机舍入**（randomized rounding）把分数解 x_S ∈ [0,1] 当**概率**：独立地以概率 x_S 选入集合 S。单轮期望成本恰为 LP\*，但可能盖不全；重复 O(log n) 轮取并集，可让「某元素始终没被盖」的概率降到 O(1/n) 以下，从而高概率得到合法覆盖，代价为

E[C] = O(log n)·LP\* = O(log n)·C\*

即集合覆盖的 **O(log n)-近似**，与 4.1.3 贪心的 ln n 同量级，但走的是 LP 路线。

这里的直觉可以这样理解，某元素 e 属于若干集合，其 LP 约束 Σ_{S∋e} x_S ≥ 1 保证「一轮里 e 没被任何集合盖到」的概率 ≤ ∏(1−x_S) ≤ e^{−Σx_S} ≤ e^{−1} < 1/2（用到 1−t ≤ e^{−t}）；独立跑 c·ln n 轮后失败概率 ≤ n^{−c}，配合并集界（union bound）覆盖全部 n 个元素。

同一手法也给 **MAX-SAT / MAX-3SAT** 漂亮的近似：把变量真值当概率随机赋值，MAX-3SAT 的纯随机赋值就满足每个子句概率 7/8，得 7/8-近似；结合 LP 随机舍入可对一般 MAX-SAT 做到 3/4。要点是随机舍入把「构造性证明」变成「期望论证」——先证期望达标，再用概率放大或去随机化（如条件期望法）落成确定算法。易错点：随机舍入后必须显式处理「可行性」（可能违约束），集合覆盖靠多轮取并、MAX-SAT 则天然无硬约束。

## 4.3 原始–对偶方法

### 4.3.1 对偶引导近似的核心思想

**原始–对偶方法**（primal-dual method）不去解 LP，而是**同时**逐步构造一个整数原始解和一个 LP 对偶可行解，用对偶目标值当 C\* 的下界。回顾 L6-01 大主题03：LP 对偶的**弱对偶**保证任何对偶可行解的目标值 ≤ 原始最优 LP\* ≤ C\*（最小化情形）。所以只要能证「我造的整数解代价 ≤ ρ·（对偶目标值）」，就有

C ≤ ρ·(对偶目标) ≤ ρ·LP\* ≤ ρ·C\*

从而不必真解 LP，只靠一个**手工构造的对偶可行解**就锁定近似比。

它相对「解 LP 再舍入」的好处是**快且组合化**：全程只做加减和比较，得到强多项式、常数因子的组合算法，工程上常比调 LP 求解器实用。初学者可以把对偶变量理解成「每个约束愿意为被满足付的钱」，算法一边涨这些钱、一边在「钱涨到刚好付得起某个原始变量」时把它选进解——**互补松弛**（complementary slackness）就是「只选那些对偶已付满的变量」这条纪律，它正是把近似比压到 ρ 的关键。

### 4.3.2 顶点覆盖的原始–对偶 2-近似

顶点覆盖的对偶是：给每条边一个变量 y_e ≥ 0，约束「每个顶点上的边权和 ≤ 1」（Σ_{e∋v} y_e ≤ 1），最大化 Σ y_e。原始–对偶算法：初始全 y_e = 0，反复挑一条未覆盖的边，涨它的 y_e 直到某端点的约束**变紧**（Σ = 1），就把该端点选入覆盖；重复到所有边被覆盖。

|C| ≤ 2·Σ y_e ≤ 2·C\*

论证只需两句话。被选顶点都是「约束变紧」的，即 Σ_{e∋v} y_e = 1；对覆盖里所有顶点求和，每条边 y_e 最多被它两个端点各数一次，故 Σ_{v∈C} 1 = Σ_{v∈C} Σ_{e∋v} y_e ≤ 2·Σ_e y_e。而 y 是对偶可行解，Σ y_e ≤ C\*（弱对偶），合得 2-近似。

这与 4.1.2（匹配）、4.2.2（LP 舍入）给出同一个 2，但视角互补：匹配是纯组合、LP 舍入要解 LP、原始–对偶只涨对偶变量不解 LP。三者对照恰好说明「同一近似比可由不同框架导出」，也是本大主题反复出现的教学呼应。

### 4.3.3 集合覆盖的原始–对偶 f-近似

同一范式套到集合覆盖：对偶给每个**元素** e 一个 y_e ≥ 0，约束「每个集合 S 覆盖的元素对偶和 ≤ 该集合成本」（Σ_{e∈S} y_e ≤ c_S），最大化 Σ y_e。算法反复挑未覆盖元素、涨其 y_e 直到某集合约束变紧、选入该集合，得到

|C 的成本| ≤ f·Σ y_e ≤ f·C\*

其中 f 是最大频率（元素所属集合数上界），与 4.2.2 确定性舍入得到的 f-近似**同界**。

要点是这套「涨对偶 → 约束变紧 → 选原始变量」的模板几乎是机械的，能套到最短路、Steiner 树、设施选址等一大类问题（W–S 全书第 II 部分即以它为主线），是近似算法里复用性最高的设计范式。易错点在于「f-近似」的 f 是**频率**（元素维度）而非集合数 m——一般集合覆盖 f 可以很大，此时 f-近似不如贪心的 ln n，两条路各有适用区间（f 小用原始对偶/舍入，f 大用贪心）。

- 无来源冲突；f-近似与 4.2.2 确定性舍入同界，两法在 W–S 中互为印证。

## 4.4 半定规划与 Max-Cut

### 4.4.1 SDP 松弛与向量规划

**Max-Cut**：把图顶点分成两组，最大化「跨两组的边数」（带权则跨组边权和）。它是 NP 难的。**半定规划**（semidefinite programming, SDP）松弛给每个顶点 i 一个**单位向量** vᵢ ∈ ℝⁿ（而非 ±1 标量），把「i、j 是否分开」松弛成向量夹角，目标写成

maximize  Σ_{(i,j)∈E} wᵢⱼ · (1 − vᵢ·vⱼ)/2，  s.t. ‖vᵢ‖ = 1

这是一个可在多项式时间内（到任意精度）求解的凸规划——它比 LP 更强，因为约束了变量间的**内积结构**（等价于一个半正定矩阵 X ⪰ 0，Xᵢⱼ = vᵢ·vⱼ）。

这样松弛的直觉在于，若真能把每个 vᵢ 限制成 ±1 的一维向量，(1 − vᵢvⱼ)/2 就恰好是「i、j 异号（被割开）取 1、同号取 0」的指示器，SDP 目标就还原成真实割值；松弛成高维单位向量只是把这个离散选择「连续化」，因而 SDP\* ≥ C\*（最大化，松弛放大可行域）。初学者只需记住「SDP 松弛 = 把 ±1 变量换成单位向量、把乘积换成内积」这一层，SDP 求解器细节（内点法）属先修 L6-01 大主题03，不在此展开。

### 4.4.2 Goemans–Williamson 随机超平面舍入 0.878

解出 SDP 的向量 {vᵢ} 后，**Goemans–Williamson (GW)** 用**随机超平面舍入**把向量变回 ±1：取一个均匀随机的单位法向量 r，令「vᵢ 落在超平面哪一侧」决定 i 属于哪一组。一对顶点 (i,j) 被割开的概率恰为它们夹角 θᵢⱼ 除以 π

Pr[(i,j) 被割] = θᵢⱼ / π，  其中 cos θᵢⱼ = vᵢ·vⱼ

对每条边比较「被割概率 θ/π」与「SDP 对该边的贡献 (1−cosθ)/2」，取二者比值的最坏值得到近似比

α_GW = min over 0 ≤ θ ≤ π  of  (2/π)·θ/(1 − cos θ) ≈ 0.87856

故 GW 是一个 0.878-近似（期望割值 ≥ 0.878·SDP\* ≥ 0.878·C\*）。

要点是这里近似比不是「凑」出来的整数，而是一个**解析极小值** 0.87856…，最小值在 θ\* ≈ 2.331 弧度（约 133.6°）处取得——本机用 scipy 对 f(θ)=(2/π)·θ/(1−cosθ) 在 (0,π) 上求极小，得 θ\*=2.3311、α=0.8785672，与文献一致（可选实测，非承重）。初学者的直觉：随机超平面「越是把夹角大（该分开）的点对切开」，而 SDP 已经把「该分开」的点对推到大夹角，两者对齐得很好，只在中等夹角处留下那 12% 的最坏损失。GW 是 SDP 用于近似的开山之作，也是「向量松弛 + 随机舍入」范式的样板。

### 4.4.3 GW 常数的最优性与 UGC

0.878 不只是「目前最好」，在一个被广泛相信的假设下它是**最优不可超越**的。在**唯一博弈猜想**（Unique Games Conjecture, UGC，Khot 2002）成立的前提下，Khot–Kindler–Mossel–O'Donnell 证明：任何多项式算法都无法把 Max-Cut 近似到比 α_GW 更好，除非 P = NP。

也就是说 GW 的 0.878 恰好卡在（条件）不可近似性的边界上——这类「算法上界与 hardness 下界严丝合缝」的结果，是近似算法理论最漂亮的形态之一。初学者要注意这是**有条件**结论：UGC 迄今（核实 2026-07-30）仍未被证明也未被证伪，是复杂性理论的核心开放问题，故 GW 的最优性带「UGC 前提」这个星号。⚙相关：UGC 本身的地位是活跃前沿（如 2018 年 2-to-2 Games 定理给了部分支持证据），但 UGC 未决。无条件（不假设 UGC）下，Max-Cut 已知的 hardness 只到 16/17。

- 锚点：Goemans–Williamson《Improved approximation algorithms for maximum cut and satisfiability problems using semidefinite programming》(JACM 42(6), 1995) —— 0.87856 随机超平面舍入的原始论文。
- 锚点：Williamson–Shmoys (2011) §6.2（Max-Cut SDP 0.878）、Ch.6（SDP 通论）；MIT 6.854J Fall 2008 Lec 19。

## 4.5 度量嵌入近似与不可近似性

### 4.5.1 度量嵌入与 Bourgain 定理

**度量嵌入**（metric embedding）把一个抽象度量空间（n 个点两两距离满足三角不等式）映射到一个「好算」的空间（如欧氏空间 ℓ₂），并尽量保持距离。保持得多好用**失真**（distortion）度量：嵌入 f 的失真是「所有点对里，距离被拉伸和被压缩的最大比值」。**Bourgain 定理 (1985)** 是奠基结果

任何 n 点度量都能嵌入 ℓ₂，失真 O(log n)，且这个界在最坏情形下最优（如常度扩张图）

其构造是**随机化**的：用随机选取的点子集到各点的距离作为坐标（Fréchet 型嵌入）。

为什么近似算法关心它：许多图割/距离类问题在「一般度量」上难解，但在 ℓ₁/ℓ₂ 这种结构好的空间上有现成算法；先把问题的度量以小失真嵌入过去、在那边求解、再拉回来，失真就直接进了近似比。初学者只需记住「失真 = 把几何问题搬家时距离最多被歪曲几倍」，O(log n) 失真意味着「搬家」会带来 O(log n) 的近似代价。

### 4.5.2 sparsest-cut 的 O(log n) 与 O(√log n)

**sparsest cut**（最稀疏割）：找一个把图切成两部分的割，使「割边数 / 两侧规模乘积（或需求）」最小；它刻画图的「瓶颈」，与图分割、并行计算负载均衡相关，是 NP 难的。经典结果 **Linial–London–Rabinovich (1995)** 用 Bourgain 嵌入把 LP 松弛的解嵌入 ℓ₁、得到

sparsest-cut 的 O(log n)-近似（经 LP 松弛 + ℓ₁ 嵌入）

**Arora–Rao–Vazirani (ARV, 2009)** 用 SDP 松弛加几何论证把它改进到

O(√log n)-近似

要点是这里近似比直接**继承自嵌入失真**：LLR 的 O(log n) 就是 Bourgain 的失真，ARV 的 O(√log n) 来自更精细的 SDP「三角不等式约束 + 集中测度」论证。这两条恰好把 4.1（组合）、4.2（LP）、4.4（SDP）三种松弛的力量在同一问题上排成阶梯：组合/LP 给 O(log n)、SDP 给 O(√log n)——是「更强松弛买更好近似」的活教材。⚙sparsest-cut 精确最优近似比仍是开放问题（核实 2026-07-30）。

### 4.5.3 PCP 定理与不可近似性

近似算法的另一半是**天花板**：哪些近似比是**不可能**多项式达到的。核心工具是 **PCP 定理**（Probabilistically Checkable Proofs，Arora–Safra；Arora–Lund–Motwani–Sudan–Szegedy，1998）

NP = PCP(O(log n), O(1))

它说每个 NP 证明都能改写成一种格式，验证者只用 O(log n) 随机比特、**读常数个比特**就能以高概率查对。它的威力在于把「精确判定 NP 难」升级成「连近似都 NP 难」，由此得到一批**紧致的不可近似性**结果：

- 集合覆盖：除非 P = NP，无法近似到优于 (1 − o(1))·ln n（Dinur–Steurer 2014，收紧了 Feige 1998 的经典 (1−ε)ln n）——所以 4.1.3 贪心的 ln n 已**触到天花板**。
- MAX-3SAT：除非 P = NP，无法近似到优于 7/8（Håstad 2001）——而 4.2.3 的随机赋值恰好给 7/8，**算法与 hardness 严丝合缝**。
- 顶点覆盖：无条件下无法近似到优于约 1.36（Dinur–Safra 2005；近年改进到 √2 ≈ 1.41 附近⚙）；在 UGC 下则无法优于 2（Khot–Regev），即 4.1.2 的 2 是（条件）最优。

初学者只需把 PCP 定理当成「一句话的黑箱」：它是「近似也难」这一整类结论的总开关，具体到每个问题的紧界（ln n、7/8、2）都由它加上问题特定的归约（gadget）得到。要点是这些 hardness 与前四节的算法上界**成对出现**——集合覆盖 ln n、MAX-3SAT 7/8、Max-Cut 0.878（UGC）、VC 2（UGC），近似算法这门学问的骨架，正是这一排「上界 = 下界」的对照。PCP 的完整证明属专家纵深，本报告只点到定理陈述与它撑起的 hardness 清单。
