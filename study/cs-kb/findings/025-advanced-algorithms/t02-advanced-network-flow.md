## 2.1 最大流与 push-relabel（预流推进法）

### 2.1.1 换范式的动机：为什么不再走增广路

先修里的 Ford–Fulkerson / Edmonds–Karp 属于"增广路（augmenting path）"范式：每一轮都从源 s 找一条到汇 t 的整条残量路径，沿它同时推流，始终维护一个合法的流（处处满足流量守恒）。push-relabel（预流推进法，preflow-push，Goldberg–Tarjan 1988）换了一条思路——它不再一次性维护 s 到 t 的整条路径，而是允许中间结点暂时"进多于出"，只做**局部**的单边推流，最后再把多余的流逼回去，从而得到更好的最坏时间界。

对初学者，最重要的心智模型是这句对比：增广路是"全局找路、整条推"，push-relabel 是"局部推流、就地决策"。为什么局部能更快？因为 Edmonds–Karp 每找一条增广路要一遍 BFS（O(E)），而它可能要找 O(VE) 条路，得到 O(VE²)；push-relabel 把工作拆成大量 O(1) 的单边操作，用一个巧妙的"高度"势能把总操作数压住，通用实现即可做到

O(V²E)

且精心选择处理顺序还能进一步降到 O(V³)，在稠密图上明显更优。它也是实践中最快的一族最大流算法之一（CLRS 4e、AMO 均如此评价）。

### 2.1.2 预流与超额（preflow, excess）

预流（preflow）是对流约束的一次松绑：它仍要求每条边的流量不超过容量（容量约束），但把"流入 = 流出"的守恒约束放宽成"流入 ≥ 流出"，即允许结点囤积流量。一个结点囤积的量叫它的超额（excess）：

e(u) = （流入 u 的总流量） − （流出 u 的总流量） ≥ 0（对除 s 外的结点）

超额为正的结点（除 s、t 外）称为活跃结点（active node）。算法的整个过程，就是不断挑一个活跃结点、把它的超额往"更靠近 t"的方向推出去，直到再没有活跃结点——此时预流处处守恒，退化成一个真正的流，而且正是最大流。

初学者可以把超额想成"水在结点上积起来的水位"：增广路法像一次接通一整根水管；预流法则先让水漫到中间水池里（允许积水），再一格一格往低处赶，最后赶不动的（既到不了 t 也回不了 s 的）水会被逼回源头。易错点：预流阶段的"流"不是合法流，不能中途拿它当答案；只有当所有中间超额清零、算法终止时，它才变成最大流。

### 2.1.3 高度函数（距离标号）与有效标号

push-relabel 给每个结点一个整数高度 h(u)（height，又叫距离标号 distance label），用来决定"流该往哪推"——只允许把流从高处推向恰好低一级的邻居。合法（有效）的高度函数要满足两条：边界条件

h(s) = |V|,  h(t) = 0

以及对每条**残量边** (u, v)（即 u→v 还有剩余容量）的"落差不陡"条件：

h(u) ≤ h(v) + 1

核心直觉是：h(u) 是"从 u 沿残量网络到 t 至少还要走几步"的一个下界估计。t 的高度定为 0（就在脚下），s 抬到 |V|（高到没有残量路径能从 s 直达 t，逼着多余的流最终回流）。因为任何残量边落差最多 1，一条 s→t 的残量路径长度至少是 h(s) = |V|，而简单路径最多 |V|−1 条边——矛盾，所以残量网络里**不存在** s 到 t 的增广路。这正是"终止即最大流"的关键（最大流最小割定理的另一面）。

初学者最容易混淆"高度"和"到 t 的真实距离"：它不是精确距离，只是一个**保守下界**，会随 relabel 单调上升、越来越准。记住"水只能往低一级流"这条规则，就抓住了 push 与 relabel 的全部动机。

### 2.1.4 push 操作（推流）

push（推流）是把活跃结点 u 的超额沿一条"可行边"送给邻居。边 (u, v) 可行（admissible）当且仅当它有残量且高度恰好差一级，即 h(u) = h(v) + 1。推送量取"还剩多少超额"和"这条边还剩多少残量"的较小者：

δ = min( e(u), 残量容量 c_f(u, v) )

推完后 e(u) 减 δ、e(v) 加 δ，边上残量减 δ、反向边残量加 δ。若这次把边推到残量为 0，称饱和推送（saturating push）；否则称非饱和推送（non-saturating push），此时 u 的超额一定被清空。

为什么要限制"恰好低一级"才能推？因为这保证流永远只往估计更接近 t 的方向走，配合高度单调上升，才能证明算法不会无限打转。初学者的最小例子：s 高度 4、a 高度 1、a 与 t 相邻且 h(t)=0，则先从 s 推到 a（前提是 s 有到 a 的可行边），a 有了超额后再从 a 推到 t。易错点：非饱和推送最多把 u 清空一次，而饱和推送可能对同一条边发生多次（残量恢复后又被推满），两者的总次数要分开数——这正是复杂度分析里"饱和 O(VE) 次、非饱和 O(V²E) 次"的来源。

### 2.1.5 relabel 操作（重贴标号）与活跃结点处理

当一个活跃结点 u 还有超额、却一条可行边都没有（所有有残量的邻居都不比它低一级，甚至更高）时，流推不出去，就对它做 relabel（重贴标号）：把 h(u) 抬到"刚好能对某个残量邻居可行"的最低高度：

h(u) ← 1 + min{ h(v) : (u, v) 是残量边 }

抬完之后 u 至少有一条可行边，又能继续 push。通用（generic）push-relabel 就是：只要还存在活跃结点，就对它做一次可行的 push，做不了就 relabel，反复直到无活跃结点。

直觉上 relabel 是"此路不通就把自己垫高，好让水能往某个方向淌"。为什么高度只升不降、且封顶？可以证明任何结点的高度不超过 2|V|−1（一旦超过 |V| 就说明它到不了 t，只能把流退回 s，而退回 s 的路径也最长 |V|−1）。于是每个结点最多被 relabel O(V) 次，总 relabel 数 O(V²)。这个"高度当势能、单调上升且有上界"的论证，正是摊还分析（势能法）在图算法里的典型用法——先修里学过的势能法在这里换了个战场。易错点：relabel 只在"有超额且无可行边"时做，不是随便抬；抬的幅度是"够用就好"（min + 1），抬过头会破坏有效标号的落差条件。

### 2.1.6 通用算法的正确性与终止

把 2.1.2–2.1.5 串起来：初始化时把 s 的所有出边一次推满（形成初始预流），s 抬到 |V|，其余高度 0；然后反复 push/relabel 直到没有活跃结点。终止时预流处处守恒（超额全清），成为合法流；又因为高度函数有效使得残量网络无 s→t 增广路，由最大流最小割定理，这个流是最大流。

正确性靠三条不变量支撑，初学者可当"检查表"记：一是始终维持有效标号（每次 push 不产生新的陡边、relabel 恰好修复陡边）；二是超额只在中间结点、且非负；三是高度单调不减。终止性靠三个计数：relabel 总数 O(V²)、饱和推送 O(VE)、非饱和推送 O(V²E)，三者都有限，故算法必停。为什么非饱和推送最多 O(V²E) 而不是更少？这是全书里最需要势能论证的一步，教辅层面记住"它是通用界 O(V²E) 的瓶颈项"即可，具体推导留一手讲义。

### 2.1.7 复杂度：通用 O(V²E)、FIFO O(V³)、最高标号 O(V²√E)

不同的"下一个处理哪个活跃结点"选择规则给出不同的界。通用（任意顺序）实现为

O(V²E)

按 FIFO 队列选活跃结点（先进先出、逐个 discharge）得到

O(V³)

按最高标号（highest-label，每次挑高度最大的活跃结点）得到

O(V²√E)

此外用"超额缩放"（excess scaling, Ahuja–Orlin）可做到 O(VE + V² log U)（U 为最大容量），配动态树（link-cut tree，见本课大主题01）可把 FIFO 版进一步降到 O(VE log(V²/E))。

初学者只需记住量级关系：三种规则的差别全在"非饱和推送"这一瓶颈项上——换个处理顺序就能把它从 O(V²E) 压到 O(V³) 乃至 O(V²√E)，而 relabel（O(V²)）与饱和推送（O(VE)）三种规则都一样。对稠密图（E ≈ V²）而言 O(V³) 已优于 Edmonds–Karp 的 O(VE²)=O(V⁵)。易错点与冲突标注：O(V²√E) 这一最高标号界由 Cheriyan–Maheshwari / Tunçel 给出、被 AMO 与多数讲义采用，但个别资料写成 O(V²√E) 之外的等价形式（如按 m、n 记号），量级一致；excess-scaling 与 dynamic-tree 的确切界在不同版次教材有细节差异，涉及具体因子处标「以所引版本为准」。

### 2.1.8 实用加速：gap 启发式与全局重标号

除了选择规则，实现里还有两个几乎必配的启发式。全局重标号（global relabeling）周期性地从 t 反向 BFS，把每个结点的高度重置为它到 t 的真实残量距离——因为高度本是这个距离的下界，定期"校准准"能大幅减少无谓的小步 relabel。gap 启发式（gap heuristic）观察：若某个高度值 k（0<k<|V|）当前没有任何结点占据（出现"空档"），则所有高度在 k 与 |V| 之间的结点都已到不了 t，可直接把它们抬到 ≥|V|，一次性淘汰。

这两招不改变最坏理论界，却常把实际运行时间降一个数量级，是 push-relabel 在工程实现（如计算机视觉的图割、`scipy` 等库背后）里跑得飞快的关键。初学者理解到"它们是加速常数、不改渐进界"即可；易错点是别把启发式当成正确性的一部分——去掉它们算法依然正确，只是慢。

## 2.2 最小费用流（最小费用循环流·消负圈）

### 2.2.1 最小费用流问题与建模

最小费用流（minimum-cost flow）把最大流的"只关心流量"升级为"在满足流量需求的前提下，让总费用最小"：每条边 (u, v) 除容量 c(u, v) 外，还带一个单位费用 a(u, v)，一份流 f 的总费用是

cost(f) = Σ_{(u,v)} a(u, v) · f(u, v)

常见提法有两种，等价可互相转化：一是"送 d 单位从 s 到 t，费用最小"（固定流量求最省）；二是给每个结点一个供给/需求 b(u)（正为供、负为需，总和为 0），求满足所有供需的最省流。它统一了指派问题、运输问题、最小费用最大流等一大批组合优化问题。

初学者可把它想成物流：容量是每条路的运力上限，费用是每单位货走这条路的运费，目标是把货按需求送到、总运费最低。最小例子：两条 s→t 的并联边，一条容量 1 费用 1、一条容量 1 费用 5，要送 1 单位就走费用 1 那条；要送 2 单位就两条都用，总费用 1+5=6。易错点：最小费用流是"给定流量下最省"，和最大流"流量最大"是两个目标；常见的"最小费用最大流"是先把流量顶到最大、再在最大流里挑最省的那份。

### 2.2.2 最小费用循环流：去掉源汇的等价视角

把最小费用流化归成一个更对称的对象——最小费用循环流（minimum-cost circulation）会让理论异常干净。循环流是**处处**满足守恒（没有源没有汇，所有流量都在"打圈"）、且每条边可带下界/上界容量与费用的流；目标是总费用最小（费用可正可负）。任何"送 d 单位 s→t"的最小费用流问题，只要加一条从 t 到 s、容量 d、费用为一个足够大负数的边，就变成"在这个增广图上求最小费用循环流"——那条负费用回边会逼算法把 d 单位塞满 s→t。

为什么值得这样转？因为循环流没有源汇的特殊地位，最优性条件可以用一句干净的话刻画（见 2.2.4），后面的消负圈、最小均值圈、cancel-and-tighten 全部直接在循环流上表述。初学者记住这个"加一条 t→s 回边"的小技巧即可在两种视角间自由切换；易错点是别忘了循环流允许边有非零下界，很多建模（如"某条边至少走几单位"）靠的就是下界。

### 2.2.3 残量费用、势与折合费用（reduced cost）

和最大流一样，最小费用流也在残量网络上工作：正向残量边 (u, v) 继承费用 a(u, v)，反向残量边 (v, u) 的费用取相反数 −a(u, v)（因为把流"退回来"应退回运费）。为分析最优性，给每个结点配一个势（potential，又称价格）p(u)，定义边的折合费用（reduced cost）：

a_p(u, v) = a(u, v) + p(u) − p(v)

折合费用有一条关键性质：任何一条**回路**上，折合费用之和等于原费用之和（因为 p(u)−p(v) 沿圈首尾相消）。所以"用势去改写费用"不改变任何圈的总费用，只是给每条边换了个便于比较的度量。

这正是从最短路里搬来的老朋友（Johnson 重赋权、Bellman–Ford 势），初学者可把 p(u) 想成"结点 u 的海拔基准价"，折合费用是"扣掉海拔差之后这条边真正的贵/便宜"。它的用处：若能找到一组势使**所有**残量边折合费用都 ≥ 0，就等于宣告"没有能省钱的圈"（见下）。易错点：折合费用是分析和加速（Dijkstra 化 SSP）的工具，不改变问题本身的最优解，只改变我们描述最优性的语言。

### 2.2.4 负圈最优性条件

最小费用（循环）流有一条极其简洁的最优性判据：一份可行流是最小费用的，当且仅当它的**残量网络里没有负费用回路**（no negative-cost residual cycle）。等价地（用 2.2.3 的势）：当且仅当存在一组结点势 p，使每条残量边的折合费用都非负

a_p(u, v) ≥ 0  对所有残量边 (u, v)

两种表述互为表里——存在可行势 ⇒ 每个残量圈折合费用非负 ⇒（圈上折合和 = 原费用和）原费用非负；反之无负圈时可用最短路距离构造出这样的势。

直觉一句话：如果残量网络里还有一个负费用圈，就说明"沿这个圈打转能白赚钱"，把流沿它推一圈总费用还能降，故当前流不最优；反之找不到这样的圈就到底了。最小例子：残量图上一个三点圈费用 −2，沿它推 1 单位省 2 元。易错点：最优性看的是**残量**网络的圈（含反向边），不是原图；一条原本费用为正的边，其反向残量边费用为负，负圈往往正是"原路径用得太多、退一点更省"的信号。这条定理是本小主题所有算法的地基。

### 2.2.5 Klein 消负圈算法与伪多项式界

由 2.2.4 直接读出一个最朴素的算法——消负圈（cycle-canceling，Klein 1967）：先随便求一份可行流（例如先跑一次最大流得到满足流量的流），然后反复用 Bellman–Ford 在残量网络里找一个负费用圈，沿它推满（推到某条边饱和），把总费用降下来；直到残量网络再无负圈，即得最小费用流。

它的正确性由负圈最优性条件直接保证：终止条件就是"无负圈"。但它只是伪多项式（pseudo-polynomial）：每消一个负圈总费用至少降一个整数量，若初始费用与最优费用之差为 O(mCU)（m 边、C 最大费用、U 最大容量），最坏要消

O(m · C · U) 个负圈

每次找负圈用 Bellman–Ford O(VE)，故总时间 O(V E · mCU) 这一档——与容量/费用的**数值大小**挂钩，不是关于输入规模的多项式。任意选负圈甚至可能选出指数长的收敛过程（Klein 原始版无收敛速度保证）。

初学者要抓两点：一是"消负圈"是"负圈最优性条件"的算法化，思路极自然；二是"伪多项式"的坑——C、U 是以二进制位数计输入规模的，费用是 2^k 时 mCU 就指数级，所以数字一大它可能极慢。这正是 2.3 要解决的问题：改成"每次消哪个圈"有讲究，就能把它变成与数值无关的强多项式算法。本机实证：Klein 消负圈得到的最小费用与 `scipy.optimize.linprog` 建模的最优值在 21 个随机图上全一致（核实 2026-07-30，仅验最优性、不验界）。

### 2.2.6 互补松弛与其他求解路线（点名）

用 2.2.3 的势还能把最优性写成互补松弛（complementary slackness）形式：存在势 p，使折合费用 < 0 的残量边不出现（等价于对应原边已用到边界）、折合费用 > 0 的边流量取下界。这与线性规划对偶完全对应——最小费用流是一个 LP，势就是它的对偶变量（下游 L6-01 大主题03 线性规划与对偶会正式讲）。

除消负圈外，同一问题还有另外几条主流路线，本报告只点名不展开：连续最短增广路（successive shortest paths, SSP，每次沿折合费用最短的增广路送流，配 Dijkstra + 势可做到多项式）、费用缩放（cost scaling，Goldberg–Tarjan 把 push-relabel 思想搬到费用上）、网络单纯形（network simplex，单纯形法在流问题上的特化）。初学者知道"消负圈只是众多路线之一、且是最好理解的那条"即可；SSP 依赖的最短路属先修，故此处不重讲。

## 2.3 Goldberg–Tarjan cancel-and-tighten（强多项式改进）

### 2.3.1 为什么消负圈需要"强多项式化"

2.2.5 的 Klein 消负圈只是伪多项式：运行时间挂在费用/容量的数值上，数字一大就可能很慢。Goldberg–Tarjan（1989）的贡献是：只要**不再随便挑负圈**，而是每次挑一个"最该消"的圈，就能把消负圈变成强多项式（strongly polynomial）——运行时间只依赖结点数 n 和边数 m，与费用、容量的具体数值无关。他们给了两个层层递进的答案：最小均值圈消圈（MMCC）和更快的 cancel-and-tighten。

强多项式为什么重要？它是理论上"最干净"的效率保证：无论费用是 10 还是 10^100，操作次数的上界不变。初学者可对比 2.1 的最大流——那里换个"处理顺序"就把界压下来；这里同理，换个"选圈规则"就把伪多项式变强多项式。核心信息：算法骨架仍是"反复消负圈"，改的只是**选哪个圈**和**怎么批量消**。

### 2.3.2 最小均值圈消圈（MMCC）：第一条强多项式路线

最小均值圈消圈（minimum-mean-cycle-canceling, MMCC）把 Klein 的"随便找个负圈"改成"每次找**平均费用最小**的圈"来消。一个圈的均值指它的总费用除以边数：

mean(C) = ( Σ_{e∈C} a(e) ) / |C|

每轮用 Karp 的最小均值圈算法（O(VE)）找到均值最小的圈，若其均值为负就沿它推满、消掉，直到最小均值 ≥ 0（即无负圈、最优）。Goldberg–Tarjan 证明这样选圈使算法强多项式；Radzik–Goldberg（Algorithmica 1994）把消圈次数的紧界定为

Θ( min( n m log(nC), n m² ) )

即强多项式上界 O(nm²) 次消圈（且此界紧），每次 O(VE) 找圈，朴素总时间 O(n²m³) 一档。

直觉是"贪心地先消掉最亏本的圈"能保证进展够快、不会像 Klein 那样绕远。为什么"均值最小"是对的抓手？因为可以证明消 MMCC 会让一个刻画"离最优多远"的量（最负折合费用 ε）单调、成比例地下降，从而给出与数值无关的迭代上界——这是把摊还/势能思想用到费用上的漂亮一例。初学者记住"MMCC = 每次消最亏的圈 ⇒ 强多项式，但每轮要 O(VE) 找圈、整体偏慢"即可；它是第一条强多项式路线，也是 cancel-and-tighten 的思想源头。冲突标注：原始 GT 1989 给的迭代上界弱于此，Radzik–Goldberg 1994 才收紧到 O(nm²) 并证其紧，引用时以后者为准。

### 2.3.3 ε-最优性（近似最优的度量）

cancel-and-tighten 的关键工具是 ε-最优性（ε-optimality）：给定 ε ≥ 0，一份流叫 ε-最优，若存在一组势 p 使**每条残量边**的折合费用都不太负，即

a_p(u, v) ≥ −ε  对所有残量边 (u, v)

ε = 0 就退回 2.2.4 的精确最优（所有折合费用 ≥ 0）。ε 越小，流离最优越近。一个整数费用的关键事实：当 ε 小到 ε < 1/n（n 为结点数）时，ε-最优的流其实已经是精确最优——因为任何残量圈上折合费用之和是整数，而 n 条边每条 ≥ −ε > −1/n 使圈和 > −1，整数且 > −1 即 ≥ 0，故无负圈。

初学者把 ε 想成"允许的最大单边亏损额度"：cancel-and-tighten 的全部工作就是把这个额度一步步逼到 1/n 以下，一旦跨过这条线就免费得到精确最优。易错点：ε-最优是"存在某组势使折合费用 ≥ −ε"，是关于"流 + 一组见证势"的性质，不是流单独的性质；tighten 步做的正是"更新势、把 ε 调小"。

### 2.3.4 cancel-and-tighten：cancel 步与 tighten 步

cancel-and-tighten 把工作组织成一系列相位（phase），每个相位维护一个当前的 ε 和一组势，做两步。cancel（消圈）步：只看"可容许边"——即折合费用为负的残量边——它们构成的子图，反复消掉其中的负圈，直到这个子图无圈（变成 DAG）；这一步把当前 ε 下"还能白赚"的圈全部榨干，但**不**减小 ε。tighten（收紧）步：在可容许边已无圈的前提下，按拓扑序重算一组新势，使新的最大单边亏损缩小一个因子，把 ε 降到

ε ← ε · (1 − 1/n)

如此 cancel 与 tighten 交替，ε 单调下降；一旦 ε < 1/n，由 2.3.3 得到精确最优，算法停。

直觉对比 MMCC：MMCC 每轮花 O(VE) 精确地找"那个"最小均值圈；cancel-and-tighten 意识到不必每次都精确找最贵的圈，只要"把当前 ε 下所有负的可容许圈一次性消光、再把 ε 收紧一档"，就能以更便宜的每相位代价达到同样的收敛效果——用"批量近似"换掉"逐个精确"。初学者记两步的分工：cancel 管"在当前精度下把能省的都省掉"，tighten 管"提高精度（调小 ε、更新势）"，二者交替把流逼向最优。易错点：cancel 步只处理折合费用为负的可容许边子图（它天然接近无环），不是整个残量网络找圈，这正是它比 MMCC 每轮便宜的原因。

### 2.3.5 相位数与总复杂度

因每个相位把 ε 乘以 (1 − 1/n)，要把 ε 从初始 O(C)（C 为最大费用绝对值）降到 < 1/n，需要的相位数是

O( n · log(nC) )

（弱多项式视角；强多项式分析另给一个 O(nm log n) 型的相位/操作上界，两者合起来就是下面的 min 形式）。Goldberg–Tarjan 证明，配动态树（link-cut tree，见大主题01）实现每个相位的 cancel/tighten，整个 cancel-and-tighten 的运行时间为

O( n m log n · min{ log(nC), m log n } )

其中 n 结点、m 边、C 最大费用绝对值。这个界既是强多项式（右分支 m log n 与数值无关），在费用不大时又享受弱多项式的 log(nC) 分支，且与当时最快的最小费用流算法同档。

初学者抓两点即可：一是"相位数 ≈ n·log(nC)"来自"每相位把 ε 削掉 1/n 比例"这一等比收缩，等比收缩到某阈值自然给对数级相位数（乘 n 是因为每次只削 1/n）；二是动态树是把每相位里"沿路径批量推流/查询"这类操作做到 O(log n) 摊还的加速结构，正是它把总时间压进上面的界。冲突/待核：不配动态树的朴素 cancel-and-tighten 每相位代价与总时间因子在不同来源写法不一（常见 O(nm) 每相位、总 O(n²m log(nC)) 一档），本报告以 GT 1989 原文/AMO 给出的动态树界为准，朴素因子标「随实现/版次异」。

### 2.3.6 三条消圈路线全景对比

把本大主题的消圈族并排：Klein 任意消负圈——最好懂，但只伪多项式 O(mCU) 次消圈，数字大则慢；MMCC 每次消最小均值圈——第一条强多项式，Θ(min(nm log(nC), nm²)) 次消圈、朴素总时间偏高（每轮 O(VE) 找圈）；cancel-and-tighten——用"批量消可容许圈 + 收紧 ε"替代"逐个精确找圈"，配动态树达 O(nm log n · min{log(nC), m log n})，是三者里理论最快的强多项式消圈算法。

这条主线的教学价值在于展示同一朴素思想（消负圈）如何经由"选圈规则 + 近似度量 ε + 数据结构加速"三级打磨，从伪多项式一路提升到强多项式。初学者不必记死每个因子，但应能复述这条演进逻辑：正确性来自 2.2.4 的负圈最优性条件（三者共享），效率差别只在"消哪个圈、怎么消、用什么结构消"。它也回扣了大主题01——动态树在这里第二次现身（第一次加速最大流的阻塞流，这里加速消圈），印证"用高级数据结构 + 摊还换更优图算法界"这条 L6-01 的总纲。
