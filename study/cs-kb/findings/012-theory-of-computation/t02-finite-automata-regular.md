## 2.1 有限自动机（§1.1）

### 2.1.1 DFA 的五元组形式定义

一个**确定型有限自动机**（deterministic finite automaton, DFA）是一个五元组（Sipser 3e Definition 1.5）

M = (Q, Σ, δ, q₀, F)

其中 Q 是**有限**状态集，Σ 是有限输入字母表，δ 是**转移函数**，q₀ ∈ Q 是起始状态，F ⊆ Q 是接受状态集。转移函数的类型是

δ : Q × Σ → Q

读作"在某个状态读到某个输入符号，唯一确定地跳到哪个状态"。

初学者要抓住的第一件事是"确定"二字的精确含义：δ 是一个**全函数**——每个 (状态, 符号) 组合都必须给出**恰好一个**下一状态，不多不少、没有选择、没有猜测。这就是它与下一节 NFA 的唯一本质区别。画状态图时，每个圆圈是一个状态，双圈表示接受状态，带箭头的边上标输入符号；"δ 是全函数"在图上意味着**每个状态对字母表里每个符号都恰有一条出边**，缺一条边的图不是合法 DFA（工程上常补一个吸收所有非法转移的"死状态/陷阱状态"来补全）。

为什么状态集必须有限？因为"有限状态"正是这台机器的全部记忆——它读完一段前缀后，关于这段前缀它能记住的只有"现在停在哪个状态"这一条信息。有限个状态 = 有限比特记忆，这个约束是整章一切能力与不能力的根源。

### 2.1.2 转移函数与扩展转移

单步转移 δ 只处理"一个状态 + 一个符号"。要描述机器读完整个串后停在哪，需要把 δ 扩展到"一个状态 + 一个串"上，即**扩展转移函数** δ*（Sipser 用递归的计算序列表述，HMU 3e §2.2 显式记作 δ̂）。它的递归定义是

δ*(q, ε) = q

δ*(q, wa) = δ( δ*(q, w), a )　（w 是串，a 是单个符号）

也就是"读空串原地不动；读 wa 就先把 w 读完到某状态、再用 δ 走 a 这一步"。

这个扩展只是把"一步步走"打包成"一口气走完一个串"，没有引入任何新能力，但它让"接受"能被干净地定义（见 2.1.3）。初学者容易忽略基例 δ*(q, ε)=q 的意义：读入空串时机器不动，所以一台把 q₀ 设为接受状态的 DFA 会接受空串 ε。区分 ε（空串，长度 0 的合法输入）与"没有输入"是后面很多细节的关键。

### 2.1.3 计算、接受与识别的语言

给定 DFA M 和输入串 w = w₁w₂…wₙ（每个 wᵢ ∈ Σ），M 在 w 上的**计算**是一个状态序列 r₀, r₁, …, rₙ，满足 r₀ = q₀ 且 rᵢ₊₁ = δ(rᵢ, wᵢ₊₁)。若末状态 rₙ ∈ F，就说 M **接受** w，否则**拒绝**。M **识别的语言** L(M) 是它接受的全部串的集合

L(M) = { w ∈ Σ* ｜ δ*(q₀, w) ∈ F }

一句话，DFA 是一台"只会点头/摇头"的成员判定机：喂一个串，它只回答"这个串在我的语言里吗"。

要点是"接受"只看**最终**落在哪个状态，中途路过接受状态不算数。一个最小例子（Sipser §1.1 风格）：识别"含偶数个 1 的 01 串"，只需两个状态 even（偶，起始且接受）和 odd（奇），读 0 状态不变、读 1 就在 even↔odd 之间翻转，读完停在 even 才接受。这台机器只需记"到目前为止 1 的个数的奇偶"这一比特，完美体现有限记忆。另一个易错点：一台 DFA 识别的语言是**唯一确定**的，但同一个语言可以被很多台不同的 DFA 识别（状态数可多可少），"最省状态的那台"由 2.4 的最小化理论给出。

### 2.1.4 正则语言的定义

一个语言 A 称为**正则语言**（regular language），当且仅当存在某台有限自动机识别它（Sipser 3e Definition 1.16）

A 是正则语言 ⟺ 存在 DFA M 使得 L(M) = A

正则语言不是某一个语言，而是"所有能被有限自动机识别的语言"构成的一整个**语言类**。

初学者要把"正则"理解成一条能力分界线的名字：线这边（正则）是有限记忆机器搞得定的语言，线那边（非正则）搞不定。它是 Chomsky 层次最底、最简单的一档，对应最弱的机器。为什么值得单独命名？因为这一类语言异常"规整、好处理"——判成员、判空、判等价都有算法（可判定性归本课大主题05），且对多种运算封闭（下条）。一个常见误解是"正则语言=简单/小语言"，其实正则语言可以是无限集（如"所有 01 串"Σ* 本身就是正则的），"正则"限制的是**结构规律性**（有限记忆可识别），不是大小。

### 2.1.5 正则运算：并、连接、星

在语言上定义三种**正则运算**（Sipser 3e Definition 1.23）。设 A、B 是 Σ 上的语言，

并（union）　　A ∪ B = { x ｜ x ∈ A 或 x ∈ B }

连接（concatenation）　　A ∘ B = { xy ｜ x ∈ A 且 y ∈ B }

星（Kleene star）　　A* = { x₁x₂…xₖ ｜ k ≥ 0 且每个 xᵢ ∈ A }

其中星运算把 A 中的串接 0 个、1 个、2 个……拼起来，因为允许 k=0（一个都不接），所以

A* 总是包含空串 ε

这三种运算是"用简单语言拼复杂语言"的三把积木：并是"或者"，连接是"接着"，星是"重复任意多次（含零次）"。理解星必须记住它含空串——这是最高频的坑：{0}* 是"零个或多个 0"（含 ε），不是"至少一个 0"（后者要写 {0}∘{0}* 即 {0}⁺）。这三种运算之所以叫"正则"运算，正是因为下一条会证明：正则语言类对它们**封闭**，即拼完仍是正则语言——这层封闭性最终就是正则表达式（2.3）能穷尽正则语言的原因。

### 2.1.6 正则语言对并运算的闭包

正则语言类对并运算**封闭**（Sipser 3e Theorem 1.25）

若 A₁、A₂ 是正则语言，则 A₁ ∪ A₂ 也是正则语言

证明的构造思想叫**乘积构造**（product construction）：并行地同时跑两台 DFA。设 M₁=(Q₁,Σ,δ₁,q₁,F₁) 识别 A₁、M₂ 识别 A₂，造一台新 DFA，其状态是**状态对** (r₁, r₂) ∈ Q₁ × Q₂，两个分量各自按 δ₁、δ₂ 独立走，接受条件设为"至少一个分量在自己的接受集里"就得到并集（把接受条件改成"两个分量都接受"则得交集，故正则语言对交也封闭）。

直觉是"一心二用地同时模拟两台机器"：新机器的每个状态记录"如果分别跑 M₁ 和 M₂，此刻它们各停在哪"，因为 Q₁×Q₂ 仍是有限集，新机器仍是合法 DFA，故并集正则。这里要点明一个初学者常卡的地方：并与交都能用乘积构造直接在 DFA 上做，但**连接和星用 DFA 直接构造很别扭**（你没法确定该在串的哪个位置"切换"到第二台机器）——正是这个困难催生了下一节的非确定性 NFA，用 NFA 来证连接与星的闭包会优雅得多（见 2.2.5）。

## 2.2 非确定性（§1.2）

### 2.2.1 NFA 的形式定义

**非确定型有限自动机**（nondeterministic finite automaton, NFA）也是五元组（Sipser 3e Definition 1.37）

N = (Q, Σ, δ, q₀, F)

与 DFA 唯一的差别在转移函数的类型

δ : Q × Σ_ε → P(Q)　，其中 Σ_ε = Σ ∪ {ε}

这里 P(Q) 是 Q 的**幂集**（所有子集构成的集合）。也就是说，给一个 (状态, 符号)，NFA 返回的是"下一步可能进入的状态的**集合**"，可以是空集、一个、或多个。

其一，δ 的值是**一组**状态而非一个，所以同一符号可以有多条出边、也可以一条都没有；其二，输入符号一栏是 Σ_ε 而非 Σ，允许 ε 转移（下条）。这与 DFA "每个 (状态,符号) 恰好一个后继"形成对照——DFA 是 NFA 的特例（每个转移集恰好一个元素、且无 ε 边）。初学者要记牢：这里的"非确定"是逻辑上的**存在量词语义**，不是随机、也不是概率（详见 2.2.3）。

### 2.2.2 ε 转移与 Σ_ε

**ε 转移**是一条不读任何输入符号就能走的边，在形式定义里体现为 δ 的定义域含 ε 这一列——δ(q, ε) 给出"不消耗输入即可从 q 跳到的状态集合"。

它的用处是"免费拼接"：想把两台机器串起来（连接）或让一台机器的末尾绕回开头（星），只需从一台的接受状态拉一条 ε 边到另一台的起始状态，机器就能在不读符号的情况下悄悄切换，构造因此变得简洁（2.2.5 的连接/星闭包正靠它）。易错点是别把 ε 边当成"读了一个叫 ε 的符号"——ε 是空串，走 ε 边时读头**不前进**；计算一个状态在读某符号前后"顺着 ε 边还能免费到达哪些状态"，这一步叫求 **ε-闭包**（ε-closure），是子集构造里必须处理的细节。

### 2.2.3 NFA 的计算语义

NFA N 接受串 w 的定义：可以把 w 写成 w = y₁y₂…yₘ（每个 yᵢ ∈ Σ_ε，允许某些 yᵢ 为 ε），且存在一个状态序列 r₀, r₁, …, rₘ 使得 r₀ = q₀、rᵢ₊₁ ∈ δ(rᵢ, yᵢ₊₁)、且 rₘ ∈ F。用一句话概括这个"存在"

N 接受 w ⟺ 存在至少一条从 q₀ 出发、沿输入 w 到达某个接受状态的路径

只要**存在一条**成功路径就接受，哪怕同时还有无数条走向拒绝的路径。

理解非确定性的最好比喻是"平行宇宙 + 存在量词"：读到有多个选择的符号时，机器仿佛**同时**分裂出多个副本各走一条路，只要**有一个**副本最终落在接受状态，整台机器就接受该串。这解释了为什么它"看起来更强"。但务必澄清两个高频误解：其一，非确定 ≠ 随机——它不掷骰子，判据是纯逻辑的"存在成功路径"，与概率无关；其二，正因如此它是数学建模工具而非物理机器，真机执行时要先转成 DFA（下条）。NFA 的价值在于**很多语言用 NFA 描述状态数少得多、也更直观**，尤其是"以某模式结尾/包含某模式"这类语言。

### 2.2.4 NFA 与 DFA 等价与子集构造

核心定理：非确定并没有带来更强的识别能力（Sipser 3e Theorem 1.39）

每台 NFA 都存在一台识别同一语言的等价 DFA

因此（Sipser 3e Corollary 1.40）"存在 NFA 识别 A"与"A 是正则语言"完全等价——NFA 与 DFA 定义的是**同一个**语言类。

构造方法叫**子集构造法**（subset construction，又称幂集构造）：让新 DFA 的**一个状态**代表"原 NFA 此刻可能同时处于的那一组状态"（即 Q 的一个子集）。新 DFA 的状态集取 P(Q)（Q 的幂集），起始状态是 {q₀} 的 ε-闭包，读符号 a 时把当前子集里每个状态按 δ 走 a 再取 ε-闭包合成新子集，只要新子集里含有原接受状态就把它设为新 DFA 的接受状态。

直觉是"用一台确定机记账，账本上写着那台非确定机所有可能分身的当前位置"——把"平行宇宙"打包成"一个记录了所有可能性的确定状态"。代价立刻可见：原 NFA 有 n 个状态，幂集有 2ⁿ 个子集，所以确定化后 DFA 最坏可能需要多达 2ⁿ 个状态，这就是**状态爆炸**（多数实际例子远达不到上界，但存在能逼近 2ⁿ 的语言族）。初学者最容易忽略 ε-闭包这一步：凡有 ε 边，构造每一步（含起始状态）都要先把"顺 ε 边免费能到"的状态并进来，漏了就会算错。

下面用一个经典例子实机加固：语言"倒数第 3 个符号是 1 的 01 串"。它有一台仅 4 状态的 NFA（起始状态自环，再猜一个 1 后强制走两步到接受），子集构造出的 DFA 应恰好用满 2³=8 个可达状态。我们把 NFA、子集构造 DFA、以及 Python `re` 三者在所有长度 ≤10 的串上逐串对拍：

```python
import re, itertools
from functools import reduce
Sigma = ['0','1']
nfa_start, nfa_accept = 0, {3}
nfa_delta = {(0,'0'):{0},(0,'1'):{0,1},(1,'0'):{2},(1,'1'):{2},
             (2,'0'):{3},(2,'1'):{3},(3,'0'):set(),(3,'1'):set()}
def nfa_accepts(w):
    cur = {nfa_start}
    for c in w:
        cur = set().union(*[nfa_delta.get((s,c),set()) for s in cur]) if cur else set()
    return bool(cur & nfa_accept)
def subset_construction():
    start = frozenset({nfa_start}); states={start}; d={}; frontier=[start]
    while frontier:
        S = frontier.pop()
        for c in Sigma:
            T = frozenset(reduce(lambda a,s: a|nfa_delta.get((s,c),set()), S, set()))
            d[(S,c)] = T
            if T not in states: states.add(T); frontier.append(T)
    return start, d, {S for S in states if S & nfa_accept}, states
d_start,d_delta,d_accept,d_states = subset_construction()
def dfa_accepts(w):
    S=d_start
    for c in w: S=d_delta[(S,c)]
    return S in d_accept
ref = re.compile(r'^(0|1)*1(0|1)(0|1)$')
ok = all(nfa_accepts(w)==dfa_accepts(w)==bool(ref.fullmatch(w))
         for n in range(11) for t in itertools.product('01',repeat=n) for w in [''.join(t)])
print("NFA == 子集构造DFA == re 在所有长度<=10 的串上一致:", ok)
print("可达 DFA 状态数:", len(d_states), "（NFA 仅 4 状态）")
```

真实输出（Python 3.11.15 @2026-07-26）：

```
NFA == 子集构造DFA == re 在所有长度<=10 的串上一致: True
可达 DFA 状态数: 8 （NFA 仅 4 状态）
```

结果坐实两件事：三种描述识别同一语言（等价定理的具体见证），且这个 4 状态 NFA 确定化后可达状态恰为 2³=8，直观展示了子集构造的指数上界并非空谈。此实证是加固，不替代教材的等价性证明。

### 2.2.5 用 NFA 证明对连接与星的闭包

正则语言类对连接与星也封闭，而用 NFA 来证异常简洁（Sipser 3e）

对并封闭　Theorem 1.45

对连接封闭　Theorem 1.47

对星封闭　Theorem 1.49

连接的构造：拿识别 A₁、A₂ 的两台 NFA，从 N₁ 的每个接受状态拉一条 ε 边到 N₂ 的起始状态，再把 N₁ 的接受状态改为非接受，起始状态用 N₁ 的——机器读完属于 A₁ 的前缀后可"免费"跳进 N₂ 继续读属于 A₂ 的后缀，故识别 A₁∘A₂。星的构造：加一个新的、同时也是接受状态的起始状态（用来接受 ε），并从原每个接受状态拉 ε 边回到原起始状态，实现"重复任意多次"。

这里正回答了 2.1.6 留下的悬念：为什么并能直接用 DFA 乘积构造，连接和星却要绕道 NFA？因为连接需要机器"在串的某个说不准的位置"从第一台切换到第二台——这个"说不准的切换点"恰好就是**非确定性**要表达的东西，用 ε 边把两台机器缝起来、让"何时切换"交给"存在一条成功路径"的语义去处理，构造就顺理成章。三个正则运算的闭包合起来说明：**从单符号语言出发、反复用并/连接/星拼出来的语言全都是正则的**——这正是下一节正则表达式能穷尽正则语言的另一半理由。

## 2.3 正则表达式（§1.3）

### 2.3.1 正则表达式的语法

**正则表达式**（regular expression）用一套递归语法来"写出"一个语言。R 是 Σ 上的正则表达式，当且仅当它由下列规则生成（Sipser 3e Definition 1.52）

R 是单个符号 a（a ∈ Σ）　｜　R = ε　｜　R = ∅

或由更小的正则表达式 R₁、R₂ 组合而成

R = R₁ ∪ R₂　｜　R = R₁ ∘ R₂　｜　R = R₁*

每个正则表达式 R 描述一个语言，记作 L(R)：符号 a 描述 {a}，ε 描述 {ε}，∅ 描述空语言，三种组合分别对应 2.1.5 的并/连接/星运算作用在子表达式的语言上。

正则表达式就是"用加(∪)、乘(∘)、星(*) 三种运算把语言写成一个代数式"，与其说是机器不如说是记号。举例（Σ={0,1}）：`10*` 表示"一个 1 后跟任意多个 0"，`(0∪1)*` 表示所有 01 串即 Σ*，`(0*10*1)*0*` 表示"含偶数个 1 的串"。两个易错点必须点清：其一，务必区分 **∅**（空语言，一个串都没有）、**ε**（含空串的语言 {ε}，有一个串）、以及**符号 a**（语言 {a}）这三个基例——它们看着像却大不同。其二，这里是**理论**正则表达式，只有并/连接/星三种运算；编程语言里的正则引擎（含反向引用 `\1`、前后视等）已超出理论正则语言的表达力，属"规范 vs 实现"分账，不要混为一谈（工程 regex 归 L4-04）。

### 2.3.2 与有限自动机等价：Kleene 定理

正则表达式与有限自动机描述的是**同一类**语言（Sipser 3e Theorem 1.54，通称 Kleene 定理）

一个语言是正则语言 ⟺ 存在某个正则表达式描述它

结合 2.1.4 与 2.2.4，于是三样东西被钉成一件事

正则语言 ⟺ 存在 DFA 识别 ⟺ 存在 NFA 识别 ⟺ 存在正则表达式描述

它把"跑起来的机器（DFA/NFA）"和"写出来的代数式（正则表达式）"精确地等同起来。证明分两个方向、各由一条引理承担（下两条）：正则表达式 → NFA（Lemma 1.55），以及 DFA → 正则表达式（Lemma 1.60）。实用价值在于给了"证明某语言正则"三条可自由切换的路子——画一台 (N)FA、或写一个正则表达式、或给一个正则文法，任选其一即可。要点边界：Kleene 定理只覆盖"正则"这一档，它**不**保证更复杂的语言（如需计数配对的 0ⁿ1ⁿ）能被有限自动机或正则表达式刻画——那些要更强的机器。

### 2.3.3 正则表达式转 NFA

Kleene 定理的一个方向（Sipser 3e Lemma 1.55）

若正则表达式 R 描述语言 A，则 A 是正则语言（可构造一台 NFA 识别 A）

构造是**沿正则表达式的递归结构自底向上搭 NFA**：三个基例 a、ε、∅ 各画一台平凡的小 NFA；遇到 R₁∪R₂、R₁∘R₂、R₁* 就分别套用 2.2.5 的并/连接/星的 NFA 构造，把子表达式的 NFA 拼起来。

直觉是"正则表达式的语法树怎么长，NFA 就怎么拼"：因为正则表达式无非是三种运算的层层嵌套，而正则语言类对这三种运算都封闭（且闭包证明本身就是 NFA 构造），所以顺着表达式结构递归地拼 NFA 必然成功。这个方向也叫 **Thompson 构造**（Thompson's construction），是工程上把正则表达式编译成自动机的标准算法的理论原型（工程实现归 L4-04）。它同时反向印证了 2.1.5 三运算命名为"正则"的恰当性——正则表达式能表达的，恰好是从基例出发用三运算能拼出的一切。

### 2.3.4 GNFA 与状态消去：DFA 转正则表达式

Kleene 定理的另一方向（Sipser 3e Lemma 1.60）

若 A 是正则语言，则存在一个正则表达式描述 A

构造借助**广义非确定有限自动机**（generalized NFA, GNFA，Sipser 3e Definition 1.64）：一种边上标的不是单个符号、而是**整个正则表达式**的 NFA，约定它有唯一起始状态（无入边）、唯一接受状态（无出边）。把一台 DFA 先改造成等价的 GNFA，然后**逐个消去中间状态**（state elimination）：删掉一个状态 qᵣ 时，对每一对"经 qᵣ 中转"的入边 (qᵢ→qᵣ 标 R₁)、自环 (qᵣ→qᵣ 标 R₂)、出边 (qᵣ→qⱼ 标 R₃)，把绕过 qᵣ 的直达边补成

R₁ R₂* R₃　（若 qᵢ→qⱼ 原有边 R₄，则新标记为 R₄ ∪ R₁R₂*R₃）

一直消到只剩起始与接受两个状态，它们之间那条边上的正则表达式就是整台机器识别的语言。

直觉是"把每个被删状态所承载的所有路径，用一个正则表达式吸收进绕过它的边里"：R₁R₂*R₃ 恰好表达"进入 qᵣ、在 qᵣ 上自环任意多次、再离开 qᵣ"这一族路径。因为每消一个状态都保持"两状态间边的正则表达式 = 该两状态间所有路径对应的串集"这个不变量，消到最后自然得到全语言的正则表达式。初学者最常忘的是自环那一项的星号 R₂*——漏了它就丢掉了"在中间状态原地打转任意多次"的所有串。这套状态消去法配合 2.3.3 的 Thompson 构造，就把 Kleene 定理两个方向都构造性地做实了。

## 2.4 非正则语言（§1.4）

### 2.4.1 正则语言的泵引理

不是所有语言都正则。判定"不正则"的主力工具是**泵引理**（pumping lemma for regular languages，Sipser 3e Theorem 1.70）

若 A 是正则语言，则存在一个数 p（**泵长度**，pumping length），使得任何长度 ≥ p 的串 s ∈ A 都能拆成三段 s = xyz，同时满足三个条件

(1) 对每个 i ≥ 0 有 x yⁱ z ∈ A　（把中段 y 复制任意多次仍在 A 中）

(2) |y| > 0　（中段非空）

(3) |xy| ≤ p　（前两段合起来不超过泵长度）

条件 (1) 里的"y 复制 i 次"就是"泵"（pumping）这个名字的来源；i=0 表示把 y 删掉。

泵引理是**正则语言的一条必要性质**：凡正则语言都逃不过它。它成立的根本原因是"鸽巢原理 + 有限状态"：一台 p 个状态的 DFA 读一个长度 ≥p 的串时，前 p 步至少经过 p+1 个状态，必有某个状态被重复经过；重复状态之间读掉的那一段就是 y，机器走到重复状态时"记忆被清零重来"，所以这段循环可以任意多次重复或删除而机器分不出差别，串仍被接受。三个条件缺一不可，尤其 |xy|≤p 把可泵的段锁定在串的**前 p 个符号**内，这是后面构造反例时的关键抓手。务必记牢泵引理的逻辑方向：它是正则的**必要非充分**条件——满足泵引理**不能**推出正则，但**违反**泵引理**一定**不正则。

### 2.4.2 用泵引理判定非正则

泵引理的实战用法是**反证**：要证 A 不正则，假设它正则，则得到某泵长度 p；再**精心挑一个**长度 ≥p 的串 s ∈ A，证明它的**任何**满足 (2)(3) 的拆分 xyz 都能被泵出 A（即找到某个 i 使 xyⁱz ∉ A），从而与泵引理矛盾。

经典对象是

L = { 0ⁿ1ⁿ ｜ n ≥ 0 }

取 s = 0ᵖ1ᵖ ∈ L。由条件 (3) |xy| ≤ p，y 落在开头那 p 个符号里，故 **y 全是 0**且非空；把 i 取 2（多复制一次 y），得到的串 0 的个数严格多于 1 的个数，不再形如 0ⁿ1ⁿ，故 xy²z ∉ L，矛盾——所以 L 不正则。

这个证明的精髓在"对手视角"：泵长度 p 和拆分 xyz 都是**对手（假设的 DFA）**给的、你不能挑，你能挑的只有那个具体的串 s 和最后要泵的次数 i；所以要选一个"无论对手怎么拆都能被你泵坏"的 s。直觉上 0ⁿ1ⁿ 不正则是因为它要求机器**数出前面有多少个 0 再核对后面 1 的个数**，而有限状态机只有有限比特记忆、n 可任意大，装不下这个计数器（这与 2.1.1 的"有限记忆"根源一脉相承）。高频易错点：不能挑一个"恰好泵得动"的特例拆分来"证明"它满足泵引理——那不是矛盾；必须证**所有**合法拆分都泵坏。另一常见错误是把泵引理当充分条件去"证正则"，方向反了。

下面用 Python 演示：对任意假想泵长度 p，程序都能在 0ᵖ1ᵖ 上找到一个把它泵出 L 的合法拆分（取 i=2），把"必然矛盾"落到具体串上：

```python
def in_L(w):
    n=len(w); return n%2==0 and w[:n//2]=='0'*(n//2) and w[n//2:]=='1'*(n//2)
def refute(p):
    s='0'*p+'1'*p
    for lenxy in range(1,p+1):          # |xy|<=p
        for leny in range(1,lenxy+1):   # |y|>0
            x,y,z = s[:lenxy-leny], s[lenxy-leny:lenxy], s[lenxy:]
            if not in_L(x+y+y+z):       # 泵 i=2 出 L
                return y, x+y+y+z
for p in [1,2,3,5]:
    y,pumped = refute(p)
    print(f"p={p}: 取 y={y!r}, 泵 i=2 得长度 {len(pumped)} 的串, 是否属于 L: {in_L(pumped)}")
```

真实输出（Python 3.11.15 @2026-07-26）：

```
p=1: 取 y='0', 泵 i=2 得长度 3 的串, 是否属于 L: False
p=2: 取 y='0', 泵 i=2 得长度 5 的串, 是否属于 L: False
p=3: 取 y='0', 泵 i=2 得长度 7 的串, 是否属于 L: False
p=5: 取 y='0', 泵 i=2 得长度 11 的串, 是否属于 L: False
```

每个 p 都构造出违反泵引理的实例（泵后串奇数长、0 比 1 多，必不属于 L），把"0ⁿ1ⁿ 不正则"的抽象反证坐实成可复现的具体反例。此为直觉演示，非替代教材证明。

### 2.4.3 Myhill–Nerode 定理

泵引理只能证"不正则"，且不是充要的。给出正则性**充要刻画**的是 **Myhill–Nerode 定理**（Sipser 3e 将其作为习题 Problem 1.52；HMU 3e §4.4 作为正文定理）。对语言 L，若串 x、z 满足"存在某个后缀 w 使 xw、zw 中恰好一个属于 L"，就说 w **区分** x 与 z。定理陈述

L 是正则语言 ⟺ L 把 Σ* 划分成的"两两可区分等价类"只有**有限**个

且这个有限的类数**恰好等于识别 L 的最小 DFA 的状态数**。

这里的等价关系是"x ≡ z 当且仅当对任何后缀 w 都有 xw∈L ⟺ zw∈L"，即两个前缀"对未来完全无差别"就归为一类。直觉是把 DFA 的状态和"前缀的等价类"对应起来：一台 DFA 读完某前缀后停在某状态，而它对该前缀的全部"记忆"就浓缩在这个状态里——凡是导致同一状态的前缀，机器往后的行为完全一样，正是一个等价类。类数有限 ⟺ 机器只需有限个状态 ⟺ 正则。用它证 0ⁿ1ⁿ 不正则一步到位：前缀 0¹,0²,0³,… 两两可区分（0ⁱ 与 0ʲ 用后缀 1ⁱ 区分），无穷多个类，故不正则。它比泵引理更强，因为它是**充要**条件（泵引理只必要），既能证不正则、也能反过来确认正则并直接给出最小状态数。

### 2.4.4 DFA 最小化

Myhill–Nerode 的构造性推论是：每个正则语言都有一台**状态数最少的 DFA**，且这台最小 DFA **在改名同构意义下唯一**（HMU 3e §4.4；Sipser 3e 置于习题）。求它的标准算法是**状态合并**：把一台 DFA 中"彼此不可区分"的状态合成一个。

一个高效做法是**分割细化**（partition refinement，Hopcroft 算法）：初始把状态分成"接受"与"非接受"两组，反复检查——若同组内两个状态在某输入符号下走到了**不同组**，就把它们拆开，直到不再有可拆的组；每个最终组合并成最小 DFA 的一个状态。

直觉上"两个状态不可区分"意思是"从它们出发、对任何后续输入串，接受/拒绝的结果完全相同"，这样的状态留着是冗余的，合并不改变所识别的语言。为什么最小 DFA 唯一而 NFA 没有这种唯一性？因为 DFA 的每个可达状态精确对应一个 Myhill–Nerode 等价类，类由语言本身唯一决定，所以最小 DFA 被语言唯一钉死；NFA 因非确定性没有这种一一对应，最小 NFA 既不唯一、求解也更难。这条结果的下游意义：它保证了自动机可以被规范化比较（判两台 DFA 是否等价，只需各自最小化后比同构），是编译器词法阶段状态压缩的理论依据（工程落地归 L4-04）。
