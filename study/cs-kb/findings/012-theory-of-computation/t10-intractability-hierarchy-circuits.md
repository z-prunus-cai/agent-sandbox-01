## 10.1 空间层级定理（§9.1）

### 10.1.1 空间可构造函数

空间层级定理成立需要给"空间界函数"加一个温和的技术条件：它必须是**空间可构造**（space constructible）的。Sipser 3e Definition 9.1 说，函数

f : ℕ → ℕ（且 f(n) ≥ log n）

是空间可构造的，当且仅当"把输入 1ⁿ 映射成 f(n) 的二进制表示"这个映射能由一台在 O(f(n)) 空间内工作的图灵机算出。

初学者可以把这个条件理解为"机器能自己量出它被允许用多少格子"。层级定理的证明要造一台机器，它要在带上先划出恰好 f(n) 格的工作区、超出就拒绝；如果连"f(n) 有多大"都算不出来，就没法划这条线。绝大多数常见函数——如 n、n²、2ⁿ、n log n——都是空间可构造的，所以这个前提在实践中几乎从不碍事；它只是用来排除某些人为构造的、连自己资源上限都算不出来的病态函数。

### 10.1.2 空间层级定理的陈述（Theorem 9.3）

空间层级定理断言：只要多给一点点空间（哪怕从 o(f) 提升到 O(f)），就一定有新语言变得可判定。Sipser 3e Theorem 9.3 的陈述是：

对任意空间可构造函数 f : ℕ → ℕ，存在一个语言 A，它可由某台在 O(f(n)) 空间内工作的图灵机判定，但**不能**由任何在 o(f(n)) 空间内工作的图灵机判定。

这里的 O 与小 o 的对比是全部要害。O(f(n)) 是"用得起 f(n) 这么多空间"，o(f(n)) 是"渐近地严格少于 f(n)"（例如 f(n)/log n、√f(n)）。定理是说：这两档之间**一定**夹着至少一个语言，它落在上档、掉出下档。于是"空间越多，判定能力真的越强"不是感觉，是被证明的事实。

初学者最容易误读成"任意多给空间都有新东西"——注意前提是可构造函数，且分界是 O 对 o 这条渐近线，不是"多一个格子"。另一个常见困惑是它和 P vs NP 的关系：层级定理能证 DSPACE 意义下**同种资源**不同量级的严格分隔，恰恰因为对比的是"同一种机器、同一种资源"的多与少；而 P vs NP 比的是"确定 vs 非确定"两种不同机器，层级定理的技术**够不着**（原因见 §10.3）。

### 10.1.3 证明骨架：带空间上限的对角化

证明用的是**对角化**（diagonalization），和第 4 章证 A_TM 不可判定同一家族的技术，但这里给对角化加了"空间预算"。构造一台机器 D，输入是某台机器的描述 ⟨M⟩（后接足够的填充），D 在 O(f(n)) 空间内模拟 M 在输入 ⟨M⟩ 上的运行，并**做相反的事**：M 接受则 D 拒绝，M 拒绝则 D 接受。

关键操心的是两点。其一，D 必须先用空间可构造性划出恰好 O(f(n)) 的工作区，模拟中一旦 M 想越界（或陷入超过状态数×空间的步数即判定它在循环）就直接拒绝，保证 D 自己**真的**只用 O(f(n)) 空间。其二，D 判定的语言 A 与任何 o(f(n)) 空间机器 M 都至少在输入 ⟨M⟩（补足填充使其足够长、让 D 有足够空间完成模拟）上**答案相反**，因此没有任何 o(f(n)) 空间机器能判定 A。这台 D 自己用 O(f(n)) 空间判定 A，两头一夹就得到定理。

"造一台在预算内、专门跟所有小预算机器对着干的机器"。填充（padding）的作用是把输入撑长，好让低阶函数 f(n) 也大到够 D 完成模拟——这是让"渐近"分界落地的技术细节，不是核心思想。

### 10.1.4 推论：真包含的复杂度类

层级定理最有用的产物是**能被证明的严格包含**。由 Theorem 9.3 可直接得到（Sipser 3e §9.1 相应推论）：

NL ⊊ PSPACE

PSPACE ⊊ EXPSPACE

例如取 f₁(n)=log n 与 f₂(n)=n（或更粗的多项式对指数），因为一个是另一个的 o( )，中间必有语言分隔，于是这些包含是**严格**的。这与大主题09 里"PSPACE ⊆ EXPSPACE 但不知是否相等"的悬念形成对照——层级定理把其中一部分悬念**落成了定理**。

初学者可以据此建立一个心态：复杂度类的无穷阶梯里，**跨越足够大的资源量级**时严格变强是可证的（层级定理管这个）；难在**相邻或异质**的类（P vs NP、L vs NL、P vs PSPACE 里的具体某步），那里层级技术使不上劲。

## 10.2 时间层级定理（§9.1）

### 10.2.1 时间可构造函数

与空间侧平行，时间层级定理要求界函数是**时间可构造**（time constructible）的：存在一台图灵机，把 1ⁿ 在 O(t(n)) 时间内变换成 t(n) 的二进制表示（Sipser 3e §9.1；一般要求 t(n) ≥ n log n 一类下界以便机器有时间读完输入并做计数）。直觉同样是"机器能自己数出它被允许跑多少步"，好在模拟中用一个计数器盯住步数、超时就停。n、n²、2ⁿ、n log n 等常见函数都是时间可构造的。

### 10.2.2 时间层级定理的陈述（Theorem 9.10）

时间层级定理是空间版的时间对应物，但**多一个对数因子的损耗**，这正是它和空间版最该记住的差别。Sipser 3e Theorem 9.10：

对任意时间可构造函数 t : ℕ → ℕ，存在一个语言 A，它可由某台在 O(t(n)) 时间内运行的图灵机判定，但**不能**由任何在 o(t(n)/log t(n)) 时间内运行的图灵机判定。

对比空间版的干净分界 O(f) 对 o(f)，时间版的下档是 o(t(n)/log t(n))，多除了一个 log t(n)。

这个 log 因子从哪来、为什么空间侧没有，是本节的核心疑点。原因在模拟开销：一台通用机去模拟"任意一台时间受限机 M"时，每模拟 M 的一步，为了在带上找到 M 的当前状态、当前读写头位置并维护自己的步数计数器，通用机要付出约 O(log t) 的额外时间（要记录/查阅规模到 t 的步数与位置信息）。空间可以**复用**（模拟腾挪同一片带子，不额外累积），时间却是**只增不减**地累加，于是模拟的对数开销留在了时间界里，逼得分界必须让出一个 log t 的余地。初学者不必深究证明，但要记住结论：**时间层级的分隔比空间层级"松"一个对数因子**，根源是"时间不可回收、模拟有对数额外开销"。

### 10.2.3 证明骨架

造一台机器 D，在 O(t(n)) 时间内模拟输入所描述的机器 M（跑在 ⟨M⟩ 上），用一个计数器限制自己最多跑 t(n) 步，超时即停并做与 M **相反**的判定。因为模拟每一步带 O(log t) 开销，D 能安全兜住的是所有 o(t/log t) 时间的机器，从而 D 判定的语言 A 与它们都不同——这就把那个 log 因子写进了定理。其余（填充、可构造性划预算）与 §10.1.3 一致。

### 10.2.4 推论：P ⊊ EXPTIME 等

时间层级定理直接给出确定时间类阶梯上的**严格**包含（Sipser 3e §9.1 相应推论）。最著名的是：

P ⊊ EXPTIME

因为任取多项式 t₁(n)=n^k 与指数 t₂(n)=2ⁿ，多项式是 o(2ⁿ/n) 一类，层级定理保证中间夹着语言，故 P 严格真含于 EXPTIME。

它是"**确实存在需要指数时间、无法多项式求解的可判定问题**"的严格证明——难解性（intractability）不是没找到好算法，而是被证明了的。初学者常把它和 P vs NP 搞混：P ⊊ EXPTIME 是**已证定理**，而 P vs NP、NP vs EXPTIME 仍未解；层级技术之所以能拿下前者、拿不下后者，同样归因于 §10.3 的相对化限制。

### 10.2.5 EXPSPACE 完全性

§9.1 末还给出一个"具体的、被证明需要指数空间"的自然问题，作为难解性的落地例子：带**指数运算符**的正则表达式的等价问题。普通正则表达式加一个幂运算 ↑，其中 R↑k 表示把 R 连接 k 次（如 (a↑3)=aaa），记这类表达式为 REX↑；定义

EQ_REX↑ = { ⟨Q, R⟩ | Q、R 是等价的带指数正则表达式 }

Sipser 3e 证明 EQ_REX↑ 是 **EXPSPACE-完全**（EXPSPACE-complete）的：它属于 EXPSPACE，且每个 EXPSPACE 问题都能多项式归约到它。

EXPSPACE-完全的份量在于：结合 §10.1.4 的 PSPACE ⊊ EXPSPACE（层级定理给的真包含），EXPSPACE-完全问题**可证**不在 PSPACE 中，因而**可证**不在 P、NP、PSPACE 中——这是少数几个"难解性有确定证明、不依赖 P≠NP 猜想"的自然问题之一。初学者可以把它当作"层级定理 + 完全性"合力的样板：层级定理先证两层真分隔，完全性再把某个具体问题钉死在上层，于是该问题的难被彻底坐实，而非停留在猜想。

（该 EXPSPACE-完全定理在 Sipser 3e §9.1 末，本报告推断其定理编号为 9.15，但 2026-07-26 未能用独立一手源复核该确切编号，故编号标「待核」；定理**内容**——EQ_REX↑ 为 EXPSPACE-完全——在 Sipser 与交叉源中一致，不存疑。）

## 10.3 相对化（§9.2）

### 10.3.1 预言机与预言图灵机

相对化研究"如果给图灵机一个**免费的超能力子程序**，复杂度会怎样变"。这个超能力就是**预言机**（oracle）：任选一个语言 A ⊆ Σ\*，一台**预言图灵机**（oracle Turing machine）M^A 在普通图灵机之外多一条**预言带**，它可以把任意串 w 写上去、进入询问状态，然后**一步之内**得到"w ∈ A 吗"的是/否回答，无论回答这个问题本身有多难（Sipser 3e §9.2）。

初学者关键要抓住"一步免费"：预言机把"判定 A"这件事当成单位代价的黑箱。这不是真实可造的机器，而是一个**思想工具**——用来问"假如某个难题免费可解，别的问题会不会跟着变简单"。比如 M^SAT 就是一台可以免费查询 SAT 的机器。

### 10.3.2 相对化的复杂度类记法

把预言机接到复杂度类上，就得到**相对化**（relativized）的类。记号是给类名加一个上标预言机：

P^A = { 由某台带预言机 A、在多项式时间内运行的确定预言图灵机判定的语言 }

NP^A = { 由某台带预言机 A、在多项式时间内运行的非确定预言图灵机判定的语言 }

读法是"在能免费查 A 的世界里的 P / NP"。P vs NP 问题相对化后就变成"在装了预言机 A 的世界里，P^A 与 NP^A 是否相等"。

### 10.3.3 相对化定理（Theorem 9.20，Baker–Gill–Solovay）

核心结果是：**P vs NP 的答案随预言机而变**——有的世界里两者相等，有的世界里不等。Sipser 3e Theorem 9.20（即经典的 Baker–Gill–Solovay 定理，1975）断言：

存在预言机 A，使得 P^A = NP^A

存在预言机 B，使得 P^B ≠ NP^B

两句话缺一不可，正是这"一正一反"制造了后面的屏障。取 A 为某个 PSPACE-完全语言（如 TQBF），因为在 PSPACE 面前多项式的确定与非确定坍缩到一起，可得 P^A = NP^A = PSPACE^A；而 B 则由对角化专门构造，让某个"稀疏见证"语言落在 NP^B 却逃出 P^B，得 P^B ≠ NP^B。

初学者不必啃 B 的构造，只需接受这个"分裂"事实：换一个预言机，P 与 NP 的相等性能被翻转。（Sipser 官方勘误页 itoc-derrs3.1.html 对本定理证明有一处符号更正——2024-09-13 报告的"给 M₁、M₂、Mᵢ 补上标 A"，仅是排版补记，不影响结论；核实 2026-07-26。）

### 10.3.4 相对化屏障：为什么它限制了 P vs NP 的证明手段

这条定理的真正价值不在两个预言机本身，而在它对**证明技术**下的封杀令，即**相对化屏障**（relativization barrier）。观察到一个关键事实：像**对角化**和**图灵机模拟**这类技术，如果对普通机器有效，那么把预言机原样接上去、证明照抄一遍，对**所有**预言机版本**同样**有效——这种技术叫会"**相对化**"的技术。

于是矛盾来了。假设有一套会相对化的技术**证明**了 P = NP，那它就会同时证明对所有预言机 O 都有 P^O = NP^O；但 Theorem 9.20 给了 B 使 P^B ≠ NP^B，矛盾。反过来，若一套会相对化的技术证明了 P ≠ NP，它又会推出所有 P^O ≠ NP^O，与 A 使 P^A = NP^A 矛盾。结论是：

任何会相对化的证明技术都**无法**判定 P vs NP（两个方向都被堵死）

这解释了为什么 §10.1/§10.2 那套对角化虽然能证出层级定理（同资源多与少的分隔），却证不出 P vs NP——因为对角化会相对化，撞上了这道墙。初学者应把这理解成一块**路标**而非绝望：它告诉研究者"别再纯用对角化/模拟去碰 P vs NP 了"，从而催生了**不相对化**的新技术（如证 IP=PSPACE 的算术化、以及电路下界方向——这也正是 §10.4 电路复杂度受重视的原因之一）。相对化屏障是复杂度理论三大屏障之一，另两道（自然证明屏障、代数化屏障）属研究前沿，本报告只点名不展开。

## 10.4 电路复杂度（§9.3）

### 10.4.1 布尔电路（Definition 9.21）

电路复杂度换一个模型来度量难度：不看图灵机跑多久，而看"要多少个逻辑门才能算出答案"。Sipser 3e Definition 9.21 定义**布尔电路**（Boolean circuit）为一个**有向无环图**（DAG），其节点是 AND、OR、NOT 三种逻辑门；有若干标为输入变量 x₁…xₙ 的入口点，以及一个指定的输出门。

一个 n 输入布尔电路 C 计算一个布尔函数：给每个输入赋 0/1，沿 DAG 从输入向输出逐门求值，输出门的值就是 C(x₁…xₙ) ∈ {0,1}。

初学者可把电路想成"一次性、无循环的组合逻辑"：没有状态、没有回边（DAG 保证），信号从输入端一路"流"到输出端。它和硬件里的组合电路是同一个东西，也和数字逻辑课的门级电路对应。本机实证坐实了这一直觉：把 MAJ(x,y,z)=(x∧y)∨(y∧z)∨(x∧z) 建成 8 个门的 DAG 逐门求值，对全部 8 组输入与"三个里至少两个为 1"的参考真值表逐行比对，8/8 全等（`CIRCUIT_MATCHES_TRUTH_TABLE: True`）——电路确实就是被 DAG 结构固定下来的一个布尔函数。

### 10.4.2 电路族与规模、深度复杂度（Definition 9.22）

单个电路只有固定条数的输入线，只能处理**某一个长度** n 的输入。要用电路处理"任意长度的语言"，就得给每个 n 配一个电路，合成一个**电路族**（circuit family）：

C = (C₀, C₁, C₂, …)，其中 Cₙ 恰有 n 个输入变量

Sipser 3e Definition 9.22 同时给出两个度量。电路族的**规模复杂度**（size complexity）是把 Cₙ 的门数看成 n 的函数；**深度复杂度**（depth complexity）是把 Cₙ 中从输入到输出的最长路径长度看成 n 的函数。

规模≈"总工作量"（对应时间的类比），深度≈"最长依赖链"（对应并行时间的类比）。初学者要抓住"一族对一个语言"这个转变：一个电路对应一个长度，一串电路才对应一门语言。这里还埋着一个后面才处理的微妙点——这一族电路是不是"能被统一、有效地造出来"？§10.4.6 会点到这个"一致性"问题。

### 10.4.3 电路族判定语言、语言的电路复杂度（Definition 9.24）

把电路族接到语言上：Sipser 3e Definition 9.24 说，电路族 (Cₙ) **判定**语言 A ⊆ {0,1}\*，当且仅当对每个长度 n 和每个长度为 n 的串 w：

Cₙ(w) = 1 当且仅当 w ∈ A

语言 A 的**电路复杂度**（circuit complexity）就是"判定 A 的最小电路族"的规模复杂度。

于是"A 难不难"有了第二个尺子：需要多大的电路。初学者要留意与图灵机的关键差异——电路是**非一致**（non-uniform）模型：每个 Cₙ 可以是完全无关地"手工定制"出来的，不要求存在一个统一算法来生成它们。这带来一个吓人的副作用：任何**单一长度**上的语言（哪怕整体是不可判定语言在长度 n 上的切片）都能被一个 Cₙ 判定，所以谈电路复杂度必须对**所有 n** 一起谈规模增长，单看一个 n 没有意义。

### 10.4.4 时间与电路的桥（Theorem 9.25）

电路复杂度不是空中楼阁，它和时间复杂度有一座桥：**快的图灵机可翻译成小的电路族**。Sipser 3e Theorem 9.25：

若语言 A ∈ TIME(t(n)) 且 t(n) ≥ n，则 A 的电路复杂度为 O(t²(n))

也就是说，一台 t(n) 时间的图灵机，其在长度 n 输入上的整段计算，可以被一个规模 O(t²(n)) 的布尔电路"逐格逐步"模拟出来。

证明直觉是把图灵机的计算画成一张**格局表**（tableau）：行是时刻、列是带格，第 t(n) 行 × t(n) 列的方格阵记录整段运行；每个格子的内容只由上一时刻它自己和左右邻居决定，这种"局部更新"恰好能用固定大小的一小块电路实现，于是整张表就拼成一个 O(t²) 大小的电路。这张 tableau 正是大主题08 Cook–Levin 定理用过的同一张图。由此立刻得到一个重要推论：**P 中的每个语言都有多项式规模的电路族**（因为 t 是多项式，t² 也是多项式）。初学者可以据此建立方向感——这也是为什么人们想反过来"证某个 NP 问题需要超多项式规模电路"来分离 P 与 NP（见 §10.4.6）。

### 10.4.5 CIRCUIT-SAT 与用电路重证 Cook–Levin

电路给了 NP-完全性一个更自然的入口。定义**电路可满足性**问题：一个电路是**可满足的**（satisfiable），若存在一组输入赋值使其输出为 1；对应的语言

CIRCUIT-SAT = { ⟨C⟩ | C 是可满足的布尔电路 }

Sipser 3e §9.3 证明 CIRCUIT-SAT 是 **NP-完全**的，并用它给出 Cook–Levin 定理的一个电路版证明脉络：先由 Theorem 9.25 的 tableau 把"NP 机器的接受计算"编码成一个电路（该电路可满足 ⟺ 原机器存在接受该输入的分支），得 CIRCUIT-SAT 的 NP-难；再把电路的门逐个翻译成合取子句，得到 CIRCUIT-SAT ≤ₚ SAT ≤ₚ 3SAT，从而重新证得 SAT / 3SAT 的 NP-完全性。

这条链让初学者看清 Cook–Levin 的"物理内核"：一台机器的运行本质上是一大片**局部一致**的更新，而"局部一致"天然就是逻辑门/逻辑子句能表达的东西，所以"存在接受计算"才会等价于"某个电路/公式可满足"。相比大主题08 直接构造 CNF 的证法，电路版把"局部性"这一步显式地摆了出来，通常更容易理解。

（CIRCUIT-SAT 的 NP-完全性在 Sipser 3e §9.3；其确切定理编号本报告未用独立一手源复核，故不锚定具体编号，只锚定 §9.3 与"CIRCUIT-SAT 为 NP-完全、并借此重证 Cook–Levin"这一内容——该内容在 Sipser 与交叉源中一致。）

### 10.4.6 电路复杂度与 P vs NP：一致性与下界（点名，不展开）

电路复杂度之所以是研究热点，是因为它给分离 P 与 NP 提供了一条**绕开相对化屏障**的可能路径。若能证明"某个 NP-完全问题的电路复杂度是超多项式的"，结合 §10.4.4"P 中语言都有多项式电路"，就能推出该问题不在 P，从而 P ≠ NP。这类下界证明通常**不相对化**，正好躲开 §10.3 的墙。

这里必须区分一致与非一致两个世界。把"有多项式规模电路族的语言"这一类记作 **P/poly**；由 §10.4.4，P ⊆ P/poly，但 P/poly 是非一致的、甚至包含某些不可判定语言，所以 P/poly ≠ P。要让"电路小"回落到"图灵机快"，需要额外的**一致性**（uniformity）条件——要求电路族 (Cₙ) 能被一个统一的低复杂度算法（如对数空间）生成。**一致 P/poly = P**，非一致则不然。这些概念（P/poly、一致性、Karp–Lipton 定理、以及电路下界研究、自然证明屏障）属于下游 L6-01 与研究前沿，本报告按跨课边界只**点名**，不展开定义与证明。

其一，电路是逼近 P vs NP 下界的主力模型，因为它有希望绕过相对化屏障；其二，"电路小"和"图灵机快"之间隔着一个"一致性"条件，非一致电路强到会包含不可判定问题，不能直接当成 P。
