# L3-05·大主题05 可判定性

> 基线 Py3.11.15/np2.4.6/gcc13.3 @2026-07-25 ｜ 核实日期：2026-07-26 ｜ 先修：大主题02 有限自动机、大主题03 上下文无关语言、大主题04 图灵机与可判定/可识别语言 ｜ 一手锚点：Sipser《Introduction to the Theory of Computation》3rd ed.(2012, Cengage) Ch4（§4.1–4.2）；交叉一手 Hopcroft–Motwani–Ullman《Introduction to Automata Theory, Languages, and Computation》3rd ed.(2007) Ch4 §4.3、Ch7 §7.4、Ch9 §9.1–9.2 ｜ 成熟度：GA/稳定（经典可计算性结果，无演进快项）

**把每个「计算问题」重新写成一个「语言」（字符串集合），于是「这个问题能不能被算法解决」就变成「这个语言是不是图灵可判定的」**。例如「DFA B 会不会接受串 w」被编码成语言 A_DFA，问它可不可判定，就是问「有没有一个总会停机并给出正确是/否的算法」。本章的乐观面是：只要被研究的机器本身「弱」（DFA、NFA、正则表达式、CFG），关于它的基本问题几乎都可判定，因为我们能设计出保证停机的判定过程。悲观面是：一旦被研究的对象是图灵机这种「和真实计算机一样强」的机器，最基本的「它会不会接受某输入」都不可判定——这由对角化论证从原理上堵死，不是「暂时没想出算法」，而是「不可能有算法」。

一个贯穿全章、必须先立住的记法约定：把对象（DFA、CFG、图灵机、串）编码成一个字符串，记作 ⟨·⟩。⟨B⟩ 表示自动机 B 的编码，⟨B, w⟩ 表示「B 与串 w」这一对的编码。判定问题就写成「某编码串是否属于某语言」。

## 5.1 关于正则语言的可判定问题

### 5.1.1 把计算问题编码成语言：⟨·⟩ 与判定过程

要谈「一个问题可不可判定」，得先把问题变成一个语言。做法是把问题的输入对象（一台机器、一个文法、一个串）用某种固定方案编码成有限字符串，再把「所有回答为是的输入」收集成一个集合，这个集合就是对应的语言。一个问题「可判定」当且仅当它对应的语言是图灵可判定的，即存在一台对任何输入都会停机、并正确输出接受/拒绝的图灵机（判定器 decider）。

判定器和「识别器（recognizer）」的关键差别是：判定器**必须对所有输入停机**，而识别器允许在「否」的输入上永远算下去（循环）不给答案。本章 5.1、5.2 的正面结论，全都是通过「描述一个必定停机的算法」来证明的——只要能给出一个不会陷入死循环、步数有限的过程，该语言就可判定。

证明「可判定」= 造一个保证停机的算法并说明它为什么停；证明「不可判定」（5.3）= 说明任何声称能判定它的算法都会自相矛盾。前者是构造，后者是反证。本节所有语言都以尖括号编码的形式给出，读的时候把 ⟨B, w⟩ 想成「一个把自动机 B 和输入串 w 打包在一起的字符串」即可，不必纠结编码细节——只要编码是可解析的，判定过程就能从字符串里恢复出 B 和 w。

### 5.1.2 A_DFA：DFA 的接受问题可判定

关于 DFA 的接受问题被编码成语言

A_DFA = { ⟨B, w⟩ | B 是一台 DFA 且 B 接受输入串 w }

Sipser 定理 4.1 断言 A_DFA 是可判定的。判定器 M 的做法极简单：从输入 ⟨B, w⟩ 解析出 B 和 w，在 B 上模拟读入 w 的每个符号、跟踪当前状态，读完后若停在接受状态就接受、否则拒绝。

这个过程为什么一定停机是重点：w 的长度有限，DFA 每读一个符号恰好走一步，所以模拟至多走 |w| 步就结束，绝不会循环。这正是「被研究的机器很弱」带来的红利——DFA 没有回头、没有分支、没有无限循环的可能，模拟它必然终止。

本机验证（可选，非承重）：把「接受以 0 结尾的二进制串」的 DFA 直接模拟，`'110'` 判为接受、`'111'` 判为拒绝，与定义一致（Python 3.11.15，2026-07-26 跑通）。这类模拟就是 A_DFA 判定器的核心，实机可运行本身佐证了「过程必定停机」。

### 5.1.3 A_NFA 与 A_REX：接受问题同样可判定

NFA 与正则表达式的接受问题分别编码成

A_NFA = { ⟨B, w⟩ | B 是一台 NFA 且 B 接受输入串 w }

A_REX = { ⟨R, w⟩ | R 是一个正则表达式且 R 生成串 w }

Sipser 定理 4.2 证 A_NFA 可判定、定理 4.3 证 A_REX 可判定。证法用了「化归到已解决的问题」这一常用手法：先把 NFA 用子集构造转成等价 DFA（大主题02 的结论），再调用 A_DFA 的判定器；正则表达式则先转成等价 NFA、再转 DFA，同样归到 A_DFA。

这里体现了一个贯穿全课的思路——**已证明的可判定性可以被复用**。一旦 A_DFA 可判定，凡是「能有效转换成 DFA」的对象，其接受问题都跟着可判定，不必每次从零造判定器。要注意子集构造可能带来状态数指数膨胀，但这只影响效率、不影响「停机」这一可判定性的本质；本章只关心「能不能有一个必停的算法」，不关心它多快（快慢是大主题08 复杂度的话题）。

### 5.1.4 E_DFA：DFA 的空性问题可判定

问「一台 DFA 是否一个串都不接受」被编码成

E_DFA = { ⟨A⟩ | A 是一台 DFA 且 L(A) = ∅ }

Sipser 定理 4.4 证 E_DFA 可判定。判定器不去逐一试无穷多个串（那样不会停），而是把 DFA 看成一张有向图，用可达性判断：从起始状态出发，沿转移边做一遍搜索（BFS/DFS），标记所有可达状态；若没有任何接受状态被标记到，则接受（语言为空），否则拒绝。

关键直觉是「语言非空 ⟺ 存在一条从起始状态到某接受状态的路径」。因为状态数有限，图搜索至多访问每个状态一次就结束，必定停机。这个「把无穷的语言问题转成有穷的图可达问题」的转换，是本章最漂亮的招式之一——它绕开了「枚举无穷多字符串」的陷阱。

本机验证（可选，非承重）：对一台接受状态不可达的 DFA 判为「空」（True）、对「以 0 结尾」的 DFA 判为「非空」（False），与定义一致（2026-07-26 本机跑通）。

### 5.1.5 EQ_DFA：DFA 的等价问题可判定

问「两台 DFA 是否识别同一个语言」被编码成

EQ_DFA = { ⟨A, B⟩ | A、B 都是 DFA 且 L(A) = L(B) }

Sipser 定理 4.5 证 EQ_DFA 可判定。证法是把等价问题化归到刚解决的空性问题：构造一台新 DFA C，让它识别 A 与 B 的对称差（symmetric difference）——即恰好被其中一个接受、不被另一个接受的那些串：

L(C) = ( L(A) ∩ L(B)ᶜ ) ∪ ( L(A)ᶜ ∩ L(B) )

然后对 C 跑 E_DFA 的判定器：L(C) = ∅ 当且仅当两个语言在每个串上答案都一致，即 L(A) = L(B)。

正则语言对补、交、并都封闭（大主题02 的闭包结论），所以对称差仍是正则的，能用一台 DFA（对 A、B 做乘积构造）识别，再复用 E_DFA。对称差为空 ⟺ 两语言无任何分歧 ⟺ 相等，这一逻辑等价是构造的灵魂。特别提醒：这套「靠补与交的封闭性把等价化归到空性」的招式，到了 CFG 上就失灵了（CFL 对交、补不封闭），这正是 5.2 里 EQ_CFG 不可判定的根源，务必记住这个对照。

本机验证（可选，非承重）：用乘积构造检查对称差是否为空——对两台真正等价（都接受空串加「以 0 结尾」）的 DFA 判为相等（True），对一台等价一台空语言的 DFA 判为不等（False），与定义一致（2026-07-26 本机跑通）。验证中还捕捉到一个易错点：两台「都接受以 0 结尾」的 DFA 若一台接受空串 ε 而另一台不接受，则它们在 ε 上分歧、判为不等——说明 ε 的处理是等价判定里常被忽视的边界。

## 5.2 关于上下文无关语言的可判定问题

### 5.2.1 A_CFG：CFG 的成员问题可判定

问「一个上下文无关文法 G 是否生成串 w」被编码成

A_CFG = { ⟨G, w⟩ | G 是一个 CFG 且 G 生成串 w }

Sipser 定理 4.7 证 A_CFG 可判定。天真的做法「枚举 G 的所有派生看有没有生成 w」不可行——派生可能无穷多，永不停机。解决办法是先把 G 转成乔姆斯基范式（CNF，大主题03），在 CNF 下有一条关键的有穷性事实：长度为 n（n ≥ 1）的串，其任何派生**恰好用 2n − 1 步**；长度为 0 的串只需检查是否有 S → ε。于是判定器只要枚举所有长度为 2n − 1 的派生（数量有限），看有没有一条恰好生成 w，有则接受、否则拒绝。

有穷步数是「必定停机」的保证：把「可能无穷的派生搜索」钉死成「有限长度的派生枚举」，正是让成员问题可判定的关键一招，思路和 E_DFA 把无穷语言转成有穷图搜索如出一辙。朴素枚举步数会随文法规模爆炸，实际实现改用 CYK 算法（一种自底向上的动态规划，需要 CNF 文法），在 O(n³) 时间内判成员——CYK 是 A_CFG 判定器的高效实现，可判定性结论不变。

本机验证（可选，非承重）：用 CNF 文法（S→AC | AB，C→SB，A→a，B→b，识别 L = { aⁿbⁿ | n ≥ 1 }）跑 CYK，`ab`/`aabb`/`aaabbb` 判为属于、`aab`/`abb`/`ba` 判为不属于，与定义一致（2026-07-26 本机跑通）。

### 5.2.2 E_CFG：CFG 的空性问题可判定

问「一个 CFG 是否一个串都生成不出」被编码成

E_CFG = { ⟨G⟩ | G 是一个 CFG 且 L(G) = ∅ }

Sipser 定理 4.8 证 E_CFG 可判定。判定器用「自底向上标记可生成终结串的变元」这一思路：先把所有终结符标记为「可生成」，然后反复扫描产生式——只要某条规则 A → U₁U₂…Uₖ 的右部符号全被标记，就把左部变元 A 也标记；如此迭代直到没有新变元被标记为止。最后看起始变元 S 有没有被标记：标记了说明 S 能生成某个终结串（语言非空），没标记则语言为空。

这个过程必定停机，因为变元数有限、每轮至少标记一个新变元否则就停，至多迭代变元个数次。直觉上它在问「从终结符出发，能不能一层层‘长’出起始变元」——能长出来，说明存在合法派生、语言非空。注意 E_CFG 判的是「空不空」，用的是可生成性传播；而 5.2.1 的 A_CFG 判的是「某个具体串生不生成」，用的是有界派生枚举，两者思路不同、别混。

### 5.2.3 每个上下文无关语言都是可判定的

Sipser 定理 4.9 是本节的压轴结论：每个上下文无关语言（CFL）都是图灵可判定的。证法是给定一个 CFL A，取它的一个 CFG G，构造判定器 M_A：输入串 w 时，M_A 直接调用 A_CFG 的判定器判 ⟨G, w⟩ 是否成立，据此接受或拒绝。因为 A_CFG 可判定（必停）、G 固定，所以 M_A 对任何 w 都停机，故 A 可判定。

**不能**简单地说「用 PDA（下推自动机）模拟 w 来判定」。非确定型 PDA 可能有无穷多条计算分支、也可能陷入不消耗输入的循环，直接模拟不保证停机——这恰恰是要绕道 A_CFG（它靠 CNF 的有界派生保证了停机）的原因。这条定理在「语言类的层级」里意义重大：它把 CFL 稳稳地放进「可判定语言」之内，于是我们得到包含链

正则语言 ⊆ 上下文无关语言 ⊆ 可判定语言 ⊆ 图灵可识别语言

每一个包含都是真包含（后续大主题会给出把它们分开的具体语言）。

### 5.2.4 边界对照：EQ_CFG 不可判定

与 5.1.5 的 EQ_DFA 形成尖锐对照：两个 CFG 是否等价的问题

EQ_CFG = { ⟨G, H⟩ | G、H 都是 CFG 且 L(G) = L(H) }

是**不可判定**的（Sipser 将其列于 §5.1 及习题，属大主题06 归约的结论；此处仅作边界提醒）。原因正是 5.1.5 埋下的伏笔：DFA 的等价判定靠「补、交封闭 → 对称差 → 判空」这套化归，而 CFL 对交与补都不封闭（大主题03 的反直觉结论），对称差不再是 CFL，无法用一个 CFG 表示、也就没法化归到 E_CFG。

可判定性对「语言类的封闭性」高度敏感。同一个「等价问题」，在封闭性好的正则语言上可判定、在封闭性差的上下文无关语言上就不可判定。E_CFG（空性）可判定但 EQ_CFG（等价性）不可判定，也提醒「空性可判定」并不自动带来「等价性可判定」——后者严格更难。

#### 来源与时效

- 一手：Sipser 3e (2012) §4.1「Decidable Problems Concerning Context-Free Languages」——A_CFG（Theorem 4.7，经 CNF 下长度 n 串派生恰 2n−1 步）、E_CFG（Theorem 4.8，可生成变元标记法）、每个 CFL 可判定（Theorem 4.9）均定位于此；EQ_CFG 不可判定见 §5.1（大主题06）。
- 交叉一手：Hopcroft–Motwani–Ullman 3e (2007) §7.4「Decision Properties of CFL's」——CFL 的成员测试（HMU 明确给出 CYK 算法，O(n³)）、空性测试；HMU 亦指出 CFG 等价性不可判定。CNF 与 CYK 的先修见 HMU §7.1、§7.4.4。
- 一致性 / 差异：两书结论一致。差异在成员判定的呈现——Sipser §4.1 用「CNF 下 2n−1 步有界派生枚举」讲清可判定性原理，HMU §7.4 直接给 CYK 动态规划讲高效实现；二者互补，本报告两者都列。
- 术语分歧：同 5.1，HMU 的「recursive」= Sipser 的「decidable」。
- 官方大纲交叉：MIT 6.045J syllabus，核实 2026-07-26。
- Python 佐证（可选，非承重）：本机 CYK 判 A_CFG 成员，L = {aⁿbⁿ} 上正负例全部与定义一致（Python 3.11.15，2026-07-26）；佐证非替代证明。

## 5.3 不可判定性与对角化

### 5.3.1 可数集与不可数集

要证明「存在算法解决不了的问题」，先要一套比较无穷集合「大小」的工具。Sipser 定义 4.12 给出：两个集合 A 与 B **同样大**，当且仅当它们之间存在一个一一对应（bijection，即又单射又满射的函数）f: A → B；一个集合 A 是**可数的（countable）**，当且仅当它要么有穷，要么与自然数集 ℕ 同样大。

用一一对应而不是「数个数」来比较大小，是因为无穷集合没法真的一个个数完——只能问「能不能把两边元素完美配对」。能和 ℕ 配对的无穷集合就叫「可数无穷」，直觉上是「能排成一列 a₁, a₂, a₃, … 不重不漏」的集合。看似更大的集合往往仍可数：整数集、有理数集都可数（有理数可用「对角线穿行」排成一列），这常让初学者意外。真正的分水岭在下一个内容项——有些集合大到根本排不成一列，那就是不可数集。

### 5.3.2 对角化方法：实数集不可数

Sipser 定理 4.17 用康托尔的对角化论证（diagonalization）证明：实数集 ℝ 是不可数的。反证：假设 ℝ（或区间内的实数）可数，就能把它们全排成一列 x₁, x₂, x₃, …，每个写成小数展开。现在构造一个新实数 y，让它的**第 i 位小数**故意不同于 xᵢ 的第 i 位（例如 xᵢ 第 i 位是 3 就取 5、否则取 3）。这个 y 与列表中每一个 xᵢ 至少在第 i 位上不同，所以 y 不在列表里——但 y 是个实数，与「列表已含所有实数」矛盾。故 ℝ 不可数。

「对角化」这个名字来自那张想象中的表格：行是 x₁, x₂, …，列是小数第 1 位、第 2 位…，沿主对角线（第 i 个数的第 i 位）逐位取反，造出一个必然「落在表外」的新对象。核心直觉是：任何「声称已列全」的清单，都能被这招造出一个漏网之鱼，从而证明「列不全」。这套「沿对角线制造反例」的技术是本节全部不可判定性结果的共同引擎，5.3.4 证 A_TM 不可判定时会再次原样使用它，务必先在这里把它嚼透。

（对角化为纯符号论证，不涉及可运行的有穷对象；本内容项无实机实证，属方法论推演。）

### 5.3.3 存在图灵不可识别的语言（计数论证）

Sipser 推论 4.18：存在一些语言不是图灵可识别的（甚至不可判定）。论证是一次漂亮的「数数」：一方面，图灵机的个数是**可数的**——每台图灵机都能编码成一个有限字符串，而给定字母表上的有限串全体可数，所以图灵机（以及它们能识别的语言）至多可数。另一方面，某字母表 Σ 上语言的个数是**不可数的**——每个语言是 Σ* 的子集，Σ* 可数无穷，而一个可数无穷集合的全部子集（幂集）不可数（同 5.3.2 的对角化，可与 [0,1] 实数一一对应）。

于是结论逼出来了：识别语言的机器只有可数多台，待识别的语言却有不可数多个，「机器」这边根本不够分——必然存在没有任何图灵机识别的语言。

这一步的威力在于它是**非构造性**的：它只用「数量对不上」就断定「有识别不了的语言存在」，却没指出具体是哪一个。这和 5.3.4 形成互补——推论 4.18 从鸽笼式的计数说「一定有」，定理 4.11 则动手造出一个货真价实的不可判定语言 A_TM。初学者把握一点即可：不可判定/不可识别不是罕见的边角料，从「个数」看它们其实是绝大多数，可判定的语言反而是可数的、稀少的一小撮。

（本内容项为集合基数的符号论证，涉及不可数无穷，无有穷可运行对象，不作实机实证。）

### 5.3.4 A_TM 图灵可识别但不可判定

图灵机的接受问题被编码成

A_TM = { ⟨M, w⟩ | M 是一台图灵机且 M 接受 w }

它是**图灵可识别的**：万能图灵机 U 拿到 ⟨M, w⟩ 后直接模拟 M 跑 w，M 接受则 U 接受。但 Sipser 定理 4.11 证明 A_TM **不可判定**——U 在 M 对 w 不停机时也跟着不停机，无法把「不接受」变成确定的「拒绝」，而这个缺陷是无法修补的。

反证（对角化）：假设存在判定器 H 能判定 A_TM，即

H 接受 ⟨M, w⟩，若 M 接受 w；   H 拒绝 ⟨M, w⟩，若 M 不接受 w

用 H 造一台新机器 D：D 拿到一台机器的编码 ⟨M⟩，先用 H 判「M 会不会接受它自己的编码 ⟨M⟩」，然后**反着来**——H 说接受，D 就拒绝；H 说拒绝，D 就接受。现在把 D 喂给它自己，即在输入 ⟨D⟩ 上运行 D，得到那句著名的自指矛盾：

D 接受 ⟨D⟩   当且仅当   D 不接受 ⟨D⟩

这是逻辑上不可能成立的（一件事不能既真又假），所以假设错误，判定器 H 不存在，A_TM 不可判定。

这正是 5.3.2 对角化的翻版：把「所有图灵机」列成一张表，行是机器 M、列是输入 ⟨M⟩，D 沿对角线（M 在自己编码上的行为）逐一取反，于是 D 的行为与表里每台机器都在「对自己」这一格上不同，造出矛盾。初学者最该带走的一句话是：A_TM 不可判定不是「人类还不够聪明」，而是「假设它可判定会导致自相矛盾」——是原理性的、永久的不可能。这台 A_TM 就是大主题06 用归约证明其他问题（停机问题 HALT_TM 等）不可判定的「源头难题」。

（**不可实证**：A_TM 的不可判定性关于图灵机的一般停机行为，无法用任何会停机的程序检验；停机与不可判定对象在基线机器上不可计算，本内容项只做符号推演，硬标不可实证。）

### 5.3.5 可判定 = 可识别且补可识别；A_TM 的补不可识别

Sipser 定理 4.22 给出可判定性的一个干净刻画：一个语言是**可判定的**，当且仅当它**既是图灵可识别的、其补语言也是图灵可识别的**（后者称为「co-Turing-recognizable，补可识别」）：

A 可判定   ⟺   A 图灵可识别 且 Aᶜ 图灵可识别

正向显然（判定器把「是/否」都给全，正反两面都能识别）；反向的构造很巧：同时并行模拟识别 A 的机器 M₁ 和识别 Aᶜ 的机器 M₂（交替走步），任何串要么属于 A、要么属于 Aᶜ，故其中一台必在有限步内接受——据谁先接受就输出接受/拒绝，于是必定停机、得到判定器。

由此立刻得到 Sipser 推论 4.23：A_TM 的补语言不是图灵可识别的。理由是反证式的组合——A_TM 已知图灵可识别（5.3.4）；若它的补也图灵可识别，由定理 4.22 就推出 A_TM 可判定，与定理 4.11 矛盾。所以补 A_TM 图灵不可识别。

这条定理给了初学者一张清晰的「难度地图」：可判定语言 = 正反都可识别的语言，是最好对付的一档；只可识别、补不可识别的语言（如 A_TM）严格更难；正反都不可识别的语言（5.3.3 保证存在）最难。它也解释了「可识别」与「可判定」的实质差距——差就差在「补是否也可识别」这一个条件上。对照 HMU 的术语，本定理即「一个语言递归（recursive）当且仅当它和它的补都是递归可枚举（recursively enumerable, RE）的」，这是可计算性理论里最经典的刻画之一。

（**不可实证**：本内容项及推论 4.23 关于图灵可识别/不可识别语言的一般性质，涉及不可判定/不可识别对象，基线机器上不可计算，只做符号推演，硬标不可实证。定理中「并行模拟两台识别器」的思想在可判定语言上可运行，但用来推翻 A_TM 可判定的部分是纯反证，不构成实证。）
