**计算理论是用「集合与函数」描述对象、用「证明」确认结论的学科**。字符串、语言、自动机、判定问题，最终都被还原成集合、序列、关系、函数这几样基本积木；而「某语言是不是正则的」「某问题能不能被机器判定」这类论断，靠的不是举例说服，而是严格证明。本章把这些积木和三种主力证明方法讲清、够用即可，不做离散数学的纵深展开。

## 1.1 集合、序列、元组、函数、关系

### 1.1.1 集合与基本集合运算

集合（set）是**一组对象（称为元素或成员）的无序汇集**，同一元素出现多次与出现一次视为相同，元素之间也没有先后。用

A = {7, 21, 57}

这样的花括号列举法，或用「性质描述法」

A = { n | n 是大于 5 的整数 }

来指定一个集合。基本运算有并、交、差、补：

A ∪ B = { x | x ∈ A 或 x ∈ B }

A ∩ B = { x | x ∈ A 且 x ∈ B }

A − B = { x | x ∈ A 且 x ∉ B }

集合 A 的幂集（power set）是 A 全部子集构成的集合，若 A 有 n 个元素则其幂集有

2^n

个元素。

初学者要抓住「集合只关心成员资格」这一点：判断两个集合是否相等，只看它们是否含有完全相同的元素，与写法、顺序、重复都无关，所以 {1,2,3}、{3,2,1}、{1,1,2,3} 是同一个集合。空集记作 ∅，是唯一没有任何元素的集合，它是任何集合的子集。子集（⊆）允许相等（A ⊆ A 恒成立），真子集（⊊）则要求严格更小。幂集为什么是 2^n：给 n 个元素每个都做「选或不选」两种独立决定，共 2×2×…×2 = 2^n 种选法，每种对应一个子集。sympy 实机核对 A = {1,2,3} 时并集 {1,2,3,4}、交集 {2,3}、差集 {1}，幂集大小 8 = 2³，与上述定义一致（2026-07-26 本机 sympy 1.14.0 跑通）。

在计算理论里，集合是最底层的语言：字母表是符号的集合，语言是字符串的集合，判定问题最终被编码成「某个串是否属于某个集合」。所以把集合这层地基打牢，后面一切都顺。

### 1.1.2 序列与元组

序列（sequence）是**一组对象按确定顺序排成的列表**；与集合相反，序列讲究顺序、也允许重复。有限长的序列称为元组（tuple），长度为 k 的元组叫 k 元组（k-tuple），2 元组特称有序对（ordered pair）。元组用圆括号写：

(7, 21, 57)

两个集合的笛卡尔积（Cartesian product / cross product）是把第一个集合的元素与第二个集合的元素两两配成有序对得到的集合：

A × B = { (a, b) | a ∈ A 且 b ∈ B }

若 A 有 m 个元素、B 有 n 个元素，则 A × B 有 m·n 个元素。

序列和集合最大的区别就在「顺序」和「重复」：(7,21,57) 与 (57,21,7) 是不同的元组，但 {7,21,57} 与 {57,21,7} 是同一集合。理解笛卡尔积的最简单办法是想象一张乘法表——A 的每个元素占一行、B 的每个元素占一列，格子里填 (行,列)，格子总数就是 m·n。可以对多个集合连续做积，A × A × … × A（k 次）记作 Aᵏ，它的元素正是 A 中元素组成的所有 k 元组。

这条工具在后面无处不在：自动机的转移函数以「(状态, 输入符号)」这样的有序对为输入，图的边是顶点的有序对或无序对，判定问题里的输入 ⟨B, w⟩ 本质也是元组。顺序在这里是本质信息，不能像集合那样随意打乱。

### 1.1.3 函数与定义域、值域

函数（function，也叫映射 mapping）是**一种把每个输入对应到唯一一个输出的关系**：只要输入相同，输出就一定相同，绝不会一个输入配出两个不同结果。若函数 f 的输入取自集合 D、输出落在集合 R 中，记作

f : D → R

其中 D 称为定义域（domain）。这里有一处**术语分歧要显式标注**：Sipser 3e 把上式中的 R（即声明的目标集合，多数教材称为「陪域 / codomain」）直接叫作「range（值域）」；而 Rosen 等离散数学教材及 Hopcroft–Motwani–Ullman 的习惯里，「range（值域/像）」特指真正被取到的输出集合 { f(x) | x ∈ D }，它只是陪域的子集。读 Sipser 时按其定义理解，跨书阅读时注意这个词在不同书里指代不同。

多参数函数把定义域取成笛卡尔积，例如二元运算 f : A × A → A 接受一对输入。判断「是不是函数」的关键只有一条：每个定义域元素**恰好**对应一个输出——不能漏（每个输入都要有值）、也不能多（一个输入不能有两个值）。反例：把每个实数映到「其平方根」不是从实数到实数的函数，因为负数无输出、正数有两个根。

函数是计算理论刻画「计算」本身的核心：一台机器做的事，抽象来看就是把输入串映到输出（或映到「接受/拒绝」）；后面的「可计算函数」「归约函数」都建立在这个最朴素的函数概念上。

### 1.1.4 一对一、映上与一一对应

在函数的基础上，按「输出这一侧的覆盖情况」给函数分三种性质。一对一（one-to-one，即单射 injective）指**不同的输入给出不同的输出**，即

若 a ≠ b，则 f(a) ≠ f(b)

映上（onto，即满射 surjective）指**陪域里的每个元素都被某个输入取到**，即

对每个 y ∈ R，都存在 x ∈ D 使 f(x) = y

既一对一又映上的函数称为一一对应（bijection，也叫对应 correspondence）。

用「不撞车、不落空」来记：一对一 = 不同输入不撞到同一个输出（无碰撞）；映上 = 陪域里没有落空的元素（全覆盖）；一一对应 = 既不撞车又不落空，于是定义域和陪域的元素能完美两两配对。最小例子：f(x)=2x 从整数到整数是一对一（不同数翻倍仍不同）但不映上（奇数取不到）；f(x)=x+1 从整数到整数则是一一对应。

一一对应是计算理论里判断「两个无限集合是否一样大」的唯一严格标尺——若能在两集合间建立一一对应，就说它们大小（基数）相同。这一点在 1.4 与后续「对角化」中反复用到：正是「自然数与所有语言之间建不出一一对应」，才逼出了「必然存在机器识别不了的语言」。

### 1.1.5 关系与等价关系

关系（relation）泛指**元组的集合**；最常用的二元关系（binary relation）是有序对的集合，即某个笛卡尔积 A × A 的子集。写 a R b 表示有序对 (a,b) 属于该关系。一个二元关系 R（定义在集合上）若同时满足三条性质，就称为等价关系（equivalence relation）：

自反性（reflexive）：对每个 x，有 x R x

对称性（symmetric）：若 x R y，则 y R x

传递性（transitive）：若 x R y 且 y R z，则 x R z

等价关系的作用是把一个集合**划分（partition）成互不相交的等价类**——凡是彼此等价的元素归到同一类，不同类之间没有交集，并起来又恰好是整个集合。最贴切的直觉是「按某种标准分组」：整数按「除以 3 的余数相同」分成余 0、余 1、余 2 三类，这个「同余」关系就是等价关系（自反：任何数与自己同余；对称、传递也显然）。反例：「小于」关系不是等价关系，因为它不自反（没有 x < x）也不对称。

等价关系在本课的高光时刻是 Myhill–Nerode 定理（大主题02 延伸内容）：它用「字符串之间的一种等价关系」把语言的正则性刻画得干净利落，并给出最少状态 DFA。在这里先把三条性质和「划分成等价类」的直觉记牢即可。

## 1.2 图、字符串与语言、布尔逻辑

### 1.2.1 图的基本术语

图（graph）是**由一组顶点（vertex/node）和一组连接顶点的边（edge）组成的结构**。无向图（undirected graph）的边是两个顶点的无序对（{u,v} 与 {v,u} 相同）；有向图（directed graph）的边是有序对（画成带箭头的弧，(u,v) 与 (v,u) 不同）。一个顶点的度（degree）是与它相连的边数；有向图区分入度（指入的边数）与出度（指出的边数）。

初学者可以把图想成「地图」：顶点是城市，边是道路，无向边是双向路、有向边是单行道。若从某顶点出发沿边能走到另一顶点，中间经过的顶点边序列叫路径（path），起点终点相同且不重复经过其他顶点的路径叫回路/圈（cycle）；任意两点间都有路径的图称为连通图（connected）；有向图里若不存在任何有向圈，则称有向无环图（DAG）。

图在计算理论里既是被研究的对象（图上的判定问题，如 PATH、连通性），也是描述工具本身——有限自动机、下推自动机、图灵机的「状态图」本质就是有向图：顶点是状态，带标签的有向边是转移。先把顶点/边/度/路径这几个词认熟，后面读状态图就不费力。

### 1.2.2 字母表、字符串与 Σ*

字母表（alphabet）是**任意有限、非空的符号集合**，通常记作 Σ 或 Γ。字符串（string，也叫 word）是**取自某字母表的有限长符号序列**。字符串 w 的长度记作 |w|，长度为 0 的字符串称为空串（empty string），记作 ε。字母表 Σ 上所有字符串（含空串）构成的集合记作

Σ*

若限定长度恰为 k，则记作 Σᵏ，于是

Σ* = Σ⁰ ∪ Σ¹ ∪ Σ² ∪ …

其中 Σ⁰ = {ε}。两个字符串 x、y 的连接（concatenation）记作 xy，即把 y 接在 x 之后；x 自身连接 k 次记作 xᵏ。

字母表必须有限且非空，但字符串可以任意长（只要有限）；Σ* 本身则是无限集合（含所有有限长串）。别把 ε（空串，长度 0 的字符串）和 ∅（空集，一个不含任何元素的集合）混为一谈——{ε} 是含一个元素的集合，∅ 是空集，二者不同。最小例子：Σ = {0,1} 时，Σ¹ = {0,1}，Σ² = {00,01,10,11}，"01" 与 "10" 是不同字符串（顺序有别），|011| = 3，011·01 = 01101。

字符串是自动机的「食物」——机器逐符号读入一个字符串并决定接受还是拒绝。Σ* 则是「所有可能输入」的全集，后面语言正是从 Σ* 里挑出来的子集。

### 1.2.3 语言的定义

语言（language）是**某字母表上字符串的集合**，即

L ⊆ Σ*

也就是说，任何 Σ* 的子集都是一个（Σ 上的）语言。空语言（不含任何字符串）记作 ∅，只含空串的语言 {ε} 与它不同。

这是全课最核心的抽象之一：把「一个计算问题」重新表述成「一个语言（= 一个字符串集合）」，于是「机器解决问题」就变成「机器判定一个串是否属于某语言」。举例，「判断一个二进制串是否表示偶数」这个问题，对应语言

L = { w ∈ {0,1}* | w 以 0 结尾 }

一台机器「解决」它，就是对任意输入串正确回答「属于 L 吗」。这个「问题即语言、解题即成员判定」的视角，是从大主题02 一直贯穿到复杂度的统一框架，务必在这里就建立起来。

为什么非要绕这一圈？因为把五花八门的问题统一成「字符串集合」后，就能用同一套机器（自动机、图灵机）和同一套工具（闭包、泵引理、归约）去研究它们，而不必为每个问题另起炉灶。

### 1.2.4 布尔逻辑与连接词

布尔逻辑（Boolean logic）是**关于真（TRUE，记 1）与假（FALSE，记 0）两个值的运算系统**。基本连接词有：非（NOT，¬）、与（AND，∧）、或（OR，∨），以及派生的异或（XOR，⊕）、蕴含（→）、等价/双条件（↔）。它们由真值表定义，例如与、或、非：

¬1 = 0，  ¬0 = 1

1 ∧ 1 = 1，其余 ∧ 组合为 0

0 ∨ 0 = 0，其余 ∨ 组合为 1

蕴含 p → q 只在「p 真而 q 假」时为 0，其余为 1。

这些连接词直觉上对应自然语言：∧ 是「并且」（两者都真才真），∨ 是「或者」（至少一个真就真，是包含性或），¬ 是「取反」。最容易被误解的是蕴含 →：它在前件 p 为假时一律为真（所谓「空真 / vacuously true」），例如「如果 2>3，那么天是绿的」整句为真，因为前提本就不成立。记法：把 p→q 读成「p 不成立，或者 q 成立」，即它等价于 ¬p ∨ q，就不会被「空真」绊住。这些连接词是写形式定义、证明中「若…则…」「当且仅当」的基本语法。

### 1.2.5 德摩根律与常用等价

德摩根律（De Morgan's laws）刻画**否定如何穿过 ∧ 和 ∨**：否定一个合取等于否定各分量再取析取，否定一个析取等于否定各分量再取合取：

¬(p ∧ q) = ¬p ∨ ¬q

¬(p ∨ q) = ¬p ∧ ¬q

配套常用的还有双重否定 ¬¬p = p、分配律、以及蕴含改写 (p → q) = (¬p ∨ q)。

「并非（既下雨又刮风）」等于「要么没下雨，要么没刮风」；「并非（下雨或刮风）」等于「既没下雨也没刮风」。取反时「∧ 与 ∨ 互换、每一项各自取反」是关键口诀。它在集合上有完全平行的版本（补集穿过交并时交并互换），这解释了为什么正则语言、可判定语言对「补」的闭包证明里常用到它。sympy 布尔化简核对：¬(p∧q) 与 ¬p∨¬q 化简后相等、¬(p∨q) 与 ¬p∧¬q 化简后相等（本机 sympy 1.14.0，2026-07-26 跑通，两式均返回等价）。

这条律在后面证明「若某语言类对交与补都闭合，则对并也闭合」之类的结论时是直接工具——把并写成「补、交、再补」即可，德摩根律保证了正确性。

## 1.3 定义、定理与证明

### 1.3.1 数学命题与定义的作用

在本学科里，定义（definition）**精确地规定一个对象或概念是什么**；有了定义，一个数学命题（mathematical statement）才能被明确地判定真或假。定义追求「无歧义」——把对象的所有相关属性钉死，使得任何人依定义都能一致地判断某物是否属于该概念。

数学定义不是「大致描述」，而是「操作性标准」。比如「正则语言」被定义为「某个有限自动机能识别的语言」——凭这条定义，要证明某语言正则，就去造一台自动机；要证明它不正则，就得说明任何自动机都识别不了它。定义决定了后续所有证明的「靶子」长什么样。术语上还需分清：一个尚未确认真假的陈述叫「命题/断言（statement）」，确认为真并写出证明后才升格为定理等。

把定义读准，是读懂后面每个定理的前提。很多初学者证明卡壳，根源在于没吃透定义，而不是不会推理。

### 1.3.2 定理、引理与推论

定理（theorem）是**一个已被证明为真的重要数学命题**。引理（lemma）是**本身不算主要结论、但用来支撑证明其他定理的辅助命题**；推论（corollary）是**从某定理（几乎立即）推出的附带结论**。三者在「是否已证明为真」这一点上没有区别，区别只在「地位和用途」。

定理是主菜，引理是备料（为做主菜先切好的配菜，如泵引理常作为「证明某语言不正则」的备料），推论是主菜端上后顺手多得的一小碟（定理成立后几乎白捡的结论）。作者把命题冠以哪个名称，更多是为组织行文、突出重点，而非表示可信度不同——它们都必须有证明。

认得这套词，读教材时就能快速判断「这条是要重点记的主结论，还是过渡用的工具」，抓住阅读节奏。

### 1.3.3 证明是什么、在本学科中的作用

证明（proof）是**一段令人信服的逻辑论证，说明某命题为真**；它必须是「无懈可击」的——从公认为真的前提出发，每一步都由逻辑规则或已证结论合法推出，最终抵达结论。在计算理论中，证明不是可选的修辞，而是唯一被接受的「确认真理」的手段。

举几个例子成立，**不构成**证明（除非命题本就只涉及有限个情形）。计算理论研究的对象（语言、机器）大多是无限的——一台自动机要对「无限多个输入串」都正确，「某语言不正则」是对「无限多台候选自动机」的断言——测试再多例子也盖不全无限，只有证明能。反过来，要推翻一个「对所有…成立」的命题，一个反例（counterexample）就够（见 1.4）。

Sipser §0.3 还给出实用的「找证明」建议：先把定义逐字展开、试小例子建立直觉、再考虑用哪种证明策略（1.4 的三种）。本课与离散数学的边界（B5）在此明确——这里把「证明是什么、怎么读怎么写」讲够用，不深入离散数学的证明理论。

定义给「靶子」，定理是「命中的结论」，证明是「命中的过程」，三者缺一不可。读定理时养成「它的证明用了哪条定义、哪种方法」的追问习惯，理解会快很多。

## 1.4 证明类型

### 1.4.1 构造性证明

构造性证明（proof by construction）通过**实际造出一个满足命题所要求性质的对象**来证明「存在这样的对象」。要证「存在某种东西」，最直接的办法就是把它做出来给你看。

要证「存在能识别语言 L 的有限自动机」，就动手写出这台自动机的五元组并验证它确实识别 L——对象一旦造出，存在性不言自明。计算理论里大量等价性结果都是构造性的：把 NFA 转成等价 DFA（子集构造）、把 CFG 转成等价 PDA，都是「给定一个对象、构造出另一个对象并证明二者等价」。

构造性证明的好处是「不仅证明存在，还给出了怎么得到」，往往能直接读成一个算法。初学者写这类证明时要记得两步都做全：既要给出构造，又要证明造出来的东西确实满足要求，缺了后半段就不完整。

### 1.4.2 反证法（含归谬）

反证法（proof by contradiction）先**假设待证命题为假，再由此推出一个逻辑上不可能成立的矛盾，从而断定原假设不成立、原命题为真**。其骨架是：欲证 P，先设 ¬P，推导得到「Q 且 ¬Q」这样的矛盾，于是 ¬P 不成立，故 P 成立。

经典例子是「√2 是无理数」：假设它有理、可写成最简分数 a/b，推导出 a、b 都是偶数，与「最简（已约分）」矛盾，故假设错误、√2 无理。计算理论里最重要的应用是对角化（大主题05）——先假设「存在一台图灵机能判定 A_TM」，构造出一个自相矛盾的输入使它「接受当且仅当不接受」，矛盾表明这样的机器不存在，即 A_TM 不可判定。

初学者易混「反证法」与「反例」：反证法是一整套「假设反面→导出矛盾」的推理，用于证明一个全称或存在命题成立；反例只是举出一个具体对象来推翻一个「对所有…都成立」的断言（如要否证「所有素数都是奇数」，举 2 即可）。二者都靠「矛盾/反例」但用途不同，别混。另需分清与「反证法」相近的「逆否证明（contrapositive）」：欲证 p→q，改证等价的 ¬q→¬p，这是改换命题形式，不引入矛盾，属另一手法。

### 1.4.3 数学归纳法

数学归纳法（proof by induction）用来**证明「某性质 P(n) 对所有自然数 n（从某个起点起）都成立」**。它分两步：

基础步（basis）：证明 P 在起点成立，如 P(1)

归纳步（induction step）：假设 P(k) 成立（归纳假设），据此证明 P(k+1) 也成立

两步都完成后，即可断定 P(n) 对所有 n ≥ 起点成立。

基础步 = 推倒第一块；归纳步 = 保证「只要第 k 块倒，第 k+1 块必倒」；两者合起来，所有骨牌都会倒。最小例子是求和公式

1 + 2 + … + n = n(n+1)/2

基础步 n=1 时左边 1、右边 1·2/2=1 成立；归纳步设对 k 成立，则 1+…+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k+2)/2，正是 n=k+1 的形式，得证。本机对 n=1..20 数值逐一核对该公式两边相等（sympy/Python 1.14.0，2026-07-26 跑通），佐证归纳结论（数值核对是佐证，非替代证明本身）。

初学者最常见的错误是漏掉基础步，或在归纳步里「偷偷假设了要证的结论」。归纳法在计算理论里无处不在：证明关于「所有字符串」「所有状态数」「计算步数」的性质，几乎都靠对长度或步数归纳。还有一种等价而好用的变体——最小反例法（也叫强归纳的反面用法）：假设命题有反例，取「最小的反例」，再推出存在更小的反例或直接矛盾，从而否定反例存在。它与标准归纳等价，只是在某些证明里更顺手。
