## 1.1 命题逻辑与联结词

### 1.1.1 命题是什么

命题（proposition）是一个**有确定真值（要么真 T、要么假 F，二者必居其一且只居其一）的陈述句**。"2 + 2 = 4"是命题（真），"北京是中国的首都"是命题（真），"1 > 2"是命题（假）。

判断"是不是命题"的关键是：它必须是**能判定真假的陈述**。疑问句（"现在几点？"）、命令句（"关门！"）、感叹句都不是命题，因为它们没有真假可言。含未定变量的句子如"x + 1 = 3"也**不是命题**——真假取决于 x，在 x 未定前无法判定；这种句子叫"命题函数/谓词"，是 1.3 节的主角。悖论句如"这句话是假的"也不是命题，因为它无法自洽地被赋一个真值。

初学者最容易踩的坑是把"我不知道真假"当成"没有真值"。"宇宙中存在外星生命"是一个合法命题——它客观上要么真要么假，只是我们暂时不知道答案；"有没有确定真值"和"我们知不知道那个值"是两回事。约定用小写字母 p、q、r 表示命题变量（propositional variable），用 T（或 1）表示真、F（或 0）表示假。

### 1.1.2 真值表是什么

真值表（truth table）是**把一个复合命题在其组成命题所有可能真值组合下的结果逐行列出的表**。n 个命题变量就有

2^n

种真值组合，因此真值表有 2^n 行。

真值表是命题逻辑的"计算器"：它把"联结词到底是什么意思"用穷举的方式钉死，不留模糊。任何关于命题逻辑的断言（某公式是不是重言式、两公式是否等价、某论证是否有效），原则上都能靠"把真值表列全、逐行检查"来机械判定——这也是为什么命题逻辑是**可判定的**。代价是行数随变量数指数增长（10 个变量就是 1024 行），所以实践中我们更爱用等价律化简（见 1.2），真值表则是最后的"真理仲裁者"。

约定按变量固定顺序、从全 F 到全 T（或看成二进制递增）枚举各行，保证不重不漏。下面各联结词小节都会给出各自的真值表。

### 1.1.3 否定（NOT）

否定是**一元**联结词：命题 p 的否定记作

¬p

读作"非 p"，当 p 为真时 ¬p 为假，当 p 为假时 ¬p 为真。真值表：

    p    ¬p
    T    F
    F    T

否定就是"把真假翻转"。直觉上它对应自然语言的"不"："p = 今天下雨"，则"¬p = 今天不下雨"。

自然语言的否定常常不精确。"所有学生都及格了"的否定**不是**"所有学生都没及格"，而是"存在一个学生没及格"——这涉及量词的否定（见 1.3.5），初学阶段务必分清"整体否定"和"逐个取反"的差别。另外 ¬ 有时也写成 ~p 或 !p（编程语言里常见 `!`），Rosen 用 ¬。

### 1.1.4 合取（AND）

合取是二元联结词：p 与 q 的合取记作

p ∧ q

读作"p 且 q"，**当且仅当 p、q 都为真时**为真，否则为假。真值表：

    p  q   p∧q
    T  T    T
    T  F    F
    F  T    F
    F  F    F

合取对应自然语言的"并且/而且"。直觉：要让"下雨并且刮风"为真，必须两件事同时成立，任一不成立整句就假。这与日常直觉一致，是最好懂的联结词。编程里对应 `&&`（短路与）或按位 `&`。

### 1.1.5 析取（OR）与异或

（包含）析取是二元联结词：p 与 q 的析取记作

p ∨ q

读作"p 或 q"，**当且仅当 p、q 都为假时**才为假，只要至少一个为真就为真。真值表：

    p  q   p∨q
    T  T    T
    T  F    T
    F  T    T
    F  F    F

这里的关键、也是初学者最大的坑：数学里的"或"是**相容（包含性）或**——"两者都成立"也算真。日常语言的"或"常是"排他"的（"你要茶还是咖啡"通常指选一个），但逻辑默认取包含义。

与之相对的是异或（exclusive or）：

p ⊕ q

**当且仅当 p、q 真值不同时**为真、相同时为假：

    p  q   p⊕q
    T  T    F
    T  F    T
    F  T    T
    F  F    F

异或对应"恰好一个成立"。记住区别：p ∨ q 只在"全假"时假，p ⊕ q 在"全假或全真"时假。编程里 `|`/`||` 是包含或，`^` 是异或。

### 1.1.6 条件（蕴含，IF-THEN）

条件（conditional，也叫蕴含 implication）是二元联结词：记作

p → q

读作"如果 p 则 q"，其中 p 叫前件（hypothesis/前提），q 叫后件（conclusion/结论）。它**只在"前件真而后件假"时为假，其余三种情况全为真**。真值表（本机 sympy 实测，见 1.1.9）：

    p  q   p→q
    T  T    T
    T  F    F
    F  T    T
    F  F    T

蕴含是命题逻辑里最反直觉、最需要掰开讲的联结词。核心难点是**"前件为假时整句为真"**（后两行），这叫"空真（vacuously true）"。

把 p → q 看成一句**承诺**："如果你考满分（p），我就请你吃饭（q）"。什么时候我算"违背承诺"（整句为假）？只有一种情况：你考了满分（p 真）我却没请（q 假）。如果你没考满分（p 假），那不管我请不请，我都没违背这句承诺——所以这两行整句判"真"。这正是"前件假则蕴含真"的来由：承诺没被触发，就没被违背。

p → q **不**表示 p 导致 q、也不表示 q → p。围绕 p → q 有三个衍生条件命题，务必分清（下面 ↔ 表示逻辑等价，见 1.2）：

逆命题（converse）：q → p

否命题（inverse）：¬p → ¬q

逆否命题（contrapositive）：¬q → ¬p

其中只有**逆否命题与原命题逻辑等价**（p → q 与 ¬q → ¬p 同真同假，1.1.9 已用 sympy 核实），逆命题和否命题都不与原命题等价（但逆与否彼此等价）。初学者常错误地由"如果下雨则地湿"推出"如果地湿则下雨"（这是逆命题，未必成立——洒水车也能弄湿地）。此外常用表述"p 是 q 的充分条件""q 是 p 的必要条件"都指 p → q。

### 1.1.7 双条件（当且仅当）

双条件（biconditional）记作

p ↔ q

读作"p 当且仅当 q"（p if and only if q，缩写 iff），**当且仅当 p、q 真值相同时**为真。真值表（本机 sympy 实测）：

    p  q   p↔q
    T  T    T
    T  F    F
    F  T    F
    F  F    T

双条件表达"两件事真假绑定、同进同退"。它等价于两个方向的蕴含合起来：

p ↔ q 与 (p → q) ∧ (q → p) 逻辑等价

这解释了数学证明里"证明 A 当且仅当 B"为什么要分两步：先证 A → B（充分性），再证 B → A（必要性）。注意别把 ↔ 和 ⊕ 搞反：双条件在"真值相同"时为真，异或在"真值不同"时为真，二者正好互为否定（p ↔ q 与 ¬(p ⊕ q) 等价）。

### 1.1.8 优先级与复合命题

把命题变量用联结词层层组合就得到复合命题（compound proposition），如 (p ∧ q) → ¬r。为了少写括号，约定联结词优先级（从高到低）：

¬  >  ∧  >  ∨  >  →  >  ↔

例如 ¬p ∧ q 读作 (¬p) ∧ q 而非 ¬(p ∧ q)；p ∨ q → r 读作 (p ∨ q) → r。

**优先级只是省括号的约定，拿不准就加括号**，尤其是 → 和 ↔ 这些低优先级的，写清楚永远不算错。Rosen 特别提醒 → 是右结合、且优先级低于所有对称联结词。复合命题的真值完全由各原子命题真值和真值表逐层算出，这正是 1.1.2 说的"逻辑是关于真假的代数"。

## 1.2 命题等价与范式

### 1.2.1 逻辑等价

两个复合命题若**在所有真值组合下真值都相同**，就称它们逻辑等价（logically equivalent），记作

p ≡ q  （等价地：p ↔ q 是重言式）

Rosen 用 ≡（也写 ⇔）表示等价关系。注意 ≡ 是"关于公式的元层面判断"，↔ 是"对象层面的一个联结词"；p ≡ q 的准确含义是"p ↔ q 恒为真"。

判断等价的最基础方法就是**列两个公式的真值表，逐行比对是否完全一致**。等价是逻辑化简的根基：既然等价公式真值处处相同，就可以在任何上下文里互相替换（等价替换），把复杂公式换成简单的等价形式，而不改变其逻辑含义——这与代数里"用恒等式化简表达式"完全类比。

p → q 与 ¬p ∨ q 逻辑等价（1.2.4 会用它把蕴含"翻译"成析取，1.2.7 有 sympy 核实）。

### 1.2.2 重言式、矛盾式与可满足性

一个复合命题若**无论组成命题真值如何都为真**，称重言式（tautology，也叫永真式），如

p ∨ ¬p

若**无论如何都为假**，称矛盾式（contradiction，也叫永假式），如

p ∧ ¬p

既非重言也非矛盾（即至少有一行真、也至少有一行假）称可能式/偶然式（contingency）。

一个相关但不同的概念是可满足性（satisfiability）：若**存在至少一种真值指派使公式为真**，就称该公式可满足（satisfiable），否则不可满足（unsatisfiable，等价于矛盾式）。

这三组词是后续一切的地基。为什么重要：p ≡ q 成立 ⟺ p ↔ q 是重言式；一个论证有效 ⟺ 某个对应的蕴含式是重言式（见 1.4）。而"可满足性"正是计算机科学里大名鼎鼎的 SAT 问题的核心——判断一个命题公式是否可满足是第一个被证明为 NP 完全的问题（深挖归 L3-05/算法课，此处只点接口）。易错点：重言式一定可满足，但可满足远不等于重言式（可满足只要求"有一行真"，重言式要求"每行都真"）。

### 1.2.3 关键等价律（含德摩根律）

命题逻辑有一批像代数恒等式一样反复使用的等价律。以下均为重言式意义下的等价（T 表重言式、F 表矛盾式）：

恒等律：p ∧ T ≡ p ，  p ∨ F ≡ p

支配律：p ∨ T ≡ T ，  p ∧ F ≡ F

幂等律：p ∨ p ≡ p ，  p ∧ p ≡ p

双重否定律：¬(¬p) ≡ p

交换律：p ∧ q ≡ q ∧ p ，  p ∨ q ≡ q ∨ p

结合律：(p ∧ q) ∧ r ≡ p ∧ (q ∧ r) ，  (p ∨ q) ∨ r ≡ p ∨ (q ∨ r)

分配律：p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r) ，  p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)

德摩根律：¬(p ∧ q) ≡ ¬p ∨ ¬q ，  ¬(p ∨ q) ≡ ¬p ∧ ¬q

吸收律：p ∨ (p ∧ q) ≡ p ，  p ∧ (p ∨ q) ≡ p

否定律（互补律）：p ∨ ¬p ≡ T ，  p ∧ ¬p ≡ F

其中**德摩根律**（De Morgan's laws）最值得单独记牢：**否定一个合取/析取，等于"取反每一部分、再把 ∧ 与 ∨ 对调"**。直觉：说"不是（下雨且刮风）"，等于说"要么没下雨、要么没刮风"（只要有一件没发生，"两件都发生"就被否定了）。它在编程里天天用到——`!(a && b)` 等价于 `!a || !b`，改写条件时极常见。

分配律里 ∧ 对 ∨ 分配、∨ 对 ∧ 也分配（这点和普通算术不同，算术里加法不对乘法分配）；德摩根律取反后**一定要对调联结词**，只取反不换符号是最常见错误。这些律本机已用 sympy 核实（见 1.2.7）。

### 1.2.4 蕴含的等价改写与逆否

含 → 和 ↔ 的公式常先"翻译"成只含 ¬、∧、∨ 的形式再处理。关键改写：

p → q ≡ ¬p ∨ q

p → q ≡ ¬q → ¬p     （逆否，与原式等价）

¬(p → q) ≡ p ∧ ¬q     （蕴含的否定）

p ↔ q ≡ (p → q) ∧ (q → p)

第一条是最常用的"去箭头"工具：把 p → q 换成 ¬p ∨ q 后，德摩根、分配律等就都能用上了。第三条（蕴含的否定）解释了"如何反驳一个'如果……则……'的断言"——要否定"如果 p 则 q"，就得**举出 p 成立但 q 不成立的例子**（p ∧ ¬q），这正是找反例的形式依据（见 1.5.3）。

逆否等价（第二条）是证明技术"逆否证明法"的理论基础（1.5.3）：想证 p → q 时，改证等价的 ¬q → ¬p 有时更容易。

### 1.2.5 逻辑化简

利用 1.2.3–1.2.4 的等价律做等价替换、把公式改写成更简形式，叫逻辑化简（simplification）。它和代数化简是一回事：一步步用恒等式替换，直到不能再简。

最小例子（吸收律的一步化简）：

p ∨ (p ∧ q) ≡ p

再看一个用分配律 + 互补律 + 恒等律的例子：

(p ∧ q) ∨ (p ∧ ¬q) ≡ p ∧ (q ∨ ¬q) ≡ p ∧ T ≡ p

两例本机 sympy 均化简为 p（见 1.2.7）。化简的价值：等价公式逻辑含义不变，但更短的公式更易读、判等价/判重言更快，工程上还对应更省的电路/更快的条件判断。易错点：每一步都必须是**等价**替换（用的必须是等价律，不能是单向蕴含），否则会悄悄改变含义。

### 1.2.6 范式（DNF 与 CNF）

任意命题公式都能改写成两种标准形式之一（"范式"normal form）：

析取范式 DNF（disjunctive normal form）：形如"若干合取项用 ∨ 连起来"，每个合取项是一些文字（变量或其否定）的 ∧，如 (p ∧ ¬q) ∨ (¬p ∧ r)。

合取范式 CNF（conjunctive normal form）：形如"若干析取项用 ∧ 连起来"，如 (p ∨ ¬q) ∧ (¬p ∨ r)。

"文字（literal）"指一个命题变量或它的否定。关键事实：**每个复合命题都逻辑等价于某个 DNF、也等价于某个 CNF**（可从真值表直接读出，Rosen §1.3 有构造法）。

范式的意义在于给公式一个"标准长相"，便于机械处理和比较。CNF 尤其是 SAT 求解器的标准输入格式，DNF 则便于直接看出"哪些真值组合让公式为真"。本机 sympy 实测 (p → q) ∧ r 的两种范式（见 1.2.7）：DNF 为 (q ∧ r) ∨ (r ∧ ¬p)，CNF 为 r ∧ (q ∨ ¬p)。

边界说明（本课范围）：**布尔函数化简、卡诺图、门电路属 L2-02**（数字逻辑），本节只在"命题逻辑层"介绍范式概念本身，不做电路化简的工程展开；布尔代数的代数层（DNF/CNF 作为布尔函数表示、对偶原理）在本课大主题 11 另有专门章节，此处点到接口即止，不重复深挖。

## 1.3 谓词、量词与嵌套量词

### 1.3.1 谓词与命题函数

谓词（predicate）是**含有变量、代入具体值后才变成命题的陈述**。例如"x > 3"记作 P(x)，它本身不是命题（真假待定），但 P(4) = "4 > 3"（真）、P(2) = "2 > 3"（假）就是命题了。P 叫谓词，x 叫变量；这样的 P(x) 也叫命题函数（propositional function）。

谓词把命题逻辑的表达力大大扩展。命题逻辑只能整句处理"苏格拉底会死"，无法表达"所有人都会死"这种对**一整类对象**的断言，因为它看不见句子内部的"对象—性质"结构。谓词逻辑（一阶逻辑）引入变量和谓词后，就能写"对每个 x，如果 x 是人则 x 会死"。

谓词可以有多个变量，如 Q(x, y) = "x + y = 5"，代入 Q(2,3) 为真。变量的取值范围叫论域（domain / universe of discourse），**论域必须明确**——同一个谓词换论域，量词命题的真假可能完全变（见 1.3.6 易错点）。

### 1.3.2 全称量词

全称量词（universal quantifier）记作 ∀，把谓词变成断言"论域中每个元素都满足它"：

∀x P(x)

读作"对所有 x，P(x)"，**当且仅当论域中每一个 x 都使 P(x) 为真时**为真；只要有一个 x 使 P(x) 假，∀x P(x) 就为假——那个 x 叫反例（counterexample）。

∀ 是"无限次（或有限论域下全部）的 ∧"。若论域是 {1,2,3}，则

∀x P(x) 等价于 P(1) ∧ P(2) ∧ P(3)

这解释了为什么"一个反例即可推翻全称命题"：合取里有一个为假，整体就假。最小例子：论域取全体整数，∀x (x² ≥ 0) 为真；而 ∀x (x > 0) 为假，反例 x = 0 或 x = −1。

全称命题在**空论域**上按约定为真（"空真"，没有元素可当反例）；日常口语说"所有"时往往默认论域非空，做题时须以给定论域为准。

### 1.3.3 存在量词（与唯一存在）

存在量词（existential quantifier）记作 ∃，断言"论域中至少有一个元素满足谓词"：

∃x P(x)

读作"存在 x 使 P(x)"，**当且仅当论域中至少有一个 x 使 P(x) 为真时**为真；若每个 x 都使 P(x) 假，则 ∃x P(x) 为假。

∃ 是"无限次（或全部）的 ∨"。论域 {1,2,3} 时

∃x P(x) 等价于 P(1) ∨ P(2) ∨ P(3)

只要有一个为真，整体就真。最小例子：论域全体整数，∃x (x² = 4) 为真（x = 2 或 −2）；∃x (x² = −1) 为假（实数/整数域内无解）。

还有唯一存在量词 ∃!x P(x)（或写 ∃₁），表示"恰好存在一个 x 使 P(x) 为真"。它可用基本量词展开：

∃!x P(x) 等价于 ∃x ( P(x) ∧ ∀y ( P(y) → y = x ) )

即"有一个满足，且任何满足的都与它相等"。初学阶段知道 ∀、∃ 两个基本量词即可，∃! 是常见缩写。

### 1.3.4 约束变量、自由变量与辖域

量词的辖域（scope）是它"管辖"的那部分公式。被某量词管辖的变量叫约束变量（bound variable），未被任何量词约束的变量叫自由变量（free variable）。

一个公式只有当**所有变量都被约束（或论域中已给具体值）时才是命题**（有确定真值）。例如 ∀x (x > y) 中 x 约束、y 自由，所以它不是命题（真假随 y 变），是关于 y 的谓词。这与 1.3.1 呼应：谓词要么代入具体值、要么用量词约束，才升级成命题。

约束变量是"哑变量"，换名不改含义——∀x P(x) 与 ∀z P(z) 是同一命题，就像求和 Σ 的指标可以随便改名。但换名时不能与已在用的变量撞名而造成"变量捕获"。辖域用括号界定，写清括号能避免歧义。

### 1.3.5 量词的否定（量词版德摩根律）

否定一个量化命题有固定规则，俗称"量词的德摩根律"：

¬∀x P(x) ≡ ∃x ¬P(x)

¬∃x P(x) ≡ ∀x ¬P(x)

**把否定往里推，∀ 和 ∃ 对调，并对谓词取反**。

说"并非所有 x 都满足 P"，等于说"存在某个 x 不满足 P"（那个 x 就是反例）；说"不存在满足 P 的 x"，等于说"所有 x 都不满足 P"。这与命题德摩根律（1.2.3）同源——∀ 是大 ∧、∃ 是大 ∨，否定后 ∧∨ 对调、各部分取反。

否定"所有学生都及格了"（∀x 及格(x)）得到"存在一个学生没及格"（∃x ¬及格(x)），**不是**"所有学生都没及格"——这是本节最常见、也最重要的易错点。多重量词逐层套用该规则：

¬∀x ∃y P(x,y) ≡ ∃x ∀y ¬P(x,y)

（否定逐个穿过量词，每穿过一个就对调一次，最后对谓词取反。）

### 1.3.6 嵌套量词与量词顺序

嵌套量词（nested quantifiers）指一个量词的辖域内还有别的量词，如 ∀x ∃y P(x,y)。读法是从外到内、像"函数嵌套"：∀x ∃y P(x,y) 读作"对每个 x，都存在（可依赖于 x 的）一个 y，使 P(x,y)"。

核心难点、也是本节最关键的一课：**不同量词的顺序不能随意交换**。一般地

∀x ∃y P(x,y)  与  ∃y ∀x P(x,y)  含义不同

典型例子（论域取全体实数，P(x,y) 表示"x + y = 0"）：

∀x ∃y (x + y = 0)

为真——对每个 x，都能找到 y = −x 使和为零（这里 y 可以随 x 而变）。但把顺序换成

∃y ∀x (x + y = 0)

为假——它要求"存在一个固定的 y，对所有 x 都有 x + y = 0"，显然不可能（同一个 y 不能同时抵消所有 x）。**∀∃ 允许内层 y 依赖外层 x；∃∀ 要求那个 y 对所有 x 通用**，这就是差别的根源。

不过，**相同的量词之间可以交换**：∀x ∀y P(x,y) ≡ ∀y ∀x P(x,y)，∃x ∃y P(x,y) ≡ ∃y ∃x P(x,y)。易错点还有前面提过的**换论域改真假**——∃x (x² = 2) 在实数域为真、在有理数域为假。做嵌套量词题务必盯紧两件事：量词顺序、论域。

## 1.4 推理规则

### 1.4.1 有效论证是什么

论证（argument）是一串命题：若干前提（premises）加一个结论（conclusion）。论证有效（valid）指**只要所有前提都为真，结论就必然为真**——即"前提合取 → 结论"是重言式：

(p₁ ∧ p₂ ∧ … ∧ pₙ) → q  是重言式

这是整个"推理"的定义性标准。

务必分清两组极易混的概念。第一，**有效 ≠ 结论真**：有效只保证"真前提必导出真结论"这个**形式**；如果某个前提本身是假的，有效论证也可能得出假结论。第二，**有效性只关乎形式，不关乎具体内容**：论证的有效与否，取决于命题之间的逻辑结构，与命题讲的是数学还是天气无关。一个论证"可靠（sound）"才要求它既有效、且前提全真——可靠才能保证结论真。推理规则（rules of inference）就是一批已被证明有效的"论证模板"，把它们串起来就构成证明。

### 1.4.2 命题逻辑的推理规则

以下是命题逻辑最常用的有效推理规则（记法：横线上方为前提，∴ 后为结论；每条对应一个重言式）。

假言推理（Modus Ponens，肯定前件）：

由 p 和 p → q，推出 q

否定后件（Modus Tollens）：

由 ¬q 和 p → q，推出 ¬p

假言三段论（Hypothetical Syllogism，蕴含传递）：

由 p → q 和 q → r，推出 p → r

析取三段论（Disjunctive Syllogism）：

由 p ∨ q 和 ¬p，推出 q

附加律（Addition）：

由 p，推出 p ∨ q

化简律（Simplification）：

由 p ∧ q，推出 p

合取律（Conjunction）：

由 p 和 q，推出 p ∧ q

消解律（Resolution）：

由 p ∨ q 和 ¬p ∨ r，推出 q ∨ r

其中假言推理（Modus Ponens）是最核心的一条，几乎所有证明都在反复用它："已知'如果 p 则 q'，又已知 p，于是得到 q"。否定后件是逆否推理的落地（配合 1.2.4 的 p→q≡¬q→¬p）。消解律是自动定理证明和 Prolog 等逻辑编程的引擎（接口指向 L3-05/PL，此处只点名）。

证明就是"从前提出发，每一步引用一条推理规则或已知等价，合法地推进，直到得到结论"。每一步都有据可依，整条链就是有效的。

### 1.4.3 谓词逻辑的推理规则

含量词的论证还需要四条"拆装量词"的规则。设论域中任取元素记为 c。

全称实例（Universal Instantiation, UI）：

由 ∀x P(x)，推出 P(c)（c 为论域中任一特定元素）

全称一般化（Universal Generalization, UG）：

由 P(c)（c 为论域中任意取定的元素），推出 ∀x P(x)

存在实例（Existential Instantiation, EI）：

由 ∃x P(x)，推出 P(c)（c 为某个新引入的、尚未使用过的名字）

存在一般化（Existential Generalization, EG）：

由 P(c)（对某个具体 c 成立），推出 ∃x P(x)

UI 是"全称成立就对任何具体对象成立"（三段论"苏格拉底会死"就靠它把"所有人都会死"落到苏格拉底身上）。UG 最微妙——只有当 c 是"**任意取定、没有任何特殊假设**"的元素时，才能从 P(c) 上升到 ∀x P(x)；这也是数学证明里"任取一个 x……"的形式依据。EI 引入的 c 必须是**全新名字**（因为你只知道"存在某个"满足的对象，但不知道具体是谁，不能和已有的对象混同）——这是最常见的出错点。UG 与 EI 的这些"侧条件"是保证推理有效的关键。

### 1.4.4 常见谬误

谬误（fallacy）是**看起来像推理规则、实则无效**的论证形式。两大经典：

肯定后件谬误（affirming the consequent）：

由 p → q 和 q，错误地"推出" p

这是把假言推理用反了：知道"如果下雨则地湿"和"地湿"，**不能**断定"下过雨"（地湿可能因为洒水）。对应的公式 (p → q) ∧ q → p 不是重言式（q 真、p 假、q 真那一行使前件真而结论 p 假）。

否定前件谬误（denying the antecedent）：

由 p → q 和 ¬p，错误地"推出" ¬q

同理无效：知道"如果下雨则地湿"和"没下雨"，不能断定"地不湿"。

另一类是循环论证（begging the question / circular reasoning）：把要证的结论偷偷当成前提用。识别谬误的通用武器还是真值表——把论证写成"前提合取 → 结论"，若**不是**重言式，论证就无效，能找到使前提真而结论假的那一行反例。初学者要牢记：肯定后件、否定前件这两个谬误分别是"逆命题""否命题"当等价用的错误（呼应 1.1.6：逆、否都不与原命题等价）。

## 1.5 证明方法与策略

### 1.5.1 基本术语（定理、公理、引理、证明）

证明（proof）是**一串有效的推理，从公理和已知为真的命题出发，导出待证命题为真**。相关术语：公理/公设（axiom）是不加证明当作出发点的命题；定理（theorem）是已被证明为真的重要命题；引理（lemma）是为证明更大定理而先证的"辅助小定理"；推论（corollary）是由某定理几乎立刻得出的结论；猜想（conjecture）是尚未被证明的命题。

数学不是"举了很多例子看起来对"，而是**用逻辑从已确立的真命题必然地推出新真命题**。例子能提供直觉、也能用来**否证**（反例），但**再多例子也不能证明一个全称命题**（∀ 需对无穷多对象成立，穷举不完）——这正是 1.3.2 说的"全称命题靠推理证、靠反例否"。下面几节是把待证命题的**逻辑形式**（是 p → q 还是 ∀x、∃x……）映射到相应证明"套路"。

### 1.5.2 直接证明

直接证明（direct proof）用于形如 p → q 的命题：**假设前件 p 为真，然后通过一串推理直接推出后件 q 为真**。因为 p → q 只在"p 真 q 假"时为假，所以只要堵死这一种情况（p 真时 q 必真），命题即得证。

模板："假设 p。……（推理）……因此 q。故 p → q 成立。"

证明"若 n 是奇数，则 n² 是奇数"。假设 n 奇，则按定义

n = 2k + 1  （k 为整数）

于是

n² = (2k + 1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1

括号内是整数，故 n² 形如 2m + 1，即奇数。证毕。要点：直接证明要**用上前件提供的信息**（这里"n 奇"给出 n=2k+1 这个可代入的形式），再靠代数/已知定理推到结论。

### 1.5.3 反证法、逆否证明与反例

当直接证明不顺手时，有几种"绕道"的标准方法。

逆否证明（proof by contraposition）：要证 p → q，改证其等价的逆否命题 ¬q → ¬p（等价性见 1.2.4）。适用于"从 ¬q 出发比从 p 出发更好推"的场合。例子：证"若 n² 是偶数则 n 是偶数"，直接证不好下手，改证逆否"若 n 是奇数则 n² 是奇数"（正是 1.5.2 已证的），于是原命题成立。

反证法（proof by contradiction，归谬法）：要证命题 s，**假设 ¬s 为真，推出一个矛盾**（推出某个 r ∧ ¬r，即恒假），从而 ¬s 不可能真，故 s 为真。它的形式依据是：若 ¬s → F（矛盾），则 s 必真。经典例子：证"√2 是无理数"——假设它是有理数 a/b（最简分数），推导会得出 a、b 都是偶数，与"最简"矛盾，故假设不成立，√2 无理。反证法威力大但易被滥用，能直接证时优先直接证。

反例（counterexample）：用于**否证**一个全称命题 ∀x P(x)——只要找到一个 x 使 P(x) 假即可（依据 1.3.2 与 1.2.4 的 ¬(p→q)≡p∧¬q）。例子：否证"所有素数都是奇数"，给出反例 2（素数但偶数）即可。要牢记：反例只能**推翻**全称命题，**不能证明**它。

逆否证明与反证法常被混淆——逆否证明是"证 ¬q → ¬p"（是一个直接证明，目标明确）；反证法是"假设结论反面、导出任意矛盾"（矛盾不必是 ¬p）。两者思路相关但形式不同。

### 1.5.4 构造性与非构造性存在证明

要证存在命题 ∃x P(x)，有两条路。

构造性存在证明（constructive existence proof）：**直接找出（构造出）一个满足 P 的具体 x**，或给出找到它的方法。例子：证"存在偶素数"——直接给出 2 即可。这类证明最令人满意，因为它不仅说"有"，还告诉你"是谁"。

非构造性存在证明（nonconstructive existence proof）：**不给出具体的 x，而是用别的方式（常配合反证法）论证"必然存在"**。经典例子：证明"存在两个无理数 a、b 使 aᵇ 有理"——考虑 √2^√2，若它有理则取 a=b=√2 即可；若它无理，则取 a=√2^√2、b=√2，可算得 aᵇ=2 有理。无论哪种情况都存在这样一对 a、b——**但整个论证并没告诉我们到底是哪一对**。这就是非构造性的特征：证明了"有"，却指不出"是谁"。

两者都是合法证明，但构造性证明在计算机科学里格外受青睐（构造过程往往就是算法）。这与 1.4.3 的 EG 相关——构造性证明本质是"找到具体 c，再由 EG 上升到 ∃x"。

### 1.5.5 穷举法与分情况证明

穷举证明（proof by exhaustion）：当待证命题只涉及**有限多种情况**时，把每种情况逐一验证。例子：证"对所有 1 ≤ n ≤ 4 的整数，(n+1)³ ≥ 3ⁿ"，只需分别验 n=1,2,3,4 四种即可。

分情况证明（proof by cases）：把论域按某种划分拆成几类，**每一类分别证明结论成立**，因各类合起来覆盖了所有可能，故结论普遍成立。形式依据是等价式

(p₁ ∨ p₂ ∨ … ∨ pₙ) → q  等价于  (p₁ → q) ∧ (p₂ → q) ∧ … ∧ (pₙ → q)

证"对任意整数 n，n² ≥ n"，分 n ≤ 0、n = 0/1、n ≥ 1 等情况（或按 n 与 1 的大小）分别验证。

分情况证明必须保证各情况**穷尽所有可能**（覆盖完整），否则漏掉的情况就是漏洞；各情况可以重叠，但绝不能有遗漏。这与"有限穷举"不同——分情况处理的是无限论域，只是把它切成有限块分别论证。

### 1.5.6 证明策略与常见陷阱

面对一个待证命题，选证明方法的实用策略（Rosen §1.8 "Proof Methods and Strategy"）大致是：先看命题的**逻辑形式**——是 p → q 就先试直接证明，卡住了试逆否，再不行试反证；是 ∀x 就"任取 x"（对应 UG）后按 p→q 处理；是 ∃x 就优先构造，构造不出再试非构造/反证；要否证全称命题就找反例；情况有限就穷举/分情况。"正向推理（从前提出发）"和"反向推理（从结论倒推需要什么）"常常要交替用。

(1) 用例子代替证明（例子不能证全称命题）；(2) 循环论证（把结论当前提）；(3) 分情况时漏掉某些情况；(4) 误用逆命题/否命题（把 p→q 当成 q→p 或 ¬p→¬q 用，呼应 1.4.4 谬误）；(5) 在 EI 里重用已有名字、或在 UG 里 c 带了特殊假设。写证明的通用建议：每一步都问"我这一步依据的是哪条定义、等价律或推理规则？"——答得出，这步就站得住。
