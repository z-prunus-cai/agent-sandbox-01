## 6.1 计数基本原理

### 6.1.1 乘法原理

乘法原理（product rule，又称乘法法则）说的是：如果完成一项任务需要依次做两步，第一步有 n₁ 种做法，且无论第一步怎么做、第二步都有 n₂ 种做法，那么完成整项任务的方法总数是两者相乘。推广到 m 步时：

n₁ · n₂ · … · nₘ

用集合语言等价地表述：若干个有限集合的笛卡尔积的基数等于各集合基数之积，即

|A₁ × A₂ × … × Aₘ| = |A₁| · |A₂| · … · |Aₘ|

乘法原理对应「一个过程被拆成一串接连进行的独立步骤」这种结构。直觉可以用一棵「选择树」来想：第一步的每个分支下都长出第二步的全部分支，所以叶子总数是各层分支数的乘积。

一个最小例子：一块车牌由 2 个字母后跟 3 个数字组成，且允许重复，则不同车牌数是 26 · 26 · 10 · 10 · 10。再如从 n 元素集合到 m 元素集合的函数共有 mⁿ 个——因为定义域里每个元素都要独立地选一个像，共 n 步、每步 m 种选择。

初学者最容易犯的错是「本该相乘却相加」。判据是问自己：这些选择是「既要…又要…（依次都要做）」还是「要么…要么…（只做其一）」。前者用乘法，后者用加法（见 6.1.2）。另一个易错点是乘法原理要求「后一步的选择数不依赖前一步具体怎么选」——如果依赖（例如「不许和前一步重复」使可选数递减），那正是排列 P(n,r) 出现的地方（见 6.3.1）。

### 6.1.2 加法原理

加法原理（sum rule，加法法则）说的是：如果一项任务可以用第一类方法之一完成、也可以用第二类方法之一完成，且这两类方法**互不重叠**（没有一种做法同时属于两类），第一类有 n₁ 种、第二类有 n₂ 种，那么完成任务的方法总数是两者相加。推广到 m 个两两不相交的类时：

n₁ + n₂ + … + nₘ

用集合语言：若 A₁, …, Aₘ 两两不相交（pairwise disjoint），则

|A₁ ∪ A₂ ∪ … ∪ Aₘ| = |A₁| + |A₂| + … + |Aₘ|

加法原理对应「把所有情况划分成互斥的几类、分别数完再合起来」这种结构。直觉就是把一个大集合切成不重叠的几块，块内各数各的、块间直接相加。

一个最小例子：从「7 名男生或 5 名女生」中选一名代表（两类人不重叠），共有 7 + 5 = 12 种选法。

关键易错点是「互不重叠」这个前提。如果两类方法有交叠，直接相加会把交叠部分数两次，这时不能用纯加法，要用减法原理（6.1.3）来扣除重复。判断用加法还是乘法的口诀：**「分类相加、分步相乘」**——把任务按互斥情形分类时相加，把任务按先后步骤分步时相乘。

### 6.1.3 减法原理

减法原理（subtraction rule）就是两个集合的容斥原理：如果完成任务的方法可以用两类方法之一实现、但两类之间有重叠，那么方法总数等于两类各自的数目之和减去两者都算进去的重叠数目。对集合 A、B：

|A ∪ B| = |A| + |B| − |A ∩ B|

直觉：先把两块各自数一遍加起来，重叠区域被数了两次，所以要减掉一次重叠，才不会重复计数。这是加法原理在「两类有交叠」时的修正版。

一个最小例子：一串 8 位的二进制串，问「以 1 开头**或**以 00 结尾」的串有多少。以 1 开头的有 2⁷ 个，以 00 结尾的有 2⁶ 个，既以 1 开头又以 00 结尾的有 2⁵ 个，故答案为 2⁷ + 2⁶ − 2⁵。

初学者容易忘记减去交集，或者反过来在两类本就不重叠时多此一举地去减一个空交集（交集为 0 时减法退化成加法，无害但没必要）。减法原理只处理两个集合的容斥；三个及以上集合的一般容斥公式（正负交替）属本课大主题8，本节不展开。

### 6.1.4 除法原理

除法原理（division rule）说的是：如果一项计数任务的每个「真正不同的结果」都恰好被某种数法重复计了 d 次，那么真正不同的结果数等于「重复计数的总数」除以 d。若一个 n 元素集合上有一种「每个对象恰好对应 d 个元素」的对应方式，则不同对象数为

n / d

直觉：当你的数法系统性地把每个答案数了固定的 d 遍，把总数除以 d 就还原出真实答案。它是乘法原理的「逆向」用法——乘法原理制造重复，除法原理消去重复。

经典最小例子是**圆排列**：n 个人围圆桌而坐，只看相对次序（旋转视为同一种）。若先当成一排来数有 n! 种，但每一种圆上的坐法都对应 n 种旋转后看起来不同、实则相同的排法，所以圆排列数是

n! / n = (n−1)!

初学者的难点在于「判断每个结果究竟被重复计了几次」——这个 d 必须对所有结果都相同，除法原理才成立。若不同结果被重复的次数不一样，就不能简单地一除了事。除法原理是后面「可重复组合」和「入盒分配」里消去顺序 / 消去等价的常用工具。

### 6.1.5 复杂计数：组合使用与减法（补集）技巧

真实的计数题往往要把上面几条原理**组合起来**用：先分步（乘法）、再分类（加法）、遇重叠（减法）、遇重复（除法）。Rosen §6.1 用大量「口令 / 密码计数」「函数 / 单射计数」「IP 地址计数」等例子演示这种混合。

一个特别常用的技巧是**补集计数**（减法的一种）：当「满足条件」的情形不好直接数、而「全体」和「不满足条件」都好数时，用

（满足条件的数目）=（全体数目）−（不满足条件的数目）

一个最小例子：长度 8、允许字母数字、且**至少含一个数字**的口令有多少？直接数「至少一个」要分很多类，但反过来——全体口令数减去「一个数字都没有」的口令数——一步就得到答案。

这一小节没有新公式，重点是建立「先看任务结构、再拼装四条原理」的解题习惯。初学者的常见困难正是「不知道该乘还是该加」——回到 6.1.1–6.1.4 的判据：分步相乘、分类相加、有交叠减交叠、有均匀重复除倍数；正面难数就数补集。

## 6.2 鸽巢原理

### 6.2.1 鸽巢原理

鸽巢原理（pigeonhole principle，又称抽屉原理）的基本形式是：如果把 k+1 个（或更多）物体放进 k 个盒子，那么至少有一个盒子里含有两个或更多物体。等价地，如果 N 个物体放进 k 个盒子且 N > k，则必有一个盒子装了不止一个物体。

它常用函数语言表述：若一个从含 k+1 个元素的集合到含 k 个元素的集合的函数，则**必不是单射**（一定有两个不同输入被映到同一个输出）。

直觉极其朴素：盒子不够多、物体太多，就一定「挤」到一起。虽然结论平凡到近乎废话，它却是证明「某种重合 / 某种存在**一定发生**」的强力工具——它只保证「存在这样一个盒子」，但**不告诉你是哪一个**，是典型的**存在性**（非构造性）论证。

一个最小例子：任意 13 个人中，必有至少两人生日在同一个月——因为月份只有 12 个盒子，13 > 12。再如：任意从 1 到 8 中取 5 个不同整数，必有两个之和为 9（把 {1,8},{2,7},{3,6},{4,5} 当 4 个盒子，5 个数放进 4 盒必有一盒装两个）。

初学者要抓住两点：一是要**主动找出「谁是鸽子、谁是巢」**——很多题的巧妙之处全在于把什么设成盒子；二是它只给「至少存在一处重合」，不给位置也不给更多数量信息，想要更强的结论（同一盒里至少几个）需要下面的广义版本。

### 6.2.2 广义鸽巢原理

广义鸽巢原理（generalized pigeonhole principle）把结论从「至少 2 个」加强为一个精确的下界：如果 N 个物体放进 k 个盒子，则至少有一个盒子里含有

⌈N / k⌉

个或更多物体（⌈·⌉ 是向上取整）。当 N = k+1 时 ⌈(k+1)/k⌉ = 2，退回基本形式。

直觉：把 N 个物体尽量「摊平」地分到 k 个盒子里，最挤的盒子也至少要装到平均数向上取整那么多——因为如果每个盒子都少于 ⌈N/k⌉，总数就凑不够 N，矛盾。

一个最小例子：100 个人中至少有 ⌈100/12⌉ = 9 人生日在同一个月。反过来常用它求「至少要多少物体才能保证某盒达到 r 个」：要保证某盒至少 r 个，需要的物体数是 k(r−1)+1——因为 k(r−1) 个还能让每盒恰好 r−1 个（尚未达标），再多一个就必然把某盒顶到 r。

初学者最容易错的是**向上取整**：平均数 N/k 通常不是整数，结论要的是「≥ ⌈N/k⌉」而不是「≥ N/k」或四舍五入。另一个易错点是把「至少一个盒子有 ⌈N/k⌉ 个」误读成「每个盒子都有这么多」——它依旧只是存在性结论。

### 6.2.3 鸽巢原理的应用

鸽巢原理的威力体现在一批「看起来不像计数题」的存在性证明里，Rosen §6.2 给出若干经典应用，本节择要点到：

- 序列中的单调子序列：任何长度为 n²+1 的、由不同实数构成的序列，必含一个长度为 n+1 的严格递增或严格递减子序列（把每个位置贴上「以它结尾的最长递增 / 递减子序列长度」标签，用鸽巢导出重合）。
- 数论应用：在 1 到 2n 之间任取 n+1 个整数，必有两个数其中一个整除另一个；也必有两个数互素。
- 存在整数倍：任给 n 个整数，必存在其中若干个连续项之和被 n 整除（用前缀和模 n 的余数作鸽巢）。

这些例子的共同套路是：**精心设计「盒子」（通常是某种余数、某种标签、某种配对），让「物体数 > 盒子数」自动逼出所需的重合**。

初学者从这些应用里要体会的是：鸽巢原理本身平凡，难点全在「构造出恰当的盒子」这一步创造性设计上。它证明的是「一定存在」，属存在性证明的代表（呼应大主题1的证明方法）；一旦盒子设对，结论几乎是自动的。

## 6.3 排列与组合

### 6.3.1 排列

排列（permutation）是从一个集合中**有序地**取出若干元素排成一列。从 n 个不同元素中取出 r 个作有序排列，其数目记作 P(n, r)（也写作 ⁿPᵣ 或 (n)ᵣ），公式为

P(n, r) = n · (n−1) · (n−2) · … · (n−r+1) = n! / (n−r)!

其中 0 ≤ r ≤ n。特别地，n 个元素全排列数为 P(n, n) = n!（约定 0! = 1，故 P(n,0)=1）。

直觉用乘法原理即可推出：排第一个位置有 n 种选择，排第二个位置因为用掉了一个、只剩 n−1 种，……排第 r 个位置剩 n−r+1 种；由乘法原理相乘即得上式。**关键在「顺序重要」**——同样三个元素，排成 ABC 和 CBA 算作不同的排列。

一个最小例子：从 5 名选手中评出金、银、铜三个**有次序**的名次，方法数是 P(5,3) = 5·4·3 = 60。

可选验证（Python 标准库 math，对应基线串）：

```python
import math
print(math.perm(5, 3))   # 60
```

真实输出为 `60`，与公式一致。

初学者最常见的混淆是**排列 vs 组合**：只要「取出后还要区分先后 / 位置 / 角色」就是排列。易错点还有边界 r=0（空排列 1 种）和 r=n（全排列 n!）。当元素可重复选取时，公式变为 nʳ（见 6.5.1），不要与不可重复的 P(n,r) 混用。

### 6.3.2 组合

组合（combination）是从一个集合中**无序地**取出若干元素构成一个子集。从 n 个不同元素中取出 r 个的组合数记作 C(n, r)、ⁿCᵣ 或二项式系数 (n choof r)，公式为

C(n, r) = n! / (r! · (n−r)!)

其中 0 ≤ r ≤ n。

直觉：组合与排列的唯一区别是「不计顺序」。任何一个 r 元子集，它内部的 r 个元素可以有 r! 种排法、都对应同一个组合，所以把排列数 P(n,r) 除以 r! 就消去了顺序，得到组合数——这正是除法原理（6.1.4）的一次应用：

C(n, r) = P(n, r) / r! = n! / (r! (n−r)!)

一个最小例子：从 5 名选手中选出 3 人组成一个**不分角色**的委员会，方法数是 C(5,3) = 10（而 6.3.1 里分金银铜是 60，正好是 10 × 3!）。

可选验证（math，对应基线串）：

```python
import math
print(math.comb(5, 3))   # 10
```

真实输出为 `10`。

初学者判断用 P 还是 C 的黄金问题是：「换个顺序算不算新的一种？」算——用排列 P；不算——用组合 C。另一个常见错误是把「选人 + 排位」这类两阶段问题只用一步公式，其实往往是「先组合选出人、再排列定顺序」两步相乘。

### 6.3.3 排列与组合的关系及常用恒等式

排列与组合由一个核心关系式串起来——先无序地选出 r 个（C(n,r) 种），再把选出的 r 个排序（r! 种），由乘法原理得到有序排列：

P(n, r) = C(n, r) · r!

另外两个天天要用的组合恒等式：

C(n, 0) = C(n, n) = 1

C(n, r) = C(n, n−r)

第二式称为**对称性**：从 n 个里挑 r 个「要谁」，等价于挑 n−r 个「不要谁」，两种视角一一对应，所以数目相等。它在计算时常用来把 r 换成较小的 n−r 以简化，例如 C(100, 98) = C(100, 2) = 4950。

可选验证（对称性，math，对应基线串）：

```python
import math
print(math.comb(10, 3), math.comb(10, 7))   # 120 120
```

真实输出为 `120 120`，对称性成立。

初学者要把 P = C·r! 这条关系记牢，它是「区分排列 / 组合」的桥梁，也解释了为什么组合数总是排列数的 1/r!。对称性 C(n,r)=C(n,n−r) 则是下一节 Pascal 三角左右对称的根源。

- 冲突 / 分歧：记号差异——组合数有 C(n,r)、ⁿCᵣ、(n r)（二项式系数竖式）多种写法，排列数有 P(n,r)、ⁿPᵣ、(n)ᵣ 等，均指同一量，非对错之分。

## 6.4 二项式系数与恒等式

### 6.4.1 二项式定理

二项式定理（binomial theorem）给出 (x+y) 的整数次幂展开式：对任意非负整数 n，

(x + y)ⁿ = Σ_{k=0}^{n} C(n, k) · xⁿ⁻ᵏ · yᵏ

展开式里 xⁿ⁻ᵏyᵏ 这一项的系数 C(n,k) 就叫**二项式系数**（binomial coefficient）——这也是组合数被叫作二项式系数的原因。

直觉（组合意义）：把 (x+y)ⁿ 看成 n 个因子 (x+y) 连乘，展开时每个因子要么贡献一个 x、要么贡献一个 y。要得到 xⁿ⁻ᵏyᵏ，就要从 n 个因子里**挑出 k 个贡献 y**（其余贡献 x），挑法共 C(n,k) 种，所以该项系数正是 C(n,k)。

一个最小例子：

(x + y)⁴ = x⁴ + 4x³y + 6x²y² + 4xy³ + y⁴

系数 1,4,6,4,1 正是 C(4,0..4)。

可选验证（sympy 符号展开，对应基线串）：

```python
from sympy import expand, symbols
x, y = symbols('x y')
print(expand((x + y)**4))
# x**4 + 4*x**3*y + 6*x**2*y**2 + 4*x*y**3 + y**4
```

真实输出为 `x**4 + 4*x**3*y + 6*x**2*y**2 + 4*x*y**3 + y**4`，系数与 C(4,k) 一致。

初学者的易错点：一是幂次此消彼长——x 的指数 n−k 与 y 的指数 k 之和恒为 n；二是别漏了 k=0 和 k=n 两个端项（系数都是 1）；三是当出现负号或系数时（如 (2x−3)⁵）要把 x=2x、y=−3 整体代入，符号和系数会随 yᵏ 一起变。

### 6.4.2 二项式系数的组合意义与几个特例

二项式系数 C(n,k) 有一个统一的组合读法：**它数的是「从 n 个里选 k 个」的方法数**，也等于「n 元集合的所有 k 元子集数」。二项式定理只是这一计数在代数展开里的化身。

把二项式定理里的 x、y 取特殊值，立刻得到几个常用恒等式。取 x=y=1：

Σ_{k=0}^{n} C(n, k) = 2ⁿ

这说明 n 元集合的全部子集数是 2ⁿ（把「每个元素选或不选」按子集大小 k 分类求和）。取 x=1, y=−1：

Σ_{k=0}^{n} (−1)ᵏ · C(n, k) = 0

即一个非空有限集合的偶数元子集数与奇数元子集数相等。

可选验证（行和，math，对应基线串）：

```python
import math
print(sum(math.comb(8, k) for k in range(9)), 2**8)   # 256 256
```

真实输出为 `256 256`。

初学者从这里应体会「一个恒等式往往能被『代值』或『组合计数』两种方式解释」。行和 = 2ⁿ 既可由代 x=y=1 得到（代数证明），也可由「子集总数 = 各种大小子集数之和」得到（组合证明）——两种证法都对，是理解二项式恒等式的两把钥匙。

### 6.4.3 Pascal 恒等式与 Pascal 三角

Pascal 恒等式（Pascal's identity）是二项式系数最基本的递推关系：对 1 ≤ k ≤ n−1（更一般地 n ≥ k ≥ 1），

C(n, k) = C(n−1, k−1) + C(n−1, k)

它是**Pascal 三角**（杨辉三角）的构造法则——三角形中每个内部数等于其正上方左右两数之和。

组合意义（最好懂的证明）：从 n 个元素里选 k 个，盯住某个特定元素 a。所有选法分成互斥两类：**含 a** 的（还需从其余 n−1 个里再选 k−1 个，共 C(n−1,k−1) 种）与**不含 a** 的（从其余 n−1 个里选 k 个，共 C(n−1,k) 种）。由加法原理两类相加，即得 Pascal 恒等式。

Pascal 三角前几行（第 n 行是 C(n,0)…C(n,n)）：

1
1 1
1 2 1
1 3 3 1
1 4 6 4 1

可选验证（Pascal 恒等式，对所有 n<12 逐点检查，math，对应基线串）：

```python
import math
ok = all(math.comb(n, k) == math.comb(n-1, k-1) + math.comb(n-1, k)
         for n in range(1, 12) for k in range(1, n))
print(ok)   # True
```

真实输出为 `True`。

初学者要注意恒等式的边界（每行两端的 1 由 C(n,0)=C(n,n)=1 提供，不适用递推）。Pascal 三角把 6.3–6.4 的很多性质「画」了出来：左右对称对应 C(n,r)=C(n,n−r)，每行之和是 2ⁿ（6.4.2），相邻两数相加得下一行对应位置（Pascal 恒等式）。

### 6.4.4 Vandermonde 恒等式

Vandermonde 恒等式（Vandermonde's identity）是一个把「组合数的乘积求和」合并成单个组合数的恒等式：对非负整数 m、n 和 r（r ≤ m+n），

C(m + n, r) = Σ_{k=0}^{r} C(m, k) · C(n, r−k)

组合意义：设想有 m 个男生、n 个女生，要从这 m+n 人里选出 r 人，直接选是 C(m+n, r) 种。换个数法：按「选中的男生数 k」分类（k 从 0 到 r），选 k 个男生有 C(m,k) 种、再选 r−k 个女生有 C(n,r−k) 种，两步相乘；对所有 k 求和（加法原理）就得到右边。两种数法数的是同一件事，故相等。

一个最小例子（m=6, n=7, r=5）：

C(13, 5) = Σ_{k=0}^{5} C(6, k) · C(7, 5−k)

可选验证（math，对应基线串）：

```python
import math
m, n, r = 6, 7, 5
lhs = math.comb(m + n, r)
rhs = sum(math.comb(m, k) * math.comb(n, r - k) for k in range(0, r + 1))
print(lhs, rhs, lhs == rhs)   # 1287 1287 True
```

真实输出为 `1287 1287 True`。

一个常用推论是取 m=n=r 并结合对称性，得到 Σ_{k=0}^{n} C(n,k)² = C(2n, n)。初学者对 Vandermonde 最需要理解的是那句「按某个中间量分类再求和」的组合叙事——它是「双计数（counting the same thing two ways）」这一证明范式的典范；死记公式不如记住「m+n 里选 r = 按选中的 m 类个数分类」这个故事。

#### 来源与时效（本小主题末集中列）
- 一手锚点：Rosen 8e §6.4「Binomial Coefficients and Identities」——二项式定理 (x+y)ⁿ=Σ C(n,k)xⁿ⁻ᵏyᵏ、行和 Σ C(n,k)=2ⁿ、交错和 Σ(−1)ᵏC(n,k)=0、Pascal 恒等式 C(n,k)=C(n−1,k−1)+C(n−1,k)、Vandermonde 恒等式 C(m+n,r)=Σₖ C(m,k)C(n,r−k) 及推论 Σ C(n,k)²=C(2n,n)。核实 2026-07-26。
- 交叉源：University of Edinburgh DMMR Chapter 6（二项式定理与 Pascal / Vandermonde 恒等式对照）；MIT 6.042J 计数单元（二项式系数的组合证明、双计数范式）作交叉核对。核实 2026-07-26。
- 本机验证：(x+y)⁴ 展开系数 1,4,6,4,1（sympy.expand）；Σ C(8,k)=2⁸=256；Pascal 恒等式对所有 n<12 为 True；Vandermonde C(13,5)=1287 两侧相等——均 sympy 1.14.0 / math 真实输出，对应基线串。
- 冲突 / 分歧：未见分歧。Vandermonde 亦称「Vandermonde's convolution（范德蒙德卷积）」，同一恒等式的别名。

## 6.5 广义排列组合

### 6.5.1 可重复排列

可重复排列（permutations with repetition allowed）指从 n 种不同类型的元素中有序地取出 r 个、**每种类型可被重复取用**。此时排列数为

nʳ

直觉用乘法原理：每个位置都独立地从 n 种里任选一种、互不影响，共 r 个位置，故为 n·n·…·n（r 个）= nʳ。这与 6.3.1 不可重复排列 P(n,r) 的区别在于：不可重复时后续位置的可选数递减（n, n−1, …），可重复时每个位置都还是 n。

一个最小例子：用 26 个字母组成长度为 4 的字符串（允许重复），共 26⁴ 种；一枚均匀硬币抛 r 次的结果序列有 2ʳ 种。

初学者的核心判据是「同一个元素能不能被选多次」——能则用 nʳ，不能则用 P(n,r)。这里 n 是「类型数」不是「物体总数」，别把两者搞混。

### 6.5.2 可重复组合（多重集组合）

可重复组合（combinations with repetition，又称多重集组合）指从 n 种不同类型中**无序地**取出 r 个、每种类型可重复取（可取 0 到 r 个）。其数目为

C(n + r − 1, r) = C(n + r − 1, n − 1)

这个结论常被称为**隔板法 / 星与条法**（stars and bars）。

直觉（星与条模型）：把要取的 r 个物体画成 r 颗星（★），把 n 种类型之间用 n−1 根隔板（|）分开；每种排布对应「第 1 种取几个 | 第 2 种取几个 | …」。于是问题变成「在 r 颗星和 n−1 根隔板共 r+(n−1) 个位置中，选哪 r 个放星（或等价地选哪 n−1 个放隔板）」，方法数即 C(n+r−1, r)。

一个最小例子：从 3 种口味（草莓 / 巧克力 / 香草）中买 4 个甜甜圈、同种可多买、不计购买顺序，方法数为

C(3 + 4 − 1, 4) = C(6, 4) = 15

可选验证（math，对应基线串）：

```python
import math
print(math.comb(3 + 4 - 1, 4))   # 15
```

真实输出为 `15`。

初学者最容易把公式里的 n 和 r 记反——记住模型：**r 颗星（要取的个数）、n−1 根隔板（类型数减一）**，总位置 n+r−1，从中选 r 个位置放星。它也是「x₁+x₂+…+xₙ = r 的非负整数解个数」的标准答案，这个等价形式在后面入盒分配和大主题8里反复出现。

### 6.5.3 有不可区分对象的排列（多项系数）

当要排列的对象中有若干**彼此不可区分**（相同）时，全排列数要相应缩小。若共有 n 个对象，其中第 1 类有 n₁ 个相同、第 2 类 n₂ 个相同、……第 k 类 nₖ 个相同（n₁+n₂+…+nₖ = n），则不同排列数为

n! / (n₁! · n₂! · … · nₖ!)

这个量称为**多项系数**（multinomial coefficient）。

直觉（除法原理）：先假装 n 个对象全都不同，有 n! 种排法；但每一类内部的 nᵢ 个相同对象无论怎样内部对调，看起来都是同一种排列，这种内部重排有 nᵢ! 种。于是每个「真正不同的排列」都被 n₁!·n₂!·…·nₖ! 次地重复计数了，除掉即得上式。

经典最小例子：单词 MISSISSIPPI（共 11 个字母：M 1 个、I 4 个、S 4 个、P 2 个）的不同字母排列数为

11! / (1! · 4! · 4! · 2!) = 34650

可选验证（math，对应基线串）：

```python
import math
print(math.factorial(11) // (math.factorial(1)*math.factorial(4)*math.factorial(4)*math.factorial(2)))
# 34650
```

真实输出为 `34650`。

初学者要注意分母是**每一类各自阶乘的乘积**，别漏掉只出现 1 次的类（其 1! = 1 不影响结果，但概念上要意识到它也是一类）。当 k=2 时，n!/(n₁!n₂!) 恰好退化为组合数 C(n, n₁)——所以二项式系数是多项系数的特例。

### 6.5.4 对象入盒分配

「把对象放进盒子」是组合计数的一个统一框架，Rosen §6.5 按「对象是否可区分」「盒子是否可区分」分成四种情形。本课只做「导论 + 常用公式」，其中最常用的是可区分对象放入可区分盒子。

把 n 个**可区分**对象放入 k 个**可区分**盒子、要求第 i 个盒子恰好放 nᵢ 个（n₁+…+nₖ = n），方法数是多项系数

n! / (n₁! · n₂! · … · nₖ!)

这与 6.5.3 是同一个公式的另一副面孔（「谁去几号盒」等价于「给每个对象贴一个盒子标签、同盒不计内部顺序」）。

四种情形的结论概览（n 个对象、k 个盒子）：

- 可区分对象、可区分盒子（指定各盒容量 n₁…nₖ）：n! / (n₁!…nₖ!)；若不指定容量、每对象独立选盒，则为 kⁿ。
- 不可区分对象、可区分盒子：等价于 x₁+…+xₖ = n 的非负整数解数，即 C(n + k − 1, n)（就是 6.5.2 的可重复组合）。
- 可区分对象、不可区分盒子：分成非空的 j 个部分对应第二类 Stirling 数 S(n, j)，放入至多 k 个不可区分盒子为 Σ_{j=1}^{k} S(n, j)。
- 不可区分对象、不可区分盒子：对应整数 n 的**分拍数**（partition，写成至多 k 个正整数之和的方法数），无简单闭式。

一个最小例子（可区分对象、可区分盒子、指定容量）：把 5 张不同的卡片发给三个人，使甲、乙各得 2 张、丙得 1 张，方法数为

5! / (2! · 2! · 1!) = 30

可选验证（math，对应基线串）：

```python
import math
print(math.factorial(5) // (math.factorial(2)*math.factorial(2)*math.factorial(1)))
# 30
```

真实输出为 `30`。

初学者面对入盒问题，第一步永远是问清**两件事**：对象可不可区分、盒子可不可区分——四种组合对应四套截然不同的公式，判错这一步后面全错。本课重点掌握前两种（多项系数 / kⁿ、以及 C(n+k−1,n)）；后两种（Stirling 数、整数分拍）只作导论性认知，其深入内容不在本课展开。
