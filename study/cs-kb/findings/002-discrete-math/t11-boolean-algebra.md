## 11.1 布尔函数与恒等式

### 11.1.1 布尔变量、三个基本运算与优先级

布尔代数处理的对象只取两个值，记作 1 和 0（可读作「真 / 假」或「开 / 关」）。在这两个值的集合上定义三个基本运算：

补（complement，记 x̄ 或 x′）：把值翻转，1̄ = 0，0̄ = 1。

布尔积（Boolean product，记 x · y 或直接并写 xy，对应逻辑合取 ∧）：只有两者都为 1 时结果才是 1，其余为 0。

布尔和（Boolean sum，记 x + y，对应逻辑析取 ∨）：只要有一个为 1 结果就是 1，只有都为 0 时才是 0。

三者的运算优先级约定为：先算补，再算布尔积，最后算布尔和（和普通代数里「先乘后加」一致，补相当于取负号那样最贴身）。于是表达式

x · y + z̄

的读法是「(x·y) + (z̄)」，不是「x·(y+z̄)」。

布尔积、布尔和这两个名字里的「积」「和」不是随便叫的——它们的真值表恰好等于把 1、0 当整数做「乘法」和「饱和加法」（1+1 记作 1 而不是 2）。所以 x·y 就是普通乘法（1·1=1，其余为 0），x+y 除了 1+1=1 这一处外都和整数加法一样。初学者最容易踩的坑正是 1 + 1：在布尔代数里它等于 1（因为「真或真」还是真），不是 2，布尔代数里根本没有 2 这个值。另一个易错点是把「补」的优先级记错——x + y 的补写成 (x+y)‾ 与 x̄ + ȳ 是**两回事**（这正是 11.1.4 德摩根律要处理的），overbar 盖住谁就先补谁。

### 11.1.2 布尔函数

一个 n 元布尔函数（Boolean function of degree n）是从 n 个布尔变量的所有取值组合到 {0,1} 的映射：

F : {0,1}ⁿ → {0,1}

因为每个变量只有 2 种取值，n 个变量共有 2ⁿ 种输入组合；而每种组合可以独立地映到 0 或 1，所以 n 元布尔函数一共有

2^(2ⁿ)

个。给定一个布尔函数，最朴素的完整描述方式就是它的**取值表**（就是真值表，只是把 T/F 写成 1/0），把 2ⁿ 行输入及其对应输出全列出来。

n=1 时输入只有 x=0、x=1 两行，共有 2^(2¹) = 4 个一元布尔函数——恒 0、恒 1、恒等（F=x）、取补（F=x̄）。n=2 时有 2^(2²) = 16 个二元布尔函数，AND、OR、XOR、NAND 等都在其中。

**「布尔函数」和「布尔表达式」不是一回事**。函数是那张输入输出表（语义），表达式（如 xy + x̄z）只是描述这张表的一种写法（语法）。同一个函数可以有无穷多个等价表达式——这正是后面 11.2「范式」（给每个函数一个标准写法）和 11.4「化简」（在众多等价写法里找最省的）之所以有意义的根源。这个「一函数、多表达式」的观念与大主题1里「一个真值表、多个等价命题公式」完全对应。

### 11.1.3 布尔恒等式（基本定律）

布尔恒等式是对**所有**变量取值都成立的等式，用来在不改变函数值的前提下改写表达式。核心定律成对出现（这正是 11.1.5 对偶原理的体现），常用的一组如下。

双重补律：

(x̄)‾ = x

幂等律：

x + x = x     x · x = x

同一律（单位元）：

x + 0 = x     x · 1 = x

支配律（零元 / 归零律）：

x + 1 = 1     x · 0 = 0

交换律：

x + y = y + x     x · y = y · x

结合律：

x + (y + z) = (x + y) + z     x · (y · z) = (x · y) · z

分配律（注意布尔代数里**两个方向都成立**）：

x · (y + z) = x · y + x · z     x + (y · z) = (x + y) · (x + z)

德摩根律：

(x · y)‾ = x̄ + ȳ     (x + y)‾ = x̄ · ȳ

吸收律：

x + x · y = x     x · (x + y) = x

互补律（单位元素性质）：

x + x̄ = 1     x · x̄ = 0

它和大主题1「命题逻辑等价」那张表逐条对应（`·`↔`∧`、`+`↔`∨`、`¯`↔`¬`、`1`↔`T`、`0`↔`F`），只是换了记号。所以你不必把它当全新的东西背，而是「同一批定律的第二种语言」。

两条最反直觉、最该单独记的是：**第二条分配律** x + yz = (x+y)(x+z)——普通实数代数里「加对乘」不满足分配（3+2·4 ≠ (3+2)(3+4)），但布尔代数里成立；以及**支配律** x + 1 = 1——一旦「或」上一个恒真项，整体就恒真，这在化简里是强力的「清零」手段。

一是把德摩根律用错，写成 (x+y)‾ = x̄ + ȳ（错，补号一进去，`+` 必须翻成 `·`）；二是忘了布尔和里 x+x = x（不是 2x）、x+1 = 1（不是「x 加一」）。验证一条恒等式是否成立，最保险的初学者办法就是列出两边的完整取值表，逐行比对——只要有一行不同就不是恒等式。

可选的 sympy 验证（`simplify_logic` 把两边化到规范形再比较），真实输出如下：

```
DeMorgan Not(x&y)==~x|~y : True
Distrib x&(y|z) == (x&y)|(x&z): True
Absorption x|(x&y) == x: True
Complement x|~x == True: True
Complement x&~x == False: True
Idempotent x|x==x: True  x&x==x: True
Double neg ~~x==x: True
```

环境：Python 3.11.15 / sympy 1.14.0 / Linux 6.18.5 x86_64（基线 @2026-07-25）。这些 True 表示对应恒等式在符号化简下成立，可加固上表；但注意这只是「补充加固」，恒等式的权威来源仍是下面「来源与时效」里 Rosen §12.1 与逻辑等价表的多源比对。

### 11.1.4 对偶原理

一个布尔表达式（恒等式）的**对偶（dual）**，是把式中所有布尔和 `+` 与布尔积 `·` 互换、同时把所有 0 与 1 互换（变量与补号保持不变）得到的新式。对偶原理断言：

如果一条恒等式成立，那么它的对偶也一定成立。

例如吸收律 x + xy = x 的对偶，是把 `+`↔`·` 互换后得到

x · (x + y) = x

它同样成立——这解释了为什么 11.1.3 那张表里的定律总是「成对」出现：每一对里的两条互为对偶。

直觉与「为什么」：布尔代数的全部公理（见 11.1.5）本身就是成对对偶的，所以任何从公理推出的定理，把证明里每一步同时取对偶，得到的就是原定理对偶的合法证明。于是对偶原理是一台「买一送一」的机器——证明或记忆一条定律，自动白得它的对偶。

德摩根律的两条 (xy)‾ = x̄+ȳ 与 (x+y)‾ = x̄·ȳ 也互为对偶。易错点在于——对偶**只换运算符和常量，不动变量、也不加减补号**。初学者常把「对偶」和「取补 / 德摩根」搞混：取补是对整个表达式求 `¯`（会用德摩根律把补推到变量上，变量也变成 x̄），而对偶只是机械地翻 `+·` 和 `01`，变量原封不动。二者是不同操作。

### 11.1.5 布尔代数的抽象定义（公理化）

前面都在具体的两元素集合 {0,1} 上讨论。更一般地，一个**布尔代数**被抽象定义为：一个集合 B，配两个二元运算 ∨（对应 `+`）和 ∧（对应 `·`）、两个特殊元素 0 和 1、一个一元运算补 `¯`，并且对 B 中所有 x、y、z 满足以下五组定律——

同一律：x ∨ 0 = x，x ∧ 1 = x

互补律：x ∨ x̄ = 1，x ∧ x̄ = 0

结合律：x ∨ (y ∨ z) = (x ∨ y) ∨ z，x ∧ (y ∧ z) = (x ∧ y) ∧ z

交换律：x ∨ y = y ∨ x，x ∧ y = y ∧ x

分配律：x ∨ (y ∧ z) = (x ∨ y) ∧ (x ∨ z)，x ∧ (y ∨ z) = (x ∧ y) ∨ (x ∧ z)

从这五组公理出发，11.1.3 里其余的定律（幂等、支配、吸收、德摩根、双重补等）都可以作为**定理推导出来**，不必单列为公理。

这个抽象定义的意义在于「一次定义、处处复用」：只要某个数学结构满足这五组定律，它就是布尔代数，前面所有恒等式与对偶原理立刻对它全部适用。三个最重要的实例是：值集 {0,1} 上的开关代数（本章主角）；一个全集的**幂集**在并 ∪、交 ∩、补下构成的集合代数（大主题2）；以及所有命题在 ∨、∧、¬ 下构成的命题代数（大主题1）——它们都是布尔代数，彼此**同构**。

初学者到这一步只需建立一个观念即可，不必深究公理独立性或格论纵深（那属更专门的代数课）：布尔代数不是「关于 0 和 1 的一堆零散规则」，而是一个有精确公理定义的代数系统，这也是为什么它的定律能在逻辑、集合、电路里反复出现。历史上 Huntington（1904）给出的正是这样一组公理，Boole（1854）是最早把逻辑代数化的人——这两个命名与年代属背景常识，本报告不据其做任何数值结论。

## 11.2 布尔函数的表示

### 11.2.1 字面量与最小项

字面量（literal）指一个布尔变量本身或它的补，例如 x 与 x̄ 都是字面量。

对 n 个变量而言，一个**最小项（minterm）**是恰好用上全部 n 个变量各一次的布尔积，其中每个变量以「原变量」或「补」的形式出现一次：

y₁ · y₂ · … · yₙ     （每个 yᵢ 是 xᵢ 或 x̄ᵢ）

它在**唯一一种**输入组合下取值 1，其余全为 0——具体就是「凡以原形式出现的变量取 1、凡以补形式出现的变量取 0」的那一行。

举个最小例子（三变量 x、y、z）：最小项 x · ȳ · z 只在 x=1, y=0, z=1 这一行为 1。反过来，给定输入组合 (1,0,1)，与之对应的最小项就是把取 1 的变量写原形、取 0 的写补：x ȳ z。

这个「一个最小项↔真值表里的一行 1」的双射，是下一节把任意函数拼成范式的砖块。初学者易错点：最小项必须**含全部 n 个变量**，缺一个都不算最小项（xy 在三变量语境下不是最小项，因为漏了 z）；以及别把「取 0 的变量写补」记反了。

### 11.2.2 积之和展开（析取范式 DNF）

任意布尔函数都能唯一地写成若干最小项的布尔和，这个表示叫**积之和展开（sum-of-products expansion）**，也叫**析取范式（disjunctive normal form, DNF）**。构造法极其机械：看函数的取值表，凡输出为 1 的每一行，写出该行对应的最小项，再把这些最小项全部用 `+` 连起来。

用公式概括，若函数 F 在输入集合 S ⊆ {0,1}ⁿ 上取 1，则

F = Σ over 各使 F=1 的行 的（该行的最小项）

设 F(x,y,z) 只在 (1,1,1) 与 (1,0,0) 两行为 1，则它的积之和展开是

F = x y z + x ȳ z̄

为什么这总能成功？因为每个最小项精确「点亮」真值表的一行、其余行为 0，把若干最小项加起来（布尔和），结果就在这几行为 1、别处为 0——恰好复刻了任意指定的取值表。这也顺带证明了 `{·, +, ¯}` 足以表达一切布尔函数（见 11.2.4）。

积之和里的「积」是最小项（AND），「和」是把它们 OR 起来，别把层次搞反；还要注意这里说的「唯一」是指**由最小项构成的**展开唯一（每个函数对应唯一一组使其为 1 的行），而经过化简后的「一般积之和表达式」并不唯一（那是 11.4 的话题）。

### 11.2.3 和之积表示（合取范式 CNF）

对偶地，任意布尔函数也能写成若干**最大项（maxterm）**的布尔积，叫**和之积展开（product-of-sums expansion）**，也叫**合取范式（conjunctive normal form, CNF）**。最大项是恰好用上全部 n 个变量各一次的布尔和：

y₁ + y₂ + … + yₙ

一个最大项只在**唯一一种**输入组合下取值 0（其余全为 1）——与最小项恰好相反。构造和之积：看取值表里输出为 0 的每一行，写出该行对应的最大项（规则与最小项相反：取 0 的变量写原形、取 1 的写补），再把这些最大项全部用 `·` 连起来。

直觉与「为什么」：每个最大项精确「压灭」真值表的一行（把该行变 0），别处保持 1；把若干最大项相乘（布尔积），结果就在这几行为 0、别处为 1。所以和之积从「哪些行该是 0」这一面来刻画函数，恰是积之和的对偶视角——积之和数 1、和之积数 0。当函数的 1 很多、0 很少时，和之积往往更短，反之积之和更短。

初学者最容易在最大项的「原形 / 补」规则上和最小项弄混。记法：最小项数 1，「1 对应原变量」；最大项数 0，一切反过来——变量取 0 时在最大项里写原形。这条镜像关系正是 11.1.5 对偶原理在范式层面的体现。

可选 sympy 验证，取 F = x ȳ + z，`to_dnf`（积之和）与 `to_cnf`（和之积）真实输出：

```
to_dnf: z | (x & ~y)
to_cnf: (x | z) & (z | ~y)
```

环境：Python 3.11.15 / sympy 1.14.0（基线 @2026-07-25）。这演示了同一函数的两种范式形态（此处 sympy 给的是化简后的范式而非「完整最小项 / 最大项」展开，两者作为同一函数的等价表示是一致的），可加固「DNF / CNF 双表示」这一结论。

### 11.2.4 函数完备集

一组布尔运算若能表达出**所有**布尔函数，就称为**函数完备（functionally complete）**的集合。由 11.2.2 可知 `{·, +, ¯}`（布尔积、和、补）是函数完备的——因为任何函数都有积之和展开。

进一步可以**缩减**这个集合：

由德摩根律 x + y = (x̄ · ȳ)‾，布尔和能用积与补表达，故 `{·, ¯}` 也函数完备；对偶地 `{+, ¯}` 也完备。

更强的是，单个运算就能完备：**与非（NAND，记 ↑）** 一个就够，**或非（NOR，记 ↓）** 一个也够。也就是说 `{NAND}` 和 `{NOR}` 各自是函数完备的单元素集合。

为什么这很重要（关联到 11.3）：它意味着理论上只用一种门（NAND 或 NOR）就能搭出任何数字电路，这在工程上极有价值（生产工艺只需造一种门）。一个最小例子：取补可以用与非实现，因为 x ↑ x = (x·x)‾ = x̄；有了补，再配合与非就能造出与、或，从而造出一切。

并非任意单运算都完备——单独的 `{·}`、`{+}`、`{¯}` 都不完备（例如只有 `·` 和 `+` 而没有补，就永远造不出「取反」这类函数）。「完备」是对整组运算的性质，判断要看能否补齐 `{·,+,¯}` 的表达力。NAND / NOR 的完备性证明属导论层，知道结论与「一种门即可」的直觉即可，工程实现归 L2-02。

## 11.3 逻辑门表示

### 11.3.1 基本逻辑门

逻辑门（logic gate）是把布尔运算物理化的基本元件，每个门接受若干布尔输入、输出一个布尔值。三种基本门与三个基本运算一一对应：

反相器（inverter / NOT 门）：一进一出，实现补，输出 x̄。

与门（AND 门）：多进一出，实现布尔积，输出 x·y·…。

或门（OR 门）：多进一出，实现布尔和，输出 x+y+…。

逻辑门只是 11.1 那三个运算换了张「电路图」的皮——门的功能表就是运算的真值表。与门、或门可以有多个输入（三输入与门输出 x·y·z），反相器则固定单输入。

初学者只需在此建立「运算↔门」的直觉对应即可，门的电气特性、延迟、扇入扇出等工程属性归 L2-02，本节不展开。易错点：别把与门 / 或门的形状（工程符号）当成本课重点——代数层关心的是「哪个门算哪个运算」，而不是画法。

### 11.3.2 布尔函数与组合电路的相互表示

把逻辑门按布尔表达式的结构接起来，就得到一个**组合电路（combinational circuit）**：给定输入，输出由当前输入唯一决定（无记忆 / 无反馈）。反过来，任何布尔函数都能画成这样一个电路。这建立起「布尔函数 ↔ 表达式 ↔ 门电路」的三方对应。

构造方法（从表达式到电路）：把表达式按运算优先级从内到外，每个 `¯` 换成反相器、每个 `·` 换成与门、每个 `+` 换成或门，前一层的输出接后一层的输入。例如实现

F = x · ȳ + z

先用反相器得 ȳ，再用与门得 x·ȳ，最后用或门把 x·ȳ 与 z 合并。

它把「布尔代数」和「数字硬件」缝在一起——化简布尔表达式（11.4）等价于减少电路里的门，这就是布尔代数在计算机里最直接的用途（加法器、多路选择器、控制逻辑等都由组合电路搭成）。一个最小例子：两位输入的「多数表决」函数（三个里至少两个为 1）可写成 xy + yz + xz，对应三个与门喂一个或门。

一是忘记按优先级分层（先补、再与、后或），接错层次会得到不同函数；二是把「组合电路」与「时序电路」混淆——本节只讲无记忆的组合电路，含触发器 / 反馈 / 状态的时序电路属 L2-02，不在此列。

### 11.3.3 用单一门类型搭建（NAND / NOR 的通用性）

承接 11.2.4 的函数完备性：既然 `{NAND}`（或 `{NOR}`）函数完备，那么**只用与非门一种门**就能搭出任何组合电路。工程上常把已有的与 / 或 / 非电路整体改写成全 NAND 或全 NOR 实现。

反相器 = 把与非门两个输入并到一起（x ↑ x = x̄）；与门 = 与非门后接一个反相器（也用与非实现）；或门 = 先把两输入各自取补再送进与非门（德摩根）。层层替换后，整张电路只剩一种门。

初学者知道「一种门即可、这有实际制造价值」这个结论与直觉即可；把任意电路系统化地转成全 NAND / NOR 的操作步骤、以及为什么工艺上偏好 NAND，属 L2-02 工程内容，本课不深挖。

## 11.4 电路的极小化（布尔表达式化简）

### 11.4.1 为什么要化简，以及「更简」的度量

同一个布尔函数有无穷多个等价表达式（11.1.2），**化简 / 极小化**就是在这些等价写法里找一个「代价最小」的，从而让实现它的电路门更少、更便宜、更快。常用的代价度量有两种：表达式里**字面量的总数**，以及所需**门的数目 / 层数**。

化简不改变函数（取值表不变），只改变表达式（写法）。目标函数固定，化简是在语义相同的语法集合里做优化。

「化简」不是「随便变短」，而是「在保持每一行取值不变的前提下变短」。任何一步化简都必须是 11.1.3 恒等式的合法应用，否则就改变了函数。为什么值得化简：在硬件里每个门都占面积、耗电、带延迟，少一个门就是实打实的成本节省——这是布尔代数在工程上最直接的收益点。

### 11.4.2 用恒等式做代数化简

代数化简就是反复套用 11.1.3 的恒等式，把积之和 / 和之积表达式逐步变短。最常用的几件武器：

分配律提取公因子：

x y + x z = x (y + z)

互补律 + 同一律「消变量」：

x y + x ȳ = x (y + ȳ) = x · 1 = x

支配律「吞并」：

x + x y = x

一个最小例子（合并两项）：

x ȳ + x y = x

因为提出公因子 x 得 x(ȳ + y)，括号内由互补律为 1，再由同一律得 x。直觉上，「ȳ 时也行、y 时也行」说明 y 根本无关紧要，可以整个消掉——这正是所有化简方法（含卡诺图）背后统一的逻辑：找出「无论某变量取何值结果都一样」的相邻项并把该变量消去。

一个更能体现价值的例子是**一致性 / 共识定理（consensus theorem）**：

x y + x̄ z + y z = x y + x̄ z

中间项 y z 是多余的（当 xy 或 x̄z 已覆盖它时它不贡献新的 1），可以直接删掉。初学者易错点：代数化简很依赖「看出该套哪条定律」，没有唯一路径，容易化到一半卡住或误删项；稳妥办法是每化一步都可用取值表抽查是否仍等价。另外「消变量」只在两项**除某一个变量的原 / 补形式外其余字面量完全相同**时才合法（如 xȳ 与 xy 只差 y 的正负），差两个及以上就不能直接合并。

可选 sympy 验证（`simplify_logic`），真实输出：

```
xy + x y' simplifies to: x
xy + x'z + yz simplifies to: (x & y) | (z & ~x)
```

环境：Python 3.11.15 / sympy 1.14.0（基线 @2026-07-25）。第一行确认 xȳ+xy 化为 x；第二行确认共识定理——xy + x̄z + yz 化简后为 xy + x̄z（多余的 yz 被删），与代数结论一致，可加固本节。

### 11.4.3 卡诺图与 Quine–McCluskey（系统化极小化，工程深挖归 L2-02）

纯代数化简靠「眼力」，容易漏。为此有两种**系统化**的极小化方法，本课只做导论、点明用途：

卡诺图（Karnaugh map, K-map）：把真值表画成一张按格雷码排列的方格图，使「只差一个变量」的最小项在图上相邻；圈出尽可能大的 2 的幂大小的「1 块」，每个块对应一个消去了若干变量的乘积项。它靠人眼识别相邻性，直观、快，但变量一多（一般超过 4～6 个）就画不动了。

Quine–McCluskey 算法：把卡诺图的思想变成**表格化、可编程**的流程——系统地两两比对最小项、合并相邻项得到「质蕴涵项（prime implicant）」，再挑出覆盖全部 1 的最小一组。它能处理更多变量，是计算机自动做电路极小化的经典算法基础。

这三者（代数化简 / 卡诺图 / Quine–McCluskey）目标完全一致——都在找函数的一个最小积之和；区别只是「怎么系统地找相邻可合并项」。卡诺图适合手算小规模，Quine–McCluskey 适合机器算大规模。

卡诺图的完整圈图规则、格雷码编号、无关项（don't-care）处理、Quine–McCluskey 的逐步质蕴涵表、以及化简到实际门电路的工程流程，全部归 L2-02（数字逻辑），本报告不展开操作细节，只需知道「有这两种系统方法、各自适用规模、都在做同一件事」即可。
