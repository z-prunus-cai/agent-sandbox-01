## 7.1 离散概率导论

### 7.1.1 样本空间、事件与拉普拉斯古典概型

一次随机试验所有可能结果构成的集合称为**样本空间**（sample space），记作 S；样本空间的任意子集称为一个**事件**（event）。当样本空间是**有限的**、且我们有理由认为每个结果**等可能**时，Rosen §7.1 采用拉普拉斯（Laplace）给出的古典概型定义：事件 E 的概率等于「有利结果数」比「全部结果数」，即

p(E) = |E| / |S|

其中 |E| 是事件 E 中的结果个数，|S| 是样本空间中的结果总数。

这是初学者接触概率的第一个、也是最直观的模型：把「求概率」变成「数数」。它之所以只在离散、等可能的场合成立，是因为分子分母都用「个数」来度量——一旦结果不是等可能（比如一枚灌了铅的骰子），或者结果有无穷多个（比如「在 0 到 1 之间随机取一个实数」），|E|/|S| 就不再有意义，必须换用 7.2 的公理化概率或 L2-03 的连续型概率。

最小例子：掷一颗公平骰子，S = {1,2,3,4,5,6}，事件「点数为偶数」E = {2,4,6}，于是

p(E) = 3 / 6 = 1/2

易错点有两个。其一是「等可能」这个前提常被默认却未被检验——古典概型的每一步都建立在「每个基本结果概率相同」之上，用之前要先确认这一点成立。其二是样本空间的粒度要选对：掷两颗骰子求「点数之和为 7」时，正确的样本空间是 36 个**有序对** {(1,1),(1,2),…,(6,6)}，而不是 11 个「和」{2,3,…,12}——因为后者里各个「和」并不等可能（和为 7 有 6 种凑法，和为 2 只有 1 种），直接对它用古典概型就会出错。

用 numpy 核对「两颗公平骰子之和为 7」的概率（脚本仅存于 scratchpad，此处贴真实输出）：

```
7.1 P(sum=7) exact = 1/6 = 0.16666666666666666
7.1 MC estimate      = 0.166826
```

（环境：Python 3.11.15 + numpy 2.4.6，2×10⁶ 次模拟；蒙特卡洛估计与精确值 1/6 一致。）

### 7.1.2 组合概率：用计数求概率

**组合概率**（combinatorial probability）是古典概型与大主题6（计数）的直接结合：当基本结果等可能时，求概率就退化为「用排列组合数出分子和分母」。这是本大主题在离散数学里真正承重的部分——它把计数的加法 / 乘法原理、排列 P(n,r)、组合 C(n,r) 直接用于概率计算。

典型形式：从一个大小为 n 的等可能集合中做某种选取，某事件 E 的概率为

p(E) = C(有利选法) / C(全部选法)

（分子分母按具体问题用排列或组合数表示。）

最小例子：从一副 52 张牌中随机抽 2 张，求「两张都是 A」的概率。全部抽法为 C(52,2) 种，有利抽法为从 4 张 A 里选 2 张即 C(4,2) 种，于是

p = C(4,2) / C(52,2) = 6 / 1326 = 1/221

numpy / math 精确核对（真实输出）：

```
7.1 P(two aces from 52) exact = 1/221 = 0.004524886877828055
```

为什么组合概率重要？因为现实中大量「等可能选取」问题——抽牌、摸球、随机分组、彩票——都归结为「数有利情形 ÷ 数全部情形」，而「数」正是大主题6的全部内容。初学者最常犯的错是**分子分母的计数口径不一致**：分母按「组合」（不计顺序）数，分子却按「排列」（计顺序）数，或反之。铁律是**分子分母必须用同一种计数方式**（同为有序或同为无序），否则比值无意义。

这一小节是本课「保留」而非「下放」的接口：更复杂的组合概率（生日问题、蒙提霍尔问题、容斥求概率）在 L2-03 大主题1「概率基础与计数」里继续展开，本课只需把「古典概型 = 数数」这个心智模型建立牢固。

## 7.2 概率论公理与条件概率（接口指向 L2-03）

> 本节主体下放 L2-03 大主题1、2。以下仅给「离散视角下够用的最小定义 + 直觉」，完整推论、独立性的系统理论、连续型推广等以 L2-03 为准。

### 7.2.1 概率的公理化定义（点到即止）

当结果不再等可能、或想把概率建立在更一般的基础上时，就从古典概型转向**公理化概率**。Rosen §7.2 给出离散样本空间上的概率函数：为每个结果 s 指定一个概率 p(s)，满足两条基本约束——非负且总和为 1：

0 ≤ p(s) ≤ 1（对每个结果 s）

Σ p(s) = 1（对样本空间中所有结果求和）

事件 E 的概率则定义为它所含结果的概率之和：

p(E) = Σ p(s)（对 s ∈ E 求和）

这套定义的意义在于**摆脱「等可能」的束缚**：只要给每个结果分配的权重非负、加起来为 1，就是一个合法的概率模型。古典概型只是「每个 p(s)=1/|S|」这一特例。由此可推出几条常用性质（本课只列结论、不展开证明）：

p(∅) = 0，p(S) = 1

p(Ē) = 1 − p(E)（补事件）

p(E ∪ F) = p(E) + p(F) − p(E ∩ F)（加法公式 / 容斥）

初学者要记住的直觉是：概率就是「总量为 1 的信念 / 权重，按结果分配」。补事件公式 p(Ē)=1−p(E) 在「至少一个」型问题里极其好用——正面数「至少一次成功」很难，反面数「一次都没成功」往往容易。完整的公理体系（Kolmogorov 三公理及其在连续空间的推广）与各性质的证明归 L2-03 大主题1，本课不展开。

### 7.2.2 条件概率与独立性（点到即止）

**条件概率**（conditional probability）刻画「已知事件 F 发生后，事件 E 发生的概率」，记作 p(E | F)，定义为

p(E | F) = p(E ∩ F) / p(F)，其中 p(F) > 0

**独立性**（independence）指一个事件是否发生不改变另一个的概率，其判定式为

p(E ∩ F) = p(E) · p(F)

条件概率的直觉是「缩小样本空间」：一旦知道 F 发生了，世界就被限制在 F 内部，此时 E 的概率要拿「E 与 F 同时发生」去比「F 发生」。最小例子：掷两颗骰子，已知第一颗是偶数（事件 A），问和为 7（事件 B）的概率——这里恰好 A、B 独立，可用 sympy/numpy 的精确分数核对（真实输出）：

```
7.2 P(A)= 1/2 P(B)= 1/6 P(AB)= 1/12 P(A)P(B)= 1/12 independent? True
```

因为 p(A∩B)=1/12 恰等于 p(A)p(B)=1/12，故 A 与 B 独立——已知第一颗为偶数并不改变「和为 7」的概率（仍是 1/6）。

最经典的易错点是把**独立**与**互斥**混为一谈：互斥（mutually exclusive）指两事件不能同时发生（p(E∩F)=0），独立指一个不影响另一个（p(E∩F)=p(E)p(F)）——两个概率都为正的互斥事件恰恰是**不**独立的（一个发生了，另一个必然不发生）。条件概率、独立性、条件独立、辛普森悖论等完整理论归 L2-03 大主题2，本课只需掌握上面两个定义式和「缩小样本空间」的直觉。

## 7.3 贝叶斯定理（离散）（接口指向 L2-03）

> 本节主体下放 L2-03 大主题2。以下给离散贝叶斯公式 + 一个坐实直觉的数值例子，完整框架（后验、共轭先验、假阳性悖论的系统讨论）以 L2-03 为准。

### 7.3.1 离散贝叶斯公式与「翻转条件」

**贝叶斯定理**（Bayes' theorem）用来「翻转条件概率的方向」：由已知的 p(F | E) 求出 p(E | F)。Rosen §7.3 给出的离散形式为

p(E | F) = p(F | E) · p(E) / [ p(F | E) · p(E) + p(F | Ē) · p(Ē) ]

其中分母是用**全概率公式**把 p(F) 拆成「经由 E」和「经由 Ē」两条路径之和。

它解决的核心问题是：现实里我们往往容易知道「原因→结果」方向的概率（如「有病时检测呈阳性的概率」＝灵敏度），却真正想要「结果→原因」方向的概率（如「检测呈阳性时真有病的概率」）。贝叶斯定理就是这两个方向之间的桥。

经典最小例子（罕见病检测）：设人群患病率 p(D)=0.001，检测灵敏度 p(+|D)=0.99，特异度使得健康者误报 p(+|D̄)=0.01。问「检测阳性者真患病」的概率 p(D|+)。代入公式并用精确分数核对（真实输出）：

```
7.3 Bayes P(D|+) exact = 11/122 = 0.090164
```

结果只有约 9%——尽管检测「很准」（灵敏度、特异度都 99%），阳性者真患病的概率却低得惊人。这就是著名的**基率谬误 / 假阳性悖论**：因为患病是罕见的（基率 0.001 极低），庞大的健康人群即便只有 1% 误报，其绝对数量也远超真正的病人。这一反直觉结论是贝叶斯定理最重要的教学价值，初学者务必亲手算一遍体会「先验（基率）会强烈拉动后验」。

易错点是**忽略先验 / 基率**，只盯着「检测准确率 99%」就下结论「阳性基本就是有病」。贝叶斯定理提醒我们：后验概率 = 似然 × 先验，再归一化；先验极小的时候，再高的似然也拉不动多少。贝叶斯的完整框架（一般划分下的贝叶斯公式、后验分布、共轭先验、在机器学习中的应用）归 L2-03 大主题2 与后续 ML 课程，本课只需掌握上面这一式子和罕见病例子的直觉。

## 7.4 期望与方差初步

> 「期望初步与线性性」是本课**保留**的部分（离散求和的直接应用）；「方差的完整理论与分布族」下放 L2-03 大主题4。

### 7.4.1 随机变量与期望

**随机变量**（random variable）是把样本空间中每个结果映射到一个实数的函数，记作 X : S → ℝ（离散情形取值可数）。它的**期望**（expected value / expectation，又称均值）是各取值按其概率加权的平均，Rosen §7.4 给出

E(X) = Σ p(s) · X(s)（对样本空间中所有结果 s 求和）

若按取值归并，也可写成

E(X) = Σ r · p(X = r)（对 X 的所有可能取值 r 求和）

期望的直觉是「大量重复试验后每次的平均结果」——把每个可能取值乘以它出现的概率再加总，就是长期平均。注意它是一个**加权平均**，权重是概率；因此期望不一定等于某个真实可取的值（掷骰子期望是 3.5，但骰子从不会掷出 3.5）。这一点是初学者的常见困惑：期望是「平均意义」上的中心，而非「最可能出现」的值（后者是众数）。

期望的定义本质上就是大主题2（求和）与本大主题（概率）的结合——它就是一个「以概率为权重的求和」。这也是为什么「期望初步」被留在离散数学课里：它不需要任何连续型 / 积分工具，纯粹是有限求和。

### 7.4.2 期望的线性性

**期望的线性性**（linearity of expectation）是期望最有用、最优美的性质：对任意随机变量 X、Y 和常数 a、b，

E(aX + bY) = a·E(X) + b·E(Y)

关键在于——**这条性质无论 X 与 Y 是否独立都成立**。

它之所以威力巨大，是因为它允许把一个复杂随机变量拆成若干简单变量之和，分别求期望再相加，而完全不必操心它们之间的相关性。最小例子：掷两颗骰子求和 X 的期望。单颗骰子期望是 3.5，由线性性直接得

E(X) = E(骰子1) + E(骰子2) = 3.5 + 3.5 = 7

无需枚举 36 种组合。numpy 核对（真实输出）：

```
7.4 E[sum] exact = 7 = 7.0  (linearity: 3.5+3.5=7)
```

初学者最容易惊讶也最该牢记的一点是「不要求独立」——很多人误以为 E(X+Y)=E(X)+E(Y) 需要 X、Y 独立，其实完全不需要（需要独立的是**方差**的可加性和 E(XY)=E(X)E(Y)，见下节）。线性性配合「指示随机变量」（把复杂计数拆成一堆 0/1 变量之和）是组合概率里极强的技巧，这一进阶用法归 L2-03 大主题4。

### 7.4.3 方差初步（点到即止，主体下放 L2-03）

**方差**（variance）度量随机变量偏离其期望的离散程度，定义为「偏差平方的期望」：

V(X) = E( (X − E(X))² )

一个等价且常用于计算的公式是

V(X) = E(X²) − (E(X))²

方差的直觉是「取值有多分散」：方差小意味着结果紧紧围绕期望，方差大意味着结果四散。取平方是为了让正负偏差不抵消、并放大大偏差的影响；其平方根即**标准差**（standard deviation），与 X 同量纲、更便于解读。

关于可加性有一条必须与 7.4.2 对照的易错点：**方差只有在随机变量相互独立时才可加**，即当 X、Y 独立时才有

V(X + Y) = V(X) + V(Y)

这与期望线性性的「无条件成立」形成鲜明对比——期望的和永远等于和的期望，但方差的和只有独立时才等于和的方差。最小例子：单颗公平骰子方差为 35/12，两颗独立骰子之和的方差为其两倍（真实输出）：

```
7.4 Var(one die) exact = 35/12 = 2.916667
7.4 Var(sum) = 2*Var(die) = 35/6 = 5.833333
7.4 MC Var(sum) = 5.8363406354097505
```

（蒙特卡洛 2×10⁶ 次得约 5.836，与精确值 35/6≈5.833 一致。）

方差的完整理论、切比雪夫不等式、各分布族（Bernoulli / Binomial / Poisson / Normal …）的期望与方差、协方差与相关系数等，全部归 L2-03 大主题4、5、7，本课只需掌握上面两个定义式、「方差＝分散程度」的直觉、以及「独立才能方差可加」这一与期望线性性的关键对照。
