## 2.1 集合与集合运算

### 2.1.1 集合、元素与两种描述法

集合（set）是一些对象的**无序、无重复**的整体，这些对象叫它的元素（element）或成员（member）。若 x 是集合 A 的元素，记

    x ∈ A

否则记 x ∉ A。描述一个集合有两种常用写法：**列举法**（roster method，把元素逐个列在花括号里，如 `{1,2,3}`）和**描述法**（set-builder，给出成员必须满足的性质），例如

    S = { x | x 是小于 10 的正偶数 } = {2, 4, 6, 8}

竖线 `|`（有的书写成冒号 `:`）读作"满足"。

初学者要抓住集合的两条"脾气"：**无序**和**不计重复**。所以 `{1,2,3}`、`{3,1,2}`、`{1,1,2,3}` 是同一个集合。这跟后面要讲的"序列/元组"正好相反——序列讲顺序、可重复。判断"某写法是不是集合"时，只看"哪些东西在里面"，不看它们排的顺序或写了几遍。

一个容易踩的坑：元素和"含这个元素的集合"是两回事。`3` 和 `{3}` 不同，前者是一个数、后者是一个装着这个数的集合；`3 ∈ {3}` 成立，但 `3 = {3}` 不成立。集合的元素本身也可以是集合，例如 `{ {1}, {2,3} }` 有两个元素，它们各自都是集合。

### 2.1.2 空集、全集与常见数集

空集（empty set）是没有任何元素的集合，记作

    ∅  （也写作 { }）

它是**唯一**的（只有一个空集），且是任何集合的子集。注意 `∅` 与 `{∅}` 不同：前者没有元素，后者有一个元素（那个元素恰好是空集），所以 `{∅}` 的大小是 1，不是 0。

全集（universal set，记 U）是当前讨论范围内"所有对象"的集合；它不是绝对的，而是随语境设定（讨论整数时 U 可取 ℤ，讨论字母时 U 可取 26 个字母）。补集运算（§2.1.6）总是相对某个全集 U 而言的。

离散数学里反复出现的标准数集记号（Rosen §2.1）：

    ℕ = {0, 1, 2, 3, …}（自然数，Rosen 含 0）
    ℤ = {…, −2, −1, 0, 1, 2, …}（整数）
    ℤ⁺ = {1, 2, 3, …}（正整数）
    ℚ = 有理数集    ℝ = 实数集    ℂ = 复数集

这里有一个必须点明的**来源分歧**：自然数 ℕ 是否含 0，各家不统一。Rosen 8e 明确把 0 算进 ℕ；但相当多欧洲教材/数论传统把 ℕ 定为从 1 起。本报告随一手锚点 Rosen，取 `0 ∈ ℕ`；读别的书时务必先看它的约定，这不是对错之争而是记号约定之别。

### 2.1.3 子集、真子集与集合相等

若 A 的每个元素都在 B 中，就说 A 是 B 的子集（subset），记

    A ⊆ B  ⟺  ∀x (x ∈ A → x ∈ B)

若额外还有 A ≠ B（即 B 里有元素不在 A 中），则 A 是 B 的真子集（proper subset），记 A ⊂ B。两个集合相等当且仅当互为子集：

    A = B  ⟺  (A ⊆ B) ∧ (B ⊆ A)

"双向包含"是证明两个集合相等的**标准套路**：想证 A = B，就分别证"任取 x ∈ A 推出 x ∈ B"和反向那一半。这条方法会在后面证集合恒等式时反复用到，也直接复用了大主题1的量词与蕴含。

两个易错点。其一：空集是**任何**集合的子集（`∅ ⊆ A` 恒成立），因为"∅ 的每个元素都在 A 中"这个蕴含前件永远为假、故整句为真（空真，vacuously true）——这正是大主题1里"前件为假则蕴含为真"的应用。其二：`∈` 和 `⊆` 不能混。`1 ∈ {1,2}` 对，`{1} ⊆ {1,2}` 对，但 `1 ⊆ {1,2}`（1 不是集合）和 `{1} ∈ {1,2}`（`{1}` 不是 `{1,2}` 的元素）都错。

### 2.1.4 幂集

集合 A 的幂集（power set）是 A 的**所有子集**组成的集合，记 P(A) 或 2^A：

    P(A) = { S | S ⊆ A }

若 A 有 n 个元素，则

    |P(A)| = 2ⁿ

例如 A = {1,2}，则 P(A) = { ∅, {1}, {2}, {1,2} }，共 2² = 4 个。注意 ∅ 和 A 自身永远是 P(A) 的成员。

为什么是 2ⁿ？直觉是：构造一个子集时，A 的每个元素都面临"选入 / 不选入"两种独立选择，n 个元素就是 n 个二选一，乘起来 2×2×…×2 = 2ⁿ（这用到大主题6的乘法原理）。正因如此，幂集大小随 n 指数爆炸——这也是 §2.4 里"幂集严格比原集合大"、以及不可数性的种子。

sympy 实测（基线 Py3.11.15/np2.4.6/gcc13.3 @2026-07-25，`sympy 1.14.0`，`FiniteSet(1,2).powerset()` 与 `len(FiniteSet(1,2,3).powerset())`）：

    power set of {1,2}: [{1}, {1, 2}, {2}, EmptySet]
    |P(A)| = 2^|A|: 8 == 2^3 = 8

（`EmptySet` 即 ∅，确实作为成员出现；三元素集幂集大小 8 = 2³。）

### 2.1.5 笛卡尔积与有序对

有序对（ordered pair）`(a, b)` 讲顺序：`(a,b) = (c,d)` 当且仅当 `a=c 且 b=d`；所以 `(1,2) ≠ (2,1)`（对比集合 `{1,2}={2,1}`）。集合 A 与 B 的笛卡尔积（Cartesian product）是所有"第一分量取自 A、第二分量取自 B"的有序对之集：

    A × B = { (a, b) | a ∈ A ∧ b ∈ B }

其大小 `|A × B| = |A|·|B|`。例如 `{1,2} × {a,b} = {(1,a),(1,b),(2,a),(2,b)}`，共 4 个。

要点：**笛卡尔积一般不交换**，`A × B ≠ B × A`（除非 A=B 或有一方为空）。它可推广到多个集合的 n 元组 `A₁ × A₂ × … × Aₙ`。笛卡尔积是后面"关系"（大主题9，关系就是 A×B 的子集）和"函数"（§2.2，函数是 A×B 的特殊子集）的地基，务必先建立"有序对讲顺序"的直觉。

### 2.1.6 并、交、差、补

设全集为 U，A、B 是它的子集。四种基本运算：

    A ∪ B = { x | x ∈ A ∨ x ∈ B }        （并集 union）
    A ∩ B = { x | x ∈ A ∧ x ∈ B }        （交集 intersection）
    A − B = { x | x ∈ A ∧ x ∉ B }        （差集 difference，也写 A \ B）
    Ā = U − A = { x ∈ U | x ∉ A }         （补集 complement，相对 U）

若 `A ∩ B = ∅`，称 A、B 不相交（disjoint）。

一个贯穿始终的类比：**集合运算和大主题1的逻辑联结词是一一对应的**——并对应"或"(∨)、交对应"且"(∧)、补对应"非"(¬)。所以集合恒等式（下一节）几乎就是逻辑等价式换了身衣服，德摩根律在两边长得一模一样。初学时把"∪ 想成或、∩ 想成且、补想成非"，绝大多数集合式子都能直接读懂。

易错点：`A − B` 不对称，`A − B ≠ B − A`（前者是"在 A 不在 B"，后者反之）。以 A={1,2,3}, B={2,3,4} 为例，`A−B={1}` 而 `B−A={4}`。

### 2.1.7 集合恒等式、文氏图与容斥

集合运算满足一批恒等式，和逻辑等价式结构一致。最常用的几条（Rosen §2.2 Table 1）：

    交换律：A ∪ B = B ∪ A，  A ∩ B = B ∩ A
    结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)
    分配律：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
    德摩根律：(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ，  (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
    幂等律：A ∪ A = A，  A ∩ A = A
    补律：A ∪ Aᶜ = U，  A ∩ Aᶜ = ∅

文氏图（Venn diagram）是理解这些式子的直觉工具：用交叠的圆代表集合，阴影出运算结果的区域，两个式子相等就看两张图阴影是否一致。但要注意——**文氏图只能"启发"不能"当证明"**（尤其集合数多时画不清），严格证明还是回 §2.1.3 的双向包含法。

对有限集，容斥原理（inclusion–exclusion，深入见大主题8）给出并集大小：

    |A ∪ B| = |A| + |B| − |A ∩ B|

直觉是"加 A 的、加 B 的，交集被数了两遍，减掉一遍"。

sympy 实测（同上环境，`FiniteSet` 上验德摩根、分配与容斥）：

    A|B = {1, 2, 3, 4}    A&B = {2, 3}    A-B = {1}    A complement in U = {4, 5}
    De Morgan lhs = {5} rhs = {5} equal: True
    distributive equal: True
    |A|+|B|-|A&B| = 4 == |A∪B| = 4

（取 A={1,2,3}, B={2,3,4}, C={3,4,5}, U={1,..,5}：德摩根两边同为 {5}、分配律两边相等、容斥数值吻合。）

### 2.1.8 有限集的基数（大小）

有限集 A 的基数（cardinality）`|A|` 就是它的元素个数，是一个非负整数。例如 `|{a,b,c}| = 3`、`|∅| = 0`。前面已用到的几条：`|P(A)| = 2^{|A|}`、`|A×B| = |A|·|B|`、容斥的 `|A∪B|`。

这里的"基数"是有限、朴素的计数概念；到 §2.4 会把"大小"这个词推广到**无限集**——那时不能再数个数，而要用"能否一一配对（双射）"来比较大小，会出现"无限也分大小"的反直觉结论。本节先把有限情形的记号握牢即可。

## 2.2 函数

### 2.2.1 函数、定义域、陪域与值域

从集合 A 到集合 B 的函数（function）f，记 `f: A → B`，是一条规则：给 A 中**每一个**元素 x，恰好指定 B 中**唯一一个**元素 f(x)。严格地说，函数就是笛卡尔积 A×B 的一个特殊子集（有序对集合），满足"每个 a 恰好出现在一个对 (a,b) 里"。相关术语：

    A = 定义域（domain）      B = 陪域 / 到达域（codomain）
    f(x) = x 在 f 下的像（image）
    值域 / 像集（range）= { f(x) | x ∈ A } ⊆ B

值域是"真正被取到的那些值"，是陪域的子集，可能是真子集。

初学者最常混的就是**陪域 ≠ 值域**。例如 `f: ℝ → ℝ, f(x)=x²`，陪域是全体实数 ℝ，但值域只有非负实数 `[0,∞)`——负数虽在陪域里却从没被取到。Rosen 明确区分这两个词；而不少中学材料和一些教材把"值域"直接当作陪域用，这是**来源用词分歧**，读题时务必看清指的是"目标集合"还是"实际取到的集合"。

两条"是函数"的硬性要求，缺一不可：**处处有定义**（A 里每个 x 都有像）和**单值**（一个 x 不能对两个不同的 y）。所以 `y² = x`（一个正 x 对应 ±√x 两个 y）不是从 ℝ 到 ℝ 的函数。

### 2.2.2 单射（一对一）

函数 f 是单射（injective / one-to-one）指：不同的输入给出不同的输出。等价的形式化写法：

    f 单射  ⟺  ∀a₁∀a₂ ( f(a₁) = f(a₂) → a₁ = a₂ )

"没有两个箭头射到同一个目标"。判断技巧就是上式的逆否用法：**假设 f(a₁)=f(a₂)，能推出 a₁=a₂，就是单射**；若能找到 a₁≠a₂ 却 f(a₁)=f(a₂)，就不是。

最小例子：`f(x)=2x`（ℝ→ℝ）是单射（2a=2b 推出 a=b）；`f(x)=x²`（ℝ→ℝ）不是单射，因为 f(−2)=f(2)=4 但 −2≠2。注意"是不是单射"依赖定义域：把 x² 的定义域限制到 `[0,∞)` 就变单射了。

### 2.2.3 满射（映上）

函数 f: A → B 是满射（surjective / onto）指：陪域 B 里**每个**元素都被取到，即值域等于陪域。形式化：

    f 满射  ⟺  ∀y ∈ B, ∃x ∈ A, f(x) = y

"B 里没有空着没人射中的点"。判断技巧：任取陪域里的 y，能不能解出一个 x 使 f(x)=y。

例子：`f: ℝ → ℝ, f(x)=2x` 是满射（任给 y，取 x=y/2 即可）；`f: ℝ → ℝ, f(x)=x²` 不是满射（负数 y 无 x 可解）。同样地，"是不是满射"依赖你把陪域声明成什么——把陪域改成 `[0,∞)`，x² 就成满射了。这再次说明：**函数三要素是"规则 + 定义域 + 陪域"，改陪域会改变单/满性质**。

### 2.2.4 双射（一一对应）

既是单射又是满射的函数叫双射（bijection / one-to-one correspondence）。双射把 A 和 B 的元素**完美配对**：A 里每个元素恰好对 B 里一个，反之亦然，无遗漏无重复。

    f 双射  ⟺  f 单射 ∧ f 满射

双射极其重要，原因有二：一是只有双射才有反函数（§2.2.5）；二是双射是 §2.4"比较两个集合大小"的唯一标准——两集合"一样大"的定义就是它们之间存在双射。对有限集，A、B 间存在双射当且仅当 `|A|=|B|`。

最小例子：`f: ℝ→ℝ, f(x)=2x+1` 是双射；恒等函数 `id(x)=x` 是双射。而 `f(x)=x²`（ℝ→ℝ）既不单也不满，不是双射。

### 2.2.5 反函数

若 f: A → B 是双射，则存在反函数（inverse function）`f⁻¹: B → A`，把每个 y 送回那个唯一的 x：

    f⁻¹(y) = x  ⟺  f(x) = y

且满足 `f⁻¹(f(x)) = x` 和 `f(f⁻¹(y)) = y`。

关键前提必须记牢：**只有双射才可逆**。若 f 不是满射，B 里有的 y 找不到原像，f⁻¹ 在那儿没定义；若 f 不是单射，一个 y 对应多个 x，f⁻¹ 不单值——两种情况都破坏"反函数也得是函数"。易错点：记号 `f⁻¹` 有歧义，`f⁻¹(x)` 指反函数，而 `f(x)⁻¹` 或 `1/f(x)` 是倒数，两者不同。

例子：`f(x)=2x+1` 的反函数是 `f⁻¹(y)=(y−1)/2`。

### 2.2.6 复合函数

给 `g: A → B` 和 `f: B → C`，复合（composition）`f∘g: A → C` 定义为"先做 g 再做 f"：

    (f ∘ g)(x) = f( g(x) )

注意书写顺序与执行顺序相反：`f∘g` 读作"f 后 g"，但先算 g。要求 g 的值域必须落在 f 的定义域内，否则复合无定义。

最需要提醒的易错点：**复合一般不交换**，`f∘g ≠ g∘f`。例如 f(x)=x+1, g(x)=2x：`(f∘g)(x)=2x+1`，`(g∘f)(x)=2x+2`，显然不等。复合与反函数的联系很漂亮：`f⁻¹∘f = id_A`、`f∘f⁻¹ = id_B`——反函数就是"能把 f 复合成恒等函数"的那个函数。复合是后面关系合成（大主题9）、函数式编程管道、以及链式法则（微积分 L1-04）的共同雏形。

### 2.2.7 取整函数：floor 与 ceil

两个在 CS 里极常用的函数：下取整（floor）`⌊x⌋` 是"不超过 x 的最大整数"，上取整（ceiling）`⌈x⌉` 是"不小于 x 的最小整数"。

    ⌊x⌋ = max { n ∈ ℤ | n ≤ x }
    ⌈x⌉ = min { n ∈ ℤ | n ≥ x }

例：`⌊2.7⌋=2`，`⌈2.3⌉=3`。它们把实数映到整数，值域是 ℤ，定义域是 ℝ。

初学者最容易在**负数**上翻车：下取整是"往负无穷方向取"，不是"截断/去小数"。所以 `⌊−2.3⌋ = −3`（不是 −2！），`⌈−2.3⌉ = −2`。这与很多编程语言的整数除法"向零截断"不同（如 C 的 `(-7)/2` 得 −3 而非 `⌊−3.5⌋=−4`），做算法分析时要分清"数学下取整"与"语言截断"。取整函数在分块、散列、二分查找取中点（`mid = ⌊(l+r)/2⌋`）、复杂度分析里到处出现。

sympy 实测（同上环境，`floor`/`ceiling`）：

    floor(2.7)= 2   ceil(2.3)= 3
    floor(-2.3)= -3   ceil(-2.3)= -2

（坐实"负数下取整往更小的整数走"这一最易错点。）

## 2.3 序列与求和

### 2.3.1 序列

序列（sequence）是一串按顺序排列、可重复的对象，本质上是**定义域为整数（某区间）的函数** `a: ℤ⁺ → S`（或从 0 起），把下标 n 映到第 n 项 aₙ。整个序列记作 `{aₙ}`。序列可以有限或无限。

与集合对照记忆：**序列讲顺序、可重复；集合无序、不重复**。所以 `1,2,2,3` 是合法序列（有重复的第 2 项），但作为集合就是 `{1,2,3}`。序列的"第 n 项" aₙ 是它的核心，给出 aₙ 关于 n 的公式（通项）就完全确定了序列。序列是后面递归（大主题5）、递推（大主题8）、以及算法里循环/数组的数学模型。

### 2.3.2 等差数列

等差数列（arithmetic progression）相邻两项差固定（公差 d），通项：

    aₙ = a + (n−1) d     （首项 a，从 n=1 起）

例：`2, 5, 8, 11, …` 首项 a=2、公差 d=3，第 n 项 `2+3(n−1)`。判断是否等差，看"后一项减前一项"是不是常数。它是"线性增长"的离散版，图像上各点落在一条直线上。

### 2.3.3 等比数列

等比数列（geometric progression）相邻两项比固定（公比 r），通项：

    aₙ = a · r^{n−1}     （首项 a，从 n=1 起；Rosen 常用 a·rⁿ 从 n=0 起）

例：`3, 6, 12, 24, …` 首项 3、公比 2。等比是"指数增长/衰减"的离散版：`r>1` 爆炸增长，`0<r<1` 衰减到 0，`r<0` 正负交替。它是指数函数、复利、算法里"每步规模减半"的模型。注意首项从 n=0 还是 n=1 起、通项里指数是 n 还是 n−1，随书约定不同，用前先对齐。

### 2.3.4 递推序列

递推地定义序列 = 用**前面的项**表示后面的项，再给初始项。经典例子斐波那契数列：

    F₀ = 0,  F₁ = 1,  Fₙ = Fₙ₋₁ + Fₙ₋₂  (n ≥ 2)

得到 `0,1,1,2,3,5,8,13,…`。

递推定义分两部分：**基础情形**（给出最前面几项）和**递推式**（用旧项算新项），这与大主题5的递归/归纳同构——递推定义的序列，其性质往往用归纳法证明。递推式给的是"局部规则"，若想直接用 n 算出 aₙ 而不迭代，需要求"闭式解/通项"，那是大主题8（求解线性递推）的任务；本节只要能"读懂递推、按规则逐项算出来"即可。等差、等比其实也是最简单的递推（`aₙ=aₙ₋₁+d`、`aₙ=r·aₙ₋₁`）。

### 2.3.5 求和记号

连加用求和记号（sigma notation）：

    ∑_{i=m}^{n} aᵢ = a_m + a_{m+1} + … + a_n

i 是求和指标（哑变量，换成 j、k 不影响结果），m、n 是下界和上界。若 m>n，约定为空和（结果 0）。求和可换指标、可拆分、可提取常数：

    ∑_{i=1}^{n} (c·aᵢ) = c · ∑_{i=1}^{n} aᵢ     （常数提取）
    ∑_{i=1}^{n} (aᵢ + bᵢ) = ∑ aᵢ + ∑ bᵢ         （线性可加）

初学者要习惯"指标是临时的、只在求和内部有意义"，以及**边界要数对**：`∑_{i=1}^{n}` 有 n 项，`∑_{i=0}^{n}` 有 n+1 项，差一错误（off-by-one）是这里最常见的坑。求和记号是后面复杂度分析、期望计算（大主题7）、级数（微积分）的通用语言。

### 2.3.6 等差求和（闭式公式）

前 n 个正整数之和，以及一般等差和：

    ∑_{i=1}^{n} i = n(n+1)/2

    ∑_{i=1}^{n} [a + (i−1)d] = n·a + d·n(n−1)/2 = n(2a + (n−1)d)/2

第一条有个著名直觉（高斯配对法）：把 `1+2+…+n` 和倒过来的 `n+…+2+1` 上下对齐相加，每列都是 `n+1`，共 n 列，总和 `n(n+1)`，再除以 2。一般等差和 = 项数 ×（首项+末项）/2，也是同一配对思想。

sympy 实测（同上环境，`summation`）：

    sum i, i=1..n = n**2/2 + n/2            （即 n(n+1)/2）
    arith sum = n*(2*a + d*n - d)/2          （即 n(2a+(n−1)d)/2）
    numeric 1..100 = 5050   formula n(n+1)/2 = 5050

### 2.3.7 等比求和（有限与无穷）

有限等比和（公比 r≠1）：

    ∑_{i=0}^{n−1} a·rⁱ = a · (rⁿ − 1)/(r − 1)     （r ≠ 1；r=1 时和为 n·a）

当 |r|<1 时，无穷等比级数收敛：

    ∑_{i=0}^{∞} a·rⁱ = a/(1 − r)     （仅当 |r| < 1）

有限公式的推导直觉：设 S = a+ar+…+ar^{n−1}，两边乘 r 得 rS，错位相减 `S − rS` 中间项全抵消，剩 `a − ar^n`，解出 S。无穷情形只是让 rⁿ→0（因 |r|<1）取极限。**收敛条件 |r|<1 必须写明**——|r|≥1 时无穷和发散，套 a/(1−r) 会得出荒谬结果（这是初学者最爱踩的坑）。等比求和是二进制"1+2+4+…+2^{n−1}=2ⁿ−1"、以及分治复杂度求和的基础。

sympy 实测（同上环境）：

    geom finite sum = Piecewise((a*n, Eq(r, 1)), (a*(r**n - 1)/(r - 1), True))
    geom infinite sum (a=1, r=1/2, i=0..∞) = 2
    numeric geom 2^0..2^9 = 1023   formula (2^10 - 1) = 1023

（sympy 自动分出 r=1 的特例 `a·n`，与公式的分段约定吻合；无穷和 `∑(1/2)ⁱ = 1/(1−1/2) = 2` 坐实收敛值。）

### 2.3.8 常用闭式求和

除等差、等比外，这几条平方/立方和常在复杂度分析里出现，务必眼熟：

    ∑_{i=1}^{n} i² = n(n+1)(2n+1)/6

    ∑_{i=1}^{n} i³ = [ n(n+1)/2 ]²

第二条有个漂亮巧合：立方和恰等于"前 n 个整数和的平方"。这些公式都可用数学归纳法（大主题5）证明；本节只要求会查用、并知道它们的量级（`∑i²` 是 Θ(n³)、`∑i` 是 Θ(n²)），这直接喂给大主题3的函数增长。

sympy 实测（同上环境）：

    sum i^2, i=1..n = n**3/3 + n**2/2 + n/6     （展开即 n(n+1)(2n+1)/6）

#### 来源与时效（本小主题末集中列）
- 一手锚点：Rosen 8e §2.4「Sequences and Summations」（序列作为整数域函数、等差/等比数列、递推序列含斐波那契、求和记号与运算律、闭式求和公式 Table 2：∑i, ∑i², ∑i³, 几何和、无穷几何和）。核实 2026-07-26。
- 交叉锚：MIT 6.042J "Sums and Asymptotics" 一章（几何和/等差和推导、错位相减法），与 Rosen 公式一致。
- 比对结论：等差和 n(n+1)/2、等比有限和 a(rⁿ−1)/(r−1)、无穷和 a/(1−r)(|r|<1)、∑i²/∑i³ 闭式，两源一致；全部经 sympy 符号+数值双重坐实。
- 冲突/约定分歧：序列/等比数列的**起始下标**（从 0 还是 1）、通项指数（rⁿ vs r^{n−1}）随书不同，非对错而是约定；本报告按各条就地注明。无穷几何和的收敛条件 |r|<1 属硬性前提，不可省。

## 2.4 集合的基数

### 2.4.1 等势：用双射比较"大小"

要比较两个集合谁大谁小（尤其无限集），不能数个数，而用**双射**：两个集合 A、B 有**相同基数**（等势，equinumerous），记 |A|=|B|，当且仅当存在从 A 到 B 的双射。

    |A| = |B|  ⟺  存在双射 f: A → B

对有限集这与"元素个数相等"一致；威力在无限集：只要能把两个无限集的元素"一一配对、无遗漏无重复"，就说它们一样大——哪怕直觉上一个像是另一个的真子集。这正是无限集反直觉的根源（真子集可以和整体一样大），务必先接受"大小 = 能否配对"这个定义，再看下面的例子。

### 2.4.2 可数集

一个集合是可数的（countable），如果它是有限集，或者能和正整数集 ℤ⁺（等价地 ℕ）建立双射；后一种叫可数无限（countably infinite），其基数记 ℵ₀（aleph-null）。

    A 可数无限  ⟺  |A| = |ℤ⁺| = ℵ₀

"可数无限"的直白含义：**能把元素排成一个无穷列表 a₁, a₂, a₃, …**，每个元素迟早出现、有确定编号。这等价于"存在一种枚举方式不重不漏地列出全部元素"。

一个必须点明的**用词分歧**：Rosen 8e 中 countable = 有限 或 可数无限（即"至多可数"）；而另一些教材/口语把 countable 专指"可数无限"。本报告随 Rosen（countable 含有限）。读文献时看清作者把有限集算不算 countable。

反直觉的经典例子：**偶数集和整数集一样大**。配对 `f(n)=2n` 是 ℤ⁺ 到正偶数的双射，故正偶数是可数无限，|正偶数|=ℵ₀=|ℤ⁺|——真子集与整体等势，这只在无限集里发生。整数集 ℤ 也可数（按 `0,1,−1,2,−2,…` 排列）。

### 2.4.3 有理数可数（对角线枚举）

一个更反直觉的结论：**有理数 ℚ 是可数的**，尽管它在数轴上"稠密"（任意两个有理数之间还有无穷多个）。

证法直觉（Cantor 的锯齿/对角线枚举）：把所有正分数 p/q 摆成一张二维表格（行是分子 p、列是分母 q），然后沿反对角线一条条地走——`1/1, 1/2, 2/1, 3/1, 2/2, 1/3, …`，跳过不是最简分数的重复项。这样每个正有理数都会在某一步被编到号，于是能排成一列，故可数。加上 0 和负数仍可数。

这里的关键教益：**"稠密/看起来无穷密"并不意味着不可数**。可数与否只取决于"能不能排成一张无穷列表"，与在数轴上排得多密无关。这与下一节的实数形成鲜明对比。

### 2.4.4 康托对角线论证：实数不可数

康托证明了**实数集 ℝ 不可数**——它"真的比" ℤ⁺ 大。只证区间 (0,1) 的实数就够（因为 (0,1) 与 ℝ 等势）。

反证法（对角线论证 diagonal argument）：假设 (0,1) 里的实数可数，则能把它们排成一列，每个写成无穷小数：

    r₁ = 0. d₁₁ d₁₂ d₁₃ …
    r₂ = 0. d₂₁ d₂₂ d₂₃ …
    r₃ = 0. d₃₁ d₃₂ d₃₃ …

现在**沿对角线造一个新数** x = 0.x₁x₂x₃…，规定第 k 位 xₖ 与 dₖₖ 不同（比如 dₖₖ 是 4 就取 5，否则取 4，避开 0/9 以躲开 0.999…=1 的表示歧义）。这个 x 与列表里**每一个** rₖ 至少在第 k 位不同，故 x 不在列表中——但 x 明明是 (0,1) 里的实数。矛盾！所以 (0,1)、进而 ℝ 不可数。

这个论证是逻辑与 CS 的分水岭级工具：它同一招（对角化）后来证明了幂集严格大于原集合（|A|<|P(A)|，康托定理）、图灵机停机问题不可判定（大主题12 / L3-05）、以及不可计算函数的存在。初学者只要抓住核心招式——"假设能列全，就造一个和列表每一行都不同的反例"——就掌握了它的精神。

### 2.4.5 基数的层级与连续统

于是无限也分大小：可数无限的 ℵ₀（ℤ⁺、ℤ、ℚ）严格小于实数的基数（连续统，记 c 或 2^{ℵ₀}）。一般地康托定理给出

    |A| < |P(A)|

任何集合都严格小于它的幂集，所以无限基数有**无穷多层**，没有最大的无限。

补充两点（点到即止，不深挖）：其一，Schröder–Bernstein 定理说"若有 A→B 与 B→A 两个单射，则存在双射"，是证明等势的常用工具。其二，"ℵ₀ 和 c 之间还有没有别的基数"（连续统假设）在 ZFC 公理系统里既不能证明也不能否证——属集合论深水区，本课不涉。本节目标只是让初学者接受"无限有大小之分、实数比自然数多"。

- 一手锚点：Rosen 8e §2.5「Cardinality of Sets」（等势定义、countable/countably infinite、ℵ₀、ℚ 可数的锯齿枚举、实数不可数的康托对角线论证、Schröder–Bernstein 提及、|A|<|P(A)|）。核实 2026-07-26。
- 交叉锚：MIT 6.042J "Infinite Sets" 一章（以双射定义等势、对角线论证证 {0,1} 无穷序列/实数不可数、幂集严格更大），论证结构与 Rosen 一致。
- 比对结论：等势用双射、ℚ 可数、ℝ 不可数（对角线）、|A|<|P(A)|，两源一致；本节为纯证明（subtopic 标 [—]），无本机数值验证点，未做 Python 实证（如实标注）。

## 2.5 矩阵基础（仅记号）

> 边界声明：按 prompt，本小主题只做矩阵的记号与最基础运算，供离散数学后续（关系矩阵大主题9、图的邻接矩阵大主题10）复用；矩阵的深挖（向量空间、行列式、特征值、分解等）归 L1-03 线性代数，本课不外扩。

### 2.5.1 矩阵与记号

矩阵（matrix）是数的矩形排列。一个 m×n 矩阵有 m 行 n 列，元素 aᵢⱼ 表示第 i 行第 j 列的项：

    A = [aᵢⱼ]  (1 ≤ i ≤ m, 1 ≤ j ≤ n)

m=n 时称方阵。行、列的先后（"行数 × 列数"、"先行后列"）是全书统一约定，读写下标 aᵢⱼ 时第一个下标永远是行。矩阵在离散数学里主要当"表格/关系的载体"用：关系可用 0-1 矩阵表示、图可用邻接矩阵表示，运算的意义要到那些主题才充分展开。

### 2.5.2 加法、数乘与矩阵乘法

同型（行列数相同）矩阵**逐元素相加**；数乘是每个元素乘该数。矩阵乘法 `C = AB` 要求 A 的列数 = B 的行数（A 是 m×k，B 是 k×n，结果 C 是 m×n），元素为

    cᵢⱼ = ∑_{t=1}^{k} aᵢₜ · bₜⱼ

即"C 的第 i 行第 j 列 = A 的第 i 行与 B 的第 j 列对应相乘再求和"（行乘列）。

初学者两个关键点。其一，**维度必须匹配**：只有"左矩阵列数 = 右矩阵行数"才能相乘，否则无定义——这是最常见的错误来源。其二，**矩阵乘法不交换**，一般 `AB ≠ BA`（甚至一个有定义另一个没定义）。加法则可交换、可结合。矩阵乘法的定义（行乘列求和）正是后面关系合成、图中路径计数（邻接矩阵的幂数出长度为 k 的通路数）的机械基础。

numpy 实测（基线 Py3.11.15/np2.4.6/gcc13.3 @2026-07-25，`numpy 2.4.6`，`M(2×3) @ N(3×2)`）：

    M shape (2, 3)  N shape (3, 2)
    M@N =
     [[2 1]
      [1 1]]

（2×3 乘 3×2 得 2×2，维度匹配规则与行乘列求和定义均坐实。）

### 2.5.3 转置与对称矩阵

矩阵 A 的转置（transpose）`Aᵀ` 把行列互换：`(Aᵀ)ᵢⱼ = aⱼᵢ`。若方阵满足 `A = Aᵀ`（即 `aᵢⱼ = aⱼᵢ`，沿主对角线镜像对称），称对称矩阵（symmetric）。

对称性在离散数学里有直接语义：**无向图的邻接矩阵一定对称**（i 到 j 有边等价于 j 到 i 有边），**对称关系的关系矩阵也对称**（大主题9）。所以"矩阵对称"和"关系/图的对称"是一回事，记号在这里和语义接上了。

### 2.5.4 0-1 矩阵与布尔运算

元素只取 0 或 1 的矩阵叫 0-1 矩阵（zero-one matrix），是离散数学表示"是/否、有/无关系"的主力。对 0-1 矩阵，除普通算术运算外，还定义按位的布尔运算：并 `∨`（对应元素取或）、交 `∧`（取且），以及布尔积（Boolean product）`A ⊙ B`：

    (A ⊙ B)ᵢⱼ = ⋁_{t=1}^{k} ( aᵢₜ ∧ bₜⱼ )

即把普通矩阵乘法里的"乘"换成"且(∧)"、"加"换成"或(∨)"。结果仍是 0-1 矩阵（只关心"有没有一条中转路径连通"，不关心有几条）。

这个布尔积正是大主题9关系合成、传递闭包（Warshall 算法）和图连通性的计算工具：`(A⊙A)ᵢⱼ=1` 表示 i 经一个中间点两步能到 j。初学者要分清它与普通矩阵乘法——普通积数"路径条数"，布尔积只答"通不通"。

numpy 实测（同上环境，普通积 vs 布尔积对同一对 0-1 矩阵）：

    M@N (普通积) =
     [[2 1]
      [1 1]]
    boolean join (0-1 布尔积 ⊙) =
     [[1 1]
      [1 1]]

（同一对矩阵：普通积左上角 2 表示"有 2 条两步路径"，布尔积对应位置为 1 只表示"连通"——两种乘法语义差异一目了然。）
