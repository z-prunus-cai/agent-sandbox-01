## 8.1 线性变换

### 8.1.1 线性变换的定义：保持加法与数乘

**线性变换（linear transformation）**是从一个向量空间 V 到另一个向量空间 W 的映射 T，它同时满足两条"保持结构"的规则——保持向量加法、保持标量数乘：

    T(u + v) = T(u) + T(v)      （可加性）

    T(c·v) = c·T(v)             （齐次性）

这两条常合并写成一条等价的"保持线性组合"：对任意向量 u、v 和任意标量 c、d，

    T(c·u + d·v) = c·T(u) + d·T(v)

满足此式的 T 就叫线性变换（当 V = W 时也叫**线性算子**）。一个直接推论是**线性变换必把零向量映到零向量**：T(0) = T(0·v) = 0·T(v) = 0。

线性变换是"尊重网格的变换"。想象平面上均匀的方格网，线性变换作用后，网格线仍是平行且等距的直线、原点不动——它可以旋转、拉伸、剪切、投影空间，但不能把直线掰弯、不能把网格挪离原点。"保持加法与数乘"正是这句几何话的代数化：先加再变换，等于先变换再加（可加性）；先放大再变换，等于先变换再放大（齐次性）。

为什么这两条如此关键？因为它们让 T 被"极少的信息"完全决定：只要知道 T 在一组基上的值，就能算出 T 在**任意**向量上的值。设 v = c₁v₁ + … + cₙvₙ（用基展开），则由线性性

    T(v) = c₁·T(v₁) + … + cₙ·T(vₙ)

也就是说，n 个基向量的像 T(v₁),…,T(vₙ) 一旦定下，整个变换就锁死了。这正是 8.1.3 能用"一个矩阵"代表整个变换的根本原因。

平面上"逆时针旋转 90°"是线性变换（网格仍是网格，原点不动）；"把每个向量平移 (1,0)"**不是**线性变换（它把 0 映到 (1,0)，违反 T(0)=0，网格整体挪离了原点）。这个对照是易错点的核心：平移看起来"很规整"，但它不线性——线性的世界里原点是钉死的。

### 8.1.2 常见的线性变换与"看似线性其实不是"的反例

拿到一个映射 T，逐条验证可加性与齐次性（或直接验证 T(cu+dv)=cT(u)+dT(v)），全过才是线性。下面这批是标准的线性变换：矩阵乘法 T(x)=Ax（**最典型，任何矩阵都给出一个线性变换**）、平面旋转与反射、向子空间的投影、坐标的缩放、剪切（shear）、多项式的求导算子 d/dx 与定积分算子、以及零变换 T(v)=0 和恒等变换 T(v)=v。

而下面这些**不是**线性变换：平移 T(x)=x+b（b≠0，破坏 T(0)=0）、仿射映射 T(x)=Ax+b（同理，b≠0 时不线性）、取长度 T(x)=‖x‖（因为 T(cx)=|c|‖x‖≠c‖x‖，且三角不等式不是等式）、平方 T(x)=x²、加常数等。

辅助理解——为什么"求导"是线性变换？把多项式看成向量空间（比如 P₂ = {a+bx+cx²}，它是 3 维空间，基 {1, x, x²}），求导算子 D=d/dx 满足 D(p+q)=Dp+Dq 且 D(c·p)=c·Dp，正是微积分里最基本的两条求导法则。所以"求导"在 P₂ 上就是一个线性算子，它甚至有矩阵（见 8.1.3 的例子）。这个例子很重要：它让初学者看到"向量"不必是数组，多项式、函数也能当向量，"线性变换"这个概念远比"矩阵乘法"更宽。

判断线性时，"看起来对称/规整"没有用，必须回到两条定义式。平移和仿射映射是最常见的陷阱——它们在图形学里到处都是，但严格说不是线性变换，需要用"齐次坐标"技巧升一维才能塞进矩阵乘法框架（这属于 L5-03 图形学范畴，本报告不深挖）。

### 8.1.3 变换的矩阵表示：相对输入基与输出基

一旦给 V 选定一组**输入基** v₁,…,vₙ、给 W 选定一组**输出基** w₁,…,wₘ，线性变换 T:V→W 就对应唯一一个 m×n 矩阵 A。构造法则是——**A 的第 j 列，是 T(vⱼ) 用输出基表示时的坐标**：

    T(vⱼ) = A₁ⱼ·w₁ + A₂ⱼ·w₂ + … + Aₘⱼ·wₘ

于是"对向量作用 T"就变成了"对坐标向量左乘矩阵 A"：若 v 在输入基下的坐标是 c，则 T(v) 在输出基下的坐标就是 Ac。

    输入坐标 c  ──左乘 A──▶  输出坐标 Ac

辅助说明——这套构造为什么必然成立、且列就该这么取？回到 8.1.1 的关键事实：T 被它在基向量上的值完全决定。所以我们只需记录 T(v₁),…,T(vₙ) 这 n 个像；而每个像又是 W 里的向量，用输出基一展开就得到一列 m 个坐标。把这 n 列并排，就是 m×n 矩阵。之后任意 v=c₁v₁+…+cₙvₙ 的像由线性性自动是各列的线性组合 c₁(第1列)+…+cₙ(第n列)=Ac——这恰好就是矩阵乘法的"列组合"视角。可以说：**矩阵乘法的定义，正是为了让"作用变换"等于"左乘矩阵"而量身定做的**。

最小例子（本机已验证）：在 P₂ 上取基 {1, x, x²}，求导算子 D 满足 D(1)=0、D(x)=1、D(x²)=2x。把每个像用基 {1,x,x²} 写坐标当列：

    D 的矩阵 = [[0, 1, 0],
               [0, 0, 2],
               [0, 0, 0]]

拿 p=3+2x+5x²（坐标 (3,2,5)）验证：矩阵乘 (3,2,5) 得 (2,10,0)，正对应 p'=2+10x。数值上 sympy 给出 D·(3,2,5)ᵀ=(2,10,0)ᵀ，与手算一致（脚本见文末）。

几个必须点破的要点。第一，**矩阵依赖于基的选择**：换一组基，同一个 T 会写出不同的矩阵（这正是 8.2、8.3 的主题）。所以"矩阵"是 T 的表示，不是 T 本身。第二，**列的方向别记反**：列对应"输入基向量的像"，不是"输出"。第三，当 V=W 且输入基=输出基时 A 是方阵，这是最常见的情形（线性算子）；一般 T:Rⁿ→Rᵐ 用标准基时，A 就是那个"显然的"m×n 矩阵，T(x)=Ax。第四，规范化的特例：恒等变换在**同一组基**下矩阵是单位阵 I，但恒等变换在**两组不同基**下的矩阵恰好就是基变换矩阵（见 8.2.2）——这是连接 8.1 与 8.2 的桥。

## 8.2 基变换

### 8.2.1 坐标：同一向量在不同基下的不同数组

向量本身是"空间里的一个几何对象"，而它的**坐标**是"用某组基把它拆开后得到的系数数组"——换基，坐标就变，向量没变。设基为 v₁,…,vₙ，向量 x 的坐标 (c₁,…,cₙ) 定义为唯一满足下式的系数：

    x = c₁·v₁ + c₂·v₂ + … + cₙ·vₙ

我们平时写的列向量 (3,1) 其实默认是"标准基 e₁=(1,0)、e₂=(0,1) 下的坐标"，因为 (3,1)=3e₁+1e₂。一旦换用别的基，同一个几何向量的坐标数组就不同了。

辅助说明——为什么坐标一定存在且唯一？这正是"基"的定义在起作用：基 = 线性无关 + 张成空间（见大主题2）。张成保证任何 x 都能被基表示（系数存在），线性无关保证表示方式只有一种（系数唯一）。所以"给定一组基，向量与坐标一一对应"，坐标系才有意义。

取新基 b₁=(1,1)、b₂=(1,−1)。几何向量 x（标准坐标 (3,1)）在新基下的坐标是什么？要找 c₁,c₂ 使 c₁(1,1)+c₂(1,−1)=(3,1)，解得 c₁=2、c₂=1。本机验证：解 B·c=(3,1) 得 c=(2,1)，回代 B·(2,1)=(3,1) 成立（脚本见文末）。所以同一个向量，标准坐标写 (3,1)、新基坐标写 (2,1)——数组不同，箭头是同一根。

初学者常把"坐标"当成向量的本质属性，于是换基时会疑惑"向量怎么变了"。要反复强调：**换基不动向量，只换描述向量所用的语言**。这与 8.1.3 的"矩阵依赖基"是同一件事的两面——向量的表示（坐标）和变换的表示（矩阵）都随基而变。

### 8.2.2 基变换矩阵与坐标变换公式

把新基向量 b₁,…,bₙ（用旧/标准坐标写出）**按列拼**成矩阵 B=[b₁ b₂ … bₙ]，B 就是**基变换矩阵**。它在"新基坐标 c"与"标准坐标 x"之间来回翻译：

    x = B·c        （新基坐标 c → 标准坐标 x）

    c = B⁻¹·x      （标准坐标 x → 新基坐标 c）

因为 B 的列是一组基、线性无关，所以 B 一定可逆，B⁻¹ 存在，两个方向都能走。

辅助说明——公式 x=Bc 为什么是这个方向、别记反？直接从定义 x=c₁b₁+…+cₙbₙ 出发：右边正是"矩阵 B 的列的线性组合，系数是 c"，也就是 B·c（这又是矩阵乘法的列组合视角）。所以"把新基坐标还原成标准坐标"是左乘 B；反过来"从标准坐标求新基坐标"就要解方程或左乘 B⁻¹。一个记忆锚点：**B 的列是新基向量本身，所以 B 把"新基下的坐标"搬回"标准世界"**。

与 8.1 的连接（重要）：基变换矩阵 B 其实就是**恒等变换 I 在"以新基为输入基、以标准基为输出基"下的矩阵**——把每个新基向量 bⱼ 恒等地送出去、再用标准基写坐标，得到的列正好是 bⱼ 本身。这解释了为什么基变换能纳入 8.1 的统一框架：换基不过是"什么都没做的变换（恒等）"在两组基之间的矩阵。

(1) B 装的是"新基向量在标准坐标下的分量"，不要装成"标准基在新基下的分量"（那是 B⁻¹）。(2) 只有当基向量彼此正交且单位长（正交规范基）时才有 B⁻¹=Bᵀ 的便利，一般基必须真的求逆。(3) 坐标变换 c=B⁻¹x 与 8.2.3 的"矩阵变换 A'=M⁻¹AM"方向看似都带 B⁻¹，但一个作用在向量坐标上、一个作用在算子矩阵上，别混为一谈。

### 8.2.3 同一变换在不同基下的矩阵：相似关系的来历

设线性算子 T 在标准基下的矩阵是 A，换到新基（基变换矩阵 M，其列为新基向量的标准坐标）后，T 在新基下的矩阵 A′ 满足

    A′ = M⁻¹·A·M

这就是"同一个变换、两组基、两个矩阵"之间的桥。左乘 M⁻¹、右乘 M 这个"三明治"结构，就是下一节相似矩阵的定义来源。

辅助说明——这条公式怎么"读"出来（初学者友好的追踪法）？想象一个向量在新基下的坐标是 c，要算 T 作用后它在新基下的新坐标，分三步走："先把 c 翻译成标准坐标"→ 左乘 M 得 Mc；"在标准世界里作用 T"→ 左乘 A 得 AMc；"再把结果翻译回新基坐标"→ 左乘 M⁻¹ 得 M⁻¹AMc。三步连起来，从 c 到新坐标的整条通道就是 M⁻¹AM，所以 T 在新基下的矩阵是 A′=M⁻¹AM。把它记成一句话：**换基做变换 = 翻译过去（M）、办事（A）、翻译回来（M⁻¹）**。

取 A=[[2,1],[0,3]]、新基 M=[[1,1],[1,−1]]，算得

    A′ = M⁻¹AM = [[3, -1],
                 [0,  2]]

它与 A 的特征值都是 {2,3}、迹都是 5、行列式都是 6（脚本见文末）——这不是巧合，正是 8.3.1 要讲的"相似不变量"。

为什么要费劲换基？因为**好的基能让矩阵变简单**。若能换到"由特征向量组成的基"，A′ 就变成对角阵 Λ（这正是大主题5 的对角化 A=SΛS⁻¹，把 M 取成特征向量矩阵 S 的特例）；MIT 18.06"Change of Basis; Image Compression"一课还给出工程动机——图像/信号压缩就是换到一组"能量集中在少数坐标"的好基（如傅里叶基、小波基），只保留大系数。所以基变换不是形式游戏，而是"选坐标语言让问题最简"的通用手段。

## 8.3 相似矩阵与 Jordan 形

### 8.3.1 相似矩阵 B=M⁻¹AM 与相似不变量

两个 n×n 方阵 A 与 B 称为**相似（similar）**，如果存在可逆矩阵 M 使得

    B = M⁻¹·A·M

由 8.2.3 可知，相似的本质是"A 与 B 是**同一个线性变换**在两组不同基下的矩阵"。相似是一个等价关系（自反、对称、传递），它把所有方阵划分成一个个"相似类"，每一类对应"本质相同"的变换。相似矩阵共享一批**相似不变量**：**相同的特征值（含代数重数）、相同的特征多项式、相同的迹、相同的行列式、相同的秩、相同的 Jordan 形**。

辅助说明——为什么这些量相似不变，直觉在哪？既然 A、B 是同一变换换基而来，那些"不依赖坐标系、只描述变换本身"的量当然不该变。特征值是"变换把哪些方向只做拉伸、拉伸多少"，与用什么坐标无关；迹（对角线之和）等于特征值之和、行列式等于特征值之积（大主题4/5），自然也不变。代数上可一步验证：det(B−λI)=det(M⁻¹AM−λM⁻¹M)=det(M⁻¹(A−λI)M)=det(A−λI)，特征多项式逐字相同，于是特征值全同。

一个**关键的易错点**：相似矩阵特征值相同，但**特征向量一般不同**——若 Ax=λx，则 B(M⁻¹x)=λ(M⁻¹x)，特征向量被 M⁻¹ 搬了个位置。所以"同特征值、异特征向量"是常态。另一个易错点：**特征值相同不一定相似**！反例是单位阵 I 与 Jordan 块 [[1,1],[0,1]]：两者特征值都是 (1,1)，但 I 只跟自己相似（M⁻¹IM=I 恒成立），二者不相似。要判定是否相似，光看特征值不够，得看到 Jordan 形（8.3.2）是否相同。

A=[[2,1],[0,3]] 与 A′=[[3,−1],[0,2]] 由 M=[[1,1],[1,−1]] 相似，二者特征值 {2,3}、迹 5、det 6 全相同（脚本见文末），印证相似不变量。

与前面的连接：**对角化就是相似的特例**——A 可对角化 ⇔ A 相似于对角阵 Λ（大主题5 的 A=SΛS⁻¹ 里 S 就是那个 M）。所以 8.3 是把大主题5"对角化"放进"换基/相似"的大框架里重新审视：对角化 = 换到特征向量基这组"最好的基"。

### 8.3.2 Jordan 标准形：不可对角化时的"最简替身"

不是每个方阵都能对角化（当独立特征向量凑不满 n 个、即某特征值的几何重数 < 代数重数时就"缺陷/defective"）。**Jordan 标准形定理**给出退而求其次的最简形式：**任何复方阵 A 都相似于一个"Jordan 形"矩阵 J**——J 是分块对角阵，每个对角块是一个 **Jordan 块**：

    Jₖ(λ) = [[λ, 1, 0, …, 0],
             [0, λ, 1, …, 0],
             [ …            ],
             [0, 0, …, λ, 1],
             [0, 0, …, 0, λ]]

即对角线上是特征值 λ、紧邻的上对角线（superdiagonal）上是 1、其余为 0。J 在"相似"意义下唯一（只差各 Jordan 块的排列顺序）。当所有 Jordan 块都是 1×1 时，J 就是对角阵——这恰好就是可对角化的情形。

辅助说明——怎么读懂它、每个数字的含义。把 Jordan 形理解成"对角化失败后能达到的最接近对角的样子"：对角线仍放特征值（这保证特征值、迹、det 都对），只是被迫在少数位置多放几个 1 来"补齐"缺失的特征向量。关键计数规则（导论级记住结论即可）：**Jordan 块的总个数 = 独立特征向量的总个数（各特征值几何重数之和）**；某个特征值 λ 对应的所有 Jordan 块阶数之和 = λ 的代数重数。所以"块越多、越碎"就越接近对角，"出现大块"正是不可对角化的标志。

最小例子（本机已验证）：
- 可对角化例：A=[[2,1],[0,3]] 有两个不同特征值、两个独立特征向量，Jordan 形就是对角阵 diag(2,3)。
- 缺陷例：A=[[2,1],[0,2]] 特征值 2 是二重根，却只有一个独立特征向量，无法对角化；它本身已是一个 2×2 Jordan 块 J₂(2)=[[2,1],[0,2]]，sympy 给出 Jordan 形正是它自己，且 A=P·J·P⁻¹ 校验为真。
- 3×3 例：A=[[5,4,2],[0,5,0],[0,0,5]] 的 Jordan 形为 [[5,1,0],[0,5,0],[0,0,5]]（一个 2×2 块 + 一个 1×1 块，共 2 个块 = 2 个独立特征向量）。
（脚本与真实输出见文末。）

为什么"复方阵"这个前提重要？Jordan 形保证存在的前提是特征多项式在数域上能完全分解成一次因式——复数域 C 代数封闭，必然可分，所以定理对**所有复方阵**成立；在实数域上若有复特征值则未必能写成实 Jordan 形（需成对处理）。这是初学者常忽略的边界。

(1) Jordan 形不是数值稳定的计算对象——微小扰动就能把"缺陷"抹平成可对角化，所以工程数值计算几乎不用 Jordan 形，改用 SVD/Schur 分解；Jordan 形的价值在**理论**（分类相似类、解 defective 情形的 du/dt=Au 等），这与大主题7 SVD"数值主力"形成互补。(2) "特征值相同"绝不等于"相似"，判据要落到 Jordan 形相同（承接 8.3.1 的反例 I vs [[1,1],[0,1]]）。(3) 上对角线的 1 也有约定差异：部分教材把 1 放在下对角线（subdiagonal），块形上下翻转，含义相同，读书时看清约定。

#### 来源与时效
- 锚点：Strang《Introduction to Linear Algebra》§6.6"Similar Matrices"（相似定义 B=M⁻¹AM、相似类、相似不变量、Jordan 形作为每个相似类的代表、Jordan 块结构、"特征值相同未必相似"）；核实 2026-07-26。
- 锚点：MIT 18.06/18.06SC (Fall 2011) syllabus，Unit III 之"Similar Matrices and Jordan Form"一课；https://www.ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/syllabus ，核实 2026-07-26。
- 交叉锚：Axler《Linear Algebra Done Right》第 8 章（复向量空间上的算子）以**广义特征向量**为主线导出 Jordan 形，并证明"每个复向量空间上的算子都有 Jordan 基"，结论与 Strang/18.06 一致；Axler 全书刻意把行列式后置，用广义特征空间而非特征多项式路径论证，视角互补。
- 成熟度：GA/稳定。
- 冲突项：三源在"相似定义、相似不变量、Jordan 形存在唯一（相似意义、复域）"上一致；差异为 (a) 论证路径（Strang/18.06 走特征值/矩阵，Axler 走广义特征向量、避开行列式）；(b) Jordan 块上/下对角线放 1 的排版约定不同（内容等价）。均属约定/进路差异，非结论冲突。

```python
import numpy as np, sympy as sp

# 8.1.3 求导算子 d/dx 在基 {1,x,x^2} 下的矩阵表示
D = sp.Matrix([[0,1,0],[0,0,2],[0,0,0]])
p = sp.Matrix([3,2,5])                    # 3 + 2x + 5x^2
print("8.1 D*p:", list(D*p))              # -> (2,10,0)  即 2+10x

# 8.2 基变换与坐标变换：新基 b1=(1,1), b2=(1,-1)
B = np.array([[1.0,1.0],[1.0,-1.0]])
v_std = np.array([3.0,1.0])
c = np.linalg.solve(B, v_std)             # 新基坐标
print("8.2 new-basis coords:", c, " B@c:", B@c)

# 8.2.3 / 8.3.1 同一算子换基后矩阵 A' = M^-1 A M，相似不变量
A = np.array([[2.0,1.0],[0.0,3.0]]); M = B
Ap = np.linalg.inv(M) @ A @ M
print("8.2.3 A' =\n", np.round(Ap,6))
print("eig A:", np.sort(np.linalg.eigvals(A)), " eig A':", np.sort(np.linalg.eigvals(Ap)))
print("trace:", np.trace(A), np.trace(Ap), " det:", round(np.linalg.det(A),6), round(np.linalg.det(Ap),6))

# 8.3.2 Jordan 形
print("8.3 diag J:", sp.Matrix([[2,1],[0,3]]).jordan_form()[1].tolist())
Anil = sp.Matrix([[2,1],[0,2]]); P2,J2 = Anil.jordan_form()
print("8.3 defective J:", J2.tolist(), " A=PJP^-1:", sp.simplify(P2*J2*P2.inv()-Anil)==sp.zeros(2))
print("8.3 3x3 J:", sp.Matrix([[5,4,2],[0,5,0],[0,0,5]]).jordan_form()[1].tolist())
```
