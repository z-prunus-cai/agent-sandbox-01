## 6.1 对称矩阵与谱定理

### 6.1.1 对称矩阵的定义

对称矩阵（symmetric matrix）是等于自身转置的方阵，即满足

    A = Aᵀ

展开来说就是每个元素关于主对角线镜像相等：aᵢⱼ = aⱼᵢ 对所有 i, j 成立。例如

    ⎡ 2  1  0 ⎤
    ⎢ 1  2  1 ⎥
    ⎣ 0  1  2 ⎦

把它沿左上到右下的对角线翻折，落上去的元素完全重合。

对称是对**方阵**才有意义的性质（Aᵀ 要能和 A 比较，行列数必须都相同）。对称矩阵在实际问题里到处都是——距离矩阵、相关/协方差矩阵、图的邻接矩阵（无向图）、二次型的系数矩阵，天生就对称。

一个特别重要的"制造对称矩阵"的方法：对任意矩阵 A（哪怕不是方阵，是 m×n），乘积

    AᵀA   和   AAᵀ

**永远是对称的**。验证很简单，用转置的反序律 (AᵀA)ᵀ = Aᵀ(Aᵀ)ᵀ = AᵀA，转置回自己，所以对称。这个事实在大主题3（最小二乘的 AᵀA）和大主题7（SVD）里反复出现，是连接各章的暗线。

不要把"对称"和"正交"混淆。对称是 A=Aᵀ；正交（orthogonal）是 QᵀQ=I（即 Qᵀ=Q⁻¹）。两者是完全不同的条件，只有个别矩阵（如单位阵、某些反射阵）同时满足。

### 6.1.2 谱定理：实对称矩阵可正交对角化

谱定理（spectral theorem，实数版）是本大主题的核心结论：**每个实对称矩阵都可以被正交对角化**。具体地，若 A 是 n×n 实对称矩阵，则存在一个正交矩阵 Q（各列是单位长度且两两正交的特征向量）和一个对角矩阵 Λ（对角线是特征值），使得

    A = Q Λ Qᵀ

由于 Q 正交（Q⁻¹ = Qᵀ），这也就是把大主题5的一般对角化 A = SΛS⁻¹ 里的 S 升级成了正交矩阵 Q，逆矩阵直接变成转置，无需求逆。

这条定理其实打包了三个断言，缺一不可：

    (1) A 的所有特征值都是实数；
    (2) A 一定有一整组（n 个）互相正交的特征向量，可张成 ℝⁿ；
    (3) 因此 A 一定可对角化，且对角化矩阵可取为正交矩阵。

辅助理解。大主题5 里我们知道"能不能对角化"要看特征向量够不够、独不独立，一般矩阵可能因为特征值重根而特征向量不够（不可对角化，得退到 Jordan 形）。谱定理给对称矩阵开了绿灯：**无论特征值有没有重根，对称矩阵永远凑得齐 n 个正交特征向量**，永远可对角化。这就是"对称矩阵最听话"的准确含义。

最小例子（本机验证见 6.1.5）：上面那个三对角矩阵 A，特征值是 2−√2、2、2+√2（约 0.586、2、3.414），全是实数；对应特征向量两两垂直，归一化后拼成的 Q 满足 QᵀQ=I，且 QΛQᵀ 精确重建 A。

这组特征值的集合称为矩阵的"谱"（spectrum），"谱定理"因此得名。展开写还有个常见记法 A = QΛQᵀ 中把 Q 的列记作 q₁,…,qₙ，则

    A = λ₁ q₁q₁ᵀ + λ₂ q₂q₂ᵀ + ⋯ + λₙ qₙqₙᵀ

这叫谱分解（见 6.1.4）。

### 6.1.3 为什么实特征值、为什么正交特征向量

先看"特征值为实数"的直觉与理由。对一般矩阵，特征值可能是复数（例如旋转矩阵的特征值成对出现为共轭复数）。对称矩阵之所以逃不出实数，关键在于一个内积恒等式：设 Ax = λx（x 可能取复向量），用共轭转置 x̄ᵀ 左乘两边，可以证明 λ 等于两个实数（x̄ᵀAx 与 x̄ᵀx）之比，因而 λ 必为实数。初学者不必记住整段推导，记住"对称性逼着虚部消掉"这个结论即可。

再看"不同特征值的特征向量互相正交"，这一条有一个短到可以现场推的论证，值得掌握。设

    A x₁ = λ₁ x₁,   A x₂ = λ₂ x₂,   且 λ₁ ≠ λ₂

考察 x₁ᵀ A x₂ 这个数，从两个方向算它：

    x₁ᵀ A x₂ = x₁ᵀ (A x₂) = λ₂ (x₁ᵀ x₂)

又因为 A 对称（A=Aᵀ），可以把 A 挪到左边作用在 x₁ 上：

    x₁ᵀ A x₂ = (Aᵀ x₁)ᵀ x₂ = (A x₁)ᵀ x₂ = λ₁ (x₁ᵀ x₂)

同一个数得到两个表达式，相减得

    (λ₁ − λ₂)(x₁ᵀ x₂) = 0

因为 λ₁ ≠ λ₂，只能是 x₁ᵀx₂ = 0，即两向量正交。

对特征值有重根的情形（同一个 λ 对应一整个特征子空间），谱定理保证在这个子空间内部还能挑出一组正交基（可用 Gram–Schmidt，见大主题3），于是整组 n 个特征向量仍可取成两两正交。

正交只是"不同特征值之间"自动成立；同一特征值的多个特征向量不一定天然正交，需要你在其特征子空间内主动正交化。另一个常见误区是把结论用到非对称矩阵上——非对称矩阵的特征向量一般既不正交、特征值也可能是复数，谱定理不适用。

### 6.1.4 谱分解：把对称矩阵拆成投影之和

由 A = QΛQᵀ 按列展开，可以把对称矩阵写成一串"秩1投影矩阵"的加权和：

    A = λ₁ q₁q₁ᵀ + λ₂ q₂q₂ᵀ + ⋯ + λₙ qₙqₙᵀ

其中每个 qᵢqᵢᵀ 都是投影到第 i 个特征方向（单位向量 qᵢ 张成的直线）上的投影矩阵，λᵢ 是这个方向上的"拉伸倍数"。

这个视角把大主题3（投影矩阵 P=qqᵀ，满足 P²=P、Pᵀ=P）和大主题5（特征值=沿特征方向的缩放）缝在一起：**对称矩阵作用在任意向量上，等于先把向量分解到 n 个互相垂直的特征方向上，各方向按 λᵢ 缩放，再加回去**。因为方向两两垂直，各方向互不干扰，这正是"对称矩阵好算"的几何原因。

Q 的列构成 ℝⁿ 的一组标准正交基，任意 x 可写成 x = Σ(qᵢᵀx)qᵢ（在正交基下的坐标就是内积）。A 作用后 Ax = Σ λᵢ(qᵢᵀx)qᵢ，把它整理成矩阵形式就是上面的谱分解。

当所有 λᵢ ≥ 0 时，这个分解直接给出对称半正定矩阵的"平方根"，也是 SVD（大主题7）在方阵对称情形下的特例——对称矩阵的奇异值就是其特征值的绝对值。

### 6.1.5 本机验证：谱定理三断言

用基线环境 numpy 的 `linalg.eigh`（专为实对称/Hermitian 阵设计，返回实特征值与正交特征向量）核对 6.1.2 的三个断言。

    import numpy as np
    A = np.array([[2.,1.,0.],[1.,2.,1.],[0.,1.,2.]])
    w, Q = np.linalg.eigh(A)
    print(w)                                  # 特征值
    print(Q.T @ Q)                            # 应为单位阵 -> 正交
    print(np.allclose(Q @ np.diag(w) @ Q.T, A))   # QΛQᵀ 重建 A

真实输出（基线 Py3.11.15/np2.4.6 @2026-07-26）：

    [0.5858 2.     3.4142]
    [[ 1. -0. -0.]
     [-0.  1.  0.]
     [-0.  0.  1.]]
    True

三点验证：特征值 0.5858、2、3.4142 全为实数（即 2−√2、2、2+√2）；QᵀQ 为单位阵，说明特征向量两两正交且单位化；QΛQᵀ 精确重建 A。与谱定理一致。（实证仅为加固，多来源比对见本小主题末。）

## 6.2 正定矩阵

### 6.2.1 正定矩阵的定义

正定矩阵（positive definite matrix）指一个**对称**矩阵 A，使得对每一个非零向量 x 都有二次型严格为正：

    xᵀ A x > 0    对所有 x ≠ 0

注意"正定"这个词在标准语境里默认前提是对称（Strang 与 18.06 都在对称矩阵框架内定义正定）。若把对称性去掉另有推广，但本课与绝大多数教材约定正定矩阵即对称正定。

把 A 看成一台"打分机器"，输入一个方向向量 x，输出一个数 xᵀAx。正定就是"除了原点，往任何方向打分都是正的"。最简单的正定矩阵是单位阵 I，此时 xᵀIx = ‖x‖² 就是长度平方，显然对非零 x 恒正。

为什么要求对称？因为二次型 xᵀAx 只"看得见" A 的对称部分——任何反对称部分对 xᵀAx 的贡献恒为 0（xᵀAx 是个标量，等于自己的转置 xᵀAᵀx，故只有 (A+Aᵀ)/2 起作用）。所以讨论正定性时把 A 限定成对称是自然且无损的。

正定是"最好的一档"矩阵——它一定可逆（否则存在 x≠0 使 Ax=0，则 xᵀAx=0 违反定义），特征值全正，行列式为正，是后续 Cholesky 分解、优化中判定极小值、协方差矩阵合法性的核心条件。

### 6.2.2 正定性的等价判定条件

直接按定义"对所有 x≠0 验证 xᵀAx>0"无法穷举，所以真正好用的是下面这组**互相等价**的判据。对一个对称矩阵 A，以下条件彼此等价，任一成立即正定：

    (1) 所有特征值 λᵢ > 0；
    (2) 所有主元（pivots，消元不换行时对角线上出现的数）> 0；
    (3) 所有顺序主子式（leading principal minors，即左上角 1×1, 2×2, …, n×n 子块的行列式）> 0；
    (4) 存在列满秩矩阵 R 使 A = RᵀR（含 Cholesky 分解，见 6.2.4）。

四条从不同角度切入同一件事，实际做题按矩阵形态挑最省力的一条用。

各条的直觉。条件 (1) 最贴近谱定理：由 A=QΛQᵀ，二次型 xᵀAx = Σ λᵢ(qᵢᵀx)²，是一堆平方项按 λᵢ 加权求和；只有全部 λᵢ>0 才能保证对任意非零 x 结果为正。条件 (3)（常称 Sylvester 判据）最适合手算小矩阵，因为它只需从左上角逐层算行列式，符号全正即通过，不必真求特征值。条件 (2) 与 (3) 由消元过程天然联系：第 k 个主元等于第 k 个顺序主子式除以第 k−1 个，所以"主元全正"和"顺序主子式全正"互相等价。

最小例子。取

    ⎡ 2  1  0 ⎤
    A = ⎢ 1  2  1 ⎥
    ⎣ 0  1  2 ⎦

顺序主子式：2 > 0，det[[2,1],[1,2]] = 3 > 0，det A = 4 > 0，全正，故正定；本机核对（6.2.5）显示其主元为 2、3/2、4/3 全正、特征值 0.586/2/3.414 全正，三条判据一致。

Sylvester 判据用的是**顺序主子式**（一路从左上角取的那几个子块行列式），**不是所有主子式**，更不能只看某几个对角元。一个反例是

    ⎡ 1  0 ⎤
    ⎢ 0 −1 ⎥

对角元一正一负，明显不正定，无需多算。

判据 (2)(3) 默认矩阵**已经对称**。对非对称矩阵套用顺序主子式判据会得错误结论，必须先确认对称。

仅 det A > 0 **不足以**保证正定。二维反例

    ⎡ −1  0 ⎤
    ⎢  0 −1 ⎥

行列式 = 1 > 0，但它是负定的（两个特征值都是 −1）。行列式为正只说明负特征值成对，必须逐个顺序主子式都为正才行。

### 6.2.3 半正定、不定、负定的分类

把定义里的严格不等号放松或反向，就得到对称矩阵按二次型符号的完整分类：

    正定（positive definite）:      xᵀAx > 0  对所有 x≠0    ⇔ 所有 λᵢ > 0
    半正定（positive semidefinite）: xᵀAx ≥ 0  对所有 x      ⇔ 所有 λᵢ ≥ 0
    不定（indefinite）:             xᵀAx 有正有负            ⇔ λᵢ 有正有负
    负定 / 半负定:                  把上面不等号反向          ⇔ 所有 λᵢ < 0 / ≤ 0

半正定是最常打交道的"放松版"：它允许某些方向上二次型取 0，对应存在特征值等于 0（矩阵奇异、不可逆）。

任何形如 AᵀA 的矩阵永远至少半正定，因为

    xᵀ(AᵀA)x = (Ax)ᵀ(Ax) = ‖Ax‖² ≥ 0

当 A 列满秩（Ax=0 只有零解）时它升级为正定。这解释了大主题3 里最小二乘正规方程 AᵀAx̂=Aᵀb 为何在 A 列无关时有唯一解——AᵀA 正定故可逆。协方差矩阵同理天然半正定。

最小例子与易错点。

    ⎡ 1  2 ⎤
    B = ⎢ 2  1 ⎥
    ⎣      ⎦

特征值为 −1 与 3（本机核对见 6.2.5），一正一负，所以 B **不定**；取 x=(1,−1) 得 xᵀBx = 1−2−2+1 = −2 < 0，取 x=(1,1) 得 +6 > 0，确实两种符号都出现。易错点：光看到 B 全是正数元素就误判正定——元素的正负和正定性没有直接关系，判据要看特征值/顺序主子式（B 的第二个顺序主子式 det B = 1−4 = −3 < 0，一眼否定正定）。

### 6.2.4 A=RᵀR 与 Cholesky 分解判据

正定的第四条等价刻画：对称矩阵 A 正定，当且仅当它能写成

    A = RᵀR

其中 R 是列满秩矩阵。特别地，当把 R 取成上三角且对角线为正时，这个分解唯一，称为 Cholesky 分解（Cholesky 记法常写 A = LLᵀ，L 为下三角、对角线为正）。

这条判据在数值实践里最实用：**判断一个对称矩阵是否正定，最快的可靠办法是尝试做 Cholesky 分解——能成功就正定，中途要对负数开平方就不正定**。它比求全部特征值便宜，是数值库判定正定性的标准手段。

A=RᵀR 意味着二次型 xᵀAx = xᵀRᵀRx = ‖Rx‖² 是某个向量的长度平方，长度平方对非零 x 恒正（前提 R 列满秩使 Rx≠0），所以正定。反过来正定矩阵由谱分解 A=QΛQᵀ、令 R = Λ^{1/2}Qᵀ（Λ 各元开正平方根，因特征值全正故可开）即得。Cholesky 的 L 的对角元恰是各主元的平方根，把 6.2.2 的"主元全正"具体化。

这解释了正定矩阵为何在优化里被青睐——A=RᵀR 保证二次型是"完美的碗"，且分解可用于高效求解线性系统。

### 6.2.5 本机验证：三判据一致 + 一个不定反例

用 numpy 对 6.2.2 的正定阵 A 同时核对顺序主子式、特征值、Cholesky，并对 6.2.3 的不定阵 B 反证。

    import numpy as np
    A = np.array([[2.,1.,0.],[1.,2.,1.],[0.,1.,2.]])
    print(A[0,0], np.linalg.det(A[:2,:2]), np.linalg.det(A))  # 顺序主子式
    print(np.linalg.eigh(A)[0])                                # 特征值
    L = np.linalg.cholesky(A); print(np.diag(L))               # Cholesky 对角
    B = np.array([[1.,2.],[2.,1.]])
    print(np.linalg.eigh(B)[0])                                # B 特征值
    try:
        np.linalg.cholesky(B)
    except np.linalg.LinAlgError as e:
        print("B not PD:", e)

真实输出（基线 Py3.11.15/np2.4.6 @2026-07-26）：

    2.0 3.0000000000000004 4.0
    [0.5858 2.     3.4142]
    [1.4142 1.2247 1.1547]
    [-1.  3.]
    B not PD: Matrix is not positive definite

核对：A 的三个顺序主子式 2、3、4 全正，特征值全正，Cholesky 成功（L 对角 √2、√1.5、√(4/3) 即各主元平方根），三条判据一致 → 正定。B 特征值 −1 与 3 一正一负、Cholesky 直接失败 → 不定，与手算 det B=−3<0 相符。

## 6.3 二次型与最小化

### 6.3.1 二次型 xᵀAx

二次型（quadratic form）是变量的纯二次齐次多项式，可统一写成矩阵形式

    Q(x) = xᵀ A x

其中 A 取对称矩阵。展开来看，n 个变量的二次型是所有"变量两两乘积"的加权和：

    xᵀ A x = Σᵢ Σⱼ aᵢⱼ xᵢ xⱼ

例如二维

    xᵀ A x = a₁₁ x₁² + 2a₁₂ x₁x₂ + a₂₂ x₂²

对角元 aᵢᵢ 是平方项 xᵢ² 的系数，非对角元贡献交叉项 x₁x₂（因对称，a₁₂ 与 a₂₁ 相等，合并出系数 2a₁₂）。

**给定一个二次多项式，如何反推它的对称系数矩阵 A**。规则是——平方项 xᵢ² 的系数直接放到对角 aᵢᵢ；交叉项 xᵢxⱼ 的系数**对半分**给 aᵢⱼ 和 aⱼᵢ。比如 Q = 2x₁² + 6x₁x₂ + 5x₂²，则 a₁₁=2、a₂₂=5、a₁₂=a₂₁=3，即

    ⎡ 2  3 ⎤
    A = ⎢ 3  5 ⎥
    ⎣      ⎦

为什么要"对半分"取对称：如 6.2.1 所述，只有 A 的对称部分对 xᵀAx 有贡献，取对称形式使 A 唯一、并让 6.1/6.2 的所有谱结构与判据都能直接套用。

二次型把"正定性"这个代数条件变成一个函数图像——Q(x)=xᵀAx 的曲面形状完全由 A 的正定性分类（6.2.3）决定，这就是下一节最小化的舞台。

### 6.3.2 配方、合同变换与二次型的形状

判断二次型 Q(x)=xᵀAx 的"形状"（是碗、是山、还是马鞍），核心手段是配方——把它写成一串加权平方之和：

    xᵀ A x = d₁ (…)² + d₂ (…)² + ⋯

其中各括号是变量的线性组合、系数 dᵢ 恰是消元得到的主元。若所有 dᵢ>0，每个平方项非负、整体是开口向上的碗（正定）；若出现负系数，则某方向能把 Q 拉成负值（不定，图像是马鞍面）。这把 6.2.2 的"主元全正"判据翻译成了看得见的几何配方。

更一般地，做变量替换 x = C y（C 可逆）会把 A 变成

    Cᵀ A C

这叫合同变换（congruence），得到的 CᵀAC 与 A 合同。合同变换的关键性质是**惯性定理（Sylvester's law of inertia）**：合同不改变正、负、零特征值的**个数**（记作惯性指数），也就是不改变二次型是正定/不定/半正定的本质分类，只是换了坐标看它。谱定理里的正交对角化 A=QΛQᵀ 是合同变换的一个特例（取 C=Q，此时 CᵀAC=Λ），它把二次型化成最干净的纯平方和 Σλᵢyᵢ²。

辅助区分一个初学者极易混淆的点：**相似（similarity）B=M⁻¹AM 与合同（congruence）B=MᵀAM 是两回事**。相似保特征值本身（用于大主题5 对角化），合同只保特征值的符号个数（用于二次型分类）。当 M 恰好是正交矩阵 Q 时（Q⁻¹=Qᵀ），两者重合，这正是对称矩阵正交对角化如此好用的原因——一次变换同时完成"化对角"和"保符号"。

最小例子。Q = 2x₁² + 2x₁x₂ + 2x₂²（对应 A=[[2,1],[1,2]]）配方：

    2x₁² + 2x₁x₂ + 2x₂² = 2(x₁ + ½x₂)² + (3/2)x₂²

两个系数 2 与 3/2（正是 A 的两个主元）都为正 → 正定 → 图像是开口向上的碗，唯一最低点在原点。

### 6.3.3 二次型的最小化与优化接口

当 A 正定时，二次型 Q(x)=xᵀAx 是一个开口向上、底在原点的碗，最小值为 Q(0)=0，且原点是**唯一**最小点。更一般的二次函数

    f(x) = ½ xᵀ A x − bᵀ x

在 A 正定时也有唯一最小点，由令梯度为零求得：

    ∇f(x) = A x − b = 0    ⇒    x* = A⁻¹ b

即最小化一个正定二次函数，等价于解一个线性方程组 Ax=b。这条把"优化"与"解方程"钉在一起，是数值优化的基石。

正定 = 碗形 = 有唯一谷底、往哪个方向走都会爬升，所以最优化算法（梯度下降等）能稳定收敛；半正定 = 碗底是一条平沟（沿零特征值方向平坦，最小点不唯一）；不定 = 马鞍面（有下坡方向，没有最小值）。二次函数是所有光滑函数在极值点附近的二阶近似模型，因此这套"正定 ⇒ 严格极小"的判据是通用的。

点接口（仅接口，不深挖，深挖归 L2-03 / L5-02）：

- 喂 Hessian（微积分 L1-04 / 优化 L5-02）：一般多元函数 f 在临界点（梯度为零处）是不是严格局部极小，判据正是"Hessian 矩阵（二阶偏导构成的对称矩阵）在该点正定"。这就是本大主题正定判据在多元微积分二阶充分条件里的直接落地——把 6.2.2 的三判据搬去查 Hessian 即可。
- 喂协方差矩阵（概率统计 L2-03）：随机向量的协方差矩阵天然对称半正定（任意方向上的方差 = 该方向的二次型 ≥ 0，故不可能为负）；当它正定时分布"满维、不退化"，其逆（精度矩阵）出现在多元正态密度中。

此处仅点明接口位置，Hessian 的二阶最优性完整条件与协方差矩阵的统计含义分别在 L1-04 / L5-02 与 L2-03 展开。

本机验证（加固"正定 ⇒ 二次型恒正、不定 ⇒ 有负值"，基线 Py3.11.15/np2.4.6 @2026-07-26）：

    import numpy as np
    A = np.array([[2.,1.,0.],[1.,2.,1.],[0.,1.,2.]])   # 正定
    x = np.array([1.,1.,1.]); print(x @ A @ x)          # 期望 >0
    B = np.array([[1.,2.],[2.,1.]])                     # 不定
    y = np.array([1.,-1.]); print(y @ B @ y)            # 期望 <0


    10.0
    -2.0

正定阵 A 上取样得 10.0>0（与"碗"一致），不定阵 B 上取到方向 (1,−1) 使二次型 =−2<0（存在下坡方向，无最小值），与 6.2.3、6.3.2 的分类相符。
