## 1.1 方程组的几何解释

### 1.1.1 行图像：每个方程是一张超平面，解是它们的交

一个 n 元线性方程组的每一个方程，在几何上都是一张"平的"图形：二元时是一条直线，三元时是一张平面，n 元时是 (n−1) 维超平面。**行图像（row picture）**就是把方程组的每一行画成这样一张图，方程组的解就是所有这些图形的公共交点。

以二元组为例：

    2x − y = 0
    −x + 2y = 3

第一行画出一条直线，第二行画出另一条直线，两条直线相交于点 (1, 2)，这就是唯一解。

行图像是大多数人中学时就有的直觉："解方程组＝找几条线/几张面的交点"。它的价值在于让你一眼看出解的三种可能：两条直线**相交于一点**（唯一解）、**平行不相交**（无解）、**完全重合**（无穷多解）。到三元时想象三张平面：一般相交于一个点，但也可能交于一条直线（无穷解）、或三张面没有公共点（无解）。

易错点：行图像在维数升高后极难画（四元起就无法可视化），而且它不容易看出"为什么"无解或无穷解——你只能"看图说话"。这正是下一节列图像和后面消元法要补的短板。行图像和列图像描述的是**同一个方程组**，只是切入的角度不同，答案必然一致。

### 1.1.2 列图像：把 b 写成 A 各列的线性组合

**列图像（column picture）**换一个角度：把方程组左边按"列"拆开，问的是"能不能用 A 的各列向量，通过某种数乘再相加（线性组合），恰好拼出右边的向量 b"。上例可以重写为

    x · [ 2, −1 ] + y · [ −1, 2 ] = [ 0, 3 ]

这里 [2, −1] 和 [−1, 2] 是系数矩阵的两个列向量，b = [0, 3]。求解就是找到系数 x、y，使这两个列向量的线性组合等于 b；答案 x=1、y=2 意味着"1 份第一列加 2 份第二列＝b"。

列图像是线性代数真正的"主视角"，也是它比中学解方程走得更远的关键。它把问题从"找交点"升级为"b 是否落在 A 各列所张成的空间里"——这个想法直接通向后面的列空间、线性无关、秩等核心概念（大主题 2）。直觉上：n 个列向量能"够到"的所有点，构成它们的所有线性组合；b 有解 ⇔ b 在这个范围内。

最小对照例子：若两个列向量方向不同（不共线），它们的线性组合能铺满整个平面，于是**任意** b 都有唯一解；若两列共线（成比例），组合只能落在一条直线上，那么 b 在这条线上时有无穷多解、不在时无解。这恰好从"列"的角度解释了 1.1.1 里"看图说话"得到的三种情况，且解释了"为什么"。

### 1.1.3 矩阵形式 Ax = b：把方程组打包成一个方程

把系数排成矩阵 A、未知数排成列向量 x、右边排成列向量 b，整个方程组就浓缩成一个矩阵方程：

    A x = b

其中 A 是 m×n 矩阵（m 个方程、n 个未知数），x 是 n×1 列向量，b 是 m×1 列向量。上例即

    A = [[2, −1], [−1, 2]],  x = [x, y]ᵀ,  b = [0, 3]ᵀ

关键要认清：**Ax 的运算规则，本身就是"用 x 的分量去线性组合 A 的各列"**。也就是说，矩阵形式 Ax=b 与列图像是同一句话——A 乘以 x 的结果，等于 x₁ 乘第 1 列 + x₂ 乘第 2 列 + …。这一点是理解后续矩阵乘法多视角（1.3.1）的地基，务必现在就记牢：**矩阵乘向量 = 列的线性组合**，而不是机械地"行点乘列"（那只是同一结果的另一种算法）。

辅助直觉：Ax=b 这套记号的好处是"维数无关"——无论 2 元还是 2000 元，方程都长成 Ax=b 一个样，所有理论（可逆、消元、分解）都能对着这一个符号展开，不必每次重画几何图。三种视角小结：行图像（超平面求交）、列图像（列的线性组合够不够到 b）、矩阵方程（Ax=b），三者等价，解题时用消元、思考时用列图像、可视化时用行图像。

数值印证：用 numpy 解上例 `np.linalg.solve([[2,-1],[-1,2]],[0,3])` 得到 `x = [1., 2.]`（基线 Py3.11.15/np2.4.6 @2026-07-26），与手算一致，验证三视角同解。完整可复现脚本见 1.4 小节末统一给出。

## 1.2 高斯消元

### 1.2.1 消元法步骤：把方程组化成上三角

**高斯消元（Gaussian elimination）**是解 Ax=b 的系统流程：反复用"把某一行的倍数加到下面的行"这类初等行变换，逐列把主元下方的元素清成 0，直到系数矩阵变成**上三角**（左下角全是 0）。之后就能从最后一个方程开始"回代"求出全部未知数。允许的初等行变换有三种：交换两行、某行乘一个非零数、把某行的倍数加到另一行。

以 Strang 常用的 3×3 例子演示（消元阶段只做"倍加"消元）：

    2x +  y +  z =  5
    4x − 6y      = −2
   −2x + 7y + 2z =  9

第 1 列用第 1 行（主元 2）消元：第 2 行减 2×第 1 行、第 3 行加 1×第 1 行；再用新的第 2 行主元消去第 3 行第 2 列，最终得到上三角系统，回代解出 x=1、y=1、z=2。

直觉："消元"就是把中学"代入消元/加减消元"标准化、机械化，使它对任意规模都能照章执行、还能交给计算机。之所以要化成上三角，是因为上三角系统"最后一个方程只含一个未知数"，可以一步步倒着解出来（见 1.2.3 回代）。

易错点：只允许上面三种行变换；尤其"某行乘一个数"必须乘**非零**数，否则会丢失方程、改变解集。另外整个过程要对增广矩阵 [A | b] 同步操作——对 A 做的每一步也要对 b 做，否则等号两边不再匹配。

### 1.2.2 主元（pivot）：每一步依赖的"支点"

**主元（pivot）**是消元时每一行用来清除其下方元素的那个"领头非零元"——通常指行化简过程中每行第一个非零元素（leading entry），它所在的列叫主元列（pivot column）。第 k 步消元把第 k 个主元下方的同列元素全部变 0，用的乘数（multiplier）就是"下方待消元素 ÷ 主元"。

在上例中，第一个主元是 2（第 1 行第 1 列），第二个主元在消元后出现在第 2 行第 2 列。主元的个数最终等于矩阵的**秩**，这是它日后最重要的身份（详见大主题 2），现在只需记住"主元＝消元时的支点、且它的个数是个关键量"。

直觉：主元就是每次消元时"站在制高点、去清理下方"的那个数。为什么用它当除数？因为要构造乘数 m 使得 "待消行 − m×主元行" 恰好在该列得 0，必然 m = 待消元素/主元，所以主元不能是 0（0 不能作除数）——这正引出 1.2.4 的"消元失败"讨论。

易错点：主元不要求等于 1（那是 Gauss-Jordan 里进一步归一化才做的事，见 1.3.3）；主元也不一定在对角线上——一旦发生行交换或出现自由列，主元位置会"错位"，但"每行至多一个主元、主元列自左向右递进"这个阶梯结构始终成立。

### 1.2.3 回代（back-substitution）：从最后一个方程倒着解

**回代（back-substitution）**是消元得到上三角系统后的求解步骤：从最底下那个"只含一个未知数"的方程解出最后一个变量，再把它代入上一行解出倒数第二个变量，如此逐行向上，直到全部解出。

对上例消元后得到的上三角系统，最后一行直接给出 z=2，代入第 2 行解出 y=1，再代入第 1 行解出 x=1。

直觉：消元把方程组"整理"成了一个前后有序的链条——最后一个方程最简单（一个未知数），解出它就为上一个方程"补齐"了一个已知量，链式往上推即可。这也解释了为什么非要化成三角形：三角形保证了"总有一个方程只剩一个未知数可先解"。

易错点/性能提示：消元（把 A 变三角）是主要计算量，约 n³/3 量级的运算；回代较便宜，约 n²/2 量级。初学阶段不必记住系数，但要有"消元贵、回代便宜"的量级感。若右边有多个不同的 b 要解，消元账本（即下节 LU）可以复用，只需对每个 b 重做便宜的前代+回代——这正是 LU 分解的实用价值（1.4.1）。

### 1.2.4 消元失败情形：主元为零→换行、无解或无穷解

消元过程中若某个位置该当主元的元素是 **0**，就"消元失败"了，因为 0 不能作除数。处理分两种：**(a) 可修复**——如果同一列下方还有非零元素，就交换两行（行交换 row exchange），把非零元换上来继续消元；这只是暂时性障碍。**(b) 不可修复**——如果该列在该行及其下方全为 0，无法通过换行补救，这时方程组要么无解、要么有无穷多解。

判据（消元到最简形后看）：出现形如

    0 = 非零数

的矛盾行 ⇒ **无解**；不出现矛盾、但存在没有主元的列（自由变量）⇒ **无穷多解**；每列都有主元、无矛盾 ⇒ **唯一解**。

直觉：情形 (a) 的"换行"只是记账顺序问题，解不受影响——这就是后面 1.4.2 置换矩阵 P 的来历。情形 (b) 才是真正的"结构性"信息：主元数不足（＜未知数个数）意味着方程之间"重复/依赖"，没提供足够独立约束，于是要么自相矛盾（无解），要么欠定（无穷解）。

最小例子：`x+y=2; 2x+2y=5` 消元后第 2 行变成 `0=1`（矛盾）→无解；`x+y=2; 2x+2y=4` 消元后第 2 行变成 `0=0`（多余方程）→无穷解（y 自由、x=2−y）。数值上要小心：浮点消元中"主元几乎为 0"会放大误差，实践中用**部分主元法（partial pivoting）**——每步选当前列绝对值最大的元素换到主元位置以增强数值稳定性，这也是 numpy/scipy 内部的默认做法。

## 1.3 矩阵乘法与逆

### 1.3.1 矩阵乘法的多视角：行×列、列组合、行组合、分块

矩阵乘积 C = A·B 定义为：C 的第 i 行第 j 列元素是 A 第 i 行与 B 第 j 列的点积。对 A 是 m×n、B 是 n×p，才可乘（A 的列数＝B 的行数），结果是 m×p。逐元素定义：

    C[i][j] = Σ_k A[i][k] · B[k][j]

但同一个乘法有**四种等价的看法**，理解它们比死记公式重要得多：
(1) **行×列**（上面的点积定义，逐个算出每个元素）；
(2) **列视角**：C 的每一列 = A 乘 B 的对应列 = A 各列的线性组合（组合系数来自 B 那一列）；
(3) **行视角**：C 的每一行 = A 对应行 乘 B = B 各行的线性组合（系数来自 A 那一行）；
(4) **分块（列×行求和）**：C = Σ_k (A 的第 k 列)×(B 的第 k 行)，即若干个"列向量×行向量"秩 1 矩阵之和。

直觉：视角 (2) 是 1.1.3"矩阵乘向量＝列的线性组合"的推广，也是最该内化的一种——它把矩阵乘法和"线性组合"这个核心思想绑在一起，后面 LU、四子空间都靠它。视角 (1) 只是"怎么手算"，视角 (2)(3)(4) 是"它在做什么"。

最小例子（验证）：

    A = [[1,2],[3,4]], B = [[5,6],[7,8]] ⇒ AB = [[19,22],[43,50]]

易错点：矩阵乘法**不满足交换律**（一般 AB ≠ BA，甚至 BA 可能维数都不合法），但满足结合律 (AB)C = A(BC) 和分配律。初学者最常犯的是"逐元素相乘"（那叫 Hadamard 积，不是矩阵乘法）——矩阵乘法是"行点乘列"的求和，不是对应位置直接相乘。

### 1.3.2 逆矩阵：定义与存在条件

方阵 A 的**逆矩阵** A⁻¹ 是满足下式的方阵：

    A A⁻¹ = A⁻¹ A = I

其中 I 是单位矩阵。若这样的 A⁻¹ 存在，A 称为**可逆（invertible）/非奇异（nonsingular）**；逆若存在则唯一。有了逆，Ax=b 的解可写成 x = A⁻¹b（理论上；实际计算仍用消元而非先求逆，见下方易错点）。

对 n×n 方阵，以下条件**彼此等价**（任一成立则全部成立，都等价于"可逆"）：
- 消元能得到 n 个非零主元（满秩，rank = n）；
- 行列式非零，det(A) ≠ 0；
- Ax = 0 只有零解 x = 0（零空间只含零向量）；
- A 的行最简形（RREF）是单位矩阵 I。

两个常用性质（乘积与转置的逆）：

    (A B)⁻¹ = B⁻¹ A⁻¹

    (Aᵀ)⁻¹ = (A⁻¹)ᵀ

直觉：逆矩阵是"撤销 A 所做变换"的那个矩阵——先做 A、再做 A⁻¹，等于什么都没做（回到 I）。存在条件的多个等价说法其实是同一件事的不同"探针"：满秩/主元齐全（消元角度）、行列式非零（体积角度，见大主题 4）、Ax=0 只有零解（零空间角度，见大主题 2）都在说"A 不把不同向量压成同一个、信息没丢失、可以还原"。

易错点：(A B)⁻¹ 是 **B⁻¹A⁻¹**（顺序反过来），不是 A⁻¹B⁻¹——想象"穿袜子再穿鞋，脱时先脱鞋再脱袜"。只有方阵才谈这种双边逆；长方形矩阵没有普通逆，得用"伪逆"（大主题 7）。另外，实际数值求解 Ax=b **不要先算 A⁻¹ 再乘 b**——那样更慢、误差更大；直接用消元/LU 解。逆矩阵主要是理论工具。

### 1.3.3 Gauss-Jordan 求逆：把 [A | I] 化成 [I | A⁻¹]

**Gauss-Jordan 消元法**求逆的做法：把 A 和同阶单位矩阵 I 并排写成增广矩阵 [A | I]，对整体做初等行变换，一路化简——不仅把主元下方清零（普通高斯消元），还把主元上方也清零、并把每个主元归一化为 1，直到左半边变成单位矩阵 I。此时右半边就变成 A⁻¹：

    [A | I]  ──行变换──▶  [I | A⁻¹]

若左半边无法化成 I（出现全零行、主元不足），则 A 不可逆。

直觉/为什么成立：对 [A | I] 做的全部行变换，等价于左乘同一个矩阵 E；当左边被化成 I，说明 E·A = I，即 E = A⁻¹；而右边此刻就是 E·I = E = A⁻¹。所以"对 A 施加使它变成 I 的那套操作，同样施加到 I 上，就长出 A⁻¹"。这也顺带解释了 1.3.2 里"RREF 是 I ⇔ 可逆"。

最小例子（验证）：

    A = [[1,2],[3,4]] ⇒ A⁻¹ = [[−2, 1],[1.5, −0.5]]，且 A·A⁻¹ = I

易错点：Gauss-Jordan 比"高斯消元 + 回代"多做了"向上消元 + 归一化"，计算量更大，所以解单个 Ax=b 不划算——求逆才用它。它和普通高斯消元不是两种对立算法，而是"消到上三角"与"消到单位阵"两种停止程度。

- 锚点：MIT 18.06SC syllabus, Unit I "Multiplication and Inverse Matrices" 一课（官方 syllabus 已核实，同上 URL，核实 2026-07-26）；Strang《Introduction to Linear Algebra》§2.4"Rules for Matrix Operations"（乘法多视角）、§2.5"Inverse Matrices"（逆定义、可逆条件、Gauss-Jordan 求逆、(AB)⁻¹=B⁻¹A⁻¹）。
- 交叉核对（独立第二源）：Wikipedia "Invertible matrix" 条目（核实 2026-07-26）确认——定义 AB=BA=I 且逆唯一；可逆 ⇔ det≠0 ⇔ rank=n ⇔ Ax=0 仅零解 ⇔ RREF=I；(AB)⁻¹=B⁻¹A⁻¹、(Aᵀ)⁻¹=(A⁻¹)ᵀ；及 Gauss-Jordan 由 [A|I]→[I|A⁻¹]。与 Strang/18.06 完全一致，无分歧。
- 实证：numpy `A@B=[[19,22],[43,50]]`、`inv([[1,2],[3,4]])=[[-2,1],[1.5,-0.5]]`、`A@inv(A)=I`，均与手算一致（脚本见 1.4 末）。
- 成熟度：GA/稳定；无「待核」项。

## 1.4 LU 分解与置换

### 1.4.1 A = LU：消元的"账本"

**LU 分解**把方阵 A 写成一个下三角矩阵 L 与一个上三角矩阵 U 的乘积：

    A = L U

其中 U 正是高斯消元后得到的那个上三角矩阵（主元在其对角线上），L 是下三角矩阵、对角线为 1，其严格下三角部分记录了消元时用过的**乘数**（第 i 行消第 j 列用的乘数放在 L[i][j]）。换句话说，LU 分解就是把"消元过程"存成两个矩阵——U 是消元结果，L 是消元账本。

来历（为什么成立）：消元的每一步"第 i 行减 m 倍第 j 行"都是左乘一个初等下三角矩阵 Eᵢⱼ；把所有这些步骤乘起来得到 E，满足 E·A = U。于是 A = E⁻¹·U，而 E⁻¹ 恰好是下三角、对角为 1、下方元素正好是各乘数——它就是 L。所以 A=LU 不是新东西，是消元的"逆向打包"。

直觉与用途：为什么要存成 LU？因为 L、U 都是三角的，解三角方程组只需便宜的前代/回代（各 ~n²/2），而做一次消元（得到 LU）才是 ~n³/3 的大头。若要对**同一个 A、不同的多个 b** 反复解 Ax=b，只需分解一次 A=LU，之后每个 b 走两步三角求解即可：先解 Ly=b（前代），再解 Ux=y（回代）。这是 LU 相较"每次从头消元"的核心实用价值。

易错点：并非每个方阵都能直接 A=LU（无行交换时才行）；一旦消元中途必须换行，就要引入置换矩阵，写成 PA=LU（见 1.4.2）。此外 L 的对角线约定为 1（这样分解唯一），主元被放进 U 的对角线；有的书用 A=LDU 把主元单独抽成对角阵 D，本质相同、只是记法差异。

### 1.4.2 置换矩阵 P：把行交换也记进账

**置换矩阵（permutation matrix）**是把单位矩阵 I 的行重新排列得到的方阵：每行每列恰有一个 1、其余为 0。左乘 P（PA）等于对 A 做相应的**行交换**。当高斯消元中途遇到主元为 0、必须换行时，这些行交换就用一个置换矩阵 P 统一记录，分解写成：

    P A = L U

置换矩阵有一个漂亮性质：它的逆等于它的转置，

    P⁻¹ = Pᵀ

（因为置换矩阵是正交矩阵——各列是单位向量的一个重排、两两正交）。

直觉：P 只是"把方程重新编号"，不改变方程组本身，所以先按需换好行（PA）再做无障碍的 LU 分解，是完全合法的。1.2.4 里说的"可修复的消元失败（换行即可继续）"，在矩阵语言里就浓缩成这个 P。

最小例子（验证，见脚本）：对 1.2.1 的 A，scipy 的 `lu` 采用部分主元，返回 P、L、U 满足 P·L·U = A，其中 P 把第 1、2 行做了交换（因为 |4|＞|2|，部分主元优先选绝对值大的当主元）。这说明数值库默认会换行以求稳定，得到的是 PA=LU 形式。

易错点：不同资料/库对 P 放哪边、代表"行置换"还是"逆置换"约定不一——例如 scipy.linalg.lu 默认返回满足 A = P·L·U 的 P（P 在等式 A 这边、L 上面），而许多教材写成 PA = LU（P 乘在 A 左边）。两者的 P 互为转置/逆，数值都对，用时务必看清该函数/教材的具体约定，不要生搬公式。

### 1.4.3 转置与对称矩阵

矩阵 A 的**转置** Aᵀ 是把行列互换得到的矩阵：Aᵀ 的第 i 行第 j 列 = A 的第 j 行第 i 列，即

    (Aᵀ)[i][j] = A[j][i]

转置的基本运算律：

    (A + B)ᵀ = Aᵀ + Bᵀ

    (A B)ᵀ = Bᵀ Aᵀ

若一个方阵满足 A = Aᵀ，称为**对称矩阵（symmetric matrix）**——它关于主对角线镜像对称，A[i][j] = A[j][i]。

一个反复出现的重要事实：对任意（甚至长方形）矩阵 A，

    AᵀA  与  AAᵀ  都是对称矩阵

因为 (AᵀA)ᵀ = Aᵀ(Aᵀ)ᵀ = AᵀA。

直觉与关联：转置把"列"变成"行"，是很多公式里在"行/列视角"间切换的开关；(AB)ᵀ=BᵀAᵀ 的顺序反转和 (AB)⁻¹=B⁻¹A⁻¹ 同一个道理（想象"逆序脱衣"）。对称矩阵是后续内容的大主角——它保证特征值为实数、能被正交对角化（谱定理，大主题 6），而 AᵀA 的对称（且半正定）性正是最小二乘正规方程（大主题 3）能求解的关键。现在只需牢记定义、转置乘法的反序律、以及"AᵀA 恒对称"这三点。

易错点：(AB)ᵀ 是 **BᵀAᵀ**（顺序颠倒），写成 AᵀBᵀ 是常见错误；对称要求矩阵先得是方阵，长方形矩阵谈不上对称（但它的 AᵀA、AAᵀ 是方阵且对称）。

```python

from scipy.linalg import lu

# 1.2 高斯消元例：解 Ax=b（Strang 3x3）
```
