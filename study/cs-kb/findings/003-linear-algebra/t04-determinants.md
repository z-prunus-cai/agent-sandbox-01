**行列式 det(A) 是给每个方阵 A 打的一个"标量分数"，它一口气回答了三个问题**——A 可不可逆（det=0 就是奇异、不可逆）、A 把空间的"体积"放大或缩小了多少倍（|det| 就是体积缩放因子）、以及方向有没有被翻转（det 的正负号）。全章围绕这一个数展开：4.1 先用少数几条"游戏规则"把这个数唯一地定下来（三条定义性质 + 七条推论，共十条）；4.2 给出按余子式一层层拆算它的通用公式；4.3 把它用回到解方程（Cramer 法则）、求逆（伴随矩阵）和几何（体积/面积）。理解了"det 是可逆性与体积的度量"这根钉子，行列式的一切性质都能挂上去。

## 4.1 行列式性质

### 4.1.1 行列式是什么：给方阵打分的一个标量

**行列式（determinant）**是一个把 **n×n 方阵** A 映射成**一个数** det(A)（也记作 |A|）的函数。只有方阵才有行列式；长方形矩阵没有行列式。最小的两个例子最该先记牢——一阶就是那个数本身，二阶是"主对角乘积减副对角乘积"：

    det([a]) = a

    det([[a, b], [c, d]]) = a·d − b·c

三阶及以上则由下面的性质或 4.2 的余子式公式算出。行列式最核心的身份是一句话：**det(A) ≠ 0 当且仅当 A 可逆**；det(A) = 0 则 A 奇异（不可逆）。

它为什么值得单独设一个数？因为"可逆与否"这件大事，被压缩进了一个标量的正负与零非零里。回忆大主题1：A 可逆 ⇔ 消元得到 n 个非零主元 ⇔ Ax=0 只有零解。行列式给了这一串等价条件又一个"探针"——而且是能直接算、能连到几何体积（见 4.3.3）的探针。

初学者最容易误解的是把行列式当成"矩阵的大小/范数"之类的度量。它不是；它可正可负可零，负号编码的是"方向翻转"（见 4.3.3 的几何意义）。另一个易错点：行列式只对方阵定义，遇到 2×3 之类的矩阵谈 det 是没有意义的。

对二阶 `[[1,2],[3,4]]`，det = 1·4 − 2·3 = −2；numpy `np.linalg.det` 与 sympy 精确计算一致（脚本见文末）。

### 4.1.2 三条定义性质：唯一确定行列式的"游戏规则"

行列式**不必**先背一个复杂公式再验证性质，反过来更本质：**只用三条性质就能唯一地把 det 这个函数定下来**，其余性质全是推论。这三条定义性质（Strang §5.1 的性质 1–3）是：

性质 1（单位阵归一）：

    det(I) = 1

性质 2（交换两行变号）：交换 A 的任意两行，行列式乘以 −1。

性质 3（对每一行分别线性，"多线性"）：固定其余各行不动，det 对被选中的那一行是线性的，拆成两条——

    (3a) 某一行乘以数 t，行列式乘以 t

    (3b) det(…行 = u + v…) = det(…行 = u…) + det(…行 = v…)

注意性质 3 是"逐行线性"，**不是** det(A+B) = det(A)+det(B)（后者一般不成立，这是头号易错点）。

这三条像一套"游戏规则"，规定了"缩放一行、交换两行、拆分一行"时分数该怎么变；数学上可以证明，满足这三条的标量函数唯一存在，就是行列式。这正是 MIT 18.06 该课的原话——"三条简单性质就完全刻画了行列式，其余七条都能从前三条推出"。

为什么这样定义好用？因为它和高斯消元完美咬合：消元只用到"某行减去另一行的倍数"和偶尔"交换两行"两种操作，而这两种操作对行列式的影响（性质 5、性质 2）都能由这三条推出——于是消元既能解方程，又能顺带把行列式算出来（见 4.1.4）。

### 4.1.3 七条推论性质：从三条规则长出来的常用结论

由 4.1.2 的三条定义性质可推出以下七条（Strang §5.1 的性质 4–10），它们是日常使用行列式时真正常用的：

性质 4（两行相等 → det = 0）：若 A 有两行完全相同，则 det(A) = 0。

性质 5（倍加消元不改变 det）：把某一行的倍数加到另一行上，行列式不变。这条是消元能"保分数"的依据。

性质 6（有一行全为 0 → det = 0）。

性质 7（三角阵 = 对角线之积）：若 A 是上三角或下三角矩阵，则

    det(A) = 主元之积 = d₁·d₂·…·dₙ（对角线元素连乘）

性质 8（奇异判据）：det(A) = 0 当且仅当 A 不可逆（奇异）；det(A) ≠ 0 当且仅当 A 可逆。

性质 9（乘积可乘）：

    det(A·B) = det(A)·det(B)

性质 10（转置不变）：

    det(Aᵀ) = det(A)

性质 4 由性质 2 推出（交换那两条相等的行，矩阵没变但 det 要变号，只能是 0）；性质 5 由性质 3b + 性质 4 推出（加过去的那部分构成"两行成比例"的项，其 det 为 0）；性质 7 由性质 3a 反复提取对角元、再配合性质 1 得到。性质 10（det(Aᵀ)=det(A)）尤其重要——它意味着**前面所有关于"行"的性质，对"列"同样成立**，所以行列式对行、对列是对称的，你可以按行也可以按列展开（见 4.2）。

- det(A+B) ≠ det(A)+det(B)（性质 3 是逐行线性，不是整体可加）。
- det(kA) = kⁿ·det(A)，**不是** k·det(A)——因为 kA 是把 n 行**每一行**都乘了 k，性质 3a 要用 n 次。
- 性质 9 只对同阶方阵之积成立；A 长方形时 AB 的 det 谈不上逐项拆。

由性质 9，det(A⁻¹) = 1/det(A)（因为 det(A)·det(A⁻¹) = det(I) = 1），这也再次说明 det=0 的矩阵没有逆。

### 4.1.4 用性质快速算行列式：消元法

综合以上性质，得到手算/机算大行列式的实用方法：**用高斯消元把 A 化成三角阵，途中只用"倍加"（性质 5，不改变 det）和必要时的"换行"（性质 2，每换一次记一个负号）**，化完后按性质 7 把对角线（主元）连乘，再补上换行累计的符号，就是 det(A)。

    det(A) = (−1)^(换行次数) × (主元连乘)

这把"算行列式"和大主题1 的"消元求主元"统一成了同一套流程，是计算机实际采用的算法——按 Leibniz 全排列公式（4.2 会提到）直接展开需要 n! 项，消元法只要约 n³/3 次运算，规模一大就是天壤之别。

对
`A = [[2,1,1],[4,−6,0],[−2,7,2]]`，消元（无净换行）得到上三角，真实主元是 **2、−8、1**，连乘 2·(−8)·1 = −16。这里要小心：主元是**消元后**对角线上的数，不是原矩阵对角线——若错拿原对角线 2、−6、2 连乘会得到 −24，是错的。实测该 A 的 det = −16（见文末 sympy/numpy 输出），说明必须用消元后的真实主元连乘，切勿拿原矩阵对角线直接相乘。

初学者常直接把原矩阵对角线元素相乘当作行列式——这只有当 A 本身已是三角阵时才对（性质 7 的前提）。一般矩阵必须先消元。

## 4.2 余子式展开

### 4.2.1 代数余子式：给每个元素配一个"带符号的小行列式"

要给出行列式的通用公式，需要**代数余子式（cofactor）**这块积木。对 n×n 矩阵 A 的元素 a_ij，先划掉它所在的第 i 行和第 j 列，剩下的 (n−1)×(n−1) 小矩阵的行列式叫**余子式（minor）** M_ij；再给它配一个正负号，就得到代数余子式 C_ij：

    C_ij = (−1)^(i+j) · M_ij

其中符号 (−1)^(i+j) 按棋盘格分布：

    +  −  +  −  …
    −  +  −  +  …
    +  −  +  −  …

左上角 (1,1) 位置为 +，横竖相邻交替变号。

M_ij（余子式）是"抠掉这个元素的十字后，剩下部分的行列式"，度量的是"除了这一行一列之外的贡献"；前面的 (−1)^(i+j) 是为了让展开公式（4.2.2）和行列式的换行变号性质自洽而必须带上的符号。

分清 minor（余子式 M_ij，纯粹的小行列式，无符号）与 cofactor（代数余子式 C_ij，带了棋盘符号）。两者差一个 (−1)^(i+j)，套公式时用的是**代数余子式** C_ij。棋盘符号从左上角 + 开始，别记反。

### 4.2.2 Laplace（余子式）展开：把 n 阶行列式降到 n−1 阶

**Laplace 展开（余子式展开）**给出行列式的递归计算公式：沿**任意一行 i**，把该行每个元素乘以它自己的代数余子式再求和，就得到行列式（沿任意一列 j 展开同理成立，因为 det(Aᵀ)=det(A)）：

按第 i 行展开：

    det(A) = a_i1·C_i1 + a_i2·C_i2 + … + a_in·C_in = Σⱼ a_ij·C_ij

按第 j 列展开：

    det(A) = Σᵢ a_ij·C_ij

因为每个 C_ij 里又是一个 (n−1) 阶行列式，这就把 n 阶问题降成若干 n−1 阶问题，一层层递归到二阶（用 4.1.1 的 ad−bc）为止。

最小例子（沿第 1 行展开三阶）：

    det([[a,b,c],[d,e,f],[g,h,i]])
      = a·det([[e,f],[h,i]]) − b·det([[d,f],[g,i]]) + c·det([[d,e],[g,h]])

注意中间项前面的负号，正是棋盘符号 (−1)^(1+2) = −1 的体现。

可以**挑零最多的那一行或那一列**去展开——某元素为 0 时它那一项整项消失，不必算对应的余子式，能省很多工。这是余子式展开相对"消元法"在手算特定稀疏矩阵时的优势。

与全排列公式的关系（了解即可，不深挖）：把余子式展开一路递归到底，等价于 Leibniz 全排列公式

    det(A) = Σ_σ sgn(σ)·a_{1,σ(1)}·a_{2,σ(2)}·…·a_{n,σ(n)}

它对所有 n! 个列的排列 σ 求和，每项带排列的奇偶符号 sgn(σ)=±1。这解释了为什么直接展开会有 n! 项、大矩阵极其昂贵——所以计算机宁可用 4.1.4 的消元法。

余子式展开每一项的符号来自代数余子式 C_ij（含棋盘符号），别只写成 a_ij·M_ij 而漏掉 (−1)^(i+j)；三阶手算时中间那一项忘记变号是最常见错误。

## 4.3 Cramer 法则与体积

### 4.3.1 Cramer 法则：用行列式的比值写出每个未知数

**Cramer 法则（Cramer's rule）**给出可逆方程组 Ax = b 每个分量的显式公式：把系数矩阵 A 的**第 j 列换成右端向量 b**，得到矩阵 Bⱼ，则第 j 个未知数等于两个行列式的比：

    xⱼ = det(Bⱼ) / det(A)

其中 Bⱼ 是"A 的第 j 列被 b 替换"后的矩阵，A 必须可逆（det(A) ≠ 0）才有唯一解。

直觉/为什么成立：由 x = A⁻¹b 与后面 4.3.2 的伴随矩阵公式可以推出这个比值；更几何的看法是——分子 det(Bⱼ) 度量"用 b 顶替第 j 列后张成的体积"，分母 det(A) 是原体积，比值恰好还原出该坐标 xⱼ。

最小例子（验证，见文末脚本）：对
`M = [[1,2,3],[4,5,6],[7,8,10]]`（det = −3）与 `b = [6,15,25]`，逐列替换算三个行列式之比，得 x = [1, 1, 1]，与 sympy 直接求解 `M.solve(b)` 完全一致。

易错点/实用告诫：Cramer 法则**理论价值 > 计算价值**。它给出漂亮的闭式公式（在证明、小规模符号推导、公式推导里很有用），但要算 n+1 个 n 阶行列式，成本远高于直接高斯消元，且数值稳定性差；**实际数值求解绝不用 Cramer，而用消元/LU**（呼应大主题1"不要先求逆再乘"的同类告诫）。另一个易错点：分母是原矩阵 A 的行列式，分子里被替换的是**第 j 列**（对应第 j 个未知数），别换成行。

### 4.3.2 伴随矩阵求逆：用代数余子式拼出 A⁻¹

**伴随矩阵（adjugate / classical adjoint）** adj(A) 定义为代数余子式矩阵的**转置**：第 (i,j) 位置放的是 C_ji（注意下标转置）。它给出逆矩阵的显式公式：

    A⁻¹ = (1 / det(A)) · adj(A)

即"逆 = 伴随矩阵除以行列式"。同样要求 det(A) ≠ 0。

二阶最好记，直接给出常用速算式：

    [[a, b], [c, d]]⁻¹ = (1/(ad−bc)) · [[d, −b], [−c, a]]

即"主对角对调、副对角变号，再除以行列式"。

为什么除以 det？因为伴随矩阵满足 A·adj(A) = det(A)·I（这可由"余子式展开"配合"错行展开得 0"证明），两边同除 det(A) 就得到 A·[adj(A)/det(A)] = I，右边那块正是 A⁻¹。这条公式把 4.2 的代数余子式与"求逆"接上了：逆矩阵的每个元素都是一个带符号的余子式除以行列式。

- adj(A) 是余子式矩阵的**转置**（元素 (i,j) = C_ji），忘记转置是常见错误——不过对二阶速算式而言，转置已经体现在"主对角对调"里。
- 与 Cramer 一样，伴随矩阵求逆是理论/符号工具，数值上仍用消元（Gauss-Jordan）更实际。
- det(A)=0 时公式失效（除零），对应 A 不可逆。

### 4.3.3 行列式与体积/面积：几何意义

行列式的绝对值 |det(A)| 等于以 A 的**行向量（或列向量）为棱张成的平行多面体的体积**（二维是平行四边形的面积，三维是平行六面体的体积，n 维是"平行多胞体"的 n 维体积）：

    |det(A)| = 平行多面体的体积

而 det(A) 的**符号**编码方向（定向）：正号表示保持原坐标系的手性（定向），负号表示发生了镜像翻转。

向量 (a,b) 与 (c,d) 张成的平行四边形，面积就是

    |det([[a, b], [c, d]])| = |a·d − b·c|

把 A 看成一个线性变换，它把单位正方体（体积 1）映成一个平行多面体，det(A) 正是这次变换的**体积缩放因子**（含方向）。这一下子解释了本章开头的所有身份——
- 若 det(A)=0：单位体被压扁成低维（体积变 0），信息坍缩、不可逆（呼应性质 8）。
- 性质 9 det(AB)=det(A)det(B)：连做两次变换，体积缩放因子相乘，天经地义。
- 性质 2 交换两行变号：交换两条棱等于把定向翻转，故符号取反。

对角阵 `diag(3,2,5)` 把单位立方体拉成 3×2×5 的长方体，det = 30 = 体积，符号为正（无翻转），与 sympy 计算一致（见文末）。

体积是 |det|（取绝对值）；det 本身带号，负号不是"负体积"而是"方向翻转"。另外这条几何意义也顺带给出 4.3.1 Cramer 法则的几何解读（用 b 替换一列 = 用 b 顶替一条棱后的体积比）。这一节还是通往大主题8（线性变换）和多元微积分中"雅可比行列式做换元的体积因子"的桥梁——同一个"行列式 = 体积缩放"的思想在那里复用。

## 交叉锚参考：Axler 视角（该书为何把行列式"后置"）

作为可选交叉锚，Sheldon Axler《Linear Algebra Done Right》采取"线性变换优先、尽量不用行列式"的路线，把行列式放到全书接近最后才引入。其观点是：特征值、可逆性、谱定理等核心结论都可以不依赖行列式而更透明地建立，行列式作为"多线性交替形式 / 体积因子"更适合最后统一收口。这与 Strang/18.06 把行列式放在特征值之前、当作计算工具与几何直觉来源的教学次序形成对照——**不是数学分歧，而是教学路径选择**：Strang 用行列式做直觉与计算铺垫，Axler 视其为可推迟的收尾。初学者了解此差异即可，本报告主体采用 Strang/18.06 次序。

## 附：本报告实证脚本与真实输出（自足、可复现）

基线 Py3.11.15/np2.4.6/sympy1.14.0 @2026-07-26。下述脚本在基线环境实跑，输出即下方所示。

```python
import numpy as np, sympy as sp

# 4.1 性质
A = np.array([[2.,1.,1.],[4.,-6.,0.],[-2.,7.,2.]])
print("det(A) numpy:", round(np.linalg.det(A),6))          # -16.0
As = sp.Matrix([[2,1,1],[4,-6,0],[-2,7,2]])
print("det(A) sympy exact:", As.det())                     # -16
U = sp.Matrix([[2,1,1],[0,-8,-2],[0,0,3]])
print("det upper-tri:", U.det(), "prod diag:", 2*-8*3)     # -48 -48
As2 = As.copy(); As2.row_swap(0,1)
print("det after one row swap:", As2.det())                # 16  (= -det A)
B = sp.Matrix([[1,2,0],[0,1,3],[1,0,1]])
print("det(AB):", (As*B).det(), "detA*detB:", As.det()*B.det())  # -112 -112
print("det(A^T):", As.T.det())                             # -16

# 4.2 余子式展开（沿第 1 行）
M = sp.Matrix([[1,2,3],[4,5,6],[7,8,10]])
cof = lambda Mat,i,j: (-1)**(i+j)*Mat.minor_submatrix(i,j).det()
print("cofactor exp row0:", sum(M[0,j]*cof(M,0,j) for j in range(3)),
      "M.det():", M.det())                                 # -3 -3
print("sympy cofactor(0,0):", M.cofactor(0,0), "manual:", cof(M,0,0))  # 2 2

# 4.3 Cramer / 伴随 / 体积
b = sp.Matrix([6,15,25]); detM = M.det()
xs = []
for j in range(3):
    Bj = M.copy(); Bj[:,j] = b; xs.append(Bj.det()/detM)
print("Cramer x:", xs, "direct:", list(M.solve(b)))        # [1,1,1] [1,1,1]
print("adj/det == inv:", sp.simplify(M.adjugate()/detM - M.inv())==sp.zeros(3))  # True
V = sp.Matrix([[3,0,0],[0,2,0],[0,0,5]])
print("volume box det:", V.det())                          # 30
```
