## 3.1 正交子空间

### 3.1.1 正交向量与向量长度

两个向量正交（orthogonal），指它们的点积（内积）为零。对实向量 x 与 y，正交的定义式为：

xᵀy = x₁y₁ + x₂y₂ + … + xₙyₙ = 0

向量自身的点积给出长度（范数）的平方：

‖x‖² = xᵀx = x₁² + x₂² + … + xₙ²

正交是「垂直」在任意维空间里的推广。在二维、三维里，xᵀy=0 恰好对应几何上的两向量成直角，这可以从毕达哥拉斯定理看出来：当且仅当 x ⊥ y 时，两向量张成的直角三角形满足

‖x‖² + ‖y‖² = ‖x + y‖²

把右边展开成 (x+y)ᵀ(x+y) = xᵀx + 2xᵀy + yᵀy，与左边比较就得到 2xᵀy = 0，即 xᵀy = 0。于是「点积为零」这个纯代数条件，就等价于「直角」这个几何图像；到了四维、n 维这种画不出图的空间里，我们干脆用 xᵀy=0 来*定义*垂直。

一个易错点：零向量与任何向量都正交（0ᵀy = 0 恒成立），这是约定也是自然结论，不要觉得「零向量没方向、谈不上垂直」而把它排除。另一个常见混淆是把「正交」和「线性无关」当成一回事——正交一定线性无关（后面 3.4 会用到），但线性无关不一定正交（比如 (1,0) 与 (1,1) 无关却不垂直）。正交是比无关更强的条件。

### 3.1.2 正交子空间

两个子空间 V 和 W 称为正交（orthogonal subspaces），指 V 中的每一个向量都与 W 中的每一个向量正交：

对所有 v ∈ V、w ∈ W，都有 vᵀw = 0

注意这是「逐对全部正交」，不是「存在某一对正交」。

初学者最容易踩的坑，是把「两个子空间正交」想成「墙面和地面那样成直角的两个平面」。恰恰相反：在三维空间里，一面墙（一个过原点的平面，2 维）和地面（另一个 2 维平面）在日常语言里「互相垂直」，但作为子空间它们*不*正交——因为两个平面相交于一条直线，这条交线上的非零向量同时属于两个子空间，它和自己点积不为零，破坏了「逐对正交」。这引出一个关键结论：两个正交子空间只能相交于零向量。直觉上，正交子空间之间没有任何「共享的方向」。

正确的图像应该是：三维里「地面（xy 平面，2 维）」和「竖直的 z 轴（1 维）」才是一对正交子空间——地面里任何向量都是水平的，z 轴上任何向量都是竖直的，逐对点积为零，且只交于原点。它们的维数 2 + 1 = 3 恰好填满整个空间，这种「正交且维数互补、合起来铺满全空间」的更强关系叫正交补（orthogonal complement），是 3.1.3 四子空间关系的核心。

### 3.1.3 四大基本子空间的正交关系

对任意 m×n 矩阵 A，大主题2 的四大基本子空间之间存在两对正交关系。在 ℝⁿ（定义域一侧）中：

行空间 C(Aᵀ) ⊥ 零空间 N(A)

在 ℝᵐ（值域一侧）中：

列空间 C(A) ⊥ 左零空间 N(Aᵀ)

而且它们不只是正交，还互为正交补：行空间与零空间在 ℝⁿ 里维数相加为 n（r + (n−r) = n），列空间与左零空间在 ℝᵐ 里维数相加为 m（r + (m−r) = m）。这被称为线性代数基本定理的第二部分。

为什么行空间和零空间正交，可以一眼看穿。零空间由满足 Ax = 0 的所有 x 组成。把 A 按行写开，Ax = 0 意思就是 A 的*每一行*与 x 做点积都等于 0：

（A 的第 i 行）· x = 0，对每一行 i 成立

也就是说，零空间里的 x 与 A 的每一行都正交，从而与这些行的所有线性组合（即整个行空间）都正交。把 A 换成 Aᵀ，同一套推理立刻给出「列空间 ⊥ 左零空间」（左零空间是满足 Aᵀy = 0 的 y）。

这个正交关系是本大主题后面全部内容的地基：正是因为「ℝⁿ 被行空间和零空间垂直地劈成两块」，任何向量都能唯一地拆成「行空间分量 + 零空间分量」，投影（3.2）才有意义；也正是因为「列空间 ⊥ 左零空间」，当 b 不在列空间里、方程 Ax=b 无解时，我们才能把 b 垂直地投到列空间上得到最优近似（3.3 最小二乘）。一个易错点：这里的「垂直劈成两块」是相对*标准点积*而言的，四子空间的正交关系是这个具体内积下的结论，不是随便换个内积都成立。

下面用 numpy 直接核对「零空间向量与每一行正交」这一条（真实输出，对应基线串）：

```python
import numpy as np
A = np.array([[1,2,2,2],[2,4,6,8],[3,6,8,10]], dtype=float)
U, s, Vt = np.linalg.svd(A)
tol = 1e-10
ns = Vt[np.sum(s > tol):].T      # 零空间基（按列）
print("rank A =", int(np.sum(s > tol)))
print("A @ nullvec =", (A @ ns[:, 0]).round(6))
print("每行·零空间向量 =", [round(float(r @ ns[:, 0]), 6) for r in A])
```

真实输出：

```
rank A = 2
A @ nullvec = [ 0. -0.  0.]
每行·零空间向量 = [0.0, 0.0, 0.0]
```

三行与零空间向量的点积全为 0，印证行空间 ⊥ 零空间。

## 3.2 投影

### 3.2.1 投影到一条直线

把向量 b 投影到由向量 a 张成的直线上，得到的投影向量 p 是 a 的某个倍数 p = x̂a，其中标量 x̂ 由「误差 e = b − p 垂直于 a」这一条件定出。由 aᵀ(b − x̂a) = 0 解得：

x̂ = aᵀb / aᵀa

p = a · (aᵀb / aᵀa)

把 p 写成「矩阵乘 b」的形式，就得到投影到直线的投影矩阵：

P = aaᵀ / aᵀa

关键直觉：投影就是在直线上找一个离 b 最近的点。「最近」等价于「误差 e = b − p 与直线垂直」——因为从 b 到直线，垂线段是最短的。所以整个投影的推导只有一个方程：aᵀe = 0，即 a 与误差正交。这正是 3.1 正交关系的第一次实战应用。

注意 aaᵀ（列 × 行，得到 n×n 矩阵）和 aᵀa（行 × 列，得到一个数）在形状上完全不同，初学者极易写反。记法：分母 aᵀa 是标量（长度平方），分子 aaᵀ 是矩阵；P 是矩阵，所以分子必须是矩阵 aaᵀ。

一个最小例子：把 b=(1,1,1) 投到 a=(1,2,2) 上，aᵀa = 1+4+4 = 9，aᵀb = 1+2+2 = 5，于是 x̂ = 5/9，p = (5/9)(1,2,2)。

### 3.2.2 投影到子空间（列空间）

更一般地，把 b 投影到矩阵 A 的列空间上（A 的各列线性无关）。投影向量 p = Ax̂ 是各列的某个线性组合，系数向量 x̂ 由「误差 b − Ax̂ 垂直于列空间」定出，即误差与 A 的每一列都正交，写成 Aᵀ(b − Ax̂) = 0，整理得：

AᵀAx̂ = Aᵀb

x̂ = (AᵀA)⁻¹Aᵀb

p = Ax̂ = A(AᵀA)⁻¹Aᵀb

于是投影到列空间的投影矩阵为：

P = A(AᵀA)⁻¹Aᵀ

这是把 3.2.1 从「一条直线（一个列向量 a）」推广到「一个子空间（多个列向量 A）」的自然结果。直线情形其实是这里 A 只有一列时的特例：那时 AᵀA 退化成标量 aᵀa，公式回到 P = aaᵀ/aᵀa。

为什么 AᵀA 可逆、公式里可以放心求逆？关键结论是：当 A 的列线性无关时，AᵀA 是可逆的方阵（n×n）。这一点在 3.3 最小二乘里是能不能求解的前提，务必记住其条件是「列无关」，不是「A 是方阵」。

误差 e = b − p 落在哪里？它垂直于列空间，因此落在列空间的正交补——也就是左零空间 N(Aᵀ) 里（回看 3.1.3）。所以投影恰好把 b 拆成两块：p 在列空间中，e 在左零空间中，b = p + e，两块互相垂直。这就是把「四子空间的正交关系」用在了具体计算上。

### 3.2.3 投影矩阵的性质

任何投影矩阵 P（无论投到直线还是子空间）都满足两条核心性质：

P² = P

Pᵀ = P

即投影矩阵是幂等（idempotent）且对称（symmetric）的。

第一条 P² = P 的直觉最好记：一个向量投到子空间上得到 p 之后，p 本身已经在子空间里了，再投一次还是 p，「投影两次等于投影一次」。第二条 Pᵀ = P（对称性）反映的是「正交投影」这一特殊性——沿着与子空间垂直的方向投下去；如果允许沿着某个倾斜方向投（斜投影），矩阵仍满足 P²=P 但不再对称，所以对称性正是「正交」在矩阵上的印记。

一个配套结论：若 P 把 b 投到子空间上，则 I − P 把 b 投到该子空间的正交补上（即取出误差 e = (I−P)b）。I−P 也是投影矩阵，同样满足 (I−P)² = I−P、(I−P)ᵀ = I−P。

一个退化易错点：当 b 已经在子空间里时，投影不改变它，Pb = b；当 b 垂直于子空间时，Pb = 0。若 A 是可逆方阵（列空间就是整个 ℝⁿ），则 P = A(AᵀA)⁻¹Aᵀ 化简为单位阵 I——因为「投到整个空间」什么也没投掉。初学者别把 A(AᵀA)⁻¹Aᵀ 盲目拆成 AA⁻¹(Aᵀ)⁻¹Aᵀ=I：这个拆分只在 A 为方阵可逆时成立，A 是长方形（m>n）时 A⁻¹ 根本不存在，绝不能这么约分。

下面用 numpy 核对投影矩阵的两条性质（真实输出，对应基线串）：

```python
import numpy as np
A = np.array([[1,0],[1,1],[1,2]], dtype=float)   # 列无关，列空间是 R^3 中的一个平面
P = A @ np.linalg.inv(A.T @ A) @ A.T
print("P =\n", P.round(4))
print("P^2 == P :", np.allclose(P @ P, P))
print("P^T == P :", np.allclose(P.T, P))
```

真实输出：

```
P =
 [[ 0.8333  0.3333 -0.1667]
 [ 0.3333  0.3333  0.3333]
 [-0.1667  0.3333  0.8333]]
P^2 == P : True
P^T == P : True
```

## 3.3 最小二乘

### 3.3.1 超定方程组与为什么要最小二乘

当方程个数多于未知数（m > n）时，Ax = b 往往*无解*——这类系统叫超定（overdetermined）系统。几何上：b 一般不在 A 的列空间里，找不到任何 x 使 Ax 精确等于 b。最小二乘（least squares）的思路是退而求其次，找一个 x̂ 使得误差向量 e = b − Ax̂ 的长度平方最小：

最小化 ‖b − Ax̂‖²

这个「平方和最小」正是「least squares」名字的由来。

直觉：既然到不了 b，就在能到达的地方（列空间）里找一个离 b 最近的点。而 3.2 已经告诉我们，列空间里离 b 最近的点就是 b 在列空间上的*投影* p。所以最小二乘的最优 Ax̂ 恰好等于投影 p——最小二乘问题和投影问题是同一件事的两种说法。这是把 3.2 和 3.3 缝在一起的关键认识。

为什么用平方和而不是绝对值和？教辅层面的两条理由：其一，平方和是光滑的、可求导，令导数为零就能一步解出（得到下面的正规方程）；其二，平方和最小对应「误差与列空间正交」这个漂亮的几何条件。用绝对值和（L1）会得到另一种拟合（更抗离群点），那是另一个话题，本课不展开。

### 3.3.2 正规方程

最小化 ‖b − Ax̂‖² 的最优 x̂，由正规方程（normal equations）给出：

AᵀAx̂ = Aᵀb

当 A 的列线性无关时 AᵀA 可逆，解唯一：

x̂ = (AᵀA)⁻¹Aᵀb

可以看到，这与 3.2.2 投影系数的公式*一模一样*——再次印证「最小二乘 = 投影」。

正规方程有两种等价的来法，任选一种理解即可。几何来法（推荐）：最优解要让误差 e = b − Ax̂ 垂直于列空间，即 Aᵀe = 0，代入 e 立刻得到 Aᵀ(b − Ax̂) = 0，也就是 AᵀAx̂ = Aᵀb。微积分来法：把 ‖b − Ax̂‖² 对 x̂ 求梯度令其为零，同样得到 AᵀAx̂ = Aᵀb。两条路殊途同归，说明「垂直」和「最短」是一回事。

「normal」在这里是「正交 / 法向」的意思（误差是列空间的法向量），不是「正常」的意思，初学者别望文生义。最大的易错点是可解条件：正规方程有唯一解要求 A 的*列*线性无关（等价于 AᵀA 可逆）；如果列相关（比如数据里有完全共线的特征），AᵀA 就奇异，正规方程有无穷多解，这时要靠伪逆（见大主题7）来挑出最小范数解。

### 3.3.3 直线拟合的最小例子

最常见的最小二乘应用是用一条直线 y = C + Dt 去拟合若干个不共线的数据点 (tᵢ, yᵢ)。每个点给出一个方程 C + Dtᵢ = yᵢ，点多于两个时一般无解，于是做最小二乘。把它写成 Ax = b：

A 的每一行是 [1, tᵢ]，未知 x = [C, D]ᵀ，b 的每一项是 yᵢ

解正规方程 AᵀAx̂ = Aᵀb 就得到最优的截距 C 与斜率 D，几何上就是那条「到所有点的竖直距离平方和最小」的直线。这条直线也叫回归直线，它是 3.3.4 统计回归的入口。

下面同时用「正规方程」「numpy.linalg.lstsq」「QR」三条路解同一个超定系统 Ax=b（A 列无关、m=3>n=2），核对三者一致，并验证残差与列空间正交（真实输出，对应基线串）：

```python
import numpy as np
A = np.array([[1,0],[1,1],[1,2]], dtype=float)
b = np.array([6., 0., 0.])
xhat_normal = np.linalg.solve(A.T @ A, A.T @ b)      # 正规方程
xhat_lstsq  = np.linalg.lstsq(A, b, rcond=None)[0]   # 库直接解
Q, R = np.linalg.qr(A)
xhat_qr = np.linalg.solve(R, Q.T @ b)                # QR 路线
print("normal:", xhat_normal, " lstsq:", xhat_lstsq, " qr:", xhat_qr)
e = b - A @ xhat_normal
print("A^T e =", (A.T @ e).round(6))                 # 残差⊥列空间
```

真实输出：

```
normal: [ 5. -3.]  lstsq: [ 5. -3.]  qr: [ 5. -3.]
A^T e = [0. 0.]
```

三条路给出同一解 x̂ = (5, −3)，且 Aᵀe = 0 证实残差与列空间正交。

### 3.3.4 与统计回归的接口

最小二乘直线拟合就是统计里的线性回归（linear regression）的代数骨架：正规方程 AᵀAx̂ = Aᵀb 解出的 x̂ 就是回归系数（截距与斜率），投影矩阵 P = A(AᵀA)⁻¹Aᵀ 在统计里叫「帽子矩阵」（hat matrix，因为它把 y 变成 ŷ）。

这里只点接口、不深挖。统计回归在这套代数之上*额外*叠加的东西——误差服从什么分布、系数的标准误与置信区间、显著性检验、R²、最小二乘估计为何是最优线性无偏估计（高斯–马尔可夫定理）等——都属于概率统计的内容，本课不展开，归 L2-03。初学者只需记住一件事：线性代数负责「给定数据怎么算出那条最优直线」（确定性的投影 / 正规方程），统计负责「这条直线有多可信」（带上随机性与推断）。

## 3.4 Gram-Schmidt 与 QR

### 3.4.1 标准正交基与正交矩阵

一组向量 q₁,…,qₙ 称为标准正交（orthonormal），指它们两两正交且各自长度为 1：

qᵢᵀqⱼ = 0（i ≠ j 时）、 qᵢᵀqᵢ = 1

把这些列拼成矩阵 Q，上述条件等价于一个漂亮的矩阵等式：

QᵀQ = I

若 Q 还是方阵，则称为正交矩阵（orthogonal matrix），此时还有 Qᵀ = Q⁻¹。

标准正交基之所以人人都爱，是因为它把很多计算「打回原形」。比如投影到列空间的公式 P = A(AᵀA)⁻¹Aᵀ，一旦列是标准正交的（A 换成 Q），QᵀQ = I，公式立刻塌缩成 P = QQᵀ，逆矩阵消失了；投影系数不再需要解方程组，直接是 x̂ = Qᵀb（每个分量就是 b 与对应 qᵢ 的点积）。正交矩阵还保长度、保角度（‖Qx‖ = ‖x‖），所以在数值计算里用它做变换不会放大误差——这正是 QR、SVD 比直接解正规方程更稳的根本原因。

一个术语易错点：「orthogonal matrix（正交矩阵）」按惯例特指*方阵*且列标准正交；而列标准正交的*长方形*矩阵 Q（QᵀQ=I 但 QQᵀ≠I）严格说不叫正交矩阵，只能说「列标准正交」。中文里两者都常被叫「正交矩阵」，读英文文献时要留意这个方阵限定。

### 3.4.2 Gram-Schmidt 正交化过程

Gram-Schmidt 过程把一组线性无关的向量 a₁,…,aₙ 逐个「扶正」成一组标准正交向量 q₁,…,qₙ，且张成同一个子空间。核心动作是：每拿到一个新向量，就把它在*已定好的那些方向*上的投影分量减掉，只留下垂直于它们的部分，再归一化成单位长度。第 k 步的做法是：

先减去在前面各 qⱼ 上的投影：aₖ' = aₖ − (q₁ᵀaₖ)q₁ − … − (qₖ₋₁ᵀaₖ)qₖ₋₁

再归一化：qₖ = aₖ' / ‖aₖ'‖

直觉就是「造一组互相垂直的坐标轴」：第一根轴直接取 a₁ 的方向；第二根轴要垂直于第一根，所以把 a₂ 里「沿第一根轴」的成分扣掉，剩下的就垂直了；第三根要同时垂直于前两根，就把 a₃ 里沿前两根的成分都扣掉……每一步都在用 3.2 的投影和 3.1 的正交。这样得到的 q₁,…,qₖ 与原来的 a₁,…,aₖ 张成完全相同的子空间，只是换了一组「互相垂直、长度为 1」的漂亮基。

易错点有二。其一，减投影时用的是*已经归一化*的 qⱼ（这样投影系数就是简单的点积 qⱼᵀaₖ）；若用未归一化的向量，系数要写成 (vⱼᵀaₖ)/(vⱼᵀvⱼ)，别漏了分母。其二，若某个 aₖ' 减到接近零向量，说明 aₖ 落在前面向量张成的空间里（原向量组线性相关），此时无法归一化——这也正是 Gram-Schmidt 顺带检测线性相关的方式。数值实现上，上面这种「经典 Gram-Schmidt」对舍入误差较敏感，实际库多用等价但更稳的「修正 Gram-Schmidt」或 Householder 变换，本课只讲思想，不深挖数值版本差异。

### 3.4.3 QR 分解及其用途

Gram-Schmidt 过程的结果可以整理成一个矩阵分解：任何列线性无关的 m×n 矩阵 A 都能分解为一个列标准正交矩阵 Q 与一个上三角矩阵 R 的乘积：

A = QR

其中 Q 的列是 Gram-Schmidt 造出的 q₁,…,qₙ（满足 QᵀQ = I），R 是上三角阵，其元素恰是过程中出现的投影系数 Rᵢⱼ = qᵢᵀaⱼ。R 上三角是因为 qᵢ 只由 a₁,…,aᵢ 造出、与后面无关，所以 qᵢᵀaⱼ 在 i > j 时为零。

QR 最重要的用途就是把最小二乘算得又快又稳。把 A = QR 代入正规方程 AᵀAx̂ = Aᵀb：因为 QᵀQ = I，AᵀA = RᵀQᵀQR = RᵀR，方程化简为

Rx̂ = Qᵀb

R 是上三角，直接回代就能解出 x̂，完全绕开了「组装 AᵀA 再求逆」这一步。这在数值上关键：直接解正规方程会把条件数平方（κ(AᵀA)=κ(A)²）放大误差，而 QR 路线只用到正交矩阵（保长度、不放大误差），因此是实际软件（含 numpy/LAPACK 的最小二乘）常用的做法之一。QR 也用于计算特征值的 QR 算法等，属后续内容。

下面核对 A=QR、QᵀQ=I，以及「Rx̂=Qᵀb 解出的 x̂ 与 lstsq 一致」（真实输出，对应基线串；本例数据与 3.3.3 同）：

```python
import numpy as np
A = np.array([[1,0],[1,1],[1,2]], dtype=float)
b = np.array([6., 0., 0.])
Q, R = np.linalg.qr(A)
print("Q =\n", Q.round(4))
print("R =\n", R.round(4))
print("A == QR :", np.allclose(A, Q @ R))
print("Q^T Q == I :", np.allclose(Q.T @ Q, np.eye(Q.shape[1])))
xhat = np.linalg.solve(R, Q.T @ b)
print("xhat (QR) =", xhat)
```

真实输出：

```
Q =
 [[-0.5774  0.7071]
 [-0.5774  0.    ]
 [-0.5774 -0.7071]]
R =
 [[-1.7321 -1.7321]
 [ 0.     -1.4142]]
A == QR : True
Q^T Q == I : True
xhat (QR) = [ 5. -3.]
```

注意 numpy 返回的 Q、R 整体带了一个符号（列取了负方向），这不影响 A=QR 与解 x̂——Gram-Schmidt/QR 的 Q 列方向可正可负，只要成对翻转符号，乘积 QR 与最终最小二乘解都不变。
