## 9.1 复矩阵

### 9.1.1 复向量与复内积

当向量的分量是复数时，"长度"和"内积"的定义必须改造，否则会算出长度为负甚至为零的荒谬结果。**复内积（complex/Hermitian inner product）** 的定义是：对复向量 u、v，先把 u 的每个分量取**共轭复数**再与 v 对应相乘求和，写成共轭转置乘法

    ⟨u, v⟩ = uᴴ v = conj(u₁)·v₁ + conj(u₂)·v₂ + … + conj(uₙ)·vₙ

其中 uᴴ（读作"u 的共轭转置 / Hermitian 转置"）表示先转置再对每个元素取共轭复数（有的教材记作 u*）。由此复向量的**范数（长度）** 定义为

    ‖u‖² = ⟨u, u⟩ = uᴴ u = |u₁|² + |u₂|² + … + |uₙ|²

这一定是非负实数（每项 |uᵢ|²≥0），长度的意义得以保留。

为什么非得取共轭？如果照搬实数的 uᵀu，对复数会失效：取 u=[i]，则 uᵀu=i·i=−1，"长度平方"成了负数，毫无意义。而共轭让 conj(i)·i=(−i)(i)=1，得到正确的 |i|²=1。直觉上，共轭复数把 a+bi 变成 a−bi，一个数乘它自己的共轭 (a+bi)(a−bi)=a²+b²，正好是这个复数模长的平方——这正是我们想要的"长度"。所以复内积的全部改造，就是"在其中一个向量上补一次共轭"。

易错点（约定陷阱，务必记）：**共轭加在哪个向量上，是一个约定，两大流派并存**。数学界（及 Wikipedia、Strang）多把共轭加在**第一个**向量上，即 ⟨u,v⟩=uᴴv=Σ conj(uᵢ)vᵢ（对第一变元共轭线性、第二变元线性）；物理界（狄拉克记号）常把共轭加在**第二个**向量上。两者互为共轭，数学等价，但读任何资料前先确认它用哪种约定，否则会在"哪边线性、哪边共轭线性"上栽跟头。本报告统一采用"共轭加在第一个向量"的约定。另一个易错点：实向量是复向量的特例（共轭对实数无作用），所以复内积退化回熟悉的 uᵀv，前面学的实内积没有白学。

### 9.1.2 Hermitian 矩阵

**Hermitian 矩阵（埃尔米特矩阵）** 是复数域里"对称矩阵"的正确推广：它等于自己的共轭转置

    Aᴴ = A

也就是说，把 A 转置再逐元素取共轭复数，得到的还是 A 本身。展开到元素级，这要求 aⱼₖ = conj(aₖⱼ)：关于主对角线对称的两个元素互为共轭复数，而对角线元素 aⱼⱼ=conj(aⱼⱼ) 必须是**实数**。当矩阵所有元素恰好都是实数时，Aᴴ 就退化成 Aᵀ，Hermitian 阵就退化回实对称阵。

Hermitian 矩阵继承了实对称阵最珍贵的两条谱性质（大主题6谱定理的复数版）：

    (1) 所有特征值都是实数；
    (2) 不同特征值对应的特征向量在复内积下正交，且 A 可被酉矩阵对角化 A = UΛUᴴ（Λ 为实对角阵）。

为什么要造这么个矩阵？因为很多"能量/长度"性质要求二次型 xᴴAx 恒为实数，而恰好 A 是 Hermitian 时 xᴴAx 才对任意复向量 x 都取实值——这让 Hermitian 阵成为量子力学（可观测量算符）、信号处理（协方差/相关矩阵的复数版）里的核心对象。记忆口诀：**"共轭转置版的对称阵，特征值一定是实数"**。

    A = [[2, 3+i], [3−i, 5]]

对角元 2、5 是实数，非对角的 3+i 与 3−i 互为共轭 ⇒ Aᴴ=A，是 Hermitian 阵。它的两个特征值算出来是实数（本报告实证得 0 与 7，见文末），印证性质 (1)。

不要把"Hermitian"错记成"实对称"——非对角元允许是复数，只要关于对角线互为**共轭**即可；也别漏掉"对角线必须实"这条（若某个对角元带虚部，就不是 Hermitian）。另外 Hermitian ≠ 酉，两者是不同性质（一个约束 Aᴴ=A，一个约束 UᴴU=I），仅在极特殊矩阵上同时满足。

### 9.1.3 酉矩阵

**酉矩阵（unitary matrix）** 是复数域里"正交矩阵"的正确推广：它的共轭转置就是它的逆

    Uᴴ U = U Uᴴ = I    （即 Uᴴ = U⁻¹）

等价地说，U 的各列（以及各行）构成复内积下的一组**标准正交基**（两两复内积为 0、每列范数为 1）。当 U 的元素全为实数时，Uᴴ=Uᵀ，酉矩阵退化回实正交矩阵。

酉矩阵最重要的特征是**保内积、保长度（等距变换）**：

    ‖U x‖ = ‖x‖    对任意复向量 x 成立

以及 ⟨Ux, Uy⟩=⟨x, y⟩。由此还能推出两条：它的所有**特征值模长为 1**（落在复平面单位圆上），行列式满足 |det U| = 1。

酉矩阵是复空间里的"刚体运动"——只做旋转/反射式的重新摆放，绝不拉伸压缩，所以长度和夹角（内积）分毫不动。这正是它在数值计算里备受青睐的原因：乘一个酉矩阵不会放大误差（条件数为 1），数值稳定。呼应大主题3——正交阵之所以好用是因为保长度、逆等于转置；酉矩阵把这套好处原样带到复数域，只是"转置"换成"共轭转置"。

    U = (1/√2) · [[1, 1], [i, −i]]

验证 UᴴU=I 成立、‖Ux‖=‖x‖、|det U|=1（本报告实证逐条通过，见文末），它是 2×2 酉矩阵。

判定酉矩阵用的是 **UᴴU=I**（共轭转置），不是 UᵀU=I（普通转置）——对含虚部的矩阵后者会算错，这是从实数搬过来时最常见的漏共轭错误。另外"列范数为 1"里的范数是复范数 Σ|uᵢ|²，别忘了取模平方。本节的酉矩阵是下一节傅里叶矩阵的直接铺垫：傅里叶矩阵除以 √n 之后恰是酉矩阵。

## 9.2 快速傅里叶变换

### 9.2.1 傅里叶矩阵

**傅里叶矩阵（Fourier matrix）** Fₙ 是一个 n×n 复矩阵，它把"对长度 n 的向量做离散傅里叶变换（DFT）"这件事写成一次矩阵乘法。它的元素全部由 n 次**单位根（root of unity）** ω 的幂填成：第 j 行第 k 列（下标从 0 数起）的元素是

    (Fₙ)ⱼₖ = ω^{jk}

其中 ω 是一个满足 ωⁿ=1 的复数（"n 等分单位圆"的旋转因子）。对向量 x 做 DFT 就是算 Fₙx。傅里叶矩阵有三条关键性质：

    (1) 对称：Fₙᵀ = Fₙ （因为 ω^{jk}=ω^{kj}）；
    (2) 归一化后是酉矩阵：(1/√n)·Fₙ 满足 ((1/√n)Fₙ)ᴴ·((1/√n)Fₙ) = I ；
    (3) 各列两两正交，列范数为 √n。

正因为 (2)，逆变换极其好求：Fₙ⁻¹ = (1/n)·Fₙᴴ，不必真去解方程。

性质 (2) 是本大主题两节的黏合点——**"做傅里叶变换"本质上就是"乘一个（归一化的）酉矩阵"，也就是把信号投影到一组由单位根构成的标准正交基上**（呼应大主题3的正交基展开：每个傅里叶系数就是信号在对应频率基向量上的投影）。因为这组基是正交的，各频率分量互不干扰、可独立读出，这正是傅里叶分析威力的来源。最小例子（n=4）：单位根 ω 的幂只在 {1, i, −1, −i} 四个值间循环，F₄ 是一个只由这四个数填成的规整矩阵；对 x=[1,2,3,4]ᵀ，F₄x 给出它的 4 个频率系数（本报告实证 F₄x=[10, −2+2i, −2, −2−2i]，见文末）。

易错点（**符号约定冲突，务必显式**）：ω 取 **e^{+2πi/n}** 还是 **e^{−2πi/n}** 两种约定并存，且不同来源不一致——

    Strang/ILA 传统上取 ω = e^{+2πi/n}（正号）；
    工程界的 DFT 定义与几乎所有数值库（含 numpy.fft）取 ω = e^{−2πi/n}（负号）。

两者互为**复共轭**（等价于"正变换 vs 逆变换"方向相反），数学上是同一套理论、只差一个共轭/方向约定，**不是分歧而是约定**。后果很实在：若你用 e^{+2πi/n} 手搭傅里叶矩阵去对 numpy.fft.fft 的结果，虚部符号会整体相反。本报告实证时特意采用与库一致的 **ω=e^{−2πi/n}**，构造的 F₄ 乘 x 与 `numpy.fft.fft(x)` 完全吻合（见文末），以此坐实库所用约定；引用 Strang 结论时其符号按其正号约定理解即可。另一个易错点：傅里叶矩阵 F 本身是**对称**的（F=Fᵀ）但**不是 Hermitian**（F≠Fᴴ，因 Fᴴ 会把 ω 换成 conj(ω)）；真正是酉矩阵的是归一化的 F/√n，别把这几个性质张冠李戴。

### 9.2.2 FFT 的分治思想与加速意义

**快速傅里叶变换（Fast Fourier Transform, FFT）** 不是一种新的变换，而是**计算 Fₙx 的一个快速算法**：它利用傅里叶矩阵单位根幂的高度规则结构，把一次 n 阶 DFT 递归地拆成两次 n/2 阶 DFT，从而把乘法次数从直接算的 O(n²) 降到 O(n log n)。核心是下面的矩阵分解（Cooley–Tukey 思想，Strang 的写法）：

    Fₙ = [[Iₘ, Dₘ], [Iₘ, −Dₘ]] · [[Fₘ, 0], [0, Fₘ]] · P    （m = n/2）

其中 P 是把输入按**偶数下标、奇数下标**重排的置换矩阵，Dₘ=diag(1, ω, ω², …, ω^{m−1}) 是一组"旋转因子（twiddle factors）"，两个 Fₘ 是规模减半的傅里叶矩阵。

这个分解说的是——要对 n 个点做 DFT，先把它们按下标奇偶分成两组各 n/2 个点、分别做一次规模减半的 DFT，再用旋转因子 D 把两组结果"缝合"起来即可。规模减半的 DFT 又能同样再拆，一直拆到平凡的 1 点变换为止（要求 n 是 2 的幂，一般情形有推广）。这就把工作量的递推写成

    T(n) = 2·T(n/2) + O(n)   ⇒   T(n) = O(n log n)

而直接按定义算 Fₙx 需要 n×n 次复乘，是 O(n²)。为什么这点差别值得单独立一个算法？因为差距随 n 爆炸式拉开：本报告的数值示意里，n=2¹⁰≈千 时 O(n²) 与 O(n log n) 已差约 100 倍，n=2²⁰≈百万 时差约 5 万倍（见文末）。正是这个从"平方"到"n 乘对数"的降维，让实时音频/图像/通信里对上百万点做傅里叶变换从不可行变为瞬时——FFT 被公认为 20 世纪最重要的算法之一。

FFT 与直接 DFT 算的是**同一个结果**，只是路径更省，不要以为 FFT 是某种近似（它在精确算术下完全精确，实际浮点下仅有正常舍入误差）。"n 必须是 2 的幂"只是最简 radix-2 版本的前提，混合基/任意长度的推广存在（库会自动处理），导论级记住"分治把 n² 变 n log n"即可。更深的内容——蝶形运算图、位反转寻址、数值精度、缓存/并行/GPU 实现——属信号处理与 HPC 课程（本大主题外围，明确不在此深挖，只做接口）。
