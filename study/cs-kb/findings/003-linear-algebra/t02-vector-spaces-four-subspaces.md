## 2.1 向量空间与子空间

### 2.1.1 向量空间与它的八条公理

向量空间（vector space）是一个集合 V，配上"加法"和"数乘（标量乘法）"两种运算，并且这两种运算的结果**仍留在 V 内**（封闭性），同时满足八条代数公理。最典型的向量空间是 n 维实空间

    ℝⁿ = { 所有 n 个实数排成的列向量 }

比如 ℝ²（平面上所有向量）、ℝ³（空间中所有向量）。标量这里取实数（ℝ）。

八条公理不必背死，直觉是"加法和数乘要像我们熟悉的那样规矩"。设 u, v, w ∈ V，c, d 为标量：

    (1) u + v = v + u                      加法交换律
    (2) (u + v) + w = u + (v + w)          加法结合律
    (3) 存在零向量 0，使 v + 0 = v          加法单位元
    (4) 每个 v 有负元 −v，使 v + (−v) = 0   加法逆元
    (5) c(u + v) = cu + cv                  数乘对向量加法分配
    (6) (c + d)v = cv + dv                  数乘对标量加法分配
    (7) c(dv) = (cd)v                       数乘结合律
    (8) 1·v = v                             数乘单位标量

初学者的关键心智模型：**"向量"不一定是几何箭头**。只要一个集合的元素能"相加"、能"乘常数"，且满足上面八条，它就是向量空间——元素可以是矩阵（所有 3×3 实矩阵构成一个向量空间）、可以是函数（所有多项式、所有连续函数）。这正是"空间"这个抽象概念的威力：同一套定理，几何向量、矩阵、函数一起适用。

为什么强调封闭性？因为如果两个向量相加会"跳出"集合，后面所有关于线性组合的讨论都无从谈起。一个最常见的反例：ℝ² 中"第一象限"（两个坐标都 ≥0 的点）**不是**向量空间——它对加法封闭，但对数乘不封闭（乘 −1 就跑到第三象限了），也没有每个元素的负元。

一个易错点：零向量必须存在且属于 V。任何缺了零向量的集合都当不成向量空间（公理 3 直接违背）。这条在下一节判定子空间时是"第一道关卡"。

### 2.1.2 子空间及其判定

子空间（subspace）是向量空间 V 中的一个子集 W，它自己（用 V 里同样的加法和数乘）也构成一个向量空间。判定一个子集是不是子空间，**不必逐条查八条公理**——因为交换律、结合律等会从 V 自动继承，只需验证三件事：

    (a) 零向量在 W 中：0 ∈ W
    (b) 对加法封闭：u, v ∈ W ⇒ u + v ∈ W
    (c) 对数乘封闭：v ∈ W，c 为任意标量 ⇒ cv ∈ W

其中 (b)(c) 常合并成一条等价说法：W 对**任意线性组合**封闭，即 u,v∈W ⇒ cu+dv∈W。

子空间就是"过原点、且平直无限延展"的那种子集。在 ℝ³ 里，子空间只有四种：{0}（只含原点）、过原点的直线、过原点的平面、以及整个 ℝ³。凡是**不过原点**的直线或平面都不是子空间——因为它们不含 0，(a) 直接不满足。

为什么"含零向量"是必查项？其实它可由 (c) 推出（取 c=0 得 0·v=0∈W），前提是 W 非空。所以更精炼的判定是"W 非空且对线性组合封闭"。实践中直接看"0 在不在里面"最快，是排除伪子空间的第一刀。

最小例子与易错点。取 W = { (x, y) | y = 2x } ⊆ ℝ²（一条过原点的直线）：含 (0,0)；两个这种点相加、数乘后仍满足 y=2x，故是子空间。反例 W' = { (x, y) | y = 2x + 1 }（不过原点的直线）：不含 (0,0)，直接出局；即便忽略这点，(1,3) 和 (2,5) 都在 W' 上，但相加 (3,8) 不满足 y=2x+1，加法也不封闭。**"线性方程 = 0"型（齐次）画出的集合才可能是子空间，"= 非零常数"（非齐次）的一律不是**——这条直接引出下一节：Ax=0 的解集是子空间，Ax=b（b≠0）的解集不是。

前后关联：子空间的两个最重要来源，一个是"某个矩阵所有列的线性组合"（列空间，见 2.4），一个是"某个齐次方程组的解集"（零空间，见 2.2）。本节把"是不是子空间"的判据握牢，后面就是反复套用它。

### 2.1.3 由向量张成的子空间

给定 V 中一组向量 v₁, …, vₖ，它们的所有线性组合构成的集合

    span(v₁, …, vₖ) = { c₁v₁ + c₂v₂ + ⋯ + cₖvₖ ｜ c₁,…,cₖ 为标量 }

一定是 V 的一个子空间，称为由这组向量**张成（span）**的子空间。它是"包含这些向量的最小子空间"。

你手里有几个向量，能"走到"的所有点，就是把它们按任意比例混合后能到达的全部位置。一个非零向量张成一条过原点的直线；两个不平行的向量张成一个过原点的平面。

为什么它必然是子空间？因为"线性组合的线性组合还是线性组合"——把两个组合相加、或乘个常数，结果仍能写成 v₁,…,vₖ 的组合，故对加法、数乘封闭，也显然含 0（全取系数 0）。这与 2.1.2 的判据完全吻合。

这一节是承上启下的枢纽：**"张成"是从向量造出子空间的标准方式**，而下一步的问题自然是——张成同一个子空间时，最少需要几个向量、这些向量之间能不能"精简"？那正是 2.3（无关/基/维数）要回答的。

## 2.2 零空间与解结构

### 2.2.1 零空间：Ax=0 的解集

对 m×n 矩阵 A，它的零空间（null space）N(A) 是齐次方程 Ax=0 的全部解构成的集合：

    N(A) = { x ∈ ℝⁿ ｜ Ax = 0 }

零空间是 ℝⁿ 的一个**子空间**（注意：向量 x 有 n 个分量，住在 ℝⁿ，不是 ℝᵐ）。

它为什么是子空间？用 2.1.2 的判据一验即知：Ax=0、Ay=0 时，A(x+y)=Ax+Ay=0，A(cx)=c·Ax=0，且 A·0=0 恒成立，故含零向量、对加法与数乘封闭。这也解释了 2.1.2 里那句话——"齐次方程（=0）的解集才是子空间"。

直觉与命名：零空间就是被 A "压成零"的所有输入向量。若 A 可逆（方阵、满秩），唯一被压成零的只有 0 本身，此时 N(A)={0}，是最小的子空间。零空间越大，说明 A "丢失的信息"越多。

易错点：N(A) ⊆ ℝⁿ（列数决定），而下一大节的列空间 C(A) ⊆ ℝᵐ（行数决定），两者住在不同维度的空间里，初学者极易混淆"x 有几个分量"。

### 2.2.2 主元列、自由变量与特解

求 N(A) 的标准算法：把 A 用消元化到**行最简形（RREF, reduced row echelon form）R**。R 中每行第一个非零元（且被规范成 1）所在的列叫**主元列（pivot column）**，其余列叫**自由列（free column）**，对应的未知量叫**自由变量（free variable）**。主元个数就是秩 r。

    自由变量个数 = n − r

求零空间基的套路：让某一个自由变量取 1、其余自由变量取 0，回代解出主元变量，得到一个解向量，称为**特解（special solution）**。有几个自由变量，就有几个特解，它们恰好张成整个零空间。

用一个具体矩阵坐实（下方 sympy 实测同一个 A）。取

    A = [ 1  2  2  2 ]
        [ 2  4  6  8 ]
        [ 3  6  8 10 ]

它的 RREF 是

    R = [ 1  2  0 −2 ]
        [ 0  0  1  2 ]
        [ 0  0  0  0 ]

主元在第 1、3 列（r=2），自由变量是 x₂、x₄（第 2、4 列）。得到两个特解

    s₁ = (−2, 1, 0, 0)      （令 x₂=1, x₄=0）
    s₂ = ( 2, 0, −2, 1)     （令 x₂=0, x₄=1）

于是 N(A) = span(s₁, s₂)，维数 2 = n − r = 4 − 2。

sympy 实测（基线 Py3.11.15/np2.4.6/gcc13.3 @2026-07-25，`sympy 1.14.0`，`Matrix.rref()` 与 `Matrix.nullspace()`）：

    rref = (Matrix([[1, 2, 0, -2], [0, 0, 1, 2], [0, 0, 0, 0]]), (0, 2))
    nullspace basis (special solutions):
    [-2, 1, 0, 0]
    [2, 0, -2, 1]
    dim N(A) = 2

（`(0, 2)` 即主元列下标 0、2，对应第 1、3 列；两个特解与手算一致；零空间维数 2。）

为什么这样取特解能张成整个零空间？因为任何解都是"自由变量随便取值 + 主元变量被唯一确定"的产物，而"自由变量的取值"本身就是一组任意标量——把每个自由变量的贡献拆开，正好是各特解的线性组合。易错点：别把自由变量数错，它等于"非主元列数 = n − r"，不是"零行数"。

### 2.2.3 Ax=b 的完全解：特解 + 齐次通解

对非齐次方程 Ax=b，若它**有解**（相容），则全部解的结构是

    x = x_p + x_n

其中 x_p 是任意一个**特解（particular solution）**（满足 Ax_p=b），x_n 取遍整个零空间 N(A)（满足 Ax_n=0）。也就是

    完全解 = 一个特解 + 零空间

求 x_p 的常用做法：把所有自由变量置 0，解出主元变量。

为什么完全解长这样？若 x 与 x_p 都满足 Ax=b，则 A(x−x_p)=b−b=0，故差 x−x_p 落在零空间里；反过来 x_p 加上任何零空间向量仍满足 =b。这就是"一个特解平移整个零空间"的几何图像：**解集是一个过 x_p 的、平行于 N(A) 的"仿射平面"**——它一般不过原点，所以（呼应 2.1.2）b≠0 时解集不是子空间。

承接上面的 A，取 b=(1,5,6)。sympy 求得完全解（`linsolve`）：

    linsolve(A,b) = {(-2*x1 + 2*x3 - 2, x1, 3/2 - 2*x3, x3)}

读法：把自由变量记作 x1(=x₂)、x3(=x₄)，令二者为 0 得特解 x_p=(−2, 0, 3/2, 0)；其余部分 x1·(−2,1,0,0)+x3·(2,0,−2,1) 恰是 2.2.2 的两个特解张成的零空间。即 x = x_p + N(A)，与公式完全吻合。

解的四种情形（按秩 r 相对 m、n 的关系判断，是本节最实用的结论）：

    r = m = n ：方阵满秩，A 可逆，恒有唯一解
    r = n < m ：列满秩，零空间只含 0，有解时解唯一（0 或 1 个解）
    r = m < n ：行满秩，恒相容，因有自由变量故有无穷多解
    r < m 且 r < n ：有解时无穷多解，也可能无解（b 落不进列空间就无解）

易错点：Ax=b 未必有解——只有 b 属于 A 的列空间（见 2.4）时才相容；消元后若出现"0 = 非零数"这种矛盾行，即无解。

## 2.3 线性无关、基与维数

### 2.3.1 线性无关与线性相关

一组向量 v₁, …, vₖ 称为**线性无关（linearly independent）**，如果使它们线性组合为零的唯一办法是全取零系数：

    c₁v₁ + c₂v₂ + ⋯ + cₖvₖ = 0  ⟹  c₁ = c₂ = ⋯ = cₖ = 0

只要存在**不全为零**的系数能让组合等于 0，就称线性相关（linearly dependent）。

"无关"意味着谁也不能被其他向量的组合表示出来——每个向量都提供了"新方向"、没有冗余。"相关"则意味着至少有一个向量是多余的（能被别的凑出来）。

判定与矩阵的联系是关键：把这些向量作为列拼成矩阵 A，则

    向量组无关  ⟺  Ax=0 只有零解  ⟺  N(A)={0}  ⟺  每列都是主元列（r = 列数）

于是"无关性"直接可用 2.2 的消元/零空间来判。

最小例子：(1,0) 与 (0,1) 无关（要组合成 0 只能系数全 0）；(1,2) 与 (2,4) 相关（后者是前者 2 倍，2·(1,2)−1·(2,4)=0）。

几个易错点与直觉边界。其一：在 ℝⁿ 中，**任何超过 n 个的向量必线性相关**（列数 > 行数时一定有自由变量、必有非零解）。其二：只要向量组里含零向量，就一定相关（给零向量配任意非零系数即可）。其三："线性无关"是对**一组**向量的性质，不是对单个向量说的。

### 2.3.2 张成（span）

一组向量**张成（span）**一个空间 W，是指 W 里每个向量都能写成它们的线性组合，即 W = span(v₁,…,vₖ)（呼应 2.1.3）。

    v₁, …, vₖ 张成 W  ⟺  W 中每个向量都是它们的某个线性组合

张成关注的是"够不够到处走"——这组向量能不能覆盖整个目标空间。它和无关性是**两个独立的维度**：张成是"够不够多（能覆盖）"，无关是"有没有冗余（不重复）"。

最小例子：(1,0)、(0,1)、(1,1) 三者张成 ℝ²（能凑出平面任意点），但它们线性相关（第三个是前两个之和）——**能张成不代表无关**。反过来，只有 (1,0) 一个向量线性无关，但张不成整个 ℝ²——**无关也不代表能张成**。把这两件事都做到刚刚好的，就是"基"。

### 2.3.3 基（basis）

空间 V 的一组**基（basis）**是一组向量，同时满足两个条件：

    (1) 线性无关（没有冗余）
    (2) 张成 V（覆盖整个空间）

等价的刻画：基是"能张成 V 的最少向量组"，也是"V 中最大的无关组"。基的最重要性质——**V 中每个向量都能用基向量唯一地线性表示**（表示法存在来自"张成"，唯一性来自"无关"）。

基就是空间的一套"最经济的坐标轴"——既能到达每个点（张成），又没有多余的轴（无关），且每个点的坐标唯一。

最小例子：ℝⁿ 的**标准基（standard basis）**是 e₁=(1,0,…,0)、e₂=(0,1,0,…,0)、…、eₙ=(0,…,0,1)。但基不唯一——(1,0) 与 (1,1) 也是 ℝ² 的一组基（无关且张成）。**一个空间有无穷多组基，但每组基的向量个数都相同**（这正是下一节"维数"能定义的前提）。

易错点：基必须两条都满足。少一个向量可能张不成（不是基），多一个向量必然相关（也不是基）。求某子空间的基时，常见做法是"从张成它的一堆向量里挑出极大无关组"，或对矩阵做消元取主元列（列空间的基）/取特解（零空间的基）。

### 2.3.4 维数（dimension）

空间 V 的**维数（dimension）**，记 dim V，定义为 V 的任意一组基所含向量的个数。这个数**与所选的基无关**（任意两组基向量个数相等，此为维数良定义的基石）。

    dim V = 基向量的个数

例如 dim ℝⁿ = n；ℝ³ 中一条过原点直线维数 1、一个过原点平面维数 2；只含零向量的空间 {0} 维数为 0（其基是空集）。

维数就是"这个空间需要几个独立方向才能描述"，也是"点的坐标需要几个数"。它把"空间有多大"变成一个确定的整数，是本大主题最核心的度量。

为什么"任意两组基个数相等"？这依赖一条基本引理（Strang/Axler 均证）：**在同一空间里，无关向量的个数永远不超过张成向量的个数**。把它对两组基各用一次，就逼出两者相等。初学者不必记证明，但要相信这条——它保证了维数不是"看你怎么选基"的随意数字。

易错点：别把"矩阵的行列数"当成"维数"。子空间的维数由"独立方向数"决定，与它嵌在多大的 ℝⁿ 里无关（一条过原点直线不管在 ℝ² 还是 ℝ¹⁰⁰ 里都是 1 维）。这为下一节"用 r、m、n 算四个子空间的维数"铺好了路。

## 2.4 四大基本子空间

### 2.4.1 列空间与行空间

一个 m×n 矩阵 A 天然带出四个子空间。前两个是：

**列空间（column space）C(A)**：A 各列的所有线性组合，是 ℝᵐ 的子空间。

    C(A) = { Ax ｜ x ∈ ℝⁿ } ⊆ ℝᵐ

**行空间（row space）**：A 各行的所有线性组合，等于 Aᵀ 的列空间 C(Aᵀ)，是 ℝⁿ 的子空间。

列空间是理解"Ax=b 何时有解"的钥匙，因为 Ax 本质就是"A 的列按 x 的分量加权求和"：

    Ax = x₁·(第1列) + x₂·(第2列) + ⋯ + xₙ·(第n列)

所以 **Ax=b 有解 ⟺ b ∈ C(A)**（b 恰能被 A 的列凑出来）。这把 2.2.3 里"相容性"那句话讲透了。

求基的方法：C(A) 的基取 A 中**主元列所对应的原始列**（注意是原矩阵的列，不是 RREF 的列）；行空间的基取 RREF 中**非零行**。

易错点与直觉：列空间住在 ℝᵐ（分量数 = 行数），行空间住在 ℝⁿ（分量数 = 列数），别搞混。一个关键事实（下一节展开）：**行空间维数 = 列空间维数 = 秩 r**，尽管两者住在不同空间。

### 2.4.2 零空间与左零空间

后两个子空间是：

**零空间（null space）N(A)**：Ax=0 的解集，ℝⁿ 的子空间（已在 2.2 详述）。

**左零空间（left null space）N(Aᵀ)**：Aᵀy=0 的解集，是 ℝᵐ 的子空间。之所以叫"左"，是因为 Aᵀy=0 转置后等价于

    yᵀA = 0ᵀ

即 y 从**左边**乘 A 得零行向量——y 是把 A 各行组合成零的系数。

零空间管"哪些输入被 A 压成零"，左零空间管"A 的各行之间有哪些线性相关关系"。左零空间维数 = m − r（下一节），它计量"A 有多少行是冗余的"。求 N(Aᵀ) 的基就是对 Aᵀ 做 2.2.2 的特解流程。

易错点：初学者常忽略左零空间，因为它在 Ax=b 里不直接出现；但它在"最小二乘/相容性判据"（大主题3）里很重要——b 可解当且仅当 b 与左零空间正交。

### 2.4.3 秩（rank）

矩阵 A 的**秩（rank）r** 是它线性无关的列的最大个数，等于消元后主元的个数。一个基本定理：**列秩 = 行秩**，即

    rank(A) = rank(Aᵀ) = r

所以"独立列数 = 独立行数"，秩是刻画 A "真实信息量"的单一整数。

秩是 A "真正有几个独立方向"。r=n（列满秩）表示列都无关、零空间只含 0；r=m（行满秩）表示行都无关、Ax=b 恒相容；r 同时小于 m、n 的矩阵叫"秩亏"，既可能无解也可能多解。

为什么列秩恒等于行秩？一个简明理由：RREF 保持行空间不变、也保持列之间的相关关系不变，而 RREF 里主元个数从行看、从列看是同一个数。这个"看似两码事却相等"的结论是四子空间维数关系的核心。

numpy 实测（同上环境，`numpy.linalg.matrix_rank`，对 2.2 的同一个 A）：

    np rank(A) = 2

sympy 亦确认（`Matrix.rank()`）r=2，且

    rank(A)==rank(A^T)? True

（数值与符号两条路都给出 r=2，列秩=行秩坐实。）

易错点：秩不超过 min(m, n)；浮点数值算秩时（如 numpy）要留意数值容差，接近奇异的矩阵可能把"很小的奇异值"误判为非零而虚高秩——严谨判定用符号计算（sympy）或看奇异值（大主题7 SVD）。

### 2.4.4 秩-零化度定理与四子空间维数

把前面所有度量串起来的收官定理。设 A 为 m×n、秩为 r，则四个子空间的维数被 r、m、n 完全决定：

    dim C(A)  = r          （列空间，在 ℝᵐ 中）
    dim C(Aᵀ) = r          （行空间，在 ℝⁿ 中）
    dim N(A)  = n − r      （零空间，在 ℝⁿ 中）
    dim N(Aᵀ) = m − r      （左零空间，在 ℝᵐ 中）

其中关于零空间的那条，单独称为**秩-零化度定理（rank–nullity theorem）**：

    rank(A) + dim N(A) = n

即"秩 + 零化度 = 列数"。它是 2.2 里"自由变量个数 = n − r"的正式命名。

列数 n 是输入向量能提供的总"自由度"，其中 r 个方向被 A 保留下来（映到列空间），剩下 n−r 个方向被压进零空间——总账必须守恒。同理，行数 m 分成 r（行空间维数）和 m−r（左零空间维数）。

sympy 实测（同上环境，对 2.2 的 A：m=3, n=4, r=2；`columnspace/rowspace/nullspace` 求各基个数）：

    m=3, n=4, r=2
    dim C(A)=r = 2
    dim C(A^T)=row space = 2
    dim N(A)=n-r = 2  expected 2
    dim N(A^T)=m-r = 1  expected 1
    rank+nullity = 4 == n = 4

（四个维数分别为 2、2、2、1，与 r、n−r、m−r 逐一吻合；秩-零化度 2+2=4=n 坐实。）

一张"大图（big picture）"帮助记忆（Strang §3.5 的招牌图）：行空间与零空间都住在 ℝⁿ，维数 r 与 n−r 加起来正好 n；列空间与左零空间都住在 ℝᵐ，维数 r 与 m−r 加起来正好 m。更强的结论是——**行空间与零空间在 ℝⁿ 里互相正交、列空间与左零空间在 ℝᵐ 里互相正交**（把 ℝⁿ、ℝᵐ 各自"垂直地"劈成两半）。这条正交性是大主题3（正交性、投影与最小二乘）的入口，本报告只点接口、不展开。

易错点与关联：秩-零化度里的"n"是**列数**（也是 x 的分量数），不是行数，方向一旦记反四个维数全乱。这条定理是后续几乎所有结论的地基——可逆性（方阵 r=n 即可逆）、最小二乘（大主题3）、乃至线性变换的维数定理（大主题8，Axler 把它写成 dim range + dim null = dim domain，是同一件事的抽象版）。
