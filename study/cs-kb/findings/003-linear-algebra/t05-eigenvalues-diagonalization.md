## 5.1 特征值与特征向量

### 5.1.1 特征值与特征向量的定义：Ax = λx

对一个 n×n 方阵 A，如果存在一个**非零**向量 x 和一个标量 λ，使得

    A x = λ x

那么 x 称为 A 的**特征向量（eigenvector）**，λ 称为对应的**特征值（eigenvalue）**。等式的含义是：A 作用在 x 上，效果只是把 x 沿它自己的方向缩放 λ 倍，既不改变方向（λ>0）或恰好反向（λ<0），也不把它转到别处去。

必须强调"x 非零"：若允许 x=0，则任何 λ 都能让 A·0=λ·0 成立，定义就失去意义。但特征值 λ **可以**是 0——λ=0 对应的特征向量正是满足 Ax=0 的非零向量，也就是零空间里的向量（关联大主题2）。

把 A 想成一个"把整个空间揉一揉"的操作。绝大多数向量被揉过之后会改变指向，但总有一些"骨架方向"只是被拉伸或压缩而指向不变——这些就是特征向量，拉伸的倍率就是特征值。它们之所以重要，是因为它们暴露了 A 最本质的行为：沿骨架方向，一个复杂的矩阵乘法退化成一次简单的数乘。

最小例子：单位阵 I 把每个向量原样保留，所以**任何**非零向量都是它的特征向量，特征值全是 1。又如把平面沿 x 轴翻转的矩阵 [[1,0],[0,−1]]：x 轴方向的向量不动（λ=1），y 轴方向的向量被反向（λ=−1），这两个方向就是它的特征方向。

易错点：特征向量只定方向不定长度——若 x 是特征值 λ 的特征向量，则 2x、−3x 也都是（同一个 λ）。所以数值库返回的特征向量通常被归一化成单位长度，方向可能带一个整体正负号，只要成比例就都对，不必纠结库给的具体数值和你手算的差一个倍数。

### 5.1.2 特征方程 det(A − λI) = 0：求特征值

把定义 Ax=λx 移项写成 Ax−λx=0，再把右边的 λx 写成 λIx（I 是单位阵），得到

    (A − λI) x = 0

这是一个齐次方程组。要它有**非零**解 x，矩阵 A−λI 必须是奇异（不可逆）的——否则唯一解就是 x=0。而方阵奇异的充要条件是行列式为零（关联大主题4），于是得到求特征值的**特征方程（characteristic equation）**：

    det(A − λI) = 0

把它按 λ 展开，是一个关于 λ 的 n 次多项式（**特征多项式**），它的根就是全部特征值。n×n 矩阵在复数范围内计重数恰有 n 个特征值。

直觉与逻辑链要理清："先有 λ 让 A−λI 变奇异，才可能有非零 x"——所以求解顺序是先用 det(A−λI)=0 解出所有 λ，再对每个 λ 回到 (A−λI)x=0 求 x（下一节）。为什么奇异是关键？因为 A−λI 奇异 ⇔ 它的零空间非平凡 ⇔ 存在非零 x 被它压成 0 ⇔ Ax=λx，这几句是同一件事的不同说法。

最小例子：

    A = [[4, 1], [2, 3]]

    A − λI = [[4−λ, 1], [2, 3−λ]]

    det(A − λI) = (4−λ)(3−λ) − 1·2 = λ² − 7λ + 10 = (λ−2)(λ−5)

所以特征值是 λ=2 与 λ=5。

两个"免算"检验（务必用来自查）：全部特征值之**和**等于矩阵的**迹**（对角线元素之和），全部特征值之**积**等于矩阵的**行列式**：

    λ₁ + λ₂ + … + λ_n = trace(A)

    λ₁ · λ₂ · … · λ_n = det(A)

上例中 2+5=7 正好是迹 4+3，2×5=10 正好是 det(A)=4·3−1·2=10，两项都对得上。

易错点：det(A−λI) 里减的是 **λI**（只在对角线上减 λ），不是把整个矩阵每个元素都减 λ——这是初学者最常见的展开错误。另外 3×3 及以上手算行列式容易出错，建议算完一定用"和=迹、积=det"这两条快速校验。

### 5.1.3 求特征向量：解 (A − λI)x = 0

求出某个特征值 λ 后，把它代回

    (A − λI) x = 0

再解这个齐次方程组，它的**非零解**就是 λ 对应的特征向量；这些解构成一个子空间，称为 λ 的**特征空间（eigenspace）**，就是 A−λI 的零空间（关联大主题2的零空间求法：消元、找自由变量）。

沿用上例 A=[[4,1],[2,3]]：

对 λ=5：

    A − 5I = [[−1, 1], [2, −2]]

两行成比例，方程退化为 −x₁+x₂=0，即 x₁=x₂，取特征向量

    x = [1, 1]ᵀ

对 λ=2：

    A − 2I = [[2, 1], [2, 1]]

方程为 2x₁+x₂=0，即 x₂=−2x₁，取特征向量

    x = [1, −2]ᵀ

λ 就是"让 A−λI 恰好塌陷出一个零空间"的那个数，代回去解零空间自然就捞出这个方向。因为 A−λI 已经是奇异的，它的两行/多行必然线性相关，所以解出来一定有自由变量、一定能取到非零向量——如果你代回后发现只有零解，说明前面的 λ 算错了。

数值印证：numpy 对上例 `np.linalg.eig` 返回特征值 {2, 5}，特征向量列分别约 [0.707,0.707]∝[1,1]（配 λ=5）与 [−0.447,0.894]∝[1,−2]（配 λ=2），方向与手算一致，仅长度被归一化、并可能相差一个整体符号（脚本见文末）。

易错点：特征向量成比例即等价，别因为库给的是单位向量、或符号相反就以为算错。若一个特征值是**重根**（代数重数>1），它的特征空间可能是多维的，需要在 (A−λI)x=0 里找出多个线性无关解；也可能"找不齐"——这正是下一小节可对角化条件要处理的核心问题。

## 5.2 对角化与矩阵的幂

### 5.2.1 对角化 A = SΛS⁻¹

若 n×n 矩阵 A 有 n 个**线性无关**的特征向量，把它们作为列拼成矩阵 S（特征向量矩阵），把对应的特征值放在对角线上组成对角阵 Λ，则

    A = S Λ S⁻¹

等价地 S⁻¹ A S = Λ。这一步称为**对角化（diagonalization）**：它说 A 与对角阵 Λ 相似，两者只是在不同坐标系下描述的同一个线性变换。

为什么成立：把 A 依次作用在 S 的各列（即各特征向量）上，第 j 列被缩放 λ_j 倍，合起来正好是 AS = SΛ；只要 S 可逆（即 n 个特征向量线性无关），两边右乘 S⁻¹ 就得到 A=SΛS⁻¹。

S 的列是一组"骨架方向"新基。把任意向量先用 S⁻¹ 翻译成"在这组骨架基下的坐标"，A 在这套坐标里只是让每个坐标各自乘上自己的 λ（这就是 Λ 的作用），最后再用 S 翻译回原坐标。原本纠缠的矩阵乘法，被"换到特征向量坐标系"后彻底解耦成 n 个独立的标量缩放——这就是对角化的全部意义，也是后面求幂、求指数能一步到位的根源。

易错点与记号：Λ 里特征值的排列顺序必须与 S 里特征向量的列顺序**一一对应**（第 j 列特征向量配第 j 个对角元 λ_j），配错则等式不成立。S 的列顺序可以任意换，只要 Λ 跟着换。另外不同教材记号不同：Strang 早期用 S，较新版本改用 X 记特征向量矩阵（写作 A=XΛX⁻¹），二者只是字母差异、含义相同；本报告统一用 S。

### 5.2.2 矩阵的幂 A^k：对角元各自求幂

对角化最直接的红利是算矩阵的高次幂。由 A=SΛS⁻¹，反复相乘时中间的 S⁻¹S 都抵消为 I：

    A^k = S Λ^k S⁻¹

而 Λ 是对角阵，Λ^k 只需把每个对角元（特征值）各自求 k 次幂：

    Λ^k = diag(λ₁^k, λ₂^k, …, λ_n^k)

于是求 A^k 从"做 k−1 次 n×n 矩阵乘法"（昂贵）变成"给 n 个标量求幂再夹一次 S、S⁻¹"（便宜且不随 k 增长）。

直觉与用途：A^k 描述"把同一个变换重复施加 k 次"后的效果，在离散动态系统里无处不在——例如状态每步演化 x_{k}=A x_{k−1}，则 x_k = A^k x_0。把 x_0 用特征向量展开成 x_0=c₁x₁+…+c_nx_n，则

    A^k x_0 = c₁ λ₁^k x₁ + c₂ λ₂^k x₂ + … + c_n λ_n^k x_n

一眼就能看出长期行为由**最大 |λ|** 那一项主导：|λ|>1 的方向指数增长、|λ|<1 的方向指数衰减、|λ|=1 的方向保持——这套"看特征值定长期命运"的思路直接通向 5.3 稳定性与 5.4 马尔可夫稳态。

数值印证：对 A=[[4,1],[2,3]]，`matrix_power(A,4)` 与 `S diag(λ⁴) S⁻¹` 给出完全相同的结果 [[422,203],[406,219]]（脚本见文末），验证 A^k=SΛ^kS⁻¹。

易错点：这套公式**只对可对角化的 A 成立**；若 A 不可对角化（S 不可逆），就不能这么算，得改用 5.4 之外的 Jordan 形（属大主题8，本报告不展开）。

### 5.2.3 可对角化条件：特征向量能否张成整个空间

A 可对角化 **⇔** 它有 n 个线性无关的特征向量（它们能张成整个 n 维空间、拼成可逆的 S）。这是对角化唯一的门槛，与特征值是否重复无必然关系。

两条实用充分条件与判据：
- **充分条件**：若 A 的 n 个特征值**两两不同**（无重根），则对应特征向量必然线性无关，A 一定可对角化。
- **重根时需逐个检查**：对每个特征值，其**几何重数**（特征空间维数，即 A−λI 零空间的维数）若等于**代数重数**（它作为特征多项式根的重数），则该特征值"贡献够了特征向量"；所有特征值都满足几何重数=代数重数时，A 可对角化，否则不可对角化，称为**亏损（defective）**矩阵。

对角化本质是"用特征向量当新基"，那就必须凑齐 n 个方向、能铺满整个空间。特征值不同必给出不同方向（无关）；但一个重复的特征值只保证"至少一个"特征向量，不保证"够数"——若它的特征空间维数不足，就凑不齐 n 个无关向量，S 缺列而不可逆。

最小易错例子：矩阵

    A = [[2, 1], [0, 2]]

特征值 λ=2（二重根，代数重数2），但 (A−2I)=[[0,1],[0,0]] 的零空间只有一维（几何重数1），只能找到一个方向的特征向量 [1,0]，凑不齐两个 ⇒ **不可对角化**。反例对照：单位阵 I 的 λ=1 也是二重根，但它的特征空间是整个二维平面（几何重数2=代数重数2）⇒ 可对角化（本来就是对角阵）。可见"有重根"不等于"不可对角化"，关键看几何重数够不够。

易错点：别把"可逆"和"可对角化"混为一谈——它们互不蕴含。上面亏损的 [[2,1],[0,2]] 可逆（det=4≠0）却不可对角化；而 [[0,0],[0,0]] 或某些含 λ=0 的矩阵可对角化却不可逆。可逆看特征值是否含 0，可对角化看特征向量是否够数，是两回事。

## 5.3 微分方程与矩阵指数

### 5.3.1 线性微分方程组 du/dt = Au：用特征值解耦

考虑一阶线性常系数微分方程组

    du/dt = A u

其中 u=u(t) 是随时间变化的向量、A 是常数方阵。它的解由 A 的特征值与特征向量给出：每个特征对 (λ_i, x_i) 贡献一个"纯模式"解 e^{λ_i t} x_i，通解是这些模式的线性组合

    u(t) = c₁ e^{λ₁ t} x₁ + c₂ e^{λ₂ t} x₂ + … + c_n e^{λ_n t} x_n

系数 c_i 由初始条件 u(0) 决定（把 u(0) 用特征向量展开即可解出）。

为什么指数会冒出来？因为若 u 恰好沿某个特征方向 x_i，则 Au=λ_i u，方程退化成标量方程 du/dt=λ_i u，其解正是 u=e^{λ_i t}u(0)——一维指数增长/衰减。对角化的思想在这里再次奏效：把向量方程投影到各特征方向上，就解耦成 n 个互不干扰的一维指数问题，最后叠加。这与 5.2 里 A^k 展开成 Σ c_i λ_i^k x_i 是同一套逻辑的"连续时间版"（那里是 λ^k，这里是 e^{λt}）。

易错点：这套模式叠加解**要求 A 可对角化**（特征向量能张成，才能展开任意 u(0)）；A 亏损时需引入 e^{λt} 乘多项式项的推广形式（导论级不展开）。

### 5.3.2 矩阵指数 exp(At)

上面的解可以统一写成一个紧凑形式，引入**矩阵指数（matrix exponential）**：

    u(t) = e^{At} u(0)

其中 e^{At} 由与标量 e^x 完全相同的幂级数定义（只是把 x 换成矩阵 At）：

    e^{At} = I + At + (At)²/2! + (At)³/3! + …

当 A 可对角化 A=SΛS⁻¹ 时，它同样能对角元逐个取指数：

    e^{At} = S e^{Λt} S⁻¹,  其中 e^{Λt} = diag(e^{λ₁ t}, …, e^{λ_n t})

e^{At} 就是"把 du/dt=Au 从 0 演化到 t 的传播算子"，作用在初值上直接给出 t 时刻的状态，类比标量方程 u'=au 的解 u(t)=e^{at}u(0)。对角化把矩阵指数还原成对每个 λ 取一次标量 e^{λt}，与 5.2 求幂完全平行（幂是 λ^k，指数是 e^{λt}）。

易错点：一般情况下

    e^{A} e^{B} ≠ e^{A+B}

只有当 A、B 可交换（AB=BA）时该等式才成立——这是矩阵指数与标量指数最大的不同，切勿照搬。另外 e^{At} 不是"把 A 的每个元素取 exp"（那是逐元素运算，完全错误），必须走级数/对角化定义。

数值印证：对稳定矩阵 B=[[−2,1],[1,−2]]，`scipy.linalg.expm(B)` 与"特征分解逐元素取 exp"两种算法给出相同结果，`allclose` 为 True（脚本见文末），验证 e^{At}=Se^{Λt}S⁻¹。

### 5.3.3 稳定性判据：看特征值实部的符号

给定 du/dt=Au，随 t→∞ 解 u(t) 的命运完全由 A 的特征值决定。因为每个模式带因子 e^{λt}，其大小 |e^{λt}|=e^{Re(λ)·t} 只取决于 λ 的**实部** Re(λ)：

- 所有特征值 **Re(λ) < 0** ⇒ 每个模式都衰减 ⇒ u(t)→0，系统**渐近稳定**；
- 存在某个 **Re(λ) > 0** ⇒ 该模式指数放大 ⇒ u(t) 发散，系统**不稳定**；
- 最大实部 **= 0**（且无重根麻烦）⇒ 该模式既不增也不减，处于**临界/中性稳定**边界。

λ 的实部管"胀缩"（e^{Re(λ)t} 的指数增减），虚部管"旋转振荡"（e^{i·Im(λ)t} 只在复平面转圈、模长不变）。所以判稳定只需盯住实部符号：只要有一个方向在指数放大，整个系统迟早被它主导而炸开。这与 5.2 离散版"看最大 |λ| 是否>1"是同一思想的连续对应——连续系统看 Re(λ) 与 0 比，离散系统看 |λ| 与 1 比。

最小例子：B=[[−2,1],[1,−2]] 的特征值是 −1 和 −3，实部全负 ⇒ 无论初值如何，u(t) 都指数衰减到 0，稳定（numpy 验证特征值为 {−3,−1}，脚本见文末）。若把某个特征值换成正实部，对应方向就会发散。

易错点：判据看的是**实部** Re(λ)，不是 λ 本身或 |λ|——连续时间系统与离散时间系统的判据不同（连续比 Re(λ) 与 0，离散比 |λ| 与 1），初学者极易张冠李戴，务必按"du/dt（连续）看实部符号、x_{k+1}=Ax_k（离散）看模长"对号入座。

#### 来源与时效（本小主题末集中列）
- 锚点：MIT 18.06SC syllabus, Unit II 课程"Differential Equations and exp(At)"（官方 syllabus 已核实列出该课，同上 URL，核实 2026-07-26）；Strang《Introduction to Linear Algebra》§6.3"Systems of Differential Equations"（du/dt=Au 的模式解、e^{At} 定义与对角化、按 Re(λ) 判稳定）。
- 交叉核对（独立第二源）：Wikipedia "Matrix exponential" 条目（核实 2026-07-26）确认——e^{At} 的幂级数定义、可对角化时 e^{At}=Se^{Λt}S⁻¹、e^{A}e^{B}=e^{A+B} 仅在 AB=BA 时成立、以及 du/dt=Au 解为 u(t)=e^{At}u(0) 并按特征值实部判渐近稳定。与 Strang/18.06 一致，无分歧。
- 实证：scipy `expm(B)` 与特征分解形式一致（allclose True）、B 特征值实部全负（{−3,−1}）（脚本见文末）。
- 成熟度：GA/稳定；无「待核」项。

## 5.4 马尔可夫矩阵与 Fourier

### 5.4.1 马尔可夫矩阵的性质：λ=1 必是特征值、其余 |λ|≤1

**马尔可夫矩阵（Markov matrix，又称随机矩阵 stochastic matrix）**是所有元素非负、且**每一列元素之和为 1** 的方阵（本报告采用"列随机"约定，与 Strang/18.06 一致；有的资料用"行随机"，见易错点）。它有两条决定性质：

- **λ = 1 一定是它的一个特征值**；
- **所有特征值都满足 |λ| ≤ 1**（没有哪个方向会被放大）。

为什么 λ=1 必在：列和全为 1 意味着"全 1 行向量 [1,1,…,1] 乘 A 等于它自身"，即 Aᵀ 有特征值 1；而 A 与 Aᵀ 特征多项式相同、特征值集合一致，所以 A 也有 λ=1。为什么 |λ|≤1：列和为 1 使得反复相乘不会让总量膨胀，任何模式都不会指数放大——这正是它能描述"概率在各状态间转移、总概率守恒"的根本原因。

把 A 的第 j 列读成"当前在状态 j，下一步转移到各状态的概率分布"（列和=1 即概率归一）。给一个概率分布向量 p（各分量非负、和为1），Ap 就是走一步后的新分布，仍是合法概率分布。λ=1 的方向就是"走一步也不变"的分布，即稳态（下一节）。

易错点：**列随机 vs 行随机**是最大的约定陷阱——Strang/18.06 用列和为 1（分布是列向量、演化为 p→Ap）；概率论许多教材（及 L2-03 马氏链）用行和为 1（分布是行向量、演化为 p→pA）。两种写法互为转置，稳态分别是 A 或 Aᵀ 的 λ=1 特征向量，数学等价但公式方向相反，读任何资料前先确认它用哪种约定，不要生搬。

### 5.4.2 稳态分布：λ=1 的特征向量（与 L2-03 马氏链互为补充）

**稳态分布（steady state / stationary distribution）**是马尔可夫矩阵 λ=1 对应的特征向量 π（归一化成各分量非负、总和为 1），它满足

    A π = π

即"再走一步分布也不变"。若马尔可夫矩阵是"正的"（某次幂后所有元素严格为正，即链不可约且非周期），则从**任意**初始分布出发反复迭代 A^k p₀ 都会收敛到同一个 π，且 π 唯一。

因为 λ=1 是（正马尔可夫矩阵中）唯一模长最大的特征值，其余 |λ|<1 的模式在 A^k 里带 λ^k→0 而逐渐消亡（回顾 5.2 的 A^k x₀=Σ c_i λ_i^k x_i），长期只剩 λ=1 那一项存活——它就是稳态。所以"求稳态"有两条等价路径：解特征向量方程 (A−I)π=0，或直接从任意分布幂迭代 A^k p₀ 到收敛。

最小例子：

    A = [[0.9, 0.2], [0.1, 0.8]]

列和均为 1，特征值为 1 与 0.7。解 (A−I)π=0 得 π ∝ [2,1]，归一化后

    π = [2/3, 1/3] ≈ [0.6667, 0.3333]

从 [1,0] 出发幂迭代同样收敛到 [0.6667,0.3333]（numpy 两法一致，脚本见文末）。

与 L2-03 的接口（**不在本报告重复立项**）：这里从"线性代数/特征值"角度看马尔可夫矩阵——稳态=λ=1 特征向量、收敛速度由第二大 |λ| 决定。概率论课 L2-03 的"马尔可夫链/平稳分布"从随机过程角度讲同一对象（状态、转移、可逆性、遍历性、混合时间等），两者互为补充：本报告只做"稳态即 λ=1 特征向量"这个线代接口，随机过程性质的深挖归 L2-03，避免重复。

易错点：并非每个马尔可夫矩阵都有唯一稳态或必然收敛——需要"正/不可约非周期"条件；周期性链（如确定性地在两状态间来回，特征值含 −1）会振荡不收敛，可约链可能有多个稳态。导论级只需记住"正马尔可夫矩阵有唯一稳态且任意初值收敛到它"。

### 5.4.3 Fourier 与投影的关联：正交基下的系数就是投影

18.06 把马尔可夫矩阵与 **Fourier 级数**放在同一讲，核心共同点是**"用一组好基把向量/函数展开"**这个思想，而 Fourier 展开的系数计算本质上就是**投影**（关联大主题3）。给一组两两正交的基向量 q₁,…,q_n，任意向量 v 可展开为

    v = c₁ q₁ + c₂ q₂ + … + c_n q_n

当基**正交**时，每个系数由一次投影（内积比）直接算出、互不干扰：

    c_i = (qᵢᵀ v) / (qᵢᵀ qᵢ)

（若基已归一化为单位正交，则分母为 1，c_i=qᵢᵀv。）Fourier 级数就是这套做法在函数空间的版本：用正弦、余弦这组"两两正交的函数基"去展开一个周期函数，每个 Fourier 系数就是该函数在对应正弦/余弦上的投影（内积用积分定义）。

直觉与关联：为什么把它和特征值这一章放一起？因为对角化（5.2）也是"换到一组特别的基（特征向量）使问题解耦"；当矩阵对称时特征向量还能取成**正交**基（谱定理，大主题6），此时"用特征向量展开"就和"用正交基做投影展开"完全统一——Fourier 正是这种正交展开在无穷维、可与信号处理相接的经典范例。正交是关键：它让每个系数独立可求（各自投影），不必解一个耦合的线性方程组。

易错点：只有基**正交**时系数才是简单的逐个投影；非正交基下的展开系数需要解 Sc=v（即 c=S⁻¹v）这个耦合方程组，不能逐分量投影。Fourier 深挖（收敛性、复指数形式、离散 FFT）归信号/大主题9（复矩阵与 FFT），本节只点明"Fourier 系数=正交基上的投影"这个线代接口。
