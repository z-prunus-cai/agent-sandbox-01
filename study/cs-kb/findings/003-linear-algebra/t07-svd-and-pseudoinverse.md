## 7.1 SVD

### 7.1.1 奇异值分解是什么

奇异值分解（Singular Value Decomposition，SVD）把任意一个 m×n 实矩阵 A 分解成三个矩阵的乘积：

A = UΣVᵀ

其中 U 是 m×m 正交矩阵（列称为左奇异向量，UᵀU = I），V 是 n×n 正交矩阵（列称为右奇异向量，VᵀV = I），Σ 是 m×n 的「对角」矩阵，对角线上是非负的奇异值（singular values），按从大到小排列：

σ₁ ≥ σ₂ ≥ … ≥ σᵣ > 0，其余为 0（r = A 的秩）

SVD 最要紧的一句话是：**每一个矩阵都有 SVD**——不论是方阵还是长方形、满秩还是降秩、对称还是不对称，都能这样分解。这一点和大主题5的特征分解 A = SΛS⁻¹ 形成鲜明对照：特征分解只对方阵谈、还要求「特征向量能张满空间」（可对角化）才成立，很多矩阵根本没有；而 SVD 对所有矩阵无条件存在，这正是它成为线性代数「压轴分解」的原因。

SVD 是把一个可能很复杂、不对称、非方阵的线性映射 A，拆成「一次旋转（Vᵀ）→ 沿坐标轴的纯缩放（Σ）→ 再一次旋转（U）」这三个最简单的动作的复合（几何细节见 7.1.3）。所有的「歪斜、拉伸、翻转」都被 SVD 归结成「转一下、按不同倍率拉一下、再转一下」。

Σ 通常和 A 一样是 m×n 的长方形，只是只有主对角位置 (i,i) 可能非零。奇异值 σᵢ 恒为非负实数（这是约定，把符号都塞进 U、V 里去了），这和特征值可以是负数、复数很不一样。另一个易错点：不要把「奇异值」和「特征值」混为一谈——只有当 A 是对称半正定矩阵时两者才恰好相等，一般情况下奇异值是 σᵢ、特征值是 λᵢ，是两套不同的数（关系见 7.1.2）。

### 7.1.2 奇异值、奇异向量与 AᵀA、AAᵀ 的关系

SVD 的三个因子不是凭空来的，它们和两个对称矩阵 AᵀA、AAᵀ 直接挂钩。右奇异向量 v₁,…,vₙ 是 AᵀA 的标准正交特征向量，左奇异向量 u₁,…,uₘ 是 AAᵀ 的标准正交特征向量，而奇异值是这两个矩阵（相同的）非零特征值的算术平方根：

AᵀA vᵢ = σᵢ² vᵢ、 AAᵀ uᵢ = σᵢ² uᵢ、 σᵢ = √λᵢ（λᵢ 为 AᵀA 的特征值）

三者由下面这条「桥梁式」的关系串起来：

A vᵢ = σᵢ uᵢ（对 i = 1,…,r）

这就是 SVD 的构造来历，也是它为什么必然存在的原因。关键在于：不管 A 多不规矩，AᵀA 永远是**对称半正定**方阵。由大主题6的谱定理，对称矩阵一定能正交对角化、特征值全为实数；又因为半正定，特征值还非负，于是可以放心开平方得到 σᵢ。这样一来，V（AᵀA 的特征向量）和 σᵢ 就都有了；再定义 uᵢ = Avᵢ/σᵢ，可以验证这些 uᵢ 正好是 AAᵀ 的标准正交特征向量，U 也有了。整条链子完全建立在「AᵀA 对称半正定」这一必然事实上，所以 SVD 对任意 A 无条件存在。

对初学者，最好把 A vᵢ = σᵢ uᵢ 读成一句人话：「A 把右边这组标准正交基 {vᵢ} 干净地送到左边那组标准正交基 {uᵢ} 上，只在途中按倍率 σᵢ 拉伸」。这正是 SVD 的核心奇迹——任何线性映射，只要在定义域和值域各自挑对了标准正交基，作用就退化成「沿轴缩放」。这和特征向量「Avᵢ = λᵢvᵢ」的区别在于：特征向量进去出来是同一个方向（同一组基），而奇异向量进去是 vᵢ、出来变成另一组基里的 uᵢ，所以 SVD 能处理非方阵（定义域 ℝⁿ 和值域 ℝᵐ 维数都不同，本就该用两组基）。

AᵀA 和 AAᵀ 虽然尺寸不同（n×n 与 m×m），但它们的**非零**特征值完全相同（都是 σᵢ²），只是零特征值的个数不同。所以算奇异值时，挑那个尺寸更小的矩阵去求特征值更省事。另一个提醒：实际数值计算**不**走「先组装 AᵀA 再求特征值」这条路——那样会把条件数平方、放大误差（和大主题3里最小二乘的告诫同理），成熟库（LAPACK / numpy）用的是直接作用于 A 的稳定算法；这里的 AᵀA 关系只用来理解「SVD 从哪来」，不是推荐的算法。

### 7.1.3 几何意义：旋转—缩放—旋转

把 A = UΣVᵀ 作用在一个向量 x 上，按从右到左读，恰好是三个几何动作的复合：

Ax = U (Σ (Vᵀx))

第一步 Vᵀ 是一次旋转（正交矩阵保长度、保角度，只转不拉）；第二步 Σ 沿各坐标轴按倍率 σ₁,…,σᵣ 纯缩放（可能还把某些维压成 0）；第三步 U 又是一次旋转。于是 A 把 ℝⁿ 里的**单位球面**映成 ℝᵐ 里的一个**椭球**（或降维的椭球面），椭球各条半轴的长度恰好就是奇异值 σᵢ，半轴方向就是左奇异向量 uᵢ。

这个「转-拉-转」的画面是理解 SVD 最好用的心智模型。为什么正交矩阵是「旋转（或反射）」？因为 QᵀQ = I 意味着它不改变任何向量的长度和向量间夹角（回看大主题3：‖Qx‖ = ‖x‖），几何上只能是「刚性转动 / 翻转」。为什么中间那步是「沿轴缩放」？因为 Σ 是对角的，作用就是把第 i 个坐标乘以 σᵢ。合起来：任何线性映射再复杂，本质都是「换一组正交坐标看它 → 发现它只是沿这些新轴各拉一个倍率 → 再换回另一组正交坐标」。

最大的奇异值 σ₁ 有个直接的几何意义：它是 A 能把单位向量拉到的最大长度，也就是矩阵的 2-范数 ‖A‖₂ = σ₁；最小的非零奇异值 σᵣ 则是「最不容易被拉伸的方向」的倍率，σ₁/σᵣ 就是条件数（衡量 A 有多「病态」）。这些量在 7.2 低秩近似和数值稳定性里反复出现，先混个眼熟。

σᵢ 全为非负，所以椭球半轴长度不会是负数；「翻转 / 反射」这类带方向反转的效果被吸收进 U、V 的符号里了，不体现在 Σ 上。还有一个约定问题：当某个 σᵢ 有重根、或某 σᵢ = 0 时，对应的奇异向量方向不唯一（可以在那个子空间里任意选正交基），所以 SVD 的 U、V **不唯一**，但奇异值 σᵢ（作为一组数）是唯一的——下面 numpy 给出的 U、V 只是众多合法选择之一。

下面用 numpy 核对 A=UΣVᵀ、U 与 V 正交、桥梁关系 Av₁=σ₁u₁，以及 σᵢ²=AᵀA 的特征值（真实输出，对应基线串）：

```python
import numpy as np
np.set_printoptions(suppress=True)
A = np.array([[4,0],[3,-5]], dtype=float)
U, s, Vt = np.linalg.svd(A)
Sigma = np.zeros_like(A); np.fill_diagonal(Sigma, s)
V = Vt.T
print("s =", s.round(4))
print("A == U S V^T :", np.allclose(A, U @ Sigma @ Vt))
print("U^T U == I :", np.allclose(U.T @ U, np.eye(2)),
      "  V^T V == I :", np.allclose(V.T @ V, np.eye(2)))
print("A v1 =", (A @ V[:,0]).round(4), "  sigma1*u1 =", (s[0]*U[:,0]).round(4))
w = np.sort(np.linalg.eigvalsh(A.T @ A))[::-1]
print("eig(A^T A) =", w.round(4), "  s^2 =", (s**2).round(4))
```

```
s = [6.3246 3.1623]
A == U S V^T : True
U^T U == I : True   V^T V == I : True
A v1 = [-2.8284 -5.6569]   sigma1*u1 = [-2.8284 -5.6569]
eig(A^T A) = [40. 10.]   s^2 = [40. 10.]
```

奇异值 (6.3246, 3.1623) 的平方 (40, 10) 恰是 AᵀA 的特征值，且 Av₁ 与 σ₁u₁ 逐分量相等，印证桥梁关系。

## 7.2 低秩近似

### 7.2.1 截断 SVD 与秩一分解求和

把 A = UΣVᵀ 按奇异值「拆开来加」，可以写成 r 个秩一矩阵之和（r = 秩）：

A = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + … + σᵣuᵣvᵣᵀ

其中每一项 σᵢuᵢvᵢᵀ 都是一个秩为 1 的 m×n 矩阵（一列乘一行）。只保留前 k 项（k < r），扔掉后面奇异值小的项，就得到**截断 SVD**（truncated SVD），即秩为 k 的近似矩阵：

Aₖ = σ₁u₁v₁ᵀ + … + σₖuₖvₖᵀ

因为奇异值已按大到小排好，前面的项「携带的信息 / 能量最多」，越往后越次要。

这个「求和」写法是理解低秩近似的钥匙。直觉上，A 被拆成一堆「重要性递减」的图层：第一层 σ₁u₁v₁ᵀ 抓住了 A 最主要的结构，第二层补充次要结构……小奇异值对应的图层往往是噪声或细枝末节。只留前 k 层，就用「秩 k 的简单矩阵」抓住了「原矩阵的主干」。这正是主成分分析（PCA）、图像压缩、推荐系统里「降维」的代数内核（点接口，归 L5-02，不深挖）。

秩一项写成 σᵢuᵢvᵢᵀ（列向量 uᵢ 乘行向量 vᵢᵀ，得到 m×n 矩阵），别写成 σᵢuᵢᵀvᵢ（那是一个数）。另一个提醒：截断到 k 项后 Aₖ 的秩恰好是 k（前提是前 k 个奇异值都非零），所以「截断 SVD」和「低秩近似」是一回事的两种说法。

### 7.2.2 Eckart-Young 定理

Eckart-Young 定理回答了一个关键问题：在所有秩不超过 k 的矩阵里，谁离 A 最近？答案是——**截断 SVD 得到的 Aₖ 就是最优的那个**，而且在 2-范数（谱范数）和 Frobenius 范数下都最优：

对任意满足 rank(B) ≤ k 的 B，都有 ‖A − Aₖ‖ ≤ ‖A − B‖

近似误差有干净的闭式，等于被扔掉的那些奇异值：

‖A − Aₖ‖₂ = σₖ₊₁

‖A − Aₖ‖_F = √(σₖ₊₁² + σₖ₊₂² + … + σᵣ²)

这条定理是「为什么低秩近似要用 SVD 而不是别的办法」的理论保证。它的分量在于：它不是说「SVD 给了一个还不错的近似」，而是说「没有任何秩 k 矩阵能比它更接近 A」——这是一个最优性结论。直觉上，你砍掉的正是那些「拉伸倍率最小」的方向（σₖ₊₁ 之后），损失当然最小；而 2-范数误差恰好等于「最大的被砍掉的奇异值」σₖ₊₁，Frobenius 误差是「所有被砍掉奇异值的平方和再开根」。

想把矩阵压到秩 k，先看奇异值列表，如果 σₖ₊₁ 及之后都很小，说明「秩 k 已经足够、砍掉的都是零头」，压缩几乎无损；如果奇异值衰减很慢，说明矩阵「本质上就是高秩的」，硬压会损失大。一个易错点：定理只保证「在这两种范数下最优」；换一个别的矩阵范数，最优近似不一定还是截断 SVD（这属于更细的话题，本课不展开）。另一个提醒：命名上「Eckart-Young」有时也写成「Eckart–Young–Mirsky」（Mirsky 把结论推广到所有酉不变范数），教材多简称 Eckart-Young，指同一结论。

下面用 numpy 核对误差公式，并用两万次随机秩 2 矩阵做「打擂台」验证 Aₖ 确实最优（真实输出，对应基线串）：

```python
import numpy as np
rng = np.random.default_rng(0)
A = rng.standard_normal((5,4))
U, s, Vt = np.linalg.svd(A, full_matrices=False)
k = 2
A_k = (U[:,:k] * s[:k]) @ Vt[:k,:]        # 截断 SVD
print("奇异值 =", s.round(4))
print("||A-A_k||_2 =", round(np.linalg.norm(A-A_k,2),4), " sigma_{k+1} =", round(s[k],4))
print("||A-A_k||_F =", round(np.linalg.norm(A-A_k,'fro'),4),
      " sqrt(尾部平方和) =", round(np.sqrt(np.sum(s[k:]**2)),4))
best = np.linalg.norm(A-A_k,'fro')
for _ in range(20000):
    B = rng.standard_normal((5,2)) @ rng.standard_normal((2,4))   # 随机秩<=2
    best = min(best, np.linalg.norm(A-B,'fro'))
print("两万次随机秩2的最小Frob误差 =", round(best,4), " (未能低于 A_k 误差)")
```

```
奇异值 = [3.0357 2.016  1.279  0.4853]
||A-A_k||_2 = 1.279   sigma_{k+1} = 1.279
||A-A_k||_F = 1.3679   sqrt(尾部平方和) = 1.3679
两万次随机秩2的最小Frob误差 = 1.3679  (未能低于 A_k 误差)
```

2-范数误差恰等于 σ₃=1.279，Frobenius 误差恰等于 √(σ₃²+σ₄²)=1.3679；两万次随机秩 2 矩阵没有一个能把误差压到 Aₖ 之下，印证 Eckart-Young 的最优性。

### 7.2.3 图像压缩与存储量

把一张灰度图像看成一个 m×n 的像素矩阵 A，做截断 SVD 保留前 k 项，就得到图像压缩：只需存 k 个奇异值、k 个左奇异向量（各 m 维）、k 个右奇异向量（各 n 维），存储量从原来的 mn 个数降到：

k(m + n + 1)

当 k ≪ min(m,n) 时，这远小于 mn，就实现了压缩；重建时用 Aₖ = Σσᵢuᵢvᵢᵀ 把图像「拼」回来，肉眼往往看不出损失。

这是 SVD 最直观的「杀手级」演示。为什么能压缩？因为真实图像的奇异值通常衰减很快——少数几个大奇异值抓住了图像的主要轮廓、大片色块，剩下一长串小奇异值只是细节和噪声。举个数量级的例子：一张 512×512 的图，原始要存 512×512 ≈ 26 万个数；取 k=50，只需 50×(512+512+1) ≈ 5.1 万个数，压到原来的约 1/5，而图像主体清晰可辨。k 取得越大越清晰、压缩比越低，这是一条可调的「质量—体积」权衡曲线。

SVD 压缩是**有损**压缩（k < r 时丢掉了信息），不是无损；而且它并不是工业界照片压缩的实际标准（JPEG 用的是离散余弦变换，深挖归信号 / 图像课），SVD 图像压缩主要作为「低秩近似」的教学演示和 PCA 的入口，不要误以为你的相机在跑 SVD。另一个提醒：彩色图有 RGB 三个通道，通常对三个通道各做一次 SVD 再合起来。

## 7.3 伪逆

### 7.3.1 Moore-Penrose 伪逆

当 A 不是可逆方阵（长方形、或方阵但降秩）时，普通逆 A⁻¹ 不存在，但仍有一个「最像逆」的替代品——Moore-Penrose 伪逆（pseudoinverse），记作 A⁺。用 SVD 构造最简单：把 A = UΣVᵀ 里的 Σ 中每个**非零**奇异值取倒数、并把矩阵转置成 n×m，得到 Σ⁺，则

A⁺ = VΣ⁺Uᵀ

其中 Σ⁺ 在原来 σᵢ 的位置放 1/σᵢ（σᵢ ≠ 0），原来是 0 的位置仍是 0。伪逆是使下面四条 Penrose 条件同时成立的唯一矩阵：

AA⁺A = A、 A⁺AA⁺ = A⁺、 (AA⁺)ᵀ = AA⁺、 (A⁺A)ᵀ = A⁺A

A 在它的「有效方向」（非零奇异值 σᵢ 对应的方向）上按倍率 σᵢ 拉伸，伪逆就在这些方向上按 1/σᵢ **拉回来**；而 A 压成 0 的那些方向（零奇异值 / 零空间），信息已经彻底丢失、无法恢复，伪逆对它们只能给 0。所以伪逆是「能逆的地方精确逆回去、逆不了的地方给零」。当 A 恰好可逆时，所有 σᵢ 非零、没有零空间，A⁺ 就退化成普通逆 A⁻¹——伪逆是逆的真正推广。

为什么用「取倒数非零奇异值」这个定义？因为 SVD 已经把 A 的作用彻底摊成「沿正交轴按 σᵢ 缩放」，逆一个缩放就是按 1/σᵢ 缩放，天经地义；而 σᵢ=0 的轴根本没被拉出去，无从拉回，只能置零。这也解释了四条 Penrose 条件的意味：AA⁺ 和 A⁺A 都是**投影矩阵**（对称、幂等，回看大主题3），分别把向量投到 A 的列空间、行空间上——伪逆做的是「在能逆的子空间里当逆用」。一个易错点：Σ⁺ 是对**非零**奇异值取倒数，绝不能对 0 取倒数（那会爆炸）；数值实现里还要设一个阈值，把「接近 0 的小奇异值」也当 0 处理，否则 1/σ 会放大噪声（这就是 `numpy.linalg.pinv` 的 `rcond` 参数在做的事）。

### 7.3.2 满秩情形：左逆与右逆

伪逆在两种「满秩长方形」情形下有更眼熟的闭式。当 A（m×n，m > n）**列满秩**（列线性无关）时：

A⁺ = (AᵀA)⁻¹Aᵀ

此时 A⁺A = I（n×n），A⁺ 是 A 的**左逆**。当 A（m < n）**行满秩**（行线性无关）时：

A⁺ = Aᵀ(AAᵀ)⁻¹

此时 AA⁺ = I（m×m），A⁺ 是 A 的**右逆**。

第一条式子应该让你「一惊」：(AᵀA)⁻¹Aᵀ 正是大主题3最小二乘的正规方程解 x̂ = (AᵀA)⁻¹Aᵀb 里那个作用在 b 上的矩阵！这不是巧合——它揭示了「最小二乘 = 用伪逆解方程」，7.3.3 会把这层统一讲透。直觉上，列满秩时 A 把 ℝⁿ 一对一地嵌进 ℝᵐ（没有零空间、不丢信息），所以存在一个把像拉回原像的左逆；行满秩时 A 是满射（值域铺满 ℝᵐ），存在右逆。

左逆、右逆一般**不相等**、也都不是「两边都能约掉」的真逆——A⁺A=I 不代表 AA⁺=I。只有 A 是可逆方阵时两者才合一成 A⁻¹。另一个提醒：这两条闭式要求「满秩」；一旦列相关或行相关（降秩），AᵀA 或 AAᵀ 就奇异、求不了逆，这时**只能**回到 7.3.1 的 SVD 定义 A⁺=VΣ⁺Uᵀ——它对任何秩都成立，是最通用的定义。所以遇到降秩矩阵，别硬套 (AᵀA)⁻¹Aᵀ。

### 7.3.3 四子空间与最小二乘的统一

伪逆把四大基本子空间（大主题2）和最小二乘（大主题3）缝成一张完整的图。A⁺ 的作用可以按四子空间讲清楚：它把 A 的**列空间**里的向量一对一地拉回**行空间**（在这两个 r 维子空间之间，A 和 A⁺ 互为逆），把 A 的**左零空间**（列空间的正交补）整个压成 0。于是对任意右端 b，

x̂ = A⁺b

给出的正是最小二乘问题「最小化 ‖Ax − b‖」的解；而且当解不唯一时（A 列相关、有零空间），A⁺b 自动挑出其中**范数最小**的那一个——它恰好落在行空间里，不含任何零空间成分。

这是本大主题的收束点，值得慢慢体会。回顾大主题3：当 Ax=b 无解（b 不在列空间）时，最小二乘把 b **投影**到列空间、再解。当 A 列相关时，最小二乘解又**不唯一**（可加任意零空间向量）。伪逆一次性解决这两个麻烦：它先把 b 投到列空间（丢掉够不着的 左零空间分量），再在行空间里唯一地拉回一个 x̂，这个 x̂ 既让残差最小（最小二乘）、又让自身范数最小（在多个解里挑最短的）。一句话总结：

x̂ = A⁺b 是最小二乘问题的「最小范数解」

**伪逆 = 万能求解器**。方程有唯一解，A⁺b 给那个解；方程无解（超定），A⁺b 给最小二乘近似；方程多解（欠定 / 降秩），A⁺b 给最小范数的那个。无论 A 什么形状什么秩，x̂ = A⁺b 都给你一个「最合理」的答案。「最小范数」这条在机器学习里尤其重要——它是一种天然的正则化（偏好简单 / 小的解），是理解岭回归、过参数化模型泛化的入口（点接口，归 L5-02 及后续课，不深挖）。一个易错点：min-norm 是指解 x̂ 的范数最小，不是残差范数最小；残差最小是「最小二乘」那一层，两层含义别混。

下面用 numpy 核对：列满秩时 A⁺=(AᵀA)⁻¹Aᵀ 且 A⁺b 与 lstsq 一致（并与大主题3的 x̂=(5,−3) 吻合）；降秩时 A⁺b 给最小范数解；四条 Penrose 条件成立（真实输出，对应基线串）：

```python
import numpy as np
np.set_printoptions(suppress=True)
# (a) 列满秩：A+ = (A^T A)^-1 A^T，且 A+ b = 最小二乘解
A = np.array([[1,0],[1,1],[1,2]], dtype=float); b = np.array([6.,0.,0.])
Ap = np.linalg.pinv(A)
print("A+ == (A^T A)^-1 A^T :", np.allclose(Ap, np.linalg.inv(A.T@A)@A.T))
print("A+ b =", (Ap@b).round(4), " lstsq =", np.linalg.lstsq(A,b,rcond=None)[0].round(4))
# (b) 降秩：A+ 给最小范数最小二乘解
C = np.array([[1,1],[1,1]], dtype=float); d = np.array([2.,4.])   # 秩1
print("秩(C) =", np.linalg.matrix_rank(C), " 最小范数解 C+ d =", (np.linalg.pinv(C)@d).round(4))
# (c) 四条 Penrose 条件
def penrose(A,Ap):
    return (np.allclose(A@Ap@A,A), np.allclose(Ap@A@Ap,Ap),
            np.allclose((A@Ap).T,A@Ap), np.allclose((Ap@A).T,Ap@A))
print("Penrose 四条 :", penrose(A,Ap))
```

```
A+ == (A^T A)^-1 A^T : True
A+ b = [ 5. -3.]  lstsq = [ 5. -3.]
秩(C) = 1  最小范数解 C+ d = [1.5 1.5]
Penrose 四条 : (True, True, True, True)
```

列满秩时 A⁺ 就是正规方程矩阵，A⁺b=(5,−3) 与大主题3的最小二乘解完全一致；降秩系统 C 的众多解里，C⁺d=(1.5,1.5) 是范数最小的那个（而不是例如 (0,3)）；四条 Penrose 条件全部为 True，确认 numpy 的 pinv 即 Moore-Penrose 伪逆。
