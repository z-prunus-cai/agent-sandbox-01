## 3.1 随机变量与分布

### 3.1.1 随机变量

**随机变量（random variable, RV）**是从样本空间 Ω 到实数的一个函数：它把随机试验的每个可能结果 ω 映射成一个实数 X(ω)。记号上通常用大写字母 X、Y 表示随机变量本身，用小写 x、y 表示它取到的具体数值。

    X : Ω → ℝ,   ω ↦ X(ω)

初学者最容易卡的第一关，就是"随机变量为什么是个**函数**，而不是一个变来变去的数"。直觉是这样的：抛两枚硬币，样本空间是 {正正, 正反, 反正, 反反} 这四个结果，本身不是数字，没法直接算平均、算方差。于是我们定义一个规则"数出正面个数"——它把"正正"记为 2、"正反"和"反正"记为 1、"反反"记为 0。这个"规则"就是随机变量，它是确定的函数（输入结果、输出数字，毫无随机性）；随机性全在"到底出现哪个结果 ω"上。所以准确说法是：**随机变量本身不随机，随机的是喂给它的那个结果**。

一次掷骰子，令 X = 掷出的点数，则 X 是随机变量，X 的取值范围是 {1,2,3,4,5,6}。再令 Y = 1（若点数为偶）或 0（若为奇），Y 也是随机变量——同一个试验上可以定义无数个随机变量，取决于你关心结果的哪个数值侧面。

不要把"随机变量 X"和"事件 {X = x}"混为一谈。X 是函数，{X = 2} 才是一个事件（即"数出的正面个数恰为 2"这件事），它才有概率 P(X = 2)。这个区分是理解下面 PMF 的前提。

### 3.1.2 离散型与连续型随机变量

按取值范围，随机变量分两大类。**离散型随机变量**的取值构成一个可数集合（有限个或可列无穷个，如 {0,1,2,…}）；**连续型随机变量**的取值充满某个实数区间（不可数，如 [0,1] 或整条实轴），且落在任一单点上的概率为 0。

如果你能把可能取值"一个一个数出来、排成一列"（哪怕排不完，如 0,1,2,3,…），就是离散；如果取值像"身高、等待时间、温度"那样在一段连续刻度上任意取，中间不留缝，就是连续。掷骰子点数、网站一小时的访问量是离散；灯泡寿命、随机点的横坐标是连续。

为什么要分家？因为两者描述"概率如何分配"的数学工具不同：离散型用 **PMF**（把概率像砝码一样放在一个个点上，见 3.1.3），连续型用 **PDF**（概率是一条密度曲线下的面积，见 3.3.1）。混用是初学者的高频错误——例如对连续型问"P(X = 3) 是多少"，答案恒为 0，得问"P(2.9 < X < 3.1)"才有意义。

还存在既非纯离散也非纯连续的"混合型"（如"下雨量：有一块概率集中在 0，其余连续分布"），本章按教材惯例只讲纯离散与纯连续两类，混合型属专家纵深，不展开。

### 3.1.3 PMF（概率质量函数）

**概率质量函数（probability mass function, PMF）**只对离散型随机变量定义，它给出 X 取每个具体值 x 的概率：

    p_X(x) = P(X = x)

一个合法的 PMF 必须满足两条：每个值非负，且所有值之和为 1。

    p_X(x) ≥ 0,   Σ_x p_X(x) = 1

"质量（mass）"这个词是精心选的：想象把总量为 1 的一块黏土，掰成小块分别粘在数轴上 X 可能取到的那些点上，每个点粘多少，就是那点的概率。PMF 就是这张"黏土分配表"，全部黏土加起来必须正好是 1（规范性），不能有负黏土（非负性）。

抛一枚公平硬币两次，X = 正面数，则

    p_X(0) = 1/4,  p_X(1) = 1/2,  p_X(2) = 1/4

三者相加 = 1，校验通过。要算"至少出一次正面"这类事件概率，就把对应点的 PMF 值加起来：P(X ≥ 1) = 1/2 + 1/4 = 3/4。

PMF 的值是**概率**，因此必须落在 [0,1] 内；这一点和后面连续型的 PDF 关键不同——PDF 的值是密度，可以大于 1（见 3.3.1）。初学者常把两者的"上界"记混。

### 3.1.4 CDF（累积分布函数）

**累积分布函数（cumulative distribution function, CDF）**对离散、连续所有随机变量都有定义，它给出 X 不超过某值 x 的概率：

    F_X(x) = P(X ≤ x)

CDF 是一个从 0 单调不减地升到 1 的函数：左端 x→−∞ 时趋于 0，右端 x→+∞ 时趋于 1，且右连续。

    lim_{x→−∞} F_X(x) = 0,   lim_{x→+∞} F_X(x) = 1

为什么要有 CDF，而不满足于 PMF/PDF？因为 CDF 是**统一语言**：离散型的 PMF 和连续型的 PDF 形式完全不同，但两者的 CDF 都是"落在阈值以下的概率"，长相一致，便于统一处理（尤其是求分位数、做随机数生成、比较不同分布）。对离散型，CDF 是一条阶梯函数——每到一个取值点就"跳"一下，跳的高度正是该点的 PMF 值；对连续型，CDF 是光滑上升的曲线，它的导数就是 PDF（见 3.3.2）。

区间概率可由 CDF 相减得到，这是 CDF 最常用的功能：

    P(a < X ≤ b) = F_X(b) − F_X(a)

易错点（离散型）：由于离散 CDF 是阶梯且在取值点处右连续，"≤"与"<"会差一个点的质量。例如掷骰子 X，P(X ≤ 3) = F(3) 含 X=3，而 P(X < 3) = F(3) − p(3) 不含。连续型没有这个烦恼（单点概率为 0，≤ 与 < 等价）。这类"边界含不含端点"的细节，是离散概率计算里最常见的踩坑处。

## 3.2 离散分布族

> 本节六个分布是离散概率的"标准零件库"。每个 ### 给出：生成场景直觉 + PMF + 参数含义 + 均值方差 + scipy 调用约定。均值方差与 PMF 数值均经本机 scipy 1.17.1 实证（见本节末）。计数记号 C(n,k) 表示二项系数（组合数），其组合学主体归 L1-02 大主题6，此处仅作概率计数接口引用。

### 3.2.1 Bernoulli（伯努利）分布

**Bernoulli(p)** 描述一次"成功/失败"二值试验：X = 1（成功，概率 p）或 X = 0（失败，概率 1−p）。它是所有离散分布里最基本的原子。

    P(X = 1) = p,   P(X = 0) = 1 − p
    E[X] = p,   Var(X) = p(1 − p)

把"抛一次硬币""点一次广告是否被点击""一次检测是否阳性"这类只有两种结果的单次试验，统一抽象成"成功概率为 p 的一次尝试"。它之所以是原子，是因为后面的 Binomial、Geometric、Negative Binomial 全都由"重复的独立 Bernoulli 试验"拼出来（见下）。

p = 0.3 时 E[X] = 0.3，Var(X) = 0.3×0.7 = 0.21。注意方差在 p = 0.5 时最大（0.25）——最不确定；在 p 趋近 0 或 1 时方差趋于 0——几乎必然是某一结果。

scipy：`scipy.stats.bernoulli(p)`，参数就是成功概率 p。

### 3.2.2 Binomial（二项）分布

**Binomial(n, p)** 描述 n 次**独立同分布** Bernoulli(p) 试验中"成功的总次数"X，取值 0,1,…,n：

    P(X = k) = C(n, k) · p^k · (1 − p)^{n−k},   k = 0,1,…,n
    E[X] = n·p,   Var(X) = n·p·(1 − p)

组合系数 C(n,k) 的意思是"n 次里挑哪 k 次成功"的方案数；p^k (1−p)^{n−k} 是任一指定的"k 成功、n−k 失败"序列的概率。二者相乘就把所有等概率序列汇总起来。

Binomial 就是 n 个 Bernoulli 之和，X = X₁+…+Xₙ。这解释了为什么均值是 n·p（期望线性性，每个贡献 p）、方差是 n·p(1−p)（独立可加，每个贡献 p(1−p)）——这两条 L2-03 大主题4 会正式讲。最小例子：抛 10 次公平硬币，正面数 X ~ Binomial(10, 0.5)，E[X] = 5。

Binomial 要求每次试验**独立且成功概率相同**。若是"不放回抽取"（每抽一次改变了后续概率），就不再是 Binomial 而是超几何分布（3.2.6）。这是初学者选型的头号混淆点。

scipy：`scipy.stats.binom(n, p)`。本机实证 `binom.pmf(3,10,0.3)=0.26682793`，与 C(10,3)·0.3³·0.7⁷ 逐位吻合。

### 3.2.3 Geometric（几何）分布

**Geometric(p)** 描述"重复独立 Bernoulli(p) 试验，直到第一次成功为止，所需的试验次数（或之前的失败次数）"。这里有一个记号陷阱：**支撑集起点有两套约定**。

约定 A（Blitzstein 主用，"失败次数"版）：X = 首次成功前的失败次数，支撑 {0,1,2,…}：

    P(X = k) = (1 − p)^k · p,   k = 0,1,2,…
    E[X] = (1 − p)/p,   Var(X) = (1 − p)/p^2

约定 B（scipy 主用，"总试验次数"版）：Y = 直到并含首次成功的试验总数，支撑 {1,2,3,…}：

    P(Y = k) = (1 − p)^{k−1} · p,   k = 1,2,3,…
    E[Y] = 1/p,   Var(Y) = (1 − p)/p^2

两者关系是 Y = X + 1，故均值差 1、方差相同。这正是"来源打架必须两边都记"的典型：Blitzstein《Introduction to Probability》把 Geometric 定义为失败次数版（起点 0），而 scipy.stats.geom 定义为试验次数版（起点 1）。用错约定会让均值差整整一个 1/p 中的常数项，是极隐蔽的 bug。

几何分布刻画"等待第一次成功要等多久"。p 越小，成功越罕见，平均等待越长（均值含 1/p）。最著名的性质是**无记忆性**——已经失败了 5 次，接下来还要等的次数分布和一开始完全一样（"骰子没有记忆"）；这是唯一具有无记忆性的离散分布，与连续侧的指数分布（3.4.3）遥相呼应。

scipy：`scipy.stats.geom(p)` 用约定 B。本机实证 p=0.25 时 `geom.stats` 给出 mean=4.0（=1/p）、var=12.0，`geom.pmf(1)=0.25`（=p，即第一次就成功），确认起点为 1。

### 3.2.4 Negative Binomial（负二项）分布

**Negative Binomial(r, p)** 是几何分布的推广：描述"重复独立 Bernoulli(p) 试验，直到累计出现第 r 次成功"，计数第 r 次成功前的**失败次数** X（Blitzstein 与 scipy 此处约定一致，均计失败数，支撑 {0,1,2,…}）：

    P(X = k) = C(k + r − 1, k) · p^r · (1 − p)^k,   k = 0,1,2,…
    E[X] = r(1 − p)/p,   Var(X) = r(1 − p)/p^2

组合系数 C(k+r−1, k) 计"前 k+r−1 次里安排哪 k 次失败"的方案数（最后一次必须是第 r 次成功，故不参与自由安排）。

把 r 段独立的几何等待接起来——等第 1 次成功、再等第 2 次……直到第 r 次，总失败数就是负二项。因此 r = 1 时负二项**退化为几何分布**（失败次数版）。均值方差也正好是几何的 r 倍，印证"独立叠加"。最小例子：r=5, p=0.4 时 E[X]=5×0.6/0.4=7.5，Var=18.75，本机实证一致。

负二项在不同文献/软件里还有"计成功前总试验数""用均值+离散度参数化"等多种约定（统计建模里常拿它当"过离散的泊松替代"）。选型前务必核对该库对 (r, p) 或 (n, p) 的确切定义。scipy：`scipy.stats.nbinom(n=r, p)`，其 n 即成功数 r、计失败数，与本节公式一致（本机 `nbinom.pmf(2,5,0.4)=0.055296` 与 C(6,2)·0.4⁵·0.6² 吻合）。

### 3.2.5 Poisson（泊松）分布

**Poisson(λ)** 描述"给定平均发生率 λ 下，单位时间/空间内某稀有事件发生的次数"X，取值 0,1,2,…：

    P(X = k) = e^{−λ} · λ^k / k!,   k = 0,1,2,…
    E[X] = λ,   Var(X) = λ

参数 λ > 0 既是均值也是方差，这个"均值等于方差"是泊松的招牌特征（实际数据若方差远大于均值，就是"过离散"，该改用负二项）。

泊松是"大量机会、每次极小概率"的极限产物——想象一小时里有极多个"可能来访问的瞬间"（n 很大），每个瞬间真来访问的概率极小（p 很小），但平均访问数 np = λ 适中，那么总访问数就近似 Poisson(λ)。这正是 3.5.1 泊松逼近的内容，也是"电话呼入数、放射性衰变计数、每页印刷错误数"都服从泊松的原因。最小例子：λ=2 时 `poisson.pmf(3,2)=0.18044704`，与 e⁻²·2³/3! 吻合（本机实证）。

泊松只对"事件独立、以恒定平均率随机发生"成立；若事件成簇发生（如地震余震）或率随时间变化，需换更复杂模型。scipy：`scipy.stats.poisson(mu=λ)`，注意参数名叫 `mu` 而非 lambda。

### 3.2.6 Hypergeometric（超几何）分布

**Hypergeometric** 描述"从一个有限总体中**不放回**抽取时，抽到的成功品个数"。设总体大小 N（此处沿用 Blitzstein 记号），其中成功品 K 个、失败品 N−K 个，抽取 n 个，令 X = 抽中的成功品数：

    P(X = k) = C(K, k) · C(N − K, n − k) / C(N, n)
    E[X] = n · K/N

分子是"从 K 个成功里挑 k 个、从 N−K 个失败里挑 n−k 个"的方案数，分母是"从 N 个里挑 n 个"的总方案数——纯古典概型。

直觉与关联（与二项对照）：Binomial 是**放回/独立**抽取（每次成功率恒为 p），Hypergeometric 是**不放回**抽取（抽走一个就改变了剩下的比例，各次不独立）。当总体 N 远大于抽取数 n 时，抽走几个几乎不改变比例，超几何就近似二项（p ≈ K/N）。经典场景：一副牌里抽 5 张有几张红桃、次品抽检、卡牌游戏抽卡。最小例子：N=50、K=5、n=10 时 E[X]=10×5/50=1.0，`hypergeom.pmf(1,50,5,10)=0.43133720` 与 C(5,1)C(45,9)/C(50,10) 吻合（本机实证）。

易错点（scipy 参数顺序，高频踩坑）：`scipy.stats.hypergeom(M, n, N)` 里 **M = 总体大小、n = 总体中成功品数、N = 抽取数**——scipy 的 `n` 是"总体成功数"，scipy 的 `N` 是"抽样数"，与许多教材（含本节）用 n 表抽样数的记号**正好相反**。调用前务必对齐，否则参数张冠李戴而不报错。

## 3.3 连续随机变量

> 本节把离散侧的 PMF/CDF 平移到连续侧。核心转变：单点概率恒为 0，概率变成"曲线下面积"，归一化从求和变成积分——这一步用到 L1-04 反常积分（无穷限）与后续多元情形的多重积分，此处点明接口，积分技巧本身归 L1-04。

### 3.3.1 PDF（概率密度函数）

**概率密度函数（probability density function, PDF）** f_X(x) 描述连续型随机变量的概率"密度"：它本身不是概率，而是"单位长度上的概率浓度"，落在区间 [a,b] 的概率等于 PDF 在该区间上的积分（曲线下面积）：

    P(a ≤ X ≤ b) = ∫_a^b f_X(x) dx

合法 PDF 须满足非负且全轴积分为 1（归一化）：

    f_X(x) ≥ 0,   ∫_{−∞}^{+∞} f_X(x) dx = 1

关键直觉（初学者最大门槛）：为什么单点概率是 0？因为单点区间长度为 0，面积 ∫_a^a f dx = 0。所以对连续型问"P(X = 3)"永远得 0，必须问"P(2.9 < X < 3.1)"这种区间概率才有意义。这也解释了 PDF 与 PMF 的本质差别——**PMF 值是概率（必 ≤1），PDF 值是密度（可以大于 1）**。例如 Uniform(0, 0.5) 的密度恒为 2（因为要让 0.5 长的区间面积等于 1，高必须是 2）。见到"密度 2"不要惊慌，它不是"概率 200%"。

PDF 之于连续概率，就像"质量密度（kg/m）"之于一根细棒——某一点的密度再高，那一点本身的质量也是 0；有质量的是一小段。要得到概率（质量），必须对密度沿区间积分。

### 3.3.2 CDF 与 PDF 的互逆关系

连续型的 CDF 与 PDF 通过积分/求导互为逆运算。CDF 是 PDF 从 −∞ 积到 x 的累计面积；反过来，PDF 是 CDF 的导数（在 CDF 可导处）：

    F_X(x) = ∫_{−∞}^{x} f_X(t) dt

    f_X(x) = d/dx F_X(x)

这一对关系是连续概率的"微积分基本定理版本"（正对应 L1-04 大主题4 的 FTC）：累积（积分）与密度（导数）互逆。它极其实用——已知 PDF 想求"落在阈值以下"的概率，就积分成 CDF；已知 CDF（往往更容易直接写出，如"最大值 ≤ x 等价于每个都 ≤ x"）想求密度，就求导。

区间概率同样用 CDF 相减，且连续型不必纠结端点：

    P(a < X ≤ b) = F_X(b) − F_X(a)

并非所有连续 CDF 处处可导（个别点可能有折角），此时 PDF 在该点可不定义，但不影响积分与概率计算（单点无面积）。初学者不必被这种测度零的细节困扰。

### 3.3.3 分位数（quantile）

**分位数函数**是 CDF 的反函数：给定概率 q ∈ (0,1)，第 q 分位数 x_q 是使"落在其以下的概率恰为 q"的那个值：

    F_X(x_q) = q,   即   x_q = F_X^{−1}(q)

特例：q = 0.5 是**中位数**（把概率对半分的点）；q = 0.25、0.75 是下、上四分位数。

CDF 是"给定阈值 x，问累计概率是多少"；分位数反过来"给定要多少累计概率 q，问阈值该设在哪"。它回答的是"考试考多少分能排进前 10%""洪水位设多高能覆盖 99% 的年份"这类实用问题。分位数还是**逆变换采样**的核心——把均匀随机数 U~Uniform(0,1) 代入 F⁻¹，得到的 F⁻¹(U) 就服从目标分布 X，这是从任意分布生成随机数的通用方法，也是连续 CDF 值得单独立项的一大原因。

分位数在离散型或 CDF 有"平台段"时可能不唯一或需约定取法（scipy 用 `ppf` 即 percent point function 计算，并对离散型采用特定约定）。连续严格增的 CDF 才有唯一分位数。

### 3.3.4 期望积分与连续归一化

连续型随机变量的期望，把离散的"取值乘概率再求和"换成"取值乘密度再积分"：

    E[X] = ∫_{−∞}^{+∞} x · f_X(x) dx

前提是这个积分（含无穷限，属 L1-04 大主题5 反常积分）**绝对收敛**；否则期望不存在（如柯西分布，重尾到期望发散）。

这里点明本小主题与 L1-04 的两个接口：其一，**归一化 ∫f dx = 1** 本身就是一个（常含无穷限的）反常积分，要判其收敛才能确认 PDF 合法；其二，多维连续情形（联合分布，归 L2-03 大主题5）的归一化与期望要用**多重积分**（L1-04 大主题8）。所以"能不能把这个密度积分出来、积分收不收敛"是连续概率的先决技能，本报告只点接口，积分技巧本身不在此纵深展开。

Uniform(0,1) 的密度恒为 1，E[X] = ∫₀¹ x·1 dx = 1/2，正是区间中点，符合"均匀分布期望在正中间"的直觉。期望的完整理论（线性性、LOTUS、方差）归 L2-03 大主题4，此处仅给连续期望的定义式作连续分布族（3.4）的计算基础。

## 3.4 连续分布族

> 五个连续标准分布。每个 ### 给场景直觉 + PDF + 参数含义 + 均值方差 + scipy 约定。**scipy 参数约定是本节重点易错处**——尤其指数/伽马用 `scale`、正态用标准差。均值方差与 PDF 数值均经本机 scipy 1.17.1 实证（见节末）。

### 3.4.1 Uniform（均匀）分布

**Uniform(a, b)** 表示在区间 [a, b] 上"处处等可能"的连续分布，密度在区间内为常数、区间外为 0：

    f(x) = 1/(b − a),   a ≤ x ≤ b   （其余为 0）
    E[X] = (a + b)/2,   Var(X) = (b − a)^2 / 12

没有任何位置比别处更受偏爱，密度是一条水平线；其高度 1/(b−a) 由"总面积=1"倒推而来。期望在正中间，方差随区间宽度平方增长（区间越宽越不确定）。

Uniform(0,1) 是所有随机模拟的"原材料"——通过逆变换采样（3.3.3）可把它变成任意分布。最小例子：Uniform(2,5) 的 E=3.5、Var=(3)²/12=0.75（本机实证一致）。易错点：连续 Uniform 的"落在子区间概率 = 子区间长度 / 总长度"，与离散均匀"每点等概率"是两回事，别把 f=1/(b−a) 当成"某点的概率"。scipy：`scipy.stats.uniform(loc=a, scale=b−a)`——注意第二参数是**区间长度**而非右端点 b。

### 3.4.2 Normal（正态/高斯）分布

**Normal(μ, σ²)** 是钟形对称分布，由均值 μ（中心位置）和方差 σ²（胖瘦）两参数决定：

    f(x) = 1/(σ·√(2π)) · exp( −(x − μ)^2 / (2σ^2) )

    E[X] = μ,   Var(X) = σ^2

μ 决定钟形峰的横向位置，σ 决定宽窄（σ 越大越矮胖）。标准正态是 μ=0、σ=1 的特例，记作 N(0,1)。任何正态都可通过**标准化** Z = (X−μ)/σ 变成标准正态，这是查表/计算的基础。

正态之所以无处不在，根子在**中心极限定理**（归 L2-03 大主题7）——大量独立小效应之和近似正态，所以身高、测量误差、样本均值都趋近正态。经验法则"68–95–99.7"：约 68% 的概率落在 μ±σ、95% 落在 μ±2σ、99.7% 落在 μ±3σ 内，是快速估计的利器。

易错点（scipy，高频）：`scipy.stats.norm(loc=μ, scale=σ)` 的 `scale` 是**标准差 σ，不是方差 σ²**。想要方差 4 的正态要传 `scale=2`。本机实证：`norm(1,2)` 给 mean=1、var=4，`norm.pdf(1,1,2)=0.19947114`，与 1/(2√(2π)) 吻合。正态密度无初等原函数，其 CDF（记作 Φ）只能数值计算或查表——这是初学者算 P(X≤x) 时必须借助 scipy `norm.cdf` 的原因。

### 3.4.3 Exponential（指数）分布

**Exponential(λ)** 描述"以恒定平均发生率 λ 随机发生的事件，相邻两次之间的等待时间"，支撑 x ≥ 0：

    f(x) = λ · e^{−λx},   x ≥ 0
    E[X] = 1/λ,   Var(X) = 1/λ^2

参数 λ 是"率"（单位时间发生几次），故等待时间均值是它的倒数 1/λ（率越高、等得越短）。

指数分布是几何分布（3.2.3）的**连续版**，同样具有唯一的**无记忆性**——已经等了 10 分钟没来，接下来还要等的时间分布和刚开始等时完全一样（"公交车不记得你已经等了多久"）。它与泊松分布是一体两面：若事件次数服从 Poisson(λ)，则事件**间隔时间**服从 Exponential(λ)。经典场景：设备寿命、客服呼入间隔、放射性衰变间隔。

易错点（scipy，头号陷阱）：`scipy.stats.expon(scale=1/λ)`——scipy 用的是 `scale = 1/λ`（均值），**不是率 λ**。要 λ=0.5 的指数分布，得传 `scale=2`。传错会让率与均值互为倒数地全盘颠倒。本机实证：`expon(scale=2)` 给 mean=2、var=4，且 `expon.pdf(0,scale=2)=0.5`（=λ），确认约定。

### 3.4.4 Gamma（伽马）分布

**Gamma(a, λ)**（形状参数 a>0、率 λ>0）描述"等到第 a 次泊松事件发生所需的总时间"，是指数分布的推广，支撑 x>0：

    f(x) = λ^a / Γ(a) · x^{a−1} · e^{−λx},   x > 0
    E[X] = a/λ,   Var(X) = a/λ^2

其中 Γ(a) 是伽马函数（阶乘对连续的推广，Γ(n)=(n−1)!）。

把 a 段独立的 Exponential(λ) 等待时间接起来，总时间就是 Gamma(a, λ)——所以 a=1 时伽马**退化为指数分布**。这正是指数之于伽马，如同几何之于负二项（离散侧）的对应关系，构成 3.5 关系网的一角。形状参数 a 控制曲线形态：a<1 时在 0 处发散、a=1 是指数、a 越大越接近钟形（趋于正态）。

易错点（scipy 参数约定）：`scipy.stats.gamma(a, scale=1/λ)`——第一参数是形状 a，第二用 **`scale = 1/λ`**（尺度，非率），与指数同一逻辑。本机实证：`gamma(a=3, scale=2)` 给 mean=6=a·scale、var=12=a·scale²，与 a/λ、a/λ² 在 λ=1/2 下一致。另注意 Gamma 有"率参数化"与"尺度参数化"两派，教材（率 λ）与 scipy（尺度 1/λ）分属两派，切勿混用。

### 3.4.5 Beta（贝塔）分布

**Beta(a, b)**（两个形状参数 a>0、b>0）是定义在 [0,1] 区间上的连续分布，天然适合描述"比例/概率"这类取值必在 0 到 1 之间的量：

    f(x) = x^{a−1} · (1 − x)^{b−1} / B(a, b),   0 < x < 1
    E[X] = a/(a + b),   Var(X) = a·b / ((a + b)^2 · (a + b + 1))

其中 B(a,b)=Γ(a)Γ(b)/Γ(a+b) 是贝塔函数，起归一化作用。

把 a 想成"成功次数+1"、b 想成"失败次数+1"，Beta 就像"对一个未知成功概率 p 的信念分布"。a=b=1 时退化为 Uniform(0,1)（无信息先验）；a、b 越大分布越集中在 a/(a+b) 附近（数据越多信念越确定）。这使 Beta 成为二项/伯努利参数的**共轭先验**（贝叶斯统计核心，归 L2-03 大主题9）——它与 Gamma 也有深刻联系（Beta-Gamma 关系归大主题5）。最小例子：Beta(2,3) 的 E=2/5=0.4、Var=6/(25×6)=0.04（本机实证一致）。

Beta 的支撑是**开区间 (0,1)**，别用它建模可能取到负值或大于 1 的量。scipy：`scipy.stats.beta(a, b)`，两个形状参数直接传，无额外 scale（除非要平移缩放到别的区间）。

- 锚点：Blitzstein & Hwang《Introduction to Probability》2nd ed. —— Uniform/Normal/Exponential 在 Ch5，Gamma/Beta 在 Ch8（含各分布 PDF、E、Var、故事化推导与相互联系）；Harvard Stat 110 Lecture 14–16（Uniform/Normal/Exponential）与 Lecture 23–25（Beta/Gamma），https://stat110.hsites.harvard.edu/ 。均核实 2026-07-26。
- 交叉锚（参数约定核对必用）：scipy.stats 文档 `uniform`/`norm`/`expon`/`gamma`/`beta` 页，scipy 1.17.1，核实 2026-07-26。均值/方差/PDF 数值经本机实证（见文末），逐位吻合。

## 3.5 泊松逼近与分布间关系

### 3.5.1 泊松逼近（二项 → 泊松）

**泊松逼近（Poisson approximation / law of rare events）**：当二项分布的试验数 n 很大、单次成功概率 p 很小、而乘积 λ = n·p 保持适中时，Binomial(n, p) 可用 Poisson(λ) 近似：

    Binomial(n, p) ≈ Poisson(λ),   其中 λ = n·p   （n 大、p 小、np 适中）

    lim_{n→∞, np→λ} C(n,k) p^k (1−p)^{n−k} = e^{−λ} λ^k / k!

直觉（也是泊松分布的"出生故事"）：想象一年里有 n=365 天，每天某人生日撞上你的概率 p 极小，但一屋子人里"撞生日"的总数均值适中——这类"海量机会、每次极罕见"的计数就收敛到泊松。这解释了为何 3.2.5 说泊松是"大量稀有事件的计数极限"。近似的好处是把带组合数、易溢出的二项 PMF，换成只含指数和阶乘的泊松 PMF，计算大为简化。

本机实证（n=1000, p=0.003, λ=3）：二项与泊松 PMF 高度吻合——k=0：0.049563 vs 0.049787；k=1：0.149137 vs 0.149361；k=3：0.224379 vs 0.224042；k=6：0.050333 vs 0.050409。误差在千分位量级，印证逼近。

逼近好坏取决于 p 是否够小。p 不小（如 0.3）时二项方差 np(1−p) 与泊松方差 λ=np 差距明显（前者被 (1−p) 压小），逼近就差。此时若 n 大且 p 适中，应改用正态逼近（下一项）。

### 3.5.2 分布间关系网

各分布并非孤立，而是通过"叠加、极限、取特例、共轭"互相连通。把这张网记住，选型和推导都事半功倍。核心关系（均在前文各项出现过，此处汇总）：

- **叠加/计数**：n 个独立 Bernoulli(p) 之和 = Binomial(n, p)；等第 1 次成功 = Geometric(p)，等第 r 次成功 = Negative Binomial(r, p)（几何是 r=1 的特例）。
- **连续等待**：Exponential(λ) 是几何的连续版；a 段独立 Exponential(λ) 之和 = Gamma(a, λ)（指数是 a=1 的特例）。
- **泊松枢纽**：事件计数 ~ Poisson(λt) ⟺ 事件间隔 ~ Exponential(λ)（一体两面）；Binomial 在 n 大 p 小时 → Poisson（3.5.1）。
- **正态逼近（CLT 的体现，详见大主题7）**：Binomial(n,p) 在 n 大时 → Normal(np, np(1−p))（棣莫弗-拉普拉斯定理）；Poisson(λ) 在 λ 大时 → Normal(λ, λ)；Gamma(a,λ) 在 a 大时 → 正态。
- **区间信念**：Uniform(0,1) = Beta(1,1)；Beta 是二项/伯努利参数的共轭先验（喂大主题9 贝叶斯估计）。

离散侧"抛硬币—数成功/等成功"一族（Bernoulli→Binomial→Geometric→Neg-Binomial）、"稀有计数"的泊松，连续侧"等待时间"一族（Exponential→Gamma）、"钟形极限"的正态、"比例先验"的 Beta——它们通过"求和变复杂、取极限变简单、取特例变基础"三种操作彼此转化。**很多分布是同一机制在不同参数/极限下的化身**，记住机制比死记二十条公式高效得多。承接提示：这张关系网直接喂 L5-02 建模——数据像"稀有计数"就上泊松/负二项，像"等待时间"就上指数/伽马，像"比例"就上 Beta，本节是分布选型的地图。
