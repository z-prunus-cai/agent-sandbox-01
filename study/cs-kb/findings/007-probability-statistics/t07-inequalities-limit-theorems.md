## 7.1 概率不等式

### 7.1.1 Markov 不等式

Markov 不等式是所有概率界里最基本、条件最弱的一条：只要随机变量 X **非负**，就能用它的期望给"X 很大"的概率套上界。对任意 a > 0，

P(X ≥ a) ≤ E(X) / a

直觉是一个"预算约束"：E(X) 是所有取值按概率加权的总"质量重心"，如果太多概率质量堆在很大的取值 a 以上，就会把重心 E(X) 抬得很高。反过来，既然重心只有 E(X) 这么大，落在 a 以上的质量就不可能超过 E(X)/a——否则光这部分对期望的贡献 a·P(X≥a) 就已经超过总期望 E(X) 了。这也是它的一行证明：E(X) ≥ E(X·I(X≥a)) ≥ a·P(X≥a)。

全班考试平均分 E(X)=60，那么"考到 90 分及以上"的人数比例至多 60/90 ≈ 66.7%。注意这个界通常**很松**——本机用 X~Exp(1)（E(X)=1）算 P(X≥3)，Markov 给上界 1/3≈0.333，而真实概率只有 e⁻³≈0.0498（见本小主题末实证）。松是有代价换来的：Markov 只用到"非负 + 期望"这一丁点信息，不知道分布形状，所以只能给保守的保证。

三个易错点。其一，**非负是硬条件**：若 X 可正可负，直接套 Markov 会出错，通常要先取绝对值或平方（这正是 Chebyshev 的做法）。其二，界只在 a > E(X) 时才有用（否则右边 ≥ 1，成了废话）。其三，它是**单边**的、只管上尾。Markov 的真正价值不在于算得准，而在于它是推导 Chebyshev、Chernoff 界、乃至弱大数定律的"母不等式"。

### 7.1.2 Chebyshev 不等式

Chebyshev 不等式在 Markov 之上多用了一个信息——**方差**——从而能双边地控制"X 偏离其均值 μ 有多远"。设 X 的均值为 μ、方差为 σ²，则对任意 a > 0，

P(|X − μ| ≥ a) ≤ σ² / a²

把偏离量以标准差为单位（令 a = kσ）写出来更直观：

P(|X − μ| ≥ kσ) ≤ 1 / k²

即"距离均值超过 k 个标准差"的概率至多 1/k²：超过 2 个标准差至多 25%，超过 3 个至多 11.1%。它的推导就是把 Markov 用在非负随机变量 (X−μ)² 上、取阈值 a²——因为 E[(X−μ)²] 恰好就是方差 σ²，所以 P((X−μ)² ≥ a²) ≤ σ²/a²。

**方差越小，概率质量就越挤在均值附近**，"跑很远"就越不可能。这条不等式的分量在于它对**任意**具有有限方差的分布都成立，不需要知道分布形状——正因如此，它是证明弱大数定律的关键工具（把 X 换成样本均值 X̄ₙ，其方差随 n 变小，右边就趋于 0）。

Chebyshev 同样通常很松（本机 X~Exp(1) 算 P(|X−1|≥3)，界 1/9≈0.111 而真值仅 0.0183）。松不代表错——它是"对最坏分布也成立"的保证。想要更紧的界需要更多假设（如已知分布正态，或用 Chernoff/MGF 界拿到指数级衰减）。还要注意 k ≤ 1 时 1/k² ≥ 1，界退化为废话。

### 7.1.3 Jensen 不等式

Jensen 不等式刻画"函数变换"与"取期望"两个操作的先后次序会差多少，前提是函数**凸/凹**。若 g 是凸函数（convex，开口朝上、如 x²、eˣ、−log x），则

g(E(X)) ≤ E(g(X))

若 g 是凹函数（concave，开口朝下、如 log x、√x），不等号反向：

g(E(X)) ≥ E(g(X))

直觉是"凸函数的弦在函数图像上方"：把 X 的取值先各自送进凸函数 g、再取平均（右边），会比先把 X 平均成一个点 E(X)、再送进 g（左边）要大，因为凸函数把"分散"放大成了"额外的高度"。一个立刻能用的推论：取 g(x)=x²，得 E(X²) ≥ (E(X))²，两边之差正是方差 Var(X)=E(X²)−(E(X))² ≥ 0——这解释了方差为什么恒非负。本机用 X~Exp(1) 核对，E(X²)≈1.998、(E(X))²≈1.000，凸向不等式成立。

最小例子（凹函数）：g(x)=√x。手里有两个等概率的钱数 1 和 100，平均财富 E(X)=50.5，其平方根 √50.5≈7.1；而"平方根的平均" E(√X)=(√1+√100)/2=5.5。可见 √E(X) ≥ E(√X)——这正是"效用递减"下人们为何厌恶风险的数学根源。

**方向极易记反**。记牢"凸↑（convex）时 g(E)≤E(g)"这一个锚，凹的翻过来即可（因为 g 凹 ⇔ −g 凸）。等号仅在 g 是直线、或 X 退化为常数时成立。Jensen 是信息论（如 log 的凹性给出熵/KL 散度不等式）、ML 里 EM 算法与变分下界的基石。

### 7.1.4 Cauchy-Schwarz 不等式

Cauchy-Schwarz 不等式在概率语境下限制"两个随机变量的乘积期望"能有多大。对任意随机变量 X、Y（各自二阶矩有限），

|E(XY)| ≤ √( E(X²) · E(Y²) )

把它用到中心化变量 X−μ_X、Y−μ_Y 上，就得到协方差与相关系数的核心界——相关系数的绝对值不可能超过 1：

|Corr(X, Y)| ≤ 1

直觉是"用期望定义内积"：令 ⟨X,Y⟩ := E(XY)，则 Cauchy-Schwarz 就是熟悉的"两向量点积的绝对值 ≤ 两者长度之积"，几何上说两个"向量"的夹角余弦落在 [−1,1] 内——这个余弦正是相关系数 Corr(X,Y)。所以相关系数天然被夹在 −1 与 1 之间，且取到 ±1 当且仅当 Y 是 X 的线性函数（完全线性相关）。

最小例子/关联：这条不等式是"相关系数是标准化协方差、量纲无关、落在 [−1,1]"（大主题5 协方差与相关）的证明依据；它也保证了协方差矩阵半正定（接 L1-03 正定性）。易错点：Cauchy-Schwarz 只管**线性**关联的强弱，|Corr|=1 意味着完全线性相关，但 Corr=0（不相关）**不等于**独立——不相关只说线性成分为零，仍可能有强的非线性依赖（大主题5 重点易错点）。

## 7.2 大数定律

### 7.2.1 收敛模式：依概率收敛 vs 几乎必然收敛

要讲清弱、强两个大数定律的差别，必须先分清随机变量序列"收敛"的两种含义——这是初学者最容易糊成一团的地方。设 X̄ₙ 是前 n 个观测的样本均值，μ 是真实期望。

**依概率收敛（convergence in probability）**：对任意小的 ε>0，"X̄ₙ 偏离 μ 超过 ε"这件事的概率随 n 增大趋于 0，

lim_{n→∞} P( |X̄ₙ − μ| ≥ ε ) = 0

**几乎必然收敛（almost sure convergence，即以概率 1 收敛）**：把整条无穷序列 X̄₁, X̄₂, … 看成一条随机轨迹，则"这条轨迹最终收敛到 μ"这件事本身发生的概率是 1，

P( lim_{n→∞} X̄ₙ = μ ) = 1

两者的差别在于"极限"和"概率"谁套谁。依概率收敛是**逐个 n** 看一张快照：每个固定的大 n，偏离都很可能很小，但不排除轨迹在无穷远处仍偶尔反复蹦出大偏差（只要这种蹦出越来越稀）。几乎必然收敛是看**整条轨迹的命运**：几乎每一条轨迹从某一点之后就永远待在 μ 附近、不再大幅折返。几乎必然收敛更强，它**蕴含**依概率收敛，反之不然。这个层级差别正是"强"与"弱"两个大数定律的唯一区别所在。

### 7.2.2 弱大数定律（WLLN）

弱大数定律说：独立同分布（i.i.d.）、期望 μ 有限的随机变量，其样本均值**依概率收敛**到 μ。记 X̄ₙ = (X₁+…+Xₙ)/n，则对任意 ε>0，

P( |X̄ₙ − μ| ≥ ε ) → 0，当 n → ∞

当各 Xᵢ 还具有有限方差 σ² 时，它有一个极短的证明，直接用 Chebyshev：样本均值的方差是 Var(X̄ₙ)=σ²/n（独立时方差可加、除以 n²），于是

P( |X̄ₙ − μ| ≥ ε ) ≤ Var(X̄ₙ)/ε² = σ²/(n ε²) → 0

这一行把 7.1 的 Chebyshev 与本节直接焊在了一起：**方差以 1/n 速率被"平均掉"，偏离概率随之被压到 0**。（一般 WLLN 只需 μ 有限、不需要有限方差，但那需要特征函数等更细的工具，入门层用有限方差版即可建立直觉。）

抛硬币，Xᵢ=1 表正面（μ=0.5）。抛得越多，正面频率越可能贴近 0.5——这就是"用频率估概率"的合法性来源。本机掷公平骰子（μ=3.5）看样本均值随 n 增长：n=100 时 3.66、n=1000 时 3.511、n=10⁵ 时 3.504、n=2×10⁵ 时 3.503，逐步稳向 3.5（见本小主题末实证）。

头号易错点——**赌徒谬误**：大数定律**不**保证"落后的一方会被追回来补偿"。前面连出 10 个正面，并不会让后面的反面概率变高；LLN 靠的是"后续海量新样本把早期偏差稀释（占比趋 0）"，而不是"用反向结果去抵消"。μ 是被慢慢逼近的，不是被"清算"的。

### 7.2.3 强大数定律（SLLN）

强大数定律把结论升级到几乎必然收敛：i.i.d.、期望 μ 有限（E|X|<∞）时，样本均值**以概率 1** 收敛到 μ，

P( lim_{n→∞} X̄ₙ = μ ) = 1

它比弱定律强在哪？弱定律只保证"对每个足够大的 n，此刻偏差大概率很小"；强定律保证"几乎每一条无穷长的实验轨迹，走到后面就永远收敛到 μ、不再回头大幅偏离"。换句话说，弱定律管"某一时刻的横截面概率"，强定律管"整条时间轨迹的最终命运"。因为几乎必然收敛蕴含依概率收敛，**SLLN 成立就自动有 WLLN**，反过来不一定。

为什么还要保留弱定律？因为存在"弱定律成立但强定律失效"的分布（教材中给出反例场景），且弱定律的证明门槛低（Chebyshev 一行）、条件更容易验证。对入门读者，实用差别其实很小：两者都在说"样本量越大、样本均值越可信"。要记住的分工是——**WLLN/SLLN 只回答"收敛到 μ"这个定性问题，完全不描述收敛过程中的波动形状**；那是下一节 CLT 的活。

LLN 的前提是**期望有限**。柯西分布（重尾、期望不存在）的样本均值**不**收敛，反而仍服从柯西分布——加再多样本也不会稳定。所以"平均一下就会稳"并非无条件成立，重尾数据要格外小心。

## 7.3 中心极限定理

### 7.3.1 CLT 的陈述

中心极限定理（CLT）是本大主题的皇冠，也是 round3a 标 ⭐ 的原因。它说：**大量 i.i.d. 随机变量的和（或均值），经标准化后，无论原始分布长什么样，都趋于标准正态分布**。设 X₁,…,Xₙ 独立同分布、均值 μ、方差 σ²（0<σ²<∞ 有限且非零），则当 n→∞，标准化样本均值依分布收敛到 N(0,1)：

( X̄ₙ − μ ) / ( σ / √n )  →ᵈ  N(0, 1)

等价地写成"和"的形式（Sₙ=X₁+…+Xₙ）：

( Sₙ − nμ ) / ( σ√n )  →ᵈ  N(0, 1)

也常记作 √n(X̄ₙ − μ) →ᵈ N(0, σ²)。这里 →ᵈ 是"依分布收敛"（CDF 逐点收敛到正态 CDF），比前面两种收敛都弱——它只关心分布形状趋同，不要求数值本身靠拢。

直觉分三点。其一，**σ/√n 是关键刻度**：它叫标准误（standard error, SE），刻画样本均值的典型波动幅度，以 1/√n 收缩——这解释了 LLN 里"均值为何收敛"（波动趋 0），也量化了"要把误差减半得把样本量翻 4 倍"。其二，**正态是普适吸引子**：把很多个独立小随机因素叠加，各自的偏态、离散细节会互相"洗掉"，只剩钟形——这就是为什么现实中身高、测量误差等叠加型量近似正态。其三，CLT 是 LLN 的"放大镜"：LLN 说 X̄ₙ→μ（点收敛），CLT 把 X̄ₙ−μ 放大 √n 倍后看清残余涨落的形状（正态）。

### 7.3.2 正态逼近与应用（蒙特卡洛 / A/B 测试）

CLT 的实用价值在于：即便不知道原始分布，只要 n 够大，就能用正态来**近似**样本均值（或样本和）的分布，从而算概率、给误差棒、定样本量。样本均值的近似写法是

X̄ₙ  ≈  N( μ, σ²/n )

这把 7.2 的定性收敛升级成了可算的定量工具，直接支撑三件事。一是**蒙特卡洛估计**：用随机样本的平均去估某个期望/积分 μ，CLT 保证误差 ≈ σ/√n 且近似正态，于是能给出"估计值 ± 1.96·σ/√n"的 95% 置信区间（正态双侧 95% 对应 ±1.96 个标准误）。二是**A/B 测试样本量**：要检出两组转化率的差异，需要 SE 小到让差异"跳出噪声"，由 σ/√n 反解出所需 n——样本量公式的 √n 正是从 CLT 来的。三是**置信区间/假设检验**（大主题9、10 的地基）：z 检验、t 检验的"统计量近似正态"这一前提，本质就是 CLT。

本机实证最能让人信服 CLT 的"抹平"威力：取右偏得厉害的 Exp(1)（偏度=2），看标准化样本均值 z 的分布随 n 变化（每档 40 万次重复，@2026-07-26）——

n=1： 偏度 +1.995，KS 距正态 0.159（还是原始的偏态指数分布）
n=2： 偏度 +1.417，KS 0.094
n=5： 偏度 +0.904，KS 0.060
n=30：偏度 +0.368，KS 0.024（已很接近 N(0,1)）

偏度与"离正态的距离"随 n 单调下降，钟形逐渐浮现。再直接验证正态逼近的可用性：n=30 时，样本均值落入 μ±1.96·SE 的经验频率为 **0.9519**，与 CLT 预测的 0.95 几乎相等——这正是置信区间"95%"这个数字的来源。

### 7.3.3 易错点与边界

第一，**CLT 描述的是"均值/和"的分布，不是原始数据的分布**。样本量再大，也不会让每个 Xᵢ 本身变正态；变正态的是把它们平均/求和之后的那个统计量。初学者常误以为"数据多了原始直方图就会变钟形"，错。

第二，**别混淆 LLN 与 CLT**。LLN：X̄ₙ 收敛到一个**常数** μ（波动消失）。CLT：X̄ₙ−μ 放大 √n 倍后收敛到一个**分布** N(0,σ²)（波动的形状）。一个讲"去哪"，一个讲"怎么抖"。

第三，**"n≥30 就能用正态"只是经验法则，不是定理**。收敛速度取决于原始分布的偏态/尾部：越对称、尾越轻，收敛越快（对称分布可能 n=10 就够）；越偏、尾越重，需要的 n 越大（上面 Exp(1) 到 n=30 仍有残余偏度 0.37）。Berry–Esseen 定理给出了收敛速率 ~ 1/√n 的严格上界，但入门层记住"看分布形状定 n、别盲信 30"即可。

第四，**有限且非零方差是硬前提**。无限方差的重尾分布（如某些幂律、柯西分布）不服从经典 CLT——柯西连期望都没有，其样本均值恒为柯西、根本不趋正态。金融/网络等重尾场景滥用 CLT 会严重低估极端风险。

第五，**独立性/同分布可放宽但不能没有**。存在处理弱相关或非同分布情形的推广版 CLT（如 Lindeberg 条件），但强相关（如带趋势的时间序列）下经典 CLT 直接失效。对离散量（如二项计数）用正态逼近时，还常做**连续性校正**（把整数 k 的概率对应到区间 [k−0.5, k+0.5]）以提高精度。
