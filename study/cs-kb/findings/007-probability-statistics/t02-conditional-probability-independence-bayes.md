**"知道了 B 发生"如何改写我们对 A 的信念**。大主题1 讲的是"无条件"世界里的概率；本大主题引入"条件"这把钥匙——先有条件概率的定义，随后所有工具（乘法法则、全概率、贝叶斯）都只是它的移项、求和与翻转。抓住一个核心动作：**条件化（conditioning）就是把样本空间缩小到"已知发生的那部分"，再在里面按比例重新分配概率**。贝叶斯定理是本章的心脏，因为它是朴素贝叶斯分类器、贝叶斯网络乃至一切"从数据反推参数"的地基（喂 L5-02）。

## 2.1 条件概率

### 2.1.1 条件概率的定义与直觉

条件概率刻画"在已知事件 B 发生的前提下，事件 A 发生的概率"，记作 P(A|B)（读作"在 B 条件下 A 的概率"）。只要 P(B) > 0，它的定义是

P(A|B) = P(A ∩ B) / P(B)

其中 A ∩ B 表示"A 与 B 同时发生"。

直觉是"缩小样本空间"。原本我们在整个样本空间 S 里衡量概率；一旦得知 B 发生了，B 之外的一切结局都被排除，B 就成了新的"整个世界"。于是 A 在这个新世界里的概率，就是"A 和 B 的重叠部分"占"B 整体"的比例——这正是分子 P(A ∩ B)、分母 P(B) 的含义。除以 P(B) 是为了把概率重新归一化，让新世界里所有可能结局的概率之和仍等于 1。

掷一枚公平骰子，A = "点数是 2"，B = "点数是偶数"。无条件时 P(A) = 1/6。已知 B（偶数）发生后，可能结局只剩 {2, 4, 6} 三个，A 在其中占 1 个，所以

P(A|B) = P(A ∩ B) / P(B) = (1/6) / (3/6) = 1/3

比 1/6 大——因为"是偶数"这条信息排除了三个奇数，让"是 2"变得更可能。

几个初学者最常踩的坑。第一，P(A|B) 与 P(B|A) **一般不相等**，方向不能颠倒（"下雨时带伞的概率"远不等于"带伞时下雨的概率"）；这个方向混淆正是 2.3 假阳性悖论的病根。第二，P(A|B) 与 P(A) 也没有固定大小关系，条件化可能让概率变大、变小或不变。第三，条件概率本身仍是一个合法的概率：固定 B 后，P(·|B) 作为 A 的函数满足大主题1 的全部概率公理（非负、P(S|B)=1、可加），因此前一章推出的所有性质（如 P(Aᶜ|B) = 1 − P(A|B)）在条件世界里照样成立。这一点是 Blitzstein 反复强调的"条件概率就是概率"（conditional probability is probability）。

## 2.2 乘法法则与全概率

### 2.2.1 乘法法则（链式法则）

把条件概率的定义两边乘以 P(B)，立刻得到乘法法则（multiplication rule），用来计算"两件事同时发生"的概率：

P(A ∩ B) = P(B) · P(A|B) = P(A) · P(B|A)

推广到多个事件，就是链式法则（chain rule）：

P(A₁ ∩ A₂ ∩ ⋯ ∩ Aₙ) = P(A₁) · P(A₂|A₁) · P(A₃|A₁∩A₂) ⋯ P(Aₙ|A₁∩⋯∩Aₙ₋₁)

核心思想是"分步走"：与其一口气算出所有事件同时发生的概率，不如按时间/逻辑顺序一步步条件化——先算第一步的概率，再算"给定第一步后第二步"的概率，依次相乘。

从一副 52 张牌里**不放回**地连抽两张，都是红桃的概率。第一张红桃概率 13/52；已知第一张是红桃后，牌堆剩 51 张、红桃剩 12 张，第二张红桃的条件概率是 12/51。于是

P(两张都红桃) = (13/52) · (12/51) = 1/17

乘法法则里第二个因子必须是**条件**概率 P(A₂|A₁)，不是无条件的 P(A₂)。只有当两事件独立时才能换成 P(A₂)（见 2.4）——不放回抽牌正是"不独立"的典型，第一次抽取改变了牌堆构成。链式法则的因子顺序可以任意重排（只要条件项相应调整），实践中选"最容易算条件概率"的那个顺序。

### 2.2.2 全概率公式

当直接算 P(A) 很难、但"在若干互斥情形下算 P(A)"很容易时，用全概率公式（law of total probability, LOTP）。设 B₁, B₂, …, Bₙ 是样本空间的一个**划分**（两两互斥、并起来是整个 S，且每个 P(Bᵢ) > 0），则

P(A) = P(A|B₁)P(B₁) + P(A|B₂)P(B₂) + ⋯ + P(A|Bₙ)P(Bₙ)

直觉是"分而治之再加权求和"：把复杂事件 A 拆到几个互不重叠的场景 Bᵢ 里分别考察，每个场景下 A 的条件概率 P(A|Bᵢ) 通常好算，再按各场景自身发生的概率 P(Bᵢ) 加权平均。因为 B₁,…,Bₙ 铺满了整个世界且不重叠，A 的每一份概率都被恰好数一次，不重不漏。

两个盒子，盒 1 有 2 红 3 蓝，盒 2 有 4 红 1 蓝；先等概率随机选一个盒子（各 1/2），再从中随机取一球。取到红球的概率

P(红) = P(红|盒1)P(盒1) + P(红|盒2)P(盒2) = (2/5)(1/2) + (4/5)(1/2) = 3/5

B₁,…,Bₙ 必须是真正的划分——既要"互斥"（否则重复计数），又要"穷尽"（否则漏掉某些结局，概率加不满）。最常用的最小划分是 {B, Bᶜ}，此时

P(A) = P(A|B)P(B) + P(A|Bᶜ)P(Bᶜ)

这个二分版本是下一节贝叶斯定理分母的标准写法。

### 2.2.3 树状分解

树状图（probability tree）是把链式法则与全概率公式"画出来"的可视化工具。从一个根节点出发，每一层代表一个随机步骤，从节点长出的每条分支标上该步骤各结局的**条件概率**（给定已走过的路径），到达某个叶子的路径概率 = 沿途各分支概率相乘（这就是链式法则）；若多条路径都通向同一个目标事件 A，把这些叶子概率相加就得到 P(A)（这就是全概率公式）。

树把"先发生什么、再发生什么"的顺序显式摆开，每一层分支的概率之和都必须为 1，避免漏算或重算。用 2.2.2 的盒子例子画树：第一层两条分支"盒1(1/2)/盒2(1/2)"，第二层每个盒子再分"红/蓝"。"红"这个结局对应两个叶子：盒1→红（1/2 × 2/5）和盒2→红（1/2 × 4/5），相加即 3/5，与全概率公式完全一致。

树状分解是初学者从"背公式"过渡到"看懂结构"的桥梁，也是 2.3 贝叶斯推断"沿树反向走"的直观基础——正向沿树走是全概率（由因求果），反向由某个观测到的叶子回推它来自哪条分支，就是贝叶斯。易错点是每条分支上写的必须是**条件**概率而非联合概率，只有把整条路径乘起来才是联合概率。

## 2.3 贝叶斯定理

### 2.3.1 贝叶斯公式

贝叶斯定理（Bayes' theorem）把条件概率的方向"翻转"过来：已知 P(B|A)，反求 P(A|B)。它直接由乘法法则的两种写法 P(A∩B)=P(A|B)P(B)=P(B|A)P(A) 相等推出：

P(A|B) = P(B|A) · P(A) / P(B)

分母 P(B) 通常用全概率公式展开（这是最常见、最实用的完整形式）：

P(A|B) = P(B|A)P(A) / [ P(B|A)P(A) + P(B|Aᶜ)P(Aᶜ) ]

核心作用是"因果反演"：现实中我们往往容易知道"给定原因，结果出现的概率"P(B|A)（比如"有病时检测呈阳性的概率"），而真正想知道的却是"给定观测到的结果，某个原因成立的概率"P(A|B)（"检测阳性时真有病的概率"）。贝叶斯定理正是连接这两个方向的桥梁。

初学者要抓住"三个已知拼出一个未知"：想求 P(A|B)，需要①反方向的 P(B|A)、②A 的基准概率 P(A)、③归一化用的 P(B)。缺了任何一个都算不出来——尤其②（基准率/先验）最容易被忽略，忽略它就直接掉进下一节的假阳性悖论。

### 2.3.2 先验、后验与推断方向

贝叶斯公式里的每一项都有专门名字，理解它们才算真正读懂这条定理。把 A 看作"某个假设/原因"，B 看作"观测到的证据/数据"：

P(A) 称为**先验概率**（prior）——看到证据之前，对假设 A 成立的信念；
P(A|B) 称为**后验概率**（posterior）——看到证据 B 之后，更新后的信念；
P(B|A) 称为**似然**（likelihood）——假设 A 为真时，出现这份证据的可能性；
P(B) 称为证据的**边缘概率**或归一化常数。

于是贝叶斯定理可读成一句话：

后验 ∝ 似然 × 先验

即"更新后的信念 正比于 数据对假设的支持度 乘以 原有信念"。分母 P(B) 不依赖具体假设，只起把所有后验概率归一化到总和为 1 的作用。

这就是贝叶斯推断的心智模型：**从先验出发，用数据（似然）去更新，得到后验**。它是朴素贝叶斯分类器、贝叶斯网络、乃至一切"从观测反推隐藏参数"方法的共同地基（直喂 L5-02）。

最关键的初学者难点仍是**方向**：P(A|B) 与 P(B|A) 是两个不同的量，二者靠先验 P(A) 与 P(B) 之比换算。一个生动的说法（Blitzstein 的"检察官谬误"）：把"无辜时出现这份证据的概率很小"直接当成"出现这份证据时无辜的概率很小"，就是把似然错当后验，忽略了先验（无辜的基准率通常很高）。方向一颠倒，结论可能天差地别，下一节用数字把这一点砸实。

### 2.3.3 假阳性悖论（基础率谬误）

假阳性悖论（false positive paradox）指：对于一种**罕见**的病，即便检测很"准"，一次阳性结果对应"真有病"的概率也可能低得惊人。这不是检测有 bug，而是贝叶斯定理 + 低基础率共同作用的必然结果，故又叫基础率谬误（base rate fallacy）。

取 Blitzstein Ch2 的经典设定：人群患病率 P(D) = 1%，检测灵敏度 P(+|D) = 95%（有病时 95% 报阳），特异度 P(−|Dᶜ) = 95%（无病时 95% 报阴，即假阳性率 5%）。求"阳性时真有病"的后验概率：

P(D|+) = P(+|D)P(D) / [ P(+|D)P(D) + P(+|Dᶜ)P(Dᶜ) ]

代入：

P(D|+) = (0.95 × 0.01) / (0.95 × 0.01 + 0.05 × 0.99) ≈ 0.161

也就是说，检测"95% 准"，但阳性者真有病的概率只有约 16%。

无病的人占了 99%，哪怕他们只有 5% 被误报阳性，绝对数量（0.05 × 0.99 = 0.0495）也远超真病人里报阳的那点（0.95 × 0.01 = 0.0095）。阳性池子里，假阳性淹没了真阳性。**罕见（低先验）是元凶**：病越罕见，同样准确度下后验越低。这正是 2.3.2"别忘先验"的量化版——只盯着"95% 准"（似然/准确度）而无视 1% 的基础率（先验），就会把 16% 误当成 95%。

本机数值验证（scratchpad 脚本，环境 Py3.11.15 np2.4.6 scipy1.17.1 @2026-07-26）：解析式与 1000 万次蒙特卡洛模拟一致——

    Bayes analytic P(D|+): 0.161
    Bayes MonteCarlo P(D|+): 0.1613

不同教材/百科选用的患病率与假阳性率不同，得到的具体后验也不同（如 Wikipedia base-rate-fallacy 词条用患病率 2%、灵敏度 100%、假阳性率 5%，算得约 29%）。数字随参数变，但结论方向一致：低基础率下阳性后验被大幅拉低。核对时务必对齐三项参数再比数值。

## 2.4 独立性

### 2.4.1 独立性

两个事件 A、B 独立（independent），指"其中一个发生与否，不改变另一个的概率"。形式定义是乘积形式：

P(A ∩ B) = P(A) · P(B)

当 P(B) > 0 时，它等价于更直观的条件形式：

P(A|B) = P(A)

即"知道 B 发生"对 A 的信念毫无影响。乘积定义比条件定义更常用作**定义**，因为它不要求 P(B) > 0，而且对称（A 独立于 B 自动意味着 B 独立于 A）。

连掷两次公平硬币，A = "第一次正面"，B = "第二次正面"。P(A) = P(B) = 1/2，而 P(A∩B) = 1/4 = (1/2)(1/2)，故独立——第一次的结果确实不影响第二次。

初学者最容易混淆的两组概念。其一，**独立 ≠ 互斥**。互斥（disjoint，A∩B=∅）是"两者不能同时发生"，此时若二者概率都非零，P(A∩B)=0 ≠ P(A)P(B)，反而是**强烈相关**（知道 A 发生，就断定 B 一定没发生）。互斥是"你死我活"，独立是"互不相干"，方向相反，别当同义词。其二，独立是关于**概率**的性质，不能只看事件的语义"感觉相不相关"，必须回到 P(A∩B)=P(A)P(B) 去验证。三个及以上事件的"相互独立"要求更强：不仅两两独立，还要求任意子集都满足乘积式——两两独立**推不出**相互独立（存在经典反例）。

### 2.4.2 条件独立

条件独立（conditional independence）指：在**给定第三个事件 C** 的前提下，A 与 B 独立：

P(A ∩ B | C) = P(A|C) · P(B|C)

它是朴素贝叶斯分类器和贝叶斯网络的核心假设，务必和"无条件独立"分清。

**条件独立与无条件独立互不蕴含**——两个方向都不成立。

一个"条件独立但不无条件独立"的例子：设 C = "今天下雨"。A = "小明带伞"，B = "小红带伞"。不下雨也不下雨的日子里，两人是否带伞可能因天气而**正相关**（阴天两人都更可能带），故无条件下 A、B 不独立；但一旦**固定了天气 C**（比如已知今天下雨），两人各自独立决定带不带伞，A、B 就条件独立了。天气 C 是制造二者相关的"共同原因"，条件化在它上面就"解释掉"了这层相关。

一个反方向的例子（无条件独立但条件不独立）：两枚公平硬币各掷一次，A、B 分别是两枚是否正面，二者无条件独立；令 C = "两次结果相同"。给定 C 后，知道了 A 的结果就能推断 B（因为要相同），于是在 C 条件下 A、B 反而不独立了。**结论：独立性会随"是否条件化、条件在谁身上"而出现或消失**，这也是理解下一节辛普森悖论的钥匙。

### 2.4.3 辛普森悖论

辛普森悖论（Simpson's paradox）指：某种关联（趋势）在**每一个分组内**都成立，但把各组数据**合并**后趋势却**反转**。它和条件独立同源——都是"条件化/不条件化会改变关系"的体现，根源在于潜藏的混杂变量（confounder）。

经典数值例（肾结石治疗，Charig 1986，Wikipedia 收录）：疗法 A（开放手术）vs 疗法 B（微创），按结石大小分组的成功率——

    小结石： A 81/87  ≈ 0.931   B 234/270 ≈ 0.867   → A 更好
    大结石： A 192/263 ≈ 0.730   B 55/80   ≈ 0.688   → A 更好
    合计：   A 273/350 ≈ 0.780   B 289/350 ≈ 0.826   → B 更好

在小结石和大结石**两个子组里 A 都优于 B**，可一旦合并，反而 B 的总成功率更高。

混杂变量是"结石大小"。大结石本身更难治（成功率天然低），而医生倾向于把难治的大结石分给疗法 A、把好治的小结石分给疗法 B。于是 A 的合计成绩被大量"高难度病例"拖累，B 的合计成绩被大量"低难度病例"抬高——合计数字混入了"病例难度"这个与疗法相关的因素，不再公平反映疗法本身的效果。

初学者要带走的两点。第一，这不是算错，两组结论和合计结论都对，只是回答的是不同问题：想比"疗法本身"，就该**在同难度分组内**比较（条件化在混杂变量上），而非看被混杂污染的合计。第二，它是"辨识因果"的第一个警钟——**合计（边缘）关联可能与分组（条件）关联方向相反**，选择在哪个变量上条件化会左右结论。另一著名实例是 UC Berkeley 1973 研究生录取（合计看男生录取率高于女生，但按院系分解后女生在多数院系录取率持平或更高，混杂变量是"女生更多申请了竞争激烈、录取率低的院系"）。

本机数值验证（scratchpad 脚本，环境同上）：三行成功率与"A 在两子组均优、合计反劣"的判定均为真——

    A small rate: 0.931  B small rate: 0.867
    A large rate: 0.73   B large rate: 0.688
    A overall: 0.78      B overall: 0.826
    A better in BOTH subgroups but worse overall: True
