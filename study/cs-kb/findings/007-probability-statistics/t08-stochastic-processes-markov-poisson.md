## 8.1 马尔可夫链

### 8.1.1 随机过程与马尔可夫性

马尔可夫链（Markov chain）是一列取值于有限或可数**状态空间**的随机变量 X_0, X_1, X_2, …，满足**马尔可夫性质**（Markov property）：给定当前状态，未来与过去条件独立。用条件概率写出来就是

P(X_{n+1} = j | X_n = i, X_{n−1} = i_{n−1}, …, X_0 = i_0) = P(X_{n+1} = j | X_n = i)

也就是说，要预测下一步 X_{n+1}，只需要知道当前 X_n，之前怎么走到这里的历史全部无关。本章默认链是**时齐的**（time-homogeneous）：上式右边不依赖 n，永远等于同一个数，记作 q_{ij}。

一句话心智模型：马尔可夫性 = "无记忆"或"未来只看现在这一步"。这不是说系统没有依赖历史的现象，而是说——只要你把"当前状态"定义得足够充分，历史信息就都被压缩进了当前状态里，多余的历史不再提供新信息。

最小例子：天气链。状态 {晴, 雨}，规则是"今天晴，明天 90% 还晴、10% 转雨；今天雨，明天 50% 转晴、50% 还雨"。要预测明天，只看今天是晴还是雨就够了，前天、大前天怎样都不影响——这就是马尔可夫性。

易错点一：马尔可夫性是一个**假设/建模选择**，不是所有过程都满足。真实天气显然依赖更多历史，"马氏链天气模型"只是一个简化。判断一个过程能不能建成马氏链，关键看"当前状态是否足以概括决定未来的全部信息"；若不够，常见补救是**扩充状态**（例如把状态定义成"最近两天的天气对"），让扩充后的过程重新具备马氏性。

易错点二：不要把"马尔可夫性（未来⊥过去 | 现在）"误当成"X_{n+1} 与 X_{n−1} 无关"。它们通常是**相关**的（今天影响明天、明天影响后天，所以今天与后天相关）；马氏性说的是"一旦知道了中间的今天，昨天就不再给后天提供额外信息"——这是**条件**独立，不是无条件独立，正好呼应大主题2 里条件独立的区分。

### 8.1.2 转移矩阵

把所有一步转移概率 q_{ij} = P(X_{n+1} = j | X_n = i) 排成一张方阵 Q（很多教材记作 P），就是**转移矩阵**（transition matrix）：第 i 行第 j 列是"从状态 i 一步走到状态 j 的概率"。它是一个**随机矩阵**（stochastic matrix）：每个元素非负，且**每一行加起来等于 1**（因为从 i 出发，下一步必然落到某个状态）。

天气链的转移矩阵（行/列顺序 = 晴, 雨）为

Q = [[0.9, 0.1], [0.5, 0.5]]

直觉：转移矩阵就是把"游戏规则"一次性装进一个表格。第 i 行是"站在状态 i 时，下一步去各处的概率分布"。因为下一步一定要去某处，所以这一行必须归一化为 1——**行和为 1** 是随机矩阵的定义性特征，也是最常用来自查矩阵有没有写错的方法。

分布的演化用**行向量**表示。若 t_n 是第 n 步的状态分布（写成行向量，t_n[j] = P(X_n = j)），则下一步分布是

t_{n+1} = t_n · Q

这里用"行向量右乘矩阵"，是因为 (t_n Q)[j] = Σ_i t_n[i] q_{ij}，正是全概率公式："到达 j 的概率 = 从各个 i 出发的概率 × 从 i 转到 j 的概率，再求和"。

易错点：**行/列约定**。Blitzstein、Wasserman 与多数概率教材用"行随机矩阵 + 行向量左乘"（q_{ij} 是 i→j，行和为 1，分布 t 右乘 Q）；而线代/数值线性代数里 PageRank 常用"列随机矩阵 + 列向量"（列和为 1，分布右侧列向量，矩阵左乘）。两者互为转置，结论等价，但抄公式前**务必确认手头矩阵是行随机还是列随机**，否则会把 i→j 和 j→i 搞反。本报告统一采用 Blitzstein 的行随机约定。

### 8.1.3 n 步转移与 Chapman–Kolmogorov 方程

"从 i 出发，恰好 n 步后到 j"的概率记作 q_{ij}^{(n)} = P(X_n = j | X_0 = i)，它恰好是**转移矩阵的 n 次幂** Q^n 的第 (i, j) 元：

P(X_n = j | X_0 = i) = (Q^n)_{ij}

更一般地，把 n 步拆成 m 步 + (n−m) 步，对中间状态求和，就得到 **Chapman–Kolmogorov 方程**：

q_{ij}^{(m+n)} = Σ_k q_{ik}^{(m)} · q_{kj}^{(n)}

这本质上就是矩阵乘法 Q^{m+n} = Q^m · Q^n 的分量形式。

为什么幂次就是多步转移？直觉：矩阵乘法 (Q^2)_{ij} = Σ_k q_{ik} q_{kj} 正是"从 i 先走到某个中转站 k，再从 k 走到 j"对所有中转站求和——这就是走两步的全概率分解。递归下去，Q^n 自然给出 n 步概率。Chapman–Kolmogorov 只是把这个"在任意中间时刻切一刀、对中间状态求和"的思想写成一般公式。

本机数值验证（天气链 Q，numpy）：Q^4 ≈ [[0.8376, 0.1624], [0.812, 0.188]]，两行还明显不同（起点仍有影响）；Q^50 ≈ [[0.8333, 0.1667], [0.8333, 0.1667]]，**两行几乎相同**——不论从晴还是从雨出发，50 步后落在晴/雨的概率都趋于 (5/6, 1/6)，起点被"遗忘"。这正是下一节平稳分布要刻画的现象。

复现命令与真实输出（基线 Py3.11.15/np2.4.6 @2026-07-26）：

    >>> import numpy as np
    >>> Q = np.array([[0.9,0.1],[0.5,0.5]])
    >>> np.linalg.matrix_power(Q,4)
    array([[0.8376, 0.1624],
           [0.812 , 0.188 ]])
    >>> np.linalg.matrix_power(Q,50)
    array([[0.833333, 0.166667],
           [0.833333, 0.166667]])

易错点：Q^n 的元素是**条件概率**（给定起点 i 时到 j 的概率），不是联合概率；一整行才构成一个合法的概率分布（行和仍为 1，因为随机矩阵的幂还是随机矩阵）。

### 8.1.4 状态分类：可约性、常返/暂留、周期

要判断一条链长期会不会"稳定下来"，需要先给状态与链分类，这里给导论级的定义与直觉。

**可达与不可约**：若从 i 出发有正概率经若干步到达 j，称 i 可达 j。若任意两状态互相可达（整条链"连成一片"），称链**不可约**（irreducible）。

**常返与暂留**：从状态 i 出发**必定**（概率 1）还会回到 i，称 i **常返**（recurrent）；若有正概率一去不返，称 i **暂留**（transient）。直觉：暂留态像"迟早会离开且再也不回来的房间"，长期停留概率为 0；常返态才可能承载长期分布。

**周期**：状态 i 的周期是"所有能回到 i 的步数"的最大公约数。若周期为 1，称 i **非周期**（aperiodic）；周期 > 1 的链会"卡在固定节拍上振荡"而不收敛。例如两状态间强制来回跳（Q = [[0,1],[1,0]]）周期为 2，分布永远在两点间摆动、不收敛到单一分布。让链非周期最简单的充分条件是"存在某个状态有自环 q_{ii} > 0"。

为什么要分类：**平稳分布的存在唯一性与"长期一定收敛到它"，取决于这些性质**。一句话预告下一节的核心定理——**有限状态、不可约、非周期**的马氏链，存在唯一平稳分布，且从任意起点出发分布都收敛到它。上面天气链两状态互通（不可约）、有自环（非周期），所以 8.1.3 里 Q^50 的收敛不是巧合，而是定理保证的。

## 8.2 平稳分布

### 8.2.1 平稳分布的定义

**平稳分布**（stationary distribution，又称不变分布 invariant distribution）是一个概率行向量 s（s_i ≥ 0，Σ_i s_i = 1），满足"用它做当前分布，走一步后分布不变"：

s = s · Q

按分量写就是 s_j = Σ_i s_i q_{ij} 对每个 j 成立。

直觉：平稳分布是这台"转移机器"的**平衡点/不动点**——一旦系统的状态分布达到 s，之后每一步分布都保持是 s（虽然具体走到哪个状态仍随机，但"落在各状态的概率比例"冻结不变）。可以类比一大群粒子在状态间流动：平稳时，每个状态"流入的概率质量 = 流出的概率质量"，宏观分布稳定，微观粒子照样在动。

线代视角（接 L1-03）：s = sQ 说明 **s 是转移矩阵 Q 的、特征值 1 对应的左特征向量**（再归一化为概率）。随机矩阵必有特征值 1（因为行和为 1，全 1 列向量是右特征向量 Q·1 = 1），故对应的左特征向量总存在——这保证了平稳分布至少存在一个。

本机验证（天气链）：三种独立算法给出同一答案 s = (5/6, 1/6) ≈ (0.8333, 0.1667)——(a) 左特征向量法（`np.linalg.eig(Q.T)` 取特征值 1）；(b) 解线性方程组 s(Q−I)=0 加约束 Σs=1；(c) 二状态解析公式 s ∝ (b, a)（其中 Q = [[1−a, a],[b, 1−b]]，此处 a=0.1, b=0.5，得 (0.5, 0.1)/0.6）。三者一致，且校验 s·Q = s 成立。

    >>> s = np.array([5/6, 1/6]); s @ Q
    array([0.833333, 0.166667])   # 等于 s，确认平稳

易错点：平稳分布是关于**分布**的不动点，不是关于**状态**的。它并不意味着系统会停在某个状态不动——系统一直在各状态间跳，只是"处于各状态的长期概率"稳定了。

### 8.2.2 极限分布与遍历定理

**极限分布**指 n→∞ 时 t_n = t_0 Q^n 的极限（若存在）。当极限存在且与起点 t_0 无关时，它必然等于平稳分布。核心定理（导论级表述）：

若有限状态马氏链**不可约且非周期**，则平稳分布 s **存在且唯一**，且从任意起点出发分布都收敛到它：

lim_{n→∞} q_{ij}^{(n)} = s_j （对所有 i、j）

即 Q^n 的每一行都趋于同一个 s——这正是 8.1.3 里 Q^50 两行趋同、且都等于 (0.8333, 0.1667) 的原因。此外还有**遍历定理**（ergodic theorem）：不可约链上，任一状态的**长期停留时间比例**几乎必然等于其平稳概率 s_j，即"时间平均 = 空间平均"，无需非周期假设。

直觉：不可约保证"整张图连成一片、跑得到任何地方"，非周期保证"没有固定节拍把你困在振荡里"，两者合起来系统就会把初始信息"混合"掉，最终忘记起点、收敛到唯一的平衡分布。遍历定理则告诉你：想估计 s_j，不必解方程，只要让链跑很久、数一数落在 j 的时间占比即可——这正是下一节 MCMC 的理论许可证。

易错点：三个概念要分清。**平稳分布**永远存在（随机矩阵必有特征值 1）；**唯一性**需要不可约；**"从任意起点收敛到它"（极限分布 = 平稳分布）** 还额外需要非周期。周期链（如 Q=[[0,1],[1,0]]）有唯一平稳分布 (0.5, 0.5)，但 t_n 在两点间永远振荡、**不收敛**——平稳分布存在 ≠ 收敛到它。

### 8.2.3 可逆性与细致平衡

若存在概率分布 s 与转移矩阵 Q 满足**细致平衡方程**（detailed balance / 局部平衡）

s_i q_{ij} = s_j q_{ji} （对所有状态对 i, j）

则称链关于 s **可逆**（reversible），且此 s **一定是平稳分布**。

为什么可逆 ⇒ 平稳：把细致平衡方程对 i 求和，

Σ_i s_i q_{ij} = Σ_i s_j q_{ji} = s_j Σ_i q_{ji} = s_j · 1 = s_j

最后一步用了行随机矩阵"第 j 行行和为 1"（Σ_i q_{ji} 是第 j 行各元素之和 = 1）。左边恰是 (sQ)_j，于是得 (sQ)_j = s_j 对所有 j 成立，即 s = sQ，正是平稳条件。所以**细致平衡是比"全局平衡 s=sQ"更强的条件**：全局平衡只要求"每个状态净流量为 0"，细致平衡要求"每一对状态之间的双向流量逐对相等"。

直觉与命名：可逆 = "把这条链的录像倒放，看起来和正放统计上无法区分"。局部平衡意味着 i→j 的概率流恰好被 j→i 的概率流抵消，没有"环流"。

本机验证：天气链在 s=(5/6,1/6) 下，s_0 q_{01} = (5/6)(0.1) = 1/12 = s_1 q_{10} = (1/6)(0.5)，逐对相等，可逆。又构造一条三状态生灭链 Q=[[.5,.5,0],[.25,.5,.25],[0,.5,.5]]，数值求得 s=(0.25, 0.5, 0.25)，并逐对验证 s_i q_{ij} = s_j q_{ji} 对全部 (i,j) 成立（numpy 输出 `detailed balance holds for all i,j: True`）。

实用价值（预告 MCMC）：细致平衡给出一个**构造性**判据——如果你能设计出满足 s_i q_{ij} = s_j q_{ji} 的转移，就自动保证 s 是平稳分布，**无需去解 s = sQ 这个大方程组**。MCMC 正是反过来用它：先固定想要的目标 s，再设计满足细致平衡的转移。注意并非所有链都可逆（生灭链、无向图上的随机游走天然可逆，但一般有向环流的链不可逆），不可逆链仍可能有唯一平稳分布，只是不能用细致平衡这条捷径去验证。

### 8.2.4 与 L1-03 马尔可夫矩阵的接口（勿重复立项）

L1-03 大主题5.4「马尔可夫矩阵与稳态」从**线性代数视角**讲同一个对象：马尔可夫矩阵（各列/各行非负、和为 1）的最大特征值恒为 1，对应特征向量归一化后即稳态向量；幂 A^k 收敛到"每列都是稳态"的秩一矩阵。本大主题从**随机过程视角**讲：它是"未来只依赖现在"的随机演化，平稳分布是分布的不动点、极限行为由可约性/周期性决定，并额外引入细致平衡与遍历定理这些概率侧概念。

## 8.3 MCMC（可选·导论级）

### 8.3.1 MCMC 的基本思想

**马尔可夫链蒙特卡洛**（Markov chain Monte Carlo, MCMC）是一族采样算法：想从一个复杂的目标分布 π 中抽样（尤其当 π 只知道"未归一化"的形式、归一化常数算不出来时），就**人为构造一条以 π 为平稳分布的马尔可夫链**，让它跑足够久，则链的状态就近似是来自 π 的样本。

核心逻辑链条（接 8.2）：由遍历定理，不可约非周期链的长期状态分布 → 平稳分布；由细致平衡，只要转移满足 π_i q_{ij} = π_j q_{ji}，π 就是平稳分布。所以问题从"直接从 π 采样"（往往做不到）转化为"设计一条满足细致平衡的链"（往往做得到）——这是 MCMC 的全部精髓。

为什么在计算机科学/统计里如此重要：贝叶斯推断中后验分布 π(θ | 数据) ∝ 似然 × 先验，其归一化常数（证据）是一个高维积分，几乎无法解析计算；但 Metropolis–Hastings 只需要 π 的**比值** π(θ')/π(θ)，归一化常数**在比值里约掉了**，于是不算积分也能采样后验。这直接喂大主题9 的贝叶斯估计与后续贝叶斯计算。

关键实践概念（导论级）：**burn-in（预热）**——链从任意起点出发需要若干步才"混合"到接近 π，前面这段要丢弃；**自相关**——相邻样本高度相关，有效样本量小于名义样本量，常靠"抽稀（thinning）"或跑更长缓解；**收敛诊断**——判断链是否真的混合好是实践难点，无绝对可靠的判据。

### 8.3.2 Metropolis–Hastings 算法

**Metropolis–Hastings（M-H）** 是最通用的 MCMC 构造。给定目标 π（可未归一化）与一个**提议分布** g(·|当前状态)，每步：

1. 在当前状态 x 处，从提议分布抽一个候选 x' ~ g(x'|x)；
2. 计算**接受概率**

a = min(1, [π(x') g(x|x')] / [π(x) g(x'|x)])

3. 以概率 a 接受（令下一状态为 x'），否则拒绝（下一状态仍为 x）。

当提议对称（g(x'|x) = g(x|x')，如以 x 为中心的正态随机游走）时，g 约掉，接受概率简化为 a = min(1, π(x')/π(x))，这就是原始的 **Metropolis** 算法：候选比当前"更可能"就一定接受，"更不可能"就按概率比值随机接受。

为什么它对：接受-拒绝这套设计恰好让转移核满足关于 π 的细致平衡（M-H 接受概率就是为了凑出 π_i q_{ij} = π_j q_{ji} 而反推出来的），所以 π 是该链的平稳分布，链跑久了状态就服从 π。直觉：接受规则让链"倾向于往高概率区爬，但偶尔也下探低概率区"，最终在各处停留的时间比例正好正比于 π。

本机验证：用对称随机游走（步长 1 的正态提议）跑 M-H 采样标准正态 N(0,1)，20 万步、丢弃前 2 万预热，得样本均值 ≈ 0.005、标准差 ≈ 0.996（目标 0 与 1），接受率 ≈ 0.707——确认链收敛到目标分布。

    # 目标 log π(z) = -z^2/2（N(0,1)，未含归一化常数）
    # 提议 x' = x + N(0,step)，对称 → a = min(1, exp(logπ(x')-logπ(x)))
    # 200000 步，burn-in 20000：mean=0.005, std=0.9959, acc=0.707

易错点：**提议步长要调**。步长太小→候选几乎总被接受但移动极慢、样本高度自相关；步长太大→候选常落到低概率区被拒、链"卡住"不动。两者都拖慢混合，需折中（随机游走 M-H 的经验接受率常调到 ~0.2–0.5 附近；本例 0.707 偏高说明步长可略增）。另一易错点：M-H 保证的是**渐近**正确（跑够久才对），有限步的样本有偏（burn-in 未除净、未收敛），不能拿刚起步的链当独立同分布样本用。

### 8.3.3 Gibbs 采样

**Gibbs 采样**（Gibbs sampling）是 M-H 的一个重要特例，用于**多维**目标分布。它不一次更新整个向量，而是**逐个坐标更新**：轮流固定其余所有坐标、从该坐标的**满条件分布**（full conditional）π(x_k | 其余坐标) 中抽样替换。

x_k^{new} ~ π(x_k | x_1, …, x_{k−1}, x_{k+1}, …, x_d)

它是接受概率恒为 1 的 M-H（提议就是满条件分布，代入 M-H 公式接受概率化简为 1，即"每次都接受")。

适用场景与直觉：当联合分布复杂、但**每个坐标在给定其余坐标时的条件分布是简单已知分布**（能直接抽样）时，Gibbs 特别好用——把一个高维采样难题拆成一串一维易采样子问题。共轭先验（大主题9 会讲）常让满条件分布是标准分布，故 Gibbs 是贝叶斯层次模型的主力。

易错点：Gibbs 要求满条件分布能被采样，若某坐标的满条件不是标准分布就退化，需要在该步内嵌 M-H（"Metropolis-within-Gibbs"）。此外坐标间强相关时，逐坐标更新移动缓慢、混合差——这是 Gibbs 的典型失效模式。

## 8.4 泊松过程（可选·导论级）

### 8.4.1 泊松过程的定义

**泊松过程**（Poisson process）是刻画"事件在连续时间轴上随机、独立地到达"的标准模型，由单一参数——**速率** λ > 0（单位时间平均到达次数）——决定。记 N(t) 为时间区间 [0, t] 内的到达次数，泊松过程（速率 λ）满足：

1. N(0) = 0；
2. **独立增量**：不相交时间区间内的到达次数相互独立；
3. 长为 t 的任意区间内的到达次数服从泊松分布

N(t) ~ Poisson(λt)， 即 P(N(t) = k) = e^{−λt} (λt)^k / k!

于是任意区间的到达次数均值 = 方差 = λ·(区间长)。

直觉：泊松过程是"完全随机、无记忆、无聚集"的到达模式——到达点像被随机撒在时间轴上的沙粒，任意小区间要么到达一次、要么不到达（同一瞬间不会同时来两个），且各区间互不影响。它是排队论、网络请求流量、呼叫中心来电、放射性衰变、可靠性中故障到达的默认模型。

本机验证：模拟速率 λ=3 的过程到 T=2000，得到达数 5976（理论 λT=6000，随机涨落内）；对 2000 个独立的单位时间窗数到达次数，样本均值 3.031、方差 3.173（理论 Poisson(3) 均值=方差=3），确认 N(单位区间) ~ Poisson(3)。

    # count in unit interval over 2000 windows: mean=3.031, var=3.173  (theory 3, 3)

易错点：λt 是"整段区间"的期望到达数，不是概率（λt 可以大于 1）；单个瞬间的到达概率为 0（连续时间）。把 λ 和 λt 搞混（速率 vs 期望次数）是初学最常见错误。

### 8.4.2 到达间隔与指数分布

泊松过程相邻两次到达之间的**间隔时间**（inter-arrival time）相互独立，且都服从速率 λ 的**指数分布**：

间隔时间 T_i ~ Exponential(λ)， 均值 E[T_i] = 1/λ

（此处沿用大主题3 的**速率参数**约定：Exp(λ) 的 PDF 为 λe^{−λx}、均值 1/λ；注意 scipy.stats.expon 用 `scale = 1/λ`，见冲突说明。）等价地，第 n 次到达的时刻服从 **Gamma(n, λ)** 分布（n 个独立 Exp(λ) 之和，接大主题5 卷积/Gamma）。

为什么是指数分布——**无记忆性**：指数分布是唯一的连续无记忆分布，P(T > s + t | T > s) = P(T > t)，即"已经等了 s 时间还没来，接下来还要等的时间分布和刚开始等时一模一样"。这与泊松过程"任意区间到达独立、系统不记得上次何时到达"的假设完全自洽——正因为过程无记忆，间隔才必须是指数分布。

本机验证：模拟 λ=3 的间隔，样本均值 0.3345（理论 1/λ=0.3333）。这条"泊松过程 ⇔ 独立指数间隔"的等价关系，是模拟泊松过程最常用的手段（累加指数间隔即得到达时刻）。

易错点：间隔是指数分布、**到达次数**才是泊松分布，两者是同一过程的两种视角，别把分布张冠李戴。另一个反直觉现象是**检验悖论/等公交悖论**：随机时刻去等车，你所在的那个间隔平均比 1/λ 更长（因为长间隔更容易"覆盖"到你），这是导论级常被忽略的陷阱。

### 8.4.3 叠加、稀释与条件均匀（导论级性质）

泊松过程有三条优雅性质，导论级只需知道结论与直觉：

**叠加**（superposition）：把速率 λ_1、λ_2 的两个独立泊松过程合并，得到的仍是泊松过程，速率为 λ_1 + λ_2。直觉：两个独立随机到达流合起来还是随机到达流，速率相加。

**稀释/分裂**（thinning）：把一个速率 λ 的泊松过程的每个到达独立地以概率 p 标记为"类型 A"、否则"类型 B"，则类型 A 的到达构成速率 λp 的泊松过程、类型 B 构成速率 λ(1−p) 的泊松过程，且**两者相互独立**。这条"独立"结论相当反直觉（同一批到达拆出来的两股竟然独立），是泊松过程的招牌性质。

**给定次数则时刻条件均匀**（conditional uniformity）：已知 [0, t] 内恰好发生 n 次到达，则这 n 个到达时刻的条件分布 = n 个独立 Uniform(0, t) 的顺序统计量。直觉：泊松过程"完全无偏好地把点撒在时间轴上"，一旦固定总数，位置就是均匀随机撒点。

这些性质让泊松过程在建模里极其好用：多源流量可叠加、按类型可拆分、给定总量可用均匀点模拟。它们也是排队论（M/M/1 队列等）与网络流量建模的基础。因是可选导论内容，此处不展开证明。
