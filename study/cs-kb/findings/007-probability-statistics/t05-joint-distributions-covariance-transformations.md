## 5.1 联合分布

### 5.1.1 联合分布（联合 PMF / PDF / CDF）

联合分布描述两个（或多个）随机变量**同时取各种值**的概率结构，是关于这组变量的"完整信息"。对离散情形，联合概率质量函数（joint PMF）为

p(x, y) = P(X = x, Y = y)

它非负且对所有 (x, y) 求和为 1。对连续情形，联合概率密度函数（joint PDF）f(x, y) 满足非负、二重积分为 1，且事件概率由密度在区域上的积分给出：

P((X, Y) ∈ A) = ∬_A f(x, y) dx dy

无论离散连续，联合累积分布函数（joint CDF）都定义为

F(x, y) = P(X ≤ x, Y ≤ y)

只要知道联合分布，关于 X、Y 的**一切**问题（各自的分布、它们的关系、任意函数的期望）原则上都能算出来——这就是"完整信息"的含义。

直觉上，可以把二维离散联合 PMF 想成一张"表格 + 高度"：行是 X 的取值、列是 Y 的取值，每个格子里的数是"这一对值同时出现"的概率，所有格子加起来是 1。连续情形则把这张表换成一张铺在平面上的"概率毯子"f(x, y)，某块区域的概率 = 毯子在那块区域下方围出的体积。

掷两枚公平骰子，X = 第一枚点数，Y = 两枚之和。每一对 (x, y) 的概率要么是 1/36（当 y − x 落在 1..6），要么是 0，把这 36 个非零格子填进表里就是联合 PMF。

**联合分布不能由两个"单独的分布"拼出来**。只知道 X 的分布和 Y 的分布，一般无法还原 (X, Y) 的联合分布——因为丢掉了"它们如何联动"的信息（除非额外假设独立，见 5.1.4）。这正是"边缘信息 < 联合信息"的核心，也是下面为什么要专门定义边缘与条件分布的原因。

### 5.1.2 边缘分布

边缘分布（marginal distribution）是"只看其中一个变量、把其余变量全部加和/积分掉"得到的单变量分布。离散情形对另一个变量求和：

p_X(x) = Σ_y p(x, y)

连续情形对另一个变量积分：

f_X(x) = ∫_{−∞}^{∞} f(x, y) dy

"边缘"这个名字来自离散表格：把每一行的概率横向加起来写在表格右边的"页边"（margin）上，得到的就是 X 的边缘 PMF；纵向加到底边就是 Y 的边缘。

直觉是"忽略掉不关心的变量"：如果只想知道 X 的行为、完全不管 Y，那就把 Y 所有可能取值下的联合概率"塌缩"（合并）到一起。因为对固定的 x，事件 {X = x} 恰好是所有 {X = x, Y = y}（对不同 y）的不相交并，按可加性把它们加起来就得到 P(X = x)。

从联合到边缘是**多对一、不可逆**的——不同的联合分布可以有完全相同的一对边缘分布（它们的区别全藏在"联动方式"里）。所以看到"X 是正态、Y 是正态"绝不能推出"(X, Y) 是二维正态"；反例在 5.5 会点到。

### 5.1.3 条件分布

条件分布把大主题2 的条件概率推广到随机变量：在"已知 X = x"的前提下，Y 的分布。离散情形直接套条件概率定义：

p_{Y|X}(y | x) = p(x, y) / p_X(x)   （要求 p_X(x) > 0）

连续情形形式完全平行，用密度替代 PMF：

f_{Y|X}(y | x) = f(x, y) / f_X(x)   （要求 f_X(x) > 0）

直觉仍是大主题2 的"缩小样本空间再归一化"：固定 X = x，就等于只保留联合表格里的"第 x 行"，再把这一行除以它自己的总和（边缘 p_X(x)），让它重新变成一个合法的、和为 1 的分布。

由此立刻得到随机变量版的乘法法则与全概率（贝叶斯定理同理），把大主题2 的工具原样搬进多变量世界：

p(x, y) = p_{Y|X}(y | x) · p_X(x)

连续情形下 f_{Y|X}(y | x) 是"给定 X 恰好等于 x"的条件密度，而 P(X = x) = 0，看似矛盾，但条件密度是通过"X 落在 x 附近一个小邻域"取极限严格定义的，不必纠结于"概率为 0 的条件"。易错点二：条件分布是 y 的分布，x 只是"参数/背景"；把 x 和 y 的角色搞反是初学者常见错误。

### 5.1.4 独立性（联合视角）

两个随机变量 X、Y 相互独立，当且仅当它们的**联合分布恰好等于两个边缘分布的乘积**，对所有 x、y 都成立。离散/连续分别写作

p(x, y) = p_X(x) · p_Y(y)      f(x, y) = f_X(x) · f_Y(y)

等价地，联合 CDF 分解为 F(x, y) = F_X(x) · F_Y(y)，或"条件分布不随条件变化"：f_{Y|X}(y | x) = f_Y(y)。

这与大主题2 的事件独立性一脉相承：事件独立是 P(A ∩ B) = P(A)P(B)，随机变量独立则要求**所有由 X 生成的事件与所有由 Y 生成的事件都独立**，因此要求"逐点乘积"对全部 (x, y) 成立，比单个事件独立强得多。

独立 = "知道 X 的取值，对 Y 的分布没有任何信息增益"。这正是 5.1.1 说的"联合信息 = 边缘信息之和"的那种特殊情形——只有独立时，两个边缘才足以还原联合。

连续情形若联合密度能写成"一个只含 x 的函数 × 一个只含 y 的函数"，**且支撑集是一个矩形（x、y 的取值范围互不牵连）**，则独立。两个条件缺一不可——例如 f(x, y) 在三角形区域 0 < x < y < 1 上为常数时，虽然形式上像"常数×常数"，但支撑集是三角形（y 的上限依赖 x），X 与 Y 并不独立。忘记检查支撑集是这里最隐蔽的坑。

## 5.2 协方差与相关

### 5.2.1 协方差

协方差（covariance）度量两个随机变量"一起偏离各自均值"的平均趋势，是刻画**线性联动方向**的二阶量。定义为

Cov(X, Y) = E[(X − E[X])(Y − E[Y])]

展开后有一个几乎总是更好用的计算式：

Cov(X, Y) = E[XY] − E[X]E[Y]

符号的含义：协方差为正表示"X 高于均值时 Y 往往也高于均值"（同向），为负表示反向，接近 0 表示没有明显的线性同/反向趋势。注意 Cov(X, X) = Var(X)，方差是协方差的自身特例。

把每个样本点相对于中心 (E[X], E[Y]) 分成四个象限。右上（都偏大）和左下（都偏小）贡献正的乘积，左上、右下贡献负的乘积；协方差就是这些带符号乘积的期望——哪种象限占主导，符号就随之。

协方差的数值**带量纲、无上界**，把 X、Y 换个单位（如米换成厘米）协方差会跟着放大 100 倍，所以它的绝对大小不能直接用来比较"关系强弱"——这正是下面要引入无量纲相关系数的原因。

### 5.2.2 协方差的性质与和的方差

协方差是**双线性**的（对每个参数分别线性），且对称：

Cov(aX + b, cY + d) = ac · Cov(X, Y)      Cov(X, Y) = Cov(Y, X)

由双线性直接推出多变量"和的方差"公式——它是本节最常被用到的结论：

Var(X + Y) = Var(X) + Var(Y) + 2 Cov(X, Y)

推广到 n 个变量：Var(ΣXᵢ) = Σ Var(Xᵢ) + 2 Σ_{i<j} Cov(Xᵢ, Xⱼ)。

加常数不改变协方差（常数没有波动，Cov(·, 常数) = 0）；乘常数按倍数缩放。和的方差里那个"+2Cov"项解释了一个反直觉现象——**独立时方差可加**（Cov = 0，回到大主题4 的 Var(X+Y)=VarX+VarY），但正相关时和的波动被放大、负相关时被抵消（对冲/分散投资的数学根源）。

本机数值验证（基线 Py3.11.15/np2.4.6 @2026-07-25，numpy.cov，样本量 1e6，代码存 scratchpad）：取 X 标准正态、Y = 0.5X + 独立噪声，实测

Var(X+Y) = 3.2499，  Var(X)+Var(Y)+2·Cov(X,Y) = 3.2499

两边吻合，佐证"+2Cov"分解。

### 5.2.3 相关系数

相关系数（correlation coefficient）是把协方差用两个标准差归一化后的**无量纲**版本，专门度量线性关系的强度与方向：

ρ(X, Y) = Cov(X, Y) / (σ_X · σ_Y)

它的关键性质是取值恒在 [−1, 1]（由 5.2.4 提到的 Cauchy–Schwarz 不等式保证），且不受线性缩放/平移影响（换单位后 ρ 不变）。ρ = ±1 当且仅当 Y 是 X 的**确定性线性函数**（完美正/负线性关系）；ρ = 0 称为"不相关"。

ρ 回答的是"这团散点有多贴近一条直线"。±1 是完美贴线，0 是没有线性趋势。因为归一化掉了量纲，不同变量对之间的 ρ 可以横向比较强弱，这是它比裸协方差实用得多的地方。

ρ 只捕捉**线性**关系。它对单调但非线性的关系会低估，对完全非线性的依赖（见下条）可能为 0，却绝不意味着"无关"。

### 5.2.4 不相关 ≠ 独立（重点易错点）

**独立一定不相关，但不相关不一定独立。** 独立蕴含 E[XY] = E[X]E[Y]，于是 Cov = 0、ρ = 0；反方向不成立——协方差只看"线性"联动，两个变量可以有很强的非线性依赖却恰好线性趋势为零。

设 X 在 {−1, 0, 1} 上等概率取值，令 Y = X²。显然 Y 由 X 完全决定（知道 X 就知道 Y，是极端的"依赖"），但由对称性 E[X] = 0、E[XY] = E[X³] = 0，故

Cov(X, Y) = E[XY] − E[X]E[Y] = 0

即 X 与 Y 不相关却高度相关（依赖）。本机验证（numpy.cov / numpy.corrcoef，X 从 {−1,0,1} 各 1/3 抽 2e6 个，Y=X²）：实测 Cov ≈ 3e-05、corr ≈ 7e-05（数值上就是 0），而 Y 明显是 X 的函数——坐实"不相关 ≠ 独立"。

机器学习/统计里大量方法（PCA、线性回归、只看相关矩阵的特征筛选）本质上只利用了"线性"信息，会漏掉非线性依赖；把"相关系数为 0"误当成"两变量无关"是数据分析中最常见、后果最严重的误判之一。唯一的例外在 5.5：**联合正态**时，不相关确实等价于独立。

### 5.2.5 协方差矩阵（接 L1-03 谱定理 / 正定）

当有一组随机变量 X = (X₁, …, X_n)ᵀ 时，把两两协方差排成矩阵，就是协方差矩阵（covariance matrix）Σ，其第 (i, j) 元为

Σ_{ij} = Cov(Xᵢ, Xⱼ)

对角线是各自的方差 Var(Xᵢ)，非对角是两两协方差。用向量记号 Σ = E[(X − μ)(X − μ)ᵀ]，其中 μ = E[X]。

两条关键结构性质，直接对接 L1-03 线性代数：
- Σ **对称**（因为 Cov(Xᵢ, Xⱼ) = Cov(Xⱼ, Xᵢ)），故由**谱定理**可正交对角化，特征向量互相垂直、特征值全为实数。
- Σ **半正定**（positive semidefinite）：对任意常向量 a，Var(aᵀX) = aᵀΣa ≥ 0，说明 Σ 的二次型非负，等价于所有特征值 ≥ 0。若无"退化的线性关系"（即没有某个 aᵀX 恒为常数），则 Σ 严格正定、可逆。

这两条正是 L1-03「大主题6 对称矩阵与正定性」的直接应用场景，也是 PCA（对 Σ 做特征分解、沿最大特征值方向找主成分）和 5.5 多元正态密度（用到 Σ⁻¹ 和 det Σ）的数学地基。接口在此点明，谱定理/正定判定的展开归 L1-03，本课不重复立项。

对 Σ = [[2, 0.5], [0.5, 1]]，numpy.linalg.eigvalsh 给出特征值 [0.7929, 2.2071]，均 > 0，佐证对称正定。

## 5.3 随机变量变换

### 5.3.1 一维变量替换（单调变换公式）

变换问题回答："已知 X 的分布，令 Y = g(X)，Y 的分布是什么？"离散情形最简单——直接把概率"搬运"到新值上：p_Y(y) = Σ_{x: g(x)=y} p_X(x)。连续情形当 g 严格单调、可导时，有变量替换（change of variables）公式：

f_Y(y) = f_X(x) · |dx/dy|,   其中 x = g⁻¹(y)

那个 |dx/dy| 叫**雅可比因子**（一维就是导数的绝对值），它的作用是"拉伸/压缩补偿"：变换会把 x 轴局部拉长或压短，密度必须反向缩放才能让"某小段区间上的概率"在变换前后守恒。

概率必须守恒——"X 落在 [x, x+dx]"这件事和"Y 落在对应的 [y, y+dy]"是同一件事，概率相等，即 f_X(x)|dx| = f_Y(y)|dy|，两边除以 |dy| 就得到公式。取 X ~ Exp(1)、Y = X²（在 x > 0 单调），g⁻¹(y) = √y，|dx/dy| = 1/(2√y)，得

f_Y(y) = e^{−√y} · 1/(2√y),   y > 0

本机验证（20e6 个 Exp(1) 样本，窄窗估密度）：y = 1 处实测密度 0.1843，理论 e^{−1}/2 = 0.1839，吻合。

**别忘了绝对值**，密度恒非负，雅可比因子取绝对值。易错点二：若 g **非单调**（如 Y = X² 而 X 可正可负），需把每个"分支"的贡献分别算再相加，不能直接套单支公式——这也是 5.2.4 里 Y = X² 例子的另一面。

### 5.3.2 多维变换与雅可比法（用到 L1-04 雅可比）

当把一组连续随机变量 (X₁, …, X_n) 通过可逆、连续可微的映射变成 (Y₁, …, Y_n) 时，一维的 |dx/dy| 升级为**雅可比行列式的绝对值**：

f_Y(y₁, …, y_n) = f_X(x₁, …, x_n) · |det(∂x / ∂y)|

其中 ∂x/∂y 是逆变换的雅可比矩阵（第 (i, j) 元为 ∂xᵢ/∂yⱼ），x 用 y 表示后代入。

这正是 L1-04「大主题8.4 变量替换与雅可比」在多重积分里那套换元的概率版本——雅可比行列式度量映射在某点附近把"小体积元"放大/缩小了多少倍，密度要除以这个体积缩放（等价于乘 |det| 的逆变换形式）才能守恒总概率。二维时 |det(∂(x,y)/∂(u,v))| 就是那个熟悉的雅可比。

从两个独立标准正态 (Z₁, Z₂) 通过极坐标式变换生成它们——即 Box–Muller 的逆向理解，或把 (X, Y) 变成 (X+Y, X−Y) 来解耦。雅可比法是"从已知联合分布造出新联合分布"的通用引擎，5.4 的卷积其实就是它在 (X, Y) → (X+Y, Y) 这一特定变换 + 边缘化下的产物。

变换必须**可逆**（至少分片可逆）雅可比法才适用；维数必须匹配（n 个输入变量配 n 个输出变量，若只关心 X+Y 这一个量，标准做法是先引入一个"辅助变量"凑成同维可逆变换、算完再把辅助变量积分掉）。忘记积掉辅助变量、或雅可比矩阵取错方向（用了 ∂y/∂x 而非 ∂x/∂y 又忘了取倒数）是这里最常见的失误。

## 5.4 卷积与和的分布

### 5.4.1 卷积公式（独立和的密度）

当 X、Y **独立**、令 T = X + Y 时，T 的分布由**卷积**（convolution）给出。离散情形：

p_T(t) = Σ_x p_X(x) · p_Y(t − x)

连续情形把求和换成积分：

f_T(t) = ∫_{−∞}^{∞} f_X(x) · f_Y(t − x) dx

"和等于 t"这件事可以按第一个变量 X 取什么值来分解——若 X = x，则必须 Y = t − x 才能凑够 t；对所有可能的 x 遍历、把两个独立密度相乘再加总（积分），就是全概率公式在"求和"这个函数上的具体化。卷积也正是 5.3.2 雅可比法在变换 (X, Y) → (X+Y, X) 下再对辅助变量边缘化的结果。

最小例子（本机验证，各 1e6 个）：两个独立 Uniform(0,1) 之和的密度是"三角形"（在 t=1 处峰值为 1，向 0 和 2 线性降到 0）。实测四段 [0,0.5],[0.5,1],[1,1.5],[1.5,2] 的平均密度为 [0.25, 0.75, 0.75, 0.25]，呈对称三角形，与理论一致。

卷积公式**要求独立**；不独立时和的分布要回到联合分布去积分，不能直接卷积。

### 5.4.2 独立和的分布（可加性家族）

某些分布族对"独立求和"是**封闭**的——同族相加还是同族，参数直接相加。常用的"可加性"结论：

- 独立 Poisson(λ₁) + Poisson(λ₂) = Poisson(λ₁ + λ₂)
- 独立 Binomial(n₁, p) + Binomial(n₂, p) = Binomial(n₁ + n₂, p)（**要求 p 相同**）
- 独立 Normal(μ₁, σ₁²) + Normal(μ₂, σ₂²) = Normal(μ₁ + μ₂, σ₁² + σ₂²)
- 独立 Gamma(a₁, λ) + Gamma(a₂, λ) = Gamma(a₁ + a₂, λ)（**要求 rate λ 相同**；n 个独立 Exp(λ) 之和 = Gamma(n, λ) 是其特例）

这些结论既可用卷积硬算，也可用大主题4 的矩生成函数（MGF）秒证——独立和的 MGF = 各 MGF 之积，若乘积仍是同族 MGF 的形式，可加性立现。这是 MGF"把卷积变成乘法"的威力所在。

可加性是"把小实验拼成大实验"的数学保证——n 次独立 Bernoulli(p) 之和是 Binomial(n, p)、独立到达时间累加落在 Gamma/Poisson 框架里，都是同一回事。它也解释了为什么正态在实践中无处不在（很多独立小效应相加仍是正态，且这一点在 CLT 里被进一步放大）。

独立 Poisson(2) + Poisson(3)（各 1e6），实测均值 4.999、方差 4.998，符合 Poisson(5) 的均值=方差=5。

**参数不匹配就不封闭**。Binomial 相加要求 p 相同，Gamma 相加要求 rate 相同；两个不同 p 的二项之和一般不再是二项。正态是最"宽容"的——任意参数的独立正态之和仍是正态。

### 5.4.3 Beta–Gamma 联系（bank–post office）

Gamma 与 Beta 之间有一个优美且实用的桥梁，Blitzstein 称之为"bank–post office story"。设 X ~ Gamma(a, λ) 与 Y ~ Gamma(b, λ) 独立（rate 相同），构造

W = X / (X + Y),   S = X + Y

则 W ~ Beta(a, b)，S ~ Gamma(a + b, λ)，**且 W 与 S 相互独立**。

直觉（故事版）：Gamma 描述"等到若干次到达所需的总时间"。X 是办完银行业务的时间、Y 是办完邮局业务的时间；S = X+Y 是总耗时，W 是"银行占了总时间的比例"。惊人之处在于——**总耗时**和**比例分配**这两件事互相独立：知道你总共花了多久，对"银行占几成"毫无信息。这就是为什么 Beta 天然是"比例/概率"的分布，而 Gamma 管"绝对量"。

这条联系是很多推导的捷径——比如它直接给出 Beta 分布的均值 a/(a+b)（"a 份里占 a"），也是贝叶斯统计里 Beta 作为二项/Bernoulli 共轭先验的结构根源（喂大主题9）。

本机验证（numpy.random.gamma，a=2、b=3、各 2e6）：W = X/(X+Y) 实测均值 0.3999（理论 Beta(2,3) 均值 a/(a+b) = 0.4）、实测方差 0.04001（理论 Beta(2,3) 方差 0.04），确认 W ~ Beta(2,3)。

Beta–Gamma 要求两个 Gamma **同 rate λ 且独立**；W 与 S 的独立性是"故事"里最反直觉、也最关键的一环，务必记住是 W ⊥ S，而不是 X ⊥ W。

## 5.5 多元正态

### 5.5.1 多元正态的定义

多元正态分布（multivariate normal, MVN）是一维正态向多维的推广，是统计与机器学习里最重要的多维分布。一个随机向量 X = (X₁, …, X_k)ᵀ 服从多元正态，最稳健的定义是：**它的每一个线性组合 a₁X₁ + … + a_kX_k 都是（一维）正态分布**（含退化的常数情形）。它由均值向量 μ 和协方差矩阵 Σ 完全确定，记 X ~ N_k(μ, Σ)。当 Σ 正定时，其联合密度为

f(x) = (2π)^{−k/2} · (det Σ)^{−1/2} · exp( −½ (x − μ)ᵀ Σ⁻¹ (x − μ) )

把一维正态密度里的 (x−μ)²/σ² 换成"矩阵版的标准化平方距离"(x−μ)ᵀΣ⁻¹(x−μ)（这叫马氏距离 Mahalanobis distance 的平方），把 1/σ 换成 (det Σ)^{−1/2}。等密度面是以 μ 为中心的椭球，椭球的朝向和长短轴由 Σ 的特征向量与特征值决定（又一次用到 5.2.5 的谱定理）。

为什么"用线性组合定义"而不是"直接给密度"：因为这个定义即使 Σ 不可逆（退化、没有密度）也成立，更本质，也直接说明了 5.5.3 的诸多性质。

本机验证（scipy.stats.multivariate_normal，μ=(1,2)、Σ=[[2,0.5],[0.5,1]]）：在 x=(0.5,1.5) 处 scipy 给出 pdf = 0.10429393，手算上式得 0.10429393，逐位吻合。

### 5.5.2 边缘、条件与线性变换的封闭性

多元正态之所以"旗舰"，在于它对几乎所有常见操作都**封闭**——做完还是（多元）正态：

- **线性变换封闭**：若 X ~ N_k(μ, Σ)，则对任意矩阵 A、向量 b，有 AX + b ~ N(Aμ + b, AΣAᵀ)。
- **边缘分布仍正态**：任取若干分量组成的子向量仍是多元正态，其均值/协方差就是从 μ、Σ 里取对应的子块。
- **条件分布仍正态**：给定一部分分量，另一部分的条件分布还是多元正态（条件均值是被给定分量的线性函数，条件协方差不依赖于给定的具体值）——这正是线性回归/高斯过程/卡尔曼滤波的数学核心。

因为 MVN 由"所有线性组合都正态"定义，而边缘、线性变换本身就是取线性组合，条件化也保持这种线性—二次结构，所以正态性一路守恒。这种"处处封闭"是任何其他多维分布都不具备的奢侈性质，也是它被建模者偏爱的根本原因。

### 5.5.3 关键特性：不相关 ⇒ 独立（正态例外）

在一般情形下"不相关 ≠ 独立"（5.2.4 已强调），但对**联合正态**，这条铁律出现唯一的例外：

若 (X, Y) 是**联合**（多元）正态，则 Cov(X, Y) = 0 ⟺ X 与 Y 独立。

推广到向量：多元正态的分量间协方差为 0（Σ 为块对角）当且仅当对应的子向量相互独立。

不相关只保证"无线性关系"，而正态分布的全部信息恰好只装在一阶（均值）和二阶（协方差）里，没有更高阶的隐藏依赖可藏——所以线性关系一没了，依赖就彻底没了。这条性质让"正交化 = 独立化"在正态世界里成立（PCA 对高斯数据能真正解耦），威力巨大。

前提是"**联合**正态"，不是"X 边缘正态且 Y 边缘正态"。存在反例——X ~ N(0,1)，令 Y = X 或 Y = −X 各以 1/2 概率（等价地 Y = SX，S 为独立的 ±1），则 X、Y 各自都是标准正态、Cov(X,Y)=0（不相关），但 |X|=|Y| 使它们高度依赖——原因就是 (X, Y) **并非联合正态**（它们的线性组合 X+Y 不是正态）。5.1.2 埋下的"边缘正态推不出联合正态"的伏笔，正在此处兑现。
