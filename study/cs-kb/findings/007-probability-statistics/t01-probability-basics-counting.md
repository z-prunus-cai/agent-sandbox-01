## 1.1 样本空间与事件

### 1.1.1 样本空间：一次随机试验所有可能结果的集合

样本空间（sample space），记作 S（部分教材记 Ω），是一个随机试验所有可能结果（outcome）构成的集合。每一个不可再分的结果叫一个样本点（sample point / outcome）。

    S = { 所有可能结果 }

例如掷一枚骰子，样本空间是

    S = {1, 2, 3, 4, 5, 6}

掷两枚可区分的硬币，样本空间是

    S = {HH, HT, TH, TT}

概率论里"随机"的一切讨论，都从"先把话说清楚——这次试验到底有哪些可能结局"开始。样本空间就是这份"结局清单"，它把一个含糊的现实问题固定成一个明确的集合。这一步看似简单，却是最容易埋错的地方：如果把两枚硬币的样本空间偷懒写成 {两个正面, 一正一反, 两个反面} 三个结果，就会误以为它们等可能，从而算错——因为"一正一反"实际上对应 HT、TH 两个样本点，出现的机会是"两个正面"的两倍。

**样本空间怎么划分，直接决定了后面能不能用"等可能"假设**。掷两枚硬币时，选 {HH, HT, TH, TT} 这个 4 元样本空间，四个结果才是等可能的；而结果个数的"细粒度"要划到"每个样本点确实等可能"为止。样本空间可以是有限的（骰子）、可数无限的（一直抛硬币直到出现正面，记录抛的次数：{1, 2, 3, …}），也可以是连续不可数的（在 [0,1] 里随机取一个实数）；本大主题主要处理有限、等可能的情形，连续情形留到后续大主题的随机变量与密度。

### 1.1.2 事件：样本空间的子集，"我们关心的那组结果"

事件（event）是样本空间 S 的一个子集 A ⊆ S。当试验的真实结果落在 A 里时，就说"事件 A 发生了"。

    A ⊆ S，结果 ∈ A ⟺ 事件 A 发生

掷一枚骰子，"掷出偶数"这个事件就是子集

    A = {2, 4, 6}

只含单个样本点的事件（如 {5}）叫基本事件（elementary event）；整个 S 本身是必然事件（一定发生）；空集 ∅ 是不可能事件（永不发生）。

这里初学者要打通的最重要一环是"事件的语言 = 集合的语言"：日常说的"且 / 或 / 非"精确对应集合的交、并、补。

    "A 且 B" 同时发生      ⟷  A ∩ B
    "A 或 B" 至少一个发生   ⟷  A ∪ B
    "A 不发生"（A 的对立） ⟷  Aᶜ = S \ A

比如"掷出偶数且大于 3"就是 {2,4,6} ∩ {4,5,6} = {4,6}。把中文的事件描述翻译成集合运算，是后面用公理和容斥算概率的前提，务必练熟。若 A ∩ B = ∅，称 A、B 互斥（mutually exclusive / disjoint），意思是它们不可能同时发生——这正是 1.2 可加性公理适用的场景。

### 1.1.3 概率的朴素（古典）定义：等可能下的"数数比值"

在样本空间有限、且所有样本点等可能的前提下，事件 A 的概率定义为 A 中的结果数除以 S 中的结果总数：

    P_naive(A) = |A| / |S|

其中 |·| 表示集合的元素个数（基数）。这就是"古典概型 / 拉普拉斯概型"，也是 Blitzstein 所称的"朴素定义（naive definition）"。

例如掷一枚公平骰子掷出偶数：

    P({2,4,6}) = |{2,4,6}| / |{1,2,3,4,5,6}| = 3 / 6 = 1/2

这个定义直觉极强——"有利结果占全部结果的比例"——但初学者必须牢记它的两条硬前提，否则会滥用：其一，样本空间必须**有限**（无法给无穷多个等可能结果每个分正的概率）；其二，所有样本点必须**等可能**。第二条前提最常被忽略：现实中"明天下雨或不下雨"绝不是各 1/2，因为这两个结果并不等可能；把朴素定义硬套到不等可能的场景，是入门阶段最典型的错误。

正因为朴素定义只在等可能时成立，它并不是概率的最终定义——它只是"当尺子恰好均匀时"的特例。更一般、不依赖等可能假设的定义要靠 1.2 的公理给出。但反过来，一旦确认了等可能，"算概率"就彻底变成"数清 |A| 和 |S|"这两个纯计数问题，这正是 1.3 计数方法要武装我们的原因，也是概率与 L1-02 组合计数共用地基的接口所在。

## 1.2 概率公理

### 1.2.1 三条公理（Kolmogorov 公理）：不靠等可能的严格定义

概率的现代（非朴素）定义不预设"等可能"，而是要求概率函数 P（把每个事件映到一个实数）满足三条公理，即 Kolmogorov 公理：

非负性（nonnegativity）：对任意事件 A，

    P(A) ≥ 0

规范性 / 单位测度（normalization）：对整个样本空间 S，

    P(S) = 1

可数可加性（countable additivity）：若事件 A₁, A₂, … 两两互斥（i ≠ j 时 Aᵢ ∩ Aⱼ = ∅），则

    P(A₁ ∪ A₂ ∪ ⋯) = P(A₁) + P(A₂) + ⋯

满足这三条的 P 就叫一个概率测度（probability measure）。

为什么要这样"绕开等可能"？因为朴素定义只覆盖有限等可能的窄情形，而现实里大量随机现象（不均匀的硬币、连续的测量、无穷次抛掷）都不满足等可能。公理化的高明之处在于：它不去规定"每个具体概率是多少"，只规定"任何合理的概率都必须遵守的三条底线规则"，把"概率"抽象成"一把给集合分配非负分量、总量为 1、且对互斥集合可以直接相加的尺子"。可数可加性尤其关键——它比"有限可加"更强，允许对无穷多个互斥事件求和，这是处理"抛硬币直到首次正面""泊松过程"等可数无穷情形的地基。初学者此处最容易漏掉的前提就是"互斥"二字：只有互斥事件才能把并集的概率直接拆成各自概率之和；不互斥时会重复计数，必须改用 1.2.3 的容斥。

朴素定义与公理并不矛盾：可以验证 P_naive(A)=|A|/|S| 恰好满足这三条公理，所以古典概型只是公理体系下"S 有限且每个样本点概率都等于 1/|S|"的一个特例。

### 1.2.2 由公理推出的性质推论

只用上面三条公理，无需任何额外假设，就能推出一批处处要用的性质：

空事件概率为 0：

    P(∅) = 0

补集（对立事件）法则：

    P(Aᶜ) = 1 − P(A)

单调性：若 A ⊆ B，则

    P(A) ≤ P(B)

有界性：对任意事件 A，

    0 ≤ P(A) ≤ 1

差集：若 A ⊆ B，则

    P(B \ A) = P(B) − P(A)

这些推论看似显然，但它们是"从三条公理逻辑地导出"而非"额外假设"，这一点对建立公理化思维很重要。给一个最有用的直觉与用法：补集法则 P(Aᶜ)=1−P(A) 是解题的头号利器——很多题里"至少发生一次""至少有一个"的正面计算要分很多类、极繁，而它的对立面"一次都不发生"往往只有一种情形、极易算，于是先算对立面再用 1 减。生日问题（1.4.3）正是这套路的范例。单调性的直觉则是"事件范围越大，发生的机会不会更小"——A ⊆ B 意味着 A 发生时 B 一定发生，所以 B 至少和 A 一样容易发生。

不要把 P(Aᶜ)=1−P(A) 误推广成"P(A 或 B)=1−P(A 且 B)"之类——补集法则只针对同一个事件与它的对立面，A 和 B 的对立关系并不成立这种式子。

### 1.2.3 容斥原理（两事件与一般形式）

对任意两个事件 A、B（不要求互斥），并集的概率为

    P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

三个事件时：

    P(A ∪ B ∪ C) = P(A) + P(B) + P(C) − P(A∩B) − P(A∩C) − P(B∩C) + P(A∩B∩C)

一般 n 个事件的容斥原理（inclusion-exclusion）：加上所有单个事件的概率，减去所有两两交的概率，加回所有三三交的概率，如此正负交替。

    P(⋃ᵢ Aᵢ) = Σ P(Aᵢ) − Σ_{i<j} P(Aᵢ∩Aⱼ) + Σ_{i<j<k} P(Aᵢ∩Aⱼ∩Aₖ) − ⋯

直觉是"防止重复计数"：把 A、B 的概率直接相加时，落在交集 A∩B 里的那部分被数了两次，所以要减掉一次交集把它扳回一次。三事件时先把两两交都减掉，却又把三重交 A∩B∩C 多减了，于是再加回来——这正是正负号交替的来由。可以画两个 / 三个相交的圆（韦恩图）来记忆：每块区域最终都恰好被计入一次。

这条公式和 1.2.1 的可加性是一致的：当 A、B 互斥时 A∩B=∅，P(A∩B)=0，容斥就退化成 P(A∪B)=P(A)+P(B)。所以可加性是容斥的特例。易错点：只有互斥才能省掉交集项；只要两事件可能同时发生，就绝不能直接相加，必须减去交集。它与 L1-02 离散数学里"集合基数的容斥"是同一个原理套在概率测度上（那里数的是 |A∪B|=|A|+|B|−|A∩B|），本课只是把"数元素个数"换成了"求概率"。

## 1.3 计数方法

### 1.3.1 乘法原理（计数基本原理）

若一件事分若干个相继的步骤完成，第 1 步有 n₁ 种做法，第 2 步有 n₂ 种做法，……，第 k 步有 n_k 种做法，且每步的做法数不依赖前面具体怎么选，则完成整件事的总方法数为各步方法数之积：

    n₁ × n₂ × ⋯ × n_k

例如一顿套餐有 3 种主菜、2 种饮料，则搭配总数为 3 × 2 = 6。

这是全部计数的出发点，直觉是"分步走，走法相乘"。为什么是乘而不是加？因为第一步的每一种选择，都能各自搭配第二步的全部选择，是"嵌套"而非"并列"：3 种主菜里的每一种都配得上 2 种饮料，所以 3 组各 2 种，共 6 种。与之相对，如果是"要么点主菜（3 选 1）要么点饮料（2 选 1），只点一样"，那是加法原理 3+2=5——加法用于"互斥的几类之一"，乘法用于"接连做几步"，初学者要分清是"分步（乘）"还是"分类（加）"。一个重要前提是"每步做法数与前面的选择无关"；若相关（如选完第一张牌后第二张的可选数变了），仍可用乘法，只要每一步在给定前面选择后的"当前可选数"是确定的——排列公式正是这么来的。乘法原理是 L1-02 离散数学计数章的基本原理，本课直接借用它做概率的分母/分子计数。

### 1.3.2 排列：有序地取，n!/(n−k)!

从 n 个不同对象中有序地取出 k 个（取出且排成一列，顺序不同算不同方案）的方法数，称为排列数：

    P(n, k) = n! / (n − k)! = n · (n−1) · (n−2) ⋯ (n−k+1)

特别地取全部 n 个（k = n）时为全排列 n!。约定 0! = 1。

排第 1 个位置有 n 种选择，排第 2 个位置只剩 n−1 个对象可选，……，排第 k 个位置剩 n−k+1 种，连乘即得，共 k 个因子。最小例子：从 10 个人里选出金、银、铜牌各一名（名次有别，有序），方法数为

    P(10, 3) = 10 × 9 × 8 = 720

（scipy 验证 `scipy.special.perm(10,3,exact=True)` = 720，见本小主题末脚本。）易错点是判断"顺序算不算数"：颁发金银铜牌时张三拿金、李四拿银，与张三拿银、李四拿金是两种不同结果，必须用排列；如果只是"从 10 人里挑 3 人组成一个无角色的委员会"，顺序不影响结果，就该用下面的组合。

### 1.3.3 组合与二项式系数：无序地取，C(n,k)=n!/(k!(n−k)!)

从 n 个不同对象中无序地取出 k 个（只看取到哪一组，不管取的先后）的方法数，称为组合数，也叫二项式系数，记作 C(n,k) 或 (n choose k)：

    C(n, k) = n! / ( k! · (n − k)! )

它与排列数的关系是"排列 = 组合再对取出的 k 个做全排列"，即 P(n,k) = C(n,k) · k!，所以

    C(n, k) = P(n, k) / k!

组合就是"排列里把仅仅顺序不同的方案算作同一种"，而 k 个对象内部有 k! 种排法，所以把排列数除以 k! 就消掉了顺序的重复计数。最小例子：从 5 个人里选 2 人组成一个无角色小组：

    C(5, 2) = 5! / (2! · 3!) = 10

若改成"选 2 人分别当正、副组长"（有序），则是 P(5,2)=20，恰好是组合数的 2! = 2 倍。

对称性 C(n,k)=C(n,n−k)（选出 k 个等价于选出"留下的 n−k 个"）；边界 C(n,0)=C(n,n)=1；Pascal 递推

    C(n, k) = C(n−1, k−1) + C(n−1, k)

（按"某个特定对象选不选"分两类相加）；以及二项式定理，二项式系数正是展开式的系数：

    (x + y)ⁿ = Σ_{k=0}^{n} C(n, k) · xᵏ · yⁿ⁻ᵏ

一个大数值的实例（扑克 52 张里取 5 张手牌，无序）：

    C(52, 5) = 2 598 960

（scipy 验证 `scipy.special.comb(52,5,exact=True)` = 2598960；Pascal 递推 `comb(5,2)=10` 与 `comb(4,1)+comb(4,2)=4+6=10` 一致，见脚本。）组合与二项式系数的完整纵深（Vandermonde 恒等式、可重组合、多重集等）归 L1-02 离散数学大主题6，本课只用到"有序用排列、无序用组合"这一层，用来数古典概型的 |A| 与 |S|。

## 1.4 概率的计算

### 1.4.1 古典概型：把算概率化归为数数

古典概型（等可能概型）指样本空间 S 有限、每个样本点等可能的模型；此时任意事件 A 的概率由朴素定义给出：

    P(A) = |A| / |S|

于是"算概率"完全归结为两个计数问题——数清有利结果数 |A| 与总结果数 |S|，而计数就用 1.3 的乘法原理、排列、组合。

给一个把 1.3 的组合直接用上的最小例子：一副 52 张牌里随机抽 5 张，恰好抽到 4 张 A（即"四条 A"）的概率。总手牌数 |S| = C(52,5) = 2 598 960；含 4 张 A 的手牌，A 已定（C(4,4)=1 种），第 5 张从剩下 48 张里任取（C(48,1)=48 种），故 |A|=48：

    P(四张A) = 48 / C(52,5) = 48 / 2 598 960 ≈ 1.85 × 10⁻⁵

古典概型的解题套路要固化成肌肉记忆：第一步——写清样本空间 S 是什么、并确认其中每个样本点等可能（这一步定了才能用 |A|/|S|）；第二步——把目标事件 A 翻译成集合，用计数工具数出 |A| 与 |S|。最常见的翻车点是分子分母"口径不一致"：如果分母 |S| 是按"无序取"数的（用组合），分子 |A| 也必须按无序数；若分母按有序（排列）数，分子也要有序。两边必须用同一种"数法"，否则比值无意义。

### 1.4.2 容斥在概型计算中的应用

当目标事件是"若干事件的并"（"至少满足其中之一"）且这些事件可能同时发生时，用 1.2.3 的容斥公式算并集概率：

    P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

例如掷一枚公平骰子，"掷出偶数或掷出大于 3 的数"：A={2,4,6}、B={4,5,6}、A∩B={4,6}，于是

    P(A ∪ B) = 3/6 + 3/6 − 2/6 = 4/6 = 2/3

（可直接验证 A∪B={2,4,5,6} 有 4 个元素，4/6，一致。）

容斥在概型里的价值是把"直接数并集"这种容易漏数或重数的活，拆成"数各部分再按容斥加减"。一个更能体现威力的经典用例是错位排列（把 n 封信随机塞进 n 个信封，问"至少有一封塞对"的概率）：直接数"至少一封对"要分很多类，而用容斥（对"第 i 封塞对"这 n 个事件求并）可一举算出，答案当 n 大时趋于 1 − 1/e ≈ 0.632。错位排列的完整推导归 L1-02 容斥章，本课点到其为容斥的概率应用即可。易错点仍是那句老话：只有互斥才能省掉交集项，一旦事件可能同时发生就必须减交集。

### 1.4.3 生日问题：用补集法则的反直觉范例

生日问题问：一屋子 n 个人（假设生日在 365 天里等可能、彼此独立、忽略闰年与双胞胎），"至少有两人生日相同"的概率有多大？直接算"至少有一对相同"要分很多类，改用补集法则先算对立面"n 人生日两两不同"再用 1 减：

    P(至少一对相同) = 1 − P(全不同) = 1 − (365 · 364 · 363 ⋯ (365−n+1)) / 365ⁿ

代入可算得：当 n = 23 时该概率首次超过 1/2：

    P(n = 23) ≈ 0.507，  P(n = 22) ≈ 0.476

"只要 23 人，就有过半机会撞生日"违反很多人的直觉（常有人误以为要接近 365/2 甚至 183 人），所以又叫生日悖论。破除直觉的关键在于：要比较的不是"你和某个特定人"是否同一天，而是"任意一对人"是否同一天；n 个人里能配出的对子数是 C(n,2)=n(n−1)/2，当 n=23 时已有 C(23,2)=253 对，253 次"配对比较"里出现一次撞上，就不再稀奇了。这里也再次示范了补集法则的价值——正面（至少一对相同）分类极繁，反面（全不同）用乘法原理一步写出：第 1 人生日随意（365/365），第 2 人要避开 1 个已用日期（364/365），……，第 n 人避开 n−1 个（(365−n+1)/365）。

本机实证（numpy）：精确公式给出 n=23 为 0.5073、n=22 为 0.4757；20 万次蒙特卡洛模拟得 n=23 约 0.5077，与理论吻合。环境串：基线 Py3.11.15/np2.4.6 @2026-07-26（脚本见本小主题末，仅存 scratchpad）。

### 1.4.4 蒙提霍尔问题：条件信息如何改变概率

蒙提霍尔（Monty Hall）问题：三扇门后一扇有车、两扇是羊，你先选一扇（比如 1 号）；主持人（他知道车在哪）从你没选的两扇里打开一扇必定是羊的门，然后问你要不要改选另一扇没开的门。结论是——**换门的中奖概率是 2/3，坚持不换只有 1/3**，所以应当换。

    P(换门中奖) = 2/3，  P(不换中奖) = 1/3

初学者几乎都会掉进"现在剩两扇门，各 1/2"的陷阱，误以为换不换无所谓。破除它的关键是抓住主持人这一步不是随机的、而是带信息的：他一定不会打开车门，也一定不会打开你已选的门，他的选择被这两条约束"挤"着走，于是把关于车位置的信息泄露给了另一扇没开的门。更清楚的算法：你最初选中车的概率是 1/3、选中羊的概率是 2/3。若你最初选中的是羊（2/3 情形），主持人被迫打开另一只羊，剩下那扇没开的必是车——此时换必赢；只有当你最初就选中车（1/3 情形）时换才输。所以换门赢的概率就等于"最初选到羊"的概率 2/3。换句话说，"换门"这个策略把你的胜负与"最初那一选"完全反了过来。

一个务必点明的前提（也是常见争议来源）：这个 2/3 结论依赖"主持人知道车在哪、且总是开一扇羊门、并总是提供交换"这套标准规则。若主持人是随机开门（有时不小心开到车），或只在你选中车时才好心让你换，概率会不同——所以答案对"主持人的行为规则"极其敏感。本题本质是条件概率与信息更新的入门直觉，其严格的贝叶斯计算归大主题2（条件概率与贝叶斯），本课先建立"新信息会改变概率、且要看信息是怎么产生的"这一直觉。

本机实证（numpy）：30 万次模拟得坚持不换中奖约 0.3334、换门中奖约 0.6666，与 1/3、2/3 吻合。环境串：基线 Py3.11.15/np2.4.6 @2026-07-26（脚本见本小主题末，仅存 scratchpad）。
