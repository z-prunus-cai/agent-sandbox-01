## 4.1 期望

### 4.1.1 期望的定义（离散与连续）

期望（expectation，又称均值 mean、期望值 expected value），记作 E(X) 或 μ，是随机变量 X 的"加权平均"——用每个取值自身的概率作权重。离散随机变量（取值 x，PMF 为 P(X=x)）的期望是求和：

E(X) = Σₓ x · P(X = x)

连续随机变量（PDF 为 f(x)）的期望是积分（把求和换成积分，把 PMF 换成 PDF·dx）：

E(X) = ∫₋∞^∞ x · f(x) dx

直觉有三层，初学者抓住任一层都够用。其一"重心"：把每个取值 x 看成数轴上一个质点、概率看成它的质量，E(X) 就是整根"概率质量杆"的平衡点（质心）。其二"长期平均"：独立重复这个随机实验很多次，观测值的算术平均会稳定地趋向 E(X)——这正是大数定律（大主题7）要严格化的直觉，也是"期望"这个词的由来。其三"公平价码"：若一次实验的收益就是 X，则 E(X) 是你长期每局应付/应得的公平价格。

掷一枚公平骰子，X = 点数。

E(X) = (1+2+3+4+5+6)/6 = 3.5

注意 3.5 这个值 X **永远取不到**——期望是"平均意义上的中心"，不必是某个真实可能的取值，这是初学者第一个要接受的反直觉点。

两个易错点。第一，期望不一定存在：当求和/积分不绝对收敛时（如柯西分布、圣彼得堡赌局），期望"不存在"或"为无穷"，不能硬写一个数。第二，期望是**分布的性质**，只跟 PMF/PDF 有关，跟你怎么给结果起名字无关。补充一个对非负整数值随机变量很好用的"尾和公式"（Blitzstein Ch4）：

E(X) = Σₙ₌₁^∞ P(X ≥ n)

即把期望换成"活到第 n 步及以后的概率"逐项相加，算几何分布、优惠券收集问题时常比直接按定义求和省力。

### 4.1.2 期望的线性性

期望的线性性（linearity of expectation）是本大主题最重要、最常被低估的性质：对任意随机变量 X、Y 和常数 a、b，

E(aX + b) = a·E(X) + b

E(X + Y) = E(X) + E(Y)

而且**第二式对 X、Y 是否独立毫无要求**——哪怕 X 与 Y 高度相关、甚至 Y 就等于 X，"和的期望等于期望的和"照样成立。这一点务必和方差区分：方差只有在独立（或不相关）时才可加（见 4.2.2）。

为什么"不需要独立"这么反直觉却又成立？因为期望本质是一个求和/积分算子，而求和/积分本身就是线性的——E(X+Y) 展开成对联合分布的双重求和 Σ(x+y)P(x,y)，可以拆成 Σx·P(x,y) 与 Σy·P(x,y) 两块分别求和，各自的联合概率一加就塌回边缘概率，于是得到 E(X)+E(Y)，全程没用到 P(x,y)=P(x)P(y) 这个独立性条件。独立性在这里根本没被调用，所以它可有可无。

线性性的威力在于**把"难算的整体"拆成"好算的零件之和"**。经典例子：二项分布 X ~ Binomial(n, p) 的期望。直接按 PMF 求 Σ k·C(n,k)pᵏ(1−p)ⁿ⁻ᵏ 很繁；但把 X 写成 n 个独立 Bernoulli 指示变量之和 X = I₁ + ⋯ + Iₙ（第 i 次成功记 1、失败记 0），每个 E(Iᵢ) = p，由线性性立刻得

E(X) = E(I₁) + ⋯ + E(Iₙ) = n·p

一步到位。这正是 4.4 指示变量法的雏形——它成立的唯一支柱就是"线性性不挑独立性"。

线性性只对**线性**运算成立，对非线性函数一般失效——

E(g(X)) ≠ g(E(X))   （g 非线性时）

例如 E(X²) ≠ (E X)²、E(1/X) ≠ 1/E(X)。把非线性函数的期望误当成"函数套在期望上"，是初学阶段最高频的错误，下一节 LOTUS 与 Jensen 不等式（大主题7）正是用来正确处理这类量的。

## 4.2 LOTUS 与方差

### 4.2.1 无意识统计学家法则（LOTUS）

无意识统计学家法则（Law of the Unconscious Statistician, LOTUS）回答一个高频问题：已知 X 的分布，如何求 X 的某个函数 g(X) 的期望？答案是**直接用 X 的 PMF/PDF 加权 g(x)，无需先求出 g(X) 的分布**。离散情形：

E(g(X)) = Σₓ g(x) · P(X = x)

连续情形：

E(g(X)) = ∫₋∞^∞ g(x) · f(x) dx

"无意识"这个诙谐名字的来历：人们常常"想都不想"就套这个公式，而它恰好是对的——它省去了"先推导 Y=g(X) 的分布、再按 E(Y)=Σ y·P(Y=y) 求"这一大步。若按定义死算，你得先算出 g(X) 落在每个值上的概率（这一步往往很痛苦）；LOTUS 保证：只要在 X 的世界里，把每个 x 的权重 P(X=x) 乘到 g(x) 上求和，结果就等于 E(g(X))。

掷公平骰子 X，求 E(X²)。用 LOTUS 直接对 x² 加权：

E(X²) = (1²+2²+3²+4²+5²+6²)/6 = 91/6 ≈ 15.17

对照 (E X)² = 3.5² = 12.25，可见 E(X²) ≠ (E X)²，二者差 91/6 − 49/4 = 35/12 ≈ 2.92——这个差恰好就是方差（下一节）。本机数值核对（scipy/numpy，环境 Py3.11.15 np2.4.6 scipy1.17.1 @2026-07-26）给出 E(X²)=15.1667、(E X)²=12.25，与手算一致。

LOTUS 是计算方差、矩、MGF 的**共同工具**——方差是 g(x)=(x−μ)² 的 LOTUS，第 n 阶矩是 g(x)=xⁿ 的 LOTUS，MGF 是 g(x)=e^{tx} 的 LOTUS。抓住这一点，后面三节就是同一个法则套不同的 g。

### 4.2.2 方差

方差（variance），记作 Var(X)、σ² 或 V(X)，度量 X 偏离其均值 μ = E(X) 的平均平方距离，即"散开程度"。定义式与计算式（两者恒等）：

Var(X) = E[(X − μ)²]

Var(X) = E(X²) − (E X)²

第二式（"平方的期望减去期望的平方"）由第一式展开 (X−μ)² = X² − 2μX + μ² 后用线性性即得，是实际计算中最常用的形式。方差恒 ≥ 0（平方的期望非负），且 Var(X)=0 当且仅当 X 几乎必然是常数。

期望告诉你"中心在哪"，方差告诉你"数据离中心平均有多远"（以平方为尺度）。取平方而非绝对值有两个原因——数学上平方可微、可展开、能配合线性性推公式；且平方放大了大偏差的惩罚，符合许多应用对"离群"的敏感需求。

仿射变换下的方差规则（务必与期望的线性性对照记）：

Var(aX + b) = a²·Var(X)

平移 b 不改变离散程度（整体挪动不影响"散开"），故 b 消失；缩放 a 使距离放大 a 倍、平方后放大 a² 倍，故系数是 a² 而非 a。

最关键的易错点——**方差不是无条件可加的**。只有当 X、Y 独立（更弱地，不相关）时才有

Var(X + Y) = Var(X) + Var(Y)   （仅当 X、Y 独立/不相关）

一般情形要补协方差项 Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)（详见大主题5）。反例一目了然：取 Y = X，则 Var(X+Y)=Var(2X)=4Var(X)，而不是 2Var(X)。这与 4.1.2"期望的线性性不挑独立"形成鲜明对比：**期望的和永远可加，方差的和只有独立时才可加**——这是本大主题最该刻进脑子的一条辨析。

本机核对（scipy.stats，同上环境）：常见分布的方差与教材一致——Bernoulli(0.3) 方差 0.21 = p(1−p)；Binomial(10,0.3) 方差 2.1 = np(1−p)；Poisson(4) 均值与方差都是 4；Exponential(率 1/2，scipy scale=2) 均值 2、方差 4 = 1/λ²；Normal(1,σ=3) 方差 9 = σ²。

### 4.2.3 标准差

标准差（standard deviation, SD），记作 σ 或 SD(X)，是方差的算术平方根：

SD(X) = √Var(X)

为什么要在方差之外再定义标准差？因为方差的**量纲是原变量量纲的平方**（若 X 以"米"计，Var(X) 的单位是"平方米"），不便直接解读；开平方后，标准差回到与 X、与均值相同的量纲，可以和期望摆在一起说"数据大致落在 μ ± σ 的范围"，直觉上更好用。

对钟形（近正态）数据，约 68% 落在 μ±σ、约 95% 落在 μ±2σ 内（"68–95–99.7 经验法则"，严格版见大主题3 正态分布与大主题7 CLT）。易错点：标准差不是"平均绝对偏差"E|X−μ|——后者是另一个量，一般比 σ 小；标准差是"均方偏差再开根"，因先平方、再平均、后开根的顺序，对大偏差更敏感。

## 4.3 矩与矩生成函数

### 4.3.1 矩

随机变量 X 的第 n 阶（原点）矩（moment）是 Xⁿ 的期望；第 n 阶中心矩是 (X−μ)ⁿ 的期望：

E(Xⁿ)   （第 n 阶原点矩）

E[(X − μ)ⁿ]   （第 n 阶中心矩）

矩是"用一串数字逐级刻画分布形状"的工具：一阶原点矩 E(X)=μ 就是期望（中心位置）；二阶中心矩 E[(X−μ)²] 就是方差（离散程度）；三阶、四阶中心矩进一步刻画"偏斜"和"尾部厚薄"（见下一节）。直觉上，越高阶的矩越关注分布"更外围、更极端"的行为，因为 xⁿ 在 n 大时会极度放大远离原点的取值。

用 LOTUS 计算矩：E(Xⁿ) 就是取 g(x)=xⁿ 的 LOTUS，即 Σ xⁿP(X=x) 或 ∫ xⁿf(x)dx。原点矩与中心矩可互相换算，最常用的是由前两阶原点矩得方差：Var(X)=E(X²)−(E X)²（即二阶中心矩 = 二阶原点矩 − 一阶原点矩的平方）。易错点：高阶矩不一定存在——重尾分布（如自由度小的 t 分布）可能只有低阶矩存在、高阶矩发散；不能默认所有矩都是有限数。

### 4.3.2 偏度与峰度

偏度（skewness）与峰度（kurtosis）是用**标准化后的三阶、四阶中心矩**刻画分布形状的无量纲指标。偏度：

Skew(X) = E[(X − μ)³] / σ³

峰度：

Kurt(X) = E[(X − μ)⁴] / σ⁴

除以 σ³、σ⁴ 是为了消去量纲和尺度，使它们只反映"形状"而与单位、放缩无关。

偏度度量"不对称方向"：正偏（右偏）表示右侧尾巴更长、少数很大的值把均值拉到中位数右边（如收入分布）；负偏反之；对称分布（如正态）偏度为 0。峰度度量"尾部厚薄/尖峰程度"：正态分布的峰度恰为 3，因此常用**超额峰度**（excess kurtosis = Kurt − 3）作为"相对正态"的基准——超额峰度 >0（尖峰厚尾，leptokurtic）意味着极端值比正态更频繁，<0（平峰薄尾，platykurtic）则更少。

不同软件/教材对峰度是否已减 3 约定不一——有的 kurtosis() 返回超额峰度（默认减 3），有的返回原始峰度。使用前务必确认约定，否则会把"正态基准"错位 3。本机核对（scipy.stats，同上环境）：指数分布的偏度为 2.0、超额峰度为 6.0（右偏、厚尾，与理论一致）；标准正态的超额峰度为 0.0（scipy 的 stats(moments='k') 默认返回超额峰度）。

### 4.3.3 矩生成函数（MGF）

矩生成函数（moment generating function, MGF），记作 M(t) 或 Mₓ(t)，把 X 的所有矩"打包"进一个关于 t 的函数：

Mₓ(t) = E(e^{tX})

（要求在 t=0 的某个开邻域内该期望有限，MGF 才"存在"。）它的名字来自"生成矩"这一核心性质——**在 t=0 处求 n 阶导，就得到第 n 阶矩**：

E(Xⁿ) = Mₓ^{(n)}(0)

道理是把 e^{tX} 按泰勒级数展开 e^{tX}=Σ (tⁿ/n!)Xⁿ，取期望后 M(t)=Σ (tⁿ/n!)E(Xⁿ)，第 n 阶矩正好是 tⁿ/n! 的系数，求 n 次导并令 t=0 即把它单独取出。所以只要求出一个 M(t)、再逐次求导，就能一网打尽所有矩，往往比逐个按 LOTUS 硬算省力。

MGF 还有两条极其有用的性质。其一**唯一性**：若两个随机变量的 MGF 在 0 的邻域内相等，则它们**同分布**——这是证明"某个和/变换服从某分布"的标准武器。其二**独立和的 MGF 相乘**：X、Y 独立时

M_{X+Y}(t) = Mₓ(t) · M_Y(t)

因为 E(e^{t(X+Y)}) = E(e^{tX}e^{tY}) = E(e^{tX})E(e^{tY})（独立才能拆开乘积期望）。两条合起来，就能优雅地证明"独立正态之和仍是正态""独立泊松之和仍是泊松"等结论（大主题5 卷积的 MGF 捷径）。

MGF 不一定存在（重尾分布如柯西、对数正态在 t>0 处期望发散），此时改用恒存在的特征函数 φ(t)=E(e^{itX})（把 t 换成虚数 it）；本课只需知道"MGF 可能不存在、有替代品"即可，不深入。

本机符号核对（sympy，同上环境）：指数分布（率 λ）的 MGF 为 M(t)=λ/(λ−t)（t<λ，由定义积分 ∫₀^∞ e^{tx}λe^{−λx}dx 得到，sympy 在 t<λ 分支给出同一结果），对其求一、二阶导并代 t=0 得 E(X)=1/λ、E(X²)=2/λ²，故 Var=1/λ²；正态 N(μ,σ²) 的 MGF 为 M(t)=exp(μt+σ²t²/2)，求导得 E(X)=μ、E(X²)=μ²+σ²、Var=σ²——全部与教材公式吻合。

## 4.4 指示随机变量

### 4.4.1 指示随机变量与"基本桥"

事件 A 的指示随机变量（indicator random variable），记作 I_A 或 𝟙_A，是一个只取 0/1 的随机变量：A 发生时取 1，不发生时取 0。它的关键性质是**期望等于概率**（Blitzstein 称之为"基本桥"fundamental bridge）：

E(I_A) = 1·P(A) + 0·P(Aᶜ) = P(A)

也就是说，"求某事件的概率"与"求对应指示变量的期望"是同一件事的两种说法。

为什么这条平平无奇的等式如此重要？因为它把**概率问题翻译成期望问题**，从而让"期望的线性性"这门重武器能用到概率/计数上。指示变量还有两个顺手的小性质：I_A² = I_A（0、1 平方不变，故 E(I_A²)=E(I_A)=P(A)，可直接算出 Var(I_A)=P(A)−P(A)²=P(A)P(Aᶜ)，这正是 Bernoulli 的方差）；I_{A∩B}=I_A·I_B、I_{A∪B}=I_A+I_B−I_A I_B，把集合运算变成算术，便于推导容斥等式。

本机核对（numpy，同上环境）：掷公平骰子、A={偶数}，E(I_A) 数值为 0.5，等于 P(偶数)=0.5，"基本桥"成立。

### 4.4.2 指示变量法与期望的组合技巧

指示变量法（indicator method）是一套威力惊人的套路：**当要求"某类事件发生的次数"的期望时，把这个计数写成一堆指示变量之和，再逐个用"基本桥 + 线性性"求和**。设总数

X = I₁ + I₂ + ⋯ + Iₙ

其中 Iᵢ 指示"第 i 个位置/对象是否满足条件"，则由期望的线性性（不需要各 Iᵢ 独立！）：

E(X) = E(I₁) + ⋯ + E(Iₙ) = P(A₁) + ⋯ + P(Aₙ)

于是"数期望个数"就退化成"把每个位置发生的概率加起来"，即便这些事件彼此高度相关也照用不误——这正是指示变量法最反直觉、也最强大的地方（相关性只影响方差，不影响期望的和）。

经典例子一——二项分布均值：X~Binomial(n,p) 写成 n 个 Bernoulli 指示之和，E(X)=n·p（本机：n=10,p=0.3 得 3.0）。

经典例子二——随机排列的不动点（配对/错位问题）：n 封信随机装进 n 个信封，问"恰好装对"的信封平均有几个？令 Iᵢ 指示第 i 封装对，P(Iᵢ=1)=1/n（第 i 封等概率落在 n 个信封之一），故

E(装对数) = Σᵢ₌₁ⁿ (1/n) = n·(1/n) = 1

无论 n 多大，平均恰好装对 1 封——一个漂亮到令人意外的结论。这里各 Iᵢ **并不独立**（一封装对会略微影响其他），但线性性完全不受影响，若按联合分布硬算将极其繁琐。本机模拟（numpy，n=20、20 万次，同上环境）得平均不动点 0.9994 ≈ 1，与理论一致。

**看到"期望有多少个……"，先设指示变量、再对概率求和**；这是概率论里性价比最高的技巧之一，后续优惠券收集、图论中期望边数/三角形数等问题都靠它。要留心的边界：指示变量法直接给的是**期望**；若还想求方差，因各 Iᵢ 通常相关，必须补上所有两两协方差项 Cov(Iᵢ,Iⱼ)（大主题5），不能简单相加。
