## 6.1 给定事件的条件期望

### 6.1.1 以事件为条件的期望

给定事件 A（且 P(A)>0），随机变量 Y 在 A 条件下的条件期望（conditional expectation given an event），记作 E(Y|A)，就是把普通期望里的"无条件概率"全部换成"以 A 为条件的概率"后重算的加权平均。离散情形：

E(Y | A) = Σᵧ y · P(Y = y | A)

连续情形（用 A 条件下的条件密度 f_{Y|A}）：

E(Y | A) = ∫₋∞^∞ y · f_{Y|A}(y) dy

其中条件概率沿用大主题2 的定义 P(Y=y | A) = P(Y=y, A) / P(A)。

直觉一句话：**先把样本空间"裁剪"到只剩 A 发生的那个小世界，在这个小世界里按重新归一化的概率求平均。** 因为已经确知 A 发生了，A 之外的结果不再可能，所以要把它们的概率清零、并把剩下的概率等比例放大（除以 P(A)）使其重新加总为 1——这正是条件概率在做的事，条件期望只是拿它当权重再加权一次。

一个最小例子：掷一枚公平骰子，Y = 点数，A = {点数为偶}。在"已知是偶数"的小世界里，2、4、6 各以概率 1/3 出现，于是

E(Y | 偶) = 2·(1/3) + 4·(1/3) + 6·(1/3) = 4

它比无条件期望 E(Y)=3.5 大，符合直觉：知道"是偶数"这一信息后，我们对点数的平均预期应当上调。本机核对（numpy，掷公平骰子取偶数子样本，环境 Py3.11.15/np2.4.6/scipy1.17.1 @2026-07-26）给出 E(Y|X=1 组)、E(Y|X=3 组) 等条件均值与理论一致（见 6.3 验证脚本同源输出）。

易错点：E(Y|A) 是一个**普通的数**（不是随机变量）——因为 A 是一个确定的事件，条件一旦给定，平均值就唯一确定了。这一点务必和 6.2 的 E(Y|X) 区分开：那里的条件是随机变量 X，结果才会变成随机变量。另一个易错点：条件期望要求 P(A)>0，对 P(A)=0 的事件（如连续变量取某个精确点）需要用条件密度而非上面的比值式来定义。

### 6.1.2 用事件划分做分步求平均（全期望公式的事件版）

当直接求 E(Y) 很难、但"分情况"后每种情况下的 E(Y|Aᵢ) 都好算时，可以用一个**互斥且穷尽的事件划分** A₁,…,Aₙ（即这些事件两两不交、并起来是整个样本空间）把总期望拆开——这就是全期望公式（law of total expectation）的事件形式，是大主题2 全概率公式的期望版：

E(Y) = Σᵢ E(Y | Aᵢ) · P(Aᵢ)

**把人群按 Aᵢ 分成若干组，先算每组的组内平均 E(Y|Aᵢ)，再以各组人数占比 P(Aᵢ) 为权重把组内平均加权平均起来，就得到全体平均。** 这与"全班平均分 = 各小组平均分按人数加权"是同一件事——它成立的根据正是 6.1.1 那个"小世界"视角：每个 Aᵢ 是一个小世界，总世界是这些小世界按概率拼起来的。

一个最小例子：一个工厂两条产线，A₁ 产线出货占 70%、次品率使得每件次品数期望 E(Y|A₁)=0.02；A₂ 产线占 30%、E(Y|A₂)=0.05。随机抽一件的期望次品数

E(Y) = 0.02 · 0.7 + 0.05 · 0.3 = 0.029

不必去求 Y 的整体分布，分组算再加权即可。

易错点：划分必须**既互斥又穷尽**——漏掉一种情况（不穷尽）或情况之间重叠（不互斥）都会算错；权重必须是 P(Aᵢ)（各组的概率占比），不是简单地把 E(Y|Aᵢ) 算术平均。这条公式是通往 6.2 塔性质的跳板：把这里"离散的事件划分"换成"由随机变量 X 的取值诱导出的划分"，就升级为 E(Y)=E(E(Y|X))。

## 6.2 条件期望作为随机变量

### 6.2.1 E(Y|X) 是一个随机变量

把 6.1 里的"条件"从一个固定事件换成另一个随机变量 X，就得到本大主题最核心、也最让初学者卡壳的对象：以 X 为条件的 Y 的条件期望，记作 E(Y|X)。它的定义分两步。第一步，对 X 的每一个可能取值 x，用 6.1 的方法算出一个普通的数——记

g(x) = E(Y | X = x)

第二步，把这个"输入 x、输出条件均值"的函数 g 作用在随机变量 X 上：

E(Y | X) = g(X)

关键结论：**E(Y|X) 是 X 的一个函数，因此它本身是一个随机变量，而不是一个数。**

这正是初学者最大的难点，反复咀嚼下面这句话就能通：E(Y|X=x)（右边固定了 x）是一个数——它是"已知 X 恰好等于 x 时 Y 的平均"；但 E(Y|X)（不指定 x）是一个随机变量——因为我们还没观测 X 到底取什么，X 会随机地落在某个 x 上，落在哪里，g(X) 就跟着取 g(x) 这个值。可以这样想：**E(Y|X) 是"等你告诉我 X 是多少、我立刻报给你的那个关于 Y 的最佳平均预测"**；在 X 揭晓之前，这个预测本身是不确定的、会随 X 波动，所以是随机变量。

一个最小例子：X ~ 均匀取 {1,2,3}，且在给定 X=x 时 Y 的均值恰好是 x（例如 Y|X=x ~ 正态，均值 x）。那么 g(x)=E(Y|X=x)=x，于是

E(Y | X) = X

这是一个随机变量：X 取 1 时它是 1，取 2 时是 2，取 3 时是 3，各以概率 1/3 出现。它自己就有分布、有期望、有方差——6.2.2 和 6.3.2 正是对这个随机变量再取期望、再取方差。

两个易错点。其一，写 E(Y|X) 时**不要在里面塞进一个具体数值**——一旦写成 E(Y|X=2) 那就退回成一个数了，两种记号含义不同。其二，别把 E(Y|X) 当成"含未知量的表达式"——它是一个有明确分布的随机变量，可以求 E[E(Y|X)]、Var(E(Y|X)) 这些量，下面两节就要用到。

### 6.2.2 塔性质（全期望公式 / Adam's law）

既然 E(Y|X) 是随机变量，就可以对它再取一次期望。塔性质（tower property，Blitzstein 称之为 **Adam's law**，又名全期望公式、迭代期望法则 law of iterated expectations）说：对这个随机变量取期望，恰好还原出 Y 的无条件期望：

E( E(Y | X) ) = E(Y)

直觉与 6.1.2 完全一致，只是把"离散事件划分"换成"由 X 的取值诱导的划分"：**先按 X 分组、在每组内算 Y 的局部平均（这一层由内层 E(Y|X) 完成），再对这些局部平均按 X 的分布求平均（外层 E(·) 完成），两层平均下来就等于对 Y 一次性求的总平均。** 名字"塔"来源于两层期望像塔一样叠起来；"迭代/smoothing"是指外层期望把内层随 X 的波动"抹平"回一个数。

离散展开就是 6.1.2 那条公式（把 Aᵢ 取成事件 {X=x}）：

E(Y) = Σₓ E(Y | X = x) · P(X = x)

一个最小例子承接 6.2.1：E(Y|X)=X 且 X 均匀取 {1,2,3}，则

E(Y) = E( E(Y|X) ) = E(X) = (1+2+3)/3 = 2

本机核对（numpy，两阶段模型 X~均匀{1,2,3}、Y|X=x~Normal(x, 方差 x)，样本量 5,000,000，环境同上）：直接算 E(Y)=1.9996，按塔性质算 E(E(Y|X))=E(X)=1.9996，两者一致（理论 2.0），塔性质成立。

塔性质是概率论里"分步求期望"的万能拆解器，很多"看似要对联合分布硬积分"的期望，一旦选对了要条件化的 X，就能拆成"内层好算 + 外层好算"。易错点：内外两层的期望是**对不同对象**求的——内层对 Y（在 X 固定下）、外层对 X；初学者容易把两层混成一层而漏掉对 X 求平均这一步。

### 6.2.3 条件期望的运算性质（取出已知因子、线性性、独立退化）

E(Y|X) 作为随机变量，服从几条和普通期望平行、但多了"X 已知"这层含义的运算规则，掌握它们才能顺畅地做拆解。

线性性（与普通期望一样，且不要求独立）：

E(aY + bZ | X) = a·E(Y | X) + b·E(Z | X)

取出已知函数（"taking out what is known"）——凡是 X 的函数 h(X)，在以 X 为条件时都当作已知常数，可以直接提到条件期望外面：

E( h(X) · Y | X ) = h(X) · E(Y | X)

独立时退化为无条件期望——若 Y 与 X 独立，则知道 X 对 Y 的平均毫无帮助：

E(Y | X) = E(Y)   （Y 与 X 独立时）

前两条的直觉都来自"以 X 为条件即把 X 当成已经知道的量"：既然 X 已知，h(X) 就是一个确定的数，自然能像常数一样提出来；线性性则单纯继承求和/积分的线性。第三条的直觉是"独立意味着 X 不携带关于 Y 的任何信息"，所以条件平均塌回无条件平均——注意此时 E(Y|X) 从"随 X 变化的随机变量"退化成了"常数 E(Y)"。

这三条性质是通往回归与预测理论（L5-02）的接口，值得点明：在"用 X 预测 Y"的问题里，可以证明**在均方误差意义下，Y 的最佳预测子恰好是条件期望 E(Y|X)**——即在所有 X 的函数 g(X) 中，E[(Y−g(X))²] 由 g(X)=E(Y|X) 取到最小。这就是"回归函数（regression function）= 条件期望"这一说法的来历，也是线性回归、树模型等一切监督学习"预测 Y 的均值"的理论原点。本课点到接口为止，具体建模留给 L5-02。易错点：取出已知因子只对**X 的函数**成立，不能把含 Y 的因子随便提出来。

## 6.3 条件方差

### 6.3.1 条件方差 Var(Y|X)

仿照条件期望，可以定义以 X 为条件的 Y 的条件方差（conditional variance），记作 Var(Y|X)：先在"给定 X"的小世界里对 Y 求方差，做法就是把 6.2 的 E(·|X) 套进方差的计算式：

Var(Y | X) = E(Y² | X) − ( E(Y | X) )²

等价地，它是"以 X 为条件的、Y 对其条件均值的平方偏差的条件期望"：

Var(Y | X) = E[ (Y − E(Y|X))² | X ]

和 E(Y|X) 一样，**Var(Y|X) 也是 X 的函数、因而是一个随机变量**：它度量的是"在已知 X 之后，Y 还剩多少不确定性"，而这个剩余不确定性本身可以随 X 不同而不同。

把人群按 X 分组，Var(Y|X=x) 是"第 x 组组内的方差"（组内 Y 散得多开）；不指定 x 时，Var(Y|X) 就是"你落在哪一组、就取那一组的组内方差"的随机变量。承接 6.2.1 的例子（Y|X=x 的方差恰为 x），则

Var(Y | X) = X

X 取 1/2/3 时组内方差分别是 1/2/3——组越"大"，组内越散。

易错点：Var(Y|X) 与后面要用的 E(Var(Y|X))、Var(E(Y|X)) 是三个不同的量，务必分清——Var(Y|X) 是随机变量；E(Var(Y|X)) 是"把各组组内方差按组概率加权平均"得到的一个数；Var(E(Y|X)) 是"各组组内均值 g(x) 这个随机变量自身的方差"，也是一个数。下一节的全方差公式正是把这三者串起来。

### 6.3.2 全方差公式（EVE / Eve's law）

全方差公式（law of total variance，Blitzstein 称 **Eve's law**，又名条件方差公式、方差分解公式）把 Y 的总方差分解成两块：

Var(Y) = E[ Var(Y | X) ] + Var[ E(Y | X) ]

用一句话记住这两块：**总波动 = 组内波动的平均 ＋ 组间均值的波动**。第一项 E[Var(Y|X)] 是"各组组内方差的加权平均"（组内的、无法靠知道 X 消除的不确定性，常称未解释方差 / within-group variability）；第二项 Var[E(Y|X)] 是"各组组内均值 g(X) 这个随机变量的方差"（组与组之间中心不同带来的波动，常称已解释方差 / between-group variability）。

直觉与"为什么两项恰好加起来等于总方差"：想象 Y 的总散布来自两种不同来源——一部分是"就算你已经知道 X 属于哪一组，组内的点仍然彼此不同"（组内散布），另一部分是"不同组的中心本来就摆在不同位置"（组间散布）。把方差按这两种来源正交分解，交叉项恰好因塔性质而消失（可由 Var(Y)=E(Y²)−(EY)² 配合 Adam's law 逐项展开验证），于是干净地得到两项之和。

一个易被误用的辨析点：只有当 X 完全决定 Y（Y 是 X 的函数）时，组内方差才为 0、第一项消失、Var(Y)=Var(E(Y|X))；反过来若 Y 与 X 独立，则 E(Y|X)=E(Y) 是常数、第二项 Var(E(Y|X))=0，全部方差都落在第一项 E[Var(Y|X)]=Var(Y)。两个极端帮助记忆两项各自代表什么。

承接 6.2/6.3.1 的例子：E(Y|X)=X、Var(Y|X)=X，X 均匀取 {1,2,3}（E(X)=2、Var(X)=2/3）。于是

Var(Y) = E[Var(Y|X)] + Var[E(Y|X)] = E(X) + Var(X) = 2 + 2/3 = 8/3 ≈ 2.6667

本机核对（numpy，同 6.2.2 的两阶段模型、样本量 5,000,000，环境 Py3.11.15/np2.4.6/scipy1.17.1 @2026-07-26）：直接 Var(Y)=2.6655；分解两项 E[Var(Y|X)]=1.9993（理论 2.0）、Var[E(Y|X)]=0.6671（理论 2/3≈0.6667），两项之和 2.6663——与直接算的总方差一致，Eve's law 成立。

这条公式是回归与预测理论（L5-02）的核心地基，值得点明接口：既然 E(Y|X) 是用 X 预测 Y 的最佳预测子（6.2.3），那么 E[Var(Y|X)] 正是"即便用上最优预测子、也无法消除的那部分预测误差方差"（不可约误差 irreducible error），而 Var[E(Y|X)] 正是"X 能解释掉的那部分 Y 的波动"。回归里的判定系数 R²、方差分析（ANOVA，大主题10）的组间/组内平方和分解，本质都是这条全方差公式的应用。易错点：全方差不是"把条件方差直接取期望"就完事——**必须补上第二项 Var(E(Y|X))**，漏掉它会系统性低估总方差，这是初学者最常见的错误。
