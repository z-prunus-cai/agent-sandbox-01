## G-05.1 纹理坐标 (u,v) 与参数化、寻址模式（wrap/clamp）

### G-05.1.1 纹理映射：把一张图像按 (u,v) 贴到表面上

纹理映射（texture mapping）是把一张预先准备好的图像（纹理，texture）"贴"到三维表面上，从而在不增加几何复杂度的前提下给表面添加颜色与细节。做法是给网格每个顶点附一对纹理坐标 (u,v)——这是一个二维参数，把顶点在几何空间里的位置对应到纹理图像里的一个位置。光栅化时（G-03）用重心坐标把顶点的 (u,v) 插值到三角形内每个片元，再拿插值出的 (u,v) 去纹理图像里查出颜色。

纹理坐标按惯例取归一化区间

(u, v) ∈ [0, 1] × [0, 1]

不管纹理实际是 256×256 还是 4096×4096 像素，(0,0) 指向纹理的一个角、(1,1) 指向对角，与分辨率解耦。

初学者最容易混淆的一点是：(u,v) 是"贴图上的地址"，不是"屏幕上的位置"，也不是"世界里的位置"。可以把纹理想成一张贴纸、把 (u,v) 想成"贴纸上的坐标"，美术在建模时决定"模型表面每一点对应贴纸上哪一点"。查纹理时用 (u,v) 乘以纹理分辨率就得到具体像素（纹素，texel）位置。一个常见坑是不同 API 的 v 轴方向不一致：OpenGL 约定 (0,0) 在纹理左下角、v 向上增长，而 Direct3D / 很多图像文件约定原点在左上角、v 向下——贴图上下颠倒往往就是这个约定没对齐，RTR4 与各 API 文档都单列提醒这一点。

### G-05.1.2 参数化（parameterization）与 UV 展开

参数化指的是"如何把三维表面上的每一点映射到 (u,v) 平面上的一点"这套对应关系本身。对球、圆柱这类解析曲面可以用公式直接给出（如球面用经纬度当 (u,v)）；对一般的三角网格，则由美术在建模软件里做 UV 展开（UV unwrapping）——像把一个立体纸盒沿棱剪开、摊平到一张平面上，摊平后每个顶点落在平面哪个位置，就是它的 (u,v)。

好的参数化要尽量少拉伸、少接缝。拉伸会让纹理在某些方向被压扁或撑大；接缝（seam）是剪开处，两侧纹理坐标不连续，处理不好会露出可见的缝。

理解这一点的关键在于：任何非可展曲面（比如球面）都无法无失真地摊平到平面，这是数学上的必然（就像世界地图必然有变形）。所以参数化总是在"拉伸"和"接缝"之间权衡。初学者阶段只需记住：(u,v) 不是自动生成的、而是"人为规定的一层对应关系"，同一个模型换一套 UV 展开，同一张纹理贴上去效果就完全不同。这也解释了为什么建模里 UV 展开是一道独立且费工的工序。

### G-05.1.3 寻址模式（wrap/clamp/mirror/border）：坐标越界怎么办

寻址模式（addressing / wrapping mode）规定当采样坐标落到 [0,1] 之外时如何取值。这在两种情况下发生：故意让 (u,v) 超过 1 来平铺（tiling）小纹理铺满大表面；或者插值/计算误差让坐标略微越界。常见有四种。repeat（wrap）对坐标取小数部分，纹理无限平铺重复，(u=1.3) 等价于 (u=0.3)。clamp（clamp-to-edge）把坐标夹到 [0,1]，越界处取最近的边缘纹素，效果是边缘颜色向外拉伸。mirror（mirrored repeat）每隔一个周期翻转一次，让平铺接缝处镜像对齐、消除硬缝。border（clamp-to-border）在越界处返回一个指定的边框颜色，而不取纹理里的值。

直觉上，repeat 适合砖墙、地板这类天然可平铺的图案；clamp 适合一张不该重复的贴图（比如一张脸、一个 logo），防止边缘漏出对面的像素。一个高频坑与过滤有关：在纹理边缘做双线性过滤时，repeat 模式会把左右两端的纹素混在一起（可能产生错误的接缝颜色），而 clamp 不会——所以非平铺纹理通常要配 clamp-to-edge。CMU 15-462 与 RTR4 都把 wrap/clamp/mirror 作为基本寻址选项列出；具体命名（GL 的 `GL_REPEAT`/`GL_CLAMP_TO_EDGE` vs D3D 的 `WRAP`/`CLAMP`）随 API 不同，语义一致。

### G-05.1.4 纹素中心与坐标约定

一张 N×N 的纹理有 N×N 个纹素，每个纹素占据一个小方格，其颜色约定采样在纹素中心。把归一化坐标 u 换算成纹素索引时要注意半像素偏移：第 i 个纹素的中心对应

u_center(i) = (i + 0.5) / N

反过来，给定 u，落在的纹素中心并不是简单的 u·N，而要考虑这半格偏移，双线性过滤正是取相邻两个纹素中心做插值。

初学者不必立刻精算这半像素，但要知道它存在：很多"贴图整体偏移半个纹素""边缘发虚"的 bug 根源就是把纹素当成了"点"而非"占一格、采样在中心"。这与 G-03 里像素采样点取像素中心 (x+0.5, y+0.5) 是同一种"格子中心"约定，两处一致地贯穿整条管线。

## G-05.2 纹理过滤（最近/双线性/三线性）与 mipmap 链

### G-05.2.1 为什么要过滤：放大与缩小两种失配

一个片元对应纹理上的一块区域（footprint），而这块区域几乎从不恰好等于一个纹素。过滤（filtering）就是决定"该怎么把纹素的值组合成这个片元要的颜色"。分两种情形，需分别处理：

放大（magnification）：纹理相对屏幕被拉大，一个纹素覆盖屏幕上好几个像素，多个相邻片元落进同一个纹素——问题是取值太"块状"，需要在纹素之间平滑。

缩小（minification）：纹理相对屏幕被缩小，一个片元覆盖纹理上一大片纹素——问题是这一片纹素只用一个采样点代表，会漏掉大量信息、产生走样（G-04 的采样不足），表现为远处纹理闪烁、摩尔纹。

初学者要抓的关键分野是：放大是"信息太少要插值补"，缩小是"信息太多要平均掉"。这两个问题的解法不同——放大靠双线性插值，缩小靠 mipmap 预滤波，下面分别讲。判断当前是放大还是缩小，硬件靠估计片元的纹理 footprint 大小（相邻像素间 (u,v) 的变化率）。

### G-05.2.2 最近邻过滤 vs 双线性过滤

最近邻（nearest / point sampling）取离采样点最近的那一个纹素的值，不做任何混合。双线性过滤（bilinear filtering）取采样点周围最近的 2×2 四个纹素，按到采样点的距离做加权平均。设采样点在四个纹素中心构成的小方格里的小数偏移为 (fx, fy)，四角纹素为 T₀₀、T₁₀、T₀₁、T₁₁，双线性结果为：

c = (1−fx)(1−fy)·T₀₀ + fx(1−fy)·T₁₀ + (1−fx)fy·T₀₁ + fx·fy·T₁₁

最近邻的结果是块状的（放大时看到明显的方块），双线性是平滑的。

直觉上双线性就是先在 x 方向做两次线性插值（上下两行各插一个中间值），再在 y 方向把这两个中间值插一次，故名"双"线性。这与 G-03 的重心坐标插值同属"线性加权"思想，只是这里权重来自到四个纹素的距离。什么时候反而要最近邻？像素艺术、色彩查找表（LUT）、以及"每个纹素代表一个离散标签"的场合——这些不能混合，混合会得到无意义的中间值。一处 numpy 加固（脚本见 5.2 节末）：对一个 2×2 灰度块，采样点取正中 (0.5,0.5) 双线性得 0.5、取 (0.25,0.0) 得 0.25，符合线性加权预期。

### G-05.2.3 mipmap 链：为缩小预先算好的多级降采样

mipmap 是把一张纹理预先逐级减半分辨率、算好并存起来的一整条金字塔：256×256 → 128×128 → 64×64 → … → 1×1，每一级（level）都是上一级做了盒式（平均）降采样的结果。缩小时不再从原始高分辨率纹理里稀疏采样（那会走样），而是选一个分辨率与片元 footprint 匹配的 mip 级去取值——这一级已经把该区域的纹素预先平均好了，等于做了预滤波（对应 G-04 的预滤波抗锯齿）。

mipmap 的额外内存开销是原图的 1/3。原因是每级面积是上一级的 1/4，无穷级数

1/4 + 1/16 + 1/64 + ⋯ = 1/3

所以全链只比单张原图多存 1/3。

对一张 256×256 的纹理，mip 层数是

levels = floor(log₂ 256) + 1 = 9

（从 256×256 一直到 1×1 共 9 级；numpy 逐级减半计数确认为 9，见节末）。理解 mipmap 的关键在于"用空间换时间且换正确性"：多花 1/3 内存，把"运行时对一大片纹素做平均"这件昂贵又易走样的事，提前离线做好、运行时只需查表。为什么减半降采样要取平均而不是抽样？因为平均才等于对高频做了低通滤波、真正去掉了会折叠成走样的高频分量——直接抽样只是换个稀疏采样，走样照旧。

### G-05.2.4 三线性过滤：在 mip 级之间也插值

选定 mip 级时，理想的连续级号 λ 通常不是整数（比如片元 footprint 介于 level 2 和 level 3 之间）。若直接四舍五入到最近整数级，物体表面上从一个 mip 级切换到另一个级的边界会出现可见的突变带（mip banding）。三线性过滤（trilinear filtering）在相邻两个整数 mip 级上各做一次双线性（共 8 个纹素），再按 λ 的小数部分在这两级之间做一次线性插值，故"三"线性 = 两次双线性 + 一次跨级线性。

三线性消除了 mip 级之间的硬边界，代价是每次采样读 8 个纹素而非 4 个。初学者可以这样记：双线性解决"同一张图里相邻纹素之间"的平滑，三线性再多解决一层"相邻两张分辨率的图之间"的平滑。连续 mip 级号 λ 由片元的纹理 footprint（相邻像素 (u,v) 变化率的最大值）取对数估计，footprint 越大选越粗的级。

### G-05.2.5 各向异性过滤（各向异性时的补充）

当表面以掠射角（近乎侧看）观察时，片元的纹理 footprint 不是各方向等大的方块，而是被拉长的细长形（比如远处地面）。mipmap 只能按"最长那条边"选级，于是在短边方向过度模糊——这就是地面远处发糊的成因。各向异性过滤（anisotropic filtering）沿 footprint 的长轴方向多次采样 mipmap 再平均，从而在保留细节的同时压掉走样。

各向异性过滤是当代实时渲染缺省开启的选项，采样次数（如 2×/4×/8×/16×）越高越清晰、越贵。本条各向异性过滤的硬件实现细节（footprint 长轴估计、采样布点）标为文档腿·未实证；概念与"为什么各向同性 mipmap 在掠射角发糊"的直觉由 RTR4 纹理章佐证，CMU 15-462 亦点到。初学者只需把它理解为"mipmap 的定向增强版"。

```python
# 5.2 节末：双线性取值 + mipmap 层数（scratchpad，真实输出）
T00,T10,T01,T11 = 0.0, 1.0, 1.0, 0.0
def bilinear(fx, fy):
    a = T00*(1-fx)+T10*fx; b = T01*(1-fx)+T11*fx
    return a*(1-fy)+b*fy
print(bilinear(0.5,0.5), bilinear(0.25,0.0))   # 0.5 0.25
w=256; lv=0
while w>=1: lv+=1; w//=2
print("mip levels 256x256 =", lv)              # 9
# 输出：
# 0.5 0.25
# mip levels 256x256 = 9
```

## G-05.3 漫反射 Lambert 与镜面 Phong / Blinn-Phong

### G-05.3.1 局部经验光照模型总览：环境 + 漫反射 + 镜面

经典的局部光照模型（如 Phong 光照模型）把一点被照亮后反射出的颜色，唯象地拆成三项相加：环境项（ambient）近似"来自四面八方的间接光"给一个常数底色、漫反射项（diffuse）表现粗糙表面把光均匀散开的哑光效果、镜面项（specular）表现光滑表面朝特定方向反射的高光。整体形式：

L = k_a·L_a + k_d·L_d·max(0, n·l) + k_s·L_s·(镜面因子)

其中 n 是表面法线、l 是指向光源的单位向量、各 k 是材质反射系数、各 L 是光源强度，向量都取单位长度。

要牢牢记住的定性事实是：这些是经验（empirical）模型——公式是"调出来看着像"的，不是从物理光传输推导出来的，不保证能量守恒。它们便宜、直观、几十年主导实时渲染；其物理正确的替代（BRDF、微表面、能量守恒的基于物理着色 PBR）是 G-09 的内容，本主题只讲经验版并在 G-05.3.6 点明分野。为什么要拆成三项？因为真实表面反射既有"漫"（哑光）又有"镜"（高光）成分，分开建模才能同时表现石膏的柔和与塑料的亮点；环境项则是对"没有全局光照时画面死黑"的粗暴补救。

### G-05.3.2 Lambert 漫反射：亮度正比于法线与光线夹角的余弦

漫反射（diffuse）建模理想粗糙表面：入射光被均匀散射到各个方向，因此从任何视角看亮度都一样，只取决于表面接收到多少光。接收到的光量正比于表面法线 n 与光源方向 l 夹角的余弦（Lambert 余弦定律），即两个单位向量的点积，并夹到非负：

L_diffuse = k_d · L_light · max(0, n · l)

当光正对表面（n 与 l 同向，n·l=1）最亮；当光掠射（夹角 90°，n·l=0）不受光；背对光（n·l<0）被 max 截为 0，表示背面照不到。

余弦的物理直觉是"同样一束光斜照时铺开在更大面积上、单位面积能量变小"——正照时光斑最集中最亮，斜照时摊薄变暗。这个 max(0, ·) 不能省：省了会让背光面出现负亮度（无意义）甚至因后续计算变成错误的发光。漫反射不含视线方向 v，这正是"从哪看都一样亮"的数学体现，也是区分漫反射与镜面的关键。一处 numpy 加固：n=(0,0,1)、l 与 n 成 45° 时 n·l=cos45°≈0.7071（见 5.3 节末）。

### G-05.3.3 Phong 镜面项：反射向量与视线的夹角

镜面反射（specular）建模光滑表面的高光：只有当视线方向 v 接近"光线关于法线的理想反射方向 r"时，才看到强烈的亮点。Phong 模型先算反射向量 r：

r = 2(n · l)·n − l

再取 r 与视线 v 夹角余弦的 p 次幂作为镜面因子：

L_specular = k_s · L_light · max(0, r · v)^p

指数 p（shininess / 高光指数）控制高光的锐利程度：p 越大高光越小越锐（越像镜子），p 越小高光越大越柔。

理解 r 的公式：把 l 分解成沿法线的分量和沿表面的分量，反射就是"沿表面分量不变、沿法线分量翻向"，整理即得上式。为什么要取高次幂？因为 cos 本身衰减太慢（高光会糊成一大片），取 p 次幂让"只有非常接近反射方向时才亮"，p 越高衰减越陡、亮点越紧。与漫反射的根本区别在于：镜面项依赖视线 v，所以高光会随观察者移动而在表面上滑动——这正是"高光是光源在表面的镜像"的体现。

### G-05.3.4 Blinn-Phong：改用半程向量

Blinn-Phong 是 Phong 的改良，用半程向量（half vector）h 代替反射向量 r。h 是光线方向 l 与视线方向 v 的角平分方向（归一化的和）：

h = normalize(l + v)

镜面因子改成法线 n 与 h 夹角余弦的幂：

L_specular = k_s · L_light · max(0, n · h)^p'

当视线恰好落在理想反射方向上时，h 恰好与 n 对齐（n·h=1），高光最强——与 Phong 判据等价地捕捉了"看向反射方向"。

半程向量的几何意义：要让 v 成为 l 的镜面反射，法线就得恰好平分 l 和 v，即法线应等于 h；于是"n 有多接近 h"就衡量"当前朝向离产生高光还差多少"。Blinn-Phong 在实践中更受欢迎有两个原因：一是省掉了算反射向量 r 的开销、且当 l 与 v 都相对稳定时 h 可复用；二是在掠射角下 Phong 的 r·v 会突然掉到负值使高光被硬切、而 Blinn-Phong 的 n·h 过渡更自然，高光形状更接近真实测量。OpenGL 固定管线历史上采用的就是 Blinn-Phong。

### G-05.3.5 Phong 与 Blinn-Phong 的差异与能量归一化

两者不是同一个公式换记法，得到的高光并不完全相同。关键量化关系：当 n、l、v 共面时，r 与 v 的夹角恰好是 n 与 h 夹角的两倍：

angle(r, v) = 2 · angle(n, h)

因此要让 Blinn-Phong 的高光大小近似匹配同一个 Phong 高光，Blinn-Phong 的指数 p' 大约要取 Phong 指数 p 的 4 倍。numpy 加固确认（见 5.3 节末）：n=(0,0,1)、v=(0,0,1)、l 与 n 成 45° 时，angle(r,v)=45°、angle(n,h)=22.5°，比值恰为 2.0；Phong p=32 的高光需 Blinn p'≈128 才大致对齐。

另一处要点是能量归一化：朴素 Phong/Blinn-Phong 改变 p 时高光的总反射能量并不守恒（p 越大高光越小但峰值未相应提高，整体变暗）。在偏物理的实现里会乘一个依赖 p 的归一化系数（形如 (p+常数)/(2π) 一类）使不同 p 下总能量一致——但具体系数因推导约定不同而有多个版本（RTR4 与 PBR 文献给出不同归一化因子），这里不给死系数，标：归一化系数依约定而异、待按所用文献锚定。初学者层面只需记住两条结论：Blinn 指数约为 Phong 的 4 倍才视觉匹配；朴素经验模型不保证能量守恒、故有归一化修正这回事。

### G-05.3.6 经验模型 vs 物理模型的分野（指向 G-09）

Phong/Blinn-Phong 属于经验（ad-hoc）着色模型：项的形式和参数靠观感调出，不满足亥姆霍兹互易、不满足能量守恒、"漫反射常数 + 高光幂"没有严格物理来源。基于物理的渲染（PBR）改用 BRDF（双向反射分布函数）描述反射、用微表面理论推导高光分布、强制能量守恒，参数换成粗糙度/金属度等有物理意义的量。

对初学者，边界是这样的：经验模型便宜、易上手、在大量实时场景里"够用且好看"，是理解光照的第一站；但要正确表现金属、粗糙度渐变、间接光时会力不从心。本主题（G-05）只覆盖经验模型；辐射度量学量纲、BRDF、渲染方程、微表面高光与能量守恒的物理正确版本，全部在 G-09 展开。把 Blinn-Phong 视作"BRDF 的一个粗糙经验特例"是一个能贯通两章的心智锚点。

```python
# 5.3 节末：Lambert、Phong r 与 Blinn-Phong h 夹角关系（scratchpad，真实输出）
import numpy as np
def norm(v): v=np.array(v,float); return v/np.linalg.norm(v)
n=norm([0,0,1]); l=norm([1,0,1]); v=norm([0,0,1])
print("Lambert n.l =", round(max(0.0,np.dot(n,l)),4))          # 0.7071
r=2*np.dot(n,l)*n-l; h=norm(l+v)
a=np.degrees(np.arccos(np.clip(np.dot(r,v),-1,1)))
b=np.degrees(np.arccos(np.clip(np.dot(n,h),-1,1)))
print("angle(r,v)=",round(a,1)," angle(n,h)=",round(b,1)," ratio=",round(a/b,2))
# 输出：
# Lambert n.l = 0.7071
# angle(r,v)= 45.0  angle(n,h)= 22.5  ratio= 2.0
```

## G-05.4 法线贴图/凹凸贴图与环境（反射）贴图

### G-05.4.1 凹凸贴图（bump mapping）：用贴图扰动法线制造假凹凸

凹凸贴图（bump mapping，Blinn 1978 提出）在不改变实际几何的前提下，用一张贴图逐片元地扰动表面法线，使光照计算"以为"表面有起伏，从而显出凹凸的明暗——但物体轮廓和实际位置并没变。经典 bump map 存的是一张高度图（heightmap），取其梯度得到法线的扰动量。

关键洞察是：人眼判断表面起伏主要靠明暗变化，而明暗来自 G-05.3 里的 n·l 等点积——所以只要"骗过法线"，就能骗出凹凸感，代价极低。局限也正在于此：因为几何没变，掠射看轮廓仍是平的、凹凸不会互相遮挡、也不产生自阴影。初学者应把它和真正改动几何的位移贴图（G-05.4.3）分清。

### G-05.4.2 法线贴图（normal mapping）与切线空间 TBN

法线贴图是凹凸贴图最流行的现代形式：不存高度、直接把每个纹素当作一个法线向量存进 RGB 三通道。最常见的是切线空间（tangent-space）法线贴图，把法线存在以表面局部坐标为基的坐标系里，因此贴图整体偏蓝——因为"不扰动"对应法线指向表面外，即切线空间的 (0,0,1)，编码到 RGB 约为 (128,128,255) 的淡蓝。解码时把 [0,1] 的颜色映回 [−1,1] 的向量：

n_tangent = 2 · rgb − 1

要把这个切线空间法线用到光照里，需要切线空间到世界（或视图）空间的变换，由 TBN 矩阵完成——T 是切线（tangent）、B 是副切线（bitangent）、N 是几何法线，三者构成表面局部标准正交基：

n_world = [ T  B  N ] · n_tangent

切线 T 通常由 (u,v) 的走向决定（沿 u 增大方向），使法线贴图的朝向与 uv 一致。

为什么用切线空间而不直接存世界空间法线？因为切线空间法线与模型朝向无关，同一张贴图能贴到弯曲、活动的表面上并随之正确旋转（角色蒙皮动画尤其需要），复用性强。理解 TBN 的关键是回到 G-01/G-02：这是一次基变换，把"相对表面"的方向换算成"世界里"的方向；T、N 来自网格，B 常由 B = N × T 叉积补齐（G-01 的叉积生成正交向量）。一个常见坑：法线是方向量，跨空间变换要用逆转置矩阵而非模型矩阵本身（G-02.6 的结论在此复用），非等比缩放下尤甚。

### G-05.4.3 位移贴图（displacement mapping）的辨析

位移贴图（displacement mapping）与凹凸/法线贴图形似而本质不同：它真正沿法线移动几何顶点（或在细分/曲面细分阶段生成新顶点后移动），改变了真实表面。因此它能产生正确的轮廓起伏、自遮挡与自阴影，但代价是需要足够密的几何（或运行时细分），比只扰动法线昂贵得多。

三者的一句话对照：凹凸/法线贴图只骗光照、几何不变、便宜但轮廓穿帮；位移贴图真改几何、正确但贵。初学者常把法线贴图误当作"让表面真的凹凸"，看轮廓（silhouette）是最快的判别法——法线贴图的轮廓永远是原始网格的平滑轮廓，位移贴图的轮廓是起伏的。视差贴图（parallax mapping）是介于两者之间的折中，用高度图偏移采样坐标制造更强的视差错觉但仍不改几何，属进阶话题，此处点到为止。

### G-05.4.4 环境贴图 / 反射贴图（cube map / sphere map）

环境贴图（environment mapping，又称反射贴图 reflection mapping）用一张预先拍好的"周围环境全景"来近似镜面反射：不去真实追踪反射光线（那是 G-08 光线追踪的活），而是用视线关于表面法线的反射方向 r 去环境贴图里查一个颜色，当作反射到眼睛里的环境。反射方向的算法与 Phong 同源：

r = 2(n · v)·n − v

（这里对视线 v 求反射；实现中常用等价的 reflect(−v, n)。）

最常见的存储是立方体贴图（cube map）：把环境拍成一个立方体的 6 个面，用方向向量 r 判断打到哪个面、再取该面上的纹素；早期也用球面贴图（sphere map）等其他参数化。

理解环境贴图的关键是"用查表冒充反射"：它假设环境无限远、忽略了物体自身以及物体间的相互反射，所以是近似——但对天空、远景这类反射足够便宜且逼真，是实时反射的主力手段。它也是基于图像光照（IBL）和 PBR 里"用预过滤环境贴图近似漫反射/镜面环境光照"的前身（那部分属 G-09 物理版）。cube map 还常复用作天空盒（skybox）背景，和反射用的是同一份数据。

## G-05.5 材质参数与多光源着色累加

### G-05.5.1 材质参数：k_a / k_d / k_s 与高光指数

材质（material）把一个表面"如何反射光"抽象成一组参数，喂给 G-05.3 的光照公式。经典 Phong 材质包含：环境反射系数 k_a、漫反射系数 k_d（决定表面固有色，常直接来自纹理采样）、镜面反射系数 k_s（高光颜色与强度）、高光指数 p / shininess（高光锐度）。完整的单光源单点着色式把三项合起来：

L = k_a·L_a + k_d·L_light·max(0, n·l) + k_s·L_light·max(0, n·h)^p

其中 k_a、k_d、k_s 通常是 RGB 三分量（对不同颜色通道分别反射），逐通道相乘。

初学者要抓的直觉是"材质 = 一组旋钮"：调大 k_s、p 得到塑料/瓷器的锐亮高光；k_s 调成偏白、p 调低得到金属的宽而亮高光（经验模型下金属只能粗略模拟，真实金属着色见 G-09）；k_d 来自纹理就得到有花纹的表面。k_d 常被称作反照率（albedo）纹理。为什么 k_d 用纹理而 k_a、k_s、p 常给常数或另附贴图？因为漫反射色的空间变化最丰富（图案、脏污），而其余参数在一个材质上往往较均匀——现代管线则把粗糙度/金属度也做成贴图（PBR，G-09）。

### G-05.5.2 多光源累加：对每盏灯的贡献线性相加

场景里通常有多盏光源。因为光照在物理上是线性可叠加的（各光源独立照明、互不干扰），最终着色就是对每个光源分别算一遍漫反射+镜面并求和，环境项通常只加一次：

L = k_a·L_a + Σᵢ [ k_d·L_i·max(0, n·lᵢ) + k_s·L_i·max(0, n·hᵢ)^p ]

其中 i 遍历所有光源，每盏灯有自己的方向 lᵢ、半程向量 hᵢ 和强度 L_i。

累加时每一项都各自带 max(0,·)，保证背对某盏灯的贡献是 0 而非负——这是逐光源分别截断、不能求和后再截。结果可能超过 1（多盏强灯叠加），最终写帧缓冲前要做色调映射或简单地夹到 [0,1]（LDR 下常直接 clamp，会丢高光细节；HDR + tone mapping 更好，属后续话题）。一处 numpy 加固（见 5.5 节末）：两盏方向光对同一点漫反射累加，逐光源点积截断后按 k_d·L_i 加权求和，结果与手算一致。初学者易犯的错是"先加所有 n·lᵢ 再截断"或"环境项每盏灯都加一遍"——都会偏亮。

### G-05.5.3 光源类型与距离衰减

实时渲染常用三类理想光源：方向光（directional，如太阳，方向恒定、无位置、不衰减）、点光源（point，从一点向四周发光、有位置、随距离衰减）、聚光灯（spot，点光源加一个锥形角度限制）。区别主要体现在"如何得到每个片元的 l 与强度"：方向光 l 是常量；点光源 l 指向光源位置、且强度随距离 d 衰减。物理上点光源强度按平方反比衰减：

attenuation = 1 / d²

实时中常用带常数/一次/二次项的经验衰减式 1/(k_c + k_l·d + k_q·d²) 以便美术控制、避免近距离爆亮。

衰减解释了为什么点光源照近处亮、远处暗，而太阳（方向光）不管远近一样亮（因为太阳太远，可视作平行光、衰减忽略）。平方反比的物理直觉与 G-05.3.2 的余弦摊薄同源：光能量随距离铺展在越来越大的球面上（球面积 ∝ d²）。聚光灯再在此基础上按片元方向与聚光轴的夹角做一个角度衰减（cone falloff）。这些衰减式的具体形式因引擎/API 而异（1/d² 物理版 vs 三项经验版 vs 带范围截断的版本），属实现约定，不给死系数。

### G-05.5.4 逐顶点（Gouraud）vs 逐片元（Phong shading）着色

着色计算放在管线哪一步，效果差别很大。Gouraud 着色（逐顶点着色）在顶点着色器里对每个顶点算一次完整光照，再把得到的颜色用重心坐标插值到三角形内部（G-03）。Phong 着色（逐片元着色，注意与 Phong 光照模型是两回事）则把法线等量插值到每个片元，在片元着色器里逐片元算光照。

两者的核心差别在高光：Gouraud 只在顶点处采样光照，若高光恰好落在三角形内部（顶点上都不亮）就会被整片漏掉或糊成一块，大三角形上尤其明显；Phong shading 逐片元算，高光位置准确、边缘锐利，代价是每个片元都要算一遍光照、更贵。初学者最常混的两个"Phong"务必分清：Phong 光照模型（reflection model，G-05.3.3 那个高光公式）vs Phong 着色（shading，指逐片元插值法线再着色的这套做法）——前者是"用什么公式算亮度"，后者是"在管线哪一步、按什么粒度算"。现代可编程管线几乎都用逐片元着色。

```python
# 5.5 节末：多光源漫反射累加（scratchpad，真实输出）
import numpy as np
def norm(v): v=np.array(v,float); return v/np.linalg.norm(v)
n=norm([0,0,1]); kd=np.array([0.8,0.6,0.2])
lights=[(norm([1,0,1]),np.array([1.,1.,1.])),
        (norm([-1,0,1]),np.array([0.3,0.3,0.5]))]
out=np.zeros(3)
for ld,li in lights:
    out += kd*li*max(0.0,np.dot(n,ld))   # 逐光源截断后累加
print("sum =", np.round(out,4), " clamp01 =", np.round(np.clip(out,0,1),4))
# 输出：
# sum = [0.7354 0.5515 0.2121]  clamp01 = [0.7354 0.5515 0.2121]
```
