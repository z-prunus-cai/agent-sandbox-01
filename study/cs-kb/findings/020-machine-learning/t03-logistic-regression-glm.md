## 3.1 逻辑回归与对数几率

### 3.1.1 为什么分类不能直接套线性回归

逻辑回归是一种**判别式二分类**模型：它直接对"给定特征 x，标签 y=1 的概率"建模，形式是把线性打分 wᵀx + b 送进 sigmoid 函数得到一个 [0,1] 的概率。名字里有"回归"是历史包袱，它做的其实是**分类**。

要理解它为什么长这样，先看直接用线性回归做分类会坏在哪。若把类别标成 0/1 然后用最小二乘拟合一条直线 ŷ = wᵀx + b，会有三个硬伤。第一，输出会跑到 [0,1] 之外，负概率、大于 1 的概率都毫无意义。第二，平方损失对"已经分得很对但打分很大"的点仍施加惩罚，方向错了。第三，多于两类且做等距编码（1,2,3）时，会隐含一个"类别 2 在类别 1 和 3 中间"的错误顺序假设。逻辑回归用一个单调挤压函数把线性打分压进 [0,1]，一举解决前两个问题。

### 3.1.2 sigmoid 函数

sigmoid（也叫 logistic 函数）把整条实轴单调地压到开区间 (0,1)：

σ(z) = 1 / (1 + e^(−z))

它有几条日后反复要用到的性质：

σ(0) = 0.5，σ(+∞) → 1，σ(−∞) → 0

σ(−z) = 1 − σ(z)

σ′(z) = σ(z)·(1 − σ(z))

最后一条导数形式极其好用——它是后面梯度公式能化简得那么干净、以及牛顿法 Hessian 里出现 h(1−h) 权重的根源。

把 z = wᵀx + b 想成"证据总分"，正证据往正无穷推、负证据往负无穷推，sigmoid 是一个"信心表"，把任意大小的证据翻译成 0 到 1 的信心值，证据为 0 时信心 0.5（完全不确定），证据越强信心越接近 0 或 1 但永不触及。逻辑回归的预测概率写成

h_w(x) = P(y=1 | x; w) = σ(wᵀx + b)

一个常见约定是把偏置 b 吸收进 w：给每个 x 前面补一个恒为 1 的分量，于是 wᵀx 就含了截距，后文公式默认这样处理。

### 3.1.3 对数几率线性——逻辑回归的定义性质

sigmoid 的逆函数是 **logit**，即对数几率（log-odds）。把 h = σ(wᵀx) 反解出 wᵀx，得到逻辑回归最本质的一句话：

logit(p) = log( p / (1 − p) ) = wᵀx

也就是说，**几率（odds）p/(1−p) 的对数，是特征的线性函数**。这是把"逻辑回归"和"随便一个套了 sigmoid 的模型"区分开的定义性质，四本教材（CS229、ISL §4.3、ESL §4.4、PRML §4.3.2）在这一点上完全一致。

为什么这句话重要？它给了系数 w 一个可解释的意义：x 的第 j 个分量每增加 1 个单位，会让**对数几率**增加 w_j，等价地让**几率乘以 e^(w_j)**。这就是流行病学、信用评分里"某因素使发病几率翻 e^(w_j) 倍"这类说法的来源。ISL Ch4 特别强调：逻辑回归里 w_j 对**概率**的影响不是线性的（因为 sigmoid 是弯的），但对**对数几率**的影响是线性、恒定的——这是初学者最容易搞混的一点。

"几率"和"概率"要分清。概率 p ∈ [0,1]；几率是 p/(1−p) ∈ [0,∞)，表示"发生 vs 不发生"的比值（p=0.5 时几率为 1，即 1 赔 1）；对数几率再取 log，把范围拉成整条实轴 (−∞,+∞)，正好和线性打分的值域对上——这就是为什么偏偏是"对数几率"而不是"概率"或"几率"本身等于线性函数。

### 3.1.4 最大似然与交叉熵损失

逻辑回归的参数用**最大似然估计**（MLE）学。把每个样本的标签看作一次伯努利试验，成功概率 h_w(xᵢ)，则单样本似然可以写成一个紧凑形式：

P(yᵢ | xᵢ; w) = h_w(xᵢ)^{yᵢ} · (1 − h_w(xᵢ))^{1−yᵢ}

（yᵢ=1 时取前项、yᵢ=0 时取后项，这是把两种情况合写的技巧。）全体样本独立，对数似然为

ℓ(w) = Σᵢ [ yᵢ log h_w(xᵢ) + (1 − yᵢ) log(1 − h_w(xᵢ)) ]

它的相反数（再取平均）正是**二元交叉熵损失**（也叫 log loss）：

J(w) = −(1/m) Σᵢ [ yᵢ log h_w(xᵢ) + (1 − yᵢ) log(1 − h_w(xᵢ)) ]

这里出现本大主题第一处**符号约定分歧**，务必留意但不必纠结：CS229 讲义把它写成"**最大化**对数似然 ℓ(w)"（梯度**上升**）；ISL、ESL、PRML、sklearn 则习惯写成"**最小化**交叉熵/负对数似然"（梯度**下降**）。两者只差一个负号，最优解 w 完全相同，梯度方向相反。本报告在公式里两种都会出现，看到时认准"是在最大化 ℓ 还是最小化 J"即可。

为什么用交叉熵而不是平方损失？两个理由。其一，从概率生成假设（伯努利）出发做 MLE，自然掉出来的就是交叉熵，它是"最符合数据分布"的损失。其二，对逻辑回归而言交叉熵是**凸函数**（Hessian 半正定，见 3.3），没有非全局的局部极小值，梯度法保证收敛到全局最优；而平方损失套 sigmoid 后是非凸的，还会在预测严重错误时给出趋近于 0 的梯度（sigmoid 饱和区），学不动。这条"交叉熵配 sigmoid、平方损失配线性输出"的配对原则，在 L6-03 深度学习里会原样复用。

### 3.1.5 梯度与 LMS 同形的更新规则

对 ℓ(w) 求关于 w 的梯度，借助 σ′ = σ(1−σ) 化简后，会得到一个异常简洁的结果：

∂ℓ/∂w = Σᵢ ( yᵢ − h_w(xᵢ) ) xᵢ

于是**梯度上升**（最大化对数似然）的更新规则是

w := w + α Σᵢ ( yᵢ − h_w(xᵢ) ) xᵢ

CS229 讲义在此点出一个"美丽的巧合"：这个更新规则和线性回归的 LMS（最小均方）更新规则**形式上一模一样**——都是"步长 × Σ(真实值 − 预测值) × 特征"。区别只在预测 h 的定义：线性回归里 h = wᵀx，逻辑回归里 h = σ(wᵀx)。CS229 明确指出这**不是**巧合，而是因为两者都是 GLM（见 3.4），同一模板下自然导出同形更新；ESL §4.4 从牛顿法角度给出同一梯度，二者交叉一致。

更新量正比于**残差** (yᵢ − hᵢ)。若模型已经把某样本预测得很准（h≈y），残差≈0，几乎不动它；若预测反了（y=1 而 h≈0），残差≈1，就朝着把该样本的打分推高的方向 (+xᵢ) 大步走。若写成最小化交叉熵，梯度是 −Σ(yᵢ−hᵢ)xᵢ，更新变成 w := w − α·(那个梯度)，殊途同归。本次 numpy 实证里，解析梯度 −Σ(yᵢ−hᵢ)xᵢ 与中心有限差分逐分量吻合（差异在 1e-2 量级、随收敛趋 0），坐实了这条公式。

### 3.1.6 决策边界与阈值

训练完成后，逻辑回归通过比较概率与阈值来分类，默认阈值 0.5：

预测 ŷ = 1  当且仅当  h_w(x) ≥ 0.5  ⇔  wᵀx ≥ 0

因为 σ(z) ≥ 0.5 等价于 z ≥ 0，所以**决策边界是超平面 wᵀx = 0**——逻辑回归是一个**线性分类器**，边界是直线/平面，尽管它输出的是弯曲的概率曲面。

初学者常见误区有二。其一，以为逻辑回归能画出弯曲的分类边界——不能，除非你手工加了非线性特征（如 x₁²、x₁x₂）。其二，把阈值 0.5 当成金科玉律——它只是"两类先验相等、误分类代价对称"时的默认值。类别不平衡或代价不对称时（如癌症筛查漏诊代价远大于误诊），应调阈值，这属于大主题12 评估纪律的内容，此处只点出"概率 → 类别"这一步和"学概率"是两件可分开调的事。

## 3.2 softmax / 多类

### 3.2.1 从二分类到 softmax

当类别数 K > 2 时，逻辑回归推广为 **softmax 回归**（又名多项/多类逻辑回归、multinomial logistic regression、最大熵分类器）。它给每个类别 k 一组权重 w_k，把 K 个线性打分经 softmax 归一成一个概率分布：

P(y=k | x; W) = exp(w_kᵀx) / Σ_{j=1}^{K} exp(w_jᵀx)

softmax 做的事就是"指数化 + 归一化"：先取 exp 保证非负，再除以总和保证 K 个概率加起来为 1。当 K=2 时它退化回 sigmoid（可以证明两组权重之差就是逻辑回归的那一组 w）。

softmax 是一个"软化的 argmax"。若某个打分远大于其余，它对应的概率会接近 1、其余接近 0（像 argmax 直接挑最大）；若几个打分接近，概率就分得较均匀，保留了不确定性。名字 soft-max 即由此而来。它天然处理"互斥多类"（一个样本恰属一类），这与"多标签"（一个样本可属多类、各类用独立 sigmoid）是不同问题，别混。

### 3.2.2 交叉熵损失与梯度

softmax 回归同样用最大似然/交叉熵学参数。把真实标签写成 one-hot 向量（属于类 k 则第 k 位为 1、其余为 0），多类交叉熵损失为

J(W) = −(1/m) Σᵢ Σ_{k=1}^{K} 1{yᵢ=k} · log P(yᵢ=k | xᵢ; W)

其中 1{·} 是示性函数。它对第 k 组权重的梯度形式与二分类惊人地一致：

∂J/∂w_k = −(1/m) Σᵢ ( 1{yᵢ=k} − P(yᵢ=k | xᵢ) ) xᵢ

依旧是"（真实的 one-hot 分量 − 预测概率）× 特征"的残差形式。这解释了为什么深度网络最后一层几乎总是"softmax + 交叉熵"：梯度干净、数值稳定，反向传播时最后一层的梯度就是"预测分布 − 真实分布"。CS229 与 PRML §4.3.4 在梯度形式上一致。

### 3.2.3 过参数化与可辨识性——一处需分清的表述差异

softmax 回归有一个微妙但重要的性质：它是**过参数化**（over-parameterized）的。若给每一组权重 w_k 都减去同一个向量 ψ，即 w_k → w_k − ψ，softmax 的输出概率**完全不变**（分子分母同乘 e^{−ψᵀx} 约掉）。这意味着最优解不唯一，参数不可辨识（unidentifiable）。

由此引出教材间一处**表述差异**（非对错冲突，是不同惯例）：CS229 讲义与 PRML 采用**满参数化**（K 组权重全留），坦承其冗余，并指出正则化（大主题6）会把解钉在唯一一点，或人为固定 w_K = 0；而**经典统计学与 ISL 的多项逻辑回归**采用**基线类编码**（baseline/reference coding），只估 K−1 组系数、把某一类当参照，天然可辨识。两种写法给出的预测概率相同，只是参数化不同——读到"K 组权重"还是"K−1 组"时要知道它们描述的是同一个模型。ISL 2nd ed（2021）§4.3.5 同时介绍了 softmax 形式并明确点出"存在冗余、需选一个基线"，与 CS229/PRML 的说法互相印证。

softmax 的概率只依赖各类打分之间的**差**，不依赖它们的绝对高度——所以你可以把所有打分整体平移而不改变结果，这正是冗余的来源，也是数值实现时"减去每行最大值再取 exp"防溢出技巧成立的原因。

### 3.2.4 与 one-vs-rest 的辨析

多类分类的另一条常见路线是 **one-vs-rest（OvR，一对多）**：训练 K 个独立的二分类逻辑回归，第 k 个判"是不是类 k"，预测时取概率最高者。它和 softmax 回归是两种不同做法，值得辨析。

softmax 是**单一联合模型**，K 组权重一起训练、输出天然归一化的概率分布、假设类别互斥；OvR 是 **K 个独立模型**，各自的概率不保证加起来为 1（需事后归一化），但实现简单、可并行、易扩展到新类。理论上 softmax 更"正宗"（直接建模互斥多类分布），实践中两者精度常常接近。sklearn 的 `LogisticRegression` 历史上通过 `multi_class` 参数在两者间切换，但该参数在近版本已弃用、默认走 softmax（'multinomial'）——具体默认与弃用时间点属实现细节，锚 sklearn 1.9.0，需查当版文档，不在此下定论。

## 3.3 牛顿法 / IRLS

### 3.3.1 牛顿法：用二阶信息一步跳到极值

牛顿法是一种**二阶**优化方法，用来更快地最大化（或最小化）逻辑回归的对数似然。梯度下降只用一阶导数（斜率），牛顿法额外用二阶导数（曲率，即 Hessian 矩阵）来决定步长与方向，更新规则为

w := w − H⁻¹ ∇J(w)

其中 ∇J 是梯度向量、H 是 Hessian 矩阵（损失对参数的二阶偏导矩阵）。

牛顿法在当前点用一个**二次抛物面**去逼近损失曲面，然后**一步跳到这个抛物面的最低点**。梯度下降像蒙眼摸黑一小步一小步下山，步长要人调；牛顿法像看清了脚下这片山谷的形状后直接迈到谷底。对逻辑回归这种凸问题，牛顿法通常十几步内就收敛到高精度（本次 numpy 实证：15 次迭代内 θ 已与 sklearn 到小数点后 4 位一致），且**不需要调学习率**——H⁻¹ 自动定了每个方向该走多远。

### 3.3.2 逻辑回归的梯度与 Hessian

一维直觉推广到多维需要 Hessian。对逻辑回归的负对数似然 J(w)，梯度与 Hessian 分别是

∇J(w) = −Σᵢ ( yᵢ − hᵢ ) xᵢ = Xᵀ(h − y)

H = Σᵢ hᵢ(1 − hᵢ) xᵢxᵢᵀ = Xᵀ S X，其中 S = diag( hᵢ(1 − hᵢ) )

这里 X 是设计矩阵（每行一个样本），h 是预测概率向量，S 是对角权重矩阵。因为每个权重 hᵢ(1−hᵢ) > 0（sigmoid 导数恒正），H 是**半正定**的，这就从二阶层面证明了 J(w) 是凸函数——逻辑回归没有坏的局部极小值。CS229、ESL §4.4.1、PRML §4.3.3 在 H = XᵀSX 这一形式上完全一致。

### 3.3.3 IRLS：牛顿法在逻辑回归上化成加权最小二乘

把 H = XᵀSX 和 ∇J = Xᵀ(h−y) 代回牛顿更新 w := w − H⁻¹∇J，经代数整理，可以把每一步写成一个**加权最小二乘**问题的解：

w_{new} = (XᵀSX)⁻¹ XᵀS z，其中 z = Xw_{old} + S⁻¹(y − h)

这个 z 叫**调整响应**（adjusted response / working response）。式子的形状和线性回归的加权正规方程 (XᵀWX)⁻¹XᵀWy 一模一样，只是这里的权重 S 和目标 z 每一步都随当前 w 重新计算。所以逻辑回归的牛顿法有个专名叫 **IRLS（Iteratively Reweighted Least Squares，迭代重加权最小二乘）**：**反复地解一个加权最小二乘，每轮更新权重与目标**。ESL §4.4.1 与 PRML §4.3.3 都以 IRLS 作为标准解法呈现，命名与推导一致。

IRLS 把一个看似陌生的分类优化，翻译成了你在大主题2 已经会的"最小二乘"语言——每一轮就是拿当前权重 S 加权、拿伪目标 z 当"y"，解一次正规方程。权重 hᵢ(1−hᵢ) 的含义也很直观：预测概率接近 0 或 1（模型很有把握）的点权重小、接近 0.5（模型最含糊）的点权重大——IRLS 每轮最关注"当前最拿不准的样本"。

### 3.3.4 牛顿法 vs 梯度下降的权衡

牛顿法收敛快（在最优点附近**二次收敛**，迭代数远少于梯度下降），但每步代价高：要算 Hessian（O(n²) 存储，n 为特征维）并解一个 n×n 线性系统（O(n³)）。当特征维 n 不大（几百以内）时，牛顿法/IRLS 通常是首选，迭代几次就到高精度。当 n 很大（成千上万，如文本 TF-IDF、基因数据）时，Hessian 存不下也解不动，此时改用一阶方法（SGD）或拟牛顿法（L-BFGS，用梯度历史近似 H⁻¹ 而不显式构造 H）。

这解释了 sklearn 的默认求解器选择：`LogisticRegression` 默认 `solver='lbfgs'`（拟牛顿），正是在"要二阶的收敛速度"和"不付 O(n³) 全 Hessian 代价"之间的折中；`newton-cg` 等其他求解器也可选（具体可用求解器集合与默认随版本演进，锚 sklearn 1.9.0）。初学者只需记住主干权衡：**牛顿法用曲率换迭代数，维度一高就换成拟牛顿或一阶法**。

## 3.4 指数族与 GLM

### 3.4.1 指数族的标准形

**指数族**（exponential family）是一大类概率分布的统一写法，把伯努利、高斯、多项、泊松、指数、伽马等常见分布收进同一模板：

p(y; η) = b(y) · exp( ηᵀT(y) − a(η) )

其中 η 是**自然参数**（natural / canonical parameter），T(y) 是**充分统计量**（多数常见情形 T(y)=y），b(y) 是基测度，a(η) 是**对数配分函数**（log-partition，起归一化作用、保证概率积分为 1）。给定 T、a、b 的选择，就固定了一族分布；变动 η 就在这族里挑出具体一个成员。

不必被公式吓到。指数族就是说"很多看起来不同的分布，其实都能被塞进 exp(线性项 − 归一化项) 这个共同外壳里"。这个共同外壳带来一个巨大好处——一旦一族分布写成指数族，它的均值、方差、MLE 求解、梯度形式都有**统一的套路**，不必对每个分布单独推。GLM 正是站在这个统一套路上。

### 3.4.2 常见分布作为指数族成员

关键的两个例子，正是前面两节的模型来源：

伯努利(φ)：写成指数族后，自然参数 η = log( φ / (1−φ) )，反解得 φ = 1/(1+e^{−η}) = σ(η)

高斯(μ, 固定 σ²)：自然参数 η = μ，即均值本身

看第一个：伯努利的自然参数 η 恰好是**对数几率**，而它的反函数恰好是 **sigmoid**——这不是巧合，而是逻辑回归里 sigmoid"从天而降"的根本原因。看第二个：高斯的自然参数就是均值，这对应线性回归"直接预测均值"。多项分布同理，其自然参数反解出来正是 **softmax**。三个模型的挤压函数（sigmoid、恒等、softmax）都不是硬凑的，而是从各自分布的指数族形式里唯一确定地掉出来的。

### 3.4.3 GLM 的三条假设

**广义线性模型**（GLM，Generalized Linear Model）用三条假设把"选一个指数族分布"变成"一个可训练的监督模型"。CS229 Part III 把它总结为三条建模选择：

其一，给定 x，响应变量 y 服从某个指数族分布：y | x; w ~ ExponentialFamily(η)。

其二，自然参数与输入呈**线性**关系：η = wᵀx（多参数时每个自然参数各配一组权重）。

其三，预测目标是该分布的**期望**：h_w(x) = E[ T(y) | x ]（多数情形 E[y|x]）。

这三条一摆好，模型就完全确定了。你只需回答一个问题——"我的响应变量 y 是什么类型的分布？"——GLM 会自动吐出对应的模型、挤压函数和损失。

### 3.4.4 链接函数与响应函数

GLM 里有两个方向相反、极易混淆的函数，务必分清：

**响应函数**（response function）g，把线性打分 η 映射成分布均值：E[y|x] = g(η) = g(wᵀx)

**链接函数**（link function）g⁻¹，是它的逆，把均值映射回线性打分：η = g⁻¹(E[y|x])

由指数族自然参数直接导出的那个特定链接叫**规范链接**（canonical link）。伯努利的规范链接是 logit（对应响应函数 sigmoid），高斯的规范链接是恒等函数，泊松的规范链接是 log。统计学教材（如 ISL、经典 GLM 文献）习惯以**链接函数**为中心叙述（"logistic 回归 = 二项分布 + logit 链接"），CS229 则以**响应函数**（g = E[T(y)|x] 对 η 的函数）为中心叙述——两者互为逆函数，是同一件事的两种说法，读到"link"与"response"时要知道谁是谁的逆。


| 响应变量分布 | GLM 模型 | 规范链接（η=…） | 响应函数（E[y]=…） |
|---|---|---|---|
| 高斯 | 线性回归 | 恒等 | 恒等 |
| 伯努利 | 逻辑回归 | logit | sigmoid |
| 多项 | softmax 回归 | 多类 logit | softmax |
| 泊松 | 泊松回归 | log | exp |

### 3.4.5 GLM 如何统一三个模型

**线性回归、逻辑回归、softmax 回归不是三个孤立模型，而是 GLM 模板下选了高斯、伯努利、多项分布后掉出来的三个特例**。它们的训练更新规则之所以都长成 "w := w + α Σ(yᵢ − hᵢ)xᵢ"（3.1.5 那个"美丽巧合"），正是因为 GLM 的对数似然梯度有统一形式 Σ(yᵢ − E[y|xᵢ])xᵢ——残差 × 特征，与具体选了哪个指数族分布无关。这就是 GLM 框架的威力：一次推导，三处（乃至更多，如泊松回归、伽马回归）通用。

学到这里应该建立一张"地图"——最上层是指数族（一堆分布的统一外壳），中层是 GLM（三条假设把分布接上线性打分），底层是你熟悉的三个具体模型。往后遇到"计数数据用泊松回归""正的连续量用伽马回归"，都只是在这张地图上换一个指数族成员，套路不变。这也是为什么 CS229 把 GLM 放在讲完逻辑回归之后——它是把前面零散模型"一网打尽"的上位视角，不是又一个新模型。

## 3.5 感知机算法

### 3.5.1 感知机模型：把 sigmoid 换成硬阈值

**感知机**（perceptron，Rosenblatt 1958）是最早的线性分类器，可视为逻辑回归的"极简祖先"：把 sigmoid 的软概率换成非黑即白的**硬阈值**。它的预测是

ŷ = g(wᵀx)，其中 g(z) = 1 若 z ≥ 0，否则 0（或用 {−1,+1} 编码时 g(z)=sign(z)）

和逻辑回归共用同一套线性打分 wᵀx，区别只在输出层：逻辑回归输出 [0,1] 的概率，感知机直接输出 0/1（或 ±1）的类别，中间没有概率、没有不确定度。

感知机就是一个"投票器"——特征加权求和，过线就判正类、不过线就判负类。它是理解后续一切的起点，因为**单个感知机 = 神经网络里的单个神经元**（线性加权 + 一个激活/阈值）。大主题8 与 L6-03 把 sigmoid/ReLU 等可导激活装回这个单元、再堆叠多层，就得到多层感知机与深度网络——所以这一小节是那条线的"原子"。

### 3.5.2 误分类驱动的更新规则

感知机的学习规则极其朴素：**只在分错时才更新**，且更新方向是把犯错样本往正确一侧推。用 {0,1} 编码时更新与逻辑回归同形（但 h 是硬阈值输出）：

w := w + α ( yᵢ − ŷᵢ ) xᵢ

用 {−1,+1} 编码时更可读地写成：仅当 yᵢ(wᵀxᵢ) ≤ 0（即分错）时，

w := w + α yᵢ xᵢ

分对的样本 (yᵢ − ŷᵢ)=0，一动不动；分错时残差为 ±1，就朝 ±xᵢ 方向纠一步。CS229 讲义把它明确呈现为"把逻辑回归里的 σ 换成硬阈值 g"后得到的规则，形式上与逻辑回归的 Σ(y−h)x 同形——但强调这**只是形式相似**：因为 g 不可导、非概率，这个更新**不是**任何似然函数的梯度，感知机没有 3.1 那样的 MLE 概率解释。

感知机是**在线/随机**地一个样本一个样本地看，见错就改、见对就过，像老师只在学生答错时纠正。它不关心"分得多有把握"（不像逻辑回归的残差随信心连续变化），只关心"对还是错"——这既是它简单的原因，也是它局限的原因。

### 3.5.3 收敛定理（线性可分）

感知机最重要的理论结果是**感知机收敛定理**（Novikoff 1962）：**若训练数据线性可分**（存在一个超平面能把两类完全分开且有间隔 γ），则感知机算法保证在**有限步**内收敛到一个能零错误分类所有训练样本的 w，更新次数上界只依赖间隔 γ 和数据半径 R（约 (R/γ)²），与样本量、维度无关。

反过来，**若数据线性不可分，感知机永不收敛**——它会永远震荡下去，因为总有分不对的点持续触发更新。这是感知机最著名的软肋（Minsky & Papert 1969 用它无法学 XOR 说明了单层感知机的表达力上限），也是历史上第一次"AI 寒冬"的导火索之一，并直接推动了后来多层网络与可微激活的发展（归大主题8/L6-03）。

本次 numpy 实证——在人工构造的线性可分数据（保留间隔）上，感知机 2 个 epoch、仅 2 次更新即达 100% 训练正确率，直观印证"可分则有限步收敛"。但要记住三条边界：(a) 收敛到的解**不唯一**（找到任一个能分开的超平面就停，不像 SVM 找最大间隔那个，SVM 归大主题5）；(b) 不可分时不收敛，实践中要么加最大迭代数上限、要么改用间隔/软化的变体（如 pocket 算法、SVM、逻辑回归）；(c) 收敛速度对间隔 γ 敏感，间隔越小越慢。

### 3.5.4 与逻辑回归的辨析、以及作为神经元的地位

把感知机和逻辑回归并排看，能一次厘清本大主题的两端。二者都用线性打分 wᵀx、都用形似 Σ(y−h)x 的更新，但三点不同：其一，输出——感知机是硬 0/1（无概率），逻辑回归是软 [0,1] 概率；其二，目标——感知机最小化的是"误分类"这个不可导的量（无光滑损失/无 MLE），逻辑回归最大化伯努利似然（光滑、凸）；其三，可分不可分数据上的行为——感知机在不可分数据上震荡不收敛，逻辑回归在不可分数据上照样收敛到一个概率最优解（间隔为 0 也无妨）。

正因逻辑回归光滑、有概率、不可分也稳，实践中的线性分类几乎都用逻辑回归/SVM 而非原始感知机。感知机的现代价值主要是**教学与历史**：它是理解"线性加权 + 激活 = 一个神经元"的最小模型，是从经典机器学习通往神经网络的门槛。把它的硬阈值换成 sigmoid，就回到了 3.1 的逻辑回归；把很多这样的单元堆成多层、换上可导激活并用反向传播训练，就进入了大主题8 与 L6-03 的深度学习——本报告到此为界，深读归那两处。
