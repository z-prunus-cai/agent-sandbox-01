## 6.1 偏差-方差分解

### 6.1.1 为什么要把泛化误差拆开看

监督学习的终极目标不是把训练数据拟合得多好，而是在**没见过的新数据**上表现好，即让**泛化误差**（也叫期望测试误差、期望风险）尽量小。偏差-方差分解回答的问题是：这个泛化误差是由哪些成分组成的？为什么增加模型复杂度有时帮倒忙？

要把这件事讲清，需要一个"思想实验"式的设定。想象我们能反复地从同一个数据分布里抽取**很多套**训练集，每套都训练出一个模型。这些模型的预测彼此不同，因为每套训练集的随机抽样不同、噪声不同。偏差-方差分解就是站在"对所有可能的训练集取平均"这个视角，把某个固定测试点上的期望误差拆成三块可解释的量。它不是某个具体模型的性质，而是"某个学习算法 + 某种模型复杂度"这一组合的性质。

### 6.1.2 三分公式：偏差² + 方差 + 噪声

设真实关系为 y = f(x) + ε，其中噪声 ε 均值为 0、方差为 σ²，与 x 独立。对某固定测试点 x₀，用平方损失，泛化误差在"对训练集 D 取期望"意义下分解为三项：

E_D[ (y − f̂(x₀))² ] = ( E_D[f̂(x₀)] − f(x₀) )² + E_D[ ( f̂(x₀) − E_D[f̂(x₀)] )² ] + σ²

写成命名形式：

期望测试误差 = 偏差²(x₀) + 方差(x₀) + 不可约噪声

其中三项分别是：

偏差(x₀) = E_D[f̂(x₀)] − f(x₀)

方差(x₀) = E_D[ ( f̂(x₀) − E_D[f̂(x₀)] )² ]

不可约误差 = σ²

这个恒等式是**精确**的（对平方损失、噪声独立同分布的假设下代数展开即得，交叉项因 ε 均值为 0 而消失），四本教材（CS229 偏差-方差讲义、ISL §2.2.2、ESL §7.3 式 7.9、PRML §3.2）在公式上完全一致。

这个分解的直觉可以这样看——把误差写成 (f̂ − f) 再拆成 (f̂ − E[f̂]) + (E[f̂] − f)，平方后展开有三项。中间的交叉项 2·(f̂−E[f̂])·(E[f̂]−f) 在对 D 取期望时，因为 E[f̂−E[f̂]]=0 而整体为 0，于是只剩"平均预测偏离真值的平方"（偏差²）和"预测围绕自己均值的抖动"（方差），再加上 y 本身自带的噪声 σ²。噪声这一项来自数据生成过程，**任何模型都消不掉**——它是泛化误差的下界（贝叶斯误差），这是初学者要记牢的第一件事：不是误差越小越好，低于 σ² 本身就说明你在拟合噪声。

### 6.1.3 偏差与方差各自的含义

偏差衡量的是**模型的平均预测系统性地偏离真相多少**。高偏差意味着模型太简单/假设太强，连数据的主要趋势都抓不住——比如用一条直线去拟合明显弯曲的关系，无论换多少套训练集，平均而言都拟合不到位。高偏差对应**欠拟合**。

方差衡量的是**模型对训练集的随机波动有多敏感**。高方差意味着模型太灵活，换一套训练集就学出很不一样的函数——它把这套样本里的噪声也当成了信号去拟合。高方差对应**过拟合**。

一个最小例子是拟合一批带噪声的、真实关系是正弦曲线的点。用 1 次多项式（直线）——不管抽哪套数据都是差不多那条斜线，各套之间几乎不变（方差极低），但都离正弦曲线很远（偏差很高），这是欠拟合。用 15 次多项式——每套数据都能被穿过几乎每个点（偏差极低），但换一套数据曲线就疯狂扭动成完全不同的样子（方差爆炸），这是过拟合。本次蒙特卡洛实证正是这个例子：1 次多项式偏差²≈0.18、方差≈0.02；15 次时偏差²和方差都以万计爆炸。用 3 次时偏差²≈0.003、方差≈0.016，两者都小——这就是甜点。

### 6.1.4 偏差-方差权衡与 U 形泛化曲线

偏差和方差随模型复杂度**反向变化**：复杂度升高，模型更灵活，偏差单调下降、方差单调上升。因为泛化误差 = 偏差² + 方差 + 噪声，两条反向曲线相加就得到一条**先降后升的 U 形曲线**，最低点即最优复杂度。这就是**偏差-方差权衡**（bias-variance tradeoff），是模型选择的核心矛盾。

最优点的定位靠一条原则——**不是让偏差最小，也不是让方差最小，而是让两者之和最小**。在最优点左侧（欠拟合区）偏差主导，应增加复杂度；右侧（过拟合区）方差主导，应降低复杂度或加正则/加数据。

从关联上看，这条 U 形曲线是本大主题后续一切的"总纲"。正则化（6.2/6.3）是把模型从 U 形右侧（高方差）往左压；特征选择（6.6）同理降复杂度；交叉验证（6.4）是用来**找到 U 形最低点**对应的超参数；验证曲线（6.5）就是把这条 U 形**画出来**。一个常见误区是把"复杂度"狭义理解成多项式次数——它泛指模型的有效自由度：正则强度（λ 越大复杂度越低）、树的深度、神经元数、特征数、训练轮数都是复杂度旋钮。

### 6.1.5 双下降现象（现代补充）

`⚙演进快·锚 2019 论文时点`

经典的 U 形权衡在一个现代场景下会**失效**：当模型参数量大到能**完全插值**训练数据（训练误差降到 0）之后，继续增大模型，测试误差不再单调上升，反而会**二次下降**，甚至降到比经典 U 形最低点还低。把测试误差对模型规模作图，会看到"下降—上升—（在插值阈值处冲高）—再下降"的形状，故称**双下降**（double descent）。

这一现象由 Belkin 等人 2019 年在 PNAS 系统提出并命名，Nakkiran 等人 2019 年在深度网络上刻画为"模型规模双下降/训练轮数双下降"（epoch-wise double descent），是理解为什么**超大过参数化神经网络反而泛化更好**的关键线索之一。它并不推翻经典偏差-方差分解（在欠参数化区间经典 U 形仍成立），而是揭示分解在**过参数化插值区间**需要新的解释——峰值出现在参数量≈样本量的插值阈值处，越过后进入一个"隐式正则"起作用的新区间。

这里要把握分寸、也要注意时效——这是一个**活跃研究议题**，机制解释（隐式正则、有效复杂度、优化路径的作用）仍在演进，**不宜当作定论**。初学者的正确认知是：(a) 在你手写的、样本远多于参数的经典模型上，**依然按 U 形权衡办事**——双下降不给你"参数越多越好"的许可；(b) 只有到深度学习的过参数化区间，才需要用双下降视角重新审视。本条硬标 `⚙演进快`，锚 2019 年论文时点，后续结论可能修订。深度学习语境的进一步讨论归 L6-03。

### 6.1.6 分类问题下的分解（一处需分清的表述差异）

上述干净的"偏差² + 方差 + 噪声"三分**只在平方损失下精确成立**。对分类的 0-1 损失，泛化误差同样可以定性地谈偏差和方差，但**不存在唯一、公认、代数上干净的加性分解**——文献里有多种定义（如 Domingos 2000 的统一框架、Kohavi-Wolpert 分解等），它们对"偏差""方差"如何组合成 0-1 误差给出不同（有时是相乘或带符号的）关系。这是教材与文献间的一处**表述差异**（非对错冲突）：ISL/ESL/PRML 主要在**回归+平方损失**下给出精确三分，而把分类下的偏差-方差当作**定性直觉**使用。

落到实践上，不要试图在分类问题上死抠"偏差² + 方差 + σ²"这个等式——它不成立。要保留的是**定性直觉**：简单分类器（如线性判别）偏差高、方差低；复杂分类器（如深树、KNN 小 k）偏差低、方差高；权衡与 U 形规律依然适用。做题和调模型时用定性版本即可，需要精确分解时明确自己用的是哪一种定义。

## 6.2 L2 岭回归（收缩）

### 6.2.1 岭回归的目标函数与闭式解

**岭回归**（ridge regression，Tikhonov 正则化）是在普通最小二乘的损失上加一个**系数平方和惩罚项**（L2 惩罚）的线性回归：

J(β) = ‖y − Xβ‖² + λ‖β‖²

其中 λ ≥ 0 是正则化强度（超参数），‖β‖² = Σⱼ βⱼ² 是系数的 L2 范数平方（一般**不惩罚截距 β₀**）。它有和普通最小二乘一样漂亮的**闭式解**：

β̂_ridge = (XᵀX + λI)⁻¹ Xᵀy

λ=0 时退化回普通最小二乘 (XᵀX)⁻¹Xᵀy；λ→∞ 时所有系数被压向 0。四本教材（CS229、ISL §6.2.1、ESL §3.4.1、PRML §3.1.4）在目标函数与闭式解上完全一致。

可以把损失函数想成两股拉力的拔河。第一项 ‖y−Xβ‖² 要求"贴合数据"，把系数往能减小训练误差的方向拉；第二项 λ‖β‖² 要求"系数别太大"，把系数往 0 拉。λ 就是后者的话语权：λ 越大，越倾向于"宁可训练误差大一点，也要系数小"。这正是 6.1 里"用一点偏差换方差下降"的具体实现——限制系数幅值就是限制模型灵活度。

### 6.2.2 收缩效应

岭回归的核心行为是**收缩**（shrinkage）：它把系数**成比例地往 0 压小，但一般不压到恰好 0**。在特征正交的理想情形，可以看得最清楚——每个最小二乘系数被乘上一个 (0,1) 的因子：

β̂ⱼ_ridge = β̂ⱼ_ols / (1 + λ)

λ 越大收缩越狠，所有系数一起缩，但都保持非零。本次实证：λ=0 时系数 L2 范数 8.43，λ=1 时缩到 2.88，λ=100 时缩到 1.01——单调收缩，与公式一致。

收缩为什么能降方差？大的系数意味着模型对输入的微小变化反应剧烈（陡峭），也就对训练集噪声敏感——换套数据系数就大变（高方差）。把系数按住不让它变大，模型就"稳"了，换套数据结论也差不多（低方差），代价是无法精确拟合（偏差略升）。易错点：岭回归**不做特征选择**——它把无关特征的系数压得很小但不置零，所有特征都保留（本次实证 Ridge 在 10 维数据上保持 10 个全非零）。想要"系数变 0、自动选特征"必须用 L1/Lasso（6.3）。

### 6.2.3 条件数改善与共线性

岭回归的另一个关键好处是**数值稳定性**：当特征高度相关（多重共线性）或特征数接近/超过样本数时，XᵀX 接近奇异（近乎不可逆），普通最小二乘的 (XᵀX)⁻¹ 会放大噪声、给出巨大且不稳定的系数。岭回归给对角线加了 λ：

XᵀX + λI

这保证了矩阵**严格正定、必可逆**（因为加了 λ 到每个特征值上，把接近 0 的小特征值抬起来），从而**改善条件数**（最大与最小特征值之比），让解稳定。

把这件事量化后直觉更清楚。本次实证——对一个含近共线列的设计矩阵，cond(XᵀX)≈5.7×10⁶（病态，解会剧烈震荡），加 λI 后 λ=0.01 时降到≈1.26×10⁴、λ=1 时≈127、λ=10 时≈14。条件数越小，矩阵求逆越"抗噪"，系数越稳。直觉上，共线性意味着"两个特征几乎携带同一信息"，最小二乘无法决定该把权重分给谁，于是给出一个 +巨大/−巨大 相互抵消的病态解；λI 相当于施加"系数别太大"的仲裁，把这种拉锯拉回可控范围。岭回归的历史动机（Hoerl & Kennard 1970）正是治共线性，ISL §6.2 与 ESL §3.4.1 都强调这一数值层面的价值。

### 6.2.4 贝叶斯解释：高斯先验下的 MAP

岭回归有一个漂亮的概率解释：它等价于在系数上放一个**均值为 0 的高斯先验**、再做**最大后验估计（MAP）**。若假设 y | x ~ 高斯（对应平方损失似然），系数先验 βⱼ ~ N(0, τ²)，则后验的对数正好是"负平方损失 − (常数)·‖β‖²"，最大化后验 = 最小化岭回归目标，且

λ = σ² / τ²

（噪声方差与先验方差之比）。

这个等价关系的意义在于解释了 λ 的贝叶斯含义——先验方差 τ² 越小（越坚信"系数应该接近 0"），λ 越大，收缩越强。这也和 6.3 Lasso 形成对照：Lasso 对应的是**拉普拉斯（双指数）先验**而非高斯先验，正是拉普拉斯先验在 0 处的尖峰导致了稀疏。这条"L2↔高斯先验、L1↔拉普拉斯先验"的对应，PRML §3.3 与 ESL §3.4 都给出，是理解两种正则本质差异的钥匙。

### 6.2.5 标准化的必要性与 λ 的选择

岭回归**对特征尺度敏感**，使用前必须**标准化特征**（每列减均值除标准差）。原因：惩罚项 Σβⱼ² 平等地惩罚每个系数，但若某特征单位是"米"、另一个是"公里"，同样的物理效应在"米"下系数会大 1000 倍、被惩罚得更狠——尺度不同导致惩罚不公平。标准化后所有特征同量纲，惩罚才公平。截距通常不标准化、也不惩罚（否则模型会被强制过原点）。

λ 没有解析最优值，用**交叉验证**（6.4）在一串候选（如 λ ∈ 对数网格 10⁻³…10³）里挑使验证误差最小者。sklearn 的 `RidgeCV` 用高效的 LOO 公式（利用闭式解可一次性算出所有留一残差，不必真跑 n 次）来选 λ；本次实证 `RidgeCV` 在 sin 数据上自动选出 α≈0.09。

忘记标准化是岭回归/Lasso 最常见的错误，会让结果由"谁的单位大"主导而非"谁真正重要"。另一个易错点是术语：sklearn 里 `Ridge(alpha=λ)` 的 `alpha` 就是本节的 λ；而 `LogisticRegression(C=…)` 里的 C 是**λ 的倒数**（C 越大正则越弱），两者方向相反，别混（这一点在大主题3 已埋伏笔）。

## 6.3 L1 Lasso（稀疏）

### 6.3.1 Lasso 的目标函数与稀疏性

**Lasso**（Least Absolute Shrinkage and Selection Operator，Tibshirani 1996）把岭回归的 L2 惩罚换成 **L1 惩罚**（系数绝对值之和）：

J(β) = ‖y − Xβ‖² + λ‖β‖₁

其中 ‖β‖₁ = Σⱼ |βⱼ|。这个看似微小的改动带来一个质变的性质：**Lasso 会把一部分系数压成恰好 0**，从而**自动做特征选择**——λ 越大，被置零的系数越多，最终只留下模型认为最重要的少数几个特征。这叫**稀疏解**（sparse solution）。四本教材（CS229、ISL §6.2.2、ESL §3.4.2/§3.4.3、PRML §3.1.4）在这一定义性性质上完全一致。

Lasso 虽只是把岭回归的惩罚项一换，结果却大不同。本次实证——10 维、真实只有 3 个非零系数的数据，λ（sklearn 的 `alpha`）从 0.001→0.05→0.2 时，非零系数数从 10→5→3，**恰好恢复了真实的 3 个支撑变量**，其余压成 0；而同一数据用 Ridge（λ=1）保持 10 个系数全非零。这就是"稀疏"的直观含义：Lasso 输出的模型只依赖少数特征，可读性强、也更省。

### 6.3.2 为什么 L1 产生稀疏而 L2 不会（几何直觉）

同样是把系数往 0 压，为什么 L1 能压到恰好 0、L2 不能？关键在两种惩罚的**约束区域形状**。把带惩罚的优化等价地看成"在一个约束区域内最小化训练误差"：L2 的约束区域是**圆/球**（‖β‖₂ ≤ t，边界光滑无角），L1 的约束区域是**菱形/多面体**（‖β‖₁ ≤ t，有尖角，尖角正好落在坐标轴上）。训练误差的等高线（椭圆）从外向内收缩，第一次碰到约束区域的点就是解。

碰到圆时，接触点几乎总在光滑边界上、各坐标都非零（L2 不稀疏）；碰到菱形时，**椭圆极易先碰到菱形的尖角**，而尖角在坐标轴上意味着某些坐标恰为 0（L1 稀疏）。维度越高，L1 的"角"越多（都在坐标子空间里），碰角的概率越大，稀疏越普遍。

还有一个等价的直觉来自软阈值。在正交特征下，L1 的解是对最小二乘系数做**软阈值**——

β̂ⱼ = sign(β̂ⱼ_ols) · max(|β̂ⱼ_ols| − λ/2, 0)

即"把每个系数的绝对值减去一个固定量 λ/2，减到负就归零"。对比之下 L2 是**成比例缩**（乘 1/(1+λ)，永不为 0）。"减固定量 vs 乘固定比例"正是"能归零 vs 不能归零"的数学根源：减法能把小系数减到 0 以下再截断为 0，乘法只会让它越来越小但永远非零。ESL §3.4.3 给出这两个正交情形的闭式对照，是最干净的稀疏性证据。

### 6.3.3 无闭式解与求解方法

与岭回归不同，Lasso **没有闭式解**——因为 |β| 在 0 处不可导，无法像岭回归那样求导置零解出。它需要迭代优化，常见解法有三类：**坐标下降**（coordinate descent，sklearn `Lasso` 默认，每次固定其他系数、对单个系数做软阈值更新，简单高效）；**LARS**（Least Angle Regression，Efron 等 2004，能一次算出整条系数路径）；以及**次梯度/近端梯度**（proximal gradient / ISTA，把不可导的 L1 用近端算子处理）。

初学者不必掌握这些求解器的内部，只需知道两点。其一，"无闭式解"不代表"难解"——L1 目标仍是**凸函数**，全局最优唯一存在（虽然在相关特征下最优系数向量可能不唯一），坐标下降几十次迭代即收敛。其二，**系数路径**（coefficient path，系数随 λ 从大到小变化的轨迹）很有用：λ 很大时全为 0，λ 减小时特征一个个"进入"模型，画出来能直观看到特征的重要性排序。sklearn `lasso_path`/`lars_path` 可画此图。

### 6.3.4 Lasso vs Ridge 辨析与 Elastic Net

两者并排是本小主题的重点。相同点：都在最小二乘上加惩罚、都需标准化、都用 CV 选 λ、都用偏差换方差。不同点有三：**稀疏性**——Lasso 出稀疏解（做特征选择），Ridge 不出（保留全部特征）；**相关特征处理**——一组高度相关的特征里，Lasso 倾向**任选一个、其余置零**（不稳定，换套数据可能选另一个），Ridge 倾向**把权重平摊到这组特征上**（稳定）；**几何**——L1 菱形有角、L2 圆无角。

两者间的选择原则是这样的——怀疑"真正相关的特征只是少数"（真稀疏）且想要可解释的精简模型，就用 Lasso；怀疑"很多特征都有小贡献"或存在强共线性、更看重稳定与预测精度，就用 Ridge。当两者的优点都想要时，用 **Elastic Net**（弹性网，Zou & Hastie 2005），它把 L1 和 L2 惩罚线性组合：

J(β) = ‖y − Xβ‖² + λ( α‖β‖₁ + (1−α)‖β‖₂² )

α 控制两者比例。Elastic Net 既能稀疏、又能像 Ridge 那样把相关特征**成组保留**（grouping effect），是 p ≫ n 且特征相关时的稳健折中。ISL §6.2 与 ESL §3.4 都给出这套对照。

有个好记的比方——Ridge 是"民主"（雨露均沾、都留但都小），Lasso 是"独裁"（选少数、其余清零），Elastic Net 是"联合政府"（既清理又保护成组的相关特征）。

### 6.3.5 Lasso 的局限

三条要记的局限。其一，**p > n 时最多选出 n 个特征**（受样本数限制），高维基因数据里可能不够。其二，**相关特征选择不稳定**——前述"任选一个"的行为使得被选中的具体特征对数据抽样敏感，可复现性差（Elastic Net 缓解此点）。其三，**选择一致性有条件**——Lasso 能否恰好选中真实支撑集，依赖"无关特征与相关特征不能太相关"这类技术条件（irrepresentable condition），并非无条件保证；这是学习理论/高维统计的内容（深挖归大主题11 及高维统计专著），初学者知道"Lasso 选出的特征子集要当参考而非真理"即可。

落到实践，Lasso 极适合"从几百上千个候选特征里快速筛出一小撮"的探索性场景，但**不要**把它选出的特征当成"因果重要"或"唯一正确子集"。稳健做法：多次重抽样跑 Lasso 看哪些特征稳定被选（stability selection 思路），或改用 Elastic Net。

## 6.4 交叉验证

### 6.4.1 为什么需要交叉验证

模型选择（挑 λ、挑多项式次数、挑哪个算法）需要**估计泛化误差**，但训练误差是有偏的（复杂模型总能把训练误差压得很低，见 6.1），不能用来选；而真正的测试集**只能用一次**（用它调参就等于把它泄漏成了训练信号，见 6.4.5）。交叉验证（cross-validation，CV）解决的正是这个矛盾：**只用训练数据，通过反复切分"训练子集 + 验证子集"，得到对泛化误差的无（低）偏估计**，用它来选超参数。

定位上，先把数据分成"训练+测试"两份，测试锁进保险箱最后才开；在训练这份里再用 CV 来选超参数。CV 的产物是"每个候选超参数的估计泛化误差"，你选让它最小的那个，然后用全部训练数据在该超参数下重训得到最终模型，最后才用测试集报告一次性能。这个三层纪律（训练/验证/测试）是大主题2 已埋的伏笔，本节把"验证"这一步做实。

### 6.4.2 k 折交叉验证

**k 折交叉验证**（k-fold CV）把训练数据随机均分成 k 个大小相近的"折"（fold），然后做 k 轮：每轮留一折当验证集、其余 k−1 折当训练集，训练并在留出折上评估，得到 k 个验证误差，取平均作为该模型/超参数的 CV 误差估计：

CV(k) = (1/k) Σ_{i=1}^{k} Err_i

其中 Err_i 是第 i 折作验证时的误差。常用 k=5 或 k=10。本次实证：5 折 CV-MSE 随多项式次数呈 U 形，在 deg=4 附近取最小（≈0.044），与真实 sin 复杂度吻合——这正是"用 CV 找 6.1 那条 U 形的最低点"。

为什么要 k 轮而不是切一刀？切一刀（单次留出法 hold-out）的估计**方差大**——恰好切到"难"的验证子集或"易"的，结果会很不同。k 折让每个样本都当过一次验证、k−1 次训练，取平均，估计更稳，且数据利用率高（每轮用了 (k−1)/k 的数据训练）。这是 6.1 偏差-方差思想在"评估器"本身上的又一次应用：单次留出高方差，k 折平均降方差。

### 6.4.3 留一交叉验证（LOO）

**留一法**（Leave-One-Out CV，LOOCV）是 k = n 的极端 k 折：每轮只留**一个**样本当验证、其余 n−1 个全用来训练，做 n 轮。本次实证确认 `LeaveOneOut` 与 `KFold(n)` 折数（40）和结果完全一致——LOO 就是 n 折。

从权衡看，LOO 的优点是每轮训练集几乎用满（n−1 个），对训练集大小的**偏差最小**；缺点有二——其一，要训练 n 次，**计算贵**（n 大时几乎不可行，除非有捷径）；其二，n 个训练集彼此高度重叠（只差一个样本），产出的 n 个模型高度相关，取平均**降方差有限**，故 LOO 估计的**方差反而偏大**（ISL §5.1.3 明确点此）。一个重要例外：对**线性模型/岭回归**，LOO 有闭式捷径（generalized/leave-one-out 公式），一次拟合即可算出所有 n 个留一残差，不必真训 n 次——这就是 `RidgeCV` 默认用 LOO 也很快的原因。

### 6.4.4 k 的选择：CV 估计自身的偏差-方差

k 的选择本身是一个偏差-方差权衡（针对"CV 估计量"）：k 小（如 2 折）→ 每轮训练集小、更偏离"用全量训练"的真实情形 → 估计**偏差大**，但 k 个模型相关性低 → **方差小**、计算便宜；k 大（如 LOO）→ 训练集接近全量 → **偏差小**，但模型高度相关 → **方差大**、计算贵。**k = 5 或 10 是经验上的甜点**，ISL §5.1.4 与 ESL §7.10 都推荐这个折中——偏差和方差都适中。

落地口诀很简单——默认用 **5 折或 10 折**；数据极少且模型训练便宜（如线性/岭回归有 LOO 捷径）时可考虑 LOO；数据很多时 5 折足矣（每折都够大）。不要盲目追求 k=n。

### 6.4.5 交叉验证的陷阱

四个必须知道的坑。其一，**数据泄漏**——任何"用到了全体数据信息"的预处理（标准化、特征选择、缺失值填补、PCA）**必须放进 CV 循环内**、只在每轮的训练折上 fit，再 transform 到验证折；若在切分前对全体数据做这些，验证折的信息就泄漏进了训练，CV 误差会**乐观偏低**。sklearn 的 `Pipeline` 正是为把预处理封进 CV 而设计。其二，**用同一 CV 既选超参又报告性能会乐观偏差**——选超参的过程已经"看过"了验证数据，正确做法是**嵌套交叉验证**（nested CV：外层估性能、内层选超参）或独立测试集。其三，**分层**——分类且类别不平衡时用**分层 k 折**（StratifiedKFold，保证每折类别比例一致），否则某折可能没有少数类。其四，**分组/时序**——样本有分组结构（同一病人多条记录）时用 `GroupKFold` 防同组跨折泄漏；时间序列**不能随机打乱**，要用前向的 `TimeSeriesSplit`（只能用过去预测未来）。

这里有一条最高优先级的提醒——**数据泄漏是 CV 最常见、最隐蔽、后果最严重的错误**——它让你在纸面上看到漂亮的 CV 分数，上线却翻车。牢记一句话：**CV 的每一折都要模拟"模型第一次见到验证数据"，任何让训练折偷看到验证折的操作都是泄漏**。这条纪律贯穿全组（大主题12 会再强调），是从"会调 API"到"会做机器学习"的分水岭。

## 6.5 学习曲线 / 验证曲线

### 6.5.1 两种诊断曲线的分工

学习曲线和验证曲线是把 6.1 偏差-方差**画成图来诊断**的两个工具，横轴不同、用途不同，初学者极易混淆，先厘清分工。**验证曲线**（validation curve）横轴是**模型复杂度**（如多项式次数、λ、树深），画训练误差和验证误差随复杂度的变化——用来找 6.1 那条 U 形的**最优复杂度**。**学习曲线**（learning curve）横轴是**训练样本数**，固定复杂度画训练误差和验证误差随数据量的变化——用来判断"当前瓶颈是偏差还是方差、加数据有没有用"。

可以用一句话区分二者——验证曲线问"**模型该多复杂**"，学习曲线问"**该不该再要数据**"。两者都同时画训练和验证两条线，靠**两条线的高低与间距**读出诊断结论。

### 6.5.2 验证曲线：误差 vs 复杂度

验证曲线上，随复杂度增加：训练误差**单调下降**（模型越灵活越能贴训练数据）；验证误差**先降后升**（U 形）。两条线的关系揭示状态——复杂度太低时两条线都高且接近（欠拟合/高偏差）；复杂度太高时训练误差趋 0 而验证误差回升、两线**间距拉大**（过拟合/高方差）。最优复杂度在验证误差的**最低点**。

读图时，训练误差和验证误差之间的**间距（gap）就是方差的代理**——间距越大，模型对训练集越"偏心"、泛化越差。这张图是选超参数的可视化版本（数值版就是 6.4 的 CV）。sklearn `validation_curve` 直接产这张图（横轴给一串超参值，纵轴给 CV 的训练/验证分数）。

### 6.5.3 学习曲线：误差 vs 训练样本数

学习曲线固定模型复杂度，横轴是训练集大小 m，画两条线：训练误差随 m **上升**（样本越多越难全部拟合好，从很低慢慢升），验证误差随 m **下降**（样本越多泛化越好，从很高慢慢降）。随着 m 增大两条线相互靠拢，收敛到一个**平台（渐近误差）**。

机制上可以这样理解——m 很小时模型能轻松记住全部训练点（训练误差≈0），但学到的规律不可靠（验证误差高），两线间距大；m 增大后模型再也记不住全部（训练误差升），但学到的规律更真（验证误差降），两线收敛。收敛到的**平台高度**约等于该复杂度下的偏差 + 噪声底线。

### 6.5.4 诊断读图：高偏差 vs 高方差及对策

学习曲线的诊断价值集中在"两线收敛到的平台"和"两线的间距"：

高偏差（欠拟合）——两条线**很快收敛**并**一起停在较高**的误差平台，间距小。含义：模型太简单，加再多数据也没用（两线已贴合、平台还高）。对策：**增加复杂度**（更高次特征、更深模型、减小 λ）、加特征，而**不是**加数据。

高方差（过拟合）——训练误差**很低**、验证误差**明显更高**，两线间存在**大间距**且**尚未收敛**（随 m 增大还在缩小）。含义：模型够复杂但数据不够。对策：**加数据**（间距会随 m 继续缩小）、加正则（6.2/6.3）、减复杂度或做特征选择（6.6）。

这张图的决策价值在于解决了实践中最烧钱的问题——"我该花力气标更多数据，还是换更强的模型？"学习曲线给出证据：两线已收敛在高位（高偏差）→ 加数据是浪费，去加复杂度；两线间距大且在缩小（高方差）→ 加数据值得。这条"看间距是否随数据缩小来决定要不要加数据"的读法，是 Andrew Ng（CS229 及其应用课）反复强调的实战诀窍。此外，**早停**（early stopping，以验证误差不再下降为停训信号）是学习曲线思想在"训练轮数"这个复杂度旋钮上的应用，作为一种隐式正则——深度学习语境的早停/Dropout 等归 L6-03 §03-2，此处只点出它与本节同源。

## 6.6 特征选择（过滤/包裹/嵌入式）

### 6.6.1 为什么做特征选择

**特征选择**（feature selection）是从原始特征集里挑出一个**子集**用于建模，目的有三：降低复杂度（对抗 6.1 的高方差/维度灾难）、提升可解释性（少数特征的模型更好懂）、减少存储与计算。它与正则化（6.2/6.3）是降复杂度的两条互补路线——正则化收缩**系数**、特征选择删除**特征**（Lasso 是两者的交汇：靠收缩实现删除）。

从动机上讲，特征不是越多越好。无关特征会给模型引入噪声维度、增大方差、拖慢训练、还可能造成虚假相关（尤其 p 接近或超过 n 时）。特征选择就是"先做减法"。经典分法把方法按"与模型的耦合程度"分为三类：过滤式、包裹式、嵌入式，下面逐一讲，最后对比。

### 6.6.2 过滤式（filter）

**过滤式**在建模**之前**，用与模型无关的**统计指标**给每个特征打分、排序、留高分者。常用指标：与目标的**相关系数**（皮尔逊，适连续）、**互信息**（能抓非线性依赖）、**卡方检验**（适类别特征）、**方差阈值**（删掉几乎不变的特征）、单变量 **F 检验/ANOVA**。sklearn 对应 `SelectKBest`/`SelectPercentile`/`VarianceThreshold`/`f_classif`/`mutual_info_classif`。

过滤式的优点是**快、与模型解耦、可扩展到超高维**（只算统计量，不训模型），常用作预处理第一道粗筛。缺点有二——其一，**单变量**评估，只看"该特征单独与目标的关系"，忽略**特征间的相互作用**（两个各自与目标无关的特征组合起来可能极有用，过滤式会把它们都删掉；反之两个高度冗余的特征可能都被留下）；其二，评分与最终模型无关，选出的未必对该模型最优。易错点：过滤要**放进 CV 循环内**（在训练折上算统计量），否则用全体数据算相关性就是 6.4.5 的泄漏。

### 6.6.3 包裹式（wrapper）

**包裹式**把特征子集的好坏交给**目标模型本身**来评判：反复地"选一个子集 → 训练模型 → 用 CV 评估 → 根据表现调整子集"，直到找到（近似）最优子集。经典策略：**前向选择**（从空集开始逐个加最有用的）、**后向消除**（从全集开始逐个删最没用的）、**递归特征消除**（RFE，反复训练模型、按系数/重要性删最弱特征）。sklearn 对应 `RFE`/`RFECV`/`SequentialFeatureSelector`。

包裹式的优点是**直接优化目标模型的性能**、能捕捉特征间相互作用，选出的子集对该模型通常最好。缺点是**计算极贵**——要为大量候选子集分别训练+CV 模型（完整子集搜索是 2^p 的组合爆炸，前向/后向是贪心近似仍要 O(p²) 量级次训练），且贪心搜索**易过拟合**到验证集、结果不稳定。适用场景：特征数不太多、模型训练不太贵、且值得为精度花算力时。

### 6.6.4 嵌入式（embedded）

**嵌入式**把特征选择**内建进模型训练过程**，训练完成的同时就得到了特征子集——不像过滤式那样与模型脱节，也不像包裹式那样反复外部搜索。最典型的就是 **Lasso/L1 正则**（6.3，训练即把无关系数置零）、**Elastic Net**，以及**树模型的特征重要性**（决策树/随机森林/GBDT 在分裂时天然选特征，可输出重要性排序，归大主题7）。sklearn 用 `SelectFromModel` 包装任意带 `coef_`/`feature_importances_` 的模型来实现。

嵌入式的定位在"过滤式的快"和"包裹式的准"之间的甜点——它在一次训练里完成选择（不必像包裹式反复训练），又用了模型自身的信号（不像过滤式与模型脱节）。这也是为什么**Lasso 在实践中是最常用的特征选择手段之一**：一次拟合，既建模又选特征。缺点是选择行为与该模型强绑定（Lasso 选的对线性模型好，未必对别的模型好），且继承该模型的局限（Lasso 在相关特征上的不稳定，见 6.3.5）。

### 6.6.5 三法对比、与降维的辨析、陷阱

三法可以一表对比。**过滤式**——最快、与模型无关、忽略交互，用于超高维粗筛；**包裹式**——最准（对目标模型）、能抓交互、最贵且易过拟合，用于中小特征集精选；**嵌入式**——速度与效果折中、一次训练完成、与模型绑定，用于日常主力（尤其 Lasso/树）。实践常**组合使用**：先过滤式粗筛到可控规模，再嵌入式或包裹式精选。

与降维的辨析（易混）：特征**选择**保留**原始特征的子集**（模型仍用"身高""体重"这些原变量，可解释）；特征**提取/降维**（PCA、流形，归大主题10）造出**新特征**（原变量的线性/非线性组合，如"第一主成分"，不可直接解释）。两者都降维度，但一个"删列"、一个"造新列"，目的和可解释性不同，别混为一谈。

有一条陷阱总纲必须刻死——**所有特征选择都必须在交叉验证的训练折内进行**——在切分前用全体数据（含验证/测试）做特征选择，是最经典也最致命的泄漏（ESL §7.10.2 专门用一个例子警示：先用全数据选特征再 CV，会得到荒谬乐观的结果）。正确做法是把特征选择当作模型的一部分封进 `Pipeline`，让它在每个 CV 折内独立重做。这条纪律与 6.4.5 一脉相承，是本大主题最该刻进肌肉记忆的一点。
