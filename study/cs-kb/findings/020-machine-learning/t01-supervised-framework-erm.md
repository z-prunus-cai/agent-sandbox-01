## 02-1.1 假设空间与参数化

### 02-1.1.1 监督学习要学的对象是一个映射 h: X → Y

监督学习的目标，是从带标注的数据里学出一个**函数**（也叫预测器、假设、模型），把输入映到输出。

h : X → Y

其中 X 是输入空间（特征所在的空间，常见是 ℝ^d，即 d 维实向量），Y 是输出空间（回归时是 ℝ，二分类时是 {0,1} 或 {−1,+1}，多分类时是 {1,…,K}）。给定训练集

S = {(x⁽¹⁾, y⁽¹⁾), …, (x⁽ⁿ⁾, y⁽ⁿ⁾)}

学习算法要输出一个 h，使得对**新的、没见过的** x，预测 h(x) 尽量接近真实 y。

这里初学者最容易忽略的一点是：我们要学的不是"这 n 个训练点的答案"（那查表就行），而是一个**能推广到新输入的规则**。监督学习之所以可能，是因为我们假设训练数据和未来数据来自**同一个分布** D，学到的规律才能迁移。CS229 讲义把这个映射记作 h（hypothesis 的首字母，历史沿用），ESL 记作 f̂ 或 Ĝ（回归函数/分类器的估计），只是符号差别，指的是同一个东西。

### 02-1.1.2 假设空间 H：你允许算法从哪些函数里挑

学习算法并不是在"所有可能的函数"里搜索——那个集合太大、无法搜索也无法泛化。它是在一个**事先限定的函数集合**里挑，这个集合就叫假设空间（hypothesis space / hypothesis class）H。

H = { h : X → Y }（某个受限的函数集合）

学习问题于是变成：在 H 里挑一个"最好"的 h。怎么定义"最好"由损失和风险决定（见 1.2、1.3），但"能挑的范围"由 H 先框死。

这里可以打个比方，H 就像你去买衣服时那家店的**货架**。你只能在货架上现有的款式里挑最合身的；如果货架上根本没有你的尺码，你再怎么挑也挑不到完美的。H 太小（货架款式太少），可能连真实规律都表达不出来（欠拟合、逼近误差大）；H 太大（货架无所不包），又容易被训练数据的噪声带偏（过拟合、见 1.3.5、大主题6）。选 H 是监督学习的第一个、也是最关键的建模决策。

### 02-1.1.3 参数化：用一组数字 θ 索引 H 里的每个函数

绝大多数实用的 H 是**参数化**的：H 里的每个函数都由一组参数（一个数值向量 θ）唯一确定，学习就退化为"找一组好的数字 θ"。

H = { h_θ : θ ∈ Θ }

最简单的例子是线性模型（CS229 U2 的起点）：

h_θ(x) = θ₀ + θ₁x₁ + … + θ_d x_d = θᵀx

（把 x 补一个恒为 1 的分量后可写成干净的内积 θᵀx，θ₀ 是截距/偏置）。这里 θ ∈ ℝ^{d+1}，每换一组 θ 就得到一条不同的直线/超平面。学习算法要做的，就是在 ℝ^{d+1} 这个**参数空间**里搜索最优的那一点。

参数化把"在函数空间里搜索"这件抽象的事，变成了"在数值向量空间里做优化"这件可计算的事——这是几乎所有机器学习算法能落地的前提。初学者要建立的对应关系是：一个**参数取值** θ ⇄ H 里的一个**具体函数** h_θ ⇄ 输入空间里的一条**决策边界或拟合曲线**。三者一一对应，换个角度看同一件事。神经网络也是这个套路，只是 θ 是几百万到几千亿个权重、h_θ 是层层复合的非线性函数（大主题8 / L6-03）。

### 02-1.1.4 参数化模型 vs 非参数化模型

按参数个数是否随数据量增长，监督学习模型分成两大类，这是 ESL/ISL Ch2 的一条主轴。

**参数化（parametric）模型**：先假定一个固定形式（如线性），参数个数固定，不随训练样本数 n 变。例如线性回归无论 100 个还是 100 万个样本，都是 d+1 个参数。优点是数据需求小、可解释、算得快；风险是如果真实规律不符合假定的形式，再多数据也救不回来（模型设定偏误）。

**非参数化（non-parametric）模型**：不预设固定形式，模型复杂度随数据量增长。例如 k 近邻（k-NN）把训练集本身当"模型"，预测时现查最近的 k 个邻居投票；决策树、核方法也常归此类。优点是灵活、能逼近复杂形状；代价是需要更多数据、更容易过拟合、预测更慢。

"非参数"不是"没有参数"，而是"参数个数不被事先固定死、可随数据增多而增多"。ISL Ch2 用 k-NN 与线性回归的对照来讲这一点：k 很小时 k-NN 非常灵活（低偏差高方差），k 很大时趋于平滑（高偏差低方差）——这正好预告了大主题6 的偏差-方差权衡。选参数化还是非参数化，本质是在"对数据形状做多强的假设"上做权衡。

## 02-1.2 损失函数谱

### 02-1.2.1 损失函数：一次预测"错多少"的标尺

损失函数（loss function）L(y, ŷ) 量化**一次**预测 ŷ 相对真实标签 y 的代价，是一个越小越好的非负数。它是把"预测得好不好"翻译成"可优化的数字"的接口——没有它，"学习"就无从定义。

L : Y × Y → ℝ≥0，  L(y, ŷ) ≥ 0，  y = ŷ 时通常取 0

把每个样本的损失在数据上平均，就得到风险（下一节 1.3）；对风险做最小化，就得到学习算法。所以损失函数的选择直接决定了"你在优化什么"，进而决定了学出来的模型偏好什么样的预测。

**不同损失编码不同的"在乎什么"**。平方损失特别在乎大偏差（因为平方放大离群点）；0-1 损失只在乎"分类对不对"、不在乎"差多少"；交叉熵在乎"你给对的类打了多高的概率"。选损失不是技术细节，而是在陈述你的目标。以下逐个过一遍监督学习最常用的四种。

### 02-1.2.2 0-1 损失：分类问题真正想最小化的那个

0-1 损失是分类任务的"本来目标"：预测对了记 0，预测错了记 1。

L₀₋₁(y, ŷ) = 1[y ≠ ŷ]

（1[·] 是指示函数，条件成立取 1 否则取 0。）它在数据上的平均正是**错误率**（1 − 准确率），是我们直觉上最想降低的量。

它的麻烦在于作为优化目标几乎没法直接用。它对预测分数是**分段常数**——预测分数从 0.4 挪到 0.49 再挪到 0.51，损失要么不变要么突然跳一格，处处梯度为 0 或不存在，梯度类算法完全使不上力；而且直接最小化训练集上的 0-1 损失是 NP 难的组合问题。这就是为什么实践中几乎所有分类器都不直接优化 0-1 损失，而是优化一个"形状好、可微或凸"的**代理损失**（surrogate，见 1.2.6），把 0-1 损失留给**评估**阶段（大主题12）而非训练阶段。这一"训练用代理、评估用 0-1"的分工，是初学者常被绕晕的点，务必分清。

### 02-1.2.3 平方损失：回归的默认

平方损失（squared / L2 loss）是回归任务最常用的损失，惩罚预测值与真值之差的平方。

L(y, ŷ) = (y − ŷ)²

在数据上平均后就是均方误差（MSE）。它光滑、凸、可导，且有漂亮的概率解释——在"真值 = 线性预测 + 高斯噪声"假设下，最小化平方损失等价于极大似然估计（MLE，详见大主题2 的概率解释）。

平方损失的性格是"厌恶大误差"：因为差被平方，一个偏差 10 的样本贡献 100，是偏差 1 的样本（贡献 1）的一百倍。好处是模型会努力照顾大偏差点、拟合平滑；坏处是对**离群点（outlier）敏感**，一个异常值就能把整条拟合线拽歪。想减弱这点可换绝对值损失 |y−ŷ|（L1，对离群点稳健但在 0 处不可导）或 Huber 损失（小误差用平方、大误差用线性的折中）。这里也埋一个易错点：平方损失**不适合分类**——把它套在分类的分数上会"惩罚过度自信的正确预测"（见下方验证：真值为 1 时，分数 f=2 的平方损失反而回升到 1，比 f=1 时的 0 更大），这不合分类的诉求。

下面的 numpy 数值对照（真实标签取正类，y=+1；分数 f 为模型原始打分）把四种损失的性格一次性摆出来，可复现：

```python
import numpy as np
f = np.array([-2.0, -0.5, 0.0, 0.5, 1.0, 2.0])
zero_one = (np.sign(f) != 1).astype(float)   # 0-1（按符号判正类）
hinge    = np.maximum(0, 1 - 1*f)            # hinge, y=+1: max(0,1-f)
p        = 1/(1+np.exp(-f)); ce = -np.log(p) # 交叉熵, y=1: -log sigmoid(f)
sq       = (1-f)**2                          # 平方, 目标1: (1-f)^2
```

真实输出（基线 Py3.11.15/np2.4.6 @2026-07-30）：

```
f=-2.0  0-1=1  hinge=3.000  CE=2.1269  sq=9.000
f=-0.5  0-1=1  hinge=1.500  CE=0.9741  sq=2.250
f=+0.0  0-1=1  hinge=1.000  CE=0.6931  sq=1.000
f=+0.5  0-1=0  hinge=0.500  CE=0.4741  sq=0.250
f=+1.0  0-1=0  hinge=0.000  CE=0.3133  sq=0.000
f=+2.0  0-1=0  hinge=0.000  CE=0.1269  sq=1.000
```

这张表可以这样读，0-1 在 f>0 处才跳到 0（f=0 的边界按 np.sign(0)=0 判为错，故仍记 1）；hinge 在 f≥1 后彻底归零（"分对且间隔够大就不再管"）；CE 永远大于 0、且随 f 增大单调下降（"永远鼓励更自信"）；平方在 f=1 处最小、f=2 又回升到 1（"太自信也要罚"，故不宜做分类损失）。这一眼就能看清四种损失"在乎什么"的差别。

### 02-1.2.4 交叉熵 / 对数损失：概率分类的默认

交叉熵损失（cross-entropy / log loss / logistic loss）是输出概率的分类模型（逻辑回归、softmax、神经网络分类头）的标准损失。二分类下，设模型给出正类概率 p = P(y=1|x)、真实标签 y ∈ {0,1}：

L(y, p) = −[ y·log p + (1−y)·log(1−p) ]

多分类（K 类）下，设模型给出概率向量 p=(p₁,…,p_K)、真实类别用 one-hot 的 y 表示：

L(y, p) = −Σ_{k=1}^{K} y_k·log p_k = −log p_{真实类}

即"只看你给正确类打了多高的概率，取负对数"。概率给得越接近 1，损失越接近 0；给正确类打了接近 0 的概率，损失趋于 +∞（惩罚"自信地错"）。

交叉熵有两条硬核出身，任一都能推出它：其一，它等价于**极大似然**——最小化交叉熵 = 最大化数据在模型下的对数似然（这也是它和逻辑回归天然配对的原因，大主题3）；其二，它等于真实分布与预测分布之间 KL 散度的可优化部分（信息论视角，PRML Ch1）。初学者只需记住行为层面的直觉：交叉熵**不满足于"分类正确"，还要求"概率标定得准"**——这正是它比 0-1 损失更适合训练、且天然产出可用概率的原因。易错点：对数的底数用自然对数（单位 nats，ML 惯例，scikit-learn 的 `log_loss` 即用自然对数）还是 2（单位 bits）不影响最优解，只差一个常数因子；另外数值实现时要对 p 做裁剪（如 clip 到 [1e-15, 1−1e-15]）以防 log(0)。

### 02-1.2.5 hinge 损失：SVM 的间隔损失

hinge（合页）损失是支持向量机（SVM，大主题5）用的损失，用 {−1,+1} 编码标签，f(x) 是模型原始分数：

L(y, f) = max(0, 1 − y·f(x))

乘积 y·f(x) 叫**函数间隔**：同号（分对）且绝对值大表示"分得又对又有把握"。hinge 的逻辑是：只要函数间隔 ≥ 1（分对且离边界够远），损失就是 0，模型不再管它；只有间隔 < 1（分错，或虽分对但离边界太近）才产生正比于"差多少"的线性惩罚。

这个"够好就不管"的性质带来 SVM 的招牌特征——**只有落在间隔边界上或被错分的点（支持向量）才影响最终解**，其余点损失恒为 0、对参数梯度无贡献。对照上表可见 hinge 与交叉熵的分歧：CE 对已经分得很好的点仍持续施加（越来越小的）压力、永不归零，hinge 则对间隔够大的点彻底松手。易错点：hinge 在拐点 y·f=1 处不可导（是次可导），所以 SVM 常用次梯度或转对偶问题求解（大主题5）；另外 hinge 直接作用于分数 f、不产出概率，若要概率需额外校准（大主题12 的 Platt scaling）。

### 02-1.2.6 代理损失与"为什么不用 0-1 直接优化"

上面平方/交叉熵/hinge 三者，本质都是 0-1 损失的**代理损失（surrogate loss）**：它们是 0-1 损失的（缩放后的）**凸上界**，形状光滑或至少凸，便于用梯度/凸优化求解，最小化它们能间接压低 0-1 错误率。

这解释了监督学习一个反复出现的分工：**训练时**优化一个好优化的代理损失，**评估时**才回到我们真正在乎的 0-1 错误率（或大主题12 的各种度量）。为什么这么替换是合理的？因为这些代理是精心设计的——它们在"分错"的区域给出大惩罚、在"分对且有把握"的区域给出小惩罚，与 0-1 损失"方向一致"，且具备**分类一致性（classification-calibrated）**：在理想条件下，最小化代理损失得到的分类器会收敛到贝叶斯最优分类器（见 1.4.2）。这不是随便挑一个可导函数就行，而是有理论保证的替身。初学者记住这条主线即可：0-1 是目的、凸代理是手段；深挖代理损失的一致性理论超出本入门范围（可参 ESL/学习理论文献，属大主题11 相邻内容）。

## 02-1.3 ERM 与期望风险

### 02-1.3.1 期望风险（真风险）：我们真正想最小化的量

给定损失 L 和数据分布 D，一个假设 h 的**期望风险**（expected risk，也叫真风险 true risk、泛化误差、ESL 中的 EPE 期望预测误差）是它在**整个分布上**的平均损失：

R(h) = E_{(x,y)∼D}[ L(y, h(x)) ]

这是学习真正的目标——我们想要的是一个在**未来所有可能数据**上平均犯错最少的 h，而不只是在手头这批数据上表现好。理想的学习就是 argmin_{h} R(h)。

**R(h) 算不出来**。因为分布 D 未知（如果 D 已知，我们直接就能算出最优预测器，根本不需要"学"），我们手里只有从 D 采样出来的有限个样本。所以期望风险是"看不见的靶心"——它定义了我们瞄准的方向，但我们无法直接测量它。这个"想要的目标不可直接计算"的困境，正是整个 ERM 框架要绕过的核心难题。初学者要牢牢分清：R(h) 是关于**分布**的期望，不是关于训练集的平均。

### 02-1.3.2 经验风险：用手上的数据算出来的替身

既然真风险算不出，就用**训练集上的平均损失**来估计它——这就是**经验风险**（empirical risk）：

R̂(h) = (1/n) Σ_{i=1}^{n} L(y⁽ⁱ⁾, h(x⁽ⁱ⁾))

它是期望风险 R(h) 里那个"对分布求期望"被"对 n 个训练样本求平均"替换后的产物。由大数定律，当 n→∞ 且样本 i.i.d. 从 D 抽取时，对任意固定的 h，R̂(h) → R(h)。所以经验风险是真风险的**无偏、且随样本增多而收敛**的估计。

关键前提是 **i.i.d. 假设**（独立同分布）：训练样本相互独立、且都来自那个未来也会遇到的同一分布 D。这条假设是"经验能代表真实"的全部合法性来源——一旦训练数据和实际部署数据分布不同（分布漂移），或者样本之间有依赖（如时间序列、同一用户的多条记录），经验风险就不再是真风险的好估计，学出来的模型会在真实场景翻车。这也预告了 1.5 数据划分纪律为什么如此要紧：切数据的方式若破坏了 i.i.d.，整个 ERM 的地基就塌了。

### 02-1.3.3 经验风险最小化（ERM）原则

**经验风险最小化**（Empirical Risk Minimization, ERM）是监督学习最核心的原则：既然真风险 R(h) 不可算，就退而在假设空间 H 内**最小化能算的经验风险** R̂(h)，用得到的 ĥ 去近似理论最优。

ĥ = argmin_{h ∈ H} R̂(h) = argmin_{h ∈ H} (1/n) Σ_{i=1}^{n} L(y⁽ⁱ⁾, h(x⁽ⁱ⁾))

监督学习里几乎所有"训练"过程都是这条公式的实例：线性回归 = H 取线性函数、L 取平方损失的 ERM；逻辑回归 = 线性打分 + sigmoid、L 取交叉熵的 ERM；SVM = 线性 + hinge（加正则）的 ERM。换 H、换 L，就得到不同的学习算法，但骨架都是"在 H 里最小化训练集平均损失"。

一个监督学习方法 = 「选一个假设空间 H」+「选一个损失 L」+「在 H 上最小化经验风险 R̂」+（通常再加）「一个正则项约束复杂度」。这四件事一确定，算法就确定了。后面大主题2–8 的各种模型，都可以套回这个模板来理解，不必把它们当成互不相干的黑箱。

### 02-1.3.4 泛化差距：经验风险与真风险的差

ERM 直接优化的是 R̂(ĥ)，但我们真正在乎的是 R(ĥ)。两者之差叫**泛化差距**（generalization gap）：

泛化差距 = R(ĥ) − R̂(ĥ)

训练误差 R̂(ĥ) 通常是真风险的**乐观**估计（偏低），因为 ĥ 恰恰是被挑来在训练集上表现最好的——它可能顺带拟合了训练集特有的噪声，这部分"运气"在新数据上不会重现，于是真风险高于训练误差。这个差距正是"模型在训练集上看着好、上线却拉胯"的数学刻画。

一个更细的分解（ESL §2/§7、CS229 学习理论讲义的视角，此处只给直觉，定量界归大主题11）把 ĥ 相对理论最优的**超额风险**拆成两块：

R(ĥ) − R* = [ R(h*_H) − R* ] + [ R(ĥ) − R(h*_H) ]

其中 R* 是所有函数里的最优（贝叶斯风险，见 1.4.2），h*_H 是 H 内最优。第一项叫**逼近误差**（approximation error）——H 本身够不够表达真实规律，H 越大越小；第二项叫**估计误差**（estimation error）——用有限样本挑 h 带来的误差，H 越大、样本越少则越大。二者反向拉扯：H 越复杂，逼近误差降、估计误差升。这正是大主题6 偏差-方差权衡、大主题11 泛化界的统计学根，本报告只把这条主线立住，不做定量推导。

### 02-1.3.5 过拟合与正则化的 ERM

纯 ERM 有一个致命隐患：如果 H 太大（表达力太强），最小化经验风险会让模型把训练集连噪声一起背下来——训练误差可以逼到 0，但真风险很高。这就是**过拟合**（overfitting）：R̂(ĥ)≈0 而泛化差距巨大。极端例子是 1-NN 或足够深的决策树在训练集上零错误，但换数据就崩。

R̂(ĥ) 很小 但 R(ĥ) 很大  ⟺  过拟合（泛化差距大）

实践中因此几乎不用"裸 ERM"，而用**正则化经验风险最小化**（regularized ERM / 结构风险最小化 SRM）：在经验风险上加一个惩罚复杂度的正则项 Ω(h)，用 λ 权衡拟合与简单：

ĥ = argmin_{h ∈ H} [ (1/n) Σ L(y⁽ⁱ⁾, h(x⁽ⁱ⁾)) + λ·Ω(h) ]

Ω 常取参数范数（L2 岭、L1 Lasso，大主题6），λ 越大越偏向简单模型。初学者要建立的因果链：H 太强 → 纯 ERM 会过拟合 → 加正则项压住复杂度 → 用验证集（1.5）挑 λ。这条链把 1.1（选 H）、1.3（ERM）、1.5（划分选超参）、大主题6（正则）串成一条完整的实践流程，不是各自孤立的知识点。

## 02-1.4 回归 vs 分类统一视角

### 02-1.4.1 两类任务的差别只在输出空间 Y 与损失 L

回归和分类不是两套独立的理论，而是**同一个 ERM 框架**在不同"输出空间 + 损失函数"配置下的两次实例化。它们共享 1.1–1.3 的全部骨架：都是在假设空间 H 里最小化经验风险去逼近期望风险，唯一的差别是 Y 和 L 换了。

在回归里 Y = ℝ（连续），L 常取平方损失 (y − ŷ)²
在分类里 Y = {1,…,K}（离散类别），L 概念上是 0-1 损失、训练时用交叉熵 / hinge 等代理

换句话说，"预测一个数"（房价、温度）和"预测一个类别"（垃圾邮件/正常、猫/狗）在建模上是一家人。CS229 讲义正是先讲线性回归（U2）、再把同一套优化思路搬到逻辑回归分类（U3），顺序本身就在传达这层统一性。

初学者常把回归和分类当成两门课分开记，其实抓住"只是 Y 和 L 变了"这一句，就能把大量模型串起来：线性回归↔逻辑回归、回归树↔分类树、SVR↔SVM、回归神经网络↔分类神经网络，每一对都只是同一模型换了输出层与损失。反过来也提醒：把连续标签硬塞进分类（如把年龄分桶）或把有序类别当连续数回归，都可能是选错了 Y/L，要按任务本质选。

### 02-1.4.2 贝叶斯最优预测器：统一框架给出的"理论上限"

统一视角最漂亮的产物，是两类任务都有一个由损失决定的**理论最优预测器**（贝叶斯预测器），它是期望风险的下确界、任何模型都无法超越（除非改变损失或获得更多信息）。关键结论是：**最优预测器长什么样，由你选的损失决定。**

平方损失下，回归的最优预测器是**条件期望**：

f*(x) = E[y | x]

即"给定输入 x，输出 y 的平均值"。0-1 损失下，分类的最优预测器是**贝叶斯分类器**——选后验概率最大的类：

h*(x) = argmax_{c} P(y = c | x)

它达到的最低错误率叫**贝叶斯风险**（Bayes risk），是 1.3.4 里那个 R* 的具体形态。

这给初学者两条极有用的心智锚。其一，"最优"不是绝对的而是**相对于损失**的：换成绝对值损失，回归最优预测器就从条件均值变成条件中位数（这解释了为何 L1 回归对离群点更稳健）；这与 1.2 "损失编码你在乎什么"完全呼应。其二，贝叶斯风险 R* 通常 **不为 0**——因为同样的 x 可能对应不同的 y（数据本身有噪声/不可约的随机性），这部分误差谁也消不掉。它对应大主题6 偏差-方差分解里的**噪声项**，也说明"追求 100% 准确"往往是不切实际的目标。真实学习做的，是用有限样本和受限的 H 去逼近这个够不到的 f* 或 h*。

### 02-1.4.3 同一 ERM 模板下的实例化对照

把前面所有零件拼进一张对照，就能看清"同一模板、两次实例化"到底同在哪、异在哪：

```
              回归                         分类
输出空间 Y    ℝ（连续）                    {1,…,K}（离散）
训练用损失 L  平方 (y-ŷ)²                  交叉熵 / hinge（0-1 的凸代理）
经验风险 R̂    (1/n)Σ(y⁽ⁱ⁾-h(x⁽ⁱ⁾))²        (1/n)Σ L_代理(y⁽ⁱ⁾, h(x⁽ⁱ⁾))
最优预测器    f*(x)=E[y|x]                 h*(x)=argmax_c P(y=c|x)
评估度量      MSE / MAE / R²               错误率、P/R/F1、AUC（大主题12）
典型线性模型  线性回归                     逻辑回归 / 线性 SVM
```

读这张表的方式：从上到下，回归和分类走的是完全一样的四步（选 Y → 选 L → 最小化 R̂ → 对照理论最优），只是每一格填的具体内容不同。掌握了这个模板，学新模型时就有了挂靠点——先问它的 Y 是什么、L 是什么、H 是什么，再看它怎么最小化经验风险，陌生模型立刻变得可解析。要注意一个易错点：分类的**训练**用交叉熵/hinge、**评估**却回到 0-1 及其衍生度量（大主题12），这一"训练损失 ≠ 评估度量"的错位是分类特有的，回归里训练损失（MSE）常和评估度量（MSE/RMSE）一致，别把两者的习惯搞混。

- ESL 2nd ed (2009) §2.4（f(x)=E[Y|X] 是平方损失下的最优；Bayes classifier 是 0-1 损失下的最优、Bayes rate）。

## 02-1.5 数据划分纪律

### 02-1.5.1 训练 / 验证 / 测试三分

监督学习不能拿同一批数据既训练又评判——那等于让学生自己出题、自己判卷。标准做法是把数据切成**三份**，各司其职：

训练集（train）用来拟合模型参数 θ，也就是真正跑 ERM 的那批数据。验证集（validation，又叫 dev）用来选超参数（λ、H 的复杂度、学习率等）、做模型选择与早停。测试集（test）只在最后用一次，估计最终模型的真风险（泛化性能）。

三者对应 1.3 里的角色：训练集算 R̂ 并最小化它；验证集是"临时的诚实评委"，帮我们在不同 H/λ 之间挑；测试集是"最终的诚实评委"，给出上线前对 R(ĥ) 的无偏估计。CS229 用 train/dev/test 三分，比例常见 60/20/20 或数据量大时训练占更高（无绝对定值，视 n 而定，具体比例「待核，依数据规模而变」）。

为什么非要三份、两份不够？因为**只要你用某批数据做过任何"选择"，它就被你"污染"成了训练信息**。用验证集反复挑超参数，挑到最后，验证集误差也会变得乐观（你间接地把验证集拟合了）。所以需要一个从头到尾**碰都没碰过**的测试集来给最终裁决。初学者要建立的铁律：测试集是"一次性用品"，看过就不能再用它指导任何决策，否则它就退化成了另一个验证集，失去无偏性。

### 02-1.5.2 为什么测试集必须"只用一次"

测试集的价值全部来自它的"纯洁"——它必须模拟"模型上线后遇到的、从未参与过任何决策的新数据"。一旦你根据测试集表现回去改模型（换特征、调超参、换算法再测），测试误差就不再是真风险的无偏估计，而是被你**乐观地拟合**过的数字。

这背后是一个统计事实：如果你在测试集上试了很多个模型、挑表现最好的那个报告，这个"最好"里混进了**多重比较的运气**——试的次数越多，纯靠偶然也能挑出一个在这批特定测试数据上碰巧好看的模型，但它在真正的新数据上并不会那么好。这就是"在测试集上过拟合"。防线很简单也很硬：测试集锁进保险箱，全部调参、选模型都在训练集+验证集（或交叉验证）上完成，测试集留到最后跑一次、报告完就作废。初学者最常犯的错就是"测完不满意，回去改改再测"——这一改，测试集就废了。

### 02-1.5.3 数据泄漏（leakage）：最隐蔽也最致命的坑

数据泄漏（data leakage）指**测试/未来的信息以不该有的方式渗进了训练**，使模型在评估时虚高、上线后暴跌。它是新手（乃至老手）最常翻的车，且往往悄无声息。几类典型来源：

一类是预处理泄漏——在划分**之前**就用**全体数据**做标准化、缺失值填充、特征选择、PCA 等，这些步骤"偷看"了测试集的统计量（如全局均值/方差），把测试信息漏进了训练。正确做法是**只在训练集上 fit 预处理器**，再用它 transform 验证/测试集（scikit-learn 的 `Pipeline` 就是为强制这条纪律而生）。

另一类是时间泄漏——对有时间顺序的数据（金融、用户行为）做随机划分，会让"未来"的样本落进训练集去预测"过去"，等于开了天眼。时序数据必须**按时间切**（训练在前、测试在后）。

第三类是分组泄漏——同一实体的多条相关记录（同一病人多次就诊、同一用户多条日志）被随机拆到训练和测试两边，模型可以靠"记住这个实体"作弊；应按实体分组划分（见 1.5.4 的 group 划分）。

最隐蔽的是标签（目标）泄漏——特征里混入了实际上由标签派生、或部署时根本拿不到的信息（如"是否已理赔"用来预测"是否出险"），这类要靠业务理解逐特征审查。

**任何"看了数据才能定"的步骤，都必须放在划分之后、且只用训练集来定。** 判断一个特征是否泄漏，问一句"预测那一刻，这个值真的已经能拿到吗？"能就留，不能就删。泄漏的危险在于它不报错、指标还特别漂亮，唯一暴露它的时刻往往是上线之后——所以划分纪律是纪律，不是可选项。（评估侧的完整泄漏防线归大主题12。）

### 02-1.5.4 分层与分组划分（stratify / group）

普通随机划分在两种情况下需要升级。其一是**类别不平衡**时用**分层划分**（stratified split）：保证训练/测试里各类别的比例与整体一致，否则小类可能在测试集里过少甚至缺席，评估失真。其二是**存在分组结构**时用**分组划分**（group split）：把同一组的所有样本整体分到同一边，杜绝 1.5.3 的分组泄漏。

下面用 scikit-learn 的 `train_test_split` 演示分层的效果（10.3% 正类的不平衡数据），可复现：

```python
from sklearn.model_selection import train_test_split
from sklearn.datasets import make_classification
```

加了 `stratify=y` 后，训练（10.25%）和测试（10.5%）的正类比例都紧贴整体的 10.3%。不加 `stratify` 时，划分只保证随机、不保证比例——数据量大时通常也差不多，但样本少或类极不平衡时，随机划分可能让测试集里的小类样本数剧烈波动甚至为 0，导致某些指标无法计算或极不稳定。这就是为什么分类任务（尤其不平衡的）默认应当分层划分。scikit-learn 提供 `StratifiedKFold`（分层 k 折）、`GroupKFold` / `StratifiedGroupKFold`（分组/分组+分层）等工具专门应对这些结构。

### 02-1.5.5 交叉验证与嵌套 CV（登记，深挖归大主题6/12）

当数据量不大、单个验证集太浪费或估计方差太大时，用**交叉验证**（cross-validation, CV）替代固定验证集：把训练数据切成 k 折，轮流用 k−1 折训练、剩 1 折验证，取 k 次结果的平均，让每个样本都当过一次验证、估计更稳。

CV 平均验证误差 = (1/k) Σ_{j=1}^{k} R̂_验证(第 j 折)

要点是 CV **替代的是"验证集"这一环**（用于选超参/选模型），**不替代测试集**——测试集仍要独立留到最后。若既要用 CV 选超参、又要无偏估计性能，需用**嵌套交叉验证**（nested CV）：外层 CV 估性能、内层 CV 选超参，避免"用同一份 CV 既调参又报成绩"的乐观偏差。

这里只登记接口与它在划分纪律里的位置：CV 是"验证集"的加强版而非测试集的替代，且 CV 内部同样要防泄漏（预处理必须在每折的训练部分单独 fit，用 `Pipeline` 套进 `cross_val_score` 才安全）。k 折的选择、LOO、CV 的偏差-方差性质等定量内容归大主题6，评估度量与更完整的泄漏防线归大主题12，本报告不展开。
