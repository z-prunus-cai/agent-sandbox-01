> 本报告一条主线心智模型：机器学习最核心的担忧是——我在训练集上表现好，凭什么相信在没见过的新数据上也好？学习理论就是给这个"凭什么"一个可证明的答案。核心量只有两个：**训练误差**（经验风险，手里样本上算得出）和**泛化误差**（真实风险，对整个数据分布而言，算不出只能估）。两者之差叫**泛化 gap**。整个理论就在回答一件事：**这个 gap 有多大、什么时候能保证它小**。答案的形状永远是"gap ≤ 某个随样本量 m 增大而缩小、随假设类复杂度增大而增大的量"。PAC（11.1）把这句话形式化成"以概率至少 1−δ，泛化误差不超过 ε"，并定义样本复杂度=达到 (ε, δ) 所需的最少样本数。11.2 用两块砖搭出第一个具体 gap 界：Hoeffding 说"单个固定假设的训练误差以指数速度集中到真误差附近"，联合界说"要让所有假设同时满足这个集中，只需把失败概率乘上假设个数 |H|"，两者相乘取对数就得到 gap ∝ √(log|H| / m)。但真实假设类（如所有线性分类器）有无穷多个假设，log|H| 变成无穷——于是 11.3 换一把尺子：**VC 维** d，衡量假设类能"打散"（任意标注方式都能拟合）的最大点数，是"有效假设个数"的正确度量，把界改写成 gap ∝ √(d / m)。11.4 最后把泛化误差拆成**近似误差**（假设类本身够不够表达真相，对应偏差）加**估计误差**（有限样本导致选错假设，对应方差），复杂度↑则近似误差↓、估计误差↑，两者之和的 U 形正是大主题6 偏差-方差权衡的严格版本；无免费午餐定理则说明"没有对一切问题都最优的学习器"，因此必须靠先验（选假设类）注入归纳偏置。

## 11.1 PAC 可学习（概率近似正确框架）

### 11.1.1 学习理论要回答的问题

机器学习训练时优化的是**训练误差**（在手里那批样本上的平均损失），但我们真正在乎的是**泛化误差**（在整个数据分布上的期望损失，对应任意新样本的表现）。这两个量几乎从不相等——训练误差总是偏乐观，因为模型是专门挑来把这批样本拟合好的。学习理论要回答的核心问题就是：**训练误差和泛化误差之间的差距（泛化 gap）有多大？在什么条件下能保证它足够小，从而"训练集上学好"能推出"新数据上也好"？**

要把这件事讲清，先固定符号。假设数据 (x, y) 独立同分布地来自某个未知分布 D。对一个假设 h（一个从输入到输出的函数），定义它的泛化误差（真实风险）为在 D 上分类错误的概率

ε(h) = P₍ₓ,ᵧ₎∼D[ h(x) ≠ y ]

以及它的训练误差（经验风险，在 m 个样本上）为

ε̂(h) = (1/m) Σᵢ 1{ h(xᵢ) ≠ yᵢ }

学习算法从假设类 H（我们允许考虑的所有假设的集合，如所有线性分类器）中挑一个 h，通常挑训练误差最小的那个，这就是**经验风险最小化 ERM**（大主题1 已讲）。学习理论就是分析"ERM 挑出来的 h 的泛化误差能有多好"。这里的关键张力是：ε̂ 我们算得出，ε 算不出（D 未知），所以必须用概率工具把 ε̂ 当作 ε 的估计、并给出估计的可靠程度。

### 11.1.2 为什么"近似"且"概率"——PAC 名字的由来

PAC = Probably Approximately Correct（大概率、近似正确）。这个名字里的两个限定词都是**必须**的，去掉任何一个都做不到，理解这一点是理解整个框架的钥匙。

"近似正确"（Approximately）里的近似不可去：因为样本有限，我们几乎不可能学到泛化误差**恰好为 0**的假设，只能要求它不超过一个小的容忍度 ε（比如错误率 ≤ 5%）。ε 叫**精度参数**（accuracy），越小要求越高。

"大概率"（Probably）里的概率不可去：因为训练集是随机抽的，总有极小概率抽到一批"特别不具代表性"的样本（比如抛硬币训练集碰巧全是正面），这时无论怎么学都会失败。所以我们只能要求"**除了概率至多 δ 的坏运气之外**，学习成功"。δ 叫**置信参数**（confidence），1−δ 是我们对结果的信心，δ 越小要求越高。

于是一个学习保证的标准句式永远长这样——**以概率至少 1−δ（对训练集的随机性而言），学出的假设满足 ε(h) ≤ ε**。初学者最常见的困惑是把这里的两个随机性搞混：ε(h) 里的概率是对**测试样本** (x,y) 的随机性（h 固定后它是个确定的数）；而"以概率 1−δ"里的概率是对**训练集** S 的随机性（换一批训练集，学出的 h 不同，是否满足 ε(h)≤ε 也可能不同）。两层随机性分属两处，不能混为一谈。

### 11.1.3 PAC 可学习的定义

一个假设类 H 称为 **PAC 可学习**的，如果存在一个学习算法 A 和一个函数 m_H(ε, δ)，使得对任意精度 ε∈(0,1)、任意置信 δ∈(0,1)、任意数据分布 D，只要训练样本数 m ≥ m_H(ε, δ)，算法 A 就能以概率至少 1−δ 输出一个假设 h 满足

ε(h) ≤ min_{h'∈H} ε(h') + ε

其中 min_{h'∈H} ε(h') 是假设类 H 里最好的那个假设的泛化误差（叫**近似误差**，见 11.4）。这个"最好假设的误差 + ε"的形式是**不可知（agnostic）PAC**，不假设真概念一定在 H 里。若额外假设存在某个 h*∈H 使 ε(h*)=0（真概念可被 H 完美表示，叫**可实现 realizable** 情形），定义简化为 ε(h) ≤ ε。

这里最关键的一点是 m_H(ε, δ) **不依赖于分布 D**——同一个样本数下界对所有分布都管用。这正是 PAC 保证的力量所在：不管数据长什么样，只要样本够多就学得会。函数 m_H(ε, δ) 叫**样本复杂度**（sample complexity），是本框架的核心产物。

对初学者，可以把 PAC 可学习理解成一个"退款保证"：你告诉我你能容忍多大误差（ε）、要多高信心（δ），我就告诉你需要多少训练样本（m_H），达到了就保证（除 δ 坏运气外）达标。学不会的假设类（如后面 11.3 会看到的无穷 VC 维的类）则给不出这样的有限样本数——无论多少样本都不能保证。

### 11.1.4 样本复杂度

样本复杂度 m_H(ε, δ) 是"为达到精度 ε、置信 1−δ 所需的最少训练样本数"。它是 PAC 理论最实用的输出，因为它直接回答"我该收集多少数据"。样本复杂度的**形状**（它如何依赖 ε、δ、以及假设类复杂度）是所有后续小主题的目标：

在有限假设类、可实现情形下（11.2 会证），样本复杂度约为

m_H(ε, δ) = O( (1/ε) · ( log|H| + log(1/δ) ) )

在有限假设类、不可知情形下，约为

m_H(ε, δ) = O( (1/ε²) · ( log|H| + log(1/δ) ) )

无限假设类则把 log|H| 换成 VC 维 d（11.3）。这里要注意两处 ε 的幂次差异：**可实现是 1/ε、不可知是 1/ε²**。直觉是可实现情形下最优假设误差为 0、训练误差也能压到 0，估计更"干净"收敛更快；不可知情形要估计一个非零误差的大小，服从中心极限式的 √ 律，所以需要平方级更多的样本。这个 1/ε vs 1/ε² 的区别是本大主题最容易被忽略但很重要的细节。

### 11.1.5 可实现 vs 不可知，以及一致收敛

**可实现（realizable）**假设：存在 h*∈H 使 ε(h*)=0，即真概念恰在假设类内、数据可被完美分类。此时 ERM 能达到训练误差 0，分析简单。

**不可知（agnostic）**假设：不对 D 与 H 的关系做任何要求，H 里最好的假设也可能有正误差（甚至数据本身带噪声、y 不是 x 的确定函数）。此时目标退化为"逼近 H 内最优"，即 ε(h) ≤ min_{h'} ε(h') + ε。不可知 PAC 更贴近现实（我们从不知道真概念是否在 H 里），是现代教科书（SSBD）的默认设定。

贯穿 11.2/11.3 的技术核心叫**一致收敛（uniform convergence）**：如果能保证"**对 H 里所有假设 h 同时**，训练误差都接近泛化误差"，即

以概率 ≥ 1−δ，对所有 h∈H：|ε̂(h) − ε(h)| ≤ ε/2

那么 ERM 选出的 h（训练误差最小）的泛化误差就必然接近最优。这是因为 ERM 选的 h 训练误差 ≤ 最优 h* 的训练误差，再两头各用一次一致收敛把训练误差换成泛化误差，就得到 ε(h) ≤ ε(h*) + ε。所以"证明 PAC 可学习"在技术上几乎总是归结为"证明一致收敛成立"——记住这个还原，后两个小主题的界就都是在算一致收敛需要多少样本。

## 11.2 有限假设类泛化界（联合界 + Hoeffding）

### 11.2.1 Hoeffding 不等式：单个假设的集中

先看最简单的情形：只有一个**固定**假设 h（在看数据之前就定好）。它的训练误差 ε̂(h) 是 m 个独立同分布的 0/1 变量（每个样本分对还是分错）的平均，而这些变量的期望恰好是泛化误差 ε(h)。于是问"ε̂(h) 会不会偏离 ε(h) 很多"就是问"m 次独立伯努利试验的样本均值会不会偏离真均值很多"——这正是**大数定律**的定量版本，由 **Hoeffding 不等式**（也叫 Chernoff 界的一种）给出：

P( | ε̂(h) − ε(h) | > γ ) ≤ 2 exp( −2 γ² m )

它说单个假设的训练误差偏离真误差超过 γ 的概率，随样本数 m **指数级**衰减。这是整个有限类分析的第一块砖。

对初学者，Hoeffding 的直觉就是"多抛几次硬币，正面比例就越来越贴近真实概率，而且贴近的速度是指数级快的"。指数里的 −2γ²m 有两点要记：一是对偏差 γ 是平方依赖（要精度提高一倍即 γ 减半，指数里的量变成 1/4，需 4 倍样本），二是对样本 m 是线性依赖（在指数上）。这个 γ² 与 m 的组合就是后面所有界里 √(1/m) 速率的来源。要点：Hoeffding 只对**事先固定的** h 成立，因为它要求那 m 个 0/1 变量与 h 独立；一旦 h 是"看了数据后挑出来的"（ERM 就是），这个独立性被破坏，不能直接用——这正是需要下一块砖的原因。

### 11.2.2 联合界（union bound）

**联合界**（布尔不等式）是一句几乎显然但极其有用的话：若干事件里"至少发生一个"的概率，不超过各事件概率之和。

P( A₁ ∪ A₂ ∪ … ∪ A_k ) ≤ P(A₁) + P(A₂) + … + P(A_k)

它对事件之间是否独立、是否相关**毫无要求**，永远成立（代价是可能很松）。在学习理论里它的用途是把"对某一个假设的保证"升级成"对所有假设同时的保证"：我们想要的是 ERM 选出的 h（依赖数据）也满足集中，但我们不知道会选中哪个，于是干脆要求 **H 里每个假设都同时**满足集中——只要 H 有限，用联合界把每个假设失败的概率加起来就行。

可以把联合界想成"最坏情况下的保险"。你有 k 个可能出岔子的地方，每处出岔子概率 ≤ p，那么"任何一处出岔子"的概率 ≤ kp。它的松是因为忽略了事件重叠，但胜在无条件成立、且在 k 不太大（这里 k=|H|，取对数后只是 log|H|）时代价可接受。

### 11.2.3 有限类的一致收敛界

把两块砖拼起来。设 |H|=k 有限。对每个 h∈H，Hoeffding 说它训练误差偏离超过 γ 的概率 ≤ 2exp(−2γ²m)。用联合界，"存在某个 h 偏离超过 γ"的概率 ≤ k·2exp(−2γ²m)。令这个总失败概率等于 δ 并反解，就得到：以概率至少 1−δ，**对所有 h∈H 同时**有

| ε̂(h) − ε(h) | ≤ √( (1 / (2m)) · log(2|H| / δ) )

这就是有限假设类的**一致收敛界**（不可知情形）。这个界的形状是理解一切的关键：泛化 gap 的上界随样本数 m 以 √(1/m) 速率缩小，随假设类大小以 √(log|H|) 增大（注意是 log，所以假设类翻倍只让界增加一点点），随置信要求以 √(log(1/δ)) 增大。

对初学者，最该记住的是三条依赖：**更多数据（m↑）→ gap 界变小（好）**；**更复杂的假设类（|H|↑）→ gap 界变大（过拟合风险，坏）**；而 log 的存在意味着复杂度的惩罚很温和（是 log|H| 不是 |H|）。这条界就是"为什么模型越复杂越容易过拟合"的第一个严格证据——不是玄学，是 √(log|H|/m) 在涨。

### 11.2.4 可实现情形的更快界

若可实现（存在 h*∈H 使 ε(h*)=0，ERM 能达到训练误差 0），可以用更简单的论证得到更快的率。此时只需保证"所有真误差大于 ε 的坏假设都不会碰巧训练误差为 0"。一个坏假设（ε(h)>ε）在一个样本上分对的概率 ≤ 1−ε，在 m 个样本上全分对的概率 ≤ (1−ε)^m ≤ exp(−εm)。用联合界乘以 |H|：至少一个坏假设骗过训练集的概率 ≤ |H|·exp(−εm)。令其 ≤ δ 反解得样本复杂度

m ≥ (1/ε) · ( log|H| + log(1/δ) )

等价地，以概率 ≥ 1−δ，ERM 输出的 h 满足

ε(h) ≤ (1/m) · ( log|H| + log(1/δ) )

注意这里是 1/m（不是 1/√m），对应 11.1.4 说的可实现情形 1/ε 样本复杂度——比不可知情形快一个平方级。原因就是可实现下我们不必估计一个非零误差的精确大小，只需排除"坏假设侥幸零训练误差"，这是个指数小概率事件，收敛更快。

### 11.2.5 样本复杂度与 log|H| 的意义

把两种情形的样本复杂度并列：

可实现：m = O( (1/ε) ( log|H| + log(1/δ) ) )

不可知：m = O( (1/ε²) ( log|H| + log(1/δ) ) )

两者都揭示同一个深刻结论：**假设类的复杂度以 log|H| 的形式进入样本复杂度**。log|H| 大致等于"用二进制描述 H 里一个假设需要多少比特"——例如 H 由 d 个布尔参数确定，则 |H|=2^d，log|H|=d（以 2 为底），样本复杂度线性依赖参数个数 d。这就把抽象的"复杂度"落到了可数的东西上：**参数越多、假设类越大，需要的样本越多**，且是温和的线性（对参数数）依赖。

这里埋着一个初学者会立刻想到的问题：真实的假设类（比如所有实数权重的线性分类器）有**无穷多**个假设，|H|=∞，log|H|=∞，这些界岂不是全废了？答案是"表面上废了，但可以救"——需要一把不数假设个数、而数假设类"有效自由度"的新尺子，这就是下一个小主题的 VC 维。11.2 的界是 11.3 的特例与跳板：VC 维界的形状与这里一模一样，只是把 log|H| 换成 VC 维 d。

## 11.3 VC 维（打散、无限类的复杂度度量）

### 11.3.1 为什么需要 VC 维

11.2 的界依赖 log|H|，对无限假设类（如 ℝ 上所有阈值、平面上所有直线）直接失效。但直觉上这些无限类并不是"无限复杂"——平面上的直线分类器显然比"任意曲线"简单。问题出在"数假设个数"是错误的复杂度度量：无限多个假设里，很多在有限的 m 个样本上给出**完全相同**的标注，实际"有区别的假设"是有限的。VC 维就是抓住这个"在有限点上到底有多少种本质不同的行为"的正确度量，从而把泛化界推广到无限类。

关键的观念转变：不要问"H 里有多少个假设"，而问"**H 在任意 m 个点上，最多能实现多少种不同的标注（对分/dichotomy）**"。后者对无限类也常常是有限的，且增长受限——这就是 VC 维要刻画的。

### 11.3.2 打散（shattering）

给定一组 m 个点 {x₁,…,x_m}。假设类 H 能**打散（shatter）**这组点，当且仅当对这些点的**每一种**可能的 0/1 标注方式（共 2^m 种），H 里都存在某个假设恰好实现它。换句话说，这 m 个点无论怎么贴标签，H 都能找出一个假设完美分开。

一个最小例子（一维阈值分类器 h(x)=1{x≥θ}）：

单点 {x₁}——两种标注 (0)、(1) 都能实现（θ 取在 x₁ 右边得 0，左边得 1），所以能打散 1 个点。

两点 {x₁<x₂}——四种标注里，(x₁=1, x₂=0) 这种"左边正、右边负"阈值分类器做不到（阈值右侧才为 1，不可能左正右负），所以**打散不了**任意 2 个点。

于是一维阈值分类器最多打散 1 个点。注意"打散"要求的是"存在一组这样的点被打散"（对 VC 维定义），且对该组点的**所有** 2^m 种标注都能实现——只要有一种标注实现不了，就没打散这组点。初学者最常犯的错是把"能分对某一种标注"当成打散，其实要**全部** 2^m 种都能分对才算。

### 11.3.3 VC 维的定义

假设类 H 的 **VC 维**（Vapnik–Chervonenkis dimension）记作 VCdim(H) 或 d_VC(H)，定义为 H 能打散的最大点数：

VCdim(H) = max { m : 存在 m 个点能被 H 打散 }

若对任意大的 m 都能找到 m 个点被打散，则 VCdim(H)=∞。要点有二：一是只需**存在**某一组 m 个点被打散（不是所有 m 个点的摆法都要能打散）；二是要证 VCdim = d，须证**两件事**——（下界）存在 d 个点能被打散；（上界）任意 d+1 个点都**不能**被打散。初学者常只证了下界（找到 d 个点能打散）就下结论，漏掉上界（还得说明再多一个点就打散不了）。

VC 维直觉上是"假设类的有效自由度/表达能力"，与参数个数常常（但不总是）相等。它取代 log|H| 成为无限类的复杂度尺子。

### 11.3.4 常见假设类的 VC 维

一维阈值/射线分类器 h(x)=1{x≥θ}：VCdim = 1。

一维区间分类器（落在某区间 [a,b] 内为 1）：VCdim = 2。

ℝⁿ 中带偏置的线性分类器（超平面）：

VCdim = n + 1

（n 维输入加一个偏置项，共 n+1 个自由度；ℝ² 平面直线为 3。）

ℝ² 中轴对齐矩形（矩形内为 1）：VCdim = 4。

有限假设类：VCdim(H) ≤ log₂|H|（因打散 m 个点需 2^m 个不同假设，故 2^m ≤ |H|）。这条不等式把 11.3 与 11.2 接上了：VC 维永远不超过 log₂|H|，所以 VC 界总是不弱于有限类界。

无穷 VC 维的经典例子——单参数正弦分类器 h(x)=1{ sin(αx) > 0 }：VCdim = ∞。它只有**一个**实参数 α，却能打散任意多个点（靠调高频率 α 在任意点集上实现任意标注）。这个反例极重要：它说明 **VC 维与参数个数不是一回事**——一个参数也能有无穷 VC 维。所以"参数少=简单"是错的直觉，正确的度量是 VC 维。

### 11.3.5 Sauer 引理与增长函数

**增长函数** Π_H(m) 定义为 H 在最坏的 m 个点上能实现的最多标注种数（≤ 2^m）。**Sauer–Shelah 引理**（也叫 Sauer 引理）说：一旦 m 超过 VC 维 d，增长函数就从指数 2^m 塌缩为**多项式**：

Π_H(m) ≤ Σ_{i=0}^{d} C(m, i) ≤ (e·m / d)^d  （当 m ≥ d）

这是 VC 理论的技术心脏。它的意义是：虽然无限类有无穷多假设，但在 m 个样本上"本质不同的行为数"被 VC 维 d 卡成了只随 m 多项式（约 m^d）增长，而不是指数增长。于是可以把 11.2 里联合界中的 |H| 换成增长函数 Π_H(m)≈m^d，取对数后 log|H| 变成 d·log m——一个有限的量！这就是为什么无限类也能有有限样本复杂度。

对初学者：Sauer 引理是"从指数到多项式的相变"。点数少于 VC 维时，假设类要多灵活有多灵活（2^m 全都能实现）；一旦点数超过 VC 维，灵活性突然被封顶到多项式级——多出来的点无法再自由标注。这个相变正是"有限 VC 维 ⟹ 可学习"的根源。

### 11.3.6 VC 泛化界与学习基本定理

把 Sauer 引理代入一致收敛论证，得到无限假设类的 **VC 泛化界**：以概率至少 1−δ，对所有 h∈H 同时（d=VCdim(H)），

| ε̂(h) − ε(h) | ≤ O( √( (d · log(m/d) + log(1/δ)) / m ) )

样本复杂度相应地为 m = O( (d + log(1/δ)) / ε² )（不可知）或 O( (d·log(1/ε) + log(1/δ)) / ε )（可实现）。与 11.2 对照，唯一的替换就是 **log|H| → VCdim(H)**，形状完全一致。

集大成的结论是**统计学习基本定理**（SSBD Ch6）：对二分类，以下四件事**等价**——(1) H 是不可知 PAC 可学习的；(2) H 是（可实现）PAC 可学习的；(3) H 满足一致收敛；(4) VCdim(H) < ∞。并且样本复杂度与 VC 维**同阶**：

m_H(ε, δ) = Θ( (d + log(1/δ)) / ε² )  （不可知）

一句话记忆：**有限 VC 维 ⟺ 可学习**。VC 维有限是二分类可 PAC 学习的充要条件，VC 维就是样本复杂度的"正确单位"。这是学习理论最漂亮的定理，把可学习性完全归结为一个组合量。

登记（不展开，超本课广度）：VC 维是最经典但不是唯一的复杂度度量。更精细的有 **Rademacher 复杂度**（数据依赖、常给更紧的界）、**覆盖数/度量熵**、**PAC-Bayes 界**、以及基于**间隔（margin）**的界（解释 SVM/boosting 为何不过拟合）。这些属研究生课/专著内容，本报告仅指路。

## 11.4 偏差-复杂度权衡（为大主题6 提供数学根）

### 11.4.1 误差分解：近似误差 + 估计误差

学习理论把 ERM 输出假设 h_S（下标 S 表示依赖训练集）的泛化误差拆成两块，这是本大主题的"落地"结论，也是偏差-方差的严格版本。设 h* = argmin_{h∈H} ε(h) 是假设类 H 内的最优假设，则

ε(h_S) = ε(h*) + ( ε(h_S) − ε(h*) )

命名为

ε(h_S) = 近似误差(approximation error) + 估计误差(estimation error)

**近似误差** ε(h*) = min_{h∈H} ε(h)：假设类 H 内能达到的最小泛化误差。它衡量"H 这个类本身够不够表达真相"，只依赖 H 的选择、**不依赖训练样本**（样本再多也降不下去，除非换更大的 H）。

**估计误差** ε(h_S) − ε(h*)：因为只有有限样本、用 ERM 从 H 里挑，挑出的 h_S 未必是 h*，两者泛化误差之差。它衡量"有限数据导致的选择误差"，由一致收敛界控制、**随样本量 m 增大而减小**。

### 11.4.2 复杂度如何反向牵动两项

这两项随假设类复杂度（VC 维 d 或 log|H|）**反向**变化，这是整个权衡的核心：

假设类越大/越复杂（d↑）→ 它更可能包含接近真相的假设 → **近似误差↓**（表达能力强）；但同时 → VC 界 √(d/m) 变大 → **估计误差↑**（有限样本下更难从大类里挑准，过拟合风险高）。

假设类越小/越简单（d↓）→ 近似误差↑（可能连真相都表达不了，欠拟合）→ 但估计误差↓（小类里挑，样本相对充足，稳）。

于是总泛化误差 = 近似误差 + 估计误差 随复杂度呈**先降后升的 U 形**：太简单时近似误差主导（欠拟合），太复杂时估计误差主导（过拟合），最优复杂度在两者平衡处。这就是**偏差-复杂度权衡**（bias-complexity tradeoff，SSBD 的叫法），是大主题6 偏差-方差权衡 U 形曲线的严格数学根。

### 11.4.3 泛化 gap 随样本量与复杂度的关系

把估计误差的上界写清楚。由 VC 一致收敛界，估计误差被泛化 gap 控制，大致为

估计误差 ≲ √( d / m )  （略去 log 与 δ 因子）

这条 √(d/m) 是本大主题最该记住的定量结论，它同时解释了三件事：

**样本量 m↑ → gap↓**：数据越多，估计误差以 √(1/m) 速率下降、训练误差越接近泛化误差。要精度翻倍（gap 减半）需约 4 倍样本。本次 numpy 模拟坐实了这条：阈值族（d=1）上 gap 从 m=10 的≈0.086 降到 m=1000 的≈0.0012，随 m 单调缩小、量级符合 Õ(d/m)。

**复杂度 d↑ → gap↑**：VC 维越大，同样样本下 gap 越大、越易过拟合。这就是"模型越复杂越需要更多数据"的严格版。

**m 与 d 的配比**：要控制过拟合，样本量应与 VC 维成正比（m 至少 ∝ d）。经验法则"样本数应远大于参数数"正是这条界的通俗版。

### 11.4.4 与偏差-方差的对应（辨析）

学习理论的"近似/估计误差分解"与大主题6 的"偏差/方差分解"是**同一现象的两种语言**，但**不是逐字等同**，初学者极易混淆，须辨清：

对应关系（直觉层面）：近似误差 ↔ 偏差（都刻画"假设类/模型太简单导致系统性偏离真相"，随复杂度↑而↓）；估计误差 ↔ 方差（都刻画"有限样本导致的不稳定/过拟合"，随复杂度↑而↑）。两者都给出复杂度-误差的 U 形，都说"复杂度要与数据量匹配"。

关键区别（不能画等号的地方）：偏差-方差分解（大主题6）是**针对平方损失、对训练集取期望**的**精确代数恒等式**（误差=偏差²+方差+噪声），是"平均意义"的；而近似/估计误差分解是**对任意损失（含 0-1）、最坏情形高概率上界**的**不等式**，是"保证意义"的。前者是统计/期望视角（ESL 传统），后者是最坏情形/PAC 视角（Vapnik/SSBD 传统）。所以可以说"近似误差扮演偏差的角色、估计误差扮演方差的角色"，但**不能说估计误差就等于方差**——它们的数学定义、损失范围、取期望还是取上界都不同。这正是 11.1 来源与时效里提到的"两种传统互补"在本处的具体体现。

### 11.4.5 无免费午餐定理

**无免费午餐定理**（No Free Lunch, NFL，SSBD Ch5）说：不存在一个"万能"学习器对**所有**可能的数据分布都学得好。更精确地，对任意学习算法，总能构造出一个分布，使该算法在此分布上的期望误差很差（而另一个算法在此分布上很好）。

它的直接推论是：**必须引入归纳偏置（inductive bias）**——即事先选定一个不太大的假设类 H（或对假设加偏好），把先验知识注入学习过程。没有免费午餐意味着"选对假设类"这件事无法回避、也无法自动化到对一切问题通用。这就把 11.4.2 的"复杂度权衡"提升为哲学层面的必然：你**必须**通过限制 H 来换取可学习性，代价是承担近似误差（若 H 选错，真相不在其中）。

对初学者：NFL 常被误读成"所有算法一样好"，其实它说的是"**平均到所有可能问题上**一样好"——但现实问题不是均匀分布的，真实世界有结构（平滑、局部、层次），所以针对性的归纳偏置（如卷积对图像、线性对表格）才有效。NFL 不否定实践中算法有优劣，只否定"存在对一切问题都最优的算法"。

### 11.4.6 结构风险最小化

既然复杂度要与数据量匹配、且不能靠单一 H，**结构风险最小化**（Structural Risk Minimization, SRM，Vapnik）给出一套原则性的模型选择方法：预先安排一列复杂度递增的嵌套假设类

H₁ ⊆ H₂ ⊆ H₃ ⊆ …  （VC 维 d₁ < d₂ < d₃ < …）

对每个 H_k 做 ERM 得到训练误差，然后不是选训练误差最小的（那总会选最复杂的、过拟合），而是选**训练误差 + 复杂度惩罚项**（惩罚 ∝ √(d_k/m)，即 VC 界）之和最小的 H_k。这样自动在近似误差（训练误差代理）与估计误差（复杂度惩罚代理）之间取平衡。

SRM 是大主题6 里正则化（L2/L1 惩罚）、模型选择（AIC/BIC、交叉验证）的**理论原型**：正则化 = 给复杂度加惩罚 = SRM 的连续化实现（λ 越大越偏向简单类）；交叉验证 = 用数据直接估计泛化误差来选复杂度，是 SRM 中"复杂度惩罚"的数据驱动替代。至此本大主题闭环：11.1–11.3 建立"泛化 gap ≲ √(复杂度/m)"，11.4 用它导出 U 形权衡与 SRM，正是大主题6 一切正则化/模型选择手段背后的数学根。
