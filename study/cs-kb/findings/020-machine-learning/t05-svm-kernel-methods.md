## 5.1 最大间隔与几何间隔

### 5.1.1 分离超平面与线性判别

支持向量机首先是一个**线性判别器**：给定权重向量 w 和偏置 b，它用一个超平面

wᵀx + b = 0

把特征空间切成两半，预测规则是看样本落在哪一侧：

ŷ = sign(wᵀx + b)

落在 wᵀx+b>0 一侧判为正类，<0 一侧判为负类。SVM 的标签约定用 **y ∈ {−1, +1}**（不是逻辑回归常用的 {0,1}），这个选择不是随意的——它让"分类正确"能被写成一个极其干净的乘积式：样本 (xᵢ, yᵢ) 被正确分类，当且仅当

yᵢ (wᵀxᵢ + b) > 0

因为正类 yᵢ=+1 时要求打分为正、负类 yᵢ=−1 时要求打分为负，两种情况乘起来都要求这个乘积为正。这个 y·(wᵀx+b) 后面会反复出现，是 SVM 全部公式的基石。

超平面在二维里就是一条直线、三维里是一张平面、更高维里是它的推广（一个比空间少一维的"平面"）。w 是垂直于这张平面的法向量（指向正类那侧），决定平面的朝向；b 决定平面离原点多远。判别就是问"这个点在平面的哪一边"，而 wᵀx+b 的正负号正好回答了这个问题。

### 5.1.2 函数间隔与几何间隔

"分得多开"需要一个度量。SVM 用两个层次的间隔来刻画。

单个样本的**函数间隔（functional margin）**定义为

γ̂ᵢ = yᵢ (wᵀxᵢ + b)

它 >0 表示分对，且值越大表示"分对得越有把握"（离超平面越远、越深入正确一侧）。整个数据集的函数间隔取所有样本里最小的那个 γ̂ = minᵢ γ̂ᵢ。

函数间隔有个致命毛病：**它会随 (w,b) 的放缩而放缩**。把 w 和 b 同时乘以 10，超平面 wᵀx+b=0 一点没变（还是同一条线），但函数间隔却翻了 10 倍。所以光靠函数间隔无法比较，必须归一化。除以 ‖w‖ 就得到**几何间隔（geometric margin）**：

γᵢ = yᵢ (wᵀxᵢ + b) / ‖w‖

几何间隔正是**样本点到超平面的带符号欧氏距离**（分对时为正），它对 (w,b) 的放缩免疫，是真正有几何意义、可比较的量。数据集的几何间隔 γ = minᵢ γᵢ 就是"最靠近超平面的那个点离面的距离"。

函数间隔像"考试分数"，但每个老师的满分不同（w 可放缩），没法直接比；几何间隔像"百分制归一化后的分数"，谁都能比。为什么除以 ‖w‖ 就得到距离？回忆点到平面距离公式 |wᵀx+b|/‖w‖，几何间隔就是它带上正负号（乘 yᵢ 把"分对"记为正）。CS229 讲义特别点明：函数间隔与几何间隔的关系是 γ = γ̂/‖w‖，这个关系是下一步建立优化问题的枢纽。

### 5.1.3 最大间隔原理

能把线性可分的两类分开的超平面通常有无穷多条。SVM 的核心主张是：**选几何间隔最大的那一条**。也就是求解

maximize_{w,b} γ  subject to  yᵢ(wᵀxᵢ + b)/‖w‖ ≥ γ, 对所有 i

意思是"让最近点的距离 γ 尽可能大，同时要求每个样本到面的几何距离都不小于 γ"。这条使间隔最大的超平面叫**最优分离超平面（optimal separating hyperplane）**，或**最大间隔分类器（maximal margin classifier）**。

想象两类点之间要修一条尽量宽的直马路，马路中线就是判别面。为什么要"最宽"？因为宽街道给未来的新样本留了最大的容错余地——一个略微偏移的新点更不容易跨过宽街道的中线而被误判，所以最大间隔面**泛化性能更稳、对扰动更鲁棒**。这也和学习理论对上号：更大的间隔对应更小的模型复杂度（ESL Ch12、CS229 都从间隔与泛化界的角度给了动机，此处只给直觉，理论纵深归大主题11）。要注意"最大间隔"只由**最靠近的那几个点**决定，远处的点挪一挪根本不影响这条最优线——这正是"支持向量"概念的萌芽。

### 5.1.4 原始优化问题（凸二次规划）

上面带 ‖w‖ 分母的问题不好直接解。关键一步是利用函数间隔可放缩这个"毛病"来固定尺度：既然放缩不改变超平面，干脆**规定最近点的函数间隔为 1**，即令 minᵢ yᵢ(wᵀxᵢ+b) = 1。这样几何间隔就变成 γ = 1/‖w‖，"最大化 1/‖w‖"等价于"最小化 ‖w‖"、也等价于"最小化 ½‖w‖²"（加平方与系数只为求导干净）。于是最大间隔问题变成一个干净的**凸二次规划（QP）**：

minimize_{w,b}  ½ ‖w‖²

subject to  yᵢ (wᵀxᵢ + b) ≥ 1,  对所有 i = 1,…,m

这就是**硬间隔 SVM（hard-margin SVM）的原始问题（primal problem）**。目标函数是凸的二次型、约束是线性的，所以它有**唯一的全局最优解**，不像神经网络会陷局部极小。此时街道两侧的"街沿"正是两个平行超平面 wᵀx+b=+1 与 wᵀx+b=−1，两者之间的距离（街宽）恰为 2/‖w‖。

为什么可以随手规定"最近点函数间隔=1"？因为 (w,b) 能自由放缩而超平面不变，这个"1"只是给尺子定了个刻度，不损失一般性。约束 yᵢ(wᵀxᵢ+b)≥1 的含义是"每个样本不仅要分对，还要被推到街沿之外（离中线至少 1 个函数间隔）"。四本教材（CS229、ESL §12.2、PRML §7.1、ISL Ch9）在这个原始形式上完全一致；ESL 写成等价的 min ½‖β‖² s.t. yᵢ(xᵢᵀβ+β₀)≥1，只是符号不同。硬间隔要求数据**严格线性可分**，否则约束无解——这正是 5.2 引入软间隔的原因。

### 5.1.5 支持向量的萌芽

在最优解处，约束 yᵢ(wᵀxᵢ+b)≥1 对绝大多数样本是**严格不等**（>1，即它们躲在街沿外面很远），只有少数样本恰好**取等号**（=1，即它们正好贴在街沿 wᵀx+b=±1 上）。这些取等号、贴着街沿的样本就是**支持向量（support vectors）**。

最优超平面**完全由支持向量决定**：把非支持向量删掉重新训练，解一模一样；把某个支持向量挪动一点，解就变。这一点在 5.3 用 KKT 条件会得到严格证明（非支持向量的拉格朗日乘子 αᵢ=0），这里先建立直觉。

支持向量就是"顶着街沿的那几个点"，像用几根柱子把马路的宽度撑到最大，其余的点都在马路外围凑热闹、对马路怎么修毫无发言权。这带来两个巨大好处：预测时只需记住这几个支持向量（模型稀疏），以及解对远处噪声不敏感（鲁棒）。名字"支持向量机"正来源于此。

## 5.2 软间隔与 hinge

### 5.2.1 为什么需要软间隔

硬间隔 SVM 要求数据**严格线性可分**——存在一个超平面能把两类零错误地分开。真实数据几乎从不满足：类别有重叠、标注有噪声、总有几个离群点。这时硬间隔的约束 yᵢ(wᵀxᵢ+b)≥1 无解，问题根本没有可行解。即便勉强可分，一个孤立的离群点也可能把最优超平面拽得严重变形，让间隔缩得极窄、泛化变差。

**软间隔（soft margin）SVM** 的思路是：允许一部分样本**违反**"必须在街沿外"的约束（可以落进街道内、甚至越到判别面另一侧被分错），但每次违反都要**付出代价**。Cortes & Vapnik 1995 正是用软间隔把 SVM 从"只能处理可分数据的理论玩具"变成"能用于真实带噪数据的实用算法"，这是 SVM 落地的分水岭。

硬间隔像一个洁癖的裁判——只要有一个点分不开就宣布"任务不可能"；软间隔像一个通情达理的裁判——"你可以有几个点没站对位置，但每个错位都要扣分，我要总扣分尽量少"。

### 5.2.2 松弛变量 ξ

对每个样本 i 引入一个**松弛变量（slack variable）ξᵢ ≥ 0**，把硬约束松弛为

yᵢ (wᵀxᵢ + b) ≥ 1 − ξᵢ,  ξᵢ ≥ 0

ξᵢ 度量样本 i "违反街沿约束的程度"：ξᵢ=0 表示老实待在街沿外（没违反）；0<ξᵢ≤1 表示落进了街道内但还在判别面正确一侧（分类仍对，只是没到街沿）；ξᵢ>1 表示越过了判别面、被**分错**。所以 Σξᵢ 是"总违规量"，而分错的样本数不超过 ξᵢ>1 的个数（Σξᵢ 是训练错误数的一个上界）。

ξᵢ 就是"样本 i 为了满足约束需要被网开一面的额度"。老实站在街沿外的点不需要额度（ξ=0）；站进街道里的点需要一点额度；站到马路对面（分错）的点需要超过 1 的额度。

### 5.2.3 惩罚系数 C 与正则权衡

把总松弛加进目标，得到**软间隔 SVM 原始问题**：

minimize_{w,b,ξ}  ½ ‖w‖² + C Σᵢ ξᵢ

subject to  yᵢ (wᵀxᵢ + b) ≥ 1 − ξᵢ,  ξᵢ ≥ 0,  对所有 i

目标里有两股拉力：½‖w‖² 想把街修宽（间隔大），C·Σξᵢ 想让违规少。**C > 0 是调节两者的旋钮**：

C → ∞ 时不容许任何违规，退化回硬间隔（若可分）；

C 很大偏向"少犯错"——街窄、支持向量少、易**过拟合**；

C 很小偏向"街宽、容忍违规"——支持向量多、易**欠拟合**。

本次 sklearn 实证坐实了这条趋势：同一份两团数据，C=0.01 时有 18 个支持向量、间隔宽度 2/‖w‖≈5.92；C=1 与 C=100 时都收缩到 3 个支持向量、间隔宽度≈1.55。C 越小街越宽、越多点被容忍落进街道（成为支持向量）。

C 是"对犯错的罚款力度"。罚款极重（C 大）时模型宁可修一条窄得贴着数据的街也不敢让任何点越界——对训练集极度负责，但一遇噪声就跟着抖，泛化差；罚款很轻（C 小）时模型乐得修宽街、随便几个点越界，边界平滑、抗噪但可能太粗糙。C 的具体取值靠交叉验证挑（选 C 的方法论归大主题6）。易错点：sklearn 里 C 是加在**误差项**上的（C 大=正则弱），这与很多教材把正则强度写成 λ、"λ 大=正则强"的方向**相反**，初学者极易搞反——C 大约等于 1/λ。

### 5.2.4 hinge 损失与无约束等价形式

软间隔问题可以消掉松弛变量、写成一个**无约束**的等价形式。由约束与 ξᵢ≥0，最优时 ξᵢ = max(0, 1 − yᵢ(wᵀxᵢ+b))。代回目标（除以 C 并整理）就得到 SVM 的"损失 + 正则"面貌：

minimize_{w,b}  Σᵢ max(0, 1 − yᵢ(wᵀxᵢ + b)) + (λ/2) ‖w‖²

其中那个 max(0, 1 − y·f(x)) 就是 **hinge 损失（合页损失）**，记 f(x)=wᵀx+b：

L_hinge(y, f) = max(0, 1 − y f(x))

hinge 损失的形状是理解 SVM 的钥匙：当 y·f ≥ 1（分对且在街沿外）损失恒为 0——**分对得够开的样本一点都不贡献损失**；当 y·f < 1（进了街道或分错）损失随 (1−yf) 线性增长。这个"损失为 0 的平台区"正是 SVM 稀疏性（只有支持向量起作用）的根源。

"合页"得名于它的图像：在 yf=1 处像门的合页一样折一下，右边平贴地面（损失 0），左边斜着往上翘（线性上升）。它和 0-1 损失（分错记 1、分对记 0）的关系是：hinge 是 0-1 损失的一个**凸上界**（凸的所以好优化，是上界所以最小化它能压住真正的错误率）。这一无约束形式把 SVM 彻底拉回大主题3 的统一视角——不同的线性分类器无非是"不同损失 + L2 正则"：换成 log 损失就是逻辑回归、换成 hinge 就是 SVM、换成平方就是最小二乘。sklearn 的 `LinearSVC` 默认最小化的正是这个（`loss='squared_hinge'` 为默认、`'hinge'` 可选，⚙锚 1.9.0）。

### 5.2.5 与逻辑回归损失的辨析

把 hinge 损失和逻辑回归的 log 损失画在同一张图（横轴 y·f）上对比，能一次看清 SVM 的性格。两者都是 0-1 损失的凸代理、都随 y·f 增大而下降，但有两点关键差异。其一，**hinge 有硬零区**：y·f≥1 后损失精确为 0，导致只有落在街道内/被分错的样本影响解（稀疏、只靠支持向量）；log 损失**永远大于 0**（即使分得很对也留一点点损失），所以逻辑回归里**每个样本都对解有贡献**（不稀疏）。其二，**hinge 不光滑**（在 yf=1 处有拐点、不可导），log 损失处处光滑——这影响了各自的求解方法（SVM 走对偶 QP/SMO，逻辑回归走梯度/牛顿法）。

逻辑回归给"每个样本一句评价"（连概率都给），SVM 则"只盯着边界附近的难点、对早已分对的样本视而不见"。所以 SVM 天然稀疏、抗远处离群点；代价是它**不直接输出概率**（要概率得额外做 Platt 缩放，归大主题12）。实践里两者常打平手，数据维度高、样本相对少、需要核化非线性时 SVM 常有优势；需要概率输出、样本极多时逻辑回归更省。

## 5.3 对偶与 KKT / 支持向量

### 5.3.1 拉格朗日函数与对偶问题

原始 QP 可以直接解，但换成它的**拉格朗日对偶（Lagrangian dual）**来解会带来两个决定性好处（内积结构→核技巧、稀疏→支持向量）。做法是给每条约束 yᵢ(wᵀxᵢ+b)≥1 配一个拉格朗日乘子 αᵢ≥0，构造拉格朗日函数（先看硬间隔）：

L(w, b, α) = ½‖w‖² − Σᵢ αᵢ [ yᵢ(wᵀxᵢ + b) − 1 ]

对偶的套路是先对原始变量 (w,b) 求最小（令偏导为 0），再对乘子 α 求最大。令 ∂L/∂w=0 与 ∂L/∂b=0 得到两个关键条件：

w = Σᵢ αᵢ yᵢ xᵢ

Σᵢ αᵢ yᵢ = 0

第一条极其重要：**最优权重 w 是训练样本的线性组合**，组合系数是 αᵢyᵢ。把这两条代回 L，消去 w 和 b，就得到只含 α 的**对偶问题**。

拉格朗日乘子法是约束优化的标准工具——把"约束"换成"违反约束就受罚"的乘子项，再在乘子与原变量之间做一个 min-max 博弈。这里最该记住的是 w=Σαᵢyᵢxᵢ：解出来的分离面法向量，就是各样本向量按 αᵢyᵢ 加权叠起来的；后面会看到大多数 αᵢ=0，所以真正参与叠加的只有支持向量。

### 5.3.2 对偶形式（只含内积）

代入化简后，硬间隔 SVM 的**对偶问题**是：

maximize_α  Σᵢ αᵢ − ½ Σᵢ Σⱼ αᵢ αⱼ yᵢ yⱼ (xᵢᵀ xⱼ)

subject to  αᵢ ≥ 0,  Σᵢ αᵢ yᵢ = 0

对**软间隔**，唯一的改动是给每个 αᵢ 加一个**上界 C**（盒约束 box constraint），其余完全不变：

maximize_α  Σᵢ αᵢ − ½ Σᵢ Σⱼ αᵢ αⱼ yᵢ yⱼ (xᵢᵀ xⱼ)

subject to  0 ≤ αᵢ ≤ C,  Σᵢ αᵢ yᵢ = 0

请盯住对偶目标里的 **xᵢᵀxⱼ**：样本**只以两两内积的形式出现**，w 本身消失了。这就是 5.4 核技巧能生效的全部原因——只要能算内积，就能解 SVM，而无需接触样本的原始坐标。软间隔与硬间隔的差别仅仅是 αᵢ≤C 这个天花板，几何上它限制了"单个样本对 w 的贡献不能无限大"，从而让离群点无法过度扭曲边界。

对偶把"找一张超平面（w,b，维度=特征数）"的问题，换成了"给每个样本分配一个权重 αᵢ（个数=样本数）"的问题。当特征维度极高（甚至无穷，如 RBF 核）而样本数有限时，解 α 反而更划算——这是 SVM 能在高维/核空间里工作的技术前提。

### 5.3.3 KKT 条件

对偶最优解满足 **KKT（Karush-Kuhn-Tucker）条件**，其中最有用的是**互补松弛（complementary slackness）**。对软间隔 SVM，KKT 把每个样本的 αᵢ 值与它相对街道的位置精确对应起来：

αᵢ = 0  ⟺  yᵢ(wᵀxᵢ + b) ≥ 1（样本在街沿外，分对且够开）

0 < αᵢ < C  ⟺  yᵢ(wᵀxᵢ + b) = 1（样本恰在街沿上）

αᵢ = C  ⟺  yᵢ(wᵀxᵢ + b) ≤ 1（样本落进街道内或被分错，ξᵢ>0）

KKT 是约束优化"取到最优"的必要条件，互补松弛这条的白话版是"约束没顶满（严格不等）的样本，它的乘子必为 0"。翻译到 SVM 就是"没顶着街沿的点，α=0，对解毫无贡献"。这条件不只是理论——SMO 算法（5.5）判断是否收敛、该优化哪个样本，靠的就是检查谁违反了 KKT。

### 5.3.4 支持向量的三分类

由 5.3.3 的 KKT 对应，样本按 αᵢ 值天然分成三类，这是 SVM 最核心的结构：

αᵢ = 0 的样本：**非支持向量**。分对且在街沿外，占绝大多数，对 w 贡献为 0，删掉它们解不变。

0 < αᵢ < C 的样本：**自由支持向量（free / margin SV）**，恰好躺在街沿 wᵀx+b=±1 上。它们的 ξᵢ=0，是用来求偏置 b 的样本。

αᵢ = C 的样本：**边界支持向量（bounded SV）**，落进街道内（0<ξ≤1，仍分对）或越过判别面（ξ>1，被分错）。它们把乘子顶到了上限 C。

因此**只有支持向量（αᵢ>0）决定最终的 w**，这就严格证明了 5.1.5 的萌芽直觉。本次实证：`SVC` 的 `dual_coef_`（即 yᵢαᵢ）非零者仅 3 个、且这些支持向量处 `decision_function` 值恰为 ±1.000/±0.999，正是"自由支持向量落在街沿 |wᵀx+b|=1 上"的坐实。

把训练完的 α 打印出来，你会看到一大片 0（普通点）、几个在 (0,C) 之间（顶街沿的点）、几个正好等于 C（越界/进街的难点）。SVM 的"稀疏"就是指那一大片 0——预测新样本时只需对少数支持向量算内积，又快又省内存。

### 5.3.5 从对偶解恢复 w、b 与决策函数

解出 α 后，回到原始量。权重直接由 w = Σᵢ αᵢyᵢxᵢ 给出（求和实际只跑支持向量）。偏置 b 由任一自由支持向量（0<αⱼ<C，它满足 yⱼ(wᵀxⱼ+b)=1）解出，实践中对所有自由支持向量取平均更稳。最终**决策函数**是：

f(x) = sign( Σᵢ αᵢ yᵢ (xᵢᵀ x) + b )

还要再次强调，预测 x 时也**只出现内积 xᵢᵀx**，且求和只跑支持向量。把这个内积换成核 k(xᵢ,x)，就是 5.4 的核化决策函数——这正是对偶形式的全部价值兑现处。

训练的产物不是一个显式的 w（在核空间里 w 可能无穷维、根本写不出来），而是一组"支持向量 + 它们的权重 αᵢyᵢ + 偏置 b"。预测新点，就是拿它和每个支持向量比"相似度"（内积/核），按权重投票，加偏置看正负。这套"存样本 + 按相似度加权投票"的形态，正是"核方法"这一大家族的共同长相。

## 5.4 核技巧

### 5.4.1 核技巧的核心思想

线性 SVM 只能画直的边界，遇到"圆圈套圆圈"这类数据无能为力。经典对策是**先把数据映到更高维空间**再做线性分类——在高维里线性可分的边界，投影回原空间就成了曲线。设特征映射 φ 把 x 映到高维特征向量 φ(x)，在那里做线性 SVM 即可。

麻烦是 φ(x) 可能维度极高甚至无穷，显式算出来不可行。**核技巧（kernel trick）**的洞见是：由 5.3 我们知道 SVM 的对偶目标和决策函数里，样本**只以内积形式出现**。所以我们根本不需要 φ(x) 的坐标，只需要能算出**两个映射后向量的内积**。定义

k(x, z) = φ(x)ᵀ φ(z)

这个 **核函数（kernel function）** 直接吃原始向量、吐出高维内积，绕过了显式映射。把对偶与决策函数里所有 xᵢᵀxⱼ 换成 k(xᵢ,xⱼ)，就"免费"得到了非线性 SVM：

f(x) = sign( Σᵢ αᵢ yᵢ k(xᵢ, x) + b )

核技巧是一记"偷天换日"——本来要"先升维（可能升到无穷维）、再算内积"，核函数让你"跳过升维、直接算出那个内积该是多少"。就像想知道两地经飞机航线的距离，不必真的飞一趟，有公式直接算。本次实证：同心圆数据上线性核训练正确率仅 0.62、RBF 核达 1.000，直观坐实"核把线性推广到非线性"。

### 5.4.2 核函数与 Mercer 条件

不是任意二元函数都能当核。一个函数 k 要能写成某个 φ 的内积 φ(x)ᵀφ(z)，充要条件是它满足 **Mercer 条件**：k 对称，且对任意有限样本集，其 **Gram 矩阵 K（Kᵢⱼ=k(xᵢ,xⱼ)）半正定（PSD）**。满足此条件的核叫**合法核 / Mercer 核**，它保证背后真的存在一个（可能无穷维的）特征空间，从而对偶 QP 仍是凸的、有唯一解。

核函数本质是一个"相似度"度量——k(x,z) 越大表示 x、z 在特征空间里越"像"。Mercer 条件（Gram 阵半正定）是这个相似度"自洽"的数学要求，否则对偶问题会变成非凸、优化崩掉。合法核可以像积木一样组合：两个核相加、相乘、乘正常数、复合多项式，结果仍是合法核——这让人能造复杂核而不必每次验证 Mercer。本次实证：RBF 核 Gram 矩阵最小特征值数值上为 0（≥0，半正定），符合 Mercer。

### 5.4.3 常见核

实践中反复用到的几个核（k(x,z)）：

线性核 k(x,z) = xᵀz —— 就是不做映射的原始 SVM，φ 为恒等，适合高维稀疏数据（如文本）。

多项式核 k(x,z) = (γ xᵀz + r)^d —— 对应把特征做到 d 次的所有单项式组合，d 是次数、r 是常数项、γ 是缩放。能画多项式边界。

高斯核 / RBF 核 k(x,z) = exp(−γ‖x−z‖²) —— 最常用的通用核，对应**无穷维**特征空间，能逼近极复杂的边界。γ>0 控制"影响半径"。

sigmoid 核 k(x,z) = tanh(γ xᵀz + r) —— 形似两层神经网络，但**并非对所有参数都满足 Mercer 条件**（某些 γ,r 下 Gram 阵非半正定），实践中不常用、需谨慎。

选核就是选"用什么形状的边界"。没先验时 RBF 是稳妥默认；特征已经很高维（文本 TF-IDF）时线性核往往就够且更快；多项式核适合已知交互次数的场景。易错点：多项式核与 RBF 核对**特征缩放极其敏感**（因为它们含 xᵀz 或 ‖x−z‖²），用前几乎必须先标准化特征，否则大尺度特征会主宰核值。

### 5.4.4 RBF 核的 γ 与无穷维

RBF 核值得单独说，因为它最常用也最容易调坏。它对应的特征映射是无穷维的（可由 e 的泰勒展开看出含所有阶单项式），所以 RBF SVM 理论上能拟合任意复杂的边界。参数 γ 控制单个样本影响的"半径"：

k(x,z) = exp(−γ ‖x−z‖²),  γ = 1/(2σ²)

γ 大（σ 小）时每个样本影响范围很窄——边界能贴着数据扭得很碎，**易过拟合**；γ 小（σ 大）时影响范围很宽——边界很平滑，**易欠拟合**。γ 与 C 通常要**联合用交叉验证**调（归大主题6）。

把每个支持向量想成一座"高斯山峰"，决策就是这些山峰按 αᵢyᵢ 叠加后的地形正负。γ 是山峰的"瘦胖"——γ 大山峰又瘦又尖，只在支持向量附近凸起，地形破碎（过拟合）；γ 小山峰又胖又缓，地形平滑（欠拟合）。易错点：sklearn `SVC` 默认 `gamma='scale'`（=1/(n_features·X.var())，是数据相关的自适应缺省，1.9.0 沿用；老版本曾默认 `'auto'`=1/n_features，此为**版本演进过的默认值**，⚙锚 1.9.0），不是固定常数；k(x,x)=exp(0)=1 解释了本次实证 RBF Gram 对角线恒为 1。

### 5.4.5 核化决策函数与表示定理直觉

核 SVM 训练完，产物是"支持向量 xᵢ + 权重 αᵢyᵢ + 偏置 b"，预测就是

f(x) = sign( Σ_{i∈SV} αᵢ yᵢ k(xᵢ, x) + b )

背后有个更普适的原理叫**表示定理（representer theorem）**：一大类"损失 + L2 范数正则"的核学习问题，其最优解总能写成**训练样本核函数的线性组合** f(·)=Σᵢ cᵢ k(xᵢ,·)，即使特征空间无穷维、解也落在由训练样本张成的有限维子空间里。这就是"无穷维空间里也能实际求解"的根本保证。

无论特征空间多大，最优解都"住在训练数据张成的那点空间里"，所以我们永远只需要处理 m×m 的核矩阵（m=样本数）、而不是无穷维的坐标。这把整个核方法家族（核 SVM、核岭回归、高斯过程）统一成"存样本 + 按核相似度加权"的形态。此处只给直觉，泛函/RKHS 纵深不展开。

### 5.4.6 实践权衡与陷阱

核 SVM 强大但有代价。计算上，核矩阵是 m×m，训练复杂度大致 O(m²)~O(m³)、内存 O(m²)，**样本量一大（十万级以上）就吃不消**——这时线性核（`LinearSVC`）或改用别的模型更实际。统计上，核（尤其小 γ 的 RBF、大 d 的多项式）表达力极强、**极易过拟合**，必须靠 C、γ 的交叉验证约束。工程上，几乎所有非线性核都**要求先标准化特征**。

核 SVM 是"中小样本、需要非线性边界、维度不算爆炸"场景的利器；一旦样本量巨大或需要概率输出、在线更新，它就不再是首选（转向线性模型、树集成或神经网络）。选择顺序的常见经验：先线性核看基线，不够再上 RBF 并调 (C,γ)。

## 5.5 SMO 求解概览

### 5.5.1 为什么不能简单坐标上升

对偶问题是一个带盒约束 0≤αᵢ≤C 和**一条等式约束 Σαᵢyᵢ=0** 的凸 QP。样本量 m 大时，通用 QP 求解器要处理 m×m 的核矩阵，内存与时间都吃不消。最朴素的想法是**坐标上升**——每次固定其余、只优化一个 αᵢ。但这里行不通：等式约束 Σαᵢyᵢ=0 把所有 α 绑在一起，**单独改一个 αᵢ 必然破坏这条等式**（因为其余固定，Σαⱼyⱼ 已定，αᵢyᵢ 不能再自由变）。

这条等式约束像"一群人手拉手站成一排，总重心必须不动"——你不能只让一个人往前迈，那样重心就偏了。要在保持重心的前提下移动，至少得**两个人配合着一进一退**。

### 5.5.2 SMO 的核心：一次优化两个 α

Platt 1998 的 **SMO（Sequential Minimal Optimization，序列最小优化）** 正是这个"两人配合"的思路：**每次挑两个乘子 αᵢ、αⱼ 一起优化，固定其余全部**。由等式约束，αⱼ 完全被 αᵢ 决定（yᵢαᵢ+yⱼαⱼ = 常数），于是两变量子问题实际只剩一个自由变量的二次优化——它有**解析解（闭式解）**，一步算出、无需迭代内层优化器。反复挑对、解析更新，直到所有 α 都满足 KKT 条件为止。

SMO 把一个巨大的 QP 拆成无数个"两变量的小题"，每道小题一笔算完。为什么是"最小"？因为等式约束下能同时改的最少数量就是 2（改 1 个破坏约束、改 2 个是能维持约束的最小步长），所以叫"最小优化"。这让 SVM 不用存整个 m×m 核矩阵、也不依赖通用 QP 库，能扩展到较大数据。

### 5.5.3 两变量子问题的解析解

固定其余后，对选定的 (αᵢ,αⱼ)，先沿等式约束把 αⱼ 表成 αᵢ 的线性函数，代入对偶目标得到关于单个 αᵢ 的一元二次函数，求其无约束极值点，再把结果**裁剪（clip）到盒约束 [L,H]** 内（L、H 由 0≤α≤C 与等式约束共同给出的可行区间端点）。这一步无需任何数值迭代，是 SMO 高效的关键。每更新一对 α 后，还要用 KKT 条件**更新偏置 b**（由更新后仍为自由支持向量的样本重新定标）。

"先求抛物线顶点、再夹回可行区间"是带界约束一维二次优化的通用招式：无约束最优在区间内就用它，超出边界就取最近的边界值。SMO 每一步都是这么一个初等运算，所以极快。

### 5.5.4 工作集选择的启发式

SMO 的效率高度依赖"每次挑哪两个 α"。Platt 用两层**启发式（heuristic）**：外层优先遍历**违反 KKT 条件**的样本（这些是还没优化好的），把最"违规"的选作第一个 αᵢ；内层选第二个 αⱼ 时，挑能让这一步**目标提升最大**的（近似用 |Eᵢ−Eⱼ| 最大来选，E 是预测误差）。选到能显著推进的样本对，能大幅减少迭代轮数。

这就是"好钢用在刀刃上"——不盲目轮询所有样本，而是优先修那些明显还没到位（违反 KKT）的点，并让每一步走得尽量远。现代实现（libsvm）用的是这类思想的改进版（如 working set selection via 二阶信息），细节归实现、不展开。

### 5.5.5 收敛、实现与地位

SMO 保证**收敛到对偶的全局最优**（凸问题 + 每步不降目标 + KKT 作为停止判据）。它是 **libsvm** 的核心算法，而 sklearn 的 `SVC`/`SVR` 底层正是封装 libsvm（`LinearSVC` 则走 liblinear、不用 SMO）。SMO 让 SVM 从"要调用笨重 QP 求解器"变成"几十行能实现、内存友好"，是 SVM 在 2000 年代广泛流行的工程推手。

可以把 SMO 记成"专为 SVM 对偶定制的坐标上升——因为有等式约束绑手，所以一次动两个、每步解析求解、优先修违反 KKT 的点"。它不改变 SVM 的解（解由对偶问题唯一确定），只是把这个解**又快又省地算出来**的手段。停止条件是所有样本都（近似）满足 KKT，容差由实现参数控制（如 libsvm 的 `tol`，⚙锚实现）。
