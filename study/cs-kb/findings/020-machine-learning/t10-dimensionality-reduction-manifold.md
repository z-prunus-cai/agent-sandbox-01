> 本报告一条主线心智模型：降维 = 用**少数几个新坐标轴**重新描述数据，使得"扔掉其余坐标"损失最小。分歧只在"损失"怎么定义。PCA 说损失 = 丢掉的方差（等价于重构平方误差），于是新轴就是数据协方差矩阵的主特征向量——一个纯线性代数问题（桥 L1-03 的 SVD）。ICA 换一个目标：不要方差最大，而要各成分**统计独立**，用来把混在一起的信号拆开（鸡尾酒会问题）。因子分析走生成模型路线：假设观测由少数隐因子线性生成再加噪声，用 EM 反推因子。这三者都是**线性**方法（新坐标是原坐标的线性组合）。但真实数据常盘绕在一张弯曲的低维"流形"上（想象一张揉皱的纸嵌在三维空间里），线性投影会把远处强行拉近、把邻近点撕开——于是 10.5 的 t-SNE/UMAP 改为只保**局部邻域关系**，专供可视化。贯穿始终的反面动机是 10.4 的维度灾难：维度一高，数据变得极度稀疏、点与点的距离趋于相等，几乎所有依赖距离的算法都失灵——这正是"必须降维"的根本理由。

## 10.1 PCA（主成分分析）

### 10.1.1 一句话定义与两个等价视角

**主成分分析（Principal Component Analysis, PCA）** 是最基础的线性降维：它找一组新的正交坐标轴（**主成分**），使得数据投影到前几个轴上时保留的**方差最大**；等价地，使得用这几个轴重构原数据的**平方误差最小**。第一主成分是数据散布最开（方差最大）的方向，第二主成分是与第一正交的方向中方差最大的，以此类推。

这里的关键是"两个视角是同一件事"。CS229 U10 与 ISL §12.2 都从**最大方差**方向切入，ESL §14.5 与 Bishop §12.1 则并列给出**最小重构误差**的等价刻画（Bishop 明确称之为 PCA 的两种定义，Pearson 1901 用的是重构误差、Hotelling 1933 用的是方差）。为什么等价？因为数据总方差是固定的，投影方向上"保留的方差"越大，垂直方向上"丢掉的方差（即重构误差）"就越小——两者此消彼长，同一个最优方向同时最大化前者、最小化后者。

对初学者，把 PCA 想成给一团椭球形的点云找"主轴"：椭球最长的那条轴就是第一主成分，次长且与之垂直的是第二主成分。沿着长轴看，点铺得最开、信息最多；沿着最短的轴看，点几乎挤成一条线，扔掉它损失最小。

### 10.1.2 数学表述：协方差矩阵的特征分解

设数据矩阵 X 为 n×d（n 个样本、d 维），先**中心化**（每列减去均值）得 X_c。样本协方差矩阵为

C = (1 / (n − 1)) · X_cᵀ X_c

PCA 的第一主成分方向 w₁ 是下面这个约束优化的解

maximize   w ᵀ C w     subject to   ‖w‖ = 1

用拉格朗日乘子求解，最优 w 满足

C w = λ w

也就是说主成分方向就是协方差矩阵 C 的**特征向量**，对应特征值 λ 恰好是数据投影到该方向上的**方差**。把特征值从大到小排序，前 k 个特征向量就是前 k 个主成分。

直观地说，特征向量给出"数据散布的天然方向"，特征值给出"该方向上散得多开"。这就是为什么大主题的锚点强调 PCA 是 L1-03 线代（特征分解/SVD）的直接应用：降维在这里被彻底还原成一个特征值问题。一个常见误解是以为主成分有"物理含义"——它们只是方差意义上的最优正交基，未必对应任何可解释的真实因素（要可解释性得看 10.3 因子分析或做旋转）。

### 10.1.3 PCA via SVD：更稳更常用的算法（桥 L1-03）

实践中很少直接对 C 做特征分解，而是对中心化数据 X_c 做**奇异值分解（SVD）**

X_c = U S Vᵀ

其中 V 的列就是主成分方向（等于 C 的特征向量），奇异值 S 与特征值的关系为

λ_i = s_i² / (n − 1)

把数据投影到前 k 个主成分得到低维坐标（**得分**，scores）

Z = X_c V_k = U_k S_k

其中 V_k 是 V 的前 k 列。本次 numpy 实证确认：对同一数据，协方差特征分解与 X_c 的 SVD 给出完全一致的主成分方差与方向（符号可能相反，这是特征向量固有的正负号自由度，不影响子空间），且保留 k 个成分的重构误差恰等于被丢弃特征值之和。

为什么工程上偏爱 SVD 而非先算 C 再分解？因为显式构造 XᵀX 会把数据的条件数平方，放大数值误差；SVD 直接作用于 X_c 数值上更稳，这也是 sklearn `PCA` 内部默认走 SVD 的原因。初学者只需记住结论：**PCA = 中心化 + SVD，取前 k 个右奇异向量**。

### 10.1.4 保留多少成分：解释方差比

第 i 个主成分**解释的方差比例**为

explained_variance_ratio_i = λ_i / (λ₁ + λ₂ + … + λ_d)

累积解释方差比常用来定 k：例如"取到累积达 90% 或 95% 的最小 k"。另一个常用工具是**碎石图（scree plot）**——把特征值从大到小画出来，找曲线的"肘部（elbow）"，肘部之后特征值趋平，说明再加成分收益甚微。

ISL §12.2 与 ESL §14.5 都强调：k 的选择没有唯一正确答案，累积方差阈值和碎石图肘部都是启发式，取决于下游用途（可视化通常直接取 2 或 3；作为回归/分类的预处理则按交叉验证挑）。易错点：解释方差比是相对于**中心化后**的总方差，且强烈受 10.1.5 的缩放选择影响。

### 10.1.5 预处理：中心化必需、标准化视量纲而定

PCA 前**必须中心化**（减均值），否则第一主成分会被数据整体偏移的方向主导，而非真正的散布方向。是否还要**标准化**（每列除以标准差，即用相关矩阵而非协方差矩阵）取决于各特征量纲：若特征量纲差异大（如"年龄"以岁计、"收入"以万元计），方差大的特征会仅因单位而霸占主成分，此时应标准化；若各特征本就同量纲同尺度，则可只中心化。

ISL §12.2 明确指出"通常对变量做标准化"，并给出一个经典例子：用不标准化的 PCA 分析各州犯罪数据，Assault（数值大）会主导结果。ESL 也讨论了这一敏感性。初学者记一句：**中心化不可省，标准化看量纲；换了缩放，主成分就变，不是 bug 而是定义如此**。

### 10.1.6 局限与常见误解

PCA 是**线性**方法：新坐标是原坐标的线性组合，因此只能捕捉线性结构，对盘绕在弯曲流形上的数据无能为力（这正是 10.5 存在的理由）。此外 PCA 以"方差大 = 重要"为前提，但方差大的方向不一定是对下游任务（如分类）最有判别力的方向——若目标是分类，LDA（线性判别分析，属监督降维）常更合适；PCA 是**无监督**的，完全不看标签。

两个高频误解要点破。其一，PCA **不是特征选择**：它产出的是原特征的线性组合（新特征），不是从原特征里挑子集。其二，主成分的正负号无意义——同一主成分乘以 −1 仍是合法主成分，不同软件/不同运行给出的符号可能相反，不影响解释。

## 10.2 ICA（独立成分分析）

### 10.2.1 一句话定义与鸡尾酒会问题

**独立成分分析（Independent Component Analysis, ICA）** 的目标不是保方差，而是把观测到的混合信号**拆成统计独立的若干源**。它的招牌场景是**鸡尾酒会问题 / 盲源分离**：房间里 d 个麦克风各录到 d 个说话人声音的不同混合，ICA 在完全不知道谁在说什么（"盲"）的前提下，仅凭"各人声音统计独立"这一假设，把每路原始人声分离出来。

CS229 U10 的 ICA 讲义正是用这个例子开篇。与 PCA 的对比是理解 ICA 的钥匙：PCA 找**不相关**（正交）的方向，ICA 要更强的**统计独立**。不相关只管二阶统计（协方差为零），独立要求所有阶统计都无关联——独立一定不相关，反之不然。

### 10.2.2 生成模型：x = A s

ICA 假设观测向量 x 由未知的独立源 s 经一个未知的**混合矩阵** A 线性生成

x = A s

其中 s 的各分量 s₁,…,s_d 相互统计独立。ICA 要估计一个**解混矩阵** W ≈ A⁻¹，使得

ŝ = W x

恢复出的 ŝ 各分量尽量独立。本次实证把正弦波与方波用固定矩阵混合，FastICA 恢复信号与真源绝对相关系数达 0.999/0.998，而 PCA 只有 0.92/0.88——直观坐实"PCA 的正交成分不等于独立成分，做盲源分离要用 ICA"。

### 10.2.3 为什么靠"非高斯"才能拆开

ICA 能工作的核心前提是**源信号非高斯**。根据中心极限定理，多个独立随机变量的线性混合会趋于高斯；反过来，越"不像高斯"的方向越可能是单一的原始源。所以 ICA 的算法实质是**寻找使投影最大程度非高斯的方向**——常用非高斯性度量是**峰度（kurtosis）**或**负熵（negentropy）**。ESL §14.6 与 Bishop §12.4 都以此为主线。

由此得出一个硬性限制——若源本身就是高斯的，ICA 就会**失效**。因为高斯分布旋转不变，多个独立高斯源的混合无法通过任何准则区分出原方向，此时 ICA 与 PCA 再无差别。一句话记住，**ICA 吃的是"非高斯"这口饭**。

### 10.2.4 三种固有不确定性

ICA 恢复的源存在三种无法消除的歧义，各来源一致列出：

顺序不确定——恢复出的各源的排列次序无法确定（无所谓哪路是"第一"源）。

幅度/符号不确定——每路源的缩放比例和正负号无法确定（因为缩放可在 A 与 s 之间互相吸收）。

高斯源禁区——至多允许一个源是高斯的，若有两个及以上高斯源则彼此无法分离（承接 10.2.3）。

这些不是算法缺陷而是问题本身的内蕴不可辨识性。对初学者：这意味着 ICA 输出的"第 2 路信号乘了 −3 倍"和真源在应用上等价（如分离出的人声，音量和顺序无关紧要）。

### 10.2.5 预处理与常见算法

ICA 前通常先**中心化 + 白化（whitening）**：白化用 PCA 把数据变换成各分量不相关且单位方差，这一步把"找解混矩阵"简化为"在白化空间里找一个正交旋转"，大幅降低问题难度。常见算法有 **FastICA**（Hyvärinen，定点迭代最大化非高斯性，sklearn 采用）和 **Infomax**（最大化输出熵）。

这里有一点要点破——白化虽用了 PCA，但白化**不是** ICA 的终点，PCA 只做到"不相关"，还差最后那个旋转才到"独立"。这恰好说明 PCA 与 ICA 是层级关系，可写成 ICA ≈ PCA 白化 + 一个额外的非高斯性驱动的旋转。sklearn `FastICA` 在 1.9.0 中 `whiten` 参数的默认已改为 `'unit-variance'`（早期版本为布尔 `True`），属实现细节演进，锚版本记录。

## 10.3 因子分析（Factor Analysis）

### 10.3.1 一句话定义与隐因子直觉

**因子分析（Factor Analysis, FA）** 是一个**生成式隐变量模型**：它假设你观测到的高维数据，其实是由少数几个看不见的**隐因子（latent factors）** 线性驱动、再叠加各维独立噪声而成。经典例子来自心理测量学——学生在多门考试上的成绩，可能主要由"语言能力""数理能力"两个隐因子决定，FA 就是要从成绩数据里反推出这些因子及其载荷。

CS229 U10 的因子分析讲义与 Bishop §12.2 都把它放在"连续隐变量模型"框架下，与 PCA/概率 PCA 并列。与 PCA 的根本区别：PCA 是纯几何/代数的方差最大化，没有概率模型和噪声概念；FA 是一个明确的**概率生成模型**，且允许**各维噪声不同**。

### 10.3.2 模型：x = μ + Λ z + ε

设隐因子 z 是 k 维（k < d），服从标准正态

z ~ N(0, I)

观测 x 由线性生成加噪声

x = μ + Λ z + ε

其中 μ 是均值，Λ 是 d×k 的**因子载荷矩阵（factor loadings）**，噪声 ε 服从对角协方差高斯

ε ~ N(0, Ψ),   Ψ = diag(ψ₁, …, ψ_d)

关键在于 Ψ 是**对角**矩阵：这表示各观测维度的噪声相互独立，观测变量之间的所有相关性都必须由共同因子 z（通过 Λ）来解释。由模型可推出边际分布

x ~ N(μ, Λ Λᵀ + Ψ)

初学者抓住一点就够——FA 把观测协方差拆成"共同因子贡献 ΛΛᵀ"加"各自独立噪声 Ψ"两部分，这就是"共性 vs 特异性"的分解。

### 10.3.3 与 PCA、概率 PCA 的关系

FA 与 PCA 常被混淆，务必分清。PCA 无噪声模型、且把所有方向的方差同等对待；FA 显式区分"共享方差（因子）"与"各维独立噪声"，因此对**各维噪声水平不同**的数据更合理。中间还有一个**概率 PCA（PPCA，Tipping & Bishop 1999）**：它是 FA 的特例，把噪声约束成**各向同性**

Ψ = σ² I

即所有维度噪声相同。Bishop §12.2 系统地给出 PPCA，并说明当 σ²→0 时 PPCA 退化为经典 PCA。所以三者的谱系是：PCA ⊂ PPCA（各向同性噪声）⊂ FA（对角但可不等的噪声）。

还有一个易错点要留意，FA 的载荷矩阵 Λ 存在**旋转不确定性**——对任意正交矩阵 R，用 ΛR 替换 Λ 得到的模型等价（因为 (ΛR)(ΛR)ᵀ = ΛΛᵀ）。这意味着因子本身不唯一，实践中常做**因子旋转（如 varimax）** 以获得可解释的载荷。这与 PCA 主成分的唯一性（在特征值不重复时）形成对比。

### 10.3.4 参数估计：EM 算法

FA 的参数 (μ, Λ, Ψ) 没有像 PCA 那样的闭式特征分解解，通常用**EM 算法**估计（μ 直接取样本均值）：E 步在当前参数下算隐因子 z 的后验期望，M 步用这些期望更新 Λ 和 Ψ，交替至收敛。这正是大主题9 EM 框架（把 z 当缺失数据）在连续隐变量上的又一应用，本报告不重复推导。

对初学者来说，FA 与 GMM（大主题9）都是"用 EM 估计的隐变量高斯模型"，区别只在隐变量——GMM 的隐变量是离散的类别指示，FA 的隐变量是连续的因子向量。把它们放在一起记，EM 的心智模型就通了。

## 10.4 维度灾难（Curse of Dimensionality）

### 10.4.1 一句话定义

**维度灾难（curse of dimensionality）** 指随着特征维度 d 增大，一系列在低维下有效的直觉和算法会急剧退化：为覆盖空间所需的样本量呈**指数增长**，数据变得极度**稀疏**，点与点之间的**距离趋于相等**，导致依赖距离/密度的方法（kNN、核方法、密度估计）失效。这个词由 Bellman 提出，ESL §2.5 与 CS229/ISL 均系统讨论。

它是本大主题所有降维方法的**共同动机**：正因为高维如此难缠，我们才要千方百计把数据压回低维。

### 10.4.2 采样稀疏：体积随维度指数膨胀

要在 d 维单位超立方体里维持固定的采样密度，所需样本数随 d 指数增长。ESL §2.5 给的经典刻画：要用一个小超立方体捕获数据的一个比例 r，其每条边的长度须为

edge_length(r) = r^(1/d)

例如在 d=10 维要捕获 1% 的数据（r=0.01），边长要达到 0.01^(1/10) ≈ 0.63——即每个维度都要覆盖 63% 的范围，"局部邻域"根本不局部了。d 越大，这个边长越接近 1，意味着"想抓一小撮邻居"必须几乎横跨整个空间。

直观地讲，低维里"附近"是个小范围，高维里为凑够几个邻居你被迫把网撒到几乎整个空间，"邻域"这个概念名存实亡。这直接打击 kNN——它的前提"近邻点标签相近"在高维下失去意义。

### 10.4.3 距离集中：远近之差被抹平

更违反直觉的现象是**距离集中（distance concentration）**：高维下，任意两点间的欧氏距离趋于相同，"最近点"和"最远点"的差距相对缩小。一个常用的刻画量是

(dmax − dmin) / dmin

它随维度升高而趋近 0。本次 numpy 实证（1000 个均匀随机点相对一个查询点）测得：d=2 时该比值约 61，d=10 约 2.3，d=100 约 0.42，d=1000 约 0.11——远近对比被系统性抹平。点对之间的对比度同样随维度骤降。

为什么？因为欧氏距离是各维度平方差之和的平方根，维度越多，每对点的距离都是大量独立项之和，由大数定律趋于同一期望值，方差相对均值越来越小。后果很致命：既然所有点都"差不多远"，"最近邻"就几乎是随机的，kNN、基于距离的聚类和检索全部退化。初学者记这句：**高维里，人人都是你的邻居，也就没有邻居**。

### 10.4.4 后果、以及"流形假设"这条出路

维度灾难带来一连串直接后果，距离/密度类方法（kNN、核密度估计、RBF 核、基于距离的聚类）在高维原始空间中都不再可靠，而且需要指数级样本才能填满空间、实践中永远样本不足。这就是为什么"先降维再建模"往往比在原始高维空间硬算更有效。

但有一个重要的"解药"叫**流形假设（manifold hypothesis）**：真实高维数据（图像、语音、文本）通常并非均匀撒满整个高维空间，而是集中在一张维度低得多的**弯曲流形**上——一张 100×100 的人脸图虽是一万维向量，但有意义的人脸只占其中极小的一张低维流形。正因如此，把数据从"名义高维"压到"内在低维"不仅可能而且有益，这正是 10.5 非线性流形学习的立足点。ESL §2.5 讲灾难，§14.8–14.9 讲流形出路，两节要连起来读。

## 10.5 非线性流形学习（t-SNE / UMAP） `⚙演进快·锚版本`

### 10.5.1 为什么线性方法不够：流形假设

承接 10.4.4：真实高维数据常盘绕在一张**弯曲的低维流形**上。经典比喻是"瑞士卷（Swiss roll）"——一张二维纸卷成三维螺旋，纸上相邻的两点在三维欧氏距离上可能很近，但沿着纸面（流形上的**测地距离**）却隔得很远。PCA 这类线性投影只会把卷"拍扁"，把本该分开的卷层压叠在一起，破坏了邻域结构。

**非线性流形学习**的目标就是"展开"这张卷：把高维流形嵌入低维（通常 2D）而**保持邻域关系**。ESL §14.9 归纳了经典方法——**Isomap**（用图上最短路近似测地距离再做 MDS）、**LLE 局部线性嵌入**（用每点邻居的线性重构权重刻画局部结构）、**拉普拉斯特征映射**等。这些是理解思路的基石，但当代可视化的主力是 t-SNE 与 UMAP。

### 10.5.2 t-SNE 的机制

**t-SNE（t-distributed Stochastic Neighbor Embedding，van der Maaten & Hinton 2008）** 把降维变成一个"匹配邻居概率分布"的问题。在高维，它用高斯核把点对相似度转成概率 p_ij（近的点概率高）；在低维嵌入空间，它用一个**重尾的 t 分布（自由度 1，即柯西分布）** 定义相似概率 q_ij

q_ij ∝ (1 + ‖y_i − y_j‖²)⁻¹

然后最小化两个分布的 **KL 散度**

Cost = Σ_ij  p_ij · log( p_ij / q_ij )

低维用重尾 t 分布是 t-SNE 的点睛之笔：它给中等距离的点留出"喘息空间"，缓解了早期 SNE 的"拥挤问题（crowding problem）"——高维的大量邻居无法都塞进低维的小邻域，重尾分布允许它们在低维适当散开。控制邻域大小的关键超参是**困惑度（perplexity）**，可粗略理解为"每个点考虑多少个有效邻居"，原论文建议取 5–50。

本机实证：手写数字集上 t-SNE 的邻域保持度（trustworthiness，10 近邻）0.9925，远高于 PCA 的 0.83，直观印证 t-SNE 更擅长把同类数字聚成可分辨的簇。

### 10.5.3 t-SNE 的陷阱（务必点破）

t-SNE 是**可视化**工具，不是通用降维或聚类算法，几个陷阱必须知道。**簇的大小无意义**——t-SNE 会放大稀疏簇、压缩密集簇，图上簇的面积不反映真实方差。**簇间距离无意义**——两个簇在图上离多远，不代表它们在原空间也那么远，全局几何被牺牲以换取局部邻域。**超参敏感**——不同 perplexity 会给出观感差异很大的图，需多试几个值。**结果随机**——初始化和随机种子会影响布局，同一数据两次运行图可能不同。

因此实践铁律：t-SNE 图**只能定性看"谁和谁聚在一起"，不能量出距离、不能据图下"有几个簇/簇有多大"的定量结论**。要做严肃聚类应回到原空间用专门算法。这些告诫在 t-SNE 后续社区讨论与 sklearn 文档中反复强调。

### 10.5.4 UMAP `⚙演进快·锚版本`

**UMAP（Uniform Manifold Approximation and Projection，McInnes/Healy/Melville 2018，arXiv:1802.03426）** 是 t-SNE 之后最流行的替代，理论根基取自黎曼几何与代数拓扑，实践中先构建高维数据的**加权 k 近邻图**（模糊拓扑表示），再在低维优化一个布局使其图结构尽量匹配（用交叉熵类目标）。相比 t-SNE，UMAP 通常**更快、可扩展到更大数据集**，并被认为在一定程度上**更好地保留全局结构**（不过"更好保全局"这点在社区仍有争论，非定论）。

两个关键超参：**n_neighbors**（局部/全局权衡，越大越看重全局结构）与 **min_dist**（低维点允许多紧凑，越小簇越密）。umap-learn 库常见默认为 n_neighbors=15、min_dist=0.1（⚙演进快·锚版本，本机未安装 umap-learn，此默认取自 UMAP 官方文档/论文，具体默认随库版本可能变，标「待核 @2026-07-30」）。

必须点破：UMAP 与 t-SNE **共享同一类陷阱**——它也是可视化优先、局部邻域优先，图上簇的大小与簇间距离同样不宜做定量解读；"UMAP 保全局更好"是相对说法，不能当成"UMAP 图的距离可信"。sklearn 核心库当前**不内置 UMAP**（需第三方 umap-learn 包），这与 t-SNE 内置于 `sklearn.manifold.TSNE` 不同。

### 10.5.5 sklearn t-SNE 关键默认（锚版本）`⚙演进快·锚版本`

在 scikit-learn 1.9.0，`sklearn.manifold.TSNE` 的当前默认值（本机 inspect 核实）：`n_components=2`、`perplexity=30.0`、`early_exaggeration=12.0`、`learning_rate='auto'`、`max_iter=1000`、`init='pca'`、`method='barnes_hut'`、`angle=0.5`、`metric='euclidean'`。
