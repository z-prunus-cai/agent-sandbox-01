## 4.1 生成 vs 判别

### 4.1.1 两种建模范式：直接学边界 vs 分别学各类画像

监督分类有两条根本不同的建模路线。**判别式（discriminative）**算法直接对条件分布 p(y|x) 建模——给定特征 x，标签 y 的概率是多少（逻辑回归、softmax 都属此类）；甚至可以更极端，只学一个决策边界函数 h(x) 而完全不碰概率（如感知机、SVM）。**生成式（generative）**算法则绕一个弯：它对每一类分别建模**类条件分布** p(x|y)（"第 y 类的样本长什么样"）以及**类先验** p(y)（"第 y 类有多常见"），这两者合起来等价于对联合分布 p(x,y) 建模。

因为学到了 p(x|y)，生成式模型理论上可以从某一类里"生成/采样"出新的假样本 x——它掌握了每一类的完整数据画像，而不只是类与类之间的分界线。判别式模型做不到这一点，它只知道边界，不知道每一类内部的分布长什么样。

给初学者一个最小对照。假设要区分大象和狗。判别式思路：直接找一条规则，比如"体重大于某阈值就是大象"，只关心那条分界。生成式思路：先分别建立"大象的体型/体重分布画像"和"狗的体型/体重分布画像"，来了一只新动物，就分别问"它有多像典型大象""有多像典型狗"，谁的画像更贴合就判给谁。两条路都能分类，但生成式额外学到了"每一类本身的样子"。

### 4.1.2 贝叶斯规则：生成式模型如何完成预测

生成式模型学的是 p(x|y) 和 p(y)，但预测时我们要的是 p(y|x)。两者通过**贝叶斯规则**连接：

p(y|x) = p(x|y) p(y) / p(x)

其中分母 p(x) 是归一化常数，对所有类都一样，按全概率公式展开为：

p(x) = Σ_y p(x|y) p(y)

因为分母与 y 无关，做分类（取最可能的类）时可以直接丢掉它，只比较分子：

ŷ = argmax_y  p(x|y) p(y)

这一步是生成式分类的操作核心：训练阶段分别估计每一类的 p(x|y) 和 p(y)，预测阶段对每个候选类算一遍"类条件似然 × 先验"，取最大的那个。

分母 p(x) 只在你需要一个**规范化的概率值**（比如"这封邮件有 92% 概率是垃圾邮件"）时才要算；如果只是要**判类**（垃圾还是正常），分母可以整个忽略，因为它不改变谁大谁小。很多入门实现直接比较未归一化的分子，就是这个道理。

### 4.1.3 生成-判别配对与数据效率权衡

许多生成式模型和判别式模型是**成对**的——它们对 p(y|x) 给出同样形式的函数，只是估参方式不同。CS229 讲义证明：GDA（共享协方差）推出的 p(y=1|x) 恰好是 x 的 **sigmoid 函数**，形式与逻辑回归完全一样；朴素贝叶斯（在合适事件模型下）也对应逻辑回归形式的后验。所以 GDA↔逻辑回归、朴素贝叶斯↔逻辑回归构成两对"生成-判别配对"。

既然后验形式一样，为什么还要两套？区别在**假设强度与数据效率**的权衡。生成式（GDA）做了更强的假设——它假定类条件分布确实是高斯的。若这个假设**成立**，GDA 用更少的数据就能收敛到好模型（渐近更省数据）；若假设**不成立**，逻辑回归因为不对 p(x|y) 做任何形状假设，反而更稳健、渐近误差更低。

这条权衡有一手出处，也存在需要点明的**表述差异**。Ng 的 CS229 讲义把它总结为："GDA 假设更强、数据高效，当高斯假设近似成立时更优；逻辑回归假设更弱、更稳健。" 而 Ng & Jordan 的经典论文《On Discriminative vs. Generative Classifiers》（NIPS 2001）给出更精细的结论：判别式模型（逻辑回归）的**渐近误差更低**，但生成式模型（朴素贝叶斯）**收敛更快**（随样本量以更快速率逼近它自己那个较高的渐近误差），因此在小样本时生成式常反而占优、大样本时判别式反超。两处不矛盾，但初学者容易只记住"生成式更省数据"而漏掉"它的渐近上限可能更差"这半句——完整图景是"小样本生成式领先、大样本判别式反超"。

## 4.2 高斯判别分析 GDA

### 4.2.1 模型设定：类先验 + 类条件高斯 + 共享协方差

高斯判别分析（Gaussian Discriminant Analysis, GDA）是连续特征上的生成式分类器。以二分类为例，它做三条假设。标签服从伯努利分布：

y ~ Bernoulli(φ)

两个类的特征各自服从**多元高斯分布**，均值不同、但**协方差矩阵共享**（同一个 Σ）：

x | y=0 ~ N(μ₀, Σ)

x | y=1 ~ N(μ₁, Σ)

"共享协方差"是 GDA 的关键设定，也是它决策边界为线性的根源（见 4.2.4）。直观上，它假定两类样本的"散布形状/朝向/大小"一样，只是"中心位置"不同——两团形状相同的椭圆云，只是平移开了。

给初学者说明为什么这个假设常常够用：真实数据里两类的散布未必完全相同，但共享协方差大幅减少了要估计的参数（只估一个 Σ 而非两个），在样本不多时更稳、更不易过拟合。若两类散布形状明显不同，可放开成各类独立协方差 Σ₀、Σ₁——那就是 4.2.4 会提到的 QDA。

### 4.2.2 多元高斯密度

类条件分布用的多元高斯（multivariate Gaussian）密度，d 维时为：

p(x; μ, Σ) = 1 / ( (2π)^{d/2} |Σ|^{1/2} ) · exp( −½ (x−μ)ᵀ Σ⁻¹ (x−μ) )

其中 |Σ| 是协方差矩阵的行列式，Σ⁻¹ 是其逆，(x−μ)ᵀΣ⁻¹(x−μ) 是**马氏距离（Mahalanobis distance）的平方**。

给初学者拆解这个看着吓人的公式。指数里的马氏距离是"考虑了各维尺度和相关性之后的距离"——普通欧氏距离把每个方向一视同仁，马氏距离先用 Σ⁻¹ 把椭圆形的等概率线"拉圆"，让距离沿方差大的方向缩水、沿方差小的方向放大。前面那个 1/((2π)^{d/2}|Σ|^{1/2}) 只是归一化常数，保证整个密度积分为 1。做分类时取对数，指数不见了、常数项可丢，最后比的就是各类的马氏距离（加上先验的对数），谁的马氏距离小就更像哪类。

### 4.2.3 参数的最大似然闭式解

GDA 的参数 φ、μ₀、μ₁、Σ 由**最大化联合似然** Πᵢ p(xᵢ, yᵢ) 得到，结果是干净的闭式解（m 为样本数，1{·} 为指示函数）：

φ = (1/m) Σᵢ 1{yᵢ = 1}

μ₀ = ( Σᵢ 1{yᵢ=0} xᵢ ) / ( Σᵢ 1{yᵢ=0} )

μ₁ = ( Σᵢ 1{yᵢ=1} xᵢ ) / ( Σᵢ 1{yᵢ=1} )

Σ = (1/m) Σᵢ (xᵢ − μ_{yᵢ}) (xᵢ − μ_{yᵢ})ᵀ

先验 φ 就是正类样本的比例；每一类的均值 μ_k 就是该类样本的算术平均（各类画像的中心）；共享协方差 Σ 是把每个样本减去**它自己那一类的均值**后，再统一算的协方差（两类的离差合在一起估一个 Σ）。全部是数一数、求个平均，没有迭代优化——这是生成式模型相对判别式（要跑梯度下降）的一个便利之处。

这里有一处需要点明的**来源差异**。CS229 讲义的 Σ 用 1/m 作除数（这是有偏的 MLE）；ESL/ISL 在讲等价的 LDA 时，共享协方差常用 1/(m−K) 作除数（K 为类数，无偏估计，即 pooled covariance）。两者只差一个常数因子，对决策边界的方向没有影响（边界由 Σ⁻¹ 决定，常数因子约掉），初学者不必纠结，但要知道不同教材除数写法不同。scikit-learn 的 `LinearDiscriminantAnalysis` 用的是经验/收缩协方差估计，具体随 solver 与 shrinkage 参数而变（⚙演进快·锚版本 sklearn 1.9.0，默认 solver='svd' 不做收缩）。

本机 numpy 手写 GDA 闭式解坐实（合成两团共享协方差高斯、各 400 点，`基线 Py3.11.15/np2.4.6 @2026-07-30`）：估得 φ=0.500，μ₀≈(−0.09,−0.10)、μ₁≈(2.05,1.56)、Σ≈[[0.96,0.47],[0.47,0.94]]（贴近真值 μ₀=(0,0)、μ₁=(2,1.5)、Σ=[[1,0.5],[0.5,1]]），用推出的线性判别式（见 4.2.4）在训练集达 acc=0.881。sklearn `GaussianNB` 在同数据 acc=0.876（GaussianNB 假设特征间独立、对角协方差，与 GDA 的满协方差略有差别，故略低），两者数量级一致，交叉印证。

### 4.2.4 共享协方差 ⇒ 线性决策边界（GDA 与逻辑回归的关系；LDA/QDA 命名）

GDA 一个漂亮的结论：**当两类共享协方差 Σ 时，后验 p(y=1|x) 是 x 的一个线性函数经 sigmoid 的结果**，即：

p(y=1 | x) = 1 / ( 1 + exp( −(wᵀx + b) ) )

其中 w = Σ⁻¹(μ₁ − μ₀)，b 由先验和均值决定。这正是**逻辑回归的形式**——决策边界 wᵀx + b = 0 是一张超平面（线性边界）。之所以线性，是因为两类高斯的指数里都带 −½ xᵀΣ⁻¹x 这个二次项，共享 Σ 时它在两类的对数几率相减时**正好抵消**，只剩下 x 的一次项。

由此引出 ESL/ISL 的命名对照，初学者务必对上号。当协方差共享、边界线性时，统计学教材叫它**线性判别分析（Linear Discriminant Analysis, LDA）**——CS229 的"共享协方差 GDA"和 ESL/ISL 的"LDA"是同一个模型的两个名字（差别仅在 CS229 主讲二分类、LDA 一般讲多类，以及 4.2.3 提到的除数约定）。若放开成两类各自独立的协方差 Σ₀、Σ₁，二次项不再抵消，决策边界变成**二次曲面**，这叫**二次判别分析（Quadratic Discriminant Analysis, QDA）**。

再点两个关联，避免概念串味。其一，GDA/LDA 与大主题9 的**高斯混合 GMM** 用同一族高斯零件，但 GDA 是**有标签**的（每个样本已知属于哪类，直接数着估参），GMM 是**无标签**的（要用 EM 迭代猜每点属于哪个成分）——同样的高斯，监督版是 GDA、无监督版是 GMM。其二，GDA↔逻辑回归就是 4.1.3 那对"生成-判别配对"的具体实例：同样得到 sigmoid 后验，GDA 靠数高斯统计量估参、逻辑回归靠梯度下降直接拟合 w，前者在高斯假设成立时更省数据、后者更稳健。

## 4.3 朴素贝叶斯

### 4.3.1 条件独立假设

朴素贝叶斯（Naive Bayes）是离散/高维特征上最常用的生成式分类器。要建模 p(x|y)，当 x 是高维（比如一封邮件用几万个词的出现与否表示）时，直接估计各特征的联合分布需要指数级的参数，不可行。朴素贝叶斯用一个大胆的简化——**给定类别 y，各特征相互条件独立**：

p(x₁, x₂, …, x_d | y) = Π_{j=1}^{d} p(x_j | y)

于是只需分别估计每个特征在每个类里的边缘分布 p(x_j|y)，参数量从指数级降到线性级。

"naive（朴素/天真）"这个名字正是在自嘲这个假设太强、几乎总是不成立——现实里词与词当然相关（"机器"后面更可能跟"学习"）。给初学者的关键直觉：这个假设几乎肯定是**错**的，但它把不可能估的高维联合分布拆成了一堆好估的一维分布，而且（见 4.3.4）即便假设错了，用来**分类**往往仍然准得出奇。这是"错误但有用"的经典范例。

预测时把条件独立代入 4.1.2 的贝叶斯规则，取对数把连乘变连加（避免大量小概率相乘下溢）：

ŷ = argmax_y [ log p(y) + Σ_{j=1}^{d} log p(x_j | y) ]

### 4.3.2 事件模型：多项式 / 伯努利 / 高斯

朴素贝叶斯按特征类型分几个"事件模型"，初学者常混淆，务必分清。**多项式朴素贝叶斯（Multinomial NB）**用于计数特征（文本里每个词出现的次数），p(x_j|y) 是词 j 在类 y 语料里的出现频率，CS229 讲义的垃圾邮件例子用的就是这个（multinomial event model / 词袋模型）。**伯努利朴素贝叶斯（Bernoulli NB）**用于二值特征（词出现/不出现，不计次数），会显式建模"词没出现"这一事件。**高斯朴素贝叶斯（Gaussian NB）**用于连续特征，假设每个特征在每类内服从一维高斯，p(x_j|y)=N(μ_{jy}, σ²_{jy})。

给初学者点明与 GDA 的关系，这是很好的对照：Gaussian NB 其实就是"**对角协方差**的 GDA"——它假设各特征条件独立，等价于协方差矩阵只有对角线、非对角为零。GDA（4.2）用满协方差矩阵能捕捉特征间相关，Gaussian NB 为了省参数把相关性一律设零。所以 4.2.3 的实证里 GaussianNB 精度略低于满协方差 GDA，正是这个对角近似的代价。

Multinomial NB 和 Bernoulli NB 在文本上会给出不同结果，因为前者计次数、后者只看有无且惩罚"缺席的词"。选哪个取决于特征是计数还是二值，不能混用。

### 4.3.3 训练与预测

训练朴素贝叶斯就是对每个类、每个特征做最大似然估计。以多项式模型（词袋）为例，词 k 在类 y 下的条件概率的 MLE 是"该类语料里词 k 的总次数 / 该类语料的总词数"：

p(x=k | y) = ( 类 y 中词 k 出现的总次数 ) / ( 类 y 的总词数 )

类先验 p(y) 则是该类文档数占比。预测时对每个类算 4.3.1 那个 log 域的分数，取最大。

给初学者强调两个工程要点。其一，**一定在对数域计算**：一封邮件几百个词的概率连乘，数值会小到浮点数下溢为 0，取对数变连加就没这个问题，这也是为什么实现里几乎都存 log p 而非 p。其二，训练全是"数数 + 除法"，没有迭代优化，所以朴素贝叶斯训练极快、是很多文本任务的强基线（baseline）。

### 4.3.4 为什么"错误的独立假设"仍然好用

朴素贝叶斯的条件独立假设几乎总不成立，但它在文本分类等任务上长期是强基线，原因值得初学者理解。分类只看 argmax——只要正确类的分数**排在最前**就判对了，哪怕算出来的概率值本身很离谱。独立假设会让概率估计失真（往往过度自信、把后验推到接近 0 或 1），但通常**不改变谁排第一**，所以分类精度不受太大影响，只是输出的"概率"不可当真（需要校准，见大主题12 的概率校准）。

朴素贝叶斯是好的**分类器**、差的**概率估计器**。要判类，它又快又准；要一个可信的概率数值（比如风控里的"违约概率"），它常常过度自信、需要后处理校准。把这两件事分开看，就不会被"假设明明是错的怎么还准"困住。

## 4.4 拉普拉斯平滑

### 4.4.1 零频问题

朴素贝叶斯直接用 MLE 估 p(x_j|y) 会踩一个致命坑：**零频问题（zero-frequency problem）**。如果某个词在训练集的某个类里**一次都没出现过**，它的 MLE 条件概率就是 0。而预测时（4.3.1）是把各词的条件概率连乘，只要有**一个**因子是 0，整类的似然就被拉成 0——哪怕这封邮件的其他所有词都强烈指向该类，一个训练时没见过的词就能一票否决。

训练语料里"正常邮件"从没出现过"Nurse"这个词，于是 p("Nurse"|正常)=0。来了一封明显正常、只是碰巧包含"Nurse"的邮件，模型算 p(正常|邮件) 时因为乘了个 0，直接判定它绝不可能是正常邮件。问题的本质是：**训练时没见过 ≠ 不可能发生**，MLE 把"没观测到"武断地等同于"概率为零"，泛化到新数据就崩了。

### 4.4.2 加性（拉普拉斯）平滑公式

修法是**拉普拉斯平滑（Laplace smoothing）**，又叫加性平滑（additive smoothing）：给每个计数都**加上一个小的正数**，让任何事件都不至于是零概率。对多项式模型（词表大小 V、类 y 中词 k 的计数 count(k,y)、类 y 总词数 N_y），加 α 后的估计是：

p(x=k | y) = ( count(k, y) + α ) / ( N_y + α·V )

标准的**拉普拉斯平滑取 α=1**（每个词的计数都假装先见过一次）；分母加 α·V 是为了让 V 个词的概率仍然加总为 1（每个词在分子多算 α，V 个词共多算 α·V，分母要补上）。0<α<1 的一般情形称为 **Lidstone 平滑**。

给初学者点明分母那一项为什么是 α·V 而不是别的：概率必须归一化，Σ_k p(x=k|y) = 1。分子对每个 k 都加了 α，V 个 k 累计给分子加了 α·V，为保持总和为 1，分母也必须加同样的 α·V。漏掉这一项是初学者手写朴素贝叶斯最常见的 bug，会让"概率"加起来不等于 1。平滑后，从没出现的词概率是 α/(N_y+α·V)——一个很小但非零的数，兜住了零频。

### 4.4.3 贝叶斯解释与 sklearn 默认

拉普拉斯平滑不只是工程补丁，它有干净的贝叶斯解释：给多项式参数放一个**狄利克雷先验（Dirichlet prior）**，则加性平滑正是该先验下的**最大后验（MAP）**或后验期望估计，α 是先验的伪计数（pseudo-count）。所以"加 1"等价于"先验地假设每个词都先见过 1 次"，α 越大先验越强、估计越被拉向均匀分布；α→0 退回未平滑的 MLE。

平滑不是拍脑袋，而是"用先验知识兜住数据没覆盖到的角落"，α 控制相信数据还是相信先验的天平。α 太小仍可能被稀有词主导，太大则把所有词概率抹平、丢失区分度，需按验证集调。

scikit-learn 的 `MultinomialNB`、`BernoulliNB` 用参数 `alpha` 控制加性平滑，**默认 `alpha=1.0`**（即标准拉普拉斯平滑）；`GaussianNB` 不用 alpha，而用 `var_smoothing`（默认 `1e-9`）给每个特征方差加一个极小值以防除零，机制不同、勿混淆（⚙演进快·锚版本 sklearn 1.9.0）。

本机实证坐实（`基线 Py3.11.15/np2.4.6/sklearn1.9.0 @2026-07-30`）：`MultinomialNB()` 默认 `alpha=1.0`；`GaussianNB()` 默认 `var_smoothing=1e-9`。用一个 4 文档、词表 V=3 的玩具语料，手算某类 [count+1]/[总数+1·3] 得条件概率 [0.1111, 0.5556, 0.3333]，与 sklearn `exp(feature_log_prob_)` 逐位一致——公式与实现对齐。
