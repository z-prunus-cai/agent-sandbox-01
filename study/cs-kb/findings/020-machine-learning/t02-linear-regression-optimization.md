## 2.1 最小二乘与几何投影

### 2.1.1 最小二乘目标：为什么是平方

线性回归假设目标是特征的线性函数，训练就是找一组系数 β 使预测尽量接近真实标签。"尽量接近"用**残差平方和**（residual sum of squares, RSS）来度量：

RSS(β) = Σᵢ (yᵢ − xᵢᵀβ)²

写成矩阵形式（X 是 n×(d+1) 设计矩阵，每行一个样本、第一列常为 1 对应截距；y 是 n 维标签向量）：

RSS(β) = ‖y − Xβ‖²

最小二乘（ordinary least squares, OLS）就是求使这个 RSS 最小的 β。

为什么偏偏用平方，而不是绝对值 |yᵢ − xᵢᵀβ| 或别的？给初学者三条并列的理由，任何一条单独都不足以"钦定"平方，但合起来解释了它的统治地位。第一，**可导且处处光滑**：平方函数是处处可导的，最小化时能直接令梯度为零解出闭式解；绝对值在 0 处不可导，优化要麻烦得多。第二，**凸且唯一极小**：RSS 是 β 的二次凸函数，碗状、只有一个全局最小，不存在"卡在局部极小"的问题（这点 2.3 会再用到）。第三，**概率含义干净**：2.4 会证明，平方误差最小化恰好等价于"假设噪声服从高斯分布"时的最大似然估计——这给了平方误差一个统计学上的正当性。

一个初学者常见的误解要在这里澄清：**平方误差对离群点（outlier）非常敏感**。因为误差被平方，一个偏差 10 的点贡献 100，是偏差 1 的点（贡献 1）的一百倍，最优解会被少数极端点强烈拉扯。如果数据有重尾噪声或离群点，绝对值损失（对应中位数回归 / L1 回归）往往更稳健。选平方是因为它在"高斯噪声、无严重离群"的常见假设下最优且最方便，不是因为它在所有场景都最好。

### 2.1.2 几何视角：把 y 投影到列空间

最小二乘有一个极其干净的几何解释：**预测向量 Xβ̂ 是把目标向量 y 正交投影到 X 的列空间（column space）上的结果。**

X 的列空间是所有形如 Xβ 的向量构成的子空间——也就是"用现有特征线性组合能表达出的全部预测"。y 一般不在这个子空间里（否则误差为零、完美拟合）。我们要在这个子空间里找一个离 y 最近（欧氏距离最小）的向量，那就是 y 到子空间的**正交投影** ŷ = Xβ̂。

欧氏空间里"子空间上离某点最近的点"就是垂足，这是几何常识，不需要任何微积分。而"垂足"意味着**残差向量与整个列空间垂直**：

Xᵀ(y − Xβ̂) = 0

想象你站在房间里（y 是你的位置），要在地板（列空间这个平面）上找一个离你最近的点。答案是你正下方地板上那一点（垂足），而"你到那一点的连线"必然**垂直于地板**——不可能斜着还最短。这条"残差垂直于列空间"就是最小二乘的几何本质，也是下一节正规方程的直接来源。

要强调"正交"是**相对列空间**而非相对某一个特征轴：残差与 X 的每一列都正交，等价地与列空间里任何方向都正交。这解释了为什么带截距列（全 1 列）时，残差之和恒为零——残差要和全 1 列正交，内积为零就是残差求和为零。

### 2.1.3 正规方程的几何推导

把 2.1.2 的正交条件 Xᵀ(y − Xβ̂) = 0 展开，就直接得到**正规方程**（normal equations）：

XᵀXβ̂ = Xᵀy

"normal"在这里正是"正交/法向"的意思（residual 与列空间正交），不是"正常"。这条方程可以完全不用微积分、纯靠几何投影得到；也可以用微积分对 RSS 求梯度令其为零得到同一条式子——两条路殊途同归，正是"几何=优化"的第一处印证。

从微积分路径看，RSS(β) = ‖y − Xβ‖² 对 β 求梯度：

∇RSS(β) = −2Xᵀ(y − Xβ)

令其为零，去掉常数 −2，就是 Xᵀ(y − Xβ) = 0，即 XᵀXβ = Xᵀy，与几何路径完全一致。

**最小二乘的最优解由一个线性方程组（正规方程）刻画**，它同时是"残差垂直于列空间"（几何）和"梯度为零"（微积分）这同一件事的两种说法。至于这个方程组解不解得出、解稳不稳，是 2.2 的主题。

## 2.2 正规方程闭式解

### 2.2.1 闭式解公式与可解条件

当 XᵀX 可逆时，正规方程 XᵀXβ̂ = Xᵀy 两边左乘 (XᵀX)⁻¹，得到最小二乘的**闭式解**（closed-form solution）：

β̂ = (XᵀX)⁻¹Xᵀy

这是一步到位、不需要迭代的解析解——给定数据直接算出最优系数。

XᵀX 可逆的条件是 **X 列满秩**，即各特征列线性无关、且样本数 n ≥ 特征数（含截距）d+1。给初学者拆解"为什么需要列满秩"：如果两个特征完全线性相关（比如"身高厘米"和"身高米"两列），列空间没变大，但有无穷多组 β 给出同一个投影 ŷ——解不唯一，XᵀX 奇异（不可逆）。同理若 n < d+1（样本比特征还少，欠定），XᵀX 必奇异。这两种情况下正规方程仍有解（投影 ŷ 唯一存在），只是 β 不唯一，须改用伪逆或加正则化（2.5 与大主题6）。

**真正计算时不要显式求逆再相乘**。数值上 `np.linalg.solve(X.T@X, X.T@y)` 或基于 QR / SVD 分解的解法（scikit-learn `LinearRegression` 内部用 SVD/最小二乘例程 `scipy.linalg.lstsq`，⚙演进快·锚 scikit-learn，具体后端随版本，标「待核具体例程」）比 `inv(X.T@X)@X.T@y` 更稳更准。公式里写 (XᵀX)⁻¹ 是为了表达简洁，不是叫你真去求那个逆。

### 2.2.2 条件数隐患：闭式解为何会"不稳"

闭式解 β̂ = (XᵀX)⁻¹Xᵀy 的数值稳定性由 **XᵀX 的条件数**（condition number）决定。条件数大致衡量"输入的小扰动会被放大多少倍传到解上"：

cond(XᵀX) = λ_max / λ_min　（XᵀX 最大与最小特征值之比）

条件数越大，矩阵越"病态"（ill-conditioned），解对数据噪声/舍入误差越敏感，算出的 β 可能面目全非。

隐患的根源有二，都会推高条件数。第一是**特征共线**（2.5 详述）：两列近似线性相关时 λ_min 趋近 0，条件数暴涨。第二是**特征量纲悬殊**：一列取值 0~1、另一列取值 0~10000，XᵀX 各方向尺度差万倍，条件数天然很大。给初学者一个关键的放大关系记法：用正规方程时误差按条件数放大，而条件数还被"平方"了——因为你算的是 XᵀX 而不是 X，cond(XᵀX) ≈ cond(X)²。这正是数值分析上"直接解正规方程不如对 X 做 QR/SVD"的原因：后者只吃 cond(X) 一次，不把病态平方。

本机实证（numpy 2.4.6 @2026-07-30）直观呈现这一点：良态数据 cond(XᵀX)≈1.29；把一列改成与另一列近似相等（近共线）后，cond(XᵀX) 跳到约 5.6×10⁶（放大约四百万倍）。这解释了为什么"公式对、但结果离谱"——不是公式错，是矩阵病态把噪声放大了。缓解手段：去除/合并共线特征、标准化量纲（2.5）、或加 L2 岭回归（给 XᵀX 加 λI 抬高 λ_min，大主题6）。

### 2.2.3 闭式解 vs 迭代解：何时用哪个

闭式解一步算出精确解，无需调学习率、无需迭代，小规模问题（特征数 d 不大）是首选。但它需要构造并"求逆" d×d 的 XᵀX，这一步的计算量大致是 O(nd² + d³)：n 个样本填 XᵀX 是 nd²，解 d×d 方程组是 d³。

当特征维度 d 很大（比如上万、上百万）时，d³ 项使闭式解不可行——这时改用**梯度下降家族**（2.3）迭代逼近，每步只做矩阵-向量乘 O(nd)（或 SGD 的 O(d)），不碰 d³。给初学者一句选择准则：**特征少、样本可放进内存、要精确解 → 正规方程；特征极多、或数据大到只能流式处理、能接受近似 → 梯度下降/SGD。** 二者在凸的平方损失上收敛到同一个最优 β（下节实证），差别只在计算代价与数值路径。

## 2.3 梯度下降 / SGD / LMS

### 2.3.1 梯度下降：沿坡下滑找碗底

梯度下降（gradient descent, GD）是一种迭代优化法：从一个初始 β 出发，反复朝**负梯度方向**（下坡最陡方向）走一小步，逐步逼近使损失最小的 β。对平方损失，更新规则是：

β ← β − α · ∇RSS(β)

其中 α 是**学习率**（learning rate，步长）。用 MSE（均方误差，RSS 除以 n）时梯度写作：

∇ = (1/n) Xᵀ(Xβ − y)

之所以能保证走到全局最优，是因为 2.1.1 说过平方损失是**凸函数**——整个损失面是一个碗，没有别的坑，沿坡下滑必然到唯一的碗底。给初学者的画面：蒙眼站在碗形山谷里，每一步都朝脚下最陡的下坡方向迈一小步，早晚到谷底。梯度就是"最陡上坡方向"，取负号就朝下坡走。

学习率 α 是唯一需要调的关键旋钮，且极其敏感。太小 → 步子太碎、收敛极慢；太大 → 一步跨过碗底、在两壁之间反复横跳甚至发散（损失越来越大）。给初学者两个易错点：一是 α 没有万能默认值，取决于数据尺度（这正是 2.5 特征缩放重要的原因之一——缩放后碗更"圆"，同一个 α 更好用）；二是判断收敛要看损失是否稳定不再下降，而不是跑固定步数就停。

### 2.3.2 批量 / 随机 / 小批量：三种吃数据的方式

按每次更新用多少样本算梯度，梯度下降分三类。

**批量梯度下降**（batch GD）：每步用**全部 n 个样本**算精确梯度再更新。梯度准、方向稳，但每步要扫全量数据，大数据集下每步很贵。

**随机梯度下降**（stochastic gradient descent, SGD）：每步只用**一个随机样本**算梯度就更新。单样本梯度是全量梯度的无偏估计但噪声大，路径抖动、"醉汉下山"，但每步极便宜、更新极频繁，大数据下总体往往更快接近最优；噪声还有跳出（非凸问题的）差区域的副作用。SGD 通常配合**逐步减小的学习率**以最终稳定。

**小批量梯度下降**（mini-batch GD）：每步用一小批（如 32、128 个）样本，是前两者的折中——梯度比 SGD 稳、又能利用向量化/GPU 并行，是深度学习的事实标准。

给初学者一句辨析要点，也是一处**术语陷阱**：严格定义里 SGD=单样本，但今天很多库（包括深度学习框架）口语和 API 里把 mini-batch 也笼统叫"SGD"（如 scikit-learn 的 `SGDRegressor`、PyTorch 的 `optim.SGD` 默认按你喂的批大小工作）。读到"SGD"要看上下文判断是严格单样本还是泛指小批量。

### 2.3.3 LMS / Widrow-Hoff 更新规则

把 SGD 用到线性回归平方损失上，对单个样本 (x, y) 求梯度并更新，得到的具体规则就是 **LMS（least mean squares）算法**，也叫 **Widrow-Hoff 学习规则**（CS229 讲义正是以此名引入）：

βⱼ ← βⱼ + α (y − xᵀβ) xⱼ　（对每个分量 j）

写成向量形式：

β ← β + α (y − xᵀβ) x

给初学者拆这条规则的直觉，它非常"讲道理"。括号里的 (y − xᵀβ) 是**当前预测的误差**（真实值减预测值）。更新量正比于误差 × 该特征值：预测偏得越多，改得越狠；预测已经准了（误差≈0），几乎不动。误差的符号还决定往哪个方向修——预测偏低（y > xᵀβ，误差正）就把权重往上调。这条"按误差比例修正"的规则不仅是线性回归的 SGD，更是感知机、乃至神经网络反向传播的思想原型（大主题8 会看到它的推广）。

这里是 `+α(误差)`，因为写成了"真实−预测"；若写成"预测−真实"的梯度形式则是 `−α`。两种写法等价，只是误差方向定义不同，初学者对号入座别被正负号绊倒。

本机实证（numpy 2.4.6 @2026-07-30）坐实 GD 与闭式解一致：同一份 n=200/d=3 数据，批量 GD（α=0.01，2 万步）得到的系数与正规方程闭式解逐分量之差最大仅 2.6×10⁻¹⁴（机器精度级），确认二者收敛到同一个 β——凸损失下"迭代"与"闭式"殊途同归。

## 2.4 概率解释（高斯噪声下 MLE 等价最小二乘）

### 2.4.1 高斯噪声模型与似然

最小二乘还有第三副眼镜——概率视角。假设真实标签由线性模型加上**独立同分布的高斯噪声**生成：

yᵢ = xᵢᵀβ + εᵢ，　εᵢ ~ N(0, σ²) 独立同分布

那么在给定 xᵢ 和 β 下，yᵢ 服从以 xᵢᵀβ 为均值、σ² 为方差的高斯分布。整个数据集的**似然**（likelihood，参数 β 下观测到这批 y 的概率密度）是各样本密度之积：

L(β) = Πᵢ (1/√(2πσ²)) exp( −(yᵢ − xᵢᵀβ)² / (2σ²) )

最大似然估计（MLE）就是找使这个 L(β) 最大的 β——即"最可能生成了我们观测到的数据"的那组参数。

给初学者拆一下这个模型在说什么。它假设：真实世界确实是线性的，我们看到的点之所以不完美落在超平面上，纯粹是因为叠加了对称、无偏、方差恒定的随机噪声。这是个**建模假设**，不是事实——但它把"最小二乘"从一个看起来随意的"平方凑数"提升为有统计学根据的最优估计。

### 2.4.2 取对数：MLE 恰好化为最小二乘

直接最大化连乘的 L(β) 不方便，取对数变成连加（对数是单调增，最大化 log L 与最大化 L 同解）。对数似然：

log L(β) = −(n/2) log(2πσ²) − (1/(2σ²)) Σᵢ (yᵢ − xᵢᵀβ)²

关于 β，第一项是常数，第二项前面是负系数。所以**最大化 log L(β) 等价于最小化 Σᵢ(yᵢ − xᵢᵀβ)²**——正是残差平方和 RSS：

argmax_β log L(β) = argmin_β Σᵢ (yᵢ − xᵢᵀβ)²

**在高斯噪声假设下，最大似然估计 = 最小二乘。**

给初学者两个关键领悟。其一，平方误差不是拍脑袋选的——它是"高斯噪声"这个假设的数学后果。反过来说，如果噪声不是高斯而是别的分布，MLE 就不再是最小二乘（例如拉普拉斯噪声对应 L1/绝对值损失，这解释了 2.1.1 说的"重尾用绝对值更稳健"）。其二，注意 σ²（噪声方差）在求 β 时被约掉了——**最优 β 与 σ² 无关**，σ² 只影响不确定性度量，不影响点估计。初学者常担心"不知道 σ² 怎么办"，答案是估 β 时根本不需要它。

至此三副眼镜合流——几何上是投影（2.1）、优化上是凸函数极小（2.3）、概率上是高斯 MLE（2.4），三者指向同一个 β̂。这种"多视角同解"正是线性回归成为机器学习第一课的原因：它是理解后续所有模型（逻辑回归的 MLE、GLM、乃至神经网络损失设计）的模板。

## 2.5 特征缩放与共线性

### 2.5.1 特征缩放（标准化）为何加速收敛

特征缩放指把各特征调整到可比的量纲，最常见的是**标准化**（standardization）：减均值、除标准差，使每列均值 0、标准差 1：

x'ⱼ = (xⱼ − μⱼ) / σⱼ

对梯度下降家族（2.3），缩放不改变最优解，但显著影响**收敛速度**。

直觉在于损失面的形状。若一个特征取值 0~1、另一个 0~10000，平方损失的等高线是极度**拉长的椭圆**（一个方向陡、一个方向平）。梯度下降在这种"狭长山谷"里会来回横跳、走"之"字形，收敛极慢；而且陡方向要求小学习率、平方向想要大学习率，单一 α 难两全。标准化后各方向尺度一致，等高线接近**圆形**，梯度直指碗底，同一个学习率各方向都合适，收敛快得多。

给初学者两个要点。其一，**闭式解（正规方程）不缩放也得同一个解**（数学上等价），缩放主要是帮迭代法（GD/SGD）和数值稳定，以及让正则化（岭/Lasso）对各特征公平惩罚——所以基于距离/梯度/正则的方法（含 SVM、KNN、神经网络）几乎都要缩放，而纯闭式 OLS 可不缩放。其二，一处**数据泄漏陷阱**：标准化用的均值/标准差必须**只从训练集**算，再用同一组参数变换验证/测试集，绝不能在划分前对全量数据求统计量（scikit-learn 用 `StandardScaler` 在训练集 `fit`、对测试集只 `transform`，或放进 `Pipeline`）——这点呼应大主题1的数据划分纪律与大主题12的评估纪律。

### 2.5.2 共线性对解的影响

**共线性**（collinearity，多个特征时称 multicollinearity）指两个或多个特征近似线性相关。它对最小二乘的危害在 2.2.2 已从条件数角度点过，这里从"解"的角度补齐。

后果是**系数估计不稳、方差巨大、可解释性崩塌**。当两列高度相关，模型无法区分该把权重分给谁，可以给 A 一个很大的正系数、给 B 一个很大的负系数而预测几乎不变——系数变得对数据的微小扰动极其敏感（换一个训练子集，系数可能翻符号），置信区间极宽。但要注意：**共线性主要伤害"系数的解释与稳定"，对整体预测精度（若新数据保持同样的相关结构）伤害相对小**——这是初学者易混的一点：模型还能预测，但"每个特征贡献多少"这件事已不可信。

诊断与缓解。诊断常用**方差膨胀因子**（VIF, variance inflation factor）：把某特征对其余特征回归，看它能被多大程度解释，VIF 越大共线越重（ISL §3.3.3 给出 VIF；常用经验阈值如 5 或 10 提示问题，属经验值非硬标准，标「经验阈值·非定论」）。缓解手段：删除/合并冗余特征、用领域知识组合特征、做 PCA 降维（大主题10）、或加 **L2 岭回归**——岭把 XᵀX 变成 XᵀX+λI，抬高最小特征值、压低条件数，直接治病态（详见大主题6，本报告只作指路）。

本机实证（numpy 2.4.6 @2026-07-30）：造两列量纲差万倍的数据，原始 cond(XᵀX)≈1.15×10⁶，标准化后降到≈1.05——标准化把病态的量纲失衡几乎完全消除，直观印证 2.5.1 "等高线变圆"。共线性实证见 2.2.2（近共线使条件数从 1.29 跳到 5.6×10⁶）。
