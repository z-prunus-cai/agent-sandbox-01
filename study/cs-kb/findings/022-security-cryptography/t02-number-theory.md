## 2.1 模运算与同余

### 2.1.1 同余关系与同余类

设 n 为正整数（模数），整数 a、b 若满足 n 整除 a − b，就说 a 与 b 模 n 同余，记作

a ≡ b (mod n)

等价说法是 a 与 b 除以 n 得到相同的余数，或存在整数 k 使 a = b + k·n。同余把全体整数切成 n 个互不相交的**同余类**（剩余类），每类里的元素彼此同余；把这 n 个类作为元素、配上模 n 的加法与乘法，得到的集合记作

Z_n = {0, 1, 2, …, n−1}

它就是密码学里反复出现的"钟面"。

初学者最容易把两种写法混掉：`a ≡ b (mod n)` 是一个对称的**关系**（a、b 地位平等，如 17 ≡ 2 (mod 5)），要么真要么假；而 `a mod n` 是一个**具体的数**（运算结果，一定落在 0 到 n−1 之间，如 17 mod 5 = 2）。二者的桥梁是：`a ≡ b (mod n)` 成立当且仅当 `a mod n == b mod n`。用钟面直觉最好记——时钟是模 12 的世界，15 点和 3 点是"同一个位置"，因为 15 − 3 = 12 被 12 整除。

另一处常见困惑是负数取模。数学约定余数必须非负，所以 −7 mod 5 = 3（因为 −7 = 5·(−2) + 3）。Python 的 `%` 恰好遵守这个约定（`(-7) % 5 == 3`），但 C/Java 的 `%` 对负数会给 −2（截断取余）。这是"规范 vs 实现"的差异，写密码代码时务必留意。

### 2.1.2 模加、模乘与"可先取模再算"

Z_n 上的加法和乘法定义为普通加乘之后再取模：

(a + b) mod n

(a · b) mod n

同余关系对加、减、乘都"兼容"：若 a ≡ a′ 且 b ≡ b′ (mod n)，则 a + b ≡ a′ + b′ 且 a·b ≡ a′·b′ (mod n)。由此得到实用推论

(a · b) mod n = ((a mod n) · (b mod n)) mod n

这条性质是模算术好用的根本原因：算大数的模乘、模幂时，可以每一步都把中间结果"绕回"到 0…n−1，绝不让数字爆炸。快速幂（平方-乘法）能在几十步内算出 g^x mod n（x 有几百比特）就全靠它。

一个关键的反直觉陷阱：模算术里**加减乘随便用，除法不能随便做**。普通整数里 6 = 2·3 可两边约掉 2，但 `a·c ≡ b·c (mod n)` 一般推不出 a ≡ b (mod n)。反例：2·3 ≡ 2·0 (mod 6)（都 ≡ 0），但 3 ≢ 0 (mod 6)。只有当 c 与 n 互素时才能安全约掉 c——这正是下面要引出"模逆元"来替代除法的原因。

### 2.1.3 模逆存在条件（gcd = 1）

在 Z_n 中，元素 a 的**乘法逆元**是满足下式的 a^{-1}：

a · a^{-1} ≡ 1 (mod n)

a 存在模逆元，当且仅当 a 与 n 互素，即

gcd(a, n) = 1

"除以 a"在 Z_n 中就被翻译成"乘以 a^{-1}"，前提是逆元存在。

为什么条件恰好是 gcd = 1？由贝祖等式（见 2.4），gcd(a, n) = 1 意味着存在整数 x、y 使 a·x + n·y = 1，两边模 n 得 a·x ≡ 1 (mod n)，这个 x 就是 a^{-1}。反过来若 gcd(a, n) = d > 1，则 a 乘任何数都是 d 的倍数（模 n 后仍是 d 的倍数），永远得不到 1，逆元不存在。举例：在 Z_6 中 3 没有逆元（gcd(3,6)=3），因为 3·0,3·1,…,3·5 只会得到 0 或 3，凑不出 1；而在 Z_7 中每个非零元都有逆元，因为 7 是素数、与 1…6 全互素。这也解释了为什么密码学偏爱素数模数 p：Z_p 里除 0 外人人可逆，运算最"干净"。

## 2.2 群、环、域基础

### 2.2.1 群、环、域三级结构

**群**是一个集合 G 配一个二元运算 ·，满足封闭性、结合律、有单位元 e、每个元素有逆元四条公理；若还满足交换律则称**交换群（阿贝尔群）**。**环**在群之上再加一个乘法，形成"加法成交换群、乘法有结合律、并满足分配律"的双运算结构。**域**是一个环，其非零元在乘法下也构成交换群——直白说，域里加减乘除四则运算都能做（除数非零）。

对本课最重要的三个具体对象：Z_n 在模加下是交换群；Z_n 在模加模乘下是交换环；当且仅当 p 是素数时，Z_p 是一个**有限域**（记作 GF(p) 或 F_p），因为此时每个非零元都可逆（见 2.1.3）。

初学者不必被公理吓到，抓住"群 = 有一个能做且能撤销的运算的集合"这个直觉即可。能"撤销"就是有逆元——这正是密码学关心群的原因：加密要能解密。域的意义在于它是"最完整"的算术系统，AES 的字节运算就发生在有限域 GF(2^8) 上，RSA/DH 则活在 Z_n 或 Z_p 的乘法结构里。

### 2.2.2 乘法群 Z_n^* 与其阶

Z_n 中所有与 n 互素的元素，在模乘下构成一个交换群，记作

Z_n^* = { a ∈ Z_n : gcd(a, n) = 1 }

它的元素个数（群的**阶**）恰好等于欧拉函数 φ(n)（见 2.3）：

|Z_n^*| = φ(n)

当 n = p 为素数时，Z_p^* = {1, 2, …, p−1}，阶为 p − 1。

为什么只收互素元素？因为群要求每个元素可逆，而 2.1.3 已证只有互素元素才有模逆元。把不可逆的元素踢掉，剩下的恰好凑成一个封闭的乘法群。例如 Z_10^* = {1, 3, 7, 9}，阶为 φ(10) = 4；这四个数两两模乘仍落在这四个数里，且各有逆元（如 3·7 = 21 ≡ 1，故 3 与 7 互逆）。这个群是 RSA、DH 等方案的"运算场地"，理解它的大小与结构是后面一切的基础。

### 2.2.3 元素的阶、循环群与生成元

群中元素 g 的**阶**是使 g^k = e（单位元）成立的最小正整数 k。若群 G 中存在某个元素 g，其阶等于整个群的阶 |G|，即 g 的幂能跑遍 G 的所有元素，就称 G 是**循环群**，g 称为**生成元**：

G = { g^0, g^1, g^2, …, g^{|G|−1} }

一个基本事实：Z_p^*（p 为素数）总是循环群，它的生成元又叫模 p 的**原根**（primitive root）。

生成元的直觉是"一把钥匙转遍所有门"：从 g 出发不断自乘，就能遍历整个群一次不重复。以 Z_7^* 为例，取 g = 3：3^1=3, 3^2=2, 3^3=6, 3^4=4, 3^5=5, 3^6=1，恰好把 {1,…,6} 全跑遍，所以 3 是 Z_7^* 的生成元（原根）。而 g = 2 只能生成 {1,2,4}（2^3 = 1 就绕回去了），阶为 3，不是生成元。DH 密钥交换和 ElGamal 都要求先选一个大素数 p 和一个生成元 g，把明文/密钥藏进 g 的指数里——这就是离散对数问题（2.7）的舞台。

### 2.2.4 拉格朗日定理

**拉格朗日定理**：有限群 G 中任意子群 H 的阶必整除 G 的阶。

|H| 整除 |G|

一个对密码学极其有用的直接推论：群中任意元素的阶都整除群的阶，因此对任意 a ∈ G 有

a^{|G|} = e

在 Z_n^* 上把 |G| = φ(n) 代入，这条推论立刻给出欧拉定理（见 2.3）。

初学者可以这样体会：子群就像"大集合里一个自成体系的小圈子"，拉格朗日说小圈子的规模必须能整除大集合的规模，不能是任意大小——这是有限群里最强的"计数约束"。它的威力在于把"元素自乘到单位元要多少步"这个看似难算的问题，一下子锁死在 |G| 的因子范围内。欧拉定理、费马小定理本质上都是它的特例，而这两条又是 RSA 正确性的命根子（解密指数要满足 e·d ≡ 1 (mod φ(n)) 才能让加解密互为逆运算）。

## 2.3 欧拉定理与费马小定理

### 2.3.1 欧拉函数 φ(n)

**欧拉函数** φ(n) 定义为 1 到 n 之间与 n 互素的整数个数，也就是乘法群 Z_n^* 的阶。它的计算公式为：对素数 p 及 k ≥ 1，

φ(p) = p − 1

φ(p^k) = p^k − p^{k−1} = p^{k−1}(p − 1)

且 φ 在互素因子上**积性**（gcd(m, n) = 1 时）：

φ(m · n) = φ(m) · φ(n)

对 RSA 最关键的特例：n = p·q（p、q 为不同素数）时

φ(n) = (p − 1)(q − 1)

直觉上 φ(n) 数的是"钟面上有多少个可逆的位置"。素数 p 的钟面除了 0 全可逆，故 φ(p) = p − 1。积性来自中国剩余定理（2.5）——Z_{mn}^* 可以拆成 Z_m^* 与 Z_n^* 的"并联"，可逆位置数相乘。RSA 里之所以要保密 p、q，正因为知道 p、q 就能算出 φ(n)，进而算出解密指数 d；而只给攻击者 n，想求 φ(n) 本质上等价于分解 n（2.7），这就是 RSA 的安全支点。用 sympy 验证 φ(10) = 4（对应 Z_10^* = {1,3,7,9}），与 2.2.2 一致。

### 2.3.2 欧拉定理

**欧拉定理**：若 gcd(a, n) = 1，则

a^{φ(n)} ≡ 1 (mod n)

这是 2.2.4 拉格朗日推论 a^{|G|} = e 在群 G = Z_n^* 上的直接实例（此处 |G| = φ(n)，单位元 e = 1）。

它的密码学意义是给出了"指数约简"的规则：在 Z_n^* 里，a 的幂是**周期性**的，周期整除 φ(n)。因此计算 a^x mod n 时，可以先把指数 x 对 φ(n) 取模，即 a^x ≡ a^{x mod φ(n)} (mod n)（要求 gcd(a,n)=1）。RSA 的正确性正是这样推的：取 e·d ≡ 1 (mod φ(n))，即 e·d = 1 + k·φ(n)，于是解密时 (m^e)^d = m^{1+kφ(n)} = m·(m^{φ(n)})^k ≡ m·1^k = m (mod n)，加解密恰好互相抵消。

### 2.3.3 费马小定理

**费马小定理**是欧拉定理在素数模上的特例。若 p 为素数且 p 不整除 a，则

a^{p−1} ≡ 1 (mod p)

等价地，对任意整数 a（包括 p 整除 a 的情形）有

a^p ≡ a (mod p)

因为素数 p 时 φ(p) = p − 1，把它代入欧拉定理即得第一式；第二式把 a 是 p 倍数的退化情况也一并覆盖（两边都 ≡ 0）。

费马小定理是很多算法的起点。它给出一种廉价的**素性筛查**（费马测试）：随机取 a，若 a^{n−1} ≢ 1 (mod n) 则 n 一定是合数；但反过来通过测试不能断定 n 是素数——存在 Carmichael 数（如 561）对所有与之互素的 a 都"骗过"费马测试，这正是需要更强的 Miller–Rabin（2.6）的原因。它也用于求逆：素数模下 a^{-1} ≡ a^{p−2} (mod p)（因为 a·a^{p−2} = a^{p−1} ≡ 1）。本机验证 2^{7−1} mod 7 = 1、3^{φ(10)} mod 10 = 3^4 mod 10 = 1，均与定理吻合。

## 2.4 扩展欧几里得与求逆

### 2.4.1 最大公约数与欧几里得算法

两个整数的**最大公约数** gcd(a, b) 是能同时整除二者的最大正整数。**欧几里得算法**基于一条恒等式反复取模求它：

gcd(a, b) = gcd(b, a mod b)，直到第二个参数变为 0

gcd(a, 0) = a

它的正确性来自"a 和 b 的公约数集合 = b 和 (a mod b) 的公约数集合"，每步把问题缩小，且余数严格递减，必在有限步内触底。它极快——步数是输入位数的线性级别（最坏情形出现在相邻斐波那契数）。

举个手算例子：gcd(240, 46)。240 mod 46 = 10，转成 gcd(46, 10)；46 mod 10 = 6，转成 gcd(10, 6)；10 mod 6 = 4，转成 gcd(6, 4)；6 mod 4 = 2，转成 gcd(4, 2)；4 mod 2 = 0，得 gcd = 2。整个过程只是不断"用小的去除大的、留余数"，是人类最古老的算法之一。

### 2.4.2 贝祖等式

**贝祖等式**：对任意整数 a、b（不全为 0），存在整数 x、y 使

a · x + b · y = gcd(a, b)

特别地，当 gcd(a, b) = 1 时存在 x、y 使 a·x + b·y = 1，这正是模逆元存在的代数根据（见 2.1.3）。

直觉上，贝祖说"gcd 是 a、b 所有整系数线性组合中最小的正数"——你用 a 和 b 加加减减能拼出的最小正整数，恰好就是它们的最大公约数。这条等式把"求 gcd"升级为"顺便求出组合系数 x、y"，而这对系数正是求模逆的钥匙：a·x ≡ 1 (mod b) 里的 x 就是 a 模 b 的逆元。

### 2.4.3 扩展欧几里得算法与模逆元

**扩展欧几里得算法**在跑欧几里得求 gcd 的同时，回带出贝祖系数 x、y。迭代版本步骤如下：

1. 初始化 (old_r, r) = (a, b)，(old_s, s) = (1, 0)，(old_t, t) = (0, 1)

2. 当 r ≠ 0 时，令商 q = old_r ÷ r（整除）

3. 同步更新三对：(old_r, r) ← (r, old_r − q·r)；(old_s, s) ← (s, old_s − q·s)；(old_t, t) ← (t, old_t − q·t)

4. 循环结束时 old_r = gcd(a, b)，且 old_s = x、old_t = y 满足 a·x + b·y = gcd(a, b)

求 a 模 n 的逆元时，对 (a, n) 跑此算法；若 old_r = gcd(a, n) = 1，则

a^{-1} ≡ old_s (mod n)

（取模保证结果落在 0…n−1；old_s 可能为负，加一个 n 即可。）

初学者最容易在"三对变量同步更新"处翻车——记住 s、t 两列跟着 r 列用**完全相同的公式**推进即可，它们只是把"当前余数是 a、b 的什么组合"这本账一路记下来。为什么求逆要它？因为若 a·x + n·y = 1，两边模 n 得 a·x ≡ 1 (mod n)，x 即为 a^{-1}。这是密码学最高频的原语之一：RSA 生成密钥要算 d = e^{-1} mod φ(n)，ECDSA 验签要算 nonce 的逆，等等。

本机纯 Python 实现并与 sympy 交叉验证（真实输出）：

    egcd(240,46) = (2, -9, 47)   校验 240*(-9)+46*47 = 2
    gcd(17,3120)=1  inv(17) mod 3120 = 2753   sympy.mod_inverse(17,3120) = 2753

第二行是经典 RSA 教科书例子（e = 17，φ(n) = 3120），扩展欧几里得算出的解密指数 d = 2753 与 sympy 完全一致。

#### 来源与时效（本小主题末集中列）

## 2.5 中国剩余定理(CRT)

### 2.5.1 CRT 陈述

**中国剩余定理**：设 n_1, n_2, …, n_k 两两互素，令 N = n_1·n_2·…·n_k，则同余方程组

x ≡ a_1 (mod n_1)

x ≡ a_2 (mod n_2)

⋯

x ≡ a_k (mod n_k)

在模 N 下有**唯一解**。等价地说，映射

x ↦ (x mod n_1, x mod n_2, …, x mod n_k)

是 Z_N 与乘积 Z_{n_1} × Z_{n_2} × ⋯ × Z_{n_k} 之间的一一对应（且保持加法与乘法结构，即环同构）。

直觉上 CRT 说"多个互素模数上的余数联合起来，恰好唯一确定一个大模数下的数"。像用几把不同刻度的尺子同时量一个物体：只要刻度两两互素，各自读数合起来就能无歧义地定位它，范围到 N 为止。这也是 2.3.1 里 φ 积性的来源——可逆位置在乘积结构里逐分量独立，故数目相乘。

### 2.5.2 两模数合并的构造

以两个互素模数为例（k = 2，n_1、n_2 互素，N = n_1·n_2），构造唯一解的步骤：

1. 用扩展欧几里得求 m_1、m_2 使 m_1·n_1 + m_2·n_2 = 1

2. 合并解为 x = (a_1·m_2·n_2 + a_2·m_1·n_1) mod N

验证：对第一个方程取模，n_1 整除含 n_1 的项，剩 a_1·m_2·n_2；而 m_2·n_2 = 1 − m_1·n_1 ≡ 1 (mod n_1)，故 x ≡ a_1 (mod n_1)；对称地 x ≡ a_2 (mod n_2)。

最小例子：x ≡ 2 (mod 3)、x ≡ 3 (mod 5)，解为 x = 8（8 mod 3 = 2，8 mod 5 = 3），在模 15 下唯一。多于两个模数时，可两两滚动合并，或用通用的 CRT 公式（每项配一个"在本模数上为 1、在其余模数上为 0"的基）。本机纯 Python 合并得 x = 8 (mod 15)，与 sympy `crt([3,5],[2,3]) = (8, 15)` 一致。

### 2.5.3 RSA 解密的 CRT 加速

RSA 私钥持有者知道 n = p·q 的分解，可用 CRT 把一次大模 n 的解密幂运算拆成两次小模幂并联，再合并：

1. 预计算 d_p = d mod (p − 1)，d_q = d mod (q − 1)，以及 q_inv = q^{-1} mod p

2. 解密时分别算 m_p = c^{d_p} mod p，m_q = c^{d_q} mod q

3. 合并（Garner 公式）：h = (q_inv · (m_p − m_q)) mod p，m = m_q + h·q

由于模幂的代价随模数位数超线性增长，把模数从 |n| 位降到约 |n|/2 位、算两次，实测约带来**4 倍左右**的解密加速（理论上模幂三次方级代价下 2·(1/2)^3 = 1/4）。这也是 RFC 8017（PKCS#1）在私钥里同时存 p、q、d_p、d_q、q_inv 的原因。

需要提醒初学者：CRT 加速虽好，却也引入了著名的**故障攻击**风险——若解密中途某一分支（比如算 m_p 时）发生硬件位翻转，攻击者拿到错误签名后可用 gcd 一步分解出 n。生产实现（如 OpenSSL）会在输出前做一次验证来防这类攻击。加速在这里是"知道分解 = 拥有捷径"的又一体现，与 2.7 的困难假设互为表里。

#### 来源与时效（本小主题末集中列）
- 一手锚点：Katz-Lindell 3rd ed. §9.1.5「The Chinese Remainder Theorem」（CRT 陈述、环同构 Z_N ≅ ∏ Z_{n_i}、RSA 解密加速讨论）。核实 2026-07-30。
- 交叉源：HAC 1996 §2.4.3「The Chinese remainder theorem」（Fact 2.120 CRT、Algorithm 2.121 Gauss/Garner 合并、§14.5 CRT-RSA 加速）。核实 2026-07-30。两源一致。
- 实证：本机纯 Python CRT 合并 x ≡ 2(3), x ≡ 3(5) → 8 (mod 15)，与 sympy `crt` 一致（见上）。
- 冲突项：无。CRT 加速倍数"约 4 倍"为理论量级估计（三次方模幂代价假设下），具体随实现与模幂算法而变，非确切常数。

## 2.6 素性测试

### 2.6.1 为什么需要概率素性测试

RSA、DH 等都需要随机生成几百甚至上千比特的大素数。素数在大整数附近仍相当稠密（由素数定理，约每 ln(N) 个数中有一个素数），所以"随机取一个奇数、判它是不是素数、不是就换"是可行的造素数流程——关键在于要有**又快又可靠的素性判定**。试除法对上千比特的数完全不可行，确定性多项式算法（AKS）太慢不实用，因此工程上普遍采用**概率素性测试**，其中 Miller–Rabin 是事实标准。

初学者要先接受一个观念转变：这里不追求"绝对证明是素数"，而是把"误判为素数"的概率压到可忽略（比如 2^{-128}）。这在密码学里完全够用——毕竟硬件出错、宇宙射线翻位的概率都比它大。费马测试（2.3.3）是最朴素的版本，但被 Carmichael 数（如 561、1105）整体击穿，故实际用更强的 Miller–Rabin。

### 2.6.2 Miller–Rabin 算法

给定待测奇数 n > 3，先把 n − 1 写成

n − 1 = 2^r · d，d 为奇数

对一个随机"证据" a ∈ [2, n−2] 做一轮测试：

1. 计算 x = a^d mod n

2. 若 x = 1 或 x = n − 1，本轮判"可能是素数"，通过

3. 否则重复至多 r − 1 次：x ← x^2 mod n；若某次 x = n − 1，本轮通过

4. 若循环走完都没出现 n − 1，则 n 一定是**合数**，直接判定

重复 k 轮（每轮换独立随机的 a）都通过，则 n 是合数的概率至多为

Pr[误判] ≤ 4^{−k}

其原理是：模素数 p 下 1 的平方根只有 ±1，而合数会出现"非平凡平方根"。算法本质是沿 a^d, a^{2d}, …, a^{n−1} 这条平方链去抓这种非平凡平方根——抓到就证明 n 是合数。相比费马测试，Miller–Rabin 对每个合数（包括 Carmichael 数）至少有 3/4 的证据 a 能揭穿它，所以 k 轮独立测试把漏网概率压到 4^{−k}。

本机纯 Python 实现并与 sympy 交叉验证（真实输出）：

    MR(561) = False    sympy.isprime = False     （561 是 Carmichael 数，费马测试会误判、MR 正确识别为合数）
    MR(2305843009213693951) = True   sympy.isprime = True   （梅森素数 2^61−1）
    MR(104729) = True  sympy.isprime = True      （第 10000 个素数）
    MR(100) = False    sympy.isprime = False

关键提醒：4^{−k} 是**最坏情形上界**，对随机生成的候选数实际错误率远低于此。另需分清两种误判方向——Miller–Rabin 判"合数"永远正确（一旦返回合数就是确定的），只有判"可能素数"才带上述概率；这类算法叫"无错误的合数判定 / 概率的素数判定"。工程实践中还会先用小素数试除快速筛掉多数合数候选，再跑若干轮 MR。

#### 来源与时效（本小主题末集中列）
- 一手锚点：Katz-Lindell 3rd ed. §9.2.2 / Appendix「Primality testing」（Miller–Rabin 算法、错误概率 ≤ 4^{−k}、大素数生成）。核实 2026-07-30。
- 交叉源：HAC 1996 §4.2.3「Miller-Rabin primality test」（Algorithm 4.24、Fact 4.25 错误概率 ≤ (1/4)^t、§4.4 随机素数生成）。核实 2026-07-30。两源算法与 4^{−k} 界一致。
- 实证：本机纯 Python Miller–Rabin 对 Carmichael 数 561、梅森素数 2^61−1 等，与 sympy 1.14.0 `isprime` 交叉验证一致（见上）。
- 冲突项：无。误判界两源都强调是最坏情形上界；对随机候选实际错误率更低（HAC §4.4.1 有平均情形更紧的界，此处按广度不深入）。

## 2.7 密码学困难假设

### 2.7.1 大整数分解问题

**大整数分解问题**（Factoring）：给定一个大合数 n（典型是两个大素数之积 n = p·q），求出它的素因子 p、q。当 p、q 足够大且随机选取时，目前没有已知的经典多项式时间算法能高效完成——已知最快的通用算法是数域筛法（NFS），其代价是**亚指数级**（关于 |n| 的比特数）。

这是 RSA 的安全支点。RSA 里 n 公开，但只有知道分解才能算出 φ(n) = (p−1)(q−1)、进而求出私钥 d。攻击者若能分解 n 就彻底攻破 RSA；反之，"由 n 求 φ(n)"、"由公钥求私钥 d"都被证明与分解 n 计算等价。初学者可记住一句不对称：把两个大素数**乘起来**是小学乘法，把乘积**拆回去**却难如登天——公钥密码就靠这种"造易拆难"的单向性活着。当前公开纪录：RSA-829（250 十进制位，约 829 比特）于 2020 年被分解，故 RSA 密钥长度建议已上调到 2048 比特及以上（NIST SP 800-57 建议 2048/3072 位对应约 112/128 比特安全强度，此为随算力演进的工程参数）。

### 2.7.2 离散对数问题(DL)

设 G 是一个循环群，g 是生成元，阶为 q。**离散对数问题**（DLP）：给定 g 和 y = g^x，求指数 x。

y = g^x（已知 g、y，求 x）

在精心挑选的群里（如大素数 p 的 Z_p^* 子群，或椭圆曲线群），已知没有高效经典算法求 x。

DLP 是 Diffie–Hellman、ElGamal、DSA、ECDSA 等一大族方案的地基。这里的不对称是：**正向的模幂** g^x mod p 用快速幂几十步就能算出，**反向的取离散对数**却极难。要点是"难不难取决于群怎么选"——在整数加法群 Z_n 里离散对数是平凡的（就是模逆乘法），毫无难度；只有在乘法群 Z_p^* 或椭圆曲线群这类"结构被打散"的群里它才难。椭圆曲线群上求 DL（ECDLP）比同等比特的 Z_p^* 更难，所以 ECC 能用短得多的密钥达到同等安全（256 位 ECC ≈ 3072 位 RSA 的安全强度，NIST SP 800-57，随算力演进）。

### 2.7.3 CDH 与 DDH

在离散对数之上，密码学更常直接依赖两条更"贴合应用"的假设。设群 G 循环、生成元 g、阶 q。

**计算性 Diffie–Hellman（CDH）**：给定 g^a 和 g^b（a、b 未知），计算 g^{ab} 是困难的。

给定 (g, g^a, g^b)，求 g^{ab}

**判定性 Diffie–Hellman（DDH）**：给定 g^a、g^b 以及第三个元素 z，判定 z 是否等于 g^{ab}（即区分真实的 DH 密钥 g^{ab} 与一个随机群元素）是困难的。

区分 (g, g^a, g^b, g^{ab}) 与 (g, g^a, g^b, g^c)（c 随机）

CDH 恰好刻画"窃听者从 DH 交换的两个公开值恢复共享密钥有多难"，是 DH 协议安全的直接假设；DDH 更强，用于证明 ElGamal 等方案的语义安全（不仅算不出密钥，连"密钥像不像随机"都分辨不出）。

三者的强弱关系要点：**DDH ⇒ CDH ⇒ DL**（能解左边就能解右边，故左边的假设更强）。反方向一般不成立，而且存在**DDH 可破但 CDH 仍难**的群——最典型是整个 Z_p^* ：那里有勒让德符号（二次剩余判定）能泄露 g^{ab} 的最低比特信息，从而破 DDH，但 CDH 依旧难。这就是实践中要把 DH 限制在 Z_p^* 的**大素数阶子群**（或椭圆曲线群）里的原因——在那种群里 DDH 才被相信成立。初学者记住这条链和"选群决定安全"即可，无需深入规约细节。
