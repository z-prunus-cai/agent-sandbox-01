**积分一开始是"两件互不相干的事"——(1) 求原函数（反向求导，得到一族函数，即不定积分）；(2) 求曲线下的净面积（把面积切成无穷多细条再求和取极限，即定积分）。微积分基本定理（FTC）的惊人之处，就是证明这两件事本质是同一件事的正反面**。抓住这条主线：4.1 只讲第一件事（反向求导的记号与积分表）；4.2 只讲第二件事（面积作为黎曼和的极限），此时它和求导毫无关系；4.3 才把桥架起来——面积的变化率恰好就是被积函数，于是"算面积"可以退化成"找原函数再相减"，把一个求极限的苦活变成一次代入。承接提示：本课只做单变量定积分与基本定理；多重积分、换元/分部等积分技巧、反常积分分别归大主题5、大主题8，本报告不展开。

## 4.1 不定积分

### 4.1.1 原函数与不定积分：求导的逆操作

若函数 F 的导数恰好是 f，即 F′(x) = f(x)，则称 F 是 f 的一个**原函数**（antiderivative）。把 f 的全体原函数记作 f 的**不定积分**：

    ∫ f(x) dx = F(x) + C

其中 F 是任意一个原函数，C 是任意常数，称为积分常数。注意不定积分的结果不是一个函数，而是"相差一个常数"的**一族**函数。

**积分（这里指求原函数）就是求导的反向操作**。求导问"这个函数的变化率是什么"，求原函数反过来问"谁的变化率是这个函数"。最小例子：因为 (x²)′ = 2x，所以 2x 的一个原函数是 x²，于是

    ∫ 2x dx = x² + C

为什么必须带那个 +C？因为常数的导数为 0，x²、x²+1、x²−7 求导后全都等于 2x，它们都是 2x 的原函数。既然求导"看不见"常数项，反向时就必须把这一整族可能性用 +C 显式带上。初学者最高频的丢分点就是**漏掉 +C**——在不定积分里漏 C 是实打实的错误（在定积分里 C 会抵消，见 4.3，但那是另一回事，不能混为一谈）。

中文的"积分"其实指两件事——不定积分（求原函数，本节）和定积分（求面积，4.2）。它们记号相似（都有 ∫）却是不同的对象：不定积分给出一族函数，定积分给出一个数。它们凭什么用同一个符号、有什么关系，正是 4.3 微积分基本定理要回答的核心问题。在读完 4.3 之前，请先把这两者当作**两件独立的事**来学。

### 4.1.2 基本积分表：把求导公式反着读

既然求原函数是求导的逆，那么把大主题2的每一条求导公式"反过来读"，就得到一张基本积分表。核心几条（每条都可通过对右边求导验证）：

    ∫ xⁿ dx = x^(n+1)/(n+1) + C   （n ≠ −1）

    ∫ (1/x) dx = ln|x| + C

    ∫ eˣ dx = eˣ + C

    ∫ cos x dx = sin x + C

    ∫ sin x dx = −cos x + C

    ∫ sec²x dx = tan x + C

    ∫ 1/(1+x²) dx = arctan x + C

    ∫ 1/√(1−x²) dx = arcsin x + C

配合两条线性法则——积分对加法可拆、常数可提到积分号外：

    ∫ [a·f(x) + b·g(x)] dx = a∫f(x)dx + b∫g(x)dx

就能积出所有多项式和这些基本函数的线性组合。

幂函数公式 ∫xⁿdx = x^(n+1)/(n+1) 的直觉很简单：反向套用幂法则 (x^(n+1))′ = (n+1)xⁿ，把多出来的因子 (n+1) 除掉即可。但要特别盯住那个例外 **n ≠ −1**：当 n = −1 时公式右边的分母 n+1 = 0，会除以零，公式失效——这个缺口恰好由 ∫(1/x)dx = ln|x| + C 补上（因为 (ln|x|)′ = 1/x）。这是初学者最容易踩的坑：见到 ∫x^(−1)dx 千万别套幂法则写成 x⁰/0，它等于 ln|x|+C。

另一个易错点是 ∫(1/x)dx 里的**绝对值**：写 ln|x| 而非 ln x，是为了在 x<0 时原函数仍有定义（对 x<0，(ln(−x))′ 也等于 1/x）。sympy 默认在正实数域上工作，会返回不带绝对值的 log(x)（见本报告末脚本，`sp.integrate(1/x,x)` 给出 `log(x)`），这是符号计算的定义域约定，手写标准答案时应带 |·|。

验证一条的最省力办法始终是"求导查回去"：想确认 ∫cos x dx = sin x + C，只需检查 (sin x)′ = cos x。这个"求导验算"习惯能挡掉绝大多数积分表记忆错误。sympy 逐条复现了上表（`x²/3`、`log(x)`、`exp(x)`、`sin(x)`、`-cos(x)`、`tan(x)`、`atan(x)`、`asin(x)`），脚本与真实输出见本报告末。

## 4.2 定积分与黎曼和

### 4.2.1 黎曼和：把曲线下的面积切成细条求和

定积分想解决的问题是：函数 f 在区间 [a, b] 上，曲线 y = f(x) 与 x 轴之间围出的（带正负号的）面积是多少。黎曼和给出的办法是"切条求和"：把 [a, b] 均分成 n 个宽度 Δx = (b−a)/n 的小区间，在每个小区间里取一个样本点 xᵢ*，用矩形 f(xᵢ*)·Δx 近似那一条的面积，再把 n 个矩形加起来：

    Sₙ = Σᵢ₌₁ⁿ f(xᵢ*) · Δx

这个和就叫黎曼和。当矩形越切越细（n → ∞），黎曼和就越来越逼近真实面积。

直觉是"用一堆细长方形拼出弯曲区域的面积"：区域上边界是曲线、不好直接算面积，但矩形面积人人会算（底×高）。切得越细，矩形顶端的"锯齿误差"越小，拼出来越接近真值。样本点 xᵢ* 可以取每个小区间的左端点、右端点或中点——只要函数够规矩（如连续），n→∞ 时结果都收敛到同一个值，取法不影响极限。

估 ∫₀¹ x² dx（即 y=x² 下方、[0,1] 上的面积）。用右端点、n 个矩形，黎曼和随 n 增大依次为（sympy/numpy 实算，@2026-07-26）：n=10 时 0.385000，n=100 时 0.338350，n=1000 时 0.333833，n=100000 时 0.333338——明显在向 1/3 ≈ 0.3333 收敛。这里右端点取样对递增函数 x² 而言每个矩形都略微高估，所以近似值从上方逼近 1/3，这也解释了为什么估计值都比 1/3 略大。

（1）"面积"是**带符号**的——曲线在 x 轴下方（f<0）的部分，f(xᵢ*)·Δx 为负，计入的是负面积。所以定积分算的是"净面积"（上方减下方），不是几何总面积。（2）Δx 是区间宽度不是样本点间距的随意值，均分时它等于 (b−a)/n。（3）别把黎曼和的"求和"与 4.1 的"求原函数"混淆——此刻我们完全没有用到求导或原函数，纯粹在做"切条、乘、加、取极限"，这是一个独立的极限过程。

### 4.2.2 定积分的定义：黎曼和的极限

把小区间无限细分、黎曼和的极限（若存在且与样本点取法无关）就定义为 f 在 [a, b] 上的**定积分**：

    ∫ₐᵇ f(x) dx = lim_{n→∞} Σᵢ₌₁ⁿ f(xᵢ*) · Δx

其中 Δx = (b−a)/n。若这个极限存在，就称 f 在 [a, b] 上**可积**。一个基本事实是：**在闭区间上连续的函数一定可积**（有限个跳跃间断的分段连续函数也可积）。

**定积分是一个数，不是一个函数**（这正是它和 4.1 不定积分最本质的区别，后者是一族函数）。记号里的 x 只是"哑变量"，换成别的字母不改变结果：∫ₐᵇ f(x)dx = ∫ₐᵇ f(t)dt，因为算出来都是同一个面积数。初学者常被记号吓到，其实定积分的值只依赖三样东西：被积函数 f、下限 a、上限 b。

由 4.2.1 的极限过程，

    ∫₀¹ x² dx = 1/3

sympy 直接给出 `1/3`（@2026-07-26），与黎曼和数值收敛的目标一致；再如 ∫₀^π sin x dx，sympy 给出 `2`。

几条一眼可懂、后面常用的性质（都可从定义直接看出）：区间可加 ∫ₐᵇ + ∫_b^c = ∫ₐ^c；上下限交换变号 ∫ₐᵇ = −∫_b^a；退化区间 ∫ₐ^a f dx = 0（宽度为零，面积为零）。易错点：（1）用定义（求极限）算定积分极其繁琐，只有 x²、x 这类简单函数勉强能手算——这恰恰是我们迫切需要 4.3 提供"捷径"的动机。（2）"连续 ⇒ 可积"是单向的，可积函数不必处处连续（允许有限个跳跃）。（3）定积分算的是净面积，若题目要"曲线与 x 轴围成的几何面积总和"，需对 f 取绝对值分段处理，不能直接用一个定积分。

## 4.3 微积分基本定理

### 4.3.1 FTC 第一部分：面积函数的导数就是被积函数

固定下限 a，让上限变动为 x，把"从 a 到 x 的定积分"看成关于 x 的函数，称为**面积函数**（累积函数）：

    G(x) = ∫ₐˣ f(t) dt

微积分基本定理第一部分（FTC I）说：若 f 在包含 a 的区间上连续，则 G 可导，且它的导数恰好就是被积函数在上限处的值：

    G′(x) = d/dx ∫ₐˣ f(t) dt = f(x)

换句话说，**"累积面积"这个函数的变化率，正是被累积的那个函数本身**。这就把 4.2 的定积分与 4.1 的求原函数第一次挂上了钩：G(x) 是 f 的一个原函数。

为什么会这样？直觉在"面积的增量"：当上限从 x 挪到 x+h（h 很小），G 增加的那一小条面积约等于一个底为 h、高约为 f(x) 的细矩形，面积 ≈ f(x)·h。于是增量比 [G(x+h)−G(x)]/h ≈ f(x)，令 h→0 就得到 G′(x) = f(x)。这条"每往右挪一点点，面积增长的速度等于当前的函数高度"是整个基本定理的心脏，值得反复咂摸。

取 f(t) = t³，则 G(x) = ∫₀ˣ t³ dt = x⁴/4，对它求导 G′(x) = x³，正好回到被积函数 t³ 在上限 x 处的值。sympy 印证：`∫₀ˣ t³ dt = x⁴/4`，`d/dx` 给出 `x³`；对一个连初等原函数都写不出的例子 d/dx ∫₀ˣ sin(t²)dt，sympy 也直接返回 `sin(x²)`（@2026-07-26）——这说明 FTC I 不依赖"能否写出原函数的显式公式"，它对任何连续 f 都成立。

（1）**求导变量是上限 x，积分里的 t 是哑变量**，两者必须用不同字母，否则会写出 ∫ₐˣ f(x)dx 这种把上限和积分变量混同的错误式子。（2）当上限是 x 的复合函数（如 ∫ₐ^{x²}），要额外乘链式法则的因子：d/dx ∫ₐ^{u(x)} f(t)dt = f(u(x))·u′(x)。（3）FTC I 的意义常被初学者低估——它其实**保证了"连续函数一定有原函数"**（G 就是现成的一个），哪怕这个原函数没有初等表达式。

### 4.3.2 FTC 第二部分：用原函数一步算出定积分

微积分基本定理第二部分（FTC II，又称求值定理）把 FTC I 反过来用，给出计算定积分的实用捷径：若 f 在 [a, b] 上连续，且 F 是 f 的**任意一个**原函数（即 F′ = f），则

    ∫ₐᵇ f(x) dx = F(b) − F(a)

也就是说，求定积分不必再去算黎曼和的极限，只需**找一个原函数，代入上下限相减**即可。右边常记作 [F(x)]ₐᵇ 或 F(x)|ₐᵇ。

它为什么成立？由 FTC I，面积函数 G(x)=∫ₐˣf 是 f 的一个原函数，而任意两个原函数只相差常数，所以 F(x) = G(x) + C。于是 F(b)−F(a) = [G(b)+C] − [G(a)+C] = G(b) − G(a) = ∫ₐᵇf − 0 = ∫ₐᵇf。注意这里**常数 C 被减法抵消**了——这正解释了 4.1 强调的"不定积分要带 +C，但定积分里 C 无所谓"：因为算定积分时首尾一减，C 自动消失，所以用哪个原函数都行。

最小例子，把 4.2 里靠黎曼和极限费劲得到的 1/3 一步算出：x² 的一个原函数是 x³/3，于是

    ∫₀¹ x² dx = [x³/3]₀¹ = 1³/3 − 0³/3 = 1/3

再如 ∫₀^π sin x dx = [−cos x]₀^π = −cos π − (−cos 0) = −(−1) + 1 = 2。两者都与 4.2 的 sympy 结果吻合。这就是 FTC 的全部威力：把一个"无穷求和取极限"的难题，降格成"求导查表 + 两次代入"的算术。

（1）用 FTC II 的前提是被积函数在 [a,b] 上**连续**（至少可积）；若区间内藏着竖直渐近线/瑕点（如 ∫_{−1}^{1} 1/x² dx），f 在 x=0 处不连续，直接套 F(b)−F(a) 会得出荒谬的负面积——这类情形要用反常积分处理（归大主题5），是经典陷阱。（2）代入顺序是上限减下限 F(b)−F(a)，reversed 会差一个符号。（3）别忘了原函数只需"任意一个"，不必带 +C（带了也会被减掉）。

### 4.3.3 积分与微分的互逆关系：一枚硬币的正反面

把两部分合看，FTC 揭示的是**微分与积分是一对互逆运算**，如同加法与减法、乘法与除法互逆。用两个"先…后…"的式子概括这层互逆：

    d/dx ∫ₐˣ f(t) dt = f(x)      （先积分、再求导，还原被积函数——FTC I）

    ∫ₐᵇ F′(x) dx = F(b) − F(a)    （先求导、再积分，还原函数的净增量——FTC II 换个写法）

第一式说"求导能撤销积分"，第二式说"积分能撤销求导（差个端点值的形式）"。这就是为什么 4.1 的不定积分（求原函数）和 4.2 的定积分（求面积）能共用 ∫ 这个符号：它们通过原函数这座桥连成了一体。

把 f 想成"速度"，那么 ∫ₐˣf(t)dt 就是"从 a 到 x 累积的位移"。FTC I 说"位移函数的变化率就是速度"（这本来就是速度的定义，求导撤销了积分）；FTC II 说"整段时间里累积的位移 = 位移函数的末值减初值 = F(b)−F(a)"（把每一瞬的速度积回位移）。速度↔位移的这层关系，正是微分与积分互逆最贴近生活的写照。

为什么这件事"惊人"？因为 4.1 的求原函数和 4.2 的求面积，出发点毫不相干——一个是反向求导的代数游戏，一个是切条求和的几何极限。事先没有任何理由认为它们有关。FTC 证明了"面积的变化率 = 函数值"，才让这两条独立发展的线索合流，把求面积这件难事永久地转化为求原函数这件（相对）容易的事。这也是"微积分"作为一门统一学科成立的基石，历史上归功于牛顿与莱布尼茨。

（1）"互逆"是有前提和形式差异的——积分撤销求导时会带出端点值（F(b)−F(a)），并非严丝合缝地还原原函数本身（毕竟原函数差一个常数）。（2）互逆关系是后续所有积分技巧的根基：换元积分（大主题5）本质是链式法则反向，分部积分是乘积法则反向——都是"把求导法则反过来读"。（3）在 ML 里，这层"累积↔瞬时"的互逆思想延伸到连续概率：概率密度 f 积分得到累积分布 F，而 F 求导又回到密度 f，正是 FTC 的直接应用（喂 L2-03，Deisenroth 微积分章佐证）。

本报告统一可复现脚本（基线 Py3.11.15/np2.4.6/sympy1.14.0/scipy1.17.1 @2026-07-26）：

    import sympy as sp
    import numpy as np
    x, t = sp.symbols('x t')
    m = sp.Symbol('m')
    # 4.1 基本积分表（sympy 默认正实数域，1/x 返回 log(x) 不带绝对值）
    print(sp.integrate(x**m, x))          # -> Piecewise: x**(m+1)/(m+1) (m≠−1), log(x) 否则
    print(sp.integrate(x**2, x))          # -> x**3/3
    print(sp.integrate(1/x, x))           # -> log(x)   （手写标准答案应作 ln|x|）
    print(sp.integrate(sp.exp(x), x))     # -> exp(x)
    print(sp.integrate(sp.cos(x), x))     # -> sin(x)
    print(sp.integrate(sp.sin(x), x))     # -> -cos(x)
    print(sp.integrate(sp.sec(x)**2, x))  # -> tan(x)  （显示为 sin/cos）
    print(sp.integrate(1/(1+x**2), x))    # -> atan(x)
    print(sp.integrate(1/sp.sqrt(1-x**2), x))  # -> asin(x)
    # 4.2 定积分
    print(sp.integrate(x**2, (x, 0, 1)))       # -> 1/3
    print(sp.integrate(sp.sin(x), (x, 0, sp.pi)))  # -> 2
    # 4.2 右端点黎曼和数值逼近 ∫₀¹ x² dx = 1/3
    for N in [10, 100, 1000, 100000]:
        xs = (np.arange(N) + 1) / N
        print(N, np.sum(xs**2) * (1/N))
    # 4.3 FTC I：先积分再求导，还原被积函数
    print(sp.diff(sp.Integral(sp.sin(t**2), (t, 0, x)), x).doit())  # -> sin(x**2)
    g = sp.integrate(t**3, (t, 0, x))
    print(g, sp.diff(g, x))               # -> x**4/4 , x**3

真实输出（逐行）：`Piecewise((x**(m+1)/(m+1), Ne(m,-1)), (log(x), True))`、`x**3/3`、`log(x)`、`exp(x)`、`sin(x)`、`-cos(x)`、`sin(x)/cos(x)`、`atan(x)`、`asin(x)`、`1/3`、`2`；黎曼和 `0.385000 / 0.338350 / 0.333833 / 0.333338`；`sin(x**2)`、`x**4/4 x**3`。
