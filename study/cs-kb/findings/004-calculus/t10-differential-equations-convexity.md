## 10.1 一阶微分方程

### 10.1.1 什么是微分方程

微分方程是一个**含有未知函数及其导数的等式**，它的"解"不是一个数，而是一个满足该等式的函数。只含一阶导数的叫一阶微分方程，一般形状是

    dy/dx = f(x, y)

即"函数在每一点的变化率 dy/dx，由该点的位置 (x, y) 决定"。

对初学者，关键的观念切换是：代数方程（如 x² − 1 = 0）的未知量是**数**，解出来是 x = ±1；而微分方程的未知量是**整条函数** y(x)，解出来是一族曲线。之所以经常一次解出"一族"而不是"一条"，是因为求解本质上要做一次积分，而积分总带一个任意常数 C——不同的 C 对应不同的初始高度，画出来是一整叠平行错开的曲线。

dy/dx = y 读作"我在每一点的增长速度，正好等于我当前的高度"。高度越高长得越快——这正是复利、人口、放射性衰变（负号版）这类"按比例变化"现象的通用模板。它的解是指数函数（见 10.1.2）。

为什么 CS/ML 的人要碰它：把"随时间连续变化"的系统写下来，天然就是微分方程——连续时间的动力系统、把梯度下降的步长取到无穷小得到的"梯度流"、扩散模型里的连续噪声过程，底层都是微分方程。本课只打通"可分离变量 + 初值问题"这个最基础的入口。

### 10.1.2 可分离变量方程

如果 dy/dx 能写成"只含 x 的部分"乘"只含 y 的部分"，这个方程就是**可分离变量**的：

    dy/dx = g(x) · h(y)

解法是把同名变量搬到同一边，再两边各自积分：

    dy / h(y) = g(x) dx

    ∫ 1/h(y) dy = ∫ g(x) dx + C

直觉上，"分离变量"就是把纠缠在一起的 x 和 y 拆到等式两侧，让每一侧都变回你已经会算的普通积分。这一步是形式上的移项（严格叙述要借助链式法则，但入门只需记住"y 那堆挪左边、x 那堆挪右边、两边积分、别忘 +C"）。

最小例子，解 dy/dx = k·y：

    ∫ 1/y dy = ∫ k dx

    ln|y| = kx + C

    y = A·e^{kx}   （A = ±e^C 是新的任意常数）

这条 y = A·e^{kx} 就是"按比例增长/衰减"的通解：k > 0 指数增长，k < 0 指数衰减。sympy 的 dsolve 给出的通解为 y(x) = C₁·e^{kx}，与手算一致（验证见 10.1.4）。

一是**丢掉 +C**，那样只得到一条特解、丢了整族解；二是**忘记绝对值**：∫1/y dy = ln|y|，处理定义域时要留意 y 的正负；三是**漏掉 h(y)=0 的常数解**：若 h(y₀)=0，则 y ≡ y₀ 也是一个解（例如逻辑斯蒂方程里 y≡0 和 y≡K），分离变量时因为拿 h(y) 当了分母，容易把这类平衡解漏掉。

### 10.1.3 初值问题（IVP）

给微分方程再配一个"起点"条件，就构成**初值问题**：

    dy/dx = f(x, y),   y(x₀) = y₀

初始条件的作用是从通解那一整族曲线里，**挑出穿过指定起点 (x₀, y₀) 的唯一一条**。

先求出带 C 的通解，再把 x = x₀、y = y₀ 代进去解出 C，回代即得特解。承接 10.1.2 的例子，若加条件 y(0) = y₀：

    y = A·e^{kx},   代入 x=0：y₀ = A·e^0 = A

    ⇒ y = y₀·e^{kx}

于是任意常数被钉死，得到唯一一条解曲线。sympy 的 dsolve(..., ics={y(0): y0}) 直接给出 y(x) = y₀·e^{kx}（验证见 10.1.4）。

通解像"一叠平行摆放的滑梯"，初始条件像"我现在人站在哪个滑梯的哪一格"，一旦指定，后续整条轨迹就完全确定了——这正是"确定性动力系统"的核心：现在的状态 + 演化规则 = 未来全程。

不要在"还没代入初始条件"时就把 C 丢掉或随手设成 0；必须先写出含 C 的通解、再用初值定 C。另外初值问题的解**未必在整条实轴上都存在**（例如 dy/dx = y² 的解会在有限时间冲到无穷，即"爆破"），本课不深挖存在唯一性定理（Picard–Lindelöf），只需知道"给了合适的起点，局部有唯一解"这一层。

### 10.1.4 通往连续动力系统与优化的接口

一阶微分方程是"连续视角"看待动态过程的通用语言，它在两个方向上接住后续课程。

其一，**连续动力系统 / 增长模型**：dy/dt = k·y 是指数增长/衰减的模板；加上"资源上限 K"的修正得到逻辑斯蒂方程

    dy/dt = r·y·(1 − y/K)

它的 S 形（sigmoid 型）解曲线正是很多"先加速、后饱和"现象的原型，也和神经网络里的 sigmoid 激活函数同源同形。

其二，**优化的连续视角（喂 L5-02）**：把梯度下降 x_{n+1} = x_n − η·∇f(x_n) 的步长 η 取到无穷小，离散迭代就变成一条连续轨迹，满足**梯度流**微分方程

    dx/dt = −∇f(x)

也就是"沿最陡下降方向连续滑动"。这解释了为什么训练能收敛到梯度为 0 的点：轨迹一直往损失下降的方向走，最终停在 ∇f = 0 的平衡点上——这个平衡点正是 10.2 要判定的极小点。这就是本大主题被定位为"微积分↔优化桥接"的原因：微分方程给"如何演化到最优"，10.2 给"最优点长什么样"。

一阶线性方程（积分因子法）、二阶常系数方程、数值解法（Euler/Runge–Kutta）等属于专门的"微分方程"课程，本接口节不展开，仅打通"可分离变量 + 初值问题 + 梯度流接口"。

本机验证（sympy 1.14.0 符号求解，环境串 基线 Py3.11.15/np2.4.6 @2026-07-25；脚本运行于仓库外 scratchpad）：

    import sympy as sp
    x, t, k = sp.symbols('x t k'); y = sp.Function('y')
    print(sp.dsolve(sp.Eq(y(x).diff(x), k*y(x)), y(x)))
    y0 = sp.symbols('y0')
    print(sp.dsolve(sp.Eq(y(x).diff(x), k*y(x)), y(x), ics={y(0): y0}))
    print(sp.dsolve(sp.Eq(y(x).diff(x), x*y(x)), y(x), ics={y(0): 1}))


    Eq(y(x), C1*exp(k*x))
    Eq(y(x), y0*exp(k*x))
    Eq(y(x), exp(x**2/2))

三行分别核实了：dy/dx=k·y 通解为 C₁·e^{kx}；配初值 y(0)=y₀ 得特解 y₀·e^{kx}；另一条可分离方程 dy/dx=x·y、y(0)=1 得 e^{x²/2}（手算 ∫dy/y=∫x dx ⟹ ln y = x²/2 ⟹ y=e^{x²/2}，一致）。均与 Stewart §9.3 的可分离变量解法结论相符。

## 10.2 无约束优化与凸性

### 10.2.1 无约束优化问题与一阶必要条件

无约束优化就是"在整个定义域上找一个使目标函数最小（或最大）的点，没有额外约束"：

    min_{x} f(x),   x ∈ ℝⁿ

**一阶必要条件**：若 f 可微且 x* 是一个（局部）极小点，则该点的导数/梯度必为零——

    单变量：f'(x*) = 0

    多变量：∇f(x*) = 0

满足梯度为零的点叫**临界点（驻点）**。

在极小点处，函数是"平的"——往任何方向挪一小步，一阶（线性）近似都不会让它下降，否则往下降方向再走就更小了，说明原点不是极小。所以"梯度为零"是极小点的**必要不充分**条件：它是一道筛子，先把候选点筛出来，但筛出来的可能是极小、可能是极大、也可能是既非极大也非极小的**鞍点**（多变量特有，形如马鞍，沿一个方向是谷、沿另一个方向是峰）。

f(x) = x²，f'(x) = 2x，令 2x = 0 得唯一临界点 x = 0，正是碗底（sympy 核实 f'=2x、临界点 [0]，见 10.2.4）。反例警示：f(x) = x³ 在 x=0 处 f'=0，但那里既不是极大也不是极小（是拐点），说明"梯度为零"绝不能直接下极值结论——这是初学者最常犯的错。

接口提示（喂 L5-02）：机器学习训练就是在做无约束优化——把模型参数当 x、损失函数当 f，用梯度下降沿 −∇f 迭代，直到逼近 ∇f = 0 的临界点。所以"∇f = 0"既是本节的数学条件，也是训练"收敛"的直接判据。

### 10.2.2 二阶充分条件

一阶条件只筛出临界点，要判断临界点到底是不是极小，看**二阶导数/Hessian**。

单变量，在临界点 x*（已有 f'(x*)=0）：

    f''(x*) > 0  ⇒ 局部极小（曲线上凹，碗口朝上）

    f''(x*) < 0  ⇒ 局部极大（曲线下凹，碗口朝下）

    f''(x*) = 0  ⇒ 判据失效，需进一步分析

多变量，在临界点（已有 ∇f=0），看 Hessian 矩阵 H = ∇²f 的正定性：

    H 正定       ⇒ 局部极小

    H 负定       ⇒ 局部极大

    H 不定       ⇒ 鞍点

    H 半定/奇异  ⇒ 判据失效

二阶导数量的是"弯曲方向"。碗口朝上（f''>0）的临界点当然是谷底；碗口朝下是峰顶。多变量把"弯曲"升级成 Hessian 这个对称矩阵——它正定意味着"从任何方向看都是往上弯的碗"，故为极小；不定意味着"有的方向往上弯、有的往下弯"，正是鞍点。这一节直接复用大主题7 的 Hessian 判据，此处只强调它作为"二阶充分条件"在优化里的角色。

二阶充分条件是**充分非必要**——f'(x*)=0 且 f''(x*)=0 时（如 f=x⁴ 在 0 点）判据失效，但 x=0 仍是极小点，需要更高阶或直接看函数值来判定。另外 f''>0 给的是**局部**极小，不保证全局最小；要谈全局，得请出凸性（10.2.3）。

### 10.2.3 凸性直觉与它为什么让优化变简单

一个函数 f 是**凸函数**，直观说就是"图像像一只碗、开口朝上"，严格定义是：连接图像上任意两点的线段，始终**位于图像上方（或重合）**：

    f(λa + (1−λ)b) ≤ λf(a) + (1−λ)f(b),   ∀ λ ∈ [0,1]

对二阶可微函数，有等价的判据：

    单变量：f 凸 ⟺ f''(x) ≥ 0 处处成立

    多变量：f 凸 ⟺ Hessian ∇²f(x) 处处半正定

凸性之所以是"优化的圣杯"，因为它把 10.2.1–10.2.2 的**局部**判据一步升级成**全局**结论：**对凸函数，任何临界点（∇f=0 的点）都自动是全局最小点，不存在骗人的局部极小、也不存在鞍点。** 于是"解 ∇f=0"或"梯度下降滑到底"找到的，就是真正的最优解，不用担心卡在半路的假谷底。

直觉解释"线段在图像上方"这个定义：凸函数弯曲方向始终一致（一直往上凹），所以你在任意两点之间拉一根直线（弦），弦总不会低于曲线；反过来，曲线上任一点的切线总在曲线**下方**——这条"切线在下"的性质是很多机器学习不等式（如 Jensen 不等式、凸对偶）的根。

最小例子与反例（sympy 核实 f'' 见 10.2.4）：
- e^x 的 f'' = e^x > 0，处处凸；
- x² 的 f'' = 2 > 0，处处凸（标准的"碗"）；
- −ln x 的 f'' = 1/x² > 0（x>0），凸——这是逻辑回归/交叉熵损失凸性的来源之一；
- x³ 的 f'' = 6x，在 x<0 为负、x>0 为正，**非凸**（既有凹段又有凸段）。

现实的深度神经网络损失函数**通常非凸**，有大量局部极小和鞍点，所以严格说梯度下降不保证到全局最优——凸性在此是"理想情形/分析工具"，解释"为什么优化能 work、朝哪个方向努力"，而不是对所有模型成立的保证。这正是本节标为"接口/直觉"而非"定理体系"的原因：先建立"凸=好优化"的正确直觉，凸优化的完整理论（KKT、对偶、收敛率）留给后续优化/ML 课程。区分两个易混词：**凸函数**（convex，开口朝上、判据 f''≥0）与中文"凸"在日常里的方向感相反，务必以"开口朝上/f''≥0"为准；开口朝下的是**凹函数**（concave）。

### 10.2.4 微积分↔优化接口小结（喂 L5-02 训练）

把本大主题两节串起来，就是机器学习训练的数学骨架：

    模型训练 = 无约束优化 min_θ L(θ)
    找最优 = 沿梯度流 dθ/dt = −∇L 演化（10.1 的微分方程视角）
             或离散地做梯度下降 θ ← θ − η∇L
    停在 ∇L(θ*) = 0 的临界点（10.2.1 一阶条件）
    是不是真极小 = 看 Hessian / 是否凸（10.2.2–10.2.3 二阶条件与凸性）

**10.1 回答"如何连续地走向最优"，10.2 回答"最优点满足什么条件、什么时候这个最优是全局唯一的"**；两者在 L5-02 的模型训练里合二为一。初学者读到这里只需带走三条钉子——"梯度为零是必要条件、二阶正定/凸性把它升级成充分且全局、训练=在损失曲面上顺着负梯度滑到谷底"，即达成本可选接口节的目标。

本机验证（sympy 1.14.0 符号求导，环境串 基线 Py3.11.15/np2.4.6 @2026-07-25；脚本运行于仓库外 scratchpad）：

    import sympy as sp
    x = sp.symbols('x')
    print(sp.diff(x**2, x), sp.diff(x**2, x, 2), sp.solve(sp.diff(x**2, x), x))
    for e in [sp.exp(x), -sp.log(x), x**2, x**3]:
        print(e, sp.diff(e, x, 2))


    2*x 2 [0]
    exp(x) exp(x)
    -log(x) x**(-2)
    x**2 2
    x**3 6*x

核实内容：x² 的一阶导 2x、二阶导常数 2>0（处处凸）、唯一临界点 x=0；e^x 的 f''=e^x>0、−ln x 的 f''=1/x²>0 均处处凸；x³ 的 f''=6x 变号故非凸。与 Stewart §4.3 凹凸判据、MML §7.3 凸性定义一致。
