## 8.1 二重积分

### 8.1.1 二重积分：把曲面下的体积切成小柱求和

设 f(x, y) 定义在平面区域 D 上，把 D 切成许多小块、每块面积记作 ΔAᵢ，在第 i 块里取一个样本点 (xᵢ*, yᵢ*)，用一根底面积为 ΔAᵢ、高为 f(xᵢ*, yᵢ*) 的细柱去近似那一块上方的体积，再把所有细柱加起来、令小块无限细分取极限，就得到 f 在 D 上的**二重积分**：

    ∬_D f(x, y) dA = lim_{‖P‖→0} Σᵢ f(xᵢ*, yᵢ*) ΔAᵢ

当 f ≥ 0 时，它的几何意义是曲面 z = f(x, y) 与区域 D 之间围出的**体积**。

这就是大主题4定积分定义的直接升维。一维时把 [a,b] 切成小段 Δx、用矩形 f(xᵢ*)Δx 拼曲线下面积；二维时把区域 D 切成小块 ΔA、用细柱 f·ΔA 拼曲面下体积。唯一变了的是"底"从一段长度变成一小片面积，求和的思想一模一样。所以每当你在二重积分里迷路，回想一维那张"切条求和"的图，把"条"换成"柱"即可。

几条从定义直接继承下来的性质，和一维完全平行：线性（∬(af+bg) = a∬f + b∬g）、区域可加（若 D 拆成不重叠的 D₁、D₂，则 ∬_D = ∬_{D₁} + ∬_{D₂}）。一个特别有用的特例：取 f ≡ 1，则

    ∬_D 1 dA = D 的面积

因为每根柱高都是 1，"体积"在数值上等于底面积。这给了我们一个用二重积分算平面区域面积的办法，后面极坐标里会反复用到。

易错点：二重积分算的同样是**带符号**的量——f 在 D 上取负值的部分贡献负体积，所以 ∬f 是"净体积"，不是几何总体积。另外 dA 只是"面积元"的抽象记号，真正动手算时它会具体化成 dx dy（8.1.2）或 r dr dθ（8.2），此刻先把它理解成"一小片面积"即可。

### 8.1.2 累次积分与 Fubini 定理：一层套一层地积

定义里的"对整片区域求和取极限"没法直接算。实际计算靠**累次积分**（iterated integral）：先固定一个变量、对另一个变量积分（内层），再对固定的那个变量积分（外层），把一个二重积分拆成两次单变量积分。在矩形区域 [a,b]×[c,d] 上，**Fubini 定理**保证只要 f 在该矩形上连续（更一般地在此区域上可积/绝对可积），两种积分顺序给出相同的结果，且都等于二重积分：

    ∬_{[a,b]×[c,d]} f(x,y) dA = ∫_a^b ( ∫_c^d f(x,y) dy ) dx = ∫_c^d ( ∫_a^b f(x,y) dx ) dy

直觉是"先切片、再累加切片"。想算一条面包（立体）的体积，可以先沿某个方向切成很多薄片、算出每一片的截面积（这是内层那次积分：固定 x，对 y 积出一条截面），再把所有薄片的截面积沿切的方向累加起来（外层积分）。你从哪个方向下刀（先对 x 还是先对 y）不影响面包总体积——这正是 Fubini 定理说的"换序不变"。

内层积分时要牢牢记住：**对谁积分，另一个变量就当常数**。这和大主题7求偏导时"对谁求导、其余当常数"是同一个思维习惯，正好互逆。最小例子，f(x,y) = x y² 在 [0,1]×[0,2] 上：

    ∫_0^2 ( ∫_0^1 x y² dx ) dy = ∫_0^2 (y²/2) dy = 4/3

sympy 两种顺序都得 4/3（见报告末脚本），印证 Fubini。

易错点：（1）Fubini 的"换序自由"有前提——被积函数在区域上可积（连续足矣；对无界或反常的情形需要绝对可积，否则换序可能得出不同结果，这是分析里的经典反例，本课不展开但要知道"换序不是无条件的"）。（2）内外层的积分限要配对正确：dy 的限必须写在 dy 这一层，dx 的限写在 dx 这一层，初学者常把限写反或写串。（3）在矩形区域上限都是常数，换序只是交换两个 ∫ 的位置；一旦区域不是矩形（8.1.3），换序会连带改写积分限，绝不能只把 ∫ 挪个位置。

### 8.1.3 一般区域上的二重积分：变限累次积分

区域 D 很少恰好是矩形。对一般区域，做法是把它描述成"一个变量在常数区间内变动，另一个变量的范围由前者决定"的形式，于是内层积分的上下限变成外层变量的函数。两类标准区域：

竖直条型（对每个固定的 x，y 在两条曲线之间）：

    ∬_D f dA = ∫_a^b ( ∫_{g₁(x)}^{g₂(x)} f(x,y) dy ) dx

水平条型（对每个固定的 y，x 在两条曲线之间）：

    ∬_D f dA = ∫_c^d ( ∫_{h₁(y)}^{h₂(y)} f(x,y) dx ) dy

关键直觉：**内层的限描述"一根扫描线穿过区域时从哪进、从哪出"，外层的限描述"扫描线扫过的整个范围"**。以竖直条型为例，固定一个 x 相当于画一条竖直线，它从下边界曲线 y=g₁(x) 进入区域、从上边界 y=g₂(x) 离开，这就是内层的下限和上限；而 x 本身从最左 a 扫到最右 b，就是外层的限。所以内层限几乎总是含外层变量的函数，外层限一定是纯常数——若你的外层积分限里还带着变量，一定是哪里写错了（这是头号高频错误）。

最小例子：三角形区域 0 ≤ y ≤ x，0 ≤ x ≤ 1 上积 f = x + y。竖直条型内层对 y 从 0 到 x：

    ∫_0^1 ( ∫_0^x (x+y) dy ) dx = 1/2

换成水平条型（对每个 y，x 从 y 到 1），限要整个重写：

    ∫_0^1 ( ∫_y^1 (x+y) dx ) dy = 1/2

两者相等（sympy 印证均为 1/2），但注意两次的积分限完全不同——这就是一般区域"换序必须重画区域、重写限"的含义，绝不是把 ∫ 简单对调。**换序的正确姿势是：先画出区域 D 的草图，再按新方向重新读进出边界**，凭空调换限几乎必错。这也是多重积分最需要动手画图的一节。

## 8.2 极坐标积分

### 8.2.1 极坐标下的面积元：dA = r dr dθ

当区域是圆盘、扇形、圆环，或被积函数里出现 x² + y² 时，直角坐标的积分限会很别扭（圆的边界写成 y = ±√(R²−x²)）。改用极坐标 x = r cos θ、y = r sin θ 常能把区域变成矩形 [r 范围]×[θ 范围]。代价是面积元不再是 dx dy，而要乘上因子 r：

    dA = r dr dθ

于是极坐标下的二重积分写成：

    ∬_D f(x,y) dA = ∬_{D'} f(r cos θ, r sin θ) · r dr dθ

那个多出来的 **r 绝不能忘**，它是极坐标积分的头号考点，也是最高频的丢分点。

为什么会冒出一个 r？因为极坐标网格切出的小块不是边长 dr、dθ 的小矩形。固定 r、让角度变 dθ 时，那段弧的长度是 r dθ（半径越大、同样的角度扫过的弧越长），而沿半径方向的宽度是 dr。所以这一小块近似是一个边长 dr 与 r dθ 的小矩形，面积 ≈ (dr)(r dθ) = r dr dθ。一句话记忆：**"外圈的格子大、内圈的格子小"，r 就是补偿这种大小差异的伸缩因子**。（更系统地看，r 正是极坐标变换的雅可比行列式，8.4 会统一解释——sympy 算得极坐标雅可比行列式恰为 r。）

最典型的例子是用极坐标算半径 R 圆盘的面积：区域是 0 ≤ r ≤ R、0 ≤ θ ≤ 2π，被积函数取 1：

    ∬_D 1 dA = ∫_0^{2π} ∫_0^R r dr dθ = ∫_0^{2π} (R²/2) dθ = π R²

正好是熟悉的圆面积公式（sympy 印证为 π R²）。如果这里忘了那个 r，内层会积成 ∫_0^R 1 dr = R，最终得到 2πR，量纲都不对（面积怎么会是长度的一次方），这也从侧面提醒你 r 不可省。

### 8.2.2 何时改用极坐标：识别信号与经典例子

判断"该不该换极坐标"的两个信号：（1）积分区域是圆/扇形/圆环/以原点为心的对称区域；（2）被积函数里出现 x² + y²（极坐标下它直接变成 r²，极大简化）。命中任一个，极坐标往往让积分限变常数、被积函数变简单。

一个必须会的例子是"用极坐标降服直角坐标里算不动的积分"——二维高斯积分：

    ∬_{ℝ²} e^{−(x²+y²)} dA = ∫_0^{2π} ∫_0^∞ e^{−r²} · r dr dθ = 2π · (1/2) = π

直角坐标下 ∫e^{−x²}dx 没有初等原函数，根本积不出来；换极坐标后，因为多出来的那个 r 恰好配上 e^{−r²}，内层 ∫_0^∞ e^{−r²} r dr = 1/2 一步可积（令 u = r²）。sympy 印证整个积分等于 π。这个技巧是概率论里证明正态分布归一化常数（∫e^{−x²}dx = √π）的标准手法，直接喂 L2-03——**正是因为极坐标里冒出的 r，才让高斯积分可算**，这是 r 因子"有用而非累赘"的最佳注脚。

易错点：（1）换极坐标后被积函数里的 x、y 都要换成 r cos θ、r sin θ，不能只换区域忘换函数。（2）r ≥ 0，θ 通常取 [0, 2π) 或 [−π, π)，描述扇形/半圆时 θ 的上下限要按张角写对。（3）面积元 r 与被积函数是相乘关系，要一起进入内层积分，别把 r 漏在外面。

## 8.3 三重积分与柱/球坐标

### 8.3.1 三重积分：把立体切成小盒求和

把二重积分再升一维，就是三重积分。设 f(x, y, z) 定义在空间区域 E 上，把 E 切成小盒、每盒体积 ΔVᵢ、取样本点乘函数值再累加取极限：

    ∭_E f(x,y,z) dV = lim Σᵢ f(xᵢ*, yᵢ*, zᵢ*) ΔVᵢ

在直角坐标下体积元 dV = dx dy dz，计算同样靠累次积分（Fubini 在三维照样成立），把三重积分化成三层套一层的单变量积分，一般区域下最内两层的限是外层变量的函数。取 f ≡ 1 时

    ∭_E 1 dV = E 的体积

这是三维版的"积 1 得测度"。

理解的关键仍是那句老话：**升维只改变"底"（长度→面积→体积），不改变"切、乘、加、取极限"的黎曼和骨架**。三重积分的难点不在概念，而在两处操作：一是确定累次积分的三层积分限（要能想象立体的形状，通常先定最内变量在什么曲面之间、逐层往外），二是判断"要不要换坐标"——直角坐标切出的立方体小盒对球、圆柱这类区域极不友好，于是有了柱坐标（8.3.2）和球坐标（8.3.3）。

### 8.3.2 柱坐标：极坐标 + 一根竖轴

柱坐标就是"把 xy 平面用极坐标、z 轴保持不变"：x = r cos θ、y = r sin θ、z = z。它继承了极坐标的面积元 r dr dθ，再配上 dz，体积元为：

    dV = r dr dθ dz

那个因子 **r** 和极坐标里的完全同源（sympy 算得柱坐标雅可比行列式也是 r），原因一样：xy 平面上外圈格子大、内圈格子小。

柱坐标专治"绕 z 轴有旋转对称"的立体：圆柱、圆锥、抛物面容器等。最小例子，半径 R、高 H 的实心圆柱体积（0 ≤ r ≤ R，0 ≤ θ ≤ 2π，0 ≤ z ≤ H）：

    ∭ 1 · r dr dθ dz = ∫_0^H ∫_0^{2π} ∫_0^R r dr dθ dz = π R² H

正是"底面积 πR² 乘高 H"（sympy 印证为 π H R²）。识别信号：区域或被积函数里出现 x² + y²（横截面是圆），且 z 方向相对独立，就优先考虑柱坐标。易错点仍是那个 r 不能漏。

### 8.3.3 球坐标：体积元 ρ² sin φ dρ dφ dθ

球坐标用"到原点的距离 ρ、从正 z 轴向下量的极角 φ、在 xy 平面内的方位角 θ"三个量定位一个点。本报告采用 MIT 18.02 的约定（ρ, φ, θ），坐标变换为：

    x = ρ sin φ cos θ,  y = ρ sin φ sin θ,  z = ρ cos φ

其中 0 ≤ ρ、0 ≤ φ ≤ π、0 ≤ θ ≤ 2π。体积元为：

    dV = ρ² sin φ dρ dφ dθ

这个 **ρ² sin φ** 因子是本大主题最需要死记又最容易记错的公式，务必与坐标约定配套记。

直觉拆解这个因子：球坐标切出的小块，沿 ρ 方向宽度是 dρ；沿 φ（俯仰）方向，转过 dφ 时点扫过的弧长是 ρ dφ（半径 ρ 的大圆上的弧）；沿 θ（方位）方向，转过 dθ 时扫过的弧长是"该点到 z 轴的距离"乘 dθ，而该点到 z 轴的距离是 ρ sin φ，故弧长为 ρ sin φ dθ。三者相乘：dρ · (ρ dφ) · (ρ sin φ dθ) = ρ² sin φ dρ dφ dθ。所以 **ρ² 来自"两个方向的弧长都正比于 ρ"，sin φ 来自"越靠近两极（φ→0 或 π）、绕 z 轴的圈越小"**。sympy 直接算球坐标雅可比行列式，输出恰为 ρ²sin φ，与手算一致。

最小例子，半径 R 球体的体积（0 ≤ ρ ≤ R，0 ≤ φ ≤ π，0 ≤ θ ≤ 2π）：

    ∭ ρ² sin φ dρ dφ dθ = ∫_0^{2π} ∫_0^π ∫_0^R ρ² sin φ dρ dφ dθ = (4/3) π R³

正是熟悉的球体积公式（sympy 印证 4πR³/3）。识别信号：区域是球/球壳、或被积函数含 x² + y² + z²（球坐标下变成 ρ²）时用球坐标。

易错点（本节最密集）：（1）**坐标约定不统一**——不同教材对 φ、θ 谁是极角谁是方位角的选择不同（见本节末"冲突项"），换书时务必先确认约定，否则 sin 会挂错角。但无论约定如何，体积元总是 ρ²·sin(极角)，"平方那个是半径、正弦那个是从 z 轴量起的极角"这条不变。（2）φ 的范围是 [0, π] 不是 [0, 2π]（只需从北极扫到南极），θ 才是 [0, 2π]，两者范围经常写反。（3）漏掉 sin φ 是仅次于坐标约定的高频错误。

## 8.4 变量替换与雅可比

### 8.4.1 一般换元公式：雅可比行列式作为局部伸缩因子

前面的极坐标 r、柱坐标 r、球坐标 ρ²sin φ 都是同一件事的特例：**换坐标时，体积元要乘以坐标变换的雅可比行列式的绝对值**。设由新变量 (u, v) 到旧变量 (x, y) 的变换 x = x(u,v)、y = y(u,v)，其雅可比行列式定义为偏导数排成的行列式：

    ∂(x,y)/∂(u,v) = det( [∂x/∂u, ∂x/∂v ; ∂y/∂u, ∂y/∂v] )

则二重积分的换元公式为：

    ∬_D f(x,y) dx dy = ∬_{D'} f(x(u,v), y(u,v)) · |∂(x,y)/∂(u,v)| du dv

三维完全平行，雅可比换成 3×3 行列式、体积元多一维。注意公式里取的是**绝对值**（体积是正的，行列式的符号只反映定向）。

这是大主题5单变量换元 ∫f(x)dx = ∫f(x(u))·(dx/du)du 的高维推广。一维时 dx/du 是"u 变一点、x 拉伸多少"的一维伸缩率；高维时一个方向的伸缩率不够用，因为坐标变换会把一个小方格拉伸并旋转成一个小平行四边形（三维是平行六面体），**雅可比行列式量的正是"这个小平行四边形/六面体的面积/体积相对原方格放大了多少倍"**。而线性代数告诉我们，一组向量张成的平行多面体的（有向）体积恰好是它们排成的矩阵的行列式——这里那组向量就是变换的偏导数列，所以伸缩因子必然是偏导数矩阵（雅可比矩阵，见大主题7）的行列式。一句话：**雅可比行列式 = 坐标变换在每一点的局部体积伸缩率**。

最小例子（线性变换）：u = x + y、v = x − y，反解 x = (u+v)/2、y = (u−v)/2，雅可比行列式为

    ∂(x,y)/∂(u,v) = det( [1/2, 1/2 ; 1/2, −1/2] ) = −1/2

取绝对值得 1/2，意味着这个变换把 uv 平面的面积压缩到一半（sympy 印证行列式为 −1/2）。做这类换元时体积元就要写成 (1/2) du dv。

易错点：（1）**别用错方向**——公式里乘的是"旧对新"∂(x,y)/∂(u,v)；若你手头算的是"新对旧"∂(u,v)/∂(x,y)，两者互为倒数（|∂(x,y)/∂(u,v)| = 1/|∂(u,v)/∂(x,y)|），用错会把因子取成倒数。（2）一定取绝对值。（3）换元后积分区域 D 也要相应变成 D'，函数 f 里的 x、y 全部换成 u、v 的表达式，一样都不能漏。

### 8.4.2 极/柱/球坐标都是换元公式的特例

有了 8.4.1 的总公式，前面三种坐标不再需要单独背，直接算它们的雅可比行列式即可核验：

    极坐标 x=r cos θ, y=r sin θ：      ∂(x,y)/∂(r,θ) = r
    柱坐标 x=r cos θ, y=r sin θ, z=z：  ∂(x,y,z)/∂(r,θ,z) = r
    球坐标 x=ρ sinφ cosθ, …：           ∂(x,y,z)/∂(ρ,φ,θ) = ρ² sin φ

这三个行列式 sympy 逐一算出，分别为 r、r、ρ²sin φ，与 8.2、8.3 手记的面积元/体积元因子一字不差。

这一节的意义在于**收束**：8.2 的 r dr dθ、8.3 的 r dr dθ dz 与 ρ²sin φ dρ dφ dθ，本来是三条要分别记忆的公式，现在统一成"雅可比行列式"这一个概念——它们只是把具体坐标代进 8.4.1 的总模具后算出的具体值。理解到这一层，就不必死记那些因子，遇到任何新坐标都能自己推。这也是为什么本大主题不该在 8.3 处拆开：8.4 才是把前三节收拢成一条主线的关键。

它对大主题7的回指也很直接：雅可比矩阵（偏导数排成的矩阵）在大主题7是"多元函数的最佳线性近似/多元链式法则的载体"，在这里取它的行列式就得到"局部体积伸缩率"。同一个雅可比矩阵，7 用它的映射作用（喂反向传播 L5-02），8 用它的行列式（管体积变换），是一体两面。

### 8.4.3 接口：概率密度积分（L2-03）与图形光照积分（L5-03）

雅可比换元不是纯数学玩具，它是两门下游课的直接地基，这里点明接口（讲清"用在哪、为什么"，不展开纵深）。

接口一，连续概率的密度变换（喂 L2-03）：若随机向量 X 有密度 f_X，做变换 Y = g(X)，则 Y 的密度为

    f_Y(y) = f_X(x) · |∂(x)/∂(y)|

那个 |∂(x)/∂(y)| 正是本节的雅可比因子。直觉是"概率质量守恒"——变换把空间局部拉伸时，同一团概率被摊到更大/更小的体积上，密度必须乘伸缩率来补偿，才能保证总概率仍为 1。这也解释了 8.2 里"用极坐标 + 那个 r 才积得出高斯积分"为何能推出正态归一化常数：多重积分的雅可比因子和概率密度变换的雅可比因子是同一个东西。

接口二，图形渲染中的积分（喂 L5-03）：渲染方程要在半球方向上对入射光积分算出一点的出射辐亮度，做球面参数化（用 φ、θ 参数化方向）时，立体角元 dω = sin φ dφ dθ 里的那个 sin φ，正是球坐标雅可比 ρ²sin φ 在单位球（ρ=1）上的遗留因子。换句话说，图形里"越靠近极点、方向格子越密"要靠 sin φ 加权，与 8.3.3 球坐标体积元同源。

一句话收束整个大主题：从 8.1 的双黎曼和到 8.4 的雅可比换元，多重积分给下游提供的最核心工具就是"高维积分 + 换坐标要配伸缩因子"，而这个伸缩因子在概率、图形里反复以雅可比的面目出现。

本报告统一可复现脚本（基线 Py3.11.15/np2.4.6/sympy1.14.0/scipy1.17.1 @2026-07-26）：

    import sympy as sp
    x, y, z, r, theta, rho, phi = sp.symbols('x y z r theta rho phi', real=True)
    R = sp.Symbol('R', positive=True); H = sp.Symbol('H', positive=True)
    # 8.1 Fubini：矩形换序 + 一般区域换序
    print(sp.integrate(sp.integrate(x*y**2, (x,0,1)), (y,0,2)))   # -> 4/3
    print(sp.integrate(sp.integrate(x*y**2, (y,0,2)), (x,0,1)))   # -> 4/3
    print(sp.integrate(sp.integrate(x+y, (y,0,x)), (x,0,1)))      # -> 1/2 (竖直条)
    print(sp.integrate(sp.integrate(x+y, (x,y,1)), (y,0,1)))      # -> 1/2 (水平条)
    # 8.2 极坐标：圆盘面积、二维高斯
    print(sp.integrate(sp.integrate(r, (r,0,R)), (theta,0,2*sp.pi)))                      # -> pi*R**2
    print(sp.integrate(sp.integrate(sp.exp(-r**2)*r, (r,0,sp.oo)), (theta,0,2*sp.pi)))    # -> pi
    # 8.3 柱/球体积
    print(sp.integrate(sp.integrate(sp.integrate(r,(r,0,R)),(theta,0,2*sp.pi)),(z,0,H)))  # -> pi*H*R**2
    print(sp.integrate(sp.integrate(sp.integrate(rho**2*sp.sin(phi),
          (rho,0,R)),(phi,0,sp.pi)),(theta,0,2*sp.pi)))                                   # -> 4*pi*R**3/3
    # 8.4 雅可比行列式（Matrix.jacobian）
    Xp = sp.Matrix([r*sp.cos(theta), r*sp.sin(theta)])
    print(sp.simplify(Xp.jacobian([r, theta]).det()))                                     # -> r  (极坐标)
    Xc = sp.Matrix([r*sp.cos(theta), r*sp.sin(theta), z])
    print(sp.simplify(Xc.jacobian([r, theta, z]).det()))                                  # -> r  (柱坐标)
    Xs = sp.Matrix([rho*sp.sin(phi)*sp.cos(theta), rho*sp.sin(phi)*sp.sin(theta), rho*sp.cos(phi)])
    print(sp.simplify(Xs.jacobian([rho, phi, theta]).det()))                              # -> rho**2*sin(phi)
    u, v = sp.symbols('u v', real=True)
    Xuv = sp.Matrix([(u+v)/2, (u-v)/2])
    print(sp.simplify(Xuv.jacobian([u, v]).det()))                                        # -> -1/2
