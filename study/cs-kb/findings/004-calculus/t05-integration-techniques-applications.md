## 5.1 换元积分

### 5.1.1 不定积分的换元法：把链式法则倒过来用

换元积分（u-substitution，又称第一类换元/凑微分）是求积分的头号技巧。它的依据是链式法则的逆运算：若 F 是 f 的原函数，则由链式法则 d/dx[F(g(x))] = f(g(x))·g′(x)，两边积分就得到换元公式

    ∫ f(g(x))·g′(x) dx = ∫ f(u) du = F(u) + C，   其中 u = g(x)

操作上就是把被积式里"某个内层函数 g(x)"整体记作 u，同时把 g′(x) dx 换成 du，使整个积分变成只含 u 的、积分表里认得的简单形式。

直觉上，换元是在"撤销链式法则"。求导时链式法则让复合函数 F(g(x)) 求导多出一个因子 g′(x)；积分时反过来，如果你在被积函数里恰好看到"一个复合函数 × 它内层的导数"这种搭配，就说明它是某个复合函数被求导的产物，把内层设成 u 就能一步还原。


    ∫ 2x·cos(x²) dx

内层是 x²，令 u = x²，则 du = 2x dx，注意被积式里恰好有 2x dx，于是积分变成 ∫ cos u du = sin u + C = sin(x²) + C。sympy 验证 `integrate(2*x*cos(x**2), x)` 返回 `sin(x**2)`（基线 Py3.11.15/sympy1.14.0 @2026-07-26，脚本见本小主题末）。

（1）**只换了函数没换微分**——记了 u = g(x) 却忘了把 dx 换成 du/g′(x)，结果 x 与 u 混在一起。合法的换元必须让最终积分里**只剩 u，一个 x 都不留**。（2）**硬凑不存在的 g′(x)**——比如 ∫ cos(x²) dx（没有那个 2x 因子）就不能用这个方法凑出来，它实际上没有初等原函数。换元能用的前提是被积式里"内层导数"这个因子（至多差一个常数倍）真的在场；差常数倍可以用常数提到积分号外补齐，差一个变量因子则不行。（3）**忘了把 u 换回 x**——不定积分的结果必须回到原变量。

### 5.1.2 定积分的换元：换元的同时换积分限

对定积分做换元时，除了换被积函数与微分，还必须**同步把积分上下限从 x 的值换成对应 u 的值**：

    ∫_{a}^{b} f(g(x))·g′(x) dx = ∫_{g(a)}^{g(b)} f(u) du

即下限由 x = a 变成 u = g(a)、上限由 x = b 变成 u = g(b)，换完限之后就再也不用换回 x 了，直接用 u 的原函数在新限上作差即可。


    ∫_{0}^{1} 2x·e^{x²} dx

令 u = x²，du = 2x dx；当 x = 0 时 u = 0，当 x = 1 时 u = 1。于是积分变成 ∫_0^1 e^u du = e^u |_0^1 = e − 1。sympy 验证 `integrate(2*x*exp(x**2), (x,0,1))` 返回 `-1 + E`（@2026-07-26），即 e − 1。

这里的关键易错点是初学者最容易踩的坑：**换了变量却没换积分限**。如果保留原来的 0 到 1 却把被积函数写成 u 的形式，就会算出完全错误的数值。有两种都正确的处理法可以二选一：要么像上面这样"换元连带换限"、全程不回 x；要么先当不定积分求出关于 x 的原函数、再换回 x 后代入原来的 0 和 1。两条路结果一致，但**绝不能"换了函数用旧限、又不换回 x"**——那是把两条路混着走。另外，做换元时要留意 g 在积分区间上的单调性与定义，避免让 u 的路径出现折返等病态情形（入门阶段的标准例子都不会遇到，但需要有这个意识）。

    x = sp.symbols('x')
    R = sp.symbols('R', positive=True)
    print(sp.integrate(2*x*sp.cos(x**2), x))              # -> sin(x**2)
    print(sp.integrate(2*x*sp.exp(x**2), (x, 0, 1)))       # -> -1 + E   (= e-1)
    print(sp.integrate(x*sp.exp(x), x))                    # -> (x - 1)*exp(x)
    print(sp.integrate(sp.log(x), x))                      # -> x*log(x) - x
    print(sp.integrate(x**2*sp.exp(x), x))                 # -> (x**2 - 2*x + 2)*exp(x)
    print(sp.apart((3*x+11)/((x-3)*(x+2)), x))             # -> 4/(x-3) - 1/(x+2)
    print(sp.integrate((3*x+11)/((x-3)*(x+2)), x))         # -> 4*log(x-3) - log(x+2)
    print(sp.integrate(1/(x**2+1), x))                     # -> atan(x)
    print(sp.integrate(sp.sqrt(1-x**2), x))                # -> x*sqrt(1-x**2)/2 + asin(x)/2
    print(sp.integrate(1/sp.sqrt(1-x**2), x))              # -> asin(x)
    print(sp.integrate(x - x**2, (x, 0, 1)))               # -> 1/6   (两曲线间面积)
    print(sp.integrate(sp.pi*(sp.sqrt(x))**2, (x, 0, 1)))  # -> pi/2  (圆盘法体积)
    print(sp.integrate(sp.pi*(R**2-x**2), (x, -R, R)))     # -> 4*pi*R**3/3 (球体积)
    print(sp.integrate(sp.sin(x)**2, (x, 0, sp.pi/2)))     # -> pi/4  (Wallis)
    print(sp.integrate(sp.sin(x)**3, (x, 0, sp.pi/2)))     # -> 2/3
    print(sp.integrate(sp.sin(x)**4, (x, 0, sp.pi/2)))     # -> 3*pi/16
    print(sp.integrate(1/x**2, (x, 1, sp.oo)))             # -> 1     (收敛)
    print(sp.integrate(1/x,    (x, 1, sp.oo)))             # -> oo    (发散)
    print(sp.integrate(1/sp.sqrt(x), (x, 0, 1)))           # -> 2     (瑕积分收敛)
    print(sp.integrate(1/x,    (x, 0, 1)))                 # -> oo    (瑕积分发散)
    print(sp.integrate(sp.exp(-x), (x, 0, sp.oo)))         # -> 1
    print(sp.integrate(sp.exp(-x**2), (x, -sp.oo, sp.oo))) # -> sqrt(pi)  (高斯积分)

## 5.2 分部积分

### 5.2.1 分部积分公式：把乘积法则倒过来用

分部积分（integration by parts）是继换元之后的第二大技巧，专治"两个不同类函数相乘"的被积式。它是乘积法则的逆运算：由 (uv)′ = u′v + uv′ 两边积分并移项，得到

    ∫ u dv = uv − ∫ v du

一块记作 u（准备**求导**），另一块连同 dx 记作 dv（准备**积分**得到 v）；套公式后，原积分 ∫ u dv 被换成一个新积分 ∫ v du，只要新积分比原来更简单，这一步就划算。

换元处理的是"复合"（链式法则的逆），分部处理的是"相乘"（乘积法则的逆）。乘积法则求导会产生两项之和，分部积分就是把这个过程反着走，用"已知一项 + 一个更容易的新积分"来表示原积分。


    ∫ x·eˣ dx

取 u = x（求导变简单，du = dx）、dv = eˣ dx（积分得 v = eˣ）。代入公式：∫ x eˣ dx = x eˣ − ∫ eˣ dx = x eˣ − eˣ + C = (x − 1)eˣ + C。sympy 验证 `integrate(x*exp(x), x)` 返回 `(x - 1)*exp(x)`（@2026-07-26）。

选谁当 u 是初学者最大的困惑，常用口诀 **LIATE**（对数 Logarithmic → 反三角 Inverse trig → 代数 Algebraic → 三角 Trigonometric → 指数 Exponential），排在前面的优先选作 u。道理是：越靠前的函数"求导后越简单"（如 ln x 求导变 1/x、x 求导变常数），把它放在 u 的位置让它被求导，新积分 ∫ v du 才会更好算。一个漂亮的应用是对付"看起来无从下手"的单个函数：

    ∫ ln x dx

把它看成 ln x · 1，取 u = ln x、dv = 1·dx（v = x），得 ∫ ln x dx = x ln x − ∫ x·(1/x) dx = x ln x − x + C。sympy 返回 `x*log(x) - x`，印证之。

（1）u 与 dv 选反会让新积分更复杂（比如上例把 eˣ 选成 u、x dx 选成 dv，越积越乱）——选反了就换一种拆法。（2）算 v 时不要再加常数 C（那个 C 会被消掉，加了只是徒增烦恼）。（3）符号——公式中间是**减号**，漏掉负号是最常见的计算错误。

### 5.2.2 递推（约化）公式：让分部积分自我调用

当被积函数含有整数幂（如 sinⁿx、xⁿeˣ、(ln x)ⁿ）时，一次分部往往不能直接算完，但能把"幂次为 n 的积分"表示成"幂次更低的同型积分 + 已知项"，反复调用直到幂次降到会算为止。这种把 Iₙ 用 Iₙ₋₁ 或 Iₙ₋₂ 表示的等式叫**递推公式（reduction formula）**。以 xⁿeˣ 为例：

    ∫ xⁿ eˣ dx = xⁿ eˣ − n ∫ xⁿ⁻¹ eˣ dx

每用一次，指数 n 降 1，最终降到 ∫ eˣ dx = eˣ 收尾。例如 ∫ x²eˣ dx = x²eˣ − 2∫ x eˣ dx = x²eˣ − 2(x−1)eˣ = (x² − 2x + 2)eˣ + C，sympy 返回 `(x**2 - 2*x + 2)*exp(x)`，印证之。

递推公式就是"分部积分的自我调用"，像编程里的递归——每一步把问题规模（幂次）减小，同时留下一个"已解决的头部"，直到触底（base case，最低幂次的已知积分）。它省去了对每个 n 重新推导的麻烦，一劳永逸。

一个反复出现、并直接喂后续应用的例子是三角幂的定积分（Wallis 型）。递推公式给出 ∫₀^{π/2} sinⁿx dx 随 n 交替出现 π 与不含 π 的有理数：sympy 逐个验证（@2026-07-26）

    ∫₀^{π/2} sin²x dx = π/4,   ∫₀^{π/2} sin³x dx = 2/3,   ∫₀^{π/2} sin⁴x dx = 3π/16

（1）递推公式**降幂但不改变积分类型**，是"化简"而非"求出"，最后一步仍需一个能直接积的 base case。（2）用于定积分时（如 Wallis），代入上下限后很多项会消掉，整体比不定积分更整洁——这也是 5.4 弧长/体积里三角幂积分的常见来源。（3）不必死记每一条递推公式的系数；理解"它由一次分部积分推出"，考场上能自己现推更稳妥，系数（如上式那个 −n）以推导或查表为准，不要凭记忆硬填。

## 5.3 部分分式与三角代换

### 5.3.1 部分分式分解：把有理函数拆成能积的碎块

部分分式（partial fractions）是积**有理函数**（多项式÷多项式）的标准武器。核心思想：任何真分式（分子次数 < 分母次数）都能拆成若干个"分母是一次或二次因式的简单分式"之和，而这些简单分式各自都能用对数或反正切积出来。

一般步骤：（1）若分子次数 ≥ 分母次数，先做多项式长除法分出整式部分；（2）把分母因式分解；（3）按因式类型写出待定分式并解出系数。最基本的情形是分母能分解为不同的一次因式：

    (3x + 11) / [(x − 3)(x + 2)] = A/(x − 3) + B/(x + 2)

解得 A = 4、B = −1。sympy 的 `apart((3*x+11)/((x-3)*(x+2)), x)` 返回 `4/(x - 3) - 1/(x + 2)`（@2026-07-26），印证系数。拆开后积分就水到渠成：

    ∫ (3x + 11)/[(x − 3)(x + 2)] dx = 4 ln|x − 3| − ln|x + 2| + C

sympy 的 `integrate` 返回 `4*log(x - 3) - log(x + 2)`（相差常数与绝对值约定），印证之。

拆分是"合并同类分式"的逆操作——平时通分把几个分式合成一个，部分分式反过来把一个复杂分式还原成几个简单分式，因为**积分对加法可拆**（∫(A+B) = ∫A + ∫B），拆成碎块后每块都在积分表里。

（1）**必须先降为真分式**——分子次数不低于分母时先长除，否则待定式写不出来。（2）分母的**重根**（如 (x−1)²）要写成 A/(x−1) + B/(x−1)² 两项，别只写一项。（3）分母含**不可约二次因式**（判别式 < 0，如 x²+1）时，对应分子要写成一次式 (Cx+D)，这一项通常积成对数 + 反正切的组合。（4）这套方法**只对有理函数**有效；带根号、指数、对数的不是有理函数，得先用换元或下面的三角代换转化。部分分式也是 5.5 里判定某些有理函数反常积分收敛性的前置化简手段。

### 5.3.2 三角代换：用三角恒等式消掉根号

三角代换（trigonometric substitution）专门对付被积式里出现 √(a²−x²)、√(a²+x²)、√(x²−a²) 这类**二次式的平方根**。思路是把 x 换成一个三角函数，利用毕达哥拉斯恒等式（sin²+cos²=1 等）把根号下的和/差**变成完全平方**，从而开根号消掉根式。三种标准配法：

    √(a² − x²)：令 x = a·sin θ，  用 1 − sin²θ = cos²θ
    √(a² + x²)：令 x = a·tan θ，  用 1 + tan²θ = sec²θ
    √(x² − a²)：令 x = a·sec θ，  用 sec²θ − 1 = tan²θ

代进去后根号变成 a·cosθ、a·secθ、a·tanθ（相差绝对值），根式消失，积分化为可算的三角积分；算完再用直角三角形把 θ 换回 x。

最小例子（半圆面积型）：

    ∫ √(1 − x²) dx

令 x = sin θ，√(1−x²) = cos θ，dx = cos θ dθ，积分变成 ∫ cos²θ dθ，用倍角公式积出后换回 x，得 (x√(1−x²))/2 + (arcsin x)/2 + C。sympy 的 `integrate(sqrt(1-x**2), x)` 返回 `x*sqrt(1 - x**2)/2 + asin(x)/2`（@2026-07-26），印证之。作为对照，`∫ 1/√(1−x²) dx = arcsin x`、`∫ 1/(x²+1) dx = arctan x`（sympy 分别返回 `asin(x)`、`atan(x)`）——后者也可视为 x = tan θ 型代换的直接结果。

根号 √(a²−x²) 在几何上就是直角三角形里"斜边 a、一条直角边 x、另一条边 √(a²−x²)"的关系，令 x = a sin θ 正是把 x 解释成"斜边×正弦"，于是那条边自然写成 a cos θ，根号消失。换句话说，三角代换是"借三角形的边角关系，把代数根式翻译成三角函数"。

（1）**积分限也要跟着换**（定积分时），并注意 θ 的取值范围要让代换单调、让 cosθ/secθ 等取正号（决定开根号后的正负）。（2）算完**务必换回原变量 x**——借助画一个直角三角形，把 sinθ、tanθ 等读成 x 与常数的比值，最稳妥。（3）先判断根号下是"a²−x²/a²+x²/x²−a²"哪一型再选代换，配错了反而更复杂。（4）有些形如 √(x²+bx+c) 的要先**配方**成标准的三类之一再代换。三角代换与部分分式常配合出现：一个复杂有理式先部分分式拆块，含不可约二次因式的块再用三角代换或直接积成 arctan。

## 5.4 积分的几何应用

### 5.4.1 平面区域的面积：两曲线之间的"竖条求和"

定积分最直接的几何意义就是面积。两条曲线 y = f(x)（上）与 y = g(x)（下）在区间 [a, b] 之间围成区域的面积是

    A = ∫_{a}^{b} [f(x) − g(x)] dx

其中 f(x) − g(x) 是每个 x 处竖直"薄条"的高度，dx 是它的宽度，乘积是薄条面积微元，积分把所有薄条从 a 到 b 加起来。

把区域切成无穷多条竖直细条，每条近似一个高 (上−下)、宽 dx 的细矩形；定积分就是"矩形面积无限细分求和"的黎曼和极限（承接大主题4）。最小例子——直线 y = x 与抛物线 y = x² 在 [0,1] 之间：上曲线是 y = x、下曲线是 y = x²，面积 = ∫₀¹ (x − x²) dx = 1/2 − 1/3 = 1/6。sympy 的 `integrate(x - x**2, (x,0,1))` 返回 `1/6`（@2026-07-26），印证之。

（1）**先判断谁在上谁在下**（在区间内可能会互换，需分段），被积函数永远是"上减下"，取绝对值思想保证面积非负。（2）有时按 dy（水平薄条、对 y 积分）比按 dx 更简单，取决于区域形状与曲线是否为单值函数。（3）纯粹的 ∫f dx 若 f 有正有负，算出的是"带符号净面积"；要"几何面积"需对 |f| 或分段处理。这是后续体积/弧长"切薄片—写微元—积分"范式的最简形态。

### 5.4.2 旋转体的体积：圆盘法与圆柱壳法

把一块平面区域绕一条轴旋转一周会扫出一个立体，其体积同样用"切薄片求和"来算，有两种常用切法。**圆盘/圆环法（disk/washer）**：垂直于旋转轴切，每片是一个薄圆盘（或中空圆环），体积微元 = 面积 × 厚度。绕 x 轴、由 y = f(x) 旋转时

    V = ∫_{a}^{b} π·[f(x)]² dx

**圆柱壳法（cylindrical shells）**：平行于旋转轴切成一层层薄圆筒，体积微元 = 周长 × 高 × 厚度。绕 y 轴时

    V = ∫_{a}^{b} 2π·x·f(x) dx

最小例子（圆盘法）：y = √x 在 [0,1] 绕 x 轴旋转，V = ∫₀¹ π(√x)² dx = ∫₀¹ πx dx = π/2。sympy 返回 `pi/2`（@2026-07-26）。一个漂亮的验证——半圆 y = √(R²−x²) 绕 x 轴转出**球**，体积 = ∫_{−R}^{R} π(R²−x²) dx，sympy 返回 `4*pi*R**3/3`，正是熟知的球体积公式 (4/3)πR³，反向印证了圆盘法。

圆盘法是"把立体沿轴切成一叠硬币"，每枚硬币体积 = πr²·厚；圆柱壳法是"把立体看成一层层套在一起的薄壁圆筒"，每层体积 = 展开成薄板 2πr·高·厚。二者算同一个体积、结果必然相等，选哪个看哪种切法的半径/高更好用一个变量表达。

（1）圆盘法里是**半径的平方**（πr²），漏掉平方是最常见错误。（2）绕的**不是坐标轴**（如绕 y = 2）时，半径要写成"到该轴的距离"（如 2 − f(x)），不能直接用 f(x)。（3）中间挖空（washer）时体积 = π(外半径² − 内半径²)，是**平方差**而非"差的平方"。（4）圆盘法 vs 圆柱壳法选错不会算错、只会更麻烦：绕 x 轴、函数写成 y=f(x) 时圆盘法自然；绕 y 轴且不易解出 x 时圆柱壳法自然。

### 5.4.3 弧长：把曲线拉直求和

一段光滑曲线 y = f(x) 从 x = a 到 x = b 的长度（弧长，arc length）为

    L = ∫_{a}^{b} √(1 + [f′(x)]²) dx

被积函数 √(1 + (f′)²) 来自把曲线切成无穷多小段、每小段用勾股定理近似成斜边：水平走 dx、竖直走 dy = f′(x)dx，斜边 √(dx² + dy²) = √(1 + f′²) dx。

这就是"沿曲线一步步量长度"的极限。每一小步是一个直角三角形的斜边，水平边 dx、竖直边 dy；把无穷多小斜边加起来就是弧长。斜率越陡（|f′| 越大），同样的水平 dx 对应的斜边越长，被积函数因此含 √(1 + f′²)。

y = cosh x（悬链线）从 0 到 1。因为 (cosh x)′ = sinh x 且 1 + sinh²x = cosh²x，被积函数 √(1+sinh²x) = cosh x，于是 L = ∫₀¹ cosh x dx = sinh(1) ≈ 1.1752。（sympy 对该弧长积分给出 `Integral(sqrt(cosh(x)**2),(x,0,1))` 未自动化简，但 √(cosh²x)=cosh x，其值 sinh(1) 由 `sp.N(sp.sinh(1))` 得 1.17520119…，@2026-07-26。）

（1）弧长积分**几乎总是"能列不能解"**——根号里嵌一个平方，绝大多数 f 得到的被积函数没有初等原函数，实践中常用数值积分（如 scipy 的 quad）近似，能手算出漂亮闭式的是少数精心挑选的例子（如上面的 cosh，或 y=x^{3/2} 一类）。这与面积/体积（多为多项式易积）形成鲜明对比，是初学者的心理落差点。（2）曲线用参数式 x=x(t), y=y(t) 给出时，弧长是 ∫ √(x′(t)² + y′(t)²) dt，是上式的推广。（3）要求 f 在 [a,b] 上有连续导数（光滑），有尖角/间断处需分段。弧长思想也是后续曲面积分、以及物理里路径长度/做功等的基础。

## 5.5 反常积分

### 5.5.1 无穷限反常积分：区间伸向无穷时用极限收尾

普通定积分要求区间有限、被积函数有界。**反常积分（improper integral）**放宽这两条中的第一条：积分上限或下限为 ±∞。它的定义是"先在有限区间上积分，再让端点趋于无穷取极限"：

    ∫_{a}^{∞} f(x) dx = lim_{t→∞} ∫_{a}^{t} f(x) dx

如果这个极限**存在且有限**，就说反常积分**收敛**，其值等于该极限；如果极限为 ±∞ 或不存在，就说它**发散**。

最小例子对照——同样是"1 除以 x 的幂"在 [1, ∞) 上，收敛与否天差地别：

    ∫_{1}^{∞} (1/x²) dx = 1   （收敛）
    ∫_{1}^{∞} (1/x)  dx = ∞   （发散）

sympy 分别返回 `1` 与 `oo`（@2026-07-26）。直觉上都是"面积伸向无穷远"，但 1/x² 衰减得足够快，无穷长的尾巴累积出**有限**面积；1/x 衰减太慢，尾巴面积累积到无穷。另一个常见收敛例子是指数衰减 `∫₀^∞ e^{−x} dx = 1`（sympy 返回 `1`）——这正是 L2-03 指数分布密度归一化的原型。

（1）反常积分**必须写成极限**，不能直接把 ∞ 代进原函数当数用；"∞ 是过程不是数"这一点承接大主题1的渐近记法。（2）**两端都无穷**时（∫_{−∞}^{∞}）要**拆成两个**独立的反常积分（如以 0 为界），**两半都收敛才算整体收敛**，不能用"对称相消"蒙混（否则会错判本发散的积分为 0）。（3）"面积有限" ≠ "函数趋于 0 就一定收敛"——趋于 0 只是必要的直觉，衰减**快慢**才是关键，下面用 p-判据量化。

### 5.5.2 瑕积分：被积函数在端点爆掉时同样用极限

反常积分的第二种：区间有限，但被积函数在区间内某点（通常是端点）**无界**（有竖直渐近线），这类叫**瑕积分**（无界被积函数的反常积分）。处理法相同——在瑕点附近截断、取极限。若 f 在 x = a 处趋于无穷：

    ∫_{a}^{b} f(x) dx = lim_{t→a⁺} ∫_{t}^{b} f(x) dx

最小例子对照——在 [0, 1] 上，瑕点为 x = 0：

    ∫_{0}^{1} (1/√x) dx = 2   （收敛）
    ∫_{0}^{1} (1/x)   dx = ∞   （发散）

sympy 分别返回 `2` 与 `oo`（@2026-07-26）。直觉：1/√x 在 0 附近虽冲向 +∞，但冲得"不够猛"，围出的竖直无界区域面积仍有限；1/x 冲得太猛，面积发散。

**没看出这是瑕积分，当普通定积分硬算**。例如 ∫_{−1}^{1} (1/x²) dx，若无视 x=0 处的瑕点直接用原函数 −1/x 代限，会算出 −2 这种"负面积"的荒谬结果——实际上它在 x=0 处发散。**动手前先检查被积函数在积分区间（含端点）上是否处处有界、有定义**，发现瑕点就按瑕积分拆开、取极限，是不可省的一步。瑕点在区间内部时（非端点）也要以瑕点为界拆成两段分别判定。

### 5.5.3 收敛判定与 p-判据：比大小定敛散、喂概率归一化

很多反常积分求不出精确值，但我们往往只需知道它**收不收敛**。核心工具是**比较判别法**：若在积分区间上 0 ≤ f(x) ≤ g(x)，则"大的收敛 ⇒ 小的收敛；小的发散 ⇒ 大的发散"。据此可以拿已知敛散性的标准函数当"标尺"去卡未知的积分。最重要的标尺是 **p-积分（p-判据）**：

    ∫_{1}^{∞} (1/xᵖ) dx  收敛 ⟺ p > 1，   发散 ⟺ p ≤ 1
    ∫_{0}^{1} (1/xᵖ) dx  收敛 ⟺ p < 1，   发散 ⟺ p ≥ 1

注意两条方向**相反**：在无穷远端（[1,∞)）要衰减够快（p 大）才收敛；在瑕点端（[0,1]，瑕点 0）要爆得够温和（p 小）才收敛。前面的例子正是它的特例：[1,∞) 上 p=2 收敛、p=1 发散；[0,1] 上 p=1/2 收敛、p=1 发散——sympy 的四个输出 `1, oo, 2, oo` 全部对应吻合。

p-判据把"衰减/发散的快慢"用一个数 p 精确刻画，临界点都在 p=1（对数增长的边界），是判定敛散最省事的对照表。比较判别法的直觉则是"面积被夹"——被一个面积有限的函数压住，自己面积必有限；压住一个面积无穷的函数，自己面积必无穷。

为什么这一节对下游重要（点明接口）：**连续型概率分布的密度函数 f(x) 必须满足全空间积分归一化**

    ∫_{−∞}^{∞} f(x) dx = 1

这本身就是一个反常积分，它**收敛到 1** 是"f 能当密度"的前提——正态、指数、Gamma 等分布密度的合法性都靠这个反常积分收敛来保证，这正是 L2-03 连续概率的入口。一个标志性例子是高斯积分 `∫_{−∞}^{∞} e^{−x²} dx = √π`（sympy 返回 `sqrt(pi)`，@2026-07-26），正态分布密度里的归一化常数 1/√(2π) 就来自它的收敛值。反常积分的收敛判定在这里从"数学习题"升级为"概率模型能否成立"的判据。

（1）比较判别法要求被比的函数**非负**（或先取绝对值判"绝对收敛"），别对变号函数直接套。（2）p-判据的两个方向容易记反——用一句话锚定："跑到无穷远，跌得快（p>1）才收敛；挤在瑕点旁，涨得慢（p<1）才收敛。"（3）"函数值趋于 0"是无穷限收敛的**必要非充分**条件（1/x 趋 0 却发散），敛散最终由 p（衰减快慢）决定，不能只看极限为 0 就断言收敛。
