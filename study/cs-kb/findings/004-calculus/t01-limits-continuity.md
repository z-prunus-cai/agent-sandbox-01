## 1.1 极限概念

### 1.1.1 极限的直觉：逼近的去处，而非到达的落点

函数 f 在点 a 处的极限，指的是当自变量 x 越来越靠近 a（但不等于 a）时，函数值 f(x) 越来越靠近的那个数 L。记作

    lim_{x→a} f(x) = L

关键词是"靠近"而不是"到达"：极限只看 x 在 a 的**附近**（去心邻域）时 f 的走向，完全不理会 f 在 a 这一点是否有定义、取值是多少。

对初学者，最容易卡住的就是把"极限"和"函数值"混为一谈。举一个最小例子：

    f(x) = (x² − 1) / (x − 1)

在 x = 1 处，分母为 0，函数**无定义**，f(1) 根本不存在。但只要 x ≠ 1，就能约分成 f(x) = x + 1，于是当 x 逼近 1 时 f(x) 逼近 2：

    lim_{x→1} (x² − 1)/(x − 1) = 2

极限存在且等于 2，尽管 f(1) 不存在。这正说明"极限描述的是趋势，不是落点"。反过来，也存在极限存在但不等于函数值的情形（比如人为把 f(1) 定义成 5），这类"趋势与落点不一致"的点，正是 1.3 要研究的间断点。

判断极限时你可以（在心里）"把那一点抠掉"。sympy 也印证了上式：`sympy.limit((x**2-1)/(x-1), x, 1)` 返回 `2`（基线 Py3.11.15/sympy1.14.0 @2026-07-26），完整脚本见本小主题末。

### 1.1.2 ε-δ 定义：把"逼近"翻译成可验证的不等式

直觉里的"越来越近"不够严格，无法用来证明。ε-δ 定义把它翻译成一个"挑战—应答"的不等式游戏：说 lim_{x→a} f(x) = L，意思是——对任意给定的误差容忍度 ε > 0，都能找到一个邻域半径 δ > 0，使得只要 x 落在 a 的去心 δ 邻域内，f(x) 就落在 L 的 ε 邻域内。写成符号：

    ∀ ε > 0, ∃ δ > 0, 使得 0 < |x − a| < δ ⇒ |f(x) − L| < ε

这里 0 < |x − a| 中的"0 <"就是"去心"——把 x = a 本身排除在外，呼应 1.1.1 的"抠掉那一点"。

初学者该怎么读它？把它想成对手在跟你叫价：对手先甩出一个多小的 ε（要求 f(x) 离 L 不超过 ε），你必须应答一个 δ（承诺"只要 x 离 a 不超过 δ，我保证做到"）。**极限存在 ⇔ 无论对手把 ε 叫得多小，你总能找到相应的 δ 兑现承诺。** ε 先给、δ 后找，这个顺序不能颠倒——δ 一般会依赖 ε（ε 越小，往往 δ 也得越小）。

为什么非要这么绕？因为"越来越近"是个含糊的动态说法，而数学证明需要静态、可检验的断言。ε-δ 把"动态逼近"压成了一条"对所有 ε 都成立的静态不等式"，从此极限的存在与否可以被严格证明或证伪，而不再依赖看图猜。

（1）忘了"去心"，误以为要考虑 x = a——那是连续性的事，不是极限的事。（2）把量词顺序记反成"存在 δ 对所有 ε"，那会变成一个几乎永远为假的错误命题。（3）以为 δ 是唯一的——任何更小的 δ 同样有效，你只需找到一个即可。ε-δ 本身不便手算具体极限，它的价值是给极限一个"金标准"定义，1.2 的法则都最终建立在它之上。

### 1.1.3 单侧极限与极限存在的判据

有时 x 只能从一侧逼近 a，或者两侧的走向不同，于是需要单侧极限。从右侧（x 比 a 大且趋于 a）逼近记作 lim_{x→a⁺}，从左侧记作 lim_{x→a⁻}。**双侧极限存在，当且仅当左右极限都存在且相等：**

    lim_{x→a} f(x) = L  ⇔  lim_{x→a⁻} f(x) = lim_{x→a⁺} f(x) = L

最小例子是符号函数式的 f(x) = |x| / x：当 x > 0 时它恒等于 1，当 x < 0 时它恒等于 −1。于是

    lim_{x→0⁺} |x|/x = 1,   lim_{x→0⁻} |x|/x = −1

左右极限一个是 1、一个是 −1，不相等，所以 lim_{x→0} |x|/x **不存在**。sympy 分别给出 `+` 侧为 `1`、`-` 侧为 `-1`（@2026-07-26），印证双侧极限不存在。

直觉上，单侧极限像是"只从马路一边走过来看红绿灯"。很多现实函数在某点两侧行为割裂（分段函数、台阶、绝对值折点），这时必须分左右讨论。这是初学者的高频陷阱：看到"lim 不存在"别急着以为函数"爆掉"了，很多时候只是左右不一致这种温和情形（这类点在 1.3 里叫跳跃间断点）。单侧极限也是定义在区间端点处连续、以及讨论 1.4 里"从某侧冲向竖直渐近线"时的必要工具。

## 1.2 极限运算

### 1.2.1 极限法则：把复杂极限拆成简单极限的加减乘除

如果 lim_{x→a} f(x) 与 lim_{x→a} g(x) 都存在，那么极限对四则运算是"可穿透"的——先取极限再运算，等于先运算再取极限：

    lim (f ± g) = lim f ± lim g
    lim (f · g) = (lim f) · (lim g)
    lim (f / g) = (lim f) / (lim g)   （要求 lim g ≠ 0）
    lim (c · f) = c · lim f

（以上各式省略了统一的下标 x→a。）配合两个最基本的极限 lim_{x→a} c = c（常数）与 lim_{x→a} x = a（恒等函数），就能像搭积木一样算出所有多项式、有理函数在其定义点处的极限。

极限法则的意思是"取极限"这个操作和加减乘除彼此不打架，可以交换顺序。这带来一个极其常用的结论——**多项式与有理函数在它有定义的点处，极限就等于直接代入的函数值**（这其实就是 1.3 说的"连续"）。最小例子：

    lim_{x→2} (x² + 3x) = 2² + 3·2 = 10

直接代入即可，因为多项式处处连续。

商法则要求分母极限**非零**；一旦分母极限为 0，法则失效，不能硬套——这时往往落入 1.2.3 的特殊极限或需要因式约分（如 1.1.1 的 (x²−1)/(x−1)）。乘积法则也要求两个因子极限**都存在**：若其中一个不存在，不能想当然地拆开。初学者常犯的错是对 lim f/g 见到"0/0"就下结论"极限不存在"或"等于 1"，实际上 0/0 是**不定型**，必须另想办法（约分、夹逼、或后续洛必达，见大主题3）。

### 1.2.2 夹逼定理：用两个"夹子"逼出中间的极限

当一个函数不好直接求极限，但能被两个更简单的函数从上下夹住，且这两个函数在该点极限相等时，被夹的函数极限也等于这个公共值。设在 a 的某去心邻域内恒有

    g(x) ≤ f(x) ≤ h(x)

且

    lim_{x→a} g(x) = lim_{x→a} h(x) = L

则必有

    lim_{x→a} f(x) = L

这就是夹逼定理（Squeeze / Sandwich Theorem）。

如果左右两片"面包"都趋向同一点，夹在中间的"馅"没有别的地方可去，只能跟着趋向那一点。它的威力在于对付"剧烈震荡但被压住幅度"的函数。经典最小例子：

    lim_{x→0} x² · sin(1/x) = 0

因为 sin(1/x) 在 x→0 时疯狂震荡、无极限，但它恒在 [−1, 1] 内，于是 −x² ≤ x²·sin(1/x) ≤ x²，而两端 ±x² 都趋于 0，被夹的函数只能趋于 0。

不等式只需在 a 的**某个去心邻域**成立即可，不必全局成立；两个夹子的极限必须**相等**，若一个趋于 0、一个趋于 1，则定理无从下结论。夹逼定理还是下一节证明 sin x / x → 1 的关键工具，也是很多"用初等法则算不动"的极限的突破口。

### 1.2.3 两个特殊极限：sin x / x → 1 与 (1 + 1/x)^x → e

有两个极限反复出现、且不能靠代入或简单法则得到，需单独记住并理解。第一个（三角，x 用弧度）：

    lim_{x→0} (sin x) / x = 1

它形式上是 0/0 不定型，却等于 1。直觉是：当角度很小时，弧长（≈ x）与其正弦值（sin x）几乎相等，比值趋于 1；严格证明用的正是 1.2.2 的夹逼（用几何面积把 sin x / x 夹在 cos x 与 1 之间）。一个直接的连带结论是

    lim_{x→0} (1 − cos x) / x² = 1/2

sympy 分别验证 `sin(x)/x → 1` 与 `(1−cos x)/x² → 1/2`（@2026-07-26）。

第二个（指数，定义自然常数 e）：

    lim_{x→∞} (1 + 1/x)^x = e ≈ 2.71828

它是"1 的无穷次方"这一不定型的代表，结果是无理数 e，这正是许多教材对 e 的定义之一。sympy 返回 `E`，印证之。

为什么把它们单拎出来？因为初学者面对 0/0、1^∞ 这类**不定型**时最容易想当然：以为 0/0 = 0 或 1、1^∞ = 1，全错。不定型的真正含义是"仅凭形式无法确定，结果取决于两者逼近 0（或到 1、∞）的相对速度"。这两个特殊极限就是最典型的反例，也是导数（sin、e^x 的求导，大主题2）与泰勒展开（大主题6）的地基。务必注意 sin x / x → 1 只在 x 用**弧度**时成立，用角度会得到别的常数——这是一个隐蔽而常见的坑。

## 1.3 连续性

### 1.3.1 连续的定义：极限值恰好等于函数值

函数 f 在点 a 处连续，指的是三件事同时成立：f(a) 有定义、极限 lim_{x→a} f(x) 存在、且二者相等。三条可以压缩成一个式子：

    lim_{x→a} f(x) = f(a)

如果 f 在某区间的每一点都连续，就称 f 在该区间连续。直观地说，连续函数的图像"一笔画得下来，中途不用抬笔"。

理解连续性的钥匙是把它和极限对照：1.1 反复强调"极限不管 f(a)"，而连续性偏偏**额外要求**"极限的去处正好落在 f(a) 上"。所以连续 = 极限存在（趋势明确）+ 落点存在（f(a) 有定义）+ 趋势与落点一致。这三条缺一不可，缺哪一条就对应 1.3.2 的一类间断。

为什么连续性重要？因为连续函数才允许"直接代入求极限"（呼应 1.2.1），也才保证后面介值定理、可导蕴含连续（大主题2）、可积（大主题4）等一系列好性质。常见的初等函数——多项式、sin、cos、e^x、以及它们在定义域内的和差积商与复合——都在各自定义域上连续，这是我们敢于"代入求值"的底气。易错点：连续是**逐点**定义的性质，"函数连续"其实是"在所讨论的每一点都连续"的简称；在孤立的坏点（如分母为零处）它可以不连续，却不影响其余点的连续性。

### 1.3.2 间断点的分类：可去、跳跃、无穷

当 1.3.1 的某一条失效，a 就是一个间断点（不连续点）。按失效的方式，常分三类：

可去间断点：极限 lim_{x→a} f(x) 存在（左右相等），但 f(a) 无定义、或 f(a) 存在却不等于该极限。此时只要"补上或修改"这一个点的值就能变连续，故称"可去"。例子就是 1.1.1 的 (x²−1)/(x−1) 在 x=1：极限是 2，只需定义 f(1)=2 即可补成连续。

跳跃间断点：左极限与右极限都存在，但二者**不相等**，图像在此处"跳一格"。例子是 1.1.3 的 |x|/x 在 x=0：左极限 −1、右极限 1，跳跃高度为 2，无论如何补一个点都补不平。

无穷间断点：至少一侧极限为 ±∞，函数在该点附近冲向无穷。例子是 f(x)=1/x 在 x=0：右极限 +∞、左极限 −∞。这类点对应 1.4 要讲的竖直渐近线。sympy 给出 `1/x` 在 0⁺ 为 `oo`、在 0⁻ 为 `-oo`（@2026-07-26），印证无穷间断。

分类的意义在于"能不能救、怎么救"：可去间断改一个点就好；跳跃间断是左右趋势本质冲突，救不了；无穷间断则是函数值发散。初学者易错点：（1）把可去间断误当"连续"——极限存在不等于连续，还差"f(a) 等于该极限"这一步。（2）遇到分母为零就一律叫"无穷间断"——未必，(x²−1)/(x−1) 分母也为零，却是可去间断，要先约分看极限是否有限。判断类型的通用做法：先算左右极限，再对照 f(a)。

### 1.3.3 介值定理：连续函数不能"跳过"中间值

介值定理（Intermediate Value Theorem, IVT）说：若 f 在闭区间 [a, b] 上连续，且 N 是介于 f(a) 与 f(b) 之间的任意一个值，则至少存在一点 c ∈ (a, b) 使得

    f(c) = N

换句话说，连续函数从 f(a) 走到 f(b) 的过程中，中间的每一个高度都必然被"路过"至少一次。

既然图像能一笔画下、中途不抬笔，那它要从低处 f(a) 爬到高处 f(b)，就绝不可能"瞬移"跳过中间的某个高度——必然在某处正好经过。连续性是这里不可省的前提：跳跃间断的函数恰恰能"跳过"中间值，例如台阶函数从 0 直接跳到 1，值 0.5 一次也没取到。

最常用的推论是**求根（zero）定理**：若连续函数 f 在区间两端异号，即 f(a) < 0 < f(b)（或反之），则中间必有一个根 f(c) = 0。最小例子：f(x) = x³ + x − 1 连续，f(0) = −1 < 0、f(1) = 1 > 0，故在 (0, 1) 内至少有一个实根。这正是二分法数值求根的理论依据。

（1）IVT 只保证"存在"至少一个 c，**不给出 c 的个数，也不给出 c 的位置或求法**——它是存在性定理，不是构造性方法。（2）前提是**闭区间上连续**，缺了连续性（有间断）结论就可能失败。（3）它说的是"值域覆盖了 f(a) 与 f(b) 之间"，并不意味着 f 单调，函数完全可以来回震荡多次经过 N。IVT 是连续性最重要的"能干什么"，也是后续证明中值定理（大主题3）一类存在性结论的同门。

## 1.4 渐近行为

### 1.4.1 无穷处的极限与水平渐近线

当自变量 x 无限增大（x→+∞）或无限减小（x→−∞）时，若函数值 f(x) 趋于一个有限数 L，就记作

    lim_{x→∞} f(x) = L

此时直线 y = L 称为图像的**水平渐近线**——曲线在远端越来越贴近这条水平线却（通常）不与之重合。x→+∞ 与 x→−∞ 可能给出不同的 L，因而一条曲线最多有两条水平渐近线。

对有理函数，一个实用的口诀是"比最高次"：分子分母同除以分母的最高次幂，看谁的次数高。最小例子：

    lim_{x→∞} (3x² + 2) / (x² − 1) = 3

分子分母同为二次，极限等于最高次项系数之比 3/1 = 3，故 y = 3 是水平渐近线。另一例分母次数更高：

    lim_{x→∞} (2x + 1) / (x² + 1) = 0

分母次数高，极限为 0，水平渐近线是 x 轴 y = 0。sympy 分别给出 `3` 与 `0`（@2026-07-26），印证口诀。

x 极大时，多项式由其最高次项主导，低次项与常数相对可忽略，所以只需比最高次的"体量"。易错点：（1）"渐近线不能相交"是常见误解——曲线在**有限**区域完全可以穿过自己的水平渐近线，渐近只描述**远端**（x→±∞）的行为。（2）不是所有函数在无穷处都收敛，如 sin x 在 x→∞ 时来回震荡、无极限，也就没有水平渐近线。一个有界但非常数的收敛例子是 arctan：`lim_{x→∞} arctan x = π/2`（sympy 返回 `pi/2`），故 y = π/2 是其水平渐近线。这类"输出被压进有限区间"的饱和行为，正是 ML 里 sigmoid / tanh 等激活函数的数学原型（ML 承重佐证，Deisenroth 微积分章）。

### 1.4.2 函数值趋于无穷与竖直渐近线

另一种渐近来自函数值本身发散：当 x 从某一侧趋于有限点 a 时，若 f(x) 冲向 +∞ 或 −∞，就记作

    lim_{x→a⁺} f(x) = +∞   （或 −∞、或从左侧 a⁻）

此时直线 x = a 称为**竖直渐近线**——曲线在靠近 x = a 时沿竖直方向无限拉伸。它对应 1.3.2 的无穷间断点：竖直渐近线处函数必不连续。

竖直渐近线通常出现在"分母趋零而分子不趋零"的地方。最小例子 f(x) = 1/x 在 x = 0：

    lim_{x→0⁺} 1/x = +∞,   lim_{x→0⁻} 1/x = −∞

x = 0 是竖直渐近线，且两侧一个奔 +∞、一个奔 −∞。sympy 印证 `1/x` 右侧 `oo`、左侧 `-oo`。对数函数也给出单侧竖直渐近：`lim_{x→0⁺} ln x = −∞`（sympy 返回 `-oo`），故 y 轴 x = 0 是 ln x 的竖直渐近线。

关键区分（初学者高频混淆）：**水平渐近线是 x→∞ 时 f 趋于有限值**（描述远端高度），**竖直渐近线是 x→有限点时 f 趋于 ∞**（描述某处的爆发）——一个让 x 跑向无穷、一个让 y 跑向无穷，方向正好相反，别记反。易错点：分母为零并不必然产生竖直渐近线——若分子在该点也为零并可约分（如 (x²−1)/(x−1) 在 x=1），得到的是有限极限（可去间断），没有竖直渐近线。判断竖直渐近线的稳妥做法：先约分，再看该点单侧极限是否发散。

这里的"= +∞"是一种约定记法，表示"发散且无界地增大"，并**不**意味着极限"存在"为某个数——∞ 不是数。这与 1.1 里极限等于有限数 L 的"存在"含义不同，写法相似但语义要分清。渐近行为为大主题3的曲线作图提供了"骨架线"，也为大主题5的反常积分（在无穷区间或瑕点上积分）埋下伏笔。
