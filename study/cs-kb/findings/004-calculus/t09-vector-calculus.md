## 9.1 向量场与线积分

### 9.1.1 向量场

向量场（vector field）是把空间里**每一个点都对应到一个向量**的函数。平面上的向量场写作

    F(x, y) = P(x, y) i + Q(x, y) j

空间里的向量场写作

    F(x, y, z) = P i + Q j + R k

其中 P、Q、R 是普通的多元标量函数，i、j、k 是坐标方向的单位向量。它与前面学过的"标量函数"（每点给一个数，如温度分布）的区别在于：向量场每点给的是一个**带方向的箭头**。

直觉上，向量场就是"画满箭头的地图"：河面上每一点水流的速度与方向、房间里每一点的风、电荷周围每一点的电场力，都是向量场。最容易上手的一类向量场是**梯度场**：任取一个标量函数 f（比如高度、温度），它的梯度

    ∇f = (∂f/∂x) i + (∂f/∂y) j

在每一点给出"f 上升最快的方向"，于是 ∇f 本身就是一个向量场。梯度场在本大主题里格外重要，因为 9.1.3 会说明——正是这类场让线积分变得"路径无关"。

初学者易错点：不要把向量场 F 和它的"某个分量"混为一谈。F(x,y) 整体是一个向量，P 和 Q 各自只是它在 x、y 方向上的一个数值分量。画向量场时也别把箭头画成"从原点出发"——每个箭头的**起点就是它所在的那个点** (x,y)，箭头只表示该点处的方向和大小。

### 9.1.2 线积分

线积分（line integral，又称曲线积分）是把积分的"积分区域"从一段直线区间换成**一条弯曲的路径 C**。它有两种，初学者务必分清：

第一种是**对弧长的线积分**（标量场沿曲线积分），把标量函数 f 沿曲线累加：

    ∫_C f ds

其中 ds 是弧长微元。直觉是"沿着弯路走一遍，把脚下的 f 值按走过的路程加起来"——例如一根密度不均的细铁丝，∫_C ρ ds 就是它的总质量。

第二种、也是本大主题真正要用的，是**向量场沿曲线的线积分**（做功型）：

    ∫_C F · dr = ∫_C (P dx + Q dy)

它累加的是"向量场 F 在每一小段位移 dr 上的**切向分量**"。最直白的物理意义就是**功**：F 是力场，你沿路径 C 移动，F · dr 是每一小步力做的功，积分就是全程总功。

计算时统一靠**参数化**：把曲线写成 r(t) = (x(t), y(t))，t 从 a 到 b，则 dr = r′(t) dt，于是

    ∫_C F · dr = ∫_a^b F(r(t)) · r′(t) dt

把向量线积分化成一个普通的一元定积分来算。

一个最小例子（后面 Green 定理还会用到它）：取 F = (−y, x)，沿单位圆逆时针走一圈，参数化 x = cos t、y = sin t，t 从 0 到 2π，则

    ∫_C F · dr = ∫_0^{2π} [(−sin t)(−sin t) + (cos t)(cos t)] dt = ∫_0^{2π} 1 dt = 2π

sympy 直接算 `integrate((-sin(t))*(-sin(t)) + cos(t)*cos(t), (t, 0, 2*pi))` 返回 `2*pi`（基线 Py3.11.15/sympy1.14.0 @2026-07-26）。

易错点：向量线积分**依赖曲线的方向**。把 C 反过来走（从终点回到起点），∫_C F · dr 会变号；而对弧长的 ∫_C f ds 与方向无关（路程不会变负）。另一个常见错误是参数化后忘了代入 F 里的 x、y——F(r(t)) 必须把曲线上的 x(t)、y(t) 全部代进去，最后被积式里只能剩参数 t。

### 9.1.3 保守场与势函数

如果向量场 F 恰好是某个标量函数 f 的梯度，即

    F = ∇f

就称 F 为**保守场（conservative field）**，而 f 称为它的**势函数（potential function）**。保守场的决定性性质是**线积分的基本定理（梯度定理）**：

    ∫_C ∇f · dr = f(终点) − f(起点)

也就是说，保守场的线积分**只看起点和终点，与走哪条路径无关**；沿任意闭合回路走一圈，积分必为 0。

这正是主线心智模型在最低维度的体现：梯度 ∇f 是"F 的一种导数"，把它沿曲线（内部）积分，等于势函数 f 只在**边界（两个端点）**上的取值之差——和一维的 ∫ₐᵇ F′ dx = F(b) − F(a) 一模一样。物理直觉：重力、静电力都是保守场，把物体从 A 搬到 B 做的功只取决于高度差/电位差，你绕多大的圈子都不影响，回到原点净做功为零（不存在"永动机"）。

怎么判断一个场是不是保守场？在平面上，若 F = (P, Q) 在一个**单连通区域**（没有洞）上处处满足

    ∂P/∂y = ∂Q/∂x

则 F 是保守场。最小例子：F = (2xy, x²)，有 ∂P/∂y = 2x、∂Q/∂x = 2x，相等，故保守，其势函数为 f = x²y。sympy 验证 `diff(2*x*y, y)` 与 `diff(x**2, x)` 均返回 `2*x`，判定一致（基线 Py3.11.15/sympy1.14.0 @2026-07-26）。

初学者两个关键易错点：（1）**"单连通"这个条件不能丢**。经典反例是"涡旋场" F = (−y, x)/(x²+y²)，它在除原点外处处满足 ∂P/∂y = ∂Q/∂x，但区域挖掉了原点后不再单连通，沿绕原点一圈的闭合回路积分等于 2π ≠ 0，所以它**不是**保守场。判据 ∂P/∂y = ∂Q/∂x 只是"局部"必要条件，只有在无洞区域上才升级为充分条件。（2）势函数不唯一——加任意常数仍是势函数，正如不定积分差一个 +C。

## 9.2 Green 定理

### 9.2.1 Green 定理（环量/切向形式）

Green 定理把**平面上一条闭合曲线 C 上的向量线积分**，换算成**它所围区域 D 上的一个二重积分**。环量（切向）形式为

    ∮_C (P dx + Q dy) = ∬_D (∂Q/∂x − ∂P/∂y) dA

其中 C 取**逆时针**方向（正向：走时区域始终在你左手边），D 是 C 围出的平面区域。

这是主线心智模型第一次真正"升维"：等式右边 ∂Q/∂x − ∂P/∂y 是向量场 F=(P,Q) 的"二维旋度"（衡量该点处场的局部旋转强度），把它在区域**内部**积分，等于沿区域**边界**的环量（转一圈的总切向累加）。所有内部小旋转在相邻边界上两两抵消，只剩最外层边界的贡献——这就是为什么"内部积分 = 边界积分"。

最小例子直接复用 9.1.2 的 F=(−y, x)、D 为单位圆盘：右边被积式 ∂Q/∂x − ∂P/∂y = 1 − (−1) = 2，二重积分 = 2 × (圆盘面积 π) = 2π；左边我们已算出沿单位圆的环量正是 2π，两边吻合。sympy 校核旋度标量 `diff(x,x) - diff(-y,y) = 2`，且线积分 = `2*pi`（基线 Py3.11.15/sympy1.14.0 @2026-07-26）。一个实用推论：取 F 使 ∂Q/∂x − ∂P/∂y ≡ 1（如 F=(−y/2, x/2)），Green 定理就把"求面积"变成了"沿边界走一圈的线积分"，这正是机械式求积仪测面积的原理。

易错点：（1）**方向必须逆时针**，顺时针会整体差一个负号；若区域有洞（如圆环），内边界要取顺时针，保证"区域永远在前进方向左侧"。（2）P、Q 必须在**整个** D 上有连续偏导——若场在 D 内某点（如原点）奇异（回想 9.1.3 的涡旋场），不能直接套用，需把奇点挖掉单独处理。

### 9.2.2 Green 定理（通量/散度形式）

同一个 Green 定理还有等价的第二副面孔——**通量（散度）形式**，衡量的不是"沿边界转多少"，而是"穿过边界流出多少"：

    ∮_C F · n ds = ∬_D (∂P/∂x + ∂Q/∂y) dA

其中 n 是边界曲线 C 的**外法向单位向量**，F · n 是场垂直穿过边界的分量。右边被积式 ∂P/∂x + ∂Q/∂y 就是二维**散度**（衡量该点处"源/汇"的强弱：正表示往外冒、负表示往里吸）。

直觉：把 F 想成水流速度场，左边是"每单位时间净流出这块区域边界的总水量"，右边是"区域内部所有小源头/汇点的净产出总和"。二者当然相等——除非区域里凭空产生或消失水，否则流出边界的必然等于内部生产的。这就是散度形式，它是 9.4.2 Gauss 散度定理在二维的雏形，正如 9.2.1 的环量形式是 9.4.1 Stokes 定理在二维的雏形。

初学者关键关联：**Green 定理的两个形式其实是同一条定理换了个方向看**——把场 F=(P,Q) 旋转 90° 代入，环量形式就变成通量形式。记住"切向 → 旋度 → 环量"与"法向 → 散度 → 通量"这两条对应链，后面三维的 Stokes 与 Gauss 就是它们各自的三维版，不必重新记。

## 9.3 曲面积分与散度旋度

### 9.3.1 散度

散度（divergence）是作用在三维向量场 F=(P, Q, R) 上、输出一个**标量场**的微分算子：

    div F = ∇ · F = ∂P/∂x + ∂Q/∂y + ∂R/∂z

它衡量场在某一点处"向外发散/膨胀的强度"：div F > 0 表示该点是"源"（场往外冒，如水龙头），div F < 0 表示"汇"（场往里收，如下水口），div F = 0 表示该点无净源汇（不可压缩流动）。

直觉记法：散度是"点乘型"的导数——把符号 ∇ = (∂/∂x, ∂/∂y, ∂/∂z) 当成一个向量，与 F 做点积，得到一个数。最小例子：径向膨胀场 F = (x, y, z)，每点箭头都指向外、离原点越远越长，其散度

    div(x, y, z) = 1 + 1 + 1 = 3

处处为正，符合"处处向外膨胀"的图像。sympy `divergence(x*i+y*j+z*k)` 返回 `3`（基线 Py3.11.15/sympy1.14.0 @2026-07-26）。

### 9.3.2 旋度

旋度（curl）是作用在三维向量场上、输出一个**向量场**的微分算子：

    curl F = ∇ × F = (∂R/∂y − ∂Q/∂z) i + (∂P/∂z − ∂R/∂x) j + (∂Q/∂x − ∂P/∂y) k

它衡量场在某一点处"局部旋转的轴向与强度"：curl F 的方向是旋转轴（右手定则），大小是旋转的快慢。旋度为零向量的场称为**无旋场（irrotational）**。

直觉：把一个极小的桨轮放进流场里，桨轮自转的轴和转速就是该点的旋度。记法上旋度是"叉乘型"的导数——∇ × F。最小例子：F = (−y, x, 0)（绕 z 轴逆时针的旋转场，即 9.1.2 那个场推到三维），

    curl(−y, x, 0) = 2k

方向沿 +z 轴、大小为 2，恰好对应"绕 z 轴匀速旋转"。sympy `curl(-y*i+x*j)` 返回 `2*k`（基线 Py3.11.15/sympy1.14.0 @2026-07-26）。注意 9.2.1 里那个"二维旋度" ∂Q/∂x − ∂P/∂y 正是三维旋度的 k 分量，二者一脉相承。

两个必须记住的恒等式（它们把梯度、散度、旋度串起来，也是 9.4 各定理成立的幕后原因）：

    curl(grad f) = ∇ × (∇f) = 0        （梯度场必无旋）

    div(curl F) = ∇ · (∇ × F) = 0       （旋度场必无散）

sympy 对具体的 f、F 均验证这两式返回 `0`（基线 Py3.11.15/sympy1.14.0 @2026-07-26）。第一式解释了 9.1.3：保守场（=梯度场）必然无旋，这就是判据 ∂P/∂y=∂Q/∂x（即旋度为零）的来源。

易错点：别把散度和旋度搞混——**散度输入向量、输出标量（点乘 ∇·）；旋度输入向量、输出向量（叉乘 ∇×）**。梯度则是输入标量、输出向量（∇f）。三个算子的输入/输出类型各不相同，是最常见的混淆点。

### 9.3.3 曲面积分与通量

曲面积分（surface integral）把积分区域从平面区域升级为**三维空间里一张弯曲的曲面 S**。最重要的一类是**向量场穿过曲面的通量（flux）**：

    ∬_S F · dS = ∬_S F · n dA

其中 n 是曲面的单位法向量，F · n 是场垂直穿过曲面的分量。它度量"每单位时间有多少 F（水/电通量等）穿过这张曲面"，是 9.2.2 平面通量在三维弯曲曲面上的推广。

计算靠**参数化曲面** r(u,v)，法向量取两条参数切向量的叉积 r_u × r_v，把曲面积分化为参数区域上的二重积分。直觉：把弯曲曲面切成许多小平面片，每片近似为平行四边形（面积就是 |r_u × r_v| du dv），累加每片上"穿过的场量"。

易错点：曲面积分的通量**依赖法向的朝向**（哪一面算"正"）。封闭曲面（如球面）约定取**向外**的法向；开曲面则要与其边界曲线的方向按右手定则配套（这正是 9.4.1 Stokes 定理要求的相容定向）。朝向选反，通量整体变号。

## 9.4 Stokes 与 Gauss 定理

### 9.4.1 Stokes 定理

Stokes 定理是 Green 定理（环量形式）在三维弯曲曲面上的推广：**向量场沿一条空间闭合曲线 C 的环量，等于它的旋度穿过以 C 为边界的任意曲面 S 的通量**：

    ∮_C F · dr = ∬_S (curl F) · dS

其中 C 是曲面 S 的边界，方向与 S 的法向按右手定则相容（右手四指沿 C 方向，拇指指向 n）。

这是主线心智模型的三维版之一：把"导数"（这里是 curl F）在曲面**内部**积分，等于原场 F 只在曲面**边界曲线**上的环量。当曲面 S 恰好是平面区域时，Stokes 定理就退化回 9.2.1 的 Green 定理——所以 Green 是 Stokes 的平面特例。

关键直觉与推论：等式右边只依赖边界 C，与"绷在 C 上的是哪张曲面"无关——像一个铁丝环上可以绷出无数张肥皂膜，穿过每一张的旋度通量都相等。一个重要结论：若 F 处处无旋（curl F = 0），则沿任意闭合回路环量为 0，回到 9.1.3 的保守场（在单连通区域上无旋 ⇔ 保守）。

易错点：定向必须相容，右手定则反了会差一个负号；C 必须是 S 的**完整边界**（S 若有多个边界洞，要把所有边界一起算进 ∮_C）。

### 9.4.2 散度（Gauss）定理

散度定理（Divergence Theorem，又称 Gauss 定理）是 Green 定理（通量形式）在三维立体上的推广：**向量场穿出一个封闭曲面 S 的总通量，等于它的散度在 S 所围立体 E 上的三重积分**：

    ∯_S F · dS = ∭_E (div F) dV

其中 S 是立体 E 的边界曲面，法向取**向外**。

这是主线心智模型的另一个三维版：把"导数"（这里是 div F）在立体**内部**积分，等于原场只在立体**边界曲面**上的净通量。物理直觉最鲜明——右边是"立体内部所有源和汇的净产出"，左边是"净流出边界的总量"，二者必然相等（内部生产多少，就净流出多少）。

最小例子：径向场 F = (x, y, z)（div = 3，见 9.3.1）穿出半径 a 的球面。右边 = 3 × 球体积 = 3 · (4/3)πa³ = 4πa³；左边球面上 F·n = a（每点场沿半径向外、大小为 a），乘球面积 4πa²，也得 4πa³，两边吻合。

易错点：（1）S 必须**封闭**（完整包住 E），开曲面不能用散度定理。（2）法向必须朝外；朝内会差负号。（3）与 Stokes 混淆——**Stokes 连接"曲线环量 ↔ 曲面上旋度通量"，Gauss 连接"曲面通量 ↔ 立体内散度积分"**，一个降一维在旋度上、一个降一维在散度上，别套错。

### 9.4.3 统一视角

把本大主题四条定理并排看，会发现它们是**同一条"广义 Stokes 定理"在不同维度的复述**，都长成

    ∫_(区域内部) (某种导数) = ∫_(区域边界) (原来的量)

一维（FTC）：∫ₐᵇ F′ dx = F(b) − F(a)，区间内部对导数积分 = 0 维端点上的值差。
二维（Green）：区域内部对旋度/散度积分 = 1 维边界曲线上的环量/通量。
三维（Stokes）：曲面内部对旋度通量积分 = 1 维边界曲线上的环量；（Gauss）立体内部对散度积分 = 2 维边界曲面上的通量。

这就是为什么这套内容看似四个独立公式，其实只有一个思想。对 CS/ML 而言，这些定理的直接用武之地不多（主要落在电磁学、流体、计算机图形的光照/辐射度积分与物理仿真里）；ML 主线真正日常使用的是本课前面的梯度、雅可比、Hessian（大主题7）。因此本节讲清"定义 + 直觉 + 统一视角"即可，无需深入证明与微分形式的一般理论——记住"内部导数积分 = 边界取值"这条主线，比记住每个公式的每个下标更重要。
