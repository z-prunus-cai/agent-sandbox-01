## 6.1 数列与级数收敛

### 6.1.1 数列极限：无穷序列"趋向"一个数

数列（sequence）是按顺序排好的一串数 a₁, a₂, a₃, …，第 n 项记作 aₙ，可看成定义域为正整数的函数。若当 n 越来越大时 aₙ 无限接近某个定值 L，就说数列**收敛**到 L，记作：

    lim_{n→∞} aₙ = L

严格（ε 语言）说法是：对任意小的 ε > 0，都存在一个下标 N，使得只要 n > N 就有 |aₙ − L| < ε。若不存在这样的 L，就说数列**发散**。

这其实就是大主题1的函数极限"搬到整数点上"的离散版：函数极限让 x 连续地趋向某处，数列极限只让 n 跳着取 1,2,3,… 趋向无穷。ε-N 定义读法和 ε-δ 一样——"你说一个误差容忍度 ε，我总能给出一个门槛 N，越过门槛后每一项都落在 L 附近 ε 以内"。

最小例子：aₙ = 1/n 收敛到 0（n 越大越接近 0）；aₙ = (−1)ⁿ 在 −1 和 +1 之间反复横跳、不趋向任何单一值，发散；aₙ = n 冲向无穷，也发散。

易错点：（1）数列收敛只关心"尾巴"（大 n 的行为），前面有限项怎么样都不影响收敛与否。（2）"有界"不等于"收敛"——(−1)ⁿ 有界但发散；但一个**单调且有界**的数列必收敛（单调有界定理），这是后面很多判别法背后的靠山。（3）别把"数列 aₙ 的极限"和下一节"级数（数列求和）的极限"混为一谈，它们是两个不同的对象，6.1.3 会专门辨析。

### 6.1.2 级数与部分和：给"无穷个数相加"下定义

把数列的各项依次相加，就得到**无穷级数**：

    Σ_{n=1}^{∞} aₙ = a₁ + a₂ + a₃ + ⋯

"无穷个数相加"没有现成含义，我们用**部分和**来定义它：只加前 N 项得到第 N 个部分和

    S_N = Σ_{n=1}^{N} aₙ = a₁ + a₂ + ⋯ + a_N

再看部分和数列 {S_N} 的极限。若 lim_{N→∞} S_N = S 存在（是个有限数），就说级数**收敛**，并把这个极限 S 叫作级数的**和**；若极限不存在或为 ±∞，级数**发散**。

关键在于理解这是一个"两层"的极限游戏：先把无穷求和"截断"成有限的部分和（这一步永远能算），再对截断长度取极限。所以"级数的和"本质是"部分和数列的极限"，级数收敛问题就被翻译回了 6.1.1 的数列极限问题。

一条最省力的**必要条件（发散判别法/n 项判别法）**：

    若 Σ aₙ 收敛，则必有 lim_{n→∞} aₙ = 0

反过来用它的逆否命题：**若通项 aₙ 不趋于 0，级数一定发散**。这是开工第一眼就该做的检查。但务必记住它**只能判发散、不能判收敛**——通项趋于 0 只是必要条件，远不充分：调和级数 Σ1/n 的通项 1/n → 0，级数却发散（见 6.1.4）。初学者最常见的错误就是看到"通项趋于 0"就断定收敛，这是错的。

### 6.1.3 几何级数：唯一能直接求出和的基本级数

各项之比为常数 r 的级数叫**几何级数**（等比级数）。以 a 为首项、从 n=0 记：

    Σ_{n=0}^{∞} a·rⁿ = a + ar + ar² + ⋯

它的收敛判据和求和公式都极其干净：

    当 |r| < 1 时收敛，和为  a/(1 − r)；当 |r| ≥ 1 时发散

几何级数是整个级数理论里少数能**直接算出和**的级数，也是比较判别法、幂级数收敛半径的"标尺"，务必背熟。

为什么是 a/(1−r)？看部分和 S_N = a + ar + ⋯ + ar^{N−1}，两边乘 r 再相减可得 S_N = a(1−r^N)/(1−r)。当 |r|<1 时 r^N → 0，于是 S_N → a/(1−r)；当 |r|≥1 时 r^N 不趋于 0（通项都不趋于 0），发散。最小例子：Σ_{n=0}^∞ (1/2)ⁿ = 1/(1−1/2) = 2（sympy 实算 = 2，见报告末）；Σ_{n=0}^∞ (1/3)ⁿ = 1/(1−1/3) = 3/2（sympy = 3/2）。

易错点：（1）求和公式对**起始下标**敏感——a/(1−r) 是"从 n=0、首项为 a"时的和；若从 n=1 开始，首项变成 ar，和是 ar/(1−r)。套公式前先认清首项到底是谁。（2）|r|=1 也发散（r=1 时是 a+a+a+…，r=−1 时在 a、0 间横跳）。

### 6.1.4 p 级数：判断收敛的另一把标尺

形如下式的级数叫 **p 级数**（p 为正实数常数）：

    Σ_{n=1}^{∞} 1/n^p

它的收敛判据是一条必须记牢的基准结论：

    当 p > 1 时收敛；当 p ≤ 1 时发散

特别地 p = 1 的 Σ 1/n 叫**调和级数**，它发散——这是最著名的"通项趋于 0 却发散"的反例。

p 级数和几何级数是两把最常用的"比较标尺"：拿到一个陌生级数，通常先看它长得像几何级数还是像 p 级数，再用比较判别法（6.2）靠过去。p 级数收敛与否可用积分判别法（6.2.4）严格证明：Σ1/n^p 的敛散和反常积分 ∫₁^∞ 1/x^p dx 完全同步，而后者恰在 p>1 时收敛（这与大主题5反常积分的结论一致，两处同源）。

直觉上体会 p=1 这个临界点：p 越大，1/n^p 衰减越快、越容易收敛；调和级数 1/n 衰减"刚好太慢"——虽然每项趋于 0，但加得不够快，部分和会缓慢地爬向无穷。最小例子：Σ1/n² = π²/6 ≈ 1.6449（p=2>1，收敛，即著名的 Basel 问题，sympy 实算 = pi²/6）；Σ1/n 发散（sympy 返回 oo）。

易错点：（1）p 级数要求分母是 n 的**幂**，n^p；像 Σ1/(n·ln n) 这种带对数的不是 p 级数，需另用积分判别法（它其实也发散）。（2）临界点 p=1 归入**发散**一侧，别记反。（3）p 级数只在 p>0 时才谈得上"通项趋于 0"，p≤0 时通项不趋于 0，由 6.1.2 的必要条件直接发散。

## 6.2 收敛判别法

### 6.2.1 比较判别法：拿已知级数当尺子

对**正项级数**（所有 aₙ ≥ 0），比较判别法用一个已知敛散的级数去"夹"待判级数。设 0 ≤ aₙ ≤ bₙ（对足够大的 n 成立），则：

    若 Σ bₙ 收敛，则 Σ aₙ 收敛；若 Σ aₙ 发散，则 Σ bₙ 发散

直觉极朴素："更小的正项级数被更大的收敛级数压住，也必收敛；更大的被更小的发散级数顶着，也必发散。"用法就是把待判级数和几何级数或 p 级数（6.1 那两把尺子）比大小。

实践中更好用的是**极限比较判别法**：若 aₙ, bₙ 均为正且

    lim_{n→∞} aₙ/bₙ = c，其中 0 < c < ∞

则 Σ aₙ 与 Σ bₙ **同敛同散**。它省去了逐项证不等式的麻烦，只需看两个通项在 n→∞ 时"同阶"。最小例子：判 Σ 1/(n²+1)，取 bₙ = 1/n²（p=2 收敛），比值 (1/(n²+1))/(1/n²) = n²/(n²+1) → 1，故 Σ1/(n²+1) 也收敛。

易错点：（1）比较判别法**只对正项级数**成立——有负项时"大小压制"的逻辑失效，得改用绝对收敛或交错级数判别法。（2）方向别用反：小的收敛推不出大的收敛，大的发散推不出小的发散。（3）挑标尺 bₙ 时看 aₙ 的"主导阶"——分式取分子分母最高次幂之比。

### 6.2.2 比值判别法：看相邻两项之比

比值判别法（ratio test）用相邻项之比的极限来判断。设

    L = lim_{n→∞} |a_{n+1} / aₙ|

则：

    L < 1 时级数（绝对）收敛；L > 1（含 L=∞）时发散；L = 1 时判别法失效、需换工具

它背后的思想是"把级数近似看成公比为 L 的几何级数"：相邻项之比趋于 L，若 L<1 则尾部像收敛的几何级数一样几何式衰减。比值判别法**对含阶乘 n!、指数 rⁿ 的通项特别好用**，因为这类项相除会大幅化简。

最小例子：判 Σ n/2ⁿ，比值 = [(n+1)/2^{n+1}]/[n/2ⁿ] = (n+1)/(2n) → 1/2 < 1，收敛（sympy 实算此级数和 = 2）；判 Σ 1/n!，比值 = n!/(n+1)! = 1/(n+1) → 0 < 1，收敛（这正是 eˣ 展开在 x=1 处收敛的原因）。

易错点：**L = 1 是无信息状态**，此时既不能判收敛也不能判发散，必须换别的方法——例如所有 p 级数比值极限都是 1，比值判别法对它们一律失效，只能靠 p>1 判据或积分判别法。初学者常在 L=1 时强行下结论，这是典型错误。

### 6.2.3 根值判别法：看通项的 n 次根

根值判别法（root test）适用于通项本身是"n 次幂"结构的级数。设

    L = lim_{n→∞} |aₙ|^{1/n}

判据与比值判别法完全相同：

    L < 1 收敛；L > 1（含 ∞）发散；L = 1 失效

它和比值判别法是"近亲"（都在与几何级数比较），但当通项形如 (…)ⁿ 时开 n 次根会直接消掉指数，比算相邻项之比更省力。最小例子：判 Σ (n/(2n+1))ⁿ，取 n 次根得 n/(2n+1) → 1/2 < 1，收敛。

易错点：（1）L=1 同样失效（与比值判别法一致）。（2）根值判别法通常比比值判别法"更强一点"（比值失效时根值有时仍可用），但对含阶乘的项远不如比值判别法方便——选工具看通项长相：阶乘/指数选比值，整体 n 次幂选根值。

### 6.2.4 积分判别法：级数与反常积分同敛散

若 f 在 [1, ∞) 上**连续、正、单调递减**，且 aₙ = f(n)，则级数与反常积分同敛同散：

    Σ_{n=1}^{∞} aₙ 收敛  ⟺  ∫_{1}^{∞} f(x) dx 收敛

直觉是把级数看成"用矩形逼近曲线下面积"：每一项 aₙ = f(n) 是一个高 f(n)、宽 1 的矩形面积，级数就是这些矩形面积之和，而积分是曲线下的真实面积——单调递减保证矩形和与积分被此消彼长地夹住，于是二者要么同时有限、要么同时无穷。这也是 6.1.4 中 p 级数判据的严格来源：Σ1/n^p 与 ∫₁^∞ x^{−p} dx 同步，后者在 p>1 时收敛（大主题5反常积分结论），故 p 级数在 p>1 时收敛。

易错点：（1）三个前提（连续、正、递减）缺一不可，尤其"递减"——若 f 不单调，矩形与积分的夹逼关系断裂。（2）积分判别法只判**敛散**，级数的和一般**不等于**那个积分值（矩形和 ≠ 曲线下面积），别把 ∫ 的值当成级数和。（3）它要求能算出（或至少能判定）那个反常积分，故只在 f 容易积分时才划算。

### 6.2.5 交错级数与条件收敛：本节最大的易错点

正负号交替出现的级数叫**交错级数**，形如 Σ(−1)ⁿ bₙ（bₙ > 0）。**交错级数判别法（莱布尼茨判别法）**：若 bₙ 单调递减且 lim bₙ = 0，则交错级数收敛。

要判断"是真的稳当收敛还是靠正负抵消才收敛"，引入两个层级的概念：

    绝对收敛：Σ|aₙ| 收敛（取绝对值后仍收敛）

    条件收敛：Σaₙ 收敛，但 Σ|aₙ| 发散（去掉符号就发散，纯靠正负抵消）

绝对收敛是"强收敛"，一定蕴含级数本身收敛；条件收敛是"弱收敛"，只在保留正负号时勉强成立。

**⚠ 条件收敛是本大主题头号易错点，务必讲透。**经典标本是**交错调和级数**：

    Σ_{n=1}^{∞} (−1)^{n+1}/n = 1 − 1/2 + 1/3 − 1/4 + ⋯ = ln 2

它收敛（由莱布尼茨判别法：1/n 递减趋 0），和为 ln 2 ≈ 0.6931（sympy 实算 = log(2)）；但把符号去掉就成了调和级数 Σ1/n，发散。所以它是**条件收敛**——收敛完全依赖正负项的相互抵消，而非项本身"加得够快"。

为什么这件事危险？因为条件收敛级数有一个反直觉性质（黎曼重排定理）：**重新排列各项的顺序，可以让它收敛到任意指定的数，甚至发散**。也就是说条件收敛级数的"和"不满足我们熟悉的加法交换律。绝对收敛级数则安全——任意重排都不改变和。初学者最常犯的两个错：（1）看到交错级数收敛就以为"收敛得很好"，忽略它可能只是条件收敛；（2）对条件收敛级数随意交换项的顺序或拆项重组，得到错误的和。判断流程应是：先查 Σ|aₙ| 是否收敛（绝对收敛，最安全）；若不收敛，再用莱布尼茨判别法看原级数是否条件收敛。

## 6.3 幂级数

### 6.3.1 幂级数：系数带 x 的"无穷次多项式"

把常数项级数的每一项乘上 x（或 x−a）的幂，就得到**幂级数**。以 a 为中心（展开点）：

    Σ_{n=0}^{∞} cₙ (x − a)ⁿ = c₀ + c₁(x−a) + c₂(x−a)² + ⋯

其中 cₙ 是常数系数。a=0 时简化为

    Σ_{n=0}^{∞} cₙ xⁿ = c₀ + c₁x + c₂x² + ⋯

关键转变：常数项级数收敛就是收敛、发散就是发散，是个"是非题"；而幂级数里含变量 x，**代入不同的 x，得到不同的常数项级数，敛散可能不同**。所以幂级数不是一个数，而是一个**函数**——它的定义域正是使级数收敛的那些 x。可以把幂级数理解成"无穷次多项式"：项数无穷，但只在某个 x 范围内"合法"（收敛）。

最小例子：Σ_{n=0}^∞ xⁿ 就是公比为 x 的几何级数，由 6.1.3 知它在 |x|<1 时收敛且

    Σ_{n=0}^{∞} xⁿ = 1/(1 − x)   （仅当 |x| < 1）

这条式子是理解幂级数的原型：左边是无穷级数（函数），右边是它在收敛范围内代表的初等函数。

### 6.3.2 收敛半径与收敛区间

对每个幂级数 Σcₙ(x−a)ⁿ，恰好存在一个 **收敛半径** R（0 ≤ R ≤ ∞），使得：

    |x − a| < R 时（绝对）收敛；|x − a| > R 时发散；|x − a| = R（两个端点）需逐个单独判定

由此得到的收敛 x 的全体叫**收敛区间**。三种情形：R=0（只在 x=a 一点收敛）、R=∞（对所有 x 收敛）、0<R<∞（在以 a 为中心、半径 R 的开区间内收敛，两端点另判）。

求 R 最常用的是对幂级数套**比值判别法**（或根值判别法）：令

    1/R = lim_{n→∞} |c_{n+1} / cₙ|   （或  1/R = lim_{n→∞} |cₙ|^{1/n}）

直觉上，收敛半径就是"x 离中心 a 多远以内，这个无穷次多项式还稳得住"。最小例子：Σxⁿ 系数全为 1，1/R = lim|1/1| = 1，故 R=1，与几何级数 |x|<1 一致；Σxⁿ/n! 的 1/R = lim (n!/(n+1)!) = lim 1/(n+1) = 0，故 R=∞（eˣ 的展开对所有 x 收敛，见 6.4）。

易错点：（1）**端点必须单独查**——比值/根值判别法在 |x−a|=R 时给出 L=1，正是失效状态，得把两个端点分别代入变成常数项级数再用别的判别法（常出现交错级数或 p 级数）。收敛区间因此可能是开、半开或闭区间。（2）收敛半径内是**绝对收敛**，这保证了幂级数在区间内可以像多项式一样逐项求导、逐项积分（这是 6.4 的技术支撑）。（3）R 的两个公式取的是极限，若极限不存在需用更一般的上极限形式（本课不展开，讲到会用即可）。

## 6.4 泰勒展开

### 6.4.1 泰勒级数与麦克劳林级数：用各阶导数造幂级数

若函数 f 在点 a 处有各阶导数，它在 a 处的**泰勒级数**（Taylor series）是这样一个幂级数：

    f(x) = Σ_{n=0}^{∞} f⁽ⁿ⁾(a)/n! · (x − a)ⁿ

展开写出前几项：

    f(x) = f(a) + f′(a)(x−a) + f″(a)/2!·(x−a)² + f‴(a)/3!·(x−a)³ + ⋯

当展开点取 a = 0 时，特称为**麦克劳林级数**（Maclaurin series）：

    f(x) = Σ_{n=0}^{∞} f⁽ⁿ⁾(0)/n! · xⁿ

核心思想是"用一个多项式在某点处模仿函数的全部局部信息"：常数项对齐函数值 f(a)，一次项对齐斜率 f′(a)，二次项对齐弯曲程度 f″(a)……每加一阶导数，多项式就在 a 附近多贴合函数一层。系数里的 n! 正是为了让求 n 次导后能精确还原出 f⁽ⁿ⁾(a)（因为 (xⁿ)⁽ⁿ⁾ = n!，除以 n! 才配平）。

几个必须记熟的麦克劳林展开（均 sympy 实算复现，见报告末）：

    eˣ = 1 + x + x²/2! + x³/3! + ⋯       （对所有 x 收敛，R=∞）

    sin x = x − x³/3! + x⁵/5! − x⁷/7! + ⋯   （R=∞）

    cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + ⋯   （R=∞）

    ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + ⋯   （−1 < x ≤ 1）

    1/(1−x) = 1 + x + x² + x³ + ⋯          （|x| < 1）

易错点：（1）泰勒级数是"在 a 附近"的展开，离 a 越远精度越差，且只在收敛半径内有效——ln(1+x)、1/(1−x) 的 R 只有 1，代入 x=2 展开式会发散、给出无意义结果。（2）"f 有泰勒级数"和"泰勒级数收敛到 f 本身"是两回事：极少数病态函数（如 f(x)=e^{−1/x²}，f(0)=0）各阶导在 0 全为 0，泰勒级数恒等于 0，却不等于 f——只有当余项趋于 0 时（见 6.4.2）级数才真正等于 f，本课遇到的初等函数都满足。（3）别背混 sin/cos 的符号与奇偶：sin 是奇函数只含奇次幂、cos 是偶函数只含偶次幂。

### 6.4.2 泰勒余项与多项式逼近

实用中我们只取有限项——前 n 阶的**泰勒多项式** Tₙ(x) 作为 f 的近似，误差由**余项** Rₙ(x) = f(x) − Tₙ(x) 刻画。最常用的**拉格朗日型余项**给出误差的显式形式：

    Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (x − a)ⁿ⁺¹

其中 ξ 是介于 a 与 x 之间的某个（未知具体位置的）点。若在该区间上 |f⁽ⁿ⁺¹⁾| ≤ M 有界，就得到误差上界

    |Rₙ(x)| ≤ M/(n+1)! · |x − a|ⁿ⁺¹

这条式子回答了"用 n 次多项式近似，误差最多多大""要保证精度需取几阶"这两个工程问题。

拉格朗日余项是拉格朗日中值定理（大主题3）的推广：n=0 时它退化为 f(x) = f(a) + f′(ξ)(x−a)，正是中值定理。直觉是"截断后剩下的尾巴，可以浓缩成'下一阶导数在中间某点的值'乘上对应的幂次项"。随着 n 增大，分母 (n+1)! 阶乘式地爆炸增长，只要 f 的高阶导数别涨得比阶乘还快（初等函数都满足），误差就飞快趋于 0——这正是泰勒多项式能高精度逼近的根本原因，也是"多加一项、精度大增"的来源。

最小例子：用麦克劳林多项式估 e（即 eˣ 在 x=1）。取到 x⁴ 项（0 到 4 阶）：1+1+1/2+1/6+1/24 = 65/24 ≈ 2.70833，真值 e ≈ 2.71828（sympy/math 实算），已相当接近；再加几项会更准。误差可用余项 |R₄(1)| ≤ e^ξ/5!·1 < 3/120 = 0.025 估上界，与实际误差 ≈ 0.00995 吻合（实际误差小于上界，符合预期）。

这一节直接喂下游：**用低次泰勒多项式近似复杂函数**，是数值计算和 ML 的通用手段——例如把 sigmoid、tanh、exp 等激活函数在某点做泰勒近似以加速或分析（喂 L6-06 数值近似/激活函数近似，点明接口）；牛顿法（优化）本质是用二阶泰勒展开近似目标函数再求极小。易错点：（1）拉格朗日余项里的 ξ **位置未知**，只用于估上界，不能当作能精确求出的点。（2）逼近只在收敛半径内、且离展开点近时才准；远离 a 时低阶多项式误差迅速变大。（3）阶数 n 与"导数阶 n+1"要对齐——Tₙ 用到 0 到 n 阶导，其余项含 n+1 阶导，套公式时别把阶数错位。
