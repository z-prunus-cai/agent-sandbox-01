## 3.1 极值与最优化

### 3.1.1 临界点（critical point）

**临界点**指函数 f 定义域内、使 f'(c) = 0 或 f'(c) 不存在的点 c。它是"函数可能取到局部极值的候选位置"的集合。

    f'(c) = 0  或  f'(c) 不存在  ⟹  c 是临界点

临界点为什么重要？因为在一个函数图像上，"山顶"和"谷底"这类局部极值点，切线要么是水平的（斜率为 0），要么根本画不出切线（导数不存在，如尖点）。所以想找极值，第一步不是盲目扫描整条曲线，而是**先把临界点这一小撮候选揪出来**，再逐个判定。这套"先找候选、再判定"的思路，贯穿整个 3.1。

最小例子：

    f(x) = x³ − 3x，f'(x) = 3x² − 3 = 0 ⟹ x = −1 或 x = 1

这两个就是全部临界点。sympy 求解得 `[-1, 1]`（脚本见文末），x = −1 处是局部极大、x = 1 处是局部极小。

初学者最常见的两个误区：第一，**临界点不一定是极值点**。反例 f(x) = x³，f'(0) = 0，但 x = 0 处既非极大也非极小（曲线只是"拐了个平"就继续上升），这类点后面 3.3 会讲到是拐点。第二，**别忘了"导数不存在"的那一类**。f(x) = |x| 在 x = 0 处导数不存在，却是全局最小值点；只盯着 f'=0 会漏掉它。

### 3.1.2 费马定理：内部极值的必要条件

**费马定理（Fermat's Theorem）**：若 f 在内点 c 取得局部极值，且 f'(c) 存在，则必有

    f'(c) = 0

它说的是"内部局部极值 ⟹ 导数为零（若可导）"这个**单向**结论，正是 3.1.1 里"极值点必在临界点中"的理论依据。

要抓住三个限定词，否则很容易用反：一是"**内点**"——区间端点上的极值不受此约束（端点处函数可能在极值却 f'≠0，例如 f(x)=x 在 [0,1] 上最大值在 x=1，但 f'=1≠0）；二是"**若可导**"——不可导的极值点（如 |x| 的尖点）不在此定理管辖内；三是"**必要不充分**"——反过来 f'(c)=0 推不出 c 是极值（x³ 的例子）。

一句话记法：费马定理只负责"把候选缩小到临界点"，不负责"确认候选是不是真极值"。确认要靠 3.1.3 / 3.1.4 的判定法。

### 3.1.3 一阶导数判定法（First Derivative Test）

设 c 是 f 的临界点、f 在 c 附近连续，考察 f' 在 c 两侧的符号变化：

    f' 由正变负（+ → −）：c 处取局部极大

    f' 由负变正（− → +）：c 处取局部极小

    f' 两侧同号（不变号）：c 处非极值

直觉极其朴素：f'>0 表示函数在上升、f'<0 表示在下降。如果走到 c 之前一路上升、过了 c 就开始下降，那 c 自然是个"山顶"（局部极大）；反之是"谷底"。符号不变（比如一直上升只是中途斜率短暂归零），就只是走势平了一下，不构成极值。

最小例子：还用 f(x) = x³ − 3x，f'(x) = 3(x−1)(x+1)。在 x = −1 左侧（如 x=−2）f'=9>0、右侧（如 x=0）f'=−3<0，故 x=−1 是局部极大；x=1 处符号由负变正，是局部极小。

一阶判定法的**优点**是普适：不管 f''是否存在、临界点是不是尖点，只要能判断 f' 两侧符号就能用。它比 3.1.4 的二阶判定法适用面更广，代价是要分析两侧符号而非代一个点。

### 3.1.4 二阶导数判定法（Second Derivative Test）

设 f'(c) = 0 且 f''(c) 存在，则

    f''(c) > 0 ⟹ c 处局部极小

    f''(c) < 0 ⟹ c 处局部极大

    f''(c) = 0 ⟹ 判定失效，需改用一阶判定法

f''>0 意味着曲线在 c 附近"开口朝上"（凹，像一只碗），临界点自然落在碗底 = 极小；f''<0 开口朝下（凸，像一座山），临界点在山顶 = 极大。它比一阶判定法省事——只要在临界点代一个二阶导数的值即可，不用分析两侧。

最小例子：f(x) = x³ − 3x，f''(x) = 6x。代入临界点：f''(−1) = −6 < 0（局部极大），f''(1) = 6 > 0（局部极小），与 3.1.3 结论一致；sympy 验证输出 `x=-1 f''=-6 -> max`、`x=1 f''=6 -> min`。

关键易错点：**f''(c)=0 时二阶判定法什么也说不了**，既可能是极大、极小，也可能不是极值。三个经典反例都满足 f'(0)=f''(0)=0：x⁴ 在 0 处是极小、−x⁴ 是极大、x³ 不是极值。这三个只能靠一阶判定法或直接观察区分。所以遇到 f''(c)=0，不要硬判，退回一阶判定法。

### 3.1.5 闭区间上的最大最小值：极值定理与"闭区间法"

**极值定理（Extreme Value Theorem）**：若 f 在闭区间 [a, b] 上连续，则 f 必在 [a, b] 上取到全局（绝对）最大值和最小值。求这两个值的标准流程称为"闭区间法"：

    候选点 = { [a,b] 内部的所有临界点 } ∪ { 两个端点 a, b }
    分别代入 f，比较函数值，最大者即绝对最大、最小者即绝对最小

注意区分两组概念：局部（相对）极值是"跟邻近点比"的山顶谷底，全局（绝对）极值是"整个区间里最高/最低"。3.1.1–3.1.4 处理的是局部极值；这里处理全局极值。

为什么要单独把端点列为候选？因为费马定理只管内点，全局最值完全可能发生在端点。例如 f(x)=x 在 [0,3] 上没有内部临界点，最大值 3、最小值 0 全在端点取得——只找临界点会一无所获。

极值定理的**两个前提缺一不可**：闭区间 + 连续。开区间 (0,1) 上的 f(x)=x 取不到最大值（越靠近 1 越大但够不着 1）；闭区间上有间断点的函数也可能取不到最值。这两个前提是很多初学者写证明时漏掉的坑。

### 3.1.6 最优化应用问题（并接无约束优化的一/二阶条件）

**最优化**就是把实际问题（成本最小、面积最大、用料最省……）翻译成一个目标函数，再用 3.1.1–3.1.5 的机器求它的极值。标准步骤：设变量 → 写出目标函数并用约束消元到单变量 → 求导找临界点 → 判定并结合定义域端点确定全局最优。

最小例子（周长固定、面积最大的矩形）：设宽 w、周长固定为 20，则长 = 10 − w，面积

    A(w) = w(10 − w)，w ∈ (0, 10)

A'(w) = 10 − 2w = 0 ⟹ w = 5，此时 A = 25（正方形面积最大）。sympy 求解输出 `optimal w: [5]  A=[25]`。

这一小节是本大主题喂给下游最重要的接口。把"求 f'=0 的临界点、再用 f''>0/<0 判定"推广到多变量，就是机器学习训练里的**无约束优化的一阶/二阶最优性条件**：一阶必要条件"梯度为零"（∇f = 0）正是单变量 f'=0 的直接推广，二阶条件"Hessian 正定 ⟹ 局部极小"正是 f''>0 的推广（多变量展开归大主题7 与后续优化课，此处只点明这条脉络，不纵深）。理解本节"临界点 + 二阶判定"的单变量原型，是读懂梯度下降为何朝 −∇f 方向走、以及"驻点不一定是极小"的地基。

一个实用易错点：应用题里**别忘了检查定义域端点和物理约束**。上例 w 必须落在 (0,10) 且为正；很多题的最优点恰在约束边界而非内部临界点上，直接套 f'=0 会答错。

## 3.2 中值定理

### 3.2.1 Rolle 定理

**Rolle 定理**：若 f 满足三个条件——(1) 在闭区间 [a, b] 上连续、(2) 在开区间 (a, b) 上可导、(3) 两端点函数值相等 f(a) = f(b)，则至少存在一点 c ∈ (a, b) 使

    f'(c) = 0

几何直觉一句话：如果一条光滑连续的曲线在起点和终点等高，那么中间必定至少有一处切线是水平的（爬上去总得下来，转折处斜率归零）。它是"存在性"定理——只保证有这样的 c、不告诉你具体在哪、也不排除有多个。

最小例子：f(x) = x² − 2x 在 [0, 2] 上，f(0) = 0 = f(2)（满足端点等值），f'(x) = 2x − 2 = 0 ⟹ c = 1 ∈ (0,2)。sympy 验证 `f(0),f(2): 0 0`、`f'(c)=0 at c:[1]`。

三个条件都是"绑住反例"用的，缺哪个都可能失效。经典反例 f(x) = |x| 在 [−1, 1]：端点等值、连续，但在 0 处不可导，结论就不成立（图像是个 V 形，处处斜率非零）。Rolle 定理是下面拉格朗日中值定理的特例（把"端点等高"这个特殊情形一般化，就得到拉格朗日）。

### 3.2.2 拉格朗日中值定理（Mean Value Theorem, MVT）

**拉格朗日中值定理**：若 f 在 [a, b] 上连续、在 (a, b) 上可导，则至少存在一点 c ∈ (a, b) 使

    f'(c) = (f(b) − f(a)) / (b − a)

也即：**瞬时变化率（某点切线斜率）一定在某处等于整段的平均变化率（割线斜率）**。

直觉最好用开车理解：一段路程你的平均速度是 60 km/h，那么途中至少有某一瞬间，你的仪表盘速度恰好是 60 km/h——不可能全程都严格快于或慢于平均值。这里 (f(b)−f(a))/(b−a) 就是平均速度（割线斜率），f'(c) 就是那一瞬间的仪表速度（切线斜率），MVT 保证两者必有相等的时刻。几何上就是：割线 AB 平移后，一定能与曲线某处相切。

最小例子：f(x) = x³ 在 [0, 2]，割线斜率 = (8 − 0)/(2 − 0) = 4，令 f'(x) = 3x² = 4 得 c = 2/√3 ≈ 1.155 ∈ (0, 2)。sympy 输出 `slope: 4`、落在区间内的解 `2*sqrt(3)/3 ≈ 1.1547`（另一根 −2/√3 在区间外舍去）。

MVT 是本大主题的"证明发动机"，很多看似显然的结论其实都靠它才严格成立。最重要的一条：

    若在区间上处处 f'(x) > 0，则 f 在该区间严格递增（f' < 0 则递增改为递减）

这正是 3.3.1 单调性判据的理论根据。另一条推论：若处处 f'(x) = 0，则 f 在该区间为常数（两点间用 MVT，斜率必为 0 ⟹ 函数值不变）——这又是不定积分"原函数只差一个常数"的依据（见大主题4）。理解 MVT 是把"局部导数信息"翻译成"整体单调性/整体行为"的桥梁，是初学者常忽视其分量的关键定理。

### 3.2.3 中值定理的推论与关联

由 MVT 直接派生的常用结论汇总（都以"导数符号 ⟹ 整体行为"为形式）：

    f' > 0（区间内）⟹ 严格递增
    f' < 0（区间内）⟹ 严格递减
    f' = 0（区间内）⟹ 恒为常数
    f' = g'（区间内）⟹ f − g 为常数

这些推论把"逐点的导数"提升为"整段的走势"，是连接 3.1（极值）、3.3（作图）乃至大主题4（积分中"原函数差一常数"）的公共支点。

一个概念澄清：Rolle 是 MVT 在 f(a)=f(b) 时的特例，而 MVT 又可进一步推广为柯西中值定理（两个函数之比的版本），后者正是 3.4 洛必达法则的证明基础。所以三者是"Rolle ⊂ 拉格朗日 ⊂ 柯西"的层层一般化关系；本课只要求掌握前两者、了解柯西作为洛必达的地基即可，不做纵深推导。

## 3.3 曲线作图与相关变化率

### 3.3.1 单调性（增减区间）

**单调性判据**：在某区间上，

    f'(x) > 0 ⟹ f 在该区间递增（上升）

    f'(x) < 0 ⟹ f 在该区间递减（下降）

它把"求增减区间"这件事变成"解一个关于 f' 的不等式"。做法：先求出所有临界点，用它们把定义域切成若干小段，再在每段里取一个测试点判断 f' 的正负，即得该段是增是减。

最小例子：f(x) = x³ − 3x，f'(x) = 3(x−1)(x+1)。临界点 ±1 把数轴分成三段，判号得递增区间为 (−∞, −1) 和 (1, +∞)、递减区间为 (−1, 1)。sympy 解不等式 f'>0 输出 `Union(Interval.open(-oo,-1), Interval.open(1,oo))`，与手算一致。

这条判据的严格性由 3.2 的 MVT 保证（f'>0 ⟹ 递增并非"显然"，而是 MVT 的推论）。一个易错点：判据给的是"充分条件"——f'>0 保证递增，但递增不一定处处 f'>0（f(x)=x³ 整体递增，却在 0 处 f'=0）。所以严格递增允许导数在孤立点处为零。

### 3.3.2 凹凸性（concavity）

**凹凸性判据**由二阶导数的符号给出：

    f''(x) > 0 ⟹ 曲线在该区间下凹（concave up，开口朝上，形如 ∪）

    f''(x) < 0 ⟹ 曲线在该区间上凸（concave down，开口朝下，形如 ∩）

f'' 是"斜率的变化率"。f''>0 表示斜率在不断增大（哪怕函数在下降，下降也在变缓、终将转升），图像像一只碗兜着；f''<0 表示斜率在减小，图像像一座拱。等价的几何说法：下凹时曲线位于其切线上方、上凸时位于切线下方。

最小例子：f(x) = x³，f''(x) = 6x。x < 0 时 f''<0 上凸、x > 0 时 f''>0 下凹。

术语易混提醒：中文"凹/凸"在不同教材里指向相反，务必以 **f''的符号 + 英文 concave up/down** 为准，别只认"凹凸"二字。本报告统一采用"f''>0 = 下凹 = concave up = ∪ 形"这一 Stewart/通行约定。凹凸性单独看没什么用，它真正的价值是与单调性叠加画出曲线形状，以及支撑 3.1.4 的二阶判定法（碗底是极小、拱顶是极大）。

### 3.3.3 拐点（inflection point）

**拐点**是曲线上凹凸性发生改变的点——即 f'' 由正变负或由负变正、符号真正翻转的地方。

    f''(c) = 0 或 f''(c) 不存在，且 f'' 在 c 两侧变号 ⟹ c 是拐点

最小例子：f(x) = x³，f''(x) = 6x = 0 ⟹ x = 0；且 f'' 在 0 左负右正、确实变号，故 (0,0) 是拐点。sympy 求 `f''=6*x`、`inflection at:[0]`。

最关键的易错点：**f''(c)=0 只是拐点的"候选条件"，不是充分条件**。必须验证 f'' 在 c 两侧真的变号才算拐点。反例 f(x) = x⁴，f''(x) = 12x²，在 x=0 处 f''=0，但 x=0 两侧 f''都 ≥ 0（不变号），所以 x=0 不是拐点（它是极小点，曲线始终下凹）。这与 3.1.3 里"临界点要看 f' 变号"完全对偶：找极值看 f' 变号，找拐点看 f'' 变号。

### 3.3.4 曲线作图综合

把前面所有信息叠加，就能不依赖描点、较准确地手绘函数图像。标准清单：

    定义域与对称性 → 截距 → 渐近线（承大主题1）→
    f' 定增减区间与极值 → f'' 定凹凸区间与拐点 → 综合成图

这一节没有新公式，价值在于"把 f、f'、f'' 三层信息拼成一张图"的整合训练：f 给出高低、f' 给出上坡下坡（及山顶谷底位置）、f'' 给出弯曲方向（及拐点位置）。三者对齐无矛盾，草图才画得对。它也反向巩固了前几节——若你在某段同时判出"f'<0（下降）且 f''>0（下凹）"，图像就该是一条"下降但越来越平缓、逐渐触底"的曲线。

### 3.3.5 相关变化率（related rates）

**相关变化率**处理的是：几个随时间变化的量之间有一个方程约束，已知其中一些量的变化率，求另一个量的变化率。核心工具是对约束方程两边**关于时间 t 求导（用链式法则）**。

标准步骤：写出各量之间的关系式 → 两边对 t 求导（每个变量都带出一个 d/dt 因子）→ 代入某一时刻的已知量与已知变化率 → 解出所求变化率。

最小例子（吹气球）：球体体积与半径的关系

    V = (4/3)·π·r³

两边对 t 求导（链式法则）：

    dV/dt = 4·π·r²·(dr/dt)

sympy 求 dV/dr = `4*pi*r**2`，故 dV/dt = 4πr²·(dr/dt)。于是"已知充气速率 dV/dt、求某半径下的膨胀速率 dr/dt"就能代数解出。

初学者最大的坑是**求导时机搞反**：一定要先对含变量的一般关系式求导、再代入具体数值；如果先把当前时刻的 r 值代进去（把变量变成了常数）再求导，那一项的变化率就被错误地当成 0 了。相关变化率本质上是链式法则的应用题化身——它把"一个量随另一个量变"通过共同的自变量 t 串成一条链，是理解大主题2 链式法则"变化如何沿变量链传播"的绝佳落地场景，也预演了后续多变量与反向传播里"变化率沿路径相乘/相加"的思想。

## 3.4 L'Hôpital 法则

### 3.4.1 不定型（indeterminate forms）

**不定型**指极限直接代入后得到的、无法据此判断结果的符号组合。最基本的两种是

    0/0    与    ∞/∞

此外还有 0·∞、∞ − ∞、0⁰、1^∞、∞⁰ 五种，共七种。它们叫"不定"是因为**结果不由这个符号形式决定**：同样是 0/0，极限可以是任意有限数、也可以是 0、∞ 或不存在，必须进一步分析。

对照一下"定型"能帮助理解：像 2/∞（→0）、∞+∞（→∞）、5/0⁺（→+∞）这些代入后结论是确定的，不是不定型。而 0/0 之所以危险，是因为分子分母都在趋于 0，谁"跑得更快"决定了比值——这正是导数（变化速率）能派上用场的地方，引出洛必达法则。

最小例子：sin x / x 当 x→0 是 0/0 型，其真实极限为 1（大主题1 已作为特殊极限出现）；而 x²/x 当 x→0 也是 0/0 型，极限却是 0。同一符号、不同答案，这就是"不定"的含义。

### 3.4.2 洛必达法则及其适用条件

**L'Hôpital 法则**：当 x→a（a 可为有限数或 ±∞）时，若极限 f(x)/g(x) 呈 0/0 或 ∞/∞ 不定型，且 f、g 在 a 附近可导、g'(x) ≠ 0，则

    lim f(x)/g(x) = lim f'(x)/g'(x)

（右端极限存在或为 ±∞ 时，等式成立）。也就是"分子分母各自求导后再取极限"。

三个适用条件必须同时满足，否则用错：

    (1) 必须先是 0/0 或 ∞/∞ 型（不是不定型时严禁使用）
    (2) f、g 在 a 的去心邻域内可导，且 g'(x) ≠ 0
    (3) 右端 lim f'/g' 存在（有限或 ±∞）；若右端不存在，本法则不给结论（不能反推左端不存在）

最小例子：

    lim(x→0) sin x / x = lim(x→0) cos x / 1 = 1

    lim(x→0) (eˣ − 1)/x = lim(x→0) eˣ / 1 = 1

sympy 验证：`lim sinx/x: 1`、`lim (e^x-1)/x: 1`、以及 ∞/∞ 型 `lim ln x / x at oo: 0`，全部吻合。

头号易错点：**对"非不定型"乱用洛必达**。例如 lim(x→0) (x+1)/(x+2) 直接代入是 1/2（不是不定型），此时若擅自分子分母求导得 1/1 = 1，就得到错误答案。用之前务必先核验是不是 0/0 或 ∞/∞。第二个坑是"洛必达不收敛不代表原极限不收敛"：条件(3) 是单向的——右端存在 ⟹ 左端等于它；右端震荡不存在时，原极限仍可能存在，需换方法。它的理论根据是柯西中值定理（3.2.3 提及），本课了解这一出处即可，不展开证明。

### 3.4.3 其它不定型的化归

0·∞、∞−∞、0⁰、1^∞、∞⁰ 这五种不能直接套洛必达，要**先代数变形化成 0/0 或 ∞/∞**再用。常用手法：

    0·∞：把一个因子倒下去，写成 0/0 或 ∞/∞
    ∞−∞：通分或有理化，合并成单个分式
    0⁰ / 1^∞ / ∞⁰：先取自然对数 y = f^g ⟹ ln y = g·ln f，转成 0·∞ 再化 0/0，求出 lim ln y 后回代 e^(·)

最小例子（0·∞ 型）：

    lim(x→0⁺) x·ln x = lim(x→0⁺) (ln x)/(1/x) = lim (1/x)/(−1/x²) = lim(−x) = 0

sympy 验证 `lim x*ln x (0*inf): 0`。再看一个 1^∞ 的经典：

    lim(x→∞) (1 + 1/x)^x = e

sympy 输出 `lim (1+1/x)^x at oo: E`，正是自然常数 e 的定义式，通过取对数化成 0·∞→0/0 求 lim ln y = 1、再回代 e¹ = e。

这一节的要点不是记住五种变形的机械步骤，而是理解"**洛必达只吃 0/0 和 ∞/∞ 两种主食，其余不定型都得先加工成这两种**"。取对数处理幂指型（0⁰/1^∞/∞⁰）是初学者最生疏的一招，务必掌握"设 y、取 ln、求 lim ln y、回代指数"这条固定流水线。

- 锚点：Stewart《Calculus》§4.4 Indeterminate Forms and l'Hospital's Rule（含七种不定型、0/0 与 ∞/∞ 主型、幂指型取对数化归）；核实 2026-07-26
