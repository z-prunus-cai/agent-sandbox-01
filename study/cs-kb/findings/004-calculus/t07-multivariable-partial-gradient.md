**多元微积分 = 把单变量导数"按方向拆开、按结构打包"**。一个多元函数 f(x, y, …) 在某点不再只有一个斜率，而是沿每条坐标轴各有一个斜率（偏导数）；把这些偏导数排成一个向量，就是**梯度**，它一举回答"最陡上升往哪个方向、有多陡"；把梯度点乘任意单位方向，就得到那个方向上的**方向导数**。当函数从向量到向量（多输入多输出），把所有偏导数排成矩阵，就是**雅可比矩阵**——它是多元链式法则的"乘法积木"，也正是神经网络反向传播逐层相乘的那块地基。最后，把二阶偏导数排成矩阵得到 **Hessian**，用它在临界点判断"碗口朝上（极小）、朝下（极大）还是马鞍（鞍点）"。抓住"一阶偏导→梯度/雅可比看方向、二阶偏导→Hessian 看弯曲"这根钉子，本章判据全能挂上去。

## 7.1 偏导数

### 7.1.1 多元函数

多元函数是把多个自变量映射到一个因变量的函数，例如 f(x, y) 或 f(x₁, x₂, …, xₙ)。它的图像不再是一条曲线，而是（对二元函数）三维空间里的一张曲面 z = f(x, y)。

    z = f(x, y),  定义域 ⊆ ℝ²,  值域 ⊆ ℝ

初学者的第一道坎是从"一根输入轴"跳到"多根输入轴"。单变量函数 y = f(x) 画出来是平面上一条曲线，你沿一个方向走就行；而 z = f(x, y) 的输入是一整个平面 (x, y)，输出是它上方的高度，画出来像一片起伏的山地。可视化上有两种常用工具：一是**曲面图**（直接画三维高度），二是**等高线图**（把高度相同的点连成一圈圈，像地图上的等高线）。等高线在后面理解梯度时极其有用——梯度永远垂直于等高线。

f(x, y) = x² + y² 是一个开口朝上的碗（旋转抛物面），它的等高线是一圈圈同心圆，越往外高度越高。这个"碗"是本章反复用的直觉道具，因为它有唯一的最低点 (0,0)，方便验证极值判据。

多元函数的"极限存在"比单变量苛刻得多——单变量只需左、右两个方向逼近一致，多元则要求**沿任意路径**逼近都得到同一个值。所以有些函数沿直线逼近处处一致，却因为沿抛物线路径逼近不同而极限不存在。本课不深挖多元极限的病态例子，但要知道"偏导存在"并不能保证函数在该点连续或可微，这是和单变量最大的观念差异。

### 7.1.2 偏导数

偏导数是"只让一个自变量变化、其余全部当常数冻住"时函数的变化率。对 f(x, y)，关于 x 的偏导数记作 ∂f/∂x 或 f_x，定义为

    ∂f/∂x = lim_{h→0} [ f(x+h, y) − f(x, y) ] / h

即在 y 固定的前提下，对 x 做普通的单变量求导。

直觉上，偏导数就是"切一刀再求斜率"：想求 ∂f/∂x，就用一个平行于 xz 平面的刀面（y = 常数）去切那张曲面，切出来是一条一维曲线，∂f/∂x 就是这条曲线的普通斜率。所以偏导数把陌生的多元求导，还原成了你已经会的单变量求导——**只需把非目标变量当作数字常数**。

f(x, y) = x²y + sin(y)。

    ∂f/∂x = 2xy         （把 y 当常数，对 x 求导；sin y 是常数导数为 0）

    ∂f/∂y = x² + cos(y)  （把 x 当常数，对 y 求导）

最常见的错误正是"忘了冻住另一个变量"：求 ∂f/∂x 时若把 sin(y) 也当成含 x 的项去处理，或漏掉 x²y 中 y 这个常数系数，都会算错。记住口诀"求谁对谁导，其余全是数"。

偏导数的记号也要认全：∂ 是专门用于偏导的圆体 d，不能写成普通的 d；f_x、f_y 是下标简写；在物理/工程里有时会强调"固定哪些变量"，写成 (∂f/∂x)_y，本课默认其余变量全固定。

### 7.1.3 高阶偏导数与相等性（Clairaut / Schwarz 定理）

对偏导数再次求偏导，得到二阶偏导数。二元函数有四个二阶偏导：f_xx、f_yy 以及两个**混合偏导** f_xy、f_yx。其中 f_xy 表示"先对 x 求偏导、再对 y 求偏导"。

    f_xy = ∂/∂y ( ∂f/∂x ),   f_yx = ∂/∂x ( ∂f/∂y )

**Clairaut 定理（也叫 Schwarz 定理）**：若 f_xy 与 f_yx 在某点附近都存在且连续，则在该点两者相等——

    f_xy = f_yx

也就是说，混合偏导数与求导顺序无关。

"先对 x 再对 y"和"先对 y 再对 x"竟然一样。直觉是：二阶混合偏导衡量的是"沿 x 走一点再沿 y 走一点"造成的高度净增量，而这个净增量对应曲面上一个小矩形的对角变化，绕矩形哪个方向走一圈是对称的，所以两种顺序结果相同。它的实用价值很大——算混合偏导时可以挑更好算的那个顺序，还能用两者是否相等来**自查计算有没有出错**。

定理要求二阶偏导**连续**。存在但不连续的病态函数（教材里有 f = xy(x²−y²)/(x²+y²) 这类反例）会出现 f_xy ≠ f_yx。本课涉及的函数（多项式、指数、三角及其组合）都光滑连续，可以放心用相等性。

sympy 符号验证（f = x²·sin y + e^{xy}）：`f_xy − f_yx` 化简为

    0

即两种求导顺序给出完全相同的结果，Clairaut 定理成立（脚本与环境串见文末"来源与时效"）。

## 7.2 梯度与方向导数

### 7.2.1 梯度（gradient）

梯度是把一个多元函数的全部一阶偏导数排成的**向量**，记作 ∇f（读作"nabla f"或"grad f"）。对 f(x, y)：

    ∇f = ( ∂f/∂x , ∂f/∂y )

对 n 元函数则是 n 维向量 ∇f = (∂f/∂x₁, …, ∂f/∂xₙ)。

梯度是本章最重要的对象，它有两个必须记牢的几何性质：**梯度方向 = 函数上升最快的方向；梯度的模长 = 那个最快方向上的上升速率**。反过来，负梯度 −∇f 就是下降最快的方向——这正是机器学习里"梯度下降"训练算法的名字来源：沿 −∇f 一步步挪，就能最快地把损失函数往下降。

第二个几何性质：**梯度垂直于等高线（等值面）**。站在山坡上，等高线是"高度不变"的方向，而梯度是"高度变化最快"的方向，两者恰好垂直。这条性质在 7.4 的拉格朗日乘子里会直接用到。

f(x, y) = x² + y²（那个碗），

    ∇f = (2x, 2y)

在点 (1, 2) 处 ∇f = (2, 4)，指向远离原点的方向——正确，因为这个碗越往外越高，最陡上升当然是背离碗底往外爬。sympy 验证 ∇f=(2x,2y)、在 (1,2) 处取值 [2, 4]，与手算一致。

梯度是向量不是标量，写答案别丢了方向；另外 ∇f 本身是一个随点变化的**向量场**，只有代入具体点才得到一个确定向量。

### 7.2.2 方向导数（directional derivative）

方向导数衡量函数沿**任意指定方向**（不限于坐标轴）的变化率。设 u 是一个**单位向量**，f 在点 P 沿 u 的方向导数为

    D_u f = ∇f · u

即梯度与该单位方向向量的点积。

它是偏导数的推广：偏导数只测"沿 x 轴"或"沿 y 轴"的变化率，而方向导数能测"沿东偏北 37°"这种任意方向。公式 D_u f = ∇f·u 把它一步归约到梯度——你只要算一次梯度，就能通过点积得到所有方向的变化率，不必对每个方向重新求极限。

这个点积公式还顺带证明了 7.2.1 的核心断言。因为 ∇f·u = |∇f|·|u|·cos θ = |∇f|·cos θ（u 是单位向量），当 u 与 ∇f 同向（θ=0，cos θ=1）时方向导数最大、等于 |∇f|；当垂直（θ=90°）时方向导数为 0。这就解释了"梯度方向上升最快、模长是最快速率、沿等高线方向变化率为零"。

    D_u f = |∇f| cos θ   （θ 为 u 与 ∇f 的夹角）

f = x²+y² 在 (1,2)，∇f=(2,4)，取方向 u=(3,4)/5=(0.6, 0.8)（已单位化）：

    D_u f = (2)(0.6) + (4)(0.8) = 4.4

sympy 用有理数计算得 22/5 = 4.4，与手算一致。

最常见的错误是**忘记把方向向量单位化**。若直接拿 (3,4) 而不除以其模长 5 去点积，会得到 2·3+4·4=22，把变化率放大了 5 倍。定义里的 u 必须是单位向量，否则数值失去"每单位距离变化多少"的意义。

### 7.2.3 切平面与线性近似

对光滑曲面 z = f(x, y)，在点 (a, b) 处的**切平面**是最贴合曲面的那张平面，方程为

    z = f(a, b) + f_x(a, b)·(x − a) + f_y(a, b)·(y − b)

它是单变量"切线"在多元的推广：把两个偏导数分别当作沿 x、沿 y 的斜率，用它们撑起一张平面去逼近曲面。

由此得到**线性近似（局部线性化）**：在 (a,b) 附近，

    f(x, y) ≈ f(a, b) + f_x(a, b)·(x − a) + f_y(a, b)·(y − b)

意思是"在一个点附近，任何光滑函数都近似等于它的切平面"。这正是深度学习里一切"梯度一阶近似"的根：把复杂损失函数在当前参数点用切平面（一阶项）替代，就能判断往哪挪能下降。可以把右边的一阶项写成梯度点积形式 f(a,b)+∇f·(Δx, Δy)，与 7.2.2 的方向导数同源。

线性近似只在"离切点足够近"时才准，离得远误差会累积（缺的是二阶及以上项，7.4 的 Hessian 就是补二阶项）。另外，"偏导都存在"并不足以保证切平面真的贴合曲面——严格意义上需要函数**可微**（偏导存在且连续是常用的充分条件），本课涉及的光滑函数都满足。

## 7.3 多元链式法则与雅可比

### 7.3.1 多元链式法则

当一个多元函数的自变量本身又是别的变量的函数时，用多元链式法则求导：各条"影响路径"的偏导数乘积**相加**。典型情形 z = f(x, y)，而 x = x(t)、y = y(t)：

    dz/dt = (∂f/∂x)(dx/dt) + (∂f/∂y)(dy/dt)

即 z 通过 x 影响的那条路径，加上通过 y 影响的那条路径。

直觉是"多条路一起算总账"：t 变一点，会同时推动 x 和 y 变化，而 x、y 又各自推动 z 变化。z 的总变化率 = 沿 x 这条路传过来的 + 沿 y 这条路传过来的。这与单变量链式法则 dz/dt=(dz/dx)(dx/dt) 的区别就在于"有多条并行路径要相加"。画一张"依赖树"（z 在顶，下接 x、y，再下接 t），把每条从 t 到 z 的路径上的偏导乘起来、再把所有路径求和，就是通用记法。

更一般地，若中间变量是多个外部变量的函数（如 x=x(s,t)、y=y(s,t)），则对每个外部变量分别写一条链式法则：

    ∂z/∂s = (∂f/∂x)(∂x/∂s) + (∂f/∂y)(∂y/∂s)

一是漏掉某条路径（少加了一项）；二是把该用偏导 ∂ 的地方写成全导 d（当中间变量依赖多个外部变量时，中间到外部这一段是偏导）。判断标准：某个量只依赖一个变量就用 d，依赖多个就用 ∂。

### 7.3.2 雅可比矩阵（Jacobian）

当函数从向量到向量（多输入 n 个、多输出 m 个），F: ℝⁿ → ℝᵐ，把所有一阶偏导数排成一个 m×n 矩阵，就是**雅可比矩阵** J：第 i 行第 j 列是第 i 个输出对第 j 个输入的偏导数。

    J_{ij} = ∂F_i / ∂x_j

例如 F(x, y) = (x²y, sin(xy))，则

    J = [ 2xy      x²      ]
        [ y·cos(xy)  x·cos(xy) ]

雅可比是"梯度的推广"：单个标量输出的函数，其雅可比就是梯度（转置成一行）；多个输出时，把每个输出的梯度堆成一行行，就得到雅可比矩阵。它的每一行是"某个输出的梯度"，每一列是"某个输入的影响"。

sympy 用 `F.jacobian([x, y])` 得到的矩阵与上式逐项一致（脚本见文末），确认排列约定"行=输出、列=输入"。

雅可比的核心用途是把 7.3.1 的多元链式法则写成**矩阵乘法**：若 z = F(y) 且 y = G(x)（两层复合），则复合函数的雅可比等于两个雅可比矩阵相乘

    J_{F∘G}(x) = J_F(y) · J_G(x)

这正是 ML 反向传播的数学骨架——神经网络是一层套一层的复合函数，整个网络对参数的导数，就是把各层雅可比矩阵按链式法则连乘起来。反向传播之所以"反向"，是因为按从输出层往输入层的顺序做这一串矩阵乘法（配合缓存中间结果）在计算上最省。理解到"雅可比 = 每层的局部导数积木、链式法则 = 把积木乘起来"这一层，就足够对接 L5-02。

雅可比的形状是"输出数 × 输入数"，行列顺序不能反（反了就是它的转置，矩阵乘法会对不上）；另外并非所有教材都用同一转置约定，读文献时先确认它的"行是输出还是输入"。

## 7.4 多元极值与 Hessian

### 7.4.1 临界点（多元）

多元函数的**临界点**是梯度为零向量（或梯度不存在）的点。对 f(x, y)：

    ∇f = 0  ⟺  f_x = 0  且  f_y = 0

它是"函数可能取到局部极值的候选位置"，是单变量"f'=0"在多元的推广。

在山地曲面上，山顶、谷底、以及"马鞍点"这三类位置，切平面都是水平的（沿任何坐标方向的斜率都为 0），也就是梯度为零。所以找极值第一步同样是"先解方程组 f_x=0, f_y=0 揪出全部临界点候选"，再逐个判定类型。

和单变量最大的新增情况是**鞍点（saddle point）**：一个方向上是极小、另一个方向上是极大的点，形状像马鞍或薯片中心。它梯度为零却既非极大也非极小，是单变量里没有的类型，也是多元优化里最需要小心的对象（神经网络高维损失面上鞍点比局部极小多得多）。

最小例子（后面判据要用）：f = x³ + y³ − 3xy，解 f_x=3x²−3y=0、f_y=3y²−3x=0，sympy 求得临界点 (0,0) 与 (1,1) 两个。

### 7.4.2 Hessian 矩阵与二阶判据

**Hessian 矩阵** H 是把全部二阶偏导数排成的方阵，第 (i,j) 元是 ∂²f/∂x_i∂x_j。对 f(x,y)：

    H = [ f_xx  f_xy ]
        [ f_yx  f_yy ]

由 Clairaut 定理（7.1.3），f_xy=f_yx，所以 Hessian 是**对称矩阵**。

在临界点用 Hessian 判定极值类型，二元情形常写成**判别式**（二阶判据）：令

    D = f_xx · f_yy − (f_xy)²   （即 Hessian 的行列式 det H）

则在临界点：

    D > 0 且 f_xx > 0 ⟹ 局部极小

    D > 0 且 f_xx < 0 ⟹ 局部极大

    D < 0            ⟹ 鞍点

    D = 0            ⟹ 判据失效（需其他方法）

D 是 Hessian 的行列式，等于两个特征值之积。两个特征值同为正（碗口朝上→极小）、同为负（碗口朝下→极大）时 D>0，此时再看 f_xx 定朝向；一正一负（一个方向上凹、一个方向下凹→马鞍）时 D<0。这与线性代数里"Hessian 正定→极小、负定→极大、不定→鞍点"是同一件事的两种说法——判别式版本是二元特例，正定/负定版本适用任意维（喂 L1-03 二次型与正定性、以及 L5-02 优化）。

sympy 验证 f = x³+y³−3xy：Hessian 为 [[6x, −3],[−3, 6y]]。

    在 (0,0)：D = 0·0 − 9 = −9 < 0 ⟹ 鞍点

    在 (1,1)：D = 6·6 − 9 = 27 > 0，f_xx=6 > 0 ⟹ 局部极小

与判据预测一致（脚本见文末）。

一是 D=0 时判据**完全无效**，不能猜，得另想办法（如沿路径分析）；二是别把 f_xx 的符号判据用在 D<0 的情形——D<0 已经是鞍点，不必也不能再看 f_xx；三是记混判别式里的减号和平方项，D = f_xx·f_yy − (f_xy)²，中间是减号、混合偏导要平方。

### 7.4.3 拉格朗日乘子（Lagrange multipliers）

拉格朗日乘子法求**带等式约束**的极值：在约束 g(x,y)=0 下求 f(x,y) 的极值。核心方程是：在最优点，目标函数梯度与约束函数梯度平行——

    ∇f = λ ∇g   （λ 为拉格朗日乘子）

再联立约束 g(x,y)=0，一起解出候选点与 λ。

约束 g=0 是一条曲线，你只能沿这条曲线走。当你沿曲线走到 f 的等高线与约束曲线**相切**的那一点时，f 达到约束下的极值——因为若还相交不相切，就说明沿曲线还能往 f 更大（或更小）的等高线挪。相切意味着两条曲线在该点法线同向，而梯度垂直于各自的等高线（7.2.1 性质），于是 ∇f 与 ∇g 平行，比例系数就是 λ。

构造上常用**拉格朗日函数** L = f − λg，令它对 x、y、λ 的偏导全为零，就自动重现上面那组方程（对 λ 求偏导即恢复约束 g=0）。

    L(x, y, λ) = f(x, y) − λ·g(x, y),   ∇L = 0

在单位圆 x²+y²=1 上求 f=xy 的极值。sympy 解出四个候选点，f=xy 在其中取值为 +1/2（在 (√2/2, √2/2) 与其对角点）和 −1/2（在另两点），故约束下最大值 1/2、最小值 −1/2（脚本见文末）。

一是别忘了把约束方程 g=0 一起联立（只解 ∇f=λ∇g 会漏掉约束，候选点不对）；二是拉格朗日法给的是"候选点"，哪个是最大、哪个是最小还要代回 f 比较（本课不展开二阶充分条件）；三是 λ 本身通常不是要求的答案，但它有含义——约束值微小放松时最优目标值的变化率（"影子价格"），在优化与经济学里重要，本课点到为止。这一节直接对接 L5-02 里"带约束的训练目标"与更一般的 KKT 条件。

## 附：本报告 Python 验证脚本与环境

以下脚本一次性验证本报告的载重结论（Clairaut 相等性、梯度、方向导数需单位化、雅可比排列、Hessian 二阶判据、拉格朗日乘子），可在基线环境复现。

基线 Py3.11.15/np2.4.6/gcc13.3 @2026-07-25；实际运行 sympy 1.14.0（`python3 -c "import sympy; print(sympy.__version__)"` → `1.14.0`）。

```python
import sympy as sp
x, y = sp.symbols('x y', real=True)

# 1. Clairaut：混合偏导相等
f = x**2*sp.sin(y) + sp.exp(x*y)
print(sp.simplify(sp.diff(f, x, y) - sp.diff(f, y, x)))   # -> 0

# 2. 梯度
f2 = x**2 + y**2
grad = [sp.diff(f2, v) for v in (x, y)]
print(grad, [g.subs({x:1, y:2}) for g in grad])           # [2*x, 2*y] [2, 4]

# 3. 方向导数（u 必须单位化）
u = sp.Matrix([sp.Rational(3,5), sp.Rational(4,5)])
gvec = sp.Matrix([g.subs({x:1, y:2}) for g in grad])
print((gvec.T*u)[0])                                       # -> 22/5 = 4.4

# 4. 雅可比（行=输出，列=输入）
F = sp.Matrix([x**2*y, sp.sin(x*y)])
print(F.jacobian([x, y]))
# [[2*x*y, x**2], [y*cos(x*y), x*cos(x*y)]]

# 5. Hessian + 二阶判据 D = fxx*fyy - fxy^2
g = x**3 + y**3 - 3*x*y
H = sp.hessian(g, (x, y))                                  # [[6x,-3],[-3,6y]]
for c in sp.solve([sp.diff(g,x), sp.diff(g,y)], [x,y], dict=True):
    Hc = H.subs(c); D = Hc[0,0]*Hc[1,1] - Hc[0,1]**2
    print(c, "D=", D, "fxx=", Hc[0,0])
# {x:0,y:0} D=-9 (鞍点)；{x:1,y:1} D=27 fxx=6 (局部极小)

# 6. 拉格朗日：单位圆上 f=xy 的极值
lam = sp.symbols('lam', real=True)
L = x*y - lam*(x**2 + y**2 - 1)
for s in sp.solve([sp.diff(L,x), sp.diff(L,y), x**2+y**2-1], [x,y,lam], dict=True):
    print((x*y).subs(s))                                   # 取值 ±1/2
```

真实输出（节选，与正文所引数值逐条一致）：

    1. 0
    2. [2*x, 2*y] [2, 4]
    3. 22/5
    4. Matrix([[2*x*y, x**2], [y*cos(x*y), x*cos(x*y)]])
    5. {x:0,y:0} D=-9 fxx=0 (鞍点)；{x:1,y:1} D=27 fxx=6 (极小)
    6. -1/2, -1/2, 1/2, 1/2  （约束下极值为 ±1/2）
