# 报告格式规范（v3 · 广度优先的"教辅" · 已定）

> 用户定调：知识库以**时效性 > 正确性 > 广度**为序，覆盖最多、最新；但成品要读起来像**教辅**，不是半罗列。
> - **舍弃的是"专家级纵深"**（不做长篇机制深挖/推导/设计权衡长论），**不是"讲不清"**：每个内容项都要讲到**初学者能懂**。
> - **不是舍弃验证**：可放弃实机验证，但**绝不放弃多来源比对**。
> 本文件（v3）作为 Round 3c 造 prompt 与 Round 4 产报告的模板。

## 一、粒度规则（不变）
- 默认 **1 大主题 = 1 报告**；小主题多/跨机制/过长时拆成 N 份（`NNN-<slug>-a/-b`）。
- 拆分判定在 Round 3c 由 subagent 逐大主题给「1 份 / 拆 N 份 + 理由」，汇总入 ledger。

## 二、报告内部结构（教辅式；标题层级固定）

> 层级：`#` 大主题（=报告标题） → `##` 小主题（=章节） → `###` 相关内容（=每个内容项一节）。
> 每个 `###` 内容项下（**不写任何行首标签**——不限于「核心概念：」「辅助说明：」，也含「核心说明：」「核心结论：」「辅助直觉：」「直觉：」等一切"词＋："开头的标签；直接正文、靠空行分段）：
> 1. **核心说明**（必需）：这个内容项是什么、定义/关键结论，正确。
> 2. **辅助说明**（必需且充分）：面向**初学者**把它讲懂所需的内容——直觉 / 为什么这样 / 最小例子 / 易错点 / 与前后关联；写到初学者能懂为止，可多段。**不是可省点缀。**
> **公式独占行**：任何公式单独成行（块级），不内联埋进句子。

```
# <课ID·大主题号> <大主题标题>
> 基线/核实：<日期> ｜ 先修：<课/大主题> ｜ 一手锚点：<教材§/规范/官方文档@版本> ｜ 成熟度：GA/⚙演进快（仅系统/前沿课标）

## <X.1> <小主题名>

### <X.1.1 相关内容名（概念/公式/术语/最佳实践/陷阱）>
（核心说明：一段把"是什么/定义/结论"讲清，正确；必要处标时效/版本。）

（若含公式，公式独占一行，如）
det(A − λI) = 0

（辅助说明：必需且充分——初学者读懂所需的直觉/为什么/最小例子/易错点/关联；可多段。）

### <X.1.2 相关内容名>
（核心说明。）

（辅助说明。）

### <X.1.3 …>
（列全本小主题下的所有相关内容，广度完备；每节都要讲到初学者能懂，但不做专家级纵深。）

#### 来源与时效（本小主题末集中列，不逐项脚注）
- 锚点：<教材§ / 规范 / 官方文档 + 版本 + 核实日期>（本章多来源比对用到的来源）
- 前沿项标「⚙演进快·锚版本·随时变」；未证实数值/默认值标「待核」，不编造。
- 冲突项：<来源分歧点，两边定位>

## <X.2> <小主题名>
### <X.2.1 …>
（核心说明。）

（辅助说明。）
```

## 三、内容纪律（讲解浅，但验证不放松）
> 关键澄清（用户 2026-07-25）：**"舍弃深度" = 讲解浅（核心解释+辅助即止），不是舍弃验证。**
> 可放弃**实机验证**，但**绝不放弃多来源比对**。

**验证红线（强制，逐项）**
- **多来源比对**：每个内容项须用 **≥2 个独立来源交叉核对**，优先一手（教材/规范/官方文档）；来源打架时**两边都记、点明分歧、不和稀泥**。这是本知识库正确性的主承重手段。
- **不编造**：具体数值/默认值/版本号/公式系数——来自比对通过的来源，或标「待核」，绝不凭记忆填。
- **标时效**：每份给核实日期；前沿项硬标演进快；改名/退役/新版单独标。
- **广度完备**：小主题下的内容项要"查全"，宁可多列浅讲，不遗漏。

**教辅可读性（必达）**
- 每个内容项**核心说明 + 辅助说明都必需**；辅助说明要**充分到初学者能懂**（直觉/为什么/例子/易错点），不是一句带过的点缀。
- **不写任何行首标签**：不限于「核心概念：」「辅助说明：」——也包括「核心说明：」「核心结论：」「辅助直觉：」「直觉：」等一切"词＋中文冒号"开头的段落标签。`###` 下直接写正文段落，靠空行分核心/辅助两段。
- **公式独占行**（块级），不内联埋进句子。

**可放松的部分**
- **本机 Python / 实机实证降为可选**：仅在便宜且能快速加固某公式/输出/默认值时做，不逐项强制。（多来源比对**不能**用它替代——它是补充，不是替代。）
- **舍专家级纵深**：不写长篇机制深挖/完整推导/设计权衡长论；讲到"初学者懂"为止，不再纵深展开。

## 四、相对 skill 的差异（明确）
1. 交付从"深度教学叙事(九要素)"改为"**广度覆盖式教辅**"：小主题=章节，章节下列全内容项；每项核心说明+充分辅助说明、讲到初学者懂，但不做专家纵深；**无标签、公式独占行**。
2. 排序优先级 **时效>正确>广度>（放弃）讲解深度**（skill 是深度取证优先）。
3. **验证不放松**：多来源比对**强制保留**（≥2 独立来源、优先一手、冲突显式）；仅**实机/Python 实证**降为可选补充。
4. 学习目标并入辅助说明，不单列段。
5. 来源标注：**章节末集中列锚点**，不逐项脚注。
6. **保留**：一手锚定、不编造、标时效、前沿硬标、subagent 直接落盘、committed ledger、独立对抗质检（质检重点=**覆盖查全 + 多来源比对是否做 + 正确性 + 时效**，而非深度）。

## 五、已定参数
- 取向：广度优先、成品为**教辅**（每项讲到初学者懂，但不做专家纵深）；**多来源比对强制、实机验证可选**。
- 每项结构：核心说明 + 辅助说明（**都必需**，辅助须充分）；**不写标签**；**公式独占行**。
- 来源标注：章节末集中列锚点。
- 深度边界：讲清 > 讲全纵深；省的是"专家级深挖"，不是"讲明白"。
